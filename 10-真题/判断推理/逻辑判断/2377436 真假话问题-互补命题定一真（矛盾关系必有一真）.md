# 真假话问题-互补命题定一真（矛盾关系必有一真）

考点：[[20-考点/判断推理/逻辑判断/真假话问题-互补命题定一真（矛盾关系必有一真）|逻辑判断 / 真假话问题-互补命题定一真（矛盾关系必有一真）]]


**问法模型**：'只有一个人说对'的日期断言题 → 先找两个不重不漏覆盖全部可能情况的互补命题锁定唯一真话位置，其余命题全假，再用假话信息排除选项

## 推理链
1. 第1步：提取五人断言——爷爷'是周末'、奶奶'星期二、四或六'、爸爸'是星期一'、儿子'星期一、三、五或日'、女儿'是星期五'
2. 第2步：发现奶奶与儿子所列日期（二/四/六 与 一/三/五/日）不重不漏恰好覆盖一周七天，构成互补关系，必有一真一假
3. 第3步：由'只有一个人说对'可知，唯一真话必落在奶奶或儿子身上，故爷爷、爸爸、女儿三人的话均为假
4. 第4步：爷爷假→不是周末（排除周六、周日）；爸爸假→不是星期一；女儿假→不是星期五
5. 第5步：若儿子是真话者：周一、周五已排除，周日属周末也被排除，只剩星期三；若奶奶是真话者：周六属周末被排除，只剩星期二或星期四
6. 第6步：对照选项——A星期一、C星期五、D星期六均被三句假话直接排除，仅B星期三可选；代入验证：星期三时只有儿子为真、其余四人皆假，符合'只有一人说对'

**最快解法**：⚡ 互补定真+排除法：一眼看出奶奶'二四六'与儿子'一三五日'拼成完整一周（必一真一假）→ 唯一真话在二人之中 → 爷爷、爸爸、女儿全假 → 直接排除'周末、周一、周五'，锁定B星期三

## 易错点
- ⚠ 找不到突破口：爷爷'周末'与爸爸'星期一'看似矛盾实非矛盾，真正的互补关系藏在奶奶与儿子的话中
- ⚠ 误以为答案不唯一而犹豫：星期二、星期四其实也满足条件，但题目问的是四个选项中'可能是'哪项，选项内只有星期三成立
- ⚠ 验证时忽略周日属周末：若选星期日，爷爷与儿子两人同真，违反'只有一人说对'的约束

## 母题抽象
> 🧩 当题干出现'只有一人说对/说错'且某两个命题所列情况不重不漏覆盖全部可能时，先把唯一真话锁定在这对互补命题中，其余命题一律为假，再用假话反面信息排除选项

**同类特征**：只有一个人说对、五人对同一事实作断言、所列日期恰好覆盖一周七天（互补）、周末/星期几的简单直言判断、问'可能是'哪一天、真假话排除型单选

### 题干
妈妈准备超市大减价活动日去购物，但她忘记活动的具体日期，于是她分别询问了如下五人，他们的回答分别是：
爷爷：是周末。
奶奶：是星期二、星期四或星期六中的一天。
爸爸：不对，是星期一。
儿子：是星期一、星期三、星期五或星期日中的一天。
女儿：是星期五。
如果这五个人中只有一个人说对了，那么超市大减价活动日可能是：

### 选项
- A. 星期一
- B. 星期三　✅
- C. 星期五
- D. 星期六

### 官方解析
第一步：找出题干矛盾关系。
根据题干可知，奶奶和儿子说的话是矛盾关系，矛盾关系必有一真，必有一假。
第二步：看其余。
已知只有一人说对了，可知爷爷、爸爸、女儿所说均为假话。即不是周末、不是周一、不是周五，排除ACD，只有B项符合。
故正确答案为B。
