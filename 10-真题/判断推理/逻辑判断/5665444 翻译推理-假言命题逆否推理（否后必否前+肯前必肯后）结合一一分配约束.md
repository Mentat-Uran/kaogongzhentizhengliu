# 翻译推理-假言命题逆否推理（否后必否前+肯前必肯后）结合一一分配约束

考点：[[20-考点/判断推理/逻辑判断/翻译推理-假言命题逆否推理（否后必否前+肯前必肯后）结合一一分配约束|逻辑判断 / 翻译推理-假言命题逆否推理（否后必否前+肯前必肯后）结合一一分配约束]]


**问法模型**：题干给出多条'如果…那么…'假言命题并追加确定事实（赵完成丙）→ 应采用'确定信息切入+否后否前/肯前肯后逐层传导'的翻译推理模型

## 推理链
1. 第1步：提取条件：(1)（张甲或李甲）→（赵乙或赵丁）；(2)（黄甲或黄丙）→李丁；新增确定事实：赵完成丙
2. 第2步：由'每人也只能完成其中的一项工作'知赵完成丙则赵不做乙也不做丁，这构成对条件(1)后件'赵完成乙或丁工作'的否定
3. 第3步：否后必否前 → '张或李完成甲'为假，即张且李都不完成甲工作
4. 第4步：甲工作只剩黄可做（赵做丙、张李不做甲），故黄完成甲工作，这是对条件(2)前件'黄完成甲或丙'的肯定
5. 第5步：肯前必肯后 → 李完成丁工作；至此甲=黄、丙=赵、丁=李，唯一剩余的乙工作只能由张完成
6. 第6步：对照选项，'张完成乙工作'为D项，得出结论

**最快解法**：⚡ 确定信息切入法+逆否链条：由'赵完成丙'直接否掉条件(1)后件（赵乙∨赵丁），否后得张李都不做甲→黄只能做甲→肯前得李做丁→甲丙丁已被黄赵李占据，乙只能归张，秒选D

## 易错点
- ⚠ 条件(1)前件是'张或李完成甲'，其否定应为'张且李都不完成甲'（德摩根），误按'张且李完成甲'的否定处理会推错
- ⚠ 忽略'每人只完成一项工作'的分配约束，推出李完成丁后不知道乙工作被唯一锁定在张身上，误选C或其他
- ⚠ 误将条件(2)理解为黄做丙也需单独讨论——赵已占据丙，黄只可能做甲，肯前对象唯一，混淆分支会绕远路

## 母题抽象
> 🧩 当题干出现多条'如果…那么…'假言命题+一个确定事实+人数与事项一一对应的分配约束时，用确定事实先否后（或肯前），沿逆否/肯前链条逐层传导，最后由剩余唯一选项锁定答案

**同类特征**：如果…那么…假言命题、前件后件含'或'的复合条件、4人4项工作一一对应分配、题干追加确定事实（赵完成丙）、问法为'可以得出下列哪项'、结论为某一具体人员对应具体工作

### 题干
办公室拟将甲、乙、丙、丁4项工作分配给张、黄、李、赵四人去完成。每项工作只能由一人完成，每人也只能完成其中的一项工作。
已知：（1）如果张或者李完成甲工作，那么赵完成乙或者丁工作；（2）如果黄完成甲或者丙工作，那么李完成丁工作。
如果赵完成丙工作，那么可以得出下列        项。

### 选项
- A. 李完成乙工作
- B. 李完成甲工作
- C. 张完成丁工作
- D. 张完成乙工作　✅

<p>第一步：分析题干条件。</p><p>（1）张 或 李完成甲工作<img flag="tex" src="../../../90-图片/公式图/formula-220d6005ff946aad.png" />赵完成乙 或 丁工作；</p><p>（2）黄完成甲 或 丙工作<img flag="tex" src="../../../90-图片/公式图/formula-220d6005ff946aad.png" />李完成丁工作；</p><p>（3）赵完成丙工作；</p><p>（4）每项工作只能由一人完成，每人也只能完成其中的一项工作。</p><p>第二步：根据题干条件进行推理。</p><p>根据条件（3）、（4）可知，赵完成丙工作，说明赵既不完成乙工作，也不完成丁工作，即是对条件（1）的否后，根据“否后必否前”可知，张 且 李都不完成甲工作，又因为赵完成丙工作，所以黄完成甲工作；黄完成甲工作是对条件（2）的肯前，根据“肯前必肯后”可知，李完成丁工作，再结合条件（4）可知，张完成乙工作。</p><p>故正确答案为D。</p>
