# 复合命题推理-类型辨识（充分条件假言推理与选言推理的叠套结构，排除直言三段论）

考点：[[20-考点/判断推理/逻辑判断/复合命题推理-类型辨识（充分条件假言推理与选言推理的叠套结构，排除直言三段论）|逻辑判断 / 复合命题推理-类型辨识（充分条件假言推理与选言推理的叠套结构，排除直言三段论）]]


**问法模型**：题干给出指定自然段文字并问'包含哪些复合型逻辑推理'、选项为类型编号两两组合 → 先把文字翻译成标准命题形式，辨析命题/推理类型，再用'未出现的类型排除法'锁定组合

## 推理链
1. 第1步：明确问法——短文第一、二自然段中'包含'的复合型逻辑推理是哪几种，须先翻译文字为标准命题再数类型
2. 第2步：翻译第一段——'（串通作弊或者有组织作弊）永远不允许进入公务员队伍'即'如果（串通作弊或有组织作弊），那么永远不允许进入公务员队伍'，前件由'或者'连接属选言命题，整体为充分条件假言命题（官方称'充分条件选言命题'）
3. 第3步：故第一段同时含②充分条件假言推理与④选言推理两种成分
4. 第4步：核对①直言三段论——其结构为P→Q、Q→S推出P→S（中项搭桥），题干两段均无'大前提+小前提+结论'的三段论结构，含①的A、B、C全部排除
5. 第5步：第二段官方译为'只有……才……'的必要条件命题表述（对广大考生公平/考试纪律严明）；对照选项，唯一不含①且与第一段复合结构吻合的组合是D（②④），当选

**最快解法**：⚡ 排除法：先验证①直言三段论（PQ、QS得PS的中项搭桥结构）在两段中均不存在，一步排除A、B、C三个含①选项，直接锁定D；回头验证第一段'（串通作弊或有组织作弊）→永不准入'确为'选言作前件的充分条件假言'叠套结构即可

## 易错点
- ⚠ 见第二段有'只有……才……'就误以为③必须入选，但选项中不存在含②③或③④的组合，陷入纠结（必要条件命题≠题干所考的复合推理组合）
- ⚠ 只认出第一段的'或者'选言结构，漏掉整体'如果……那么……'的充分条件假言骨架，漏选②
- ⚠ 把第一段误判为三段论（误以为存在中项搭桥），错选含①的A或B

## 母题抽象
> 🧩 当题干出现'文字材料中包含哪几种复合逻辑推理'且选项为推理类型编号组合时，先把文字翻译为标准命题（如果…那么…/只有…才…/或者…），识别命题叠套结构（如选言作前件的假言命题），再用'未出现的类型直接排除选项'锁定答案

**同类特征**：指定自然段中包含的复合型逻辑推理、选项为①②③④的两两组合、'串通作弊或者有组织作弊'——'或者'选言作前件、'永远不允许进入公务员队伍'——充分条件后件、'只有……才……'必要条件命题表述、'PQ、QS可得PS'式三段论结构缺失

### 题干
第48题短文第一第二自然段中，包含有复合型的逻辑推理，找出正确的选项：
①直言三段论推理    ②充分条件假言推理
③必要条件假言推理  ④选言推理

### 选项
- A. ①④
- B. ①②
- C. ①③
- D. ②④　✅

### 官方解析
第一步：翻译题干。
翻译题干第一段：充分条件选言命题：（串通作弊或者有组织作弊）永远不允许进入公务员队伍。
翻译题干第二段：必要条件命题“只有······才······”：对广大考生公平考试纪律严明。
第二步：逐一分析选项。
A项：并没有体现①直言三段论，即PQ、QS，可得“PS”，排除；
B项：并没有体现①直言三段论，即PQ、QS，可得“PS”，排除；
C项：并没有体现①直言三段论，即PQ、QS，可得“PS”，排除；
D项：第一段是（串通作弊或者有组织作弊）永远不允许进入公务员队伍，有②充分条件假言推理和④选言命题，当选。
故正确答案为D。
