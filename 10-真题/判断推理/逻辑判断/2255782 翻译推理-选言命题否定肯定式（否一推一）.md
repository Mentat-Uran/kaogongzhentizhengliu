# 翻译推理-选言命题否定肯定式（否一推一）

考点：[[20-考点/判断推理/逻辑判断/翻译推理-选言命题否定肯定式（否一推一）|逻辑判断 / 翻译推理-选言命题否定肯定式（否一推一）]]


**问法模型**：问'一定为假的是'→ 先由题干推出必然为真的确定结论，再找与该结论直接矛盾的选项（找矛盾模型）

## 推理链
1. 第1步：题干第一句建立选言关系：好文章 → 观点新颖深刻 或 论证逻辑清晰 或 语言表达生动感人（三者至少满足其一）
2. 第2步：题干给定两个事实：'韩某的文章是一篇好的文章' 且 '观点并不新颖深刻'（即肯定了前提，又否定了选言的第一个肢命题）
3. 第3步：根据相容选言'否一推一'规则：既然'观点新颖深刻'为假，则'论证逻辑清晰 或 语言表达生动感人'必须至少有一项为真，此为必然结论
4. 第4步：A项'清晰且生动'使选言为真，与题干不矛盾，排除
5. 第5步：B项'不清晰但生动'、D项'清晰但不生动'均有一项为真，选言成立，与题干不矛盾，排除
6. 第6步：C项'论证逻辑不清晰且语言表达也不生动感人'将两个肢命题同时否定，使'清晰或生动'这一必然结论为假，与题干直接矛盾，一定为假，当选

**最快解法**：⚡ 否一推一＋找矛盾法：由'观点不新颖深刻'一步推出'逻辑清晰或语言生动'必真，四个选项中唯一使该选言两项全为否定的即是矛盾项，秒选C

## 易错点
- ⚠ 把相容选言'或'误解为不相容'要么…要么'，误以为B、D含否定项就与题干矛盾（相容选言一项为真即真）
- ⚠ 方向搞反：把'一定为假'当成选'一定为真'的选项，错选A
- ⚠ 忽略前提'韩某的文章是好的文章'，没有先肯定'好文章'这一条件，否一推一无从启动

## 母题抽象
> 🧩 当题干出现'A→(B或C或D)'且给出'A且¬B'的特征时，用否一推一得'¬B→(C或D)必真'，问'一定为假'就选同时否定C和D的选项，问'一定为真'只能选'C或D'本身

**同类特征**：或者……或者……（相容选言）、一定为假、肯定前提且否定一个肢命题、否一推一、选言命题找矛盾

### 题干
一篇好的文章或者因为观点新颖深刻，或者因为论证逻辑清晰，或者因为语言表达生动感人。现在有人认为韩某的文章是一篇好的文章，但是他的文章观点并不新颖深刻。一定为假的是：

### 选项
- A. 韩某的文章论证逻辑清晰且语言表达生动感人
- B. 韩某的文章论证逻辑不清晰但语言表达生动感人
- C. 韩某的文章论证逻辑不清晰且语言表达也不生动感人　✅
- D. 韩某的文章论证逻辑清晰但语言表达不生动感人

### 官方解析
第一步：分析题干。
韩某的文章是一篇好的文章，但-观点新颖深刻，根据或关系“否一推一”可知，韩某的文章或者论证逻辑清晰，或者语言表达生动感人。
第二步：逐一分析选项。
A项：翻译为论证逻辑清晰且语言表达生动感人，满足或关系的其中一项，排除；
B项：翻译为-论证逻辑清晰且语言表达生动感人，满足或关系的其中一项，排除；
C项：翻译为-论证逻辑清晰且-语言表达生动感人，或关系两项均不成立，题干或关系则不成立，一定为假，当选；
D项：翻译为逻辑清晰且-语言表达生动感人，满足或关系的其中一项，排除。
本题为选非题，故正确答案为C。
