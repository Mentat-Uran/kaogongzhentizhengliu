# 分析推理-元素位置排列（多重位置约束下的唯一解判定，代入排除法）

考点：[[20-考点/判断推理/逻辑判断/分析推理-元素位置排列（多重位置约束下的唯一解判定，代入排除法）|逻辑判断 / 分析推理-元素位置排列（多重位置约束下的唯一解判定，代入排除法）]]


**问法模型**：题干给出'黄在绿紫之前、蓝≠B、红绿相隔一个抽屉'等位置约束，问'黄在哪个抽屉时排放顺序唯一' → 采用代入排除法，逐项代入黄球位置并枚举满足全部条件的排列，找出排列数恰为1的选项

## 推理链
1. 第1步：从题干提取三个约束——①黄球位置 < 绿球位置且 < 紫球位置（黄球后至少要留2个抽屉给绿、紫）；②蓝球≠B抽屉；③红球与绿球抽屉序号相差2（中间隔1个抽屉，红可在绿前或绿后）
2. 第2步：问法要求'排放顺序唯一'，故对4个选项依次代入黄球位置，枚举满足①②③的全部排列，排列数=1者当选；可先用约束①排除黄球在D、E的情形
3. 第3步：黄球在B（A项）：绿、紫可放C/D/E，红绿组合可为(红A,绿C)、(绿C,红E)、(红C,绿E)等，得蓝黄红紫绿、红黄绿紫蓝、蓝黄绿紫红等多种排列（蓝均不在B），排列不唯一，排除A
4. 第4步：黄球在C（B项）：绿、紫只能占D、E；红绿相差2且C已被黄占，绿在E则红须在C（被占），故只能绿在D、红在B；紫在E，蓝只能在A（满足蓝≠B），得唯一排列'蓝红黄绿紫'，当选
5. 第5步：黄球在D（C项）：黄球后仅剩E一个抽屉，无法同时放绿、紫两个球，违反约束①，排除；黄球在E（D项）：黄球后无抽屉，同理违反约束①，排除
6. 第6步：只有黄球在C抽屉时满足全部条件且排列唯一（蓝红黄绿紫），与选项对照，正确答案为B

**最快解法**：⚡ 代入排除法+先排不可能：先用'黄须在绿、紫之前'秒杀排除C（黄在D后仅剩1位）、D（黄在E后剩0位）；再对比A、B：黄在B时红绿组合(A,C)/(C,E)/(B,D)多个可行、排列不唯一；黄在C时绿紫被锁死在D/E、红绿差2只能红B绿D，唯一排列蓝红黄绿紫，直接选B

## 易错点
- ⚠ 忽略'红球和绿球之间隔着一个抽屉'是双向的（红可在绿前也可在绿后，位置差为2即可），漏数排列而误判唯一性
- ⚠ 忘记核对'蓝球不能放在B抽屉'这一禁位条件，多算或漏算可行排列
- ⚠ 未先用'黄球后须留出两个位置给绿、紫'排除黄在D/E，对不可能情形做无效枚举浪费时间

## 母题抽象
> 🧩 当题干出现多元素对固定位置的多重约束（先后顺序、相隔定距、禁位）且问'何情况下排列唯一'时，用代入法：先据'前置元素需占2个后位'排除后位不足的选项，再对剩余选项枚举验证排列数是否为1

**同类特征**：五个球匹配五个有序抽屉（元素-位置对应）、黄球在绿球和紫球前面（前置约束）、红球和绿球相隔一个抽屉（位置差为2）、蓝球不能放B抽屉（禁位条件）、问排放顺序唯一的情形、选项为单一位置，适合代入排除

### 题干
把红、黄、蓝、绿、紫五个小球放在五个排成一列的抽屉里，序号为A、B、C、D、E。要求:黄球放在绿球和紫球前面，蓝球不能放在B抽屉里，红球和绿球之间隔着一个抽屉。
问黄球放在哪个抽屉时，五个球的排放顺序是唯一的？

### 选项
- A. B抽屉
- B. C抽屉　✅
- C. D抽屉
- D. E抽屉

### 官方解析
该题需要将不同颜色的球和抽屉顺序做匹配，为排列组合题，优先用代入排除法，问黄球放在哪个抽屉时，五个球的排放顺序是唯一的，4个选项依次代入，满足要求即为正确答案。
A项，假设黄球放在B抽屉，根据题干要求，黄球在绿球和紫球的前面，红球和绿球隔一个，蓝球不在B，可以有蓝黄红紫绿、蓝黄绿紫红等排放顺序，并不唯一，排除；
B项，假设黄球放在C抽屉，根据题干要求，黄球在绿球和紫球的前面，红球和绿球隔一个，蓝球不在B，只有蓝红黄绿紫唯一的排放顺序，当选；
C项，假设黄球放在D抽屉，如果黄球放在D抽屉，题干要求黄球在绿球和紫球的前面，黄球后面只剩一个抽屉，无法同时放绿球和紫球，不满足题干要求，排除；
D项，假设黄球放在E抽屉，如果黄球放在E抽屉，与C项同理，题干要求黄球在绿球和紫球的前面，黄球后面没有抽屉，无法放绿球和紫球，不满足题干要求，排除。
故正确答案为B。
