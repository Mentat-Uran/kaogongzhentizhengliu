# 论证类-补充前提（确定主因需'单位强度×总量'复合数据）

考点：[[20-考点/判断推理/逻辑判断/论证类-补充前提（确定主因需'单位强度×总量'复合数据）|逻辑判断 / 论证类-补充前提（确定主因需'单位强度×总量'复合数据）]]


**问法模型**：题干给出'单位效果比值'但问'确定主要原因还需收集什么数据' → 用'总贡献=单位效果×数量'模型，寻找补充'总量'类数据的选项

## 推理链
1. 第1步：表格给出'导致相同温室效应的气体分子数比值'：二氧化碳=1、甲烷=20、氧化亚氮=160、氯氟烃=17000，即1个二氧化碳分子即可达到17000个氯氟烃分子相同的温室效果
2. 第2步：该比值只反映各气体'单位分子的温室效应强度'，属于'效果强度'维度，完全不涉及各气体在大气中的实际数量
3. 第3步：要判定'哪种气体主要导致温室效应'，必须比较各气体的总贡献，而总贡献=单位强度×大气中气体总量，当前缺少'总量'这一乘数
4. 第4步：D项'四种气体在大气中的总排放量'恰好补上数量维度，与表格强度数据结合即可比较总贡献、确定主因
5. 第5步：A项产源只说明气体来源、B项植物吸收量不等于大气实际存量、C项分子式与题干已有的比较无关，均无法与强度比值相乘得出总贡献，予以排除

**最快解法**：⚡ 乘法模型速判：表格数据是'单位强度'，问法要'确定主要原因'（即总贡献），公式'总贡献=强度×数量'中唯一缺失的是'数量/总量'，直接锁定D；A、B、C与'在大气中的量'无关，一秒排除

## 易错点
- ⚠ 误把'氯氟烃比值最大（17000）'当成主要气体，混淆'单位分子作用强度'与'总贡献'两个概念
- ⚠ 被B项'植物吸收量'干扰，误以为吸收影响大气存量，但吸收量既非排放总量也不能单独确定大气中的实际量
- ⚠ 被A项'产源'的因果联想带偏，误认为知道来源即可判断主因，忽略题干要的是可量化对比的数据

## 母题抽象
> 🧩 当题干出现'单位效果/单位强度比值表'+问'确定主要原因/总影响还缺什么数据'时，套用'总贡献=单位效果×总量'模型，选补充'总量/数量'的选项

**同类特征**：导致相同温室效应的气体分子数比值、不能确定哪种是主要气体、还应该收集下列哪项的数据、比值只反映单位强度、四种气体对比表格

### 题干
<p>科学家认为二氧化碳不是造成温室效应的主要原因，导致温室效应的主要为以下四种气体：</p><p><img width="563px" height="118px" src="../../../90-图片/题目图/17664db4d74f86e.png" /></p><p>从这个表不能确定哪种是影响温室效应的主要气体，还应该收集下列<u>          </u>的数据才能得出是什么气体主要导致了温室效应。</p>

### 选项
- A. 关于这四种气体的产源
- B. 植物所能吸收这些气体的量
- C. 这四种气体的分子式
- D. 这四种气体在大气中的总排放量　✅

### 官方解析
<p>温室效应是指透射阳光的密闭空间由于与外界缺乏热对流而形成的保温效应，即太阳短波辐射可以透过大气射入地面，而地面增暖后放出的长波辐射却被大气中的二氧化碳等物质所吸收，从而产生大气变暖的效应。大气中的二氧化碳就像一层厚厚的玻璃，使地球变成了一个大暖房。</p><p>从题干中表格可知，与其他三种气体相比，最少量的二氧化碳即可导致相同效果的温室效应，这仅说明了二氧化碳对温室效应的作用效果是最强的。但要确定哪种气体是造成温室效应的主要原因，还需确定每种气体在大气中的量。作用效果<img flag="tex" src="../../../90-图片/公式图/formula-4d90d7a7e1165b03.png" />排放量综合分析后方可确定，故D项正确，A、B、C三项均与题意无关。</p><p>故正确答案为D。</p>
