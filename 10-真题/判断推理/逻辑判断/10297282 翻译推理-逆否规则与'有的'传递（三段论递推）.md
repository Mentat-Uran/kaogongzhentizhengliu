# 翻译推理-逆否规则与'有的'传递（三段论递推）

考点：[[20-考点/判断推理/逻辑判断/翻译推理-逆否规则与'有的'传递（三段论递推）|逻辑判断 / 翻译推理-逆否规则与'有的'传递（三段论递推）]]


**问法模型**：'由此可以推出'→ 将直言命题翻译成箭头式，用逆否等价和'有的A→B→C'串联递推，排除换位陷阱

## 推理链
1. 第1步：翻译题干三个条件：（1）正式编制员工→参加周末团建；（2）后勤部门员工→非正式编制；（3）有的综合部门员工→未参加团建
2. 第2步：对（1）作逆否等价：未参加团建→非正式编制员工
3. 第3步：将（3）与逆否命题串联递推：有的综合部门员工→未参加团建→非正式编制，即'有的综合部门员工不是正式编制员工'
4. 第4步：对照选项，A项'综合部门有的员工不是正式编制员工'与递推结论完全一致，可以推出
5. 第5步：B项是把'有的综合部门员工不是正式编制'换位为'有的正式编制不是综合部门'，但'有的A不是B'不可换位，排除
6. 第6步：C、D项涉及'后勤部门'与'参加团建'的关系，题干只有'后勤→非正式编制'，由'非正式编制'对'是否参加团建'无必然指向（否定前件不能逆推），排除

**最快解法**：⚡ 逆否递推法：一眼锁定'所有正式编制都参加'与'综合有的没参加'这对条件，逆否得'没参加→非正式编制'，串联即得A，无需逐项细推B、C、D

## 易错点
- ⚠ 把'有的A不是B'错误换位成'有的B不是A'而误选B项
- ⚠ 由'后勤→非正式编制'与'正式编制→参加'误推'后勤都没参加'或'后勤有的没参加'（C/D项陷阱，犯了否定前件谬误）
- ⚠ 只看到'有的综合没参加'找不到出口，漏做逆否转换导致卡壳

## 母题抽象
> 🧩 当题干同时出现'所有A都B'与'有的C不B'时，对全称命题作逆否得'不B→不A'，再与'有的C不B'串联，即可推出'有的C不是A'；注意'有的A不是B'永远不可换位

**同类特征**：所有正式编制员工都参加了、后勤部门所有员工都不是正式编制、综合部门有的员工没有参加、由此可以推出、有的…不是…换位陷阱、全称命题+特称否定组合

### 题干
某单位所有正式编制员工都参加了周末举办的团建活动，该单位后勤部门所有员工都不是正式编制员工，综合部门有的员工没有参加周末举办的团建活动。
由此可以推出该单位：

### 选项
- A. 综合部门有的员工不是正式编制员工　✅
- B. 有的正式编制员工不是综合部门的员工
- C. 后勤部门有的员工没有参加周末举办的团建活动
- D. 后勤部门所有员工都参加了周末举办的团建活动
