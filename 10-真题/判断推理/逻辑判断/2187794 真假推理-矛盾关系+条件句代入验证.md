# 真假推理-矛盾关系+条件句代入验证

考点：[[20-考点/判断推理/逻辑判断/真假推理-矛盾关系+条件句代入验证|逻辑判断 / 真假推理-矛盾关系+条件句代入验证]]


**问法模型**：'只有一位预测正确（一真三假）+以下哪项一定为真'→ 先找矛盾锁定唯一真话范围，由假话推确定信息，剩余两种情形再代入选项的条件句逐一假设验证

## 推理链
1. 第1步：翻译四人预测——方：¬甲→¬乙（逆否等价于'乙晋级→甲晋级'，即'甲晋级 或 乙不晋级'）；白：¬乙；夏：乙 且 ¬甲；邓：都不能晋级
2. 第2步：找矛盾——方'甲∨¬乙'与夏'乙∧¬甲'互为矛盾，必一真一假
3. 第3步：四位中只有一位预测正确，唯一真话必在方/夏这对矛盾之中，故白某、邓某一定为假，排除A、B
4. 第4步：白某'乙队不能晋级'为假→乙队晋级了（邓某'都不能晋级'为假与此相容，无新信息）
5. 第5步：乙已确定晋级，此时方的真假取决于甲（甲晋级则方真、夏假），夏的真假也取决于甲（甲不晋级则夏真、方假），两种情形均恰有一真，单靠题干无法唯一确定谁正确
6. 第6步：验证C——假设甲队晋级，则乙也晋级，此时夏'乙且¬甲'为假、方为真，加上白邓必假，恰好只有方某一人正确，C的条件句两情形下均为真，一定成立
7. 第7步：验证D——假设甲队不晋级，则乙晋级，此时夏'乙且¬甲'为真、方为假，D断言'方某预测正确'在该情形下为假，不必然为真，排除

**最快解法**：⚡ 矛盾法+代入法：一眼锁定方（¬甲→¬乙）与夏（乙∧¬甲）互为矛盾→白邓必假→乙晋级；剩余真假系于甲是否晋级，直接用C、D给的条件分别假设'甲晋级''甲不晋级'，检验'方某是否为真'，只有C在两种情形下都成立

## 易错点
- ⚠ 把方某'如果甲不能晋级，那么乙也不能晋级'误译为'甲→乙'，找错矛盾对；正确翻译需逆否等价为'乙晋级→甲晋级'（即'甲∨¬乙'）
- ⚠ 推出'乙晋级'后误以为能直接判定方/夏谁真，其实此时唯一真话取决于甲是否晋级，必须借助选项条件句代入
- ⚠ 把C、D的条件句当成事实命题，因'无法确定甲是否晋级'而错选或漏选；条件句在前件不成立时为真，故C两种情形下均为真

## 母题抽象
> 🧩 当题干出现'只有一人预测正确'且其中两句话互为矛盾时，先锁定矛盾对必含唯一真话、其余全假以提取确定信息；若剩余对象的真假仍取决于某一未知变量，就代入选项给出的'如果…那么…'条件句分别假设验证，两情形下皆真者即为'一定为真'的答案

**同类特征**：只有一位预测是正确的（一真三假）、存在互为矛盾的两句话（¬甲→¬乙 与 乙∧¬甲）、'不管…都…'全称断言为假可推出确定信息（乙晋级）、剩余真假取决于甲是否晋级这一未定变量、选项以条件句'如果甲队能/不能晋级'设问、问'以下哪项一定为真'

### 题干
四位球迷在某球赛的晋级赛开始之前对几个队伍的赛况进行预测，他们比较关注其中的两支球队，分别作了如下预测：
方某说：如果甲队不能晋级，那么乙队也不能晋级。
白某说：不管甲队能不能晋级，乙队都不能晋级。
夏某说：乙队能晋级，但甲队不能晋级。
邓某说：我看这几支球队都不能晋级。
比赛结果证明，四位球迷中只有一位的预测是正确的。
根据上述情况，以下哪项一定为真？

### 选项
- A. 白某预测是正确的
- B. 邓某预测是正确的
- C. 如果甲队能够晋级，那么方某的预测是正确的　✅
- D. 如果甲队不能晋级，那么方某的预测是正确的
