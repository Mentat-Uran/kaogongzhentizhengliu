# 翻译推理-逆否规则（假言连锁+摩根定律）

考点：[[20-考点/判断推理/逻辑判断/翻译推理-逆否规则（假言连锁+摩根定律）|逻辑判断 / 翻译推理-逆否规则（假言连锁+摩根定律）]]


**问法模型**：题干给出多个'如果…那么…'加一个否定性确定条件（预算成本不超一亿），问'由此可以推出'→ 翻译为逻辑表达式后，从确定信息出发沿逆否链条做必然性推理锁定唯一可推出项

## 推理链
1. 第1步：翻译题干四个条件：（1）交通便捷→市中心；（2）发挥功能→建成大厦；（3）（市中心且大厦）→成本超一亿；（4）成本不超一亿（即对'成本超一亿'的否定）。
2. 第2步：唯一确定信息是（4）'成本不超一亿'，以它为推理起点，对（3）用逆否+摩根定律：¬(市中心且大厦)=¬市中心 或 ¬大厦。
3. 第3步：验证B项前件'发挥功能'：对（2）肯前必肯后推出'建成大厦'，排除'¬大厦'分支，由'¬市中心 或 ¬大厦'锁定'¬市中心'。
4. 第4步：由'¬市中心'对（1）否后必否前推出'¬交通便捷'，连锁得'发挥功能→不建在交通便捷处'，与B项完全一致。
5. 第5步：对照A项'¬交通便捷 且 ¬发挥功能'：（3）（4）逆否只给出'¬市中心 或 ¬大厦'的或然关系，无法同时全称否定两支，A项断言过强，排除。
6. 第6步：对照C项'只有交通便捷才发挥功能'即'发挥功能→交通便捷'，与B项推出的方向恰好相反，排除；D项'¬交通便捷→¬发挥功能'是C项的逆否命题，与C同真同假，一并排除。

**最快解法**：⚡ 逆否连锁法：用（4）'成本不超一亿'否定（3）后件，摩根拆开得'¬市中心 或 ¬大厦'；把B项前件'发挥功能'代入（2）肯前必肯后得'大厦'，锁定'¬市中心'，再否（1）后件得'¬交通便捷'，秒选B。

## 易错点
- ⚠ 摩根定律用错：¬(市中心且大厦)=¬市中心或¬大厦，误写成'¬市中心且¬大厦'会错选A。
- ⚠ 对'或'关系不当全称否定：由'¬市中心或¬大厦'不能同时推出'¬交通便捷'和'¬发挥功能'，A项的'并且'是陷阱；必须借助'发挥功能→大厦'锁定分支才能推B。
- ⚠ 误把D当新选项：D只是C的逆否命题，与C真假等价，C方向与正确结论相反则D同样错，'逆否形式不同'不代表独立成立。

## 母题抽象
> 🧩 当题干出现多个'如果…那么…'且末尾附有一个否定性确定条件（预算/限制类）时，把该确定条件作为起点，对'且'前件的条件句做'逆否+摩根定律'拆解，再代入选项前件做假言连锁，验证'要A就不能B'式结论。

**同类特征**：多个'如果…那么…'假言条件、末尾出现否定性确定信息（成本不能超过一亿元）、第三条为'既要…又要…'的'且'关系前件、问法为'由此可以推出'、选项为假言命题与联言命题混排、需要逆否规则与摩根定律综合运用

### 题干
（1）如果新的市政府大楼要建在交通特别便捷的地方，那么它必须选址在靠近城市中心的位置。（2）如果这个新的市政府大楼要想发挥它高效的行政功能，那么它必须建成一个足以容纳绝大部分政府机构的大厦。（3）如果该大楼既要选址在市中心又要建成一个大厦，那么它的建造成本将会超过一亿元。（4）但是根据政府预算，这个大楼的成本不能超过一亿元。
由此可以推出：

### 选项
- A. 新的市政府大楼不会建在交通特别便捷的地方并且也不会发挥它高效的行政功能
- B. 如果新的市政府大楼要想发挥它高效的行政功能，就不能建在交通特别便捷的地方　✅
- C. 新的市政府大楼只有建在交通特别便捷的地方，才能发挥它高效的行政功能
- D. 如果新的市政府大楼不建在交通特别便捷的地方，那么就不能发挥它高效的行政功能

### 官方解析
第一步：翻译题干。
（1）建在交通便捷的地方选址在市中心；
（2）发挥功能建成大厦；
（3）选址在市中心 且 建成大厦建造成本将会超过一亿元；
（4）建造成本将会超过一亿元。
第二步：逐一分析选项。
A项：翻译为：建在交通便捷的地方 且 发挥功能，根据条件（3）（4）的逆否可以推出“选址在市中心 或 建成大厦”，无法根据条件（1）（2）得出该项结论，无法推出，排除；
B项：翻译为：发挥功能建在交通便捷的地方，“发挥功能”是对条件（2）的肯前，肯前必肯后，可以推出将建成大厦，再根据条件（3）（4）的逆否可以推出“选址在市中心 或 建成大厦”，综合上述推理可以推出“选址在市中心”，是对条件（1）的否后，否后必否前，可以推出“建在交通便捷的地方”，可以推出，当选；
C项：翻译为：发挥功能建在交通便捷的地方，根据B项推理过程可知，“发挥功能”可以推出“建在交通便捷的地方”，无法推出，排除；
D项：翻译为：建在交通特别便捷的地方发挥功能，该项是对C项逻辑关系的逆否，C项不成立，则该项无法推出，排除。
故正确答案为B。
