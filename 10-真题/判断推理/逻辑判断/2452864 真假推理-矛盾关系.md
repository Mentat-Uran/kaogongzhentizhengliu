# 真假推理-矛盾关系

考点：[[20-考点/判断推理/逻辑判断/真假推理-矛盾关系|逻辑判断 / 真假推理-矛盾关系]]


**问法模型**：题干出现'只有一个人说谎'+若干断定某人是否到场的话 → 采用'找矛盾、定真假、看其余'的真假推理模型

## 推理链
1. 第1步：题干限定'甲、乙、丙、丁中有一人没有参加，其他三人都参加了'，且'只有一个人说谎'，即四句话三真一假。
2. 第2步：甲说'乙没有来'，乙说'我不但参加了'，两句围绕'乙是否参加'构成矛盾关系，必一真一假，唯一的谎话必在甲、乙之间。
3. 第3步：由'唯一说谎者在甲乙之中'推出其余命题必真，即丙、丁的话都为真。
4. 第4步：丙说'我晚来了一会儿，但一直到座谈会结束才走'，说明丙参加了座谈会。
5. 第5步：丁说'如果丙来了，那就是我没来'，前件'丙来了'已确定为真，根据充分条件推理'肯前必肯后'，得出'丁没来'，即丁没有参加。
6. 第6步：验证自洽：四人中只有丁没参加，乙确已参加，故甲的'乙没有来'为假，正是那唯一一句谎话，与'只有一人说谎'完全吻合，选D。

**最快解法**：⚡ 找矛盾法：甲乙两句关于'乙是否参加'互为矛盾 → 唯一假话锁定甲乙之间 → 丙丁必真 → 丙参加了 → 丁的话'丙来→丁没来'肯前肯后 → 丁没参加，直接选D

## 易错点
- ⚠ 把'说谎者'误当成'没参加者'：推出甲说谎后误选A，但甲只说谎并未缺席，缺席的是丁
- ⚠ 不会用丁的假言命题：见'如果……那么……'以为真假难定而弃用，忽略'丙来了为真→肯前必肯后'即可断定丁没来
- ⚠ 忽略'四人恰有一人没参加'这一限定，未与'只有一人说谎'结合锁定矛盾所在范围

## 母题抽象
> 🧩 当题干出现'只有一人说真话/说谎'且某两句话围绕同一对象的肯定与否定构成矛盾时，先找矛盾锁定真假范围，断定其余命题必真，再用事实命题或假言命题'肯前推后'得出结论，最后回验三真一假是否自洽。

**同类特征**：只有一个人说谎、四人中恰有一人没参加、甲乙陈述互为矛盾（乙没来vs我参加了）、丁的话为'如果丙来则我没来'的充分条件假言、以是否到场为断定对象

### 题干
有员工没参加单位举行的学习宣传《习近平谈治国理政》(第二卷)座谈会。甲、乙、丙、丁中有一人没有参加，其他三人都参加了。单位负责人在询问时，他们做了如下的回答。
甲：乙没有来。
乙：我不但参加了，而且还谈了感想。
丙：我晚来了一会儿，但一直到座谈会结束才走。
丁：如果丙来了，那就是我没来。
如果他们中只有一个人说谎，则以下成立的是：

### 选项
- A. 甲没有参加
- B. 乙没有参加
- C. 丙没有参加
- D. 丁没有参加　✅

### 官方解析
本题属于真假推理题。
第一步：找出题干矛盾命题。
甲说“乙没有来”和乙说“我不但参加了，而且还谈了感想”是矛盾关系，必有一真一假。
第二步：看其余。
已知只有一个人说谎，说明其余人说的都是真的。丙说“我晚来了一会儿”，说明丙参加了。丁说“如果丙来了，那就是我没来”，因丙参加为真，说明丁没有参加。
故正确答案为D。
