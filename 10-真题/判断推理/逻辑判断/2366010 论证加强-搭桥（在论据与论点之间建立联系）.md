# 论证加强-搭桥（在论据与论点之间建立联系）

考点：[[20-考点/判断推理/逻辑判断/论证加强-搭桥（在论据与论点之间建立联系）|逻辑判断 / 论证加强-搭桥（在论据与论点之间建立联系）]]


**问法模型**：问法为'哪项最能够加强上述论证'→ 先拆论点与论据，锁定两者之间的概念断层，找能在断层处搭桥的选项

## 推理链
1. 第1步：提取论点——'做家务有助于培养更多的社会精英'，核心词是'社会精英'
2. 第2步：提取论据——爱做家务的求职者更易就业、收入更高、幸福感更高；'通过做家务，求职者能养成合理规划的习惯和不骄不躁的品质'，核心词是'合理规划''不骄不躁'
3. 第3步：识别断层——论据只讲到求职者养成了两种品质，论点却跳到'社会精英'，中间缺少'这些品质与成为社会精英有关联'这一环节
4. 第4步：确定加强方向——需找同时涉及'合理规划/不骄不躁'与'社会精英'、把论据和论点连起来的选项
5. 第5步：逐项对照——A项说两种品质为'求职者'所必需，主体仍是求职者，未触及'社会精英'，无关；B项父母鼓励做家务，与'社会精英'无关，无法加强；C项'合理规划和保持不骄不躁是社会精英的必备品质'，正好把论据的品质与论点的'社会精英'搭桥，加强；D项'做家务可以提升求职者的规划能力和生活幸福感'，只是重复论据内容，仍未触及'社会精英'
6. 第6步：结论——C项在论据与论点之间建立必然联系，加强力度最强，与官方答案一致

**最快解法**：⚡ 关键词搭桥法：圈出论点核心词'社会精英'，再圈论据关键词'合理规划''不骄不躁'，唯一直接同时包含这两组关键词并建立联系的选项即C，可秒杀

## 易错点
- ⚠ A项偷换主体：'求职者所必需'≠'社会精英必备'，主体不一致不能搭桥，易误选
- ⚠ D项重复论据：'提升规划能力和幸福感'只是复述论据，未连接'社会精英'，易误认为是加强
- ⚠ 忽略论点核心词：在'就业、收入、幸福感'上找联系而漏掉论点真正要证明的是'培养社会精英'

## 母题抽象
> 🧩 当论点出现身份/结果类核心词（如'社会精英'）而论据只给原因/品质类关键词（如'合理规划''不骄不躁'）时，用搭桥法：选同时包含论据关键词与论点核心词、说明'品质是身份必备条件'的选项，即为最强加强

**同类特征**：问法为'最能够加强上述论证'、论点核心词是身份类概念'社会精英'、论据关键词为品质类'合理规划''不骄不躁'、论据与论点之间存在明显的概念跳跃/断层、干扰项为重复论据或偷换主体（求职者≠社会精英）、正确项形如'X是Y的必备品质'的搭桥句式

### 题干
一项长达20年的研究表明，爱做家务的求职者比不爱做家务的求职者更容易成功就业，就业后的收入前者也比后者高。此外，爱做家务的求职者比不爱做家务的求职者生活幸福感更高。通过做家务，求职者能养成合理规划的习惯和不骄不躁的品质。从这个角度看，做家务有助于培养更多的社会精英。
下列哪项如果为真，最能够加强上述论证？

### 选项
- A. 养成合理规划和不骄不躁的习惯为求职者所必需
- B. 非常多的求职者都在被他们父母积极鼓励做家务
- C. 合理规划和保持不骄不躁是社会精英的必备品质　✅
- D. 做家务可以提升求职者的规划能力和生活幸福感

### 官方解析
第一步：找出论点和论据。
论点：做家务有助于培养更多的社会精英。
论据：爱做家务的求职者比不爱做家务的求职者更容易成功就业，就业后的收入高，生活幸福感更高。通过做家务，求职者能养成合理规划的习惯和不骄不躁的品质。
本题论据告知了爱做家务使求职者养成合理规划的习惯和不骄不躁的品质，论点是做家务有助于培养社会精英。要想加强论证，应说明合理规划的习惯和不骄不躁的品质和成为社会精英有关联。
第二步：逐一分析选项。
A项：合理规划和不骄不躁的习惯为求职者所必需，说的是求职者应具备的条件，与论点中说的社会精英无关，无关项，排除；
B项：求职者被父母积极鼓励做家务，与论点中说的社会精英无关，无关项，无法加强，排除；
C项：合理规划和保持不骄不躁是社会精英的必备品质，论据表明做家务，求职者能养成合理规划的习惯和不骄不躁的品质，选项在论据和论点中搭桥，可以加强，当选；
D项：做家务可以提升求职者的规划能力和生活幸福感，重复论据观点，与论点社会精英无关，无法加强，排除。
故正确答案为C。
