# 削弱论证-选非题（找不能削弱项）

考点：[[20-考点/判断推理/逻辑判断/削弱论证-选非题（找不能削弱项）|逻辑判断 / 削弱论证-选非题（找不能削弱项）]]


**问法模型**：题干为'现象+发现某物质→断定其为关键因素'的因果论证，问'哪项没有削弱'→选非题，逐项判定削弱方式（断开因果/他因），排除削弱项后剩下的即为答案

## 推理链
1. 第1步：提取论点：溶酶酵素这种物质'很可能就是抵御细菌侵扰的关键因素'，即因果断定'溶酶酵素→丛冢雉蛋低感染率'
2. 第2步：提取论据：丛冢雉蛋'发生感染的几率仅为'极低值，且研究者发现'其蛋壳中含有溶酶酵素'；背景是自然情况下其他动物蛋感染比例高
3. 第3步：题干为选非题，需对A、B、C、D逐项判断是否构成削弱（断开因果或他因）
4. 第4步：A项：其他动物蛋壳溶酶酵素'含量大抵相当'却感染率高，说明单靠溶酶酵素含量无法解释感染率差异，切断因果，构成削弱，排除
5. 第5步：B项'纳米级碳酸钙层防水抗细菌'、C项'特殊气味使细菌数减少'，均提出其他原因解释低感染率，属他因削弱，排除
6. 第6步：D项说丛冢雉蛋壳'薄三分之一、更易受到微生物入侵'，讨论的是蛋壳是否易被入侵，而非溶酶酵素是否为关键因素；且壳更薄更易入侵而感染率仍极低，反而凸显内部防护（溶酶酵素）的必要性，不构成削弱，与论点话题不一致，当选
7. 第7步：对照问法'没有削弱'，确认D为不能削弱项，故答案为D

**最快解法**：⚡ 排除法+削弱方式归类：A为对比断开因果（含量相当却感染率不同），B、C为他因削弱，快速排除三个削弱项，D'蛋壳薄更易入侵'与'溶酶酵素是否关键'话题不一致，选非选D

## 易错点
- ⚠ 忽略'没有削弱'的选非问法，误选削弱力度最强的A项
- ⚠ D项'更易受到微生物入侵'字面像不利信息，被误认为在削弱结论，实际与论点话题不一致甚至反向支持（壳更薄仍低感染率，更需内部因素解释）
- ⚠ A项需结合背景'其他动物感染率高'才能看出'含量相当'的削弱作用，孤立看A易误判为无关项

## 母题抽象
> 🧩 当题干出现'发现某对象含有某物质/特征且现象优异→断定该物质是关键原因'的因果模板，削弱优先找'他因'和'有无该物质的对比断开因果'；问'没有削弱'时，锁定与因果链话题不一致的无关项或反向加强项

**同类特征**：因果断定（很可能就是关键因素）、选非问法（没有削弱）、论据为低感染率+含有溶酶酵素、选项含他因（碳酸钙层、特殊气味）、对比其他动物（含量相当/蛋壳更薄）、削弱方式：断开因果与他因削弱

### 题干
<p>一般来说，动物的蛋会通过土壤中微生物和堆肥分解有机物时产生的热量来孵化，但这些微生物（包含细菌）也会穿透蛋壳、感染胚胎，自然情况下这一比例高于<img flag="tex" src="../../../90-图片/公式图/formula-23d85574dc6adf1c.png" />。然而，在澳洲有一种名为丛冢雉的鸟类，其蛋发生感染的几率仅为<img flag="tex" src="../../../90-图片/公式图/formula-17529a172989d12e.png" />，研究者发现其蛋壳中含有溶酶酵素，研究者据此认为这种物质很可能就是抵御细菌侵扰的关键因素。</p><p>以下哪项如果为真，没有削弱上述结论？</p>

### 选项
- A. 丛冢雉的蛋壳中所含的溶酶酵素量，与其他动物相比，含量大抵相当
- B. 丛冢雉的蛋壳被一层纳米级的碳酸钙层包裹，拥有了更强的防水性和抗细菌入侵能力
- C. 丛冢雉蛋散发一种特殊气味，会使附着在其蛋壳上的细菌数减少
- D. 与其他动物的蛋壳相比，丛冢雉的蛋壳要薄三分之一，更易受到微生物的入侵　✅

### 官方解析
<p>第一步：找出论点和论据。</p><p>论点：溶酶酵素这种物质很可能就是抵御细菌侵扰的关键因素。</p><p>论据：在澳洲有一种名为丛冢雉的鸟类，其蛋发生感染的几率仅为<img flag="tex" src="../../../90-图片/公式图/formula-17529a172989d12e.png" />，研究者发现其蛋壳中含有溶酶酵素。</p><p>本题论点说的是溶酶酵素是抵御细菌侵扰的关键因素，论据说的是一种蛋壳中含有溶酶酵素的鸟类蛋发生感染的几率仅为<img flag="tex" src="../../../90-图片/公式图/formula-17529a172989d12e.png" />，二者都是在说溶酶酵素与细菌感染之间的关系，话题一致，削弱优先考虑削弱论点，且论点为因果关系，也可以考虑因果倒置（能够抵御细菌侵扰使其出现溶酶酵素），还可以考虑他因削弱（其他原因导致该鸟类可以抵御细菌侵扰）。</p><p>第二步：逐一分析选项。</p><p>A项：指出丛冢雉的蛋壳中所含的溶酶酵素量与其他动物含量相当，这说明溶酶酵素并不是丛冢雉的蛋的感染率比其他动物的蛋低很多的原因，削弱论点，排除；</p><p>B项：指出纳米级的碳酸钙拥有了更强的防水性和抗细菌入侵能力，说明碳酸钙可能是丛冢雉的蛋的感染率比其他动物的蛋低很多的原因，提出了其他的原因可能是抵御细菌侵扰的关键因素，他因削弱，排除；</p><p>C项：指出丛冢雉散发一种特殊气味会使附着在其蛋壳上的细菌数减少，说明气味可能是丛冢雉的蛋的感染率比其他动物的蛋低很多的原因，提出了其他的原因可能是抵御细菌侵扰的关键因素，他因削弱，排除；</p><p>D项：指出丛冢雉的蛋壳很薄，更易受到微生物的入侵，讨论的是丛冢雉的蛋壳是否容易受到入侵，而论点讨论的是溶酶酵素是抵御细菌侵扰的关键因素，话题不一致，无法削弱，当选。</p><p>本题为选非题，故正确答案为D。</p>
