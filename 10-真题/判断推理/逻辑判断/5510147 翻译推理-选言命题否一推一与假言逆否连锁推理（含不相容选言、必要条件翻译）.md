# 翻译推理-选言命题否一推一与假言逆否连锁推理（含不相容选言、必要条件翻译）

考点：[[20-考点/判断推理/逻辑判断/翻译推理-选言命题否一推一与假言逆否连锁推理（含不相容选言、必要条件翻译）|逻辑判断 / 翻译推理-选言命题否一推一与假言逆否连锁推理（含不相容选言、必要条件翻译）]]


**问法模型**：题干给出多个真假已知的条件句并以'施文确定无法参加'提供确定信息 → 先将全部条件翻译为箭头/或关系，再从确定信息出发做链式逆否与否一推一，边推边排除选项

## 推理链
1. 第1步：从确定信息'施文确定无法参加'出发，记为¬施文；条件（5）'施文、丁晓至少有1人参加'译为施文或丁晓
2. 第2步：或关系否一推一：由¬施文与（5）推出丁晓参加；条件（4）'或者丁晓不参加，或者郭斌参加'等价于丁晓→郭斌，由丁晓参加推出郭斌参加
3. 第3步：条件（3）'郭斌且吴芳→施文'，由¬施文逆否得¬（郭斌且吴芳）＝¬郭斌或¬吴芳，结合郭斌参加，否一推一得吴芳不参加，排除C、D
4. 第4步：条件（2）'只有吴芳参加，刘佳才参加'译为刘佳→吴芳，由¬吴芳逆否推出刘佳不参加，排除A
5. 第5步：条件（1）'要么刘佳参加，要么郑毅参加'为不相容选言（恰一人参加），由¬刘佳推出郑毅参加
6. 第6步：汇总确定参加者为郑毅、郭斌、丁晓，与选项对照，对应B

**最快解法**：⚡ 确定信息起点法＋连锁推理口诀：从'¬施文'起，沿（5）否一推一→丁晓，沿（4）丁晓→郭斌，沿（3）逆否拆联言→¬吴芳，沿（2）逆否→¬刘佳，沿（1）不相容选言→郑毅，全程边推边排除

## 易错点
- ⚠ 条件（2）'只有…才…'是必要条件，须译为刘佳→吴芳；若误译为吴芳→刘佳，逆推方向全错
- ⚠ 条件（3）逆否得'并非郭斌且吴芳'，须拆为'¬郭斌或¬吴芳'再否一推一，不能一步跳到'吴芳不参加'
- ⚠ 条件（1）'要么…要么…'是不相容选言（二者恰居其一），若按相容'或者'处理，会在¬刘佳时误认为郑毅不确定

## 母题抽象
> 🧩 当题干出现'只有…才/如果…那么/要么…要么/或者…或者/至少有1人'等条件且末尾给出某对象'确定不参加（或参加）'的确定信息时，先全题翻译成箭头与或关系，再从确定信息出发，沿'逆否等价＋否一推一'逐环连锁，唯一推出的组合即答案

**同类特征**：要么…要么…（不相容选言）、只有…才…（必要条件翻译为前推后）、如果…且…那么…（联言前件的假言，逆否拆为或）、或者…或者…（相容选言否一推一）、至少有1人参加、末尾给出'某人确定无法参加'作推理起点

### 题干
某医院刘佳、郑毅、郭斌、丁晓、吴芳、施文6位医生拟报名参加“一心向党，健康为民”进社区义诊活动，已知下列情况为真：
（1）要么刘佳参加，要么郑毅参加；
（2）只有吴芳参加，刘佳才参加；
（3）如果郭斌和吴芳都参加，那么施文也会参加；
（4）或者丁晓不参加，或者郭斌参加；
（5）施文、丁晓至少有1人参加。
现施文确定无法参加，那么6位医生中最后参加义诊活动的是：

### 选项
- A. 刘佳、郭斌、丁晓
- B. 郑毅、郭斌、丁晓　✅
- C. 郑毅、丁晓、吴芳
- D. 刘佳、丁晓、吴芳

### 官方解析
第一步：翻译题干。
（1）要么刘佳，要么郑毅；
（2）刘佳吴芳；
（3）郭斌 且 吴芳施文；
（4）丁晓 或 郭斌；
（5）施文 或 丁晓；
（6）施文。
第二步：根据题干条件进行推理。
从确定信息进行推理，施文无法参加，结合条件（5）和“或关系否一推一”可知丁晓参加，结合条件（4）和“或关系否一推一”可知郭斌参加；已知施文无法参加，结合条件（3）和“否后必否前”可知郭斌 或 吴芳，结合郭斌参加和“或关系否一推一”可知吴芳不参加，排除C、D两项；结合条件（2）和“否后必否前”可知刘佳不参加，排除A项；再结合条件（1）可知，郑毅参加，此时确定参加的医生为丁晓、郭斌和郑毅，对应B项。
故正确答案为B。
