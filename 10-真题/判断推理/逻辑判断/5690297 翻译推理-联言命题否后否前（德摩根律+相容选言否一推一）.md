# 翻译推理-联言命题否后否前（德摩根律+相容选言否一推一）

考点：[[20-考点/判断推理/逻辑判断/翻译推理-联言命题否后否前（德摩根律+相容选言否一推一）|逻辑判断 / 翻译推理-联言命题否后否前（德摩根律+相容选言否一推一）]]


**问法模型**：'根据以上信息，可以得出下列哪项' → 翻译题干条件后用逆否等价+德摩根展开，逐项对照排除

## 推理链
1. 第1步：提取条件并翻译：(1) 被陈灵拉进该群 且 通过该群和蔡骏建立互信联系 → 茶叶经销商（联言前件）；(2) 黎阳是陈灵的客户；(3) 黎阳通过该群和蔡骏建立了互信联系；(4) 陈灵的客户都不是茶叶经销商
2. 第2步：由(2)(4)得：黎阳不是茶叶经销商，即否定了条件(1)的后件
3. 第3步：逆否等价（否后必否前）：¬茶叶经销商 → ¬(被陈灵拉进 ∧ 通过该群建互信)，德摩根展开为：¬被陈灵拉进 ∨ ¬通过该群建互信
4. 第4步：条件(3)表明黎阳'通过该群和蔡骏建立了互信联系'，即否定了析取式中的后一支，由否一推一规则得：黎阳没有被陈灵拉进该群
5. 第5步：与选项对照：B项'陈灵不曾将黎阳拉进群'与推理结论完全一致，当选
6. 第6步：A项蔡骏身份、C项黎阳与陈灵的关系、D项陈灵与蔡骏的关系题干均无信息支持，无法推出，排除

**最快解法**：⚡ 归谬假设法最快：假设'陈灵拉黎阳进了群'，结合题干已知'黎阳通过该群和蔡骏建立了互信联系'，则黎阳满足条件(1)的联言前件，应推出'黎阳是茶叶经销商'，与'陈灵的客户都不是茶叶经销商'矛盾，假设不成立，直接锁定B

## 易错点
- ⚠ 把条件(1)误拆为'被拉进群→经销商'和'建互信→经销商'两个独立推出关系，推理链条完全走偏
- ⚠ 逆否得到'¬拉进 或 ¬建互信'后忘记相容选言'否一推一'规则，无法收敛到确定结论
- ⚠ 误选C：将'黎阳通过该群和蔡骏建立互信'偷换为'黎阳和陈灵建立互信'，犯了主语偷换错误

## 母题抽象
> 🧩 当题干出现'A且B→C'的联言前件翻译，又同时给出'¬C'和'B'成立时，先逆否得'¬A或¬B'，再否一推一得'¬A'，即可锁定'不曾/没有'类否定性结论

**同类特征**：'被拉进群且建立互信的都是……'（联言前件充分条件）、'客户都不是……'（全称否定，可否定后件）、某个体已满足联言前件中的一个支命题、结论为'不曾/没有做某事'的否定判断、问法为'可以得出下列哪项'

### 题干
蔡骏建立了“茶香江左”微信群，被陈灵拉进该群并通过该群和蔡骏建立了互信联系的人都是茶叶经销商，陈灵的一个客户黎阳通过该群和蔡骏建立了互信联系，但是陈灵的客户都不是茶叶经销商。
根据以上信息，可以得出下列        项。

### 选项
- A. 蔡骏是茶叶经销商
- B. 陈灵不曾将黎阳拉进“茶香江左”微信群　✅
- C. 黎阳和陈灵通过“茶香江左”微信群建立了互信联系
- D. 陈灵通过“茶香江左”微信群和蔡骏建立了互信联系

### 官方解析
第一步：分析题干条件。
（1）被陈灵拉进该群 且 通过该群和蔡骏建立了互信联系茶叶经销商；
（2）黎阳是陈灵的客户；
（3）黎阳通过该群和蔡骏建立了互信联系；
（4）陈灵的客户茶叶经销商。
第二步：根据题干条件进行推理。
根据条件（2）和条件（4）可知，黎阳不是茶叶经销商，根据条件（1）否后必否前可知，被陈灵拉进该群 或 通过该群和蔡骏建立了互信联系，再根据条件（3）可知，黎阳通过该群和蔡骏建立了互信联系，则否一推一可推出：黎阳没有被陈灵拉进该群，B项当选。A、C、D三项均无法推出，排除。
故正确答案为B。
