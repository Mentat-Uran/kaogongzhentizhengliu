# 真假话问题-无矛盾关系的代入排除法

考点：[[20-考点/判断推理/逻辑判断/真假话问题-无矛盾关系的代入排除法|逻辑判断 / 真假话问题-无矛盾关系的代入排除法]]


**问法模型**：三人预测'只有一人正确'且命题间无矛盾/反对关系 → 用代入法逐项验证选项真假数量

## 推理链
1. 第1步：提取三人预测——甲：'李和吴不可能取得冠军'（即冠军不是李也不是吴）；乙：'冠军不是赵就是钱'（即冠军为赵或钱）；丙：'冠军绝对不是孙'（即冠军不是孙）
2. 第2步：三命题之间不存在矛盾关系和反对关系，无法用'找矛盾定真假'；题干条件'只有一个人的预测是正确的'是真假数量限定，故采用代入法逐一验证
3. 第3步：代入A项'钱'：甲真、乙真（钱属赵钱之一）、丙真（钱非孙），三人全对，不符合'只有一人正确'，排除
4. 第4步：代入B项'孙'：甲真（孙非李非吴）、乙假（孙非赵非钱）、丙假（冠军恰为孙），恰好只有甲一人正确，符合题干条件
5. 第5步：代入C项'周'：甲真、乙假、丙真，两人正确，排除；代入D项'赵'：甲真、乙真、丙真，三人正确，排除
6. 第6步：四个选项中只有B项满足'只有一个人预测正确'，故冠军为孙，答案选B

**最快解法**：⚡ 秒杀观察法：四个选项（钱/孙/周/赵）均不是李或吴，故甲'李和吴不可能取得冠军'在所有选项下必然为真；由'只有一人正确'知乙、丙必假，丙假即'冠军是孙'，直接锁定B，无需逐项代入

## 易错点
- ⚠ 把甲的话误解为'李和吴中必有一人夺冠'或复合联言命题导致真假判断出错；实际只要冠军既非李也非吴，甲即为真
- ⚠ 执着于在三个命题间寻找矛盾/反对关系而陷入僵局；本题无矛盾关系，应果断转用代入法
- ⚠ 代入验证时误判某人真假（如C项'周'误判丙为假、A/D项误判甲为假），导致错误排除或错选

## 母题抽象
> 🧩 当题干出现'多人预测只有一人真（假）'且命题间无矛盾/反对关系时，用代入法逐项验证真假数量；若能先锁定一个在所有候选情形下必然为真的命题，则其余命题必假，可据此一步推出答案

**同类特征**：只有一个人的预测是正确的、甲乙丙三人预测无矛盾/反对关系、甲断言李和吴不可能夺冠、乙断言不是赵就是钱、丙断言冠军绝对不是孙、六个姓氏（赵钱孙李周吴）限定冠军范围
