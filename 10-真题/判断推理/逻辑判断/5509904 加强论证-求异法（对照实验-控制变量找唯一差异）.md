# 加强论证-求异法（对照实验-控制变量找唯一差异）

考点：[[20-考点/判断推理/逻辑判断/加强论证-求异法（对照实验-控制变量找唯一差异）|逻辑判断 / 加强论证-求异法（对照实验/控制变量找唯一差异）]]


**问法模型**：“以下哪项如果为真，最能支持……面积减少的原因在于施用制剂α”→用求异法：构造甲乙两区“其他条件全同、仅差是否施α”的对照，唯一差异因素与结果变化对应即为最强支持。

## 推理链
1. 第1步：读图提取数据：乙区（实线）发生面积约7.2→6.8→6.0→3.3→2.4，2020年后降幅骤增；甲区（虚线）约8.5→7.5→6.9→5.7→4.9，全程平缓下降。
2. 第2步：读图标注X、Y、Z：乙区2019年起改栽品种β（X），2020年起施用制剂α（Y），甲区2019年起也改栽品种β（Z），故论点把乙区2020年后的骤降归因于“施用新型生物制剂α”。
3. 第3步：明确支持思路（求异法）：需使甲乙两区除“是否施用α”外其余条件（尤其品种β）完全相同，且结果差异与该因素同步。
4. 第4步：A项甲区自2020年后不再栽种β且也施用α，两区的差异因素变成品种，原因可能指向种子，官方解析认定构成削弱，排除。
5. 第5步：B项甲区不栽β也不用α，两区在品种、制剂两个因素上均不同，无法定位原因，为不明确项；C项两区均栽β均施α，条件完全相同，无法解释乙区降幅为何更陡，同为不明确项，均排除。
6. 第6步：D项甲区自2019年后一直栽种β且不施α，与乙区（栽β+施α）唯一差异是是否施α：乙区骤降而甲区平缓，差异因素与结果变化一一对应，构成求异法支持，当选D。

**最快解法**：⚡ 求异法口诀“唯一差异即原因”：先由图中X、Z标注锁定两区2019年起同栽品种β（排除品种干扰），再在选项中找“甲区品种不变+不施α”的组合，只有D同时满足，直接锁定。

## 易错点
- ⚠ 误选C：以为两区条件完全相同对照最“公平”，实则条件全同时无法把乙区更陡的下降归因于α，属不明确项而非支持
- ⚠ 忽略图中X、Z标注（两区2019年起均已改栽品种β），误把品种仍当作待排除的干扰因素而在B、D间犹豫
- ⚠ 误选A：看到甲区“也施用α”以为可形成验证，但此时两区差异落在品种上，方向实为削弱而非支持

## 母题抽象
> 🧩 当题干以折线图/数据给出“某对象自某时点出现变化”并断言“变化的原因在于某措施”时，用求异法：在选项中寻找使对照组与实验组“其他条件全部相同、仅差该措施”的条件，唯一差异因素与结果变化同步即为最强支持。

### 题干
稻瘟病是一种由稻瘟病原菌引起的水稻病害。甲、乙两个水稻种植试验区2018~2022年五年间稻瘟病发生面积如图所示：

以下哪项如果为真，最能支持这样的观点：乙试验区自2020年开始稻瘟病发生面积减少的原因在于施用新型生物制剂抑制稻瘟病。

- B. <p>甲试验区自2020年以后不再栽种<img flag="tex" src="../../../90-图片/公式图/formula-2cef1fcdc275c923.png" />品种，也没有施用<img flag="tex" src="../../../90-图片/公式图/formula-6e27632bdd146bdd.png" />制剂</p>
- C. <p>甲试验区自2019年以后一直栽种<img flag="tex" src="../../../90-图片/公式图/formula-2cef1fcdc275c923.png" />品种，自2020年以后也开始施用<img flag="tex" src="../../../90-图片/公式图/formula-6e27632bdd146bdd.png" />制剂</p>
- D. <p>甲试验区自2019年以后一直栽种<img flag="tex" src="../../../90-图片/公式图/formula-2cef1fcdc275c923.png" />品种，也没有施用<img flag="tex" src="../../../90-图片/公式图/formula-6e27632bdd146bdd.png" />制剂</p>　✅

### 官方解析
第一步：找出论点和论据。
论点：乙试验区自2020年开始稻瘟病发生面积减少的原因在于施用新型生物制剂抑制稻瘟病。
论据：题干折线图。
第二步：逐一分析选项。
A项：甲试验区不再栽种品种，施用制剂，此时两试验区的不同点是种子，所以乙试验区稻瘟病发生面积减少的原因可能是种子的问题，可以削弱题干论点，排除；
B项：甲试验区不再栽种品种，不施用制剂，那么不清楚乙试验区稻瘟病发生面积减少的原因到底是什么，为不明确项，排除；
C项：两试验区种子相同，施用相同制剂，此时不清楚乙试验区稻瘟病发生面积减少的原因到底是什么，为不明确项，排除；
D项：两试验区种子相同，乙试验区施用制剂，但甲试验区没有施用制剂，此时乙试验区稻瘟病发生面积减少，说明乙试验区稻瘟病发生面积减少的原因在于施用新型生物制剂抑制稻瘟病，补充论据，当选。
故正确答案为D。
