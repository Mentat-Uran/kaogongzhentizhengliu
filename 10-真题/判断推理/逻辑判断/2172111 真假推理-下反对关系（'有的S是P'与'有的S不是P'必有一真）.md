# 真假推理-下反对关系（'有的S是P'与'有的S不是P'必有一真）

考点：[[20-考点/判断推理/逻辑判断/真假推理-下反对关系（'有的S是P'与'有的S不是P'必有一真）|逻辑判断 / 真假推理-下反对关系（'有的S是P'与'有的S不是P'必有一真）]]


**问法模型**：三个断定中只有一个为真 → 先找两句话之间的下反对/矛盾关系锁定唯一真话所在范围，再由其余断定为假推出确定结论

## 推理链
1. 第1步：提取三个断定——（1）'有些城市有降雪'、（2）'有些城市没有降雪'、（3）'北京和邯郸没有降雪'，且限定'三个断定中只有一个为真'
2. 第2步：套用规则——（1）'有的S是P'与（2）'有的S不是P'为下反对关系，不能同假、必有一真
3. 第3步：既然（1）（2）中必有一真，唯一的真话已在（1）（2）之内，故（3）'北京和邯郸没有降雪'一定为假
4. 第4步：（3）为假 → 其负命题'北京有降雪或邯郸有降雪'成立 → 可知'有些城市有降雪'为真，即（1）为真
5. 第5步：由'只有一个为真'且（1）为真 → （2）'有些城市没有降雪'必为假
6. 第6步：（2）为假 → 其矛盾命题'所有这些城市都有降雪'为真，对照选项：B恰好为其表述，A与B矛盾（邯郸应有降雪）、C与B矛盾，均排除

**最快解法**：⚡ 下反对定位法：'有的…有雪'与'有的…没雪'两句必有一真 → 真话锁定在这两句中 → （3）必假 → 由（3）假推出（1）真 → （2）假 → 直接换为矛盾命题'所有城市都有降雪'，秒选B

## 易错点
- ⚠ 误认为'有的A是B'与'有的A不是B'可以同假，找不到突破口（二者是下反对关系，必有一真）
- ⚠ 推出（3）为假后误选A：'北京或邯郸有降雪'只表明至少一个城市有雪，无法确定具体城市，且（2）为假后结论已被锁定为全称肯定
- ⚠ 忽略'有些…没有'为假时须转换为其矛盾命题'所有…都'，漏掉负命题等价转换这一步

## 母题抽象
> 🧩 当题干出现'两句话为 有的A是B / 有的A不是B 且限定只有一真'的特征时，用下反对定位法：真话必在这两句之间，其余断定必假，再由其余断定的负命题推出唯一确定结论

**同类特征**：三个断定只有一个为真、两句话为'有些…有降雪'与'有些…没有降雪'的下反对结构、第三句涉及具体对象（北京和邯郸）、选项含全称肯定'所有这些城市都有降雪'、问法为'哪个断定一定为真'、冬日北方城市降雪情境

### 题干
下面是某冬日我国北方某些城市的天气情况：（1）有些城市有降雪；（2）有些城市没有降雪；（3）北京和邯郸没有降雪。
如果三个断定中只有一个为真，那么以下选项中哪个断定一定为真？

### 选项
- A. 北京有降雪，但邯郸没有
- B. 所有这些城市都有降雪　✅
- C. 所有这些城市都没有降雪
- D. 以上各选项都不一定为真

### 官方解析
第一步：找关系。
（1）有些城市有降雪；
（2）有些城市没有降雪；
（3）北京和邯郸没有降雪。
条件（1）和（2）为两个“有的”，必有一真，而根据三个断定中只有一个为真可知唯一的一真在条件（1）和（2）中，那么条件（3）一定为假。
第二步：看其余。
根据条件（3）为假，即真话为北京或邯郸有降雪，可推知有的城市有降雪，条件（1）为真，那么条件（2）有些城市没有降雪为假，真话为所有城市都有降雪。
故正确答案为B。
