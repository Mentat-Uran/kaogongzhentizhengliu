# 论证缺陷-前提假设（否定代入验证+可行性-有效性择优）

考点：[[20-考点/判断推理/逻辑判断/论证缺陷-前提假设（否定代入验证+可行性-有效性择优）|逻辑判断 / 论证缺陷-前提假设（否定代入验证+可行性/有效性择优）]]


**问法模型**：'要使该建议成立，必须补充的前提是'→前提假设题，用否定代入法找'否定则论点崩塌'的必要条件；若多个选项皆为必要，按'是否贴近论点核心'择优

## 推理链
1. 第1步：论据指出'流动人口同样会为城市创造GDP'，当城市'流动人口占比较高'时，只用常住人口算人均GDP会'高估'经济发展水平——即人均GDP的缺陷在于人口基数失真
2. 第2步：论点建议对'经济发展水平相近'的城市用'吨均GDP'（GDP总量÷生活垃圾总量）替代'人均GDP'，其隐含桥梁是：垃圾总量须能换算出实际人口总数（实际人口=垃圾总量÷人均垃圾产生量）
3. 第3步：否定代入检验桥梁：若经济发展水平相近的城市人均垃圾产生量不相近，则垃圾总量无法确定实际人口数，'吨均GDP'随之失真，无法准确比较发展水平，论点不成立
4. 第4步：C项'经济发展水平相近的城市，居民的生活垃圾人均产生量相近'恰好补上该桥梁，选项不成立则论点不成立，是不可或缺的前提
5. 第5步：对照A项：只说明垃圾'能准确统计'，属方法可行性，未证明垃圾指标能用来比较发展水平的有效性，与论点核心隔一层，择优排除
6. 第6步：对照B项（气候、城市布局与'能否准确比较发展水平'话题不一致）与D项（'各个城市'范围超出论点限定的'经济发展水平相近的城市'），排除，锁定C

**最快解法**：⚡ 否定代入法+前提择优：将C否定——发展水平相近的城市人均垃圾产生量若不相近，垃圾总量就不能反映实际人口，'吨均GDP'失去可比性，论点崩塌，故C必选；A虽也必要但只保'可行性'不保'有效性'，与论点核心（能否用垃圾比较发展水平）不贴合，择优选C

## 易错点
- ⚠ 误选A：把'可行性'当'有效性'——垃圾能准确统计不代表垃圾指标能衡量城市发展水平，A离论点核心隔一层
- ⚠ 误选D：忽略D的'各个城市'范围过大超出论点限定，且D只比较流动人口与常住人口之间的垃圾量，并未建立'垃圾总量—实际总人口'的换算关系
- ⚠ 未识别隐含桥梁：替代论证成立必须默认'垃圾总量与实际人口成正比'，即比较范围内人均垃圾产生量相近，漏掉此桥则无从下手

## 母题抽象
> 🧩 当题干出现'用指标X替代指标Y进行比较/衡量'的建议时，必须补充的前提是使'X与Y在限定比较范围内等价（成正比）'的桥梁条件；用否定代入法验证，并在'可行性'与'有效性'两个必要项中择优选更贴近论点核心者

### 题干
人均GDP可以基于常住人口计算，但算出的结果可能并不准确，因为流动人口同样会为城市创造GDP。当一个城市的流动人口占比较高时，只用常住人口来计算人均GDP，可能会导致对城市经济发展水平的高估。有专家因此建议，对经济发展水平相近的城市而言，用“吨均GDP”（每吨生活垃圾所对应的GDP）替代“人均GDP”，更能准确比较各个城市的发展水平。
要使该建议成立，必须补充的前提是（    ）。

### 选项
- A. 所有城市都能准确统计本地区居民产生的生活垃圾数量
- B. 气候条件、城市布局等因素不会影响居民的生活垃圾产生量
- C. 经济发展水平相近的城市，居民的生活垃圾人均产生量相近　✅
- D. 各个城市中，流动人口和常住人口每人每天产生的垃圾数量相近

### 官方解析
第一步：找出论点和论据。
论点：对经济发展水平相近的城市而言，用“吨均GDP”（每吨生活垃圾所对应的GDP）替代“人均GDP”，更能准确比较各个城市的发展水平。
论据：当一个城市的流动人口占比较高时，只用常住人口来计算人均GDP，可能会导致对城市经济发展水平的高估。
本题的论点和论据均在讨论准确比较各个城市发展水平的方法，二者话题一致，且问题为“前提”，优先考虑必要条件。
第二步：逐一分析选项。
A项：该项说的是所有城市都能准确统计本地区居民产生的生活垃圾数量，说明生活垃圾数量可以进行准确统计，该方法具有可行性，是论点成立的必要条件，保留；
B项：该项说的是气候条件、城市布局等因素不会影响居民的生活垃圾产生量，而论点说的是“吨均GDP”更能准确比较各个城市的发展水平，话题不一致，无法加强，排除；
C项：该项说的是经济发展水平相近的城市，居民的生活垃圾人均产生量相近，实际人口总数=垃圾总量/人均垃圾产生量，如果经济发展水平相近的城市中人均垃圾产生量不相近，也就无法根据垃圾总量来确定实际人口总数，那么就无法用垃圾来确定城市发展水平，即用“吨均GDP”就无法比较各个城市的发展水平，即选项不成立则论点不成立，因此选项可以证明该方法有效，是论点成立的必要条件，保留；
D项：该项说的是各个城市，论点针对的是“经济发展水平相近”的城市，“各个城市”范围过大，超出了论点论述的范围，且即使流动人口和常住人口每人每天产生的垃圾数量不相近，但能保证经济发展水平相近的城市人均产生量相近也可以满足论点成立的条件，选项不是论点成立的必要条件，排除。
A、C两项比较，A项证明方法具有可行性，C项证明方法具有有效性，二者都是论点成立的必要条件，需要注意的是，论点讨论的就是该方法能否用来比较城市发展水平，但A项只能证明生活垃圾可以准确统计，无法证明能否用生活垃圾来比较相近城市的发展水平，而C项能证明生活垃圾确实可以用来比较城市发展水平，因此，C项比A项更贴近论点，择优选择C项。
故正确答案为C。
