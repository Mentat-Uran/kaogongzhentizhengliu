# 翻译推理-由结论倒推前提（逆否等价+选言否一推一）

考点：[[20-考点/判断推理/逻辑判断/翻译推理-由结论倒推前提（逆否等价+选言否一推一）|逻辑判断 / 翻译推理-由结论倒推前提（逆否等价+选言否一推一）]]


**问法模型**：问'增加哪项作为前提可推出给定结论'→ 从结论出发逆向倒推，将各条件反向串联成传导链，链的起点即为所选项

## 推理链
1. 第1步：翻译条件：①赵哲→¬周经；②钱法医 或 赵哲；③李计 或 孙计；④孙计→¬钱法医，目标结论是'李计'
2. 第2步：条件③是相容选言'李计 或 孙计'，要用'否一推一'推出'李计'，必须补充'¬孙计'这一前提
3. 第3步：条件④'孙计→¬钱法医'的逆否等价为'钱法医→¬孙计'，故要得'¬孙计'必须补充'钱法医'
4. 第4步：条件②'钱法医 或 赵哲'，要推出'钱法医'，同样用'否一推一'，必须补充'¬赵哲'
5. 第5步：条件①'赵哲→¬周经'的逆否等价为'周经→¬赵哲'，故要得'¬赵哲'必须补充'周经'
6. 第6步：倒推链条为：周经→¬赵哲→钱法医→¬孙计→李计，逐项对照，D项'小周是经济学专业的'恰好是链条起点，A、B、C均无法启动该链条

**最快解法**：⚡ 逆向倒推法：以结论'小李计算机'为终点，按③(否一推一)→④(逆否)→②(否一推一)→①(逆否)逆序串联，得到需要的前提'小周是经济学专业的'，直接选D

## 易错点
- ⚠ 误选B'小孙是计算机专业的'：B加上条件③推不出结论，反而与'否一推一'方向相反（需要的是孙不是计算机）
- ⚠ 把②中选言的'否一推一'方向用反：要推出'钱法医'必须否定'赵哲'，而不是肯定'赵哲'（误肯定赵哲会误选C）
- ⚠ 逆否等价方向搞错：①的逆否是'周经→¬赵哲'，若记反则找不到正确起点

## 母题抽象
> 🧩 当题干给出完整条件链并问'增加哪项可推出某结论'时，用逆向倒推法：从结论出发，相容选言用'否一推一'、假言命题用'逆否等价'逐层反推，倒推出的链条起点即正确选项

**同类特征**：给出结论求所缺前提、如果…那么与或者…或者混合、至少有一人是、选言否一推一、假言逆否等价、人名对应专业

### 题干
滨海大学选派小赵、小钱、小孙、小李、小周组成辩论队，参加滨海市组织的大学生辩论赛。已知：
（1）如果小赵是哲学专业的，那么小周就不是经济学专业的；
（2）或者小钱是法医专业的，或者小赵是哲学专业的；
（3）小李和小孙至少有一人是计算机专业的；
（4）如果小孙是计算机专业的，那么小钱不是法医专业的。
增加以下哪项作为前提，可以推出“小李是计算机专业的”？

### 选项
- A. 小钱不是法医专业的
- B. 小孙是计算机专业的
- C. 小赵是哲学专业的
- D. 小周是经济学专业的　✅

### 官方解析
第一步：翻译题干。
①小赵哲学小周经济学；
②小钱法医 或 小赵哲学；
③小李计算机 或 小孙计算机；
④小孙计算机小钱法医。
第二步：根据题干条件进行推理。
提问为“推出‘小李是计算机专业的’”，本题给出了结论，需要从结论出发倒推条件。
根据条件③可知：想要推出“小李是计算机专业的”，根据“否一推一”，需要“小孙不是计算机专业的”成立；
根据条件④可知：想要推出“小孙不是计算机专业的”，根据“逆否等价”，需要“小钱是法医专业的”成立；
根据条件②可知：想要推出“小钱是法医专业的”，根据“否一推一”，需要“小赵不是哲学专业的”成立；
根据条件①可知：想要推出“小赵不是哲学专业的”，根据“逆否等价”，需要“小周是经济学专业的”成立，对应D项。
故正确答案为D。
