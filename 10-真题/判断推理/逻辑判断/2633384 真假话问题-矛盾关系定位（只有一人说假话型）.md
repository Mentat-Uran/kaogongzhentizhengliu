# 真假话问题-矛盾关系定位（只有一人说假话型）

考点：[[20-考点/判断推理/逻辑判断/真假话问题-矛盾关系定位（只有一人说假话型）|逻辑判断 / 真假话问题-矛盾关系定位（只有一人说假话型）]]


**问法模型**：题干给出多人断言且限定'只有一人说假话' → 先找互为矛盾的两句话锁定唯一假话范围，其余命题必真，直接读出结论

## 推理链
1. 第1步：符号化四人断言——甲：'不是我干的'（非甲）；乙：'是丁干的'（丁）；丙：'是乙干的'（乙）；丁：'乙是诬告'（即非丁）
2. 第2步：识别矛盾——乙说'是丁干的'与丁说'乙是诬告（非丁）'互为矛盾关系，必一真一假，唯一的假话必落在这两句之间
3. 第3步：由'他们当中只有一人说假话'，推出甲和丙两句必定都是真话
4. 第4步：甲为真 → 甲不是扒手；丙为真 → '是乙干的'，即扒手是乙
5. 第5步：代入验证——若乙是扒手，则乙说'丁干的'为假，丁说'诬告'为真，甲丙均为真，恰好只有一人说假话，与题干完全吻合，故选B

**最快解法**：⚡ 矛盾定位法：一眼锁定乙与丁的话互为矛盾（必一真一假），唯一假话被锁定，其余甲、丙必真，丙直言'是乙干的'，直接得答案B，无需逐项假设

## 易错点
- ⚠ 把乙丁的话误判为上反对关系而犹豫'能否同假'，实际二者一为'丁干的'一为'非丁干的'，是标准矛盾关系
- ⚠ 忽略'只有一人说假话'这一全真限定条件，转而逐一假设四人身份逐一验证，浪费考场时间
- ⚠ 找错矛盾对象：误以为甲的话（否认自己）与题干情境存在矛盾，绕远路

## 母题抽象
> 🧩 当题干出现'只有一人说（真/假）话'且多人各给一句断言时，先找互为矛盾的一对锁定真假范围，再依据其余命题必真直接读出结论，最后代入验证真伪数量

**同类特征**：只有一人说假话、四人各说一句断言、乙指责丁、丁否认（互为矛盾）、其余人话全真、扒手只有一个人、甲作排除性否认

### 题干
一天，一位上车不久的乘客发现自己的背包被人割开，刚取回的一万元钱不见了。据乘客说上车时还没事，因当时还没有乘客下车，司机于是把车开到附近的派出所。经过调查寻找，发现钱已被扒手丢在了座位下边。嫌疑人有甲、乙、丙、丁。
甲：“反正不是我干的。”
乙：“是丁干的。”
丙：“是乙干的。”
丁：“乙是诬告。”
他们当中只有一人说假话，扒手只有一个人，是：

### 选项
- A. 甲
- B. 乙　✅
- C. 丙
- D. 丁
