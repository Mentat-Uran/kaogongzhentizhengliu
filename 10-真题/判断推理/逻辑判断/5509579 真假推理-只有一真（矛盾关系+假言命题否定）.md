# 真假推理-只有一真（矛盾关系+假言命题否定）

考点：[[20-考点/判断推理/逻辑判断/真假推理-只有一真（矛盾关系+假言命题否定）|逻辑判断 / 真假推理-只有一真（矛盾关系+假言命题否定）]]


**问法模型**：四句话'只有一项为真'且含假言命题与联言命题 → 先找互为矛盾的两句锁定唯一真话范围，其余全假，再用'假言为假=前真且后假'还原事实

## 推理链
1. 第1步：提取隐藏前提——四人'要么只看了电影，要么只购了物'，即对每个人'购物'与'看电影'非此即彼、互为矛盾
2. 第2步：由'乙购物=乙没看电影'，把条件④'甲和乙都有购物'改写为'甲购物 且 乙没看电影'，这恰是条件②'甲购物→乙电影'（A→B）的矛盾形式'A且非B'，故②④必一真一假
3. 第3步：题干限定四句话'只有一项为真'，唯一真话必落在②④这对矛盾之中，因此条件①'丁有购物'和条件③'如果丁没有购物，那么丙去看了电影'均为假
4. 第4步：①为假 → 丁没有购物 → 结合非此即彼前提 → 丁去看了电影
5. 第5步：③为假，按'前件真且后件假'取其否定 → '丁没有购物 且 丙没有看电影'成立 → 丙没有看电影 → 丙有购物
6. 第6步：对照选项，'丙有购物，丁看了电影'为C项；且无论②真④假还是④真②假两种情形，'丙购物、丁看电影'均成立，故为必然结论

**最快解法**：⚡ 矛盾法+唯一真：一眼看出④（甲乙都购物）代入'非此即彼'后＝'甲购物且乙没看电影'，正是②（甲购物→乙电影）的矛盾命题，二者必一真一假；唯一真话被②④包揽，则①③必假——①假得'丁看电影'，③假得'丁没购物且丙没看电影→丙购物'，直接锁定C

## 易错点
- ⚠ 忽略'要么只看电影，要么只购物'这一隐藏前提，无法把联言④改写成'甲购物且乙没看电影'，从而找不到②④的矛盾关系
- ⚠ 不会否定假言命题：③为假应得'丁没购物 且 丙没看电影'（前真且后假），误以为只否定后件或否定前件
- ⚠ 担心②④何者为真不确定会导致结论不唯一——实际上两种取真情形下'丙购物、丁看电影'均成立，题目只要求推出必然结论

## 母题抽象
> 🧩 当题干出现'若干句话只有一真/一假'且混有假言与联言命题时，先用'非此即彼'类前提把联言改写成假言的矛盾形式（A且非B），锁定真话范围，其余全假，再按'假言为假=前真且后假'还原事实作答

**同类特征**：要么只看电影，要么只购物（非此即彼）、只有一项为真、如果…那么…（假言命题）、甲和乙都有购物（联言命题）、真假话问题找矛盾、结论须为必然推出

### 题干
周末，甲、乙、丙、丁在商场偶遇，一阵寒暄过后得知，他们几人在商场要么只看了电影，要么只购了物：
①丁有购物
②如果甲有购物，那么乙去看了电影
③如果丁没有购物，那么丙去看了电影
④甲和乙都有购物
如果以上陈述只有一项为真，可以推出：

### 选项
- A. 乙有购物，甲看了电影
- B. 丙有购物，乙看了电影
- C. 丙有购物，丁看了电影　✅
- D. 甲和乙都看了电影

> [!warning] 疑点（官方解析可能有误，待人工复核）
> 官方解析中间步骤有笔误：'①和③为假可知，其矛盾命题丁购物和丁购物且丙电影为真'表述与命题不符——①'丁有购物'为假，其矛盾面应为'丁没有购物（即丁看电影）'；③为假的否定应为'丁没有购物且丙没有看电影（丙有购物）'。解析最终结论'丁看了电影，丙有购物'及答案C本身正确
