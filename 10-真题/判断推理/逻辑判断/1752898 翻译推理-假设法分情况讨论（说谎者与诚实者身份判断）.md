# 翻译推理-假设法分情况讨论（说谎者与诚实者身份判断）

考点：[[20-考点/判断推理/逻辑判断/翻译推理-假设法分情况讨论（说谎者与诚实者身份判断）|逻辑判断 / 翻译推理-假设法分情况讨论（说谎者与诚实者身份判断）]]


**问法模型**：题干无任何确定信息却问'M族人有几个'→对关键人物甲做'是M族/不是M族'两分假设，分情况讨论后取共同结论

## 推理链
1. 第1步：题干仅有规则'M族人从不说真话，N族人总是说真话'，甲乙丙三人身份全部未知，题干及选项均无确定信息。
2. 第2步：对小张的提问'你是M族人吗'，若甲是M族则说假话答'我不是M族人'，若甲是N族则说真话答'我不是M族人'，即无论甲身份如何其回答必为'我不是M族人'，回答本身无鉴别力，须假设甲的身份分情况讨论。
3. 第3步：情况一假设甲是M族：甲回答'我不是M族人'（假话）；乙'根据甲的回答'说'甲不是M族人'，乙并不知真实情况、其话与甲的回答一致，故乙说了真话→乙是N族；丙的话不基于甲的回答而基于真实情况，'甲是M族人'符合假设的真实情况→丙说真话是N族；此时只有甲1个M族人。
4. 第4步：情况二假设甲不是M族（是N族）：甲回答'我不是M族人'（真话）；乙的话与甲的回答一致，乙说真话→乙是N族；丙说'甲是M族人'与真实情况不符，丙说假话→丙是M族；此时只有丙1个M族人。
5. 第5步：两种情况下乙均为N族，且三人中均恰好只有1个M族人（情况一为甲、情况二为丙），'个数'结论唯一，故正确答案为B。

**最快解法**：⚡ 假设法＋'自指问题答案恒定'技巧：先抓住甲对'你是M族人吗'的回答必是'我不是M族人'（与身份无关），再对甲做'M族/N族'两分假设快速核乙丙两人的话，两种情况均得'乙是N族、M族人恰1个'，直接选B。

## 易错点
- ⚠ 未发现甲的回答与身份无关（两类人对'你是不是M族'都答'不是'），导致不知从何下手假设。
- ⚠ 把乙的话误当成对甲身份的独立事实判断：题干明确'乙根据甲的回答'说，乙不掌握真实情况，其话与甲的回答一致即为说真话；若按客观身份评判乙，情况一里会误判乙为M族而错算成2个M族人。
- ⚠ 只验证一种假设就下结论，或看到两种情况下M族人分别是'甲或丙'不同的人就误认为结论不唯一，忽略题目问的是'个数'而非'是谁'。

## 母题抽象
> 🧩 当题干出现'说谎族/诚实族'且问某类人个数、无确定信息时，先证明关键人物对'你是不是X族'的回答恒为'不是'（无信息量），再对其做两分假设逐人核对话语真假定身份，两种情况一致的结果即为答案。

**同类特征**：只住M族（说假话）与N族（说真话）两种人、问'你是M族人吗'的自指问题、乙'根据甲的回答'说话、丙独立断言'甲是M族人'、问三人中M族人的个数、题干无确定信息、适合假设法

### 题干
从前，有一个奇怪的岛屿，岛屿上只住着M族人和N族人。M族人从不说真话，N族人总是说真话。有一天，小张来到这个岛屿，碰到该岛屿上的三个人。小张问甲：“你是M族人吗？”甲做了回答。乙根据甲的回答说：“甲不是M族人。”丙说：“甲确实是M族人。”
根据以上陈述，可推出小张碰到的三个人中，有几个M族人？

### 选项
- A. 0
- B. 1　✅
- C. 2
- D. 3

### 官方解析
题干及选项均无确定信息，适合用假设法，分情况讨论，由于题干三人所讨论的都是甲的情况，所以分别假设甲是M族人、甲不是M族人。
情况（一）：假设甲是M族人，由题干“M族人从不说真话”，那么甲说假话，所以甲回答小张的应该是：我不是M族人；
由题干“乙根据甲的回答说”，说明乙说的话并非根据真实情况（即乙并不知道甲是否M族人），乙说的话是基于甲的回答，乙说的是，“甲不是M族人”，和甲的回答一致，所以乙说了真话，由题干“N族人总是说真话”，得出乙是N族人；
此时丙说，“甲是M族人”，丙说的话并非根据甲的回答，说明丙是基于真实情况来说的，而真实情况是，甲是M族（假设的真实情况），因此丙说了真话，由题干“N族人总是说真话”，得出丙是N族人；此种情况下只有甲一个人是M族人；
情况（二）：假设甲不是M族人，是N族人，那么甲只说真话，因此甲回答小张的应该是：我不是M族人。
此时，乙根据甲的回答说，甲不是M族人，与甲的回答一致，说明乙说了真话，所以乙是N族人；
丙说，甲是M族人，丙说的话是基于真实情况，即假设的情况（甲不是M族人），所以此时丙说了假话，由题干“M族人从不说真话”，则丙是M族人。此种情况下只有丙一个人是M族人。
综上两种情况，三个人中均只有一个人是M族人。
故正确答案为B。
