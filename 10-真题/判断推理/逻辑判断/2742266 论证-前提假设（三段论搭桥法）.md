# 论证-前提假设（三段论搭桥法）

考点：[[20-考点/判断推理/逻辑判断/论证-前提假设（三段论搭桥法）|逻辑判断 / 论证-前提假设（三段论搭桥法）]]


**问法模型**：问法为'为使上述论证成立，需补充的前提是'→ 前提假设题，论据与论点话题不一致时用搭桥法，在两个核心概念间补全称命题，并验证'论据+选项→论点'必然成立。

## 推理链
1. 第1步：提取论据——'某培训机构的一些舞蹈教师拥有舞蹈师资格证'，即'有些舞蹈教师→有证'；提取论点——'该机构有些女教师拥有舞蹈师资格证'，即'有些女教师→有证'。
2. 第2步：论点说'女教师'与'证'的关系，论据说'舞蹈教师'与'证'的关系，二者主项不一致，前提题优先搭桥，需在'舞蹈教师'与'女教师'之间建立必然联系。
3. 第3步：依据三段论有效式'有些A是B + 所有B是C → 有些A是C'，要由'有些舞蹈教师有证'推出'有些女教师有证'，必须补充'所有舞蹈教师都是女教师'这一全称前提。
4. 第4步：C项'该机构所有舞蹈教师均为女教师'代入：'有些舞蹈教师有证'+ '所有舞蹈教师均为女教师'→ 必然推出'有些女教师有证'，论点成立，当选。
5. 第5步：A项'有些舞蹈教师是女教师'、B项'有些女教师是舞蹈教师'（与A互为换位、等价），均只提供'有些'关系，与'有些舞蹈教师有证'两个'有些'无法传递，有证者未必是女教师，不必然推出论点，排除。
6. 第6步：D项'有些女舞蹈教师没有舞蹈师资格证'讨论的是'没有证'，与论点'拥有证'方向相反且无必然联系，排除。

**最快解法**：⚡ 搭桥法口诀'有些+所有推有些，缺桥找全称'：论点主项'女教师'与论据主项'舞蹈教师'之间缺连接，直接找含'所有……都……'的搭桥项，秒选C（唯一全称选项）。

## 易错点
- ⚠ 误选A/B：以为'有些舞蹈教师是女教师'与'有些舞蹈教师有证'可在'舞蹈教师'上重叠推出结论，但'有些'+'有些'无法必然传递，有证的舞蹈教师可能恰好都不是女教师。
- ⚠ 混淆三段论方向：由'有些舞蹈教师有证'推'有些女教师有证'，桥必须从'舞蹈教师'指向'女教师'且是全称，选B时误以为换位后方向不同会有区别。
- ⚠ 忽略前提题的必然性标准：A、B、D只是'可能加强/不明确'项，前提必须使论点必然成立，不能选'有点帮助'的选项。

## 母题抽象
> 🧩 当题干出现'论据与论点主项（话题）不一致+问法为补充前提'的特征时，用搭桥法，在两个不一致概念间补'所有……都是……'的全称命题，并验证'论据+所补前提→论点'是否必然成立。

### 题干
某培训机构的一些舞蹈教师拥有舞蹈师资格证，所以，该机构有些女教师拥有舞蹈师资格证。
为使上述论证成立，需补充的前提是：

### 选项
- A. 该机构有些舞蹈教师是女教师
- B. 该机构有些女教师是舞蹈教师
- C. 该机构所有舞蹈教师均为女教师　✅
- D. 该机构有些女舞蹈教师没有舞蹈师资格证

### 官方解析
第一步：找出论点和论据。
论点：该机构有些女教师拥有舞蹈师资格证。
论据：某培训机构的一些舞蹈教师拥有舞蹈师资格证。
本题论点说的是女教师与舞蹈师资格证之间的关系，论据说的是舞蹈教师与舞蹈师资格证之间的关系，二者话题不一致，且问题为“前提”，优先考虑搭桥，即在舞蹈教师与女教师之间建立联系。
第二步：逐一分析选项。
A项：指出有些舞蹈教师是女教师，结合论据中一些舞蹈教师拥有舞蹈师资格证，无法确定是否有些女教师拥有舞蹈师资格证，不明确选项，无法加强，排除；
B项：指出有些女教师是舞蹈教师，可以推出有些舞蹈教师是女教师，与A项相同，无法确定是否有些女教师拥有舞蹈师资格证，不明确选项，无法加强，排除；
C项：指出所有舞蹈教师均为女教师，结合论据中一些舞蹈教师拥有舞蹈师资格证，可以推出有些女教师拥有舞蹈师资格证，即论点成立，搭桥项，当选；
D项：指出有些女舞蹈教师没有舞蹈师资格证，无法确定是否有些女教师拥有舞蹈师资格证，无法加强，排除。
故正确答案为C。
