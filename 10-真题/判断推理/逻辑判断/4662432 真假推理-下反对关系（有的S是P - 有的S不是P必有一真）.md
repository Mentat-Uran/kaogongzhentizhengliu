# 真假推理-下反对关系（有的S是P - 有的S不是P必有一真）

考点：[[20-考点/判断推理/逻辑判断/真假推理-下反对关系（有的S是P - 有的S不是P必有一真）|逻辑判断 / 真假推理-下反对关系（有的S是P / 有的S不是P必有一真）]]


**问法模型**：三种说法只有一真 → 先用'两个有的必有一真'锁定真话范围，排除单称/全称命题为假，再由特称命题为假换矛盾得全称结论

## 推理链
1. 第1步：提取三个命题——(1)单称肯定'甲型检测仪能预测'；(2)特称否定'有的型号不能预测'；(3)特称肯定'有的型号能预测'
2. 第2步：调用规则：(2)'有的不能'与(3)'有的能'是下反对关系，不能同假、必有一真；题干限定'这三种说法中只有一种是真的'，故唯一真话必落在(2)(3)之间，从而(1)一定为假
3. 第3步：(1)为假 → 甲型检测仪不能预测350公里以内的地震 → 这恰好构成'有的型号不能预测'，即(2)为真
4. 第4步：唯一真话已确定为(2)，故(3)为假；特称否定(3)'有的型号能预测'为假，其矛盾命题'所有型号都不能预测350公里以内将可能发生的地震'为真
5. 第5步：甲、乙、丙三种检测仪全部不能预测，对照选项：A'乙能'错、B'甲能'错、D'丙能'错，只有C'乙和丙都不能预测'与结论一致

**最快解法**：⚡ 下反对关系秒杀法：见到'两个有的'（有的能/有的不能）即知二者必有一真 → 题干只有一真 → (1)必假 → 甲不能 → (2)真 → (3)假 → 换矛盾得'全都不能' → 选C

## 易错点
- ⚠ 不掌握'有的S是P'与'有的S不是P'为下反对关系（必有一真、可以同真），找不到突破口无从下手
- ⚠ (3)为假时忘记换成矛盾命题'所有型号都不能'，误以为只能推出乙、丙中某一个的情况
- ⚠ 误把单称命题(1)与特称命题(2)(3)也当作必有一真的关系，错锁真话范围

## 母题抽象
> 🧩 当题干出现'两个有的（有的…是/有的…不是）+其他说法、且限定只有一真'时，先由下反对关系把唯一真话锁定在两个'有的'之间，令其余命题为假推出具体对象情况，再确定哪个'有的'为真、另一个为假，最后将假的特称换成矛盾的全称得出结论

**同类特征**：三种说法中只有一种是真的、两个'有的'句式并存、单称命题与特称命题混合、真假限定（只有一真）、判定多对象是否具有某属性

### 题干
某市地震监控部门购买了甲、乙、丙三种型号的地震检测仪各一台。关于它们的性能，该部门负责人老李在不同场合有三种不同的说法：
（1）甲型检测仪能预测到350公里以内将可能发生的地震。
（2）有的型号的检测仪不能预测到350公里以内将可能发生的地震。
（3）有的型号的检测仪能预测到350公里以内将可能发生的地震。
事后证实，这三种说法中只有一种是真的。
根据上述信息，对于三种检测仪能否预测到350公里以内将可能发生的地震，可以得出以下哪项？

### 选项
- A. 乙能预测，而丙不能
- B. 甲能预测，而乙不能
- C. 乙和丙都不能预测　✅
- D. 丙能预测，而甲不能

### 官方解析
第一步：分析题干条件。
（1）甲型检测仪能预测到350公里以内将可能发生的地震；
（2）有的型号的检测仪不能预测到350公里以内将可能发生的地震；
（3）有的型号的检测仪能预测到350公里以内将可能发生的地震。
条件（2）和条件（3）为两个“有的”，必有一真，而根据“这三种说法中只有一种是真的”可知，唯一的真话应该在条件（2）和条件（3）中，那么条件（1）一定为假。
第二步：根据题干条件进行推理。
根据条件（1）为假可知，甲型检测仪不能预测到350公里以内将可能发生的地震，可推出条件（2）一定为真的，那么条件（3）一定是假的，由此可知所有型号的检测仪都不能预测到350公里以内将可能发生的地震，只有C项符合。
故正确答案为C。
