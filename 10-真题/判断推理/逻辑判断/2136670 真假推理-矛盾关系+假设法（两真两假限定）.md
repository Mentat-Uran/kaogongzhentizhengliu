# 真假推理-矛盾关系+假设法（两真两假限定）

考点：[[20-考点/判断推理/逻辑判断/真假推理-矛盾关系+假设法（两真两假限定）|逻辑判断 / 真假推理-矛盾关系+假设法（两真两假限定）]]


**问法模型**：题干给出'两人真话两人假话'的数量限定且各人陈述可互推真假 → 先找矛盾命题锁定一真一假，再对剩余命题用假设法（假设代入看是否自洽）

## 推理链
1. 第1步：提取四人陈述——甲'我们四个都没有坚持一个月'（全称否定），乙'我们四个中有人坚持了一个月'（特称肯定），丙'乙和丁至少有一人没有坚持一个月'（包容命题），丁'我没有坚持一个月'（单称否定）
2. 第2步：甲的'所有都没坚持'与乙的'有人坚持了'构成矛盾关系，必一真一假；由'两真两假'限定可知丙、丁必一真一假
3. 第3步：假设丁为真（丁没坚持一个月），则'乙和丁至少有一人没坚持'的丙必也为真，与'丙丁一真一假'矛盾，故丁必为假
4. 第4步：丁为假 → 其话的否定'丁坚持了一个月'为真 → '有人坚持了一个月'成立，故乙为真；再由甲乙一真一假得甲为假，由丙丁一真一假得丙为真
5. 第5步：说真话的是乙和丙，对照选项，B项'说真话的是乙和丙'与结论一致

**最快解法**：⚡ 矛盾锁定+假设法：甲乙矛盾定一真一假 → 丙丁一真一假 → '丁真则丙必真'自相矛盾，故丁假 → 丁坚持了一个月即'有人坚持了'→ 乙真甲假、丙真，秒选B

## 易错点
- ⚠ 不找矛盾命题，把四种真话组合逐一代入验证，费时且易在组合对应上出错
- ⚠ 忘记'说假话'意味着其陈述的否定为真：丁说假话可直接推出'丁坚持了一个月'
- ⚠ 忽略真假传导链条：由丁假推出乙真后，还需回头用'甲乙矛盾''丙丁一真一假'分别确定甲假、丙真，漏一步就会选错

## 母题抽象
> 🧩 当题干出现'N人X真X假'限定且存在一对'所有都不/有的是'式矛盾命题时，先用矛盾对固定一真一假，剩余命题若'甲真则乙必真'与真假限定冲突，则甲必假，再顺推传导定其余人真假

**同类特征**：两真两假的数量限定、全称否定与特称肯定的矛盾对、'至少有一人'的包容命题、单称否定命题（我没有…）、真假的传导关系、问谁说真话

### 题干
四个好朋友相约在孤岛进行野外生活体验一个月，随后他们对这次活动有如下对话：
甲：我们四个都没有坚持一个月；
乙：我们四个中有人坚持了一个月；
丙：乙和丁至少有一人没有坚持一个月；
丁：我没有坚持一个月。
如果四个人中有两人说的是真话，两人说的是假话，则下列说法正确的是：

### 选项
- A. 说真话的是甲和丁
- B. 说真话的是乙和丙　✅
- C. 说真话的是甲和丙
- D. 说真话的是乙和丁

### 官方解析
本题属于真假推理题。
第一步：找出题干矛盾命题。
甲说的“四人都没有坚持一个月”和乙说的“四人有人坚持了一个月”是矛盾关系，已知两人说真话，两人说假话，矛盾关系必有一真一假，所以丙和丁的话必有一真一假。
假设丁说的是真话，则丙说的一定也是真话，与题干相违背，所以丁说的一定是假话。
第二步：看其余人的话。
丁说的是假话，则丁坚持了一个月，即有人坚持了一个月，所以乙和丙的话是真话。
故正确答案为B。
