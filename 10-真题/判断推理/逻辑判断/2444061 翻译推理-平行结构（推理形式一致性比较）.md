# 翻译推理-平行结构（推理形式一致性比较）

考点：[[20-考点/判断推理/逻辑判断/翻译推理-平行结构（推理形式一致性比较）|逻辑判断 / 翻译推理-平行结构（推理形式一致性比较）]]


**问法模型**：题干问'下列选项与题干的逻辑结构相符'→ 将题干与各选项统一翻译为字母符号式（含否定标记），逐项比对命题顺序、肯定/否定与推理方向，找完全同构者

## 推理链
1. 第1步：将题干三句翻译：'科学不是宗教'为 科学(a)→¬宗教(¬b)；'宗教都主张信仰'为 宗教(b)→主张信仰(c)；'主张信仰都不科学'为 主张信仰(c)→¬科学(¬a)
2. 第2步：提炼结构模板：a→¬b，b→c，所以 c→¬a，特征是第一、三句含否定词，结论主项恰为第二前提的谓项
3. 第3步：A项翻译：广东人(a)→¬北京人(¬b)，北京人(b)→说普通话(c)，说普通话(c)→¬广东人(¬a)，否定位置与推理方向与题干逐一对应
4. 第4步：B项翻译：犯罪行为(a)→违法(b)，违法(b)→受谴责(c)，受谴责(c)→犯罪行为(a)，形式为 a→b，b→c⇒c→a，全部为肯定命题，与题干不符，排除
5. 第5步：C项翻译：领导(a)→渴望成功(b)，小王(c)→渴望成功(b)，小王(c)→领导(a)；D项翻译：商品(a)→使用价值(b)，空气(c)→使用价值(b)，空气(c)→商品(a)，两者同为 a→b，c→b⇒c→a 结构，前提顺序与题干不符，排除
6. 第6步：只有A项与题干符号式逐字同构，故正确答案为A

**最快解法**：⚡ 字母替换法+结构对照：把题干写成 'a→¬b，b→c ⇒ c→¬a'，快速给四个选项写符号式，A 项符号串与题干完全一致（否定词位置、前提顺序、结论方向全同），直接锁定；平行结构题只比形式、不判断推理对错

## 易错点
- ⚠ 误去评判题干推理本身是否有效（该推理实为无效的'逆推错误'），但本题型只比对逻辑结构，不因结论错误而排除选项
- ⚠ 忽略否定词位置：B项三句均为肯定命题（a→b，b→c⇒c→a），表面同为'三段递推'，若不标注否定号易误选B
- ⚠ C、D两项结构完全相同（a→b，c→b⇒c→a），易与题干第二前提 b→c 混淆，未注意结论中 c 的位置（主项vs谓项）差异

## 母题抽象
> 🧩 当题干出现'……不是……；……都……；所以……都不……'且问'与题干逻辑结构相符'时，先用字母统一翻译并标出否定号，再逐项写选项符号式，找逐字同构者；形式比较题不问推理有效性

**同类特征**：与题干的逻辑结构相符（平行结构问法）、首句含'不是'的否定命题、'都'字全称肯定前提、结论对首句主项作否定、三段论形式符号化比较、只比形式不比对错

### 题干
科学不是宗教，宗教都主张信仰，所以主张信仰都不科学。
下列选项与题干的逻辑结构相符的是：

### 选项
- A. 广东人不是北京人，北京人都说普通话，所以说普通话的都不是广东人　✅
- B. 犯罪行为都是违法行为，违法行为都应受到社会的谴责，所以应受到社会谴责的行为都是犯罪行为
- C. 不渴望成功的人都成不了领导，小王渴望成功，所以小王能成为领导
- D. 商品都有使用价值，空气有使用价值，所以空气也是商品

### 官方解析
第一步：翻译题干。
科学（a）→宗教（-b），宗教（b）→主张信仰（c），主张信仰（c）→科学（-a）。
第二步：逐一分析选项。
A项：翻译为:，，，与题干逻辑关系一致，当选；
B项：翻译为:犯罪行为(a)→违法行为(b)，违法行为(b)→受到谴责(c)，受到谴责(c)→犯罪行为(a)，与题干逻辑关系不一致，排除；
C项：翻译为：领导(a)→渴望成功(b)，小王(c)→渴望成功(b)，小王(c)→领导(a)，与题干逻辑关系不一致，排除；
D项：翻译为：商品(a)→使用价值(b)，空气(c)→使用价值(b)，空气(c)→商品(a)，与题干逻辑关系不一致，排除。
故正确答案为A。
