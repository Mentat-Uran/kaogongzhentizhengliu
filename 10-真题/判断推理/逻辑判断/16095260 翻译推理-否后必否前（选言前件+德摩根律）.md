# 翻译推理-否后必否前（选言前件+德摩根律）

考点：[[20-考点/判断推理/逻辑判断/翻译推理-否后必否前（选言前件+德摩根律）|逻辑判断 / 翻译推理-否后必否前（选言前件+德摩根律）]]


**问法模型**：'以下哪种情况不符合小王的预测'→选非题模型：以题干确定信息为起点正向推出唯一确定结论，选择与该结论相矛盾的选项

## 推理链
1. 第1步：抓住确定信息条件（5）'研发部录用硕士生'，以此为推理起点
2. 第2步：结合隐含前提'每个部门只招聘1名员工'，研发部录用硕士生推出'研发部没有录用本科生'
3. 第3步：条件（3）翻译为'（财务部录用本科生 或 财务部录用硕士生）→研发部录用本科生'，'研发部未录用本科生'构成对该假言后件的否定
4. 第4步：否后必否前，得'并非（财务录本科 或 财务录硕士）'，由德摩根律展开为'财务部没有录用本科生 且 财务部没有录用硕士生'
5. 第5步：财务部既不录本科生也不录硕士生，结合每部门录用1人，财务部只能录用博士生
6. 第6步：D项'财务部录用硕士生'与'财务部只能录用博士生'直接矛盾，本题为选非题，D项当选

**最快解法**：⚡ 确定信息起点+否后否前法：由'研发录硕士'→研发不录本科→对条件（3）否后→德摩根拆'或'得财务不录本科且不录硕士→财务必录博士→D项与之矛盾，选非题选D

## 易错点
- ⚠ 忽略选非题标志'不符合'，推出财务部录用博士生后误选相符项A而错选
- ⚠ 条件（3）前件为'或'关系，否前时须用德摩根律拆成'且'，只否定其中一支会误以为结论不确定
- ⚠ 忽略'每个部门只招聘1名员工'这一隐含前提，无法由'录用硕士生'推出'未录用本科生'，导致否后链条断裂

## 母题抽象
> 🧩 当题干给出多个假言/选言预测并附带一个确定事实时，从确定事实出发寻找能被否定后件的假言，否后必否前（'或'前件用德摩根律展开为'且'），得出唯一确定结论，选非题选与结论矛盾的选项

**同类特征**：确定信息起点（研发部录用硕士生）、假言命题+选言前件、否后必否前、德摩根律拆'或'、选非题、隐含前提：每部门只录1人

### 题干
如果研发部录用硕士生，那么以下哪种情况不符合小王的预测？

### 选项
- A. 生产部录用博士生
- B. 财务部录用博士生
- C. 生产部录用本科生
- D. 财务部录用硕士生　✅

### 官方解析
第一步：分析题干条件。
（1）生产部录用本科生研发部录用硕士生；
（2）研发部录用博士生生产部录用博士生；
（3）财务部录用本科生 或 财务部录用硕士生研发部录用本科生；
（4）有3名博士生、3名硕士生和3名本科生；
（5）研发部录用硕士生。
第二步：根据题干条件进行推理。
条件（5）为确定信息，以此为起点开始推理。
根据条件（5）“研发部录用硕士生”以及题干条件“每个部门只招聘1名员工”，可以推出“研发部没有录用本科生”，是对条件（3）的否后，否后必否前，可以推出“财务部没有录用本科生 且 财务部没有录用硕士生”，即财务部只能录用博士生，D项不符合小王的预测，当选。
本题为选非题，故正确答案为D。

### 给定材料
<p>某企业的生产部、研发部和财务部分别需要招聘1名员工，有3名博士生、3名硕士生和3名本科生前来应聘。该公司人事部小王对招聘结果做了如下预测：</p><p>（1）如果生产部录用本科生，那么研发部录用硕士生；</p><p>（2）如果研发部录用博士生，那么生产部录用博士生；</p><p>（3）如果财务部录用本科生或者硕士生，那么研发部录用本科生。</p>
