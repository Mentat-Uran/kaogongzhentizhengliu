# 翻译推理-逆否规则（“除非…否则不…”的翻译与禁漂原因锁定）

考点：[[20-考点/判断推理/逻辑判断/翻译推理-逆否规则（“除非…否则不…”的翻译与禁漂原因锁定）|逻辑判断 / 翻译推理-逆否规则（“除非…否则不…”的翻译与禁漂原因锁定）]]


**问法模型**：“由此可推知，以下选项一定为真的是”→将题干须知翻译为推出关系，结合“救生衣已穿＋没被允许漂流”两个事实，用逆否规则锁定禁漂触发原因，再排除法选必然真项。

## 推理链
1. 第1步：翻译须知①“除非年龄在55岁以下，并且穿上救生衣，否则不能漂流”＝能漂流→（55岁以下 且 穿救生衣），逆否得（年满55岁 或 没穿救生衣）→不能漂流。
2. 第2步：翻译规定②“有高血压或心脏病的游客不能漂流”＝有高血压 或 有心脏病→不能漂流。
3. 第3步：代入题干事实“老王穿上了救生衣，但工作人员没允许他去漂流”：禁漂已发生，而“没穿救生衣”分支已被“穿上了救生衣”排除；题干默认工作人员只依据循环播放的两条须知作决定，故触发禁漂的原因只能落在“年满55岁”或“有高血压或心脏病”之中。
4. 第4步：即两条禁令的触发条件“只要满足其一”就会导致不能漂流，而老王实际被禁漂且救生衣已满足，故可确定：老王要么年满55岁，要么有高血压或心脏病（至少其一成立，二者可并存）。
5. 第5步：逐项对照：A项把两种并列的禁漂原因强说成“年满55岁→高血压/心脏病”的推出关系，排除；B、C项把“有高血压或心脏病（且年满55岁）”这一可能原因断定为必然事实，过于确定，排除；D项恰为上述“触发原因至少其一”的选言判断，一定为真。

**最快解法**：⚡ 排除法＋翻译口诀：把“除非A否则不B”译成B→A，两条禁令译出后，抓住“救生衣已穿＋没让漂流”锁定禁漂原因只剩“年满55岁”和“高血压/心脏病”至少其一，直接锁定D；A是强加推出关系、B/C把可能当必然，排除更快。

## 易错点
- ⚠ “除非…否则不…”翻译方向搞反，误译成“不能漂流→55岁以下且穿救生衣”，导致后续逆否全错。
- ⚠ 由“没允许漂流”直接断定“有高血压或心脏病”而误选B，实质是把可能原因当必然原因（肯定后件式错误）。
- ⚠ 忽略“老王穿上了救生衣”这一已满足的排除性信息，或把“要么…要么…”误解为互斥必居其一而错排D。

## 母题抽象
> 🧩 当题干出现“除非A（且B），否则不C”＋“D→不C”的双禁令结构，并给出“C未发生且B已满足”时，将禁令逆否后锁定禁令触发原因，答案选表示“触发原因至少其一”的选言项。

**同类特征**：除非…否则不能…、复合条件（并且/或）、肯前必肯后、否后必否前、已满足部分条件（穿上了救生衣）、结果为否定（没允许他去漂流）、由此可推知一定为真

### 题干
某景区漂流项目的工作人员用扩音器循环播放注意须知：“除非年龄在55岁以下，并且穿上救生衣，否则不能漂流。”同时，出于安全考虑，有高血压或心脏病的游客不能漂流。老王穿上了救生衣，但最后工作人员没允许他去漂流。
由此可推知，以下选项一定为真的是（    ）。

### 选项
- A. 如果老王年满55岁，则他一定有高血压或心脏病
- B. 老王有高血压或心脏病
- C. 老王年满55岁，且有高血压或心脏病
- D. 老王要么年满55岁，要么有高血压或心脏病　✅

### 官方解析
<p>第一步：翻译题干。</p><p>①能漂流<img flag="tex" src="../../../90-图片/公式图/formula-220d6005ff946aad.png" />55岁以下 且 穿上救生衣</p><p>②有高血压 或 心脏病<img flag="tex" src="../../../90-图片/公式图/formula-692b70564d8c5bce.png" />漂流</p><p>第二步：根据题干条件进行推理。</p><p>如果老王年满55岁，是对条件①的否后，根据“否后必否前”可以得出老王不能漂流；</p><p>如果老王有高血压或心脏病，是对条件②的肯前，根据“肯前必肯后”可以得出老王不能漂流。</p><p>综上，只要满足其一，那么老王就不能漂流。</p><p>故正确答案为D。</p>
