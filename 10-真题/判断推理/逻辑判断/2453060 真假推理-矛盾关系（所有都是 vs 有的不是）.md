# 真假推理-矛盾关系（所有都是 vs 有的不是）

考点：[[20-考点/判断推理/逻辑判断/真假推理-矛盾关系（所有都是 vs 有的不是）|逻辑判断 / 真假推理-矛盾关系（所有都是 vs 有的不是）]]


**问法模型**：'只有一位同学猜错'限定唯一假话 → 先找矛盾关系锁定假话范围，其余命题按真处理推出结论

## 推理链
1. 第1步：提取四句话——甲'所有同学都及格'、乙'小张没有及格'、丙'肯定不会全部同学都及格'、丁'也不会所有同学都不及格'
2. 第2步：识别矛盾关系：甲'所有同学都及格'（所有S是P）与丙'不会全部及格'（有的S不是P）互为矛盾，必一真一假
3. 第3步：由'只有一位同学猜错'，唯一假话必落在甲丙这对矛盾之中，故乙和丁的话必为真
4. 第4步：乙真→小张没有及格；丁真→并非所有同学都不及格（有的同学及格），两者可同时成立
5. 第5步：由'小张没有及格'直接推翻甲'所有同学都及格'，故甲是唯一猜错者，丙为真
6. 第6步：对照选项：B'甲猜错了，小张没有及格'与推理完全一致；若如D设丙错，则甲真（全及格），乙'小张没及格'也随之错，出现两句假话与题设矛盾，排除

**最快解法**：⚡ '找矛盾、看其余'法：甲丙是矛盾对→唯一假话锁定在甲丙之间→乙丁必真→'小张没有及格'为真→甲'所有都及格'必假，秒选B

## 易错点
- ⚠ 误把甲'所有都及格'与丁'所有都不及格'当作矛盾关系（实为上反对关系，可以同假），找错矛盾对
- ⚠ 忽略'只有一位猜错'意味着其余三句全真，没有利用乙丁的真话直接推出结论
- ⚠ 误选D：未检验'丙错→甲真→乙也错'会同时出现两句假话，与题设矛盾

## 母题抽象
> 🧩 当题干出现'只有一人猜对/猜错'+多个直言命题时，先找矛盾关系（'所有A是B'与'有的A不是B'）锁定唯一真/假话的位置，其余命题必真，代入个体命题即可推出答案

**同类特征**：只有一位同学猜错（唯一假话限定）、所有同学都及格（全称肯定）、肯定不会全部及格（特称否定，与全称肯定构成矛盾）、不会所有同学都不及格（特称肯定）、小张没有及格（单称个体命题）、四人猜测真假判定

### 题干
某大学哲学系三年级本科生参加了一次国家英语六级考试。关于考试成绩，四位同学做出了如下猜测：
甲：所有同学都及格了。
乙：小张没有及格。
丙：肯定不会全部同学都及格。
丁：也不会所有同学都不及格。
如果只有一位同学猜错了，则下列                    项为真。

### 选项
- A. 甲猜错了，小张及格了
- B. 甲猜错了，小张没有及格　✅
- C. 乙猜错了，小张及格了
- D. 丙猜错了，小张及格了

### 官方解析
本题属于真假推理题。
第一步：找出题干矛盾关系。
甲说“所有同学都及格”和丙说“肯定不会全部同学都及格”（即有的同学不会及格）是矛盾关系，必有一真必有一假。
第二步：看其余。
已知只有一句是假话，则乙和丁说的是真话，即小张没有及格，也不会所有同学都不及格（即有的同学会及格），因此甲说的是假话，丙说的是真话。
故正确答案为B。
