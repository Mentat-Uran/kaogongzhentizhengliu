# 分析推理-位置排序与数值约束综合推断（排除法）

考点：[[20-考点/判断推理/逻辑判断/分析推理-位置排序与数值约束综合推断（排除法）|逻辑判断 / 分析推理-位置排序与数值约束综合推断（排除法）]]


**问法模型**：题干给多重条件组合、问'以下说法正确的是'→先由方位条件锁定位置对应，再用数值约束解出各量，最后逐项排除验证

## 推理链
1. 第1步：从条件①②提取位置信息——大象住'东边'，骆驼4岁、住'西边'，三馆为西—中—东布局，中间位置只能是猴子
2. 第2步：用条件③'小王看的是动物园东边和西边之间的动物'进行位置搭桥，中间的动物即猴子，故小王看猴子，C项'小王参观的是大象'错误
3. 第3步：由条件⑤'年龄从西到东依次增加'得年龄排序：骆驼＜猴子＜大象；结合'平均年龄为5岁'转化为总年龄=5×3=15
4. 第4步：代入条件②骆驼4岁及条件①'年龄均为整数'，猴子+大象=11且猴子＞4、大象＞猴子，唯一解为猴子5岁、大象6岁，故B项'大象年龄为7岁'错误
5. 第5步：由条件④'小张去看的动物年龄最小'，最小的是骆驼，故小张看骆驼；三人各不相同，剩余小李看大象，D项'小李参观的是骆驼'错误
6. 第6步：逐项对照，仅A项'猴子年龄为5岁'与推理结果一致

**最快解法**：⚡ 位置代入法+整数枚举：先按'西—中—东'排出骆驼—猴子—大象并确定小王看猴子；再由平均5岁得总和15、骆驼4岁、年龄为递增整数，直接写出4、5、6三个数，秒选A

## 易错点
- ⚠ 忽略'年龄均为整数'这一约束，误以为递增组合不唯一（如猴5象6与猴5象7混淆），错选B
- ⚠ 未将'平均年龄5岁'先转化为总年龄15再分配，导致数值推理卡壳
- ⚠ 位置线索（西—中—东）与参观人对应关系交叉时出错，误判小张或小李的参观对象

## 母题抽象
> 🧩 当题干同时出现'方位/顺序排列+数值依次递增+平均值+整数约束'时，先按位置排出对象顺序，再把平均值转化为总和，用整数与递增条件枚举出唯一数值解，最后按人与物的剩余对应关系排除选项

**同类特征**：三种动物对应西—中—东三个方位、年龄均为整数、年龄从西到东依次增加、平均年龄为5岁、三人各选一种动物且互不相同、问法为'以下说法正确的是'

### 题干
动物园中有三种动物：骆驼、大象和猴子，它们的年龄均为整数。三个伙伴小张、小王和小李去动物园参观动物，他们各选择一种动物去参观，三人选的动物各不相同。已知：
①大象住在动物园东边的动物馆；
②骆驼已经4岁，住在西边的动物馆；
③小王去看的是动物园东边和西边之间的动物；
④小张去看的动物年龄最小；
⑤三种动物年龄从西到东依次增加，且平均年龄为5岁。
以下说法正确的是：

### 选项
- A. 猴子年龄为5岁　✅
- B. 大象年龄为7岁
- C. 小王参观的是大象
- D. 小李参观的是骆驼

### 官方解析
第一步：分析题干条件。
（1）骆驼、大象和猴子的年龄均为整数；
（2）大象住在动物园东边；
（3）骆驼4岁，住在动物园西边；
（4）小王看的是动物园东边和西边之间的动物；
（5）小张去看的动物年龄最小；
（6）三种动物年龄从西到东依次增加，且平均年龄为5岁。
第二步：根据题干条件进行推理。
根据条件（2）（3）和（4），大象住东边，骆驼住西边，可知住动物园东边和西边之间的动物是猴子，则小王看的是猴子，排除C项；根据条件（6）可知，三种动物的年龄排序从小到大为骆驼、猴子和大象，结合条件（5）可知小张看的是骆驼，排除D项；根据条件（3）可知骆驼4岁，根据（1）和条件（6）可知，猴子的年龄为5岁，大象的年龄为6岁，排除B项。
故正确答案为A。
