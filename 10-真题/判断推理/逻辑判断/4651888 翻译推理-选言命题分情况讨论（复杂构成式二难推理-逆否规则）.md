# 翻译推理-选言命题分情况讨论（复杂构成式二难推理-逆否规则）

考点：[[20-考点/判断推理/逻辑判断/翻译推理-选言命题分情况讨论（复杂构成式二难推理-逆否规则）|逻辑判断 / 翻译推理-选言命题分情况讨论（复杂构成式二难推理/逆否规则）]]


**问法模型**：'由此可推知'的翻译推理题→将三个条件符号化，从唯一的确定信息（选言命题）入手分情况讨论，各分支沿假言推理链推至末端后取'或'。

## 推理链
1. 第1步：翻译条件①'如果宅基地没有管理良好，那么村民活动中心不会建成'为¬良好→¬建成，其逆否命题为'村民活动中心建成→宅基地管理良好'。
2. 第2步：翻译条件②'除非乡村道路铺设完成，否则生态旅游产业无法发展'，'除非A否则B'＝¬A→B，即¬铺设→¬发展（生态旅游无法发展）。
3. 第3步：翻译条件③'村民活动中心建成或者乡村道路没有铺设完成'为'建成∨¬铺设'，这是题干中唯一的确定信息，作为推理入口。
4. 第4步：情况一：若'村民活动中心建成'为真，由条件①逆否（否后推否前）得'宅基地管理良好'为真。
5. 第5步：情况二：若'乡村道路没有铺设完成'为真，由条件②肯前推得'生态旅游产业无法发展'为真。
6. 第6步：情况一、二必居其一，故'宅基地管理良好'与'生态旅游产业无法发展'至少一项为真，即'宅基地管理良好 或 生态旅游产业无法发展'。
7. 第7步：对照选项：D项与此结论完全一致；A、B为'且'关系、结论过强，C项肯定/否定词与推导相反，均排除。

**最快解法**：⚡ 分情况讨论法（二难推理构成式）：抓住唯一确定条件'建成 或 没铺设'，两个分支各自接龙——'建成→管理良好'、'没铺设→生态旅游无法发展'，两个末端结论取'或'直接锁定D。

## 易错点
- ⚠ '除非…否则…'翻译错误：应译为'¬铺设→¬发展'，若误译成'铺设→发展'则后续推理全错。
- ⚠ 从'乡村道路铺设完成'出发推'生态旅游产业发展'属于肯后误推，选言的正确分支入口是'乡村道路没有铺设完成'。
- ⚠ 最终结论是'或'关系而非'且'关系，误选A、B这类过强结论；另C项与D项肯定否定词相反，易看混。

## 母题抽象
> 🧩 当题干由'两个假言命题+一个选言命题'构成，且选言的两个分支恰好是两条假言推理链的入口时，从选言入手分情况讨论，每条支沿链推到末端，再对末端结论取'或'即为答案。

### 题干
上级视察小康村，了解到以下实情：如果宅基地没有管理良好，那么村民活动中心不会建成；除非乡村道路铺设完成，否则生态旅游产业无法发展；村民活动中心建成或者乡村道路没有铺设完成。
由此可推知：

### 选项
- A. 宅基地没有建设良好且生态旅游无法发展
- B. 宅基地管理良好且乡村道路铺设完成
- C. 宅基地没有管理良好或者生态旅游产业发展
- D. 宅基地管理良好或者生态旅游产业无法发展　✅

### 官方解析
第一步：翻译题干。
（1）宅基地管理良好村民活动中心建成；
（2）生态旅游产业发展乡村道路铺设完成；
（3）村民活动中心建成 或 乡村道路铺设完成。
第二步：判断选项词语间逻辑关系。
条件（3）是相对比较确定的信息，可以从条件（3）入手。
条件（3）表明“村民活动中心建成”和“乡村道路铺设完成”至少有一项为真。当“村民活动中心建成”为真时，根据条件（1）否后推出否前可知，“宅基地管理良好”为真；当“乡村道路铺设完成”为真时，根据条件（2）否后推出否前可知，“生态旅游产业发展”为真。由于“村民活动中心建成”和“乡村道路铺设完成”至少有一项为真，因此“宅基地管理良好”和“生态旅游产业发展”至少一项为真，即“宅基地管理良好” 或 “生态旅游产业发展”，即为D项。
故正确答案为D。

> [!warning] 疑点（官方解析可能有误，待人工复核）
> 官方解析文本存在转录/表述瑕疵：题干条件（3）实为'村民活动中心建成或者乡村道路没有铺设完成'，解析漏掉'没有'写成'乡村道路铺设完成'；解析中'乡村道路铺设完成为真→生态旅游产业发展为真'方向有误，正确应为'乡村道路没有铺设完成为真→生态旅游产业无法发展'，结论相应为'宅基地管理良好或生态旅游产业无法发展'。按正确读法推导恰得D，正确答案D本身无误。
