# 原因解释类-矛盾双方覆盖

考点：[[20-考点/判断推理/逻辑判断/原因解释类-矛盾双方覆盖|逻辑判断 / 原因解释类-矛盾双方覆盖]]


**问法模型**：'以下哪项如果为真，最能解释上述现象'→先锁定矛盾双方（空超市vs人气爆棚），选项必须同时解释矛盾两面才最强

## 推理链
1. 第1步：从题干提取矛盾双方——'所有店内商品……里面却是空的，包装上找不到拆封的痕迹'与'却人气爆棚'构成表面矛盾：卖空商品为何仍吸引大量顾客
2. 第2步：明确最强解释的标准——选项须既能说明商品为何是空的（为何这样经营），又能说明顾客为何蜂拥而至（人气来源），二者缺一则解释力不足
3. 第3步：逐项对照——A项'部分购买者不知道里面是空的'只解释了顾客为何购买，无法解释超市明知商品被掏空仍如此经营，且'部分购买者'撑不起'人气爆棚'
4. 第4步：B项'空包装实际上是一种艺术商品'：作为艺术品，商品被'掏空'正是其艺术形态，同时公众慕名购买/观赏艺术品，完美覆盖矛盾双方
5. 第5步：C项'有一些空包装是恶作剧的道具'与D项'超市引发日常消费文化的探讨'均未说明顾客大量涌入的直接原因，也不能完整解释经营形态，排除
6. 第6步：结论——只有B同时解释'卖空'与'人气爆棚'两面，故选B

**最快解法**：⚡ 矛盾双方覆盖法：先写出矛盾式'空商品却爆棚'，再用选项逐一检验能否同时解释'空'与'爆棚'，能覆盖两面的即答案，直接锁定B

## 易错点
- ⚠ A项看似能解释'明知是空的还买'，实际只解释单侧且'部分购买者'力度不足，不能推出'人气爆棚'
- ⚠ D项'引发探讨'是结果性描述，与顾客主动涌入的因果链断裂，易被误认为能解释人气
- ⚠ 忽略最强解释须兼顾矛盾双方，误选只解释'为何是空的'或只解释'为何有人来'的单侧选项

## 母题抽象
> 🧩 当题干出现'看似反常的现象A，却出现结果B'的解释类问法时，用'矛盾双方覆盖法'，验证选项是否同时解释A的成因和B的成因，只解释一侧的选项力度不够

**同类特征**：最能解释上述现象、卖空的超市、外观与普通商品没有分别、人气爆棚、找不到拆封的痕迹、矛盾双方须同时解释

### 题干
最近，上海长宁区开了一个新超市。从外表看，这是一间典型的中国连锁超市。满满当当的货架塞满了各种食品和日用品。然而所有店内商品，虽然外观与普通商品没有分别，里面却是空的，包装上找不到拆封的痕迹，来访者也无处得知商品是如何被“掏空”的。虽然这是一家卖空的超市，却人气爆棚。
以下哪项如果为真，最能解释上述现象：

### 选项
- A. 部分购买者不知道里面是空的
- B. 空包装实际上是一种艺术商品　✅
- C. 有一些空包装是恶作剧的道具
- D. 超市引发日常消费文化的探讨

### 官方解析
此题属于原因解释类题目，需要解释的现象为：超市内塞满了各种被“掏空”的食品和日用品，但是却人气爆棚。
A 项：解释了部分购买者不知道里面是空的，出现了购买行为，但是不能解释为什么人气爆棚，排除。
B 项：空包装实际上是一种艺术商品，既解释了超市内塞满了各种被“掏空”的食品和日用品，是艺术品超市，又解释了人气爆棚的原因，是因为大家都来购买艺术品，解释了矛盾的两个方面，当选。
C 项：有一些空包装是恶作剧的道具，无法解释题干中矛盾，排除。
D 项：超市引发日常消费文化的探讨，无法解释题干中矛盾，排除。
故正确答案为B。
