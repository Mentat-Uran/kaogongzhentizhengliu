# 分析推理-排除法（人物配对匹配）

考点：[[20-考点/判断推理/逻辑判断/分析推理-排除法（人物配对匹配）|逻辑判断 / 分析推理-排除法（人物配对匹配）]]


**问法模型**：问法为'由此可推知三对兄妹分别是'，且题干条件确定、四个选项均给出完整配对 → 优先采用排除法逐项验证

## 推理链
1. 第1步：从题干提取三个确定条件：（1）花花的哥哥是豆豆的好朋友，故花花的哥哥不是豆豆；（2）花花的哥哥在三个男生中年纪最小；（3）毛毛的年纪比妞妞的哥哥大，故妞妞的哥哥不是毛毛
2. 第2步：题干信息确定、选项配对信息充分，选用排除法而非正向推理
3. 第3步：对照条件（1）：B项中豆豆和花花是兄妹，与'花花的哥哥是豆豆的好朋友'矛盾，排除B项
4. 第4步：对照条件（3）：A项中毛毛和妞妞是兄妹，与'毛毛比妞妞的哥哥大'矛盾，排除A项
5. 第5步：结合条件（2）（3）：若花花的哥哥是毛毛，则毛毛年纪最小，但毛毛又比妞妞的哥哥大，'最年轻者不可能比他人大'，矛盾，C项中毛毛和花花是兄妹，排除C项
6. 第6步：剩余D项（蓝蓝和花花，豆豆和妞妞，毛毛和贝贝）与所有条件相符，验证成立：蓝蓝最小，毛毛＞豆豆＞蓝蓝，故选D

**最快解法**：⚡ 排除法：先由'花花的哥哥是豆豆的好朋友'排除B（豆豆-花花），再由'毛毛比妞妞的哥哥大'排除A（毛毛-妞妞），最后由'花花的哥哥年纪最小'+'毛毛比妞妞的哥哥大'联立矛盾排除C（毛毛-花花），锁定D

## 易错点
- ⚠ 漏掉条件（1）的隐含信息：'花花的哥哥是豆豆的好朋友'意味着花花的哥哥不是豆豆本人，从而错排B项
- ⚠ 排除C项需将条件（2）与条件（3）联立推理（年纪最小者不可能比任何人年长），单独看任一条件都无法排除，易在此卡壳
- ⚠ 习惯正向推配对而不先用选项排除，在确定条件+完整选项配对的题型中浪费时间

## 母题抽象
> 🧩 当题干出现'确定条件+选项给出完整人物配对'的特征时，优先用排除法：先排与单一直接条件矛盾的选项，再对剩余选项联立条件（尤其是涉及年龄/排序的隐性矛盾）逐一排查

**同类特征**：人物两两配对（兄妹匹配）、题干条件均为确定信息、选项信息充分（四个完整配对）、涉及年龄大小比较、含隐含关系（好朋友≠本人）、问法'由此可推知'

### 题干
有蓝蓝、豆豆、毛毛三个男生，他们各自有一个妹妹。已知：三个妹妹分别是花花、贝贝、妞妞；花花的哥哥是豆豆的好朋友，并且在三个男生中年纪最小；毛毛的年纪比妞妞的哥哥大。
由此可推知，三对兄妹分别是（    ）。

### 选项
- A. 蓝蓝和花花，豆豆和贝贝，毛毛和妞妞
- B. 蓝蓝和妞妞，豆豆和花花，毛毛和贝贝
- C. 蓝蓝和贝贝，豆豆和妞妞，毛毛和花花
- D. 蓝蓝和花花，豆豆和妞妞，毛毛和贝贝　✅

### 官方解析
第一步：分析题干条件。
（1）花花的哥哥是豆豆的好朋友；
（2）花花的哥哥在三个男生中年纪最小；
（3）毛毛的年纪比妞妞的哥哥大。
第二步：根据题干条件进行推理。
题干信息确定，选项信息充分，优先考虑排除法。
根据条件（1）可知花花的哥哥不是豆豆，排除B项；
根据条件（3）可知妞妞的哥哥不是毛毛，排除A项；
结合条件（2）、（3）可知花花的哥哥不是毛毛，排除C项。
故正确答案为D。
