# 直言命题-下反对关系（有人是-有人不是）与真假话推理

考点：[[20-考点/判断推理/逻辑判断/直言命题-下反对关系（有人是-有人不是）与真假话推理|逻辑判断 / 直言命题-下反对关系（有人是/有人不是）与真假话推理]]


**问法模型**：三句直言判断只有一真 → 先找下反对关系锁定真话范围，再以假话的矛盾命题求出结论

## 推理链
1. 第1步：整理题干三个判断：①'有人是外地的'（I命题：有些是）、②'学历最高的不是外地人'、③'有人不是外地的'（O命题：有些不是）
2. 第2步：①'有人是'与③'有人不是'构成下反对关系，二者必有一真、可同真，绝不可能同假
3. 第3步：题干限定'三个判断中只有一个是真的'，则这唯一真话必落在①③之中，故②必为假
4. 第4步：②为假即其否定成立：学历最高的'是'外地人
5. 第5步：学历最高者既是外地人，则①'有人是外地的'为真；由'只有一真'可知③'有人不是外地的'为假
6. 第6步：③为假，其矛盾命题为真，即'所有人（30名）都是外地人'
7. 第7步：对照选项，30名职工都是外地人为B；回验：此时①真、②假、③假，恰符合只有一真

**最快解法**：⚡ 下反对关系法：①'有人是'与③'有人不是'必有一真 → 唯一真话在①③中 → ②为假 → 学历最高者是外地人 → ①真③假 → 取③的矛盾'所有人都外地'直接锁定B

## 易错点
- ⚠ 把①③误当矛盾关系（一真一假），实际是下反对关系（必有一真、可同真），方向判断错则全盘错
- ⚠ 推出②为假后即选答案，漏掉继续回推：由②假确定①真、进而锁定③为假
- ⚠ 忽略最后一步'假话的矛盾为真'，得不到'30人都是外地人'这一数量结论

## 母题抽象
> 🧩 当题干出现'有人是P'与'有人不是P'两句且限定'只有一真'时，用下反对关系（必有一真）断定真话必在其中、其余句为假，再取假句的矛盾命题得出结论

**同类特征**：三句判断只有一真、有人是外地的、有人不是外地的、下反对关系必有一真、假话取矛盾、求外地人数量

### 题干
某单位今年新招收了30名职工。
①新招收的职工里有人是外地的；
②新招收的职工里，学历最高的不是外地人；
③新招收的职工里有人不是外地的。
如果上述三个判断中只有一个是真的，则下列哪项正确地表示了该单位新招收的职工中外地人的数量：

### 选项
- A. 只有1个人是外地人
- B. 30名职工都是外地人　✅
- C. 30名职工都不是外地人
- D. 只有1个人不是外地人

### 官方解析
首先整理题干：①有人是外地的；②学历最高的不是外地人；③有人不是外地的。
分析可知①和③为反对关系，必有一真，条件说只有一真，则其余的（即②）为假，也就是说学历最高的是外地人，进而可知“有人是外地的”为真，即①为真，因为条件说只有一真，因此③为假，它的矛盾为真，即：所有人都是外地人。
故正确答案为B。
