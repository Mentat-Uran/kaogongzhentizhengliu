# 翻译推理-逆否规则（选言命题的否后与肯后）

考点：[[20-考点/判断推理/逻辑判断/翻译推理-逆否规则（选言命题的否后与肯后）|逻辑判断 / 翻译推理-逆否规则（选言命题的否后与肯后）]]


**问法模型**：多个结论'一定为真'的复合判断题 → 先将题干翻译为'前提→（A或B）'，再逐项判断是'否后''肯后'还是对'或'关系下结论

## 推理链
1. 第1步：提取题干前提：'市场里的商家'可推出'使用电子付款系统 或 使用自动贩卖机'，翻译为：在市场里 →（电子付款 或 自动贩卖机）
2. 第2步：所用规则：①箭头后的'或'关系只能保证两支至少一个为真，不能断定某一支必真；②德摩根律：对'或'整体否定等价于'两个都否定'，即¬（A或B）=¬A且¬B；③逆否规则'否后必否前'成立，'肯后'得不到确定结论
3. 第3步：验证Ⅰ：'一些商户使用了自动贩卖机'试图从'或'关系中确定一支为真，违反规则①，无法推出
4. 第4步：验证Ⅱ：'既没有使用自动贩卖机，也没有使用电子付款系统'即¬自动贩卖机且¬电子付款，由德摩根律等价于否定箭头后的'或'关系，属于'否后'，根据否后必否前推出'不在该市场里'，成立
5. 第5步：验证Ⅲ：'既使用了自动贩卖机，也使用了电子付款系统'是对箭头后'或'关系的肯定，属于'肯后'，肯后得不到确定性结论，无法反推'该商店一定在该市场里'
6. 第6步：与选项对照：仅Ⅱ可推出，故选B

**最快解法**：⚡ 口诀法：'否后必否前，肯后无必然，或关系断不了某一支'——先判断三项分别是对'或'关系的断支（Ⅰ）、整体否后（Ⅱ）、整体肯后（Ⅲ），直接锁定只有Ⅱ成立，秒选B

## 易错点
- ⚠ 误以为'或'关系意味着两支都可能出现，从而错认Ⅰ'一些商户使用了自动贩卖机'为真，实际上可能全部商户都只用电子付款系统
- ⚠ 看不出Ⅱ中'既不…也不…'就是对'或'关系的整体否定（德摩根律），漏判Ⅱ为可推出项
- ⚠ 误认为'两个都使用了'满足题干条件就能反推商店在市场里，忽略肯后推不出必然结论

## 母题抽象
> 🧩 当题干出现'前提→（A或B）'的选言式翻译时，对A、B整体否定（既不A也不B）可由否后必否前推出'否定前提'，对A、B肯定（肯后）推不出前提，且'或'关系本身不能确定任何一支为真

**同类特征**：'一定为真'的复项判断问法、前提翻译为'→（A或B）'、结论Ⅰ从或关系中定一支、结论Ⅱ构成否后、结论Ⅲ构成肯后、逆否规则与德摩根律综合考查

### 题干
某文化用品市场正在推进市场的信息化和电子化，市场主管部门建议市场里的商家可以使用电子付款系统或者使用自动贩卖机。
如果市场里的每家商户都落实了这一建议，那么以下哪项一定为真？
Ⅰ.市场里的一些商户使用了自动贩卖机。
Ⅱ.如果一家商店既没有使用自动贩卖机，也没有使用电子付款系统，那么这家商店一定不在该市场里。
Ⅲ.如果一家文具店既使用了自动贩卖机，也使用了电子付款系统，这家商店一定在该市场里。

### 选项
- A. 只有Ⅰ
- B. 只有Ⅱ　✅
- C. 只有Ⅰ和Ⅱ
- D. 只有Ⅱ和Ⅲ

### 官方解析
第一步：翻译题干。
市场里的商家使用电子付款系统 或 使用自动贩卖机。
第二步：逐一分析结论。
Ⅰ.题干中箭头后方是“或”关系，则无法确定市场里的商家使用的是电子付款系统还是自动贩卖机，因此无法推出市场里的一些商户使用了自动贩卖机，排除A、C两项；
Ⅱ.翻译为：商店没有使用自动贩卖机且没有使用电子付款系统商店一定不在该市场里，是对题干翻译的否后，根据否后必否前，可以推出该商店一定不在该市场里，可以推出；
Ⅲ.翻译为：一家文具店使用了自动贩卖机且使用了电子付款系统这家商店在该市场里，是对题干翻译的肯后，肯后得不到确定性结论，无法推出这家商店一定在该市场里，排除D项。
故正确答案为B。
