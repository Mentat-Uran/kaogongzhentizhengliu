# 分析推理-最大信息法（多对象多属性匹配）

考点：[[20-考点/判断推理/逻辑判断/分析推理-最大信息法（多对象多属性匹配）|逻辑判断 / 分析推理-最大信息法（多对象多属性匹配）]]


**问法模型**：给出人物、地点、职业的多个匹配条件求具体对应关系 → 从被提及次数最多的元素（最大信息）入手，逐步排除锁定，最后对照选项即可

## 推理链
1. 第1步：统计题干提及次数，'老二'出现3次、'浙江'出现3次，为最大信息，从'老二'与'浙江'的组合入手
2. 第2步：由'老二不在浙江'与'在浙江工作的是律师'串联 → 老二不是律师；再结合'老二不是医生' → 老二只能是公务员
3. 第3步：由'在上海工作的不是公务员' → 公务员老二不在上海；又老二不在浙江 → 老二只能在江西
4. 第4步：由'老大不在上海'且江西已被老二占据 → 老大在浙江；剩下的老三在上海
5. 第5步：对照选项，仅B项'浙江、江西和上海'与三兄弟地点完全吻合，A/C中老二在上海与'上海不是公务员'矛盾，D中老二在浙江与'老二不在浙江'矛盾

**最快解法**：⚡ 最大信息法+排除法：先推定老二为公务员（不在浙江→非律师，非医生→公务员），锁定老二在江西；再由'老大不在上海'锁定老大在浙江、老三在上海，直接选B

## 易错点
- ⚠ 忽略地点与职业的绑定条件'在浙江工作的是律师'，推不出老二是公务员这一关键链条
- ⚠ 推出老二在江西后以为还需补全三人职业才可作答，浪费时间——问法只问地点，推出地点即可对照选项
- ⚠ 不验证选项直接凭直觉，漏用'老大不在上海'排除A、C等干扰项

## 母题抽象
> 🧩 当题干出现'多对象+多地/多职业'的匹配条件且某对象或某地点被反复提及时，用最大信息法从它入手串联条件推出唯一归属，再用排除法对照选项，无需推全所有属性对应

**同类特征**：三兄弟三地三职业匹配、'老二''浙江'为最大信息、负向条件多（不在/不是）、地点与职业交叉限定（上海非公务员、浙江是律师）、问法只问地点

### 题干
老大、老二、老三三兄弟在上海、浙江和江西工作，他们的职业是律师、医生和公务员。已知：老大不在上海工作，老二不在浙江工作；在上海工作的不是公务员；在浙江工作的是律师；老二不是医生。那么老大、老二、老三分别在哪里工作？

### 选项
- A. 浙江、上海和江西
- B. 浙江、江西和上海　✅
- C. 江西、上海和浙江
- D. 江西、浙江和上海

### 官方解析
分析题干，从最大信息入手。
“老二”和“浙江”被提到的次数最多，由它们入手展开推理。
已知老二不在浙江工作，在浙江工作的是律师，可知老二不是律师；又因为老二不是医生，所以老二只能是公务员；根据在上海工作的不是公务员，可知老二不在上海；又因为老二不在浙江工作，所以老二只能在江西。只有B项符合。
故正确答案为B。
