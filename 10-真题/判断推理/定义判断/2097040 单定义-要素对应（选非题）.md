# 单定义-要素对应（选非题）

考点：[[20-考点/判断推理/定义判断/单定义-要素对应（选非题）|定义判断 / 单定义-要素对应（选非题）]]


**问法模型**：题干给单一定义，问'不属于'该定义的选项 → 选非题模型：提取定义全部要点，逐项核验，找缺任一要点者

## 推理链
1. 第1步：从题干提取定义要点：'不同的社会群体''不同的地区''不同的时代'三个来源维度之一 + '对同一事物的不同称呼'这一核心限定
2. 第2步：明确本题为选非题，需找出'不符合定义'的选项；解题方法是三维度+同一事物逐项对照
3. 第3步：A项'老一辈的人把火柴称作洋火'——老一辈与今人对照（时代/群体差异），洋火与火柴同指一物，符合定义，排除
4. 第4步：C项'明代人们把蛤蟆称为癞施或田鸡'——明代与今对照（时代差异），癞施/田鸡与蛤蟆同指一物，符合定义，排除
5. 第5步：D项'四川人说的红苕就是河南人说的红薯'——四川与河南对照（地区差异），红苕与红薯同指一物，符合定义，排除
6. 第6步：B项'售货员称女顾客为美女'——同一时代、同一地区的礼貌称呼语，既无群体/地区/时代对照，也非'对同一事物的不同称呼'，不符合定义，当选

**最快解法**：⚡ 关键词排除法：紧扣核心限定'对同一事物的不同称呼'，A（洋火=火柴）、C（癞施/田鸡=蛤蟆）、D（红苕=红薯）均为同一物的异称且分别体现时代/时代/地区差异，快速排除后锁定B——'美女'仅是对人的称呼，不构成异称词

## 易错点
- ⚠ 被B项'不同群体（售货员）有特殊说法'的表面相似性迷惑，忽略'对同一事物的不同称呼'这一核心限定——美女是对人的礼貌称谓，不是同一物的另一名称
- ⚠ 选非题惯性思维反转，误选符合定义的A/C/D
- ⚠ C项'癞施或田鸡'易被误认为指两种事物（田鸡今多指青蛙），但题干已明确二者皆为蛤蟆的称呼，应依据题干而非外部常识判断

## 母题抽象
> 🧩 当单定义题干出现'不同X（群体/地区/时代）对同一事物不同称呼'类多要素界定且问'不属于'时，先拆出'差异维度'与'同一事物'两个核心要件，逐项找缺要件者即为答案

**同类特征**：异称词、不同社会群体、不同地区、不同时代、对同一事物的不同称呼、选非题

### 题干
异称词是指不同的社会群体、不同的地区或不同的时代对同一事物的不同称呼。
根据上述定义，下列不属于异称词的是：

### 选项
- A. 老一辈的人仍习惯把火柴称作“洋火”
- B. 现在售货员很多时候会称女顾客为“美女”　✅
- C. 明代时人们一般把蛤蟆称为癞施或田鸡
- D. 四川人说的红苕其实就是河南人说的红薯

### 官方解析
第一步：找出定义关键词。
“不同社会群体”、“不同地区”、“不同时代”、“对同一事物的不同称呼”。
第二步：逐一分析选项。
A项：老一辈人把火柴称为“洋火”，体现了不同的社会群体对火柴的不同称呼，符合定义，排除； 
B项：现在售货员称女顾客为“美女”，并不是不同社会群体、不同地区、不同时代对同一事物的不同称呼，不符合定义，当选；
C项：明代人们把蛤蟆称为“癞施或田鸡”，体现了不同时代对同一事物的不同称呼，符合定义，排除；
D项：四川人说的红苕就是河南人说的红薯，体现了不同地区对同一事物的不同称呼，符合定义，排除。
本题为选非题，故正确答案为B。
