# 单定义-要件对照（选非题，验证主体身份'被害人'）

考点：[[20-考点/判断推理/定义判断/单定义-要件对照（选非题，验证主体身份'被害人'）|定义判断 / 单定义-要件对照（选非题，验证主体身份'被害人'）]]


**问法模型**：题干给出'被害人盲点症'定义，问'不属于'（选非问法）→ 提取定义核心要件，逐项对照，三项要件齐备者排除，缺要件者当选

## 推理链
1. 第1步：拆解定义三要件——①主体为'被害人'且'出于某种迫切的需要和急切的欲望'；②'注意力狭窄、判断力减弱甚至轻度丧失理智'；③'对自己所处的危险或面临的风险视而不见'
2. 第2步：题目为选非题，需找出不满足任一要件的选项；先验证最易被忽略的主体要件——是否存在使其受损的加害来源（被骗/被害）
3. 第3步：A项'为强身健体'是迫切需要，'高价购买大量伪劣保健品'存在伪劣商品这一加害来源且对风险视而不见，三要件齐备，排除
4. 第4步：B项'争抢座位不慎滑倒'是自身意外受伤，无任何加害方使其'被害'，主体不是'被害人'，也不存在'对危险或风险视而不见'的对象，不符合定义
5. 第5步：C项'为谋高额回报'是急切欲望，'网络刷单导致经济受损'存在刷单骗局这一加害来源，三要件齐备，排除
6. 第6步：D项'幻想一夜暴富'是急切欲望，'给了骗子可乘之机'存在骗子这一加害来源且对风险视而不见，三要件齐备，排除
7. 第7步：四项中仅B项缺失'被害人（有施害方使其受损）'这一主体要件，故不属于定义的是B

**最快解法**：⚡ 找加害方秒杀法：定义主体必须是'被害人'——A有'伪劣保健品'、C有'刷单骗局'、D有'骗子'三种加害来源，而B是自己'不慎滑倒'无人加害，直接锁定B

## 易错点
- ⚠ 忽视隐含的'被害人'主体要件，只对照'注意力狭窄、判断力减弱'等表象特征而误判
- ⚠ 见B项'争抢座位'似有'急切欲望'（想抢座），误以为符合'迫切需要和急切欲望'；但滑倒属自身意外，既无施害方也无被无视的外部风险
- ⚠ 选非题看反问法，把'不属于'当'属于'去找最典型的受骗项而错选C或D

## 母题抽象
> 🧩 当单定义主体含'被害人/受骗者/受损者'类身份要件且问'不属于'时，先验证主体身份——是否有使其受损的加害方或被无视的风险来源，再对照'迫切欲望+判断力减弱+无视风险'要件，缺主体身份者秒选

**同类特征**：被害人、迫切的需要和急切的欲望、注意力狭窄、判断力减弱甚至轻度丧失理智、对危险或风险视而不见、选非问法'不属于'

### 题干
被害人盲点症是指被害人出于某种迫切的需要和急切的欲望，以致注意力狭窄、判断力减弱甚至轻度丧失理智，对自己所处的危险或面临的风险视而不见的一种状态。
根据上述定义，下列不属于被害人盲点症的是：

### 选项
- A. 王某为强身健体高价购买大量伪劣保健品
- B. 林某在公交车上因争抢座位不慎滑倒受伤　✅
- C. 为谋高额回报黄某兼职网络刷单导致经济受损
- D. 幻想通过理财一夜暴富的刘某给了骗子可乘之机

### 官方解析
第一步：找出定义关键词。
“被害人出于某种迫切的需要和急切的欲望”、“注意力狭窄、判断力减弱甚至轻度丧失理智”、“对自己所处的危险或面临的风险视而不见”。
第二步：逐一分析选项。
A项：王某为强身健体，符合“被害人出于某种迫切的需要和急切的欲望”，高价购买大量伪劣保健品，符合“注意力狭窄、判断力减弱甚至轻度丧失理智”、“对自己所处的危险或面临的风险视而不见”，符合定义，排除； 
B项：林某不慎滑倒是林某自己不小心所致，没有人要害他，不符合“被害人”，不符合定义，当选；
C项：黄某为谋高额回报，符合“被害人出于某种迫切的需要和急切的欲望”，黄某网络刷单导致经济受损，符合“注意力狭窄、判断力减弱甚至轻度丧失理智”、“对自己所处的危险或面临的风险视而不见”，符合定义，排除；
D项：刘某幻想通过理财一夜暴富，符合“被害人出于某种迫切的需要和急切的欲望”，刘某给了骗子可乘之机，符合“注意力狭窄、判断力减弱甚至轻度丧失理智”、“对自己所处的危险或面临的风险视而不见”，符合定义，排除；
本题为选非题，故正确答案为B。
