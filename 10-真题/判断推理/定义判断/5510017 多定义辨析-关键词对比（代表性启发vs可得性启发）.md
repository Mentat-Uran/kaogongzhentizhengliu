# 多定义辨析-关键词对比（代表性启发vs可得性启发）

考点：[[20-考点/判断推理/定义判断/多定义辨析-关键词对比（代表性启发vs可得性启发）|定义判断 / 多定义辨析-关键词对比（代表性启发vs可得性启发）]]


**问法模型**：题干并列给出两个相近定义并问'属于可得性启发的是'→先分别提取两个定义的核心关键词，再用关键词逐项比对排除

## 推理链
1. 第1步：拆解定义一'代表性启发'，核心是'借鉴要判断的事件本身或同类事件以往的经验，即以往出现的结果'——依据是'以往结果'
2. 第2步：拆解定义二'可得性启发'，核心是'依赖最先想到的经验和信息……以此作为判断的依据'——依据是'最先想到的信息'，且认定容易想起的事件更常出现
3. 第3步：A项'高估连续事件发生的概率'是依据以往连续发生的结果预测未来，属'同类事件以往出现的结果'，指向代表性启发，排除
4. 第4步：B项由'高质量产品一般价格不菲'推出'贵=质量好'，依据是以往同类事件的经验结果，属代表性启发，排除
5. 第5步：C项'根据服装判断社会地位'同样基于以往同类经验（高档服装→地位高），属代表性启发，排除
6. 第6步：D项'因为首先想到的是关于飞机失事的报道，而通常想不起火车意外事故的报道'，'首先想到'直接命中'依赖最先想到的经验和信息'，且认为易想起的飞机失事'更常出现'而高估其危险，完全符合可得性启发，当选

**最快解法**：⚡ 关键词法+排除法：抓'最先想到'与'以往出现的结果'两个关键词二分选项，A/B/C均含'以往经验/同类结果'特征（代表性启发），唯D含'首先想到'（可得性启发），秒选D

## 易错点
- ⚠ 只看'启发法'共同外壳就选，未区分两个定义的判断依据来源不同
- ⚠ 误把A/B/C中'以往经验'当'最先想到的信息'，混淆代表性启发与可得性启发
- ⚠ 忽略D项中'通常想不起火车意外事故'这一补充——正是'容易回想起的事件被认定更常出现'的体现，漏看会误以为D证据不足

## 母题抽象
> 🧩 当题干并列给出两个相近定义时，先用各定义的核心关键词（判断依据的来源）建立二分标准，再逐项把选项归入某一关键词，排除法锁定答案

**同类特征**：两个并列相近定义、'以往出现的结果'vs'最先想到的经验和信息'、认定容易回想起的事件更常出现、以'首先想到'为标志词、心理学概念定义判断、选是型问法（属于…的是）

### 题干
代表性启发，是指在使用启发法时，首先会考虑借鉴要判断的事件本身或同类事件以往的经验，即以往出现的结果；可得性启发，是指在使用启发法进行判断时，人们往往会依赖最先想到的经验和信息，并认定这些容易知觉到或回想起的事件更常出现，以此作为判断的依据。
根据上述定义，下列属于可得性启发的是：

### 选项
- A. 人们偏向于高估连续事件发生的概率，这往往会导致对某一计划的成功过分乐观
- B. 我们知道高质量产品一般价格不菲，因此，如果某个产品很贵，我们会认为它的质量很好
- C. 很多人会根据服装来判断他人社会地位的高低，看到身着高档服装的人，就认为他们更成功、社会地位更高
- D. 人们在判断交通工具的安全性时，都认为乘坐飞机更危险，因为首先想到的是关于飞机失事的报道，而通常想不起火车意外事故的报道　✅

### 官方解析
第一步：找出定义关键词。
代表性启发：“首先借鉴要判断的事件本身或同类事件以往的出现的结果”；
可得性启发：“把最先想到的经验和信息作为判断的依据”。
第二步：逐一分析选项。
A项：高估连续事件发生的概率，即以往连续发生的预测还会发生，借鉴的是同类事件以往出现的结果，不符合“把最先想到的经验和信息作为判断的依据”，不符合“可得性启发”定义，符合“代表性启发”定义，排除；
B项：高质量产品一般贵，因此，如果某个产品很贵，我们会认为它的质量很好，借鉴的是同类事件以往出现的结果，不符合“把最先想到的经验和信息作为判断的依据”，不符合“可得性启发”定义，符合“代表性启发”定义，排除；
C项：会根据服装来判断他人社会地位的高低，看到身着高档服装的人，就认为他们更成功、社会地位更高，借鉴的是同类事件以往出现的结果，不符合“把最先想到的经验和信息作为判断的依据”，不符合“可得性启发”定义，符合“代表性启发”定义，排除；
D项：认为乘坐飞机更危险，因为首先想到的是关于飞机失事的报道，“首先想到”说明是根据最先想到的信息去判断的，符合“把最先想到的经验和信息作为判断的依据”，符合“可得性启发”定义，当选。
故正确答案为D。
