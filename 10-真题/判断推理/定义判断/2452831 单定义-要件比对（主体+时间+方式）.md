# 单定义-要件比对（主体+时间+方式）

考点：[[20-考点/判断推理/定义判断/单定义-要件比对（主体+时间+方式）|定义判断 / 单定义-要件比对（主体+时间+方式）]]


**问法模型**：'根据定义，以下属于应激性的是'的正向选是题 → 提取定义核心要件后逐项比对排除

## 推理链
1. 第1步：提取定义要件——主体是'生物'，存在'外来刺激(如温度、声音)'，且是'短时间内'做出的'反应'
2. 第2步：确定解题方法：以最易判定的'主体是否为生物'作第一重排除，再用'短时间+反应'作第二重验证
3. 第3步：A项篮球、C项鲜牛奶、D项纸张均不是生物，直接不符合主体要件
4. 第4步：B项含羞草是生物，'被碰触'是外来刺激，'叶子收缩'是短时间内的反应，四要件全部满足
5. 第5步：结论——只有B项同时满足全部要件，故选B

**最快解法**：⚡ 主体排除法——定义限定主体为'生物'，A篮球、C牛奶、D纸均非生物直接排除，仅B含羞草为生物且符合'碰触→叶子收缩'的短时反应，锁定B

## 易错点
- ⚠ 只看'刺激—反应'表象而漏掉主体要件：篮球弹起也有'受刺激反弹'的样子，但篮球不是生物
- ⚠ C项双重不符易只识其一：牛奶发酸既非生物反应，也需'24小时'不满足'短时间内'，只抓一个要件易犹豫
- ⚠ D项明火易被误当'外来刺激'：火确实是刺激，但纸张不是生物，主体不符即排除

## 母题抽象
> 🧩 当定义明确给出主体限定（如'生物''行政机关''消费者'）时，先拿主体要件扫一遍选项做排除，再用其余要件（时间、方式、目的）二次验证，'属于型'选是题常有多项仅缺主体要件

**同类特征**：定义给出主体'生物'、括号内附示例'如温度、声音'、限定'短时间内'、正向选是型问法、选项均为日常现象描述

### 题干
应激性是指生物对外来刺激(如温度、声音)在短时间内所做出的反应。
根据上述定义，以下属于应激性的是：

### 选项
- A. 篮球触地后高高弹起
- B. 含羞草被碰触后叶子收缩　✅
- C. 鲜牛奶常温放置24小时后发酸
- D. 纸张遇到明火燃烧

### 官方解析
第一步：找出定义关键词。
“生物对外来刺激(如温度、声音)在短时间内所做出的反应”。
第二步：逐一分析选项。
A项：篮球触碰地面之后会高高弹起，篮球不是生物，不符合“生物对外来刺激(如温度、声音)在短时间内所做出的反应”，不符合定义，排除； 
B项：含羞草被碰触后叶子收缩，符合“生物对外来刺激(如温度、声音)在短时间内所做出的反应”，符合定义，当选；
C项：鲜牛奶放置24小时后发酸，鲜牛奶不是生物，不符合“生物对外来刺激(如温度、声音)在短时间内所做出的反应”，不符合定义，排除；
D项：纸遇到火会燃烧，纸不是生物，不符合“生物对外来刺激(如温度、声音)在短时间内所做出的反应”，不符合定义，排除。
故正确答案为B。
