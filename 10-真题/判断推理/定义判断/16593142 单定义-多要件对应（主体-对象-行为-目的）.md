# 单定义-多要件对应（主体-对象-行为-目的）

考点：[[20-考点/判断推理/定义判断/单定义-多要件对应（主体-对象-行为-目的）|定义判断 / 单定义-多要件对应（主体/对象/行为/目的）]]


**问法模型**：题干给出'领导负面反馈'定义，问'属于'的是哪项 → 拆解定义要件，逐项核对要件齐全性（要件法）

## 推理链
1. 第1步：从题干提取定义要件——主体'领导'、对象'员工'、情境'当前行为或绩效未达到目标或标准'、行为'给予指示、否定或批评'、目的'激励员工更加努力工作或改变行为方式以减小差距'
2. 第2步：采用要件逐一对照法，重点核验两处易漏要件：一是目的是'激励'而非'淘汰/处分'，二是批评须由领导直接给予员工本人
3. 第3步：A项王部长'对总经理说'员工能力差并'建议合同到期后不再续聘'——对象是总经理而非员工本人，且目的是淘汰而非激励减小差距，缺目的要件，排除
4. 第4步：B项小徐'炒菜口味问题被顾客多次投诉'即绩效未达标，厨师长（领导）'严肃批评'并'帮他寻找原因'——主体、情境、行为、目的四要件全部满足
5. 第5步：C项小冯'为激励自己进步''向同事们征求批评意见'——是员工主动索取而非领导给予，主体方向相反，排除
6. 第6步：D项侯主任'把名单递交给人事处'，'人事处向员工通报处理结果'——领导未直接对员工给予批评指示，仅走程序通报结果，缺行为要件，排除
7. 第7步：对照结论——仅B项要件齐全，符合定义

**最快解法**：⚡ 要件排除法——抓'目的是激励减小差距'与'领导直接给予员工本人'两把尺子：A项目的是不续聘（淘汰），C项是员工主动征求意见（方向反了），D项是转交名单+他人通报（非领导直接批评），三刀排除，锁定B

## 易错点
- ⚠ A项见'领导否定员工能力'便误判为负面反馈，忽略其目的是'不再续聘'而非'激励员工减小差距'（偷换目的要件）
- ⚠ D项见'年度考核不合格''通报'便误判符合，忽略批评须由领导直接给予员工，'递交名单、人事处通报'是程序性处分流程而非反馈行为
- ⚠ C项见'批评意见''激励进步'字眼便放松，忽略主体方向：定义要求'领导→员工'的给予，而非员工主动征求

## 母题抽象
> 🧩 当定义包含'主体+对象+条件+行为+目的'多要件时，用要件逐一核对法：每个选项至少检查主体是谁、行为是否由主体直接实施、目的是否与定义一致，缺任一要件即排除；尤其盯紧'目的要件'与'行为直接性'两处命题人最爱挖坑的位置

**同类特征**：单定义判断、多要件定义（含明确目的句'其目的是…'）、主体限定'领导'对'员工'、情境限定'行为或绩效未达标'、行为限定'指示、否定或批评'、问法为'属于定义的是'

### 题干
领导负面反馈是指领导对员工当前行为或绩效未达到目标或标准时所给予员工的指示、否定或批评，其目的是激励员工更加努力工作或改变行为方式以减小差距。
根据上述定义，下列属于领导负面反馈的是：

### 选项
- A. 人力资源部王部长对总经理说，员工小李的工作能力实在太差，建议合同到期后不再续聘
- B. 厨师小徐因为炒菜口味问题被顾客多次投诉，厨师长对他进行了严肃批评并帮他寻找原因　✅
- C. 在单位年终总结会上，小冯为激励自己进步，积极就自身工作不足向同事们征求批评意见
- D. 办公室侯主任把年度考核不合格的员工名单递交给人事处，人事处向员工通报了处理结果

### 官方解析
第一步：找出定义关键词。
“领导对员工当前行为或绩效未达到目标或标准时所给予员工的指示、否定或批评”、“激励员工更加努力工作或改变行为方式以减小差距”。
第二步：逐一分析选项。
A项：人力资源部长对总经理说员工小李的工作能力差，符合“领导对员工当前行为或绩效未达到目标或标准时所给予员工的指示、否定或批评”，但他建议合同到期后不续聘，不符合“激励员工更加努力工作或改变行为方式以减小差距”，不符合定义，排除；
B项：小徐因为炒菜口味问题被顾客多次投诉，厨师长对小徐进行了严肃批评，符合“领导对员工当前行为或绩效未达到目标或标准时所给予员工的指示、否定或批评”，帮助他寻找被投诉的原因，符合“激励员工更加努力工作或改变行为方式以减小差距”，符合定义，当选；
C项：小冯为激励自己进步，向同事们征求批评意见，不符合“领导对员工当前行为或绩效未达到目标或标准时所给予员工的指示、否定或批评”，不符合定义，排除；
D项：办公室侯主任把年度考核不合格的员工名单递交给人事处，由人事处向员工通报处理结果，不符合“领导对员工当前行为或绩效未达到目标或标准时所给予员工的指示、否定或批评”，不符合定义，排除。
故正确答案为B。
