# 物理-沸腾的条件（达到沸点且继续吸热）与热传递

考点：[[20-考点/判断推理/科学推理/物理-沸腾的条件（达到沸点且继续吸热）与热传递|科学推理 / 物理-沸腾的条件（达到沸点且继续吸热）与热传递]]


**问法模型**：判断套层加热下两种液体能否沸腾 → 用沸腾双条件（达沸点＋继续吸热）逐液体检验

## 推理链
1. 第1步：从题干提取前提——碗中汤与大锅中水沸点相同均为100℃，且'碗中的汤吸收的热量全部来自于周围的水'（即汤只能通过热传递从锅中的水获得热量）
2. 第2步：所用规则——液体沸腾必须同时满足两个条件：①温度达到沸点；②能继续吸热；而热传递发生的前提是存在温度差
3. 第3步：大锅中的水直接从火源吸热，升温至100℃后仍能继续从火吸热，满足双条件，故水会沸腾，且沸腾时温度保持100℃不变
4. 第4步：碗中汤通过水传热升温，温度最高只能达到与周围水相同的100℃，即汤可达到沸点
5. 第5步：当汤达100℃时与锅中的水温度相同，无温度差，热传递停止，汤无法继续吸热
6. 第6步：汤满足条件①但不满足条件②，故不会沸腾；对照选项只有B'水会沸腾，汤不会沸腾'符合

**最快解法**：⚡ 沸腾双条件口诀'达沸点，还要继续吸热'：大锅水有火持续供热→能沸腾；碗内汤与锅水同温100℃、无温差断热源→卡在第二条件，直接锁定B

## 易错点
- ⚠ 只看到'汤能升到100℃（达沸点）'就误判汤会沸腾，漏掉'继续吸热'这一必要条件
- ⚠ 误以为汤泡在水中温度能超过100℃或受热更快，忽略热传递只能进行到温度平衡、且水沸腾后温度不再升高
- ⚠ 误选C'水先沸、汤后沸'，把问题当成升温快慢的时间差，而实际是汤永远缺一个沸腾条件

## 母题抽象
> 🧩 当题干出现'大容器套小容器加热、内外液体沸点相同、问能否沸腾'特征时，用'沸腾双条件'模型，验证内层液体达沸点后能否与外层保持温差继续吸热——同温即断热，永不开沸

**同类特征**：碗放在大锅内的水中、汤和水沸点相同均为100℃、汤的热量全部来自周围的水、热传递需要温度差、水沸腾时温度保持不变、问谁沸腾/沸腾先后

### 题干
如图所示，把碗放在大锅内的水中蒸食物，假设碗中的汤和水的沸点一样都是100℃，且碗中的汤吸收的热量全部来自于周围的水，则下列关于水和汤沸腾的说法正确的是          。

### 选项
- A. 水和汤同时沸腾
- B. 水会沸腾，汤不会沸腾　✅
- C. 水先沸腾，汤后沸腾
- D. 汤先沸腾，水后沸腾

### 官方解析
液体沸腾需要达到沸点且继续吸热。开始汤和水都会吸热升温，但当水达到沸点100℃时，继续吸热，沸腾起来，但温度不再升高；此时碗中的汤也会达到沸点100℃，但由于碗中的汤与大锅中水的温度相同，不能继续吸热，因而碗中的汤不会沸腾。
故正确答案为B。
