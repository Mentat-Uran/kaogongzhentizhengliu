# 物理-凸透镜成像规律（照相机原理：物近像远像变大）

考点：[[20-考点/判断推理/科学推理/物理-凸透镜成像规律（照相机原理：物近像远像变大）|科学推理 / 物理-凸透镜成像规律（照相机原理：物近像远像变大）]]


**问法模型**：情境变化（合照→单人照）问相机操作方式 → 用凸透镜成像中物距、像距与像大小的变化规律直接判定

## 推理链
1. 第1步：照相机镜头是凸透镜，成倒立缩小的实像，底片位置固定，靠镜头前后伸缩改变像距
2. 第2步：从班级合照转为单人照，单人在底片中的像要'尽量大'，依据凸透镜成像规律'物近像远像变大'
3. 第3步：像变大需减小物距——相机离人近一些，排除C、D
4. 第4步：像变大还需增大像距——镜头应远离底片即'前伸'，排除A（镜头后缩为减小像距）
5. 第5步：对照选项，B'离人近一些+镜头前伸'同时满足物距减小、像距增大，当选

**最快解法**：⚡ 口诀法：记住'物近像远像变大'，单人照要人像变大→物距减（离人近）、像距增（镜头前伸），直接锁定B

## 易错点
- ⚠ 误以为拍单人照视野变小要离人远，选C/D，混淆'取景范围'与'物距调节方向'
- ⚠ 镜头伸缩方向记反：前伸是增大像距、后缩是减小像距，搞反会错选A
- ⚠ 忽略'底片位置固定、靠调镜头改变像距'这一相机结构前提，凭生活感觉乱调

## 母题抽象
> 🧩 当题干出现'照相机/凸透镜成像且像的大小发生变化'特征时，用口诀'物近像远像变大、物远像近像变小'，同步核对物距与像距（镜头伸缩）两个方向是否匹配

**同类特征**：单反相机拍照、合照变单人照、像的大小变化、凸透镜成实像、镜头伸缩与物距调节

### 题干
毕业季来临之际，摄影师用单反相机给某毕业班的同学们拍完合照，随后要用同一台相机给每个学生拍单人照片，那么这时他应该      。

### 选项
- A. 把相机离人近一些，同时镜头后缩
- B. 把相机离人近一些，同时镜头前伸　✅
- C. 把相机离人远一些，同时镜头后缩
- D. 把相机离人远一些，同时镜头前伸

### 官方解析
<p>本题考查光学相关知识。</p><p>从班级合照转向单人照，则拍照视野由大变小，根据常识，相机要离人近一些，排除C、D两项。同时对于镜头而言，照单人照，则使人在底片中尽量大，如图所示，应该是镜头前伸，A项排除，B项当选。</p><p><img width="328px" height="399px" src="../../../90-图片/题目图/160693b4ebef529.png" /></p><p>故本题答案为B。</p>
