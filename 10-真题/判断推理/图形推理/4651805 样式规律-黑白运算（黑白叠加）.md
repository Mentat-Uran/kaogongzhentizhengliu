# 样式规律-黑白运算（黑白叠加）

考点：[[20-考点/判断推理/图形推理/样式规律-黑白运算（黑白叠加）|图形推理 / 样式规律-黑白运算（黑白叠加）]]


**问法模型**：九宫格问号处填入图形使之呈现规律性 → 元素组成相似且含黑白填充时，横向逐行做黑白叠加运算，先归纳规则再代入验证

## 推理链
1. 第1步：九宫格每格均为正方形沿对角线分成上、下、左、右四个三角形区域，仅出现黑色与空白两种填充，元素组成相似，优先考虑样式规律
2. 第2步：有黑白两类区域→锁定'黑白运算'；九宫格优先横向逐行观察，先对比第一行图1与图2同一位置三角形
3. 第3步：由第一行归纳四条运算规则：黑+黑=白，白+黑=黑，黑+白=黑，白+白=白（即同色得白、异色得黑）
4. 第4步：用第二行图1与图2同位区域逐一代入运算，结果与第二行图3一致，验证规则成立
5. 第5步：将第三行图1与图2各同位三角形按规则叠加，得出问号处四区域应有的黑白分布
6. 第6步：与选项对照，A、C、D均有区域颜色与运算结果不符，只有B项各区域黑白分布完全吻合，故选B

**最快解法**：⚡ 规律口诀法：先从第一行读出'同色相加得白、异色相加得黑'（即异或运算），再用第二行快速校验方向无误，直接对第三行前两图逐区域叠加，对照四个选项的黑白位置锁定B

## 易错点
- ⚠ 运算方向看反：误用'同色得黑、异色得白'，必须先用第一行（或第二行）校验规则方向再套用
- ⚠ 只凭某一个三角形的颜色排除选项，忽略四个区域需逐一对应运算，易在A、C、D之间误判
- ⚠ 观察路线走错：九宫格误走整列或米字形路线，而本题规律只在横向行内，纵向不构成运算关系

## 母题抽象
> 🧩 当九宫格各格轮廓完全相同、仅黑白填充分布不同时，横向叠加前两格同位区域，按第一行归纳'黑+黑、白+白、黑+白、白+黑'四条运算法则，代入第三行求出目标图形再对照选项

**同类特征**：九宫格、每格轮廓相同仅黑白填充不同、对角线分割的三角形区域、黑色与空白区域并存、元素组成相似、问号位于第三行末格
