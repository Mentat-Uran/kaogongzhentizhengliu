# 图形推理-位置规律（平移+重合覆盖+方向翻转变速）

考点：[[20-考点/判断推理/图形推理/图形推理-位置规律（平移+重合覆盖+方向翻转变速）|图形推理 / 图形推理-位置规律（平移+重合覆盖+方向翻转变速）]]


**问法模型**：'填入问号处使之呈现一定的规律性'且元素组成基本相同 → 优先考虑位置规律：逐列归纳每个元素的移动步数、重合覆盖与方向翻转（变速）规则，再由第6列外推第7列。

## 推理链
1. 第1步：题干7列竖条元素组成基本相同，每列均含黑点、三角形、梯形三种元素，三角形和梯形的位置逐列依次往上移动，优先考虑位置规律。
2. 第2步：归纳三角形规律：正常每次上移1步；当与黑点重合时，三角形覆盖黑点，且方向由尖朝上变为尖朝下；尖朝下时移动步数由1步变为2步。
3. 第3步：归纳梯形规律：正常每次上移2步；当与黑点重合时，梯形覆盖黑点，且方向由短边在上变为短边在下；短边在下时移动步数由2步变为3步。
4. 第4步：看第6列三角形为尖朝上 → 第7列三角形应上移1步；C项三角形位置相当于上移了2步，排除C。
5. 第5步：看第6列梯形为短边在下 → 第7列梯形应上移3步；又因每一列都必须呈现三种元素，梯形上移3步后必与顶部黑点重合（覆盖黑点），方向由短边在下翻转回短边在上。
6. 第6步：逐项对照：A项顶部仍是黑点（梯形未与之重合翻转）、D项顶部梯形仍短边在下，均不符排除；B项梯形在顶部覆盖黑点且短边在上、三角形恰好上移1步，完全吻合，故选B。

**最快解法**：⚡ 位置规律口诀'逐列上移+重合覆盖翻转+翻转后变速'：只看第6列末状态——三角形尖朝上→上移1步定位置排除C；梯形短边在下→上移3步必与顶部黑点重合且翻回短边在上，排除A、D，秒选B。

## 易错点
- ⚠ 只相邻两列比对位置，漏掉'与黑点重合时覆盖黑点并翻转方向'这一复合规律
- ⚠ 忽略变速：三角形尖朝下时步数由1变2、梯形短边在下时由2变3，按恒定步数外推会推错第7列位置
- ⚠ 忽略'每一列都有三种元素'的隐含约束，想不到梯形在第7列必与顶部黑点重合（黑点被覆盖）

## 母题抽象
> 🧩 当多列图形中相同小元素逐列移动、且中途出现方向翻转时，用'移动步数＋重合覆盖翻转＋翻转后变速'三要素为每个元素建立运动规则，再以末列状态外推问号列并排除选项。

**同类特征**：元素组成基本相同、多列竖条阶梯排列、黑点+三角形+梯形三种元素、逐列依次上移、重合覆盖黑点、方向翻转且移动步数改变

### 题干
从所给的四个选项中，选择最合适的一个填入问号处，使之呈现一定的规律性：

### 选项
- A. A
- B. B　✅
- C. C
- D. D

### 官方解析
元素组成基本相同，优先考虑位置规律。整体来看，每一列都有三种元素，黑点、三角形、梯形，且三角形和梯形的位置依次往上移动。先看三角形，在依次往上移动的过程中，如果与黑点重合，三角形会把黑点覆盖，且三角形的方向会从尖朝上变成尖朝下，尖朝下时移动步数由一步变成两步，由第6列三角形尖朝上，可知三角形向上移动一步，排除C项。再看梯形，在往上移动的过程中，如果与黑点重合，梯形会把黑点覆盖，且梯形的方向会从短边在上变成短边在下，短边在下时步数由两步变成三步，由第6列梯形短边在下，可知梯形向上移动三步，又因为每一列都有三种元素，得知梯形在第7列必定与黑点重合了，所以梯形方向发生变化，由短边在下变成短边在上，排除A、D两项。
故正确答案为B。
