# 数量规律-黑白块面积占比（等分图形求比例递变）

考点：[[20-考点/判断推理/图形推理/数量规律-黑白块面积占比（等分图形求比例递变）|图形推理 / 数量规律-黑白块面积占比（等分图形求比例递变）]]


**问法模型**：题干图形均由黑白块组成且元素组成不同、属性无规律 → 将各图等分后计算黑块面积占整体的比例，找比例递变规律

## 推理链
1. 第1步：题干五幅图元素组成不同、无对称/曲直等属性规律，但均由黑块和白块组成且色块分布均匀，考虑黑白块面积
2. 第2步：对每幅图做等分计数：图1六角星形由12个小三角形组成、黑2个，占1/6；图2五边形分成5块、黑1块，占1/5；图3大三角形内含4个小三角形、黑1个，占1/4；图4三角形分成3块、黑1块，占1/3；图5矩形分成2块、黑1块，占1/2
3. 第3步：归纳规律：黑块面积占整体比例依次为1/6、1/5、1/4、1/3、1/2，分母依次减1，故？处黑块面积应占整体的1（即整个图形全为黑色）
4. 第4步：对照选项：A项黑白相间、B项仅一小块黑、C项黑白条纹相间，均非全黑；只有D项整个图形全为黑色，符合占比为1的要求，故选D

**最快解法**：⚡ 等分计数法：逐图数出'黑块面积/总面积'，得1/6→1/5→1/4→1/3→1/2的分母递减序列，问号处需占满全图，直接锁定全黑图形D

## 易错点
- ⚠ 只数黑块个数而不看每幅图的总份数（五图总份数分别为12、5、4、3、2），误以为黑块数量1、1、1、1、2无规律
- ⚠ 图1误按6等分计算（2黑=1/3），打乱1/6、1/5、1/4、1/3、1/2的递变序列
- ⚠ 看到C项黑白相间、交替排列，误入'黑白交替/间隔排列'的位置规律而错选C

## 母题抽象
> 🧩 当题干各图均由黑白色块组成、元素组成不同且属性无规律时，把每幅图等分后计算黑块占总面积的比例，验证比例是否构成1/n型递变规律，问号处按递变结果取图

**同类特征**：黑白块组成、色块分布均匀、图形被等分为三角形/块状区域、黑块占比呈1/6到1/2递变、元素组成不同、属性无规律、问号处需全黑图形
