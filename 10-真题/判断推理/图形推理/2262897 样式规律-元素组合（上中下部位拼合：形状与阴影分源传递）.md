# 样式规律-元素组合（上中下部位拼合：形状与阴影分源传递）

考点：[[20-考点/判断推理/图形推理/样式规律-元素组合（上中下部位拼合：形状与阴影分源传递）|图形推理 / 样式规律-元素组合（上中下部位拼合：形状与阴影分源传递）]]


**问法模型**：两组图类比'根据现有规律选最合理答案'→ 将图3按上、下部位拆分，逐部位确认形状来源图与阴影来源图，再对照选项排除

## 推理链
1. 第1步：两组图元素相似，每幅图均由'上部图形+中间竖线+下部图形'三段拼成，考虑样式规律中的元素组合
2. 第2步：拆解第一组——图1=斜线阴影圆形+Z形底，图2=留白盾形+U形底，图3=斜线阴影盾形+Z形底
3. 第3步：归纳规律：图3上部形状取图2（盾形）、上部阴影取图1（斜线阴影），下部整体取图1（Z形）
4. 第4步：代入第二组——？上部形状应为图2的五边形箭头、阴影应为图1的留白（无阴影），下部应为图1的黑色实心梯形
5. 第5步：逐项对照——A上部为斜线阴影且下部是白色椭圆，排除；B下部是椭圆（误取了图2的下部），排除；C上部为斜线阴影且下部梯形未填黑，排除
6. 第6步：D项上部为留白五边形箭头、下部为黑色实心梯形，与推导结果完全一致，故选D

**最快解法**：⚡ 部位拆分排除法：先只看下半部分——规律要求'下半部分与图1下半部分相同'即黑色实心梯形，四个选项中只有D的下部是黑色梯形，可直接锁定D，再用上部（形状取图2、阴影取图1的留白）验证无误

## 易错点
- ⚠ 误以为下部取自图2而看到B的黑椭圆就选B（下部应取图1的黑色梯形）
- ⚠ 只核对形状不核对阴影填充，误选下部为白色梯形的C
- ⚠ 把上部阴影来源记成图2的斜线阴影，误选A或C（阴影应取图1的留白）

## 母题抽象
> 🧩 当两组图元素相似且每幅图呈'上+中+下'拼接结构时，把第三幅图按部位拆分，逐部位确认'形状取自哪幅图、阴影取自哪幅图'，再回选项逐一排除

**同类特征**：两组图对照类比、元素组成相似、上中下三段式拼合结构、形状与阴影分属不同来源图、下半部分整体取自图1、阴影与留白交替出现

### 题干
根据所给图形的现有规律，选出一个最合理的答案：

### 选项
- A. A
- B. B
- C. C
- D. D　✅

### 官方解析
元素组成相似，考虑样式规律。观察第一组图，图3上半部分图形与图2上面图形形状相同，与图1上面图形阴影一样，下半部分与图1下半部分形状相同。第二组图运用规律，？处图形上半部分应该与图2上半部分形状相同，与图1上面图形阴影一样，下半部分与图1下半部分形状相同，只有D项符合。
故正确答案为D。
