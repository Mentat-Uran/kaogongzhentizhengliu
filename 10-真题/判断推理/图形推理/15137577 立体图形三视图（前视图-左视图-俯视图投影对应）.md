# 立体图形三视图（前视图-左视图-俯视图投影对应）

考点：[[20-考点/判断推理/图形推理/立体图形三视图（前视图-左视图-俯视图投影对应）|图形推理 / 立体图形三视图（前视图/左视图/俯视图投影对应）]]


**问法模型**：给组合立体模型标注前视、左视、俯视三个投影方向，要求选出三视图均正确的一项 → 分解基本体逐方向投影，再与选项三组小图形逐一比对排除

## 推理链
1. 第1步：分解立体模型的组成基本体——长方体底板、底板左上的小长方体块、中部楔形块（带斜面）、板面上的圆形特征、右侧圆锥，题干图中箭头标明俯视图从上方、左视图从左前、前视图从右前投影
2. 第2步：按投影规律分别想象三个视图：前视图中底板为长矩形、小长方体为小矩形、楔形块顶部轮廓出现一条斜线、圆锥呈小三角形；左视图中楔形块投影为三角形、小长方体矩形宽高比例须与实物一致；俯视图中圆形特征投影为一个纯圆、圆锥投影为圆加中心点，故俯视图应含两个圆（其中一个带圆心）
3. 第3步：逐项对照——A项前视图缺少楔形产生的那条斜线，且俯视图只有一个带圆心圆、缺一个纯圆形，排除
4. 第4步：B项左视图中小长方形比例与实物不符，且俯视图缺一个圆形及其中心点，排除
5. 第5步：C项左视图中三角形（楔形块投影）形状画错，排除
6. 第6步：D项前视图含斜线与小三角、左视图三角形与小矩形比例正确、俯视图两个圆（含圆心）齐全，三视图均正确，当选

**最快解法**：⚡ 特征元素排除法：先看俯视图应有的'两个圆'（一个纯圆+一个圆加中心点），可秒杀A（缺一个圆）；再看左视图三角形形状与小长方形比例排除B、C，锁定D

## 易错点
- ⚠ 混淆圆锥与平面圆的俯视图区别：圆锥俯视图是圆加中心点，圆形凸台/圆孔是纯圆，少画一个即错
- ⚠ 忽略前视图中楔形斜面顶部轮廓产生的斜线这一细节
- ⚠ 左视图只看轮廓不看比例，小长方形的宽高比例失真难察觉
- ⚠ 把前视图与左视图的投影方向（题干箭头）搞反导致整体错位

## 母题抽象
> 🧩 当题干给出组合立体并要求选三视图时，先分解基本体（柱、锥、楔块），按题干箭头方向逐一投影，抓'斜线、圆、圆心、三角形、比例'等特征元素与选项比对排除

**同类特征**：立体组合模型、题图标注前视图/左视图/俯视图箭头方向、含楔形块、圆锥、圆形特征、选项由三幅小视图组合、选项间差异集中在斜线、圆数量、三角形状与矩形比例

### 题干
为下方立体模型绘制前视图、左视图和俯视图，正确的一项是：

### 选项
- A. A
- B. B
- C. C
- D. D　✅

### 官方解析
本题考查三视图，该立体图形的前视图、左视图和俯视图如下图所示，逐一分析选项。

A项：对应该立体图形的前视图缺少一条斜线，俯视图缺少一个圆形，排除；
B项：对应该立体图形的左视图小长方形比例有误，俯视图缺少一个圆形及其中心点，排除；
C项：对应该立体图形的左视图三角形形状有误，排除； 
D项：对应该立体图形前视图、左视图和俯视图均正确，当选。
故正确答案为D。
