# 空间重构-四面体展开图折叠（画边法-相邻面相对位置）

考点：[[20-考点/判断推理/图形推理/空间重构-四面体展开图折叠（画边法-相邻面相对位置）|图形推理 / 空间重构-四面体展开图折叠（画边法/相邻面相对位置）]]


**问法模型**：给出带箭头特征的四面体展开图，问哪一项能折叠而成 → 用画边法：从特征点出发顺时针标边，比对选项中相邻面所接的边号

## 推理链
1. 第1步：将展开图各面从左至右标记为面a、b、c、d，各面均带箭头（蓝色点）特征，折叠后需保证相邻面上箭头的相对位置关系不变
2. 第2步：采用画边法——以面b上的蓝色点为起点，顺时针给面b的三条边依次标为边1、边2、边3，由展开图可知：边1与面d相接、边2与面c相接、边3与面a相接
3. 第3步：A项由面b和面d构成，选项中面b的边2挨着面d，而题干中边2挨着面c，相邻关系不符，排除
4. 第4步：B项由面b和面a构成，选项中面b的边1挨着面a，而题干中边3才挨着面a，相邻关系不符，排除
5. 第5步：C项由面b和面d构成，选项中面b的边3挨着面d，而题干中边1才挨着面d，相邻关系不符，排除
6. 第6步：D项中两面箭头的指向及与相邻面的边号关系均与展开图完全一致，当选

**最快解法**：⚡ 画边法：在展开图面b上从蓝色点出发顺时针给三条边标1、2、3，锁定'边1邻d、边2邻c、边3邻a'，逐项核对选项中与邻面相接的边号——A项边2错邻d、B项边1错邻a、C项边3错邻d均排除，仅D项完全吻合

## 易错点
- ⚠ 标边时针向搞反：必须从箭头/蓝点出发沿顺时针标边，逆时针标会导致边号全部错位而误判
- ⚠ 只看箭头方向、不验证邻边：四面体折叠后两面共用一条边，需同时核对箭头面对应边号与邻面是否一致
- ⚠ A、C两选项同为面b与面d的组合，需靠边1/边2/边3与邻面对应关系的细微差异区分，粗看易混淆

## 母题抽象
> 🧩 当展开图各面带箭头或特征点、问'哪项能折叠而成'时，用画边法：从特征点出发顺时针标边并记录每条边的相邻面，再逐项比对选项中邻面所接边号，全部吻合者即为答案

**同类特征**：四面体展开图折叠、面上画有箭头（蓝色点）、问哪一项能折叠而成、相邻面相对位置关系、画边法（描点顺时针标边）

### 题干
左边给出的是纸盒外表面的展开图，右边哪一项能由它折叠而成？请把它找出来。

### 选项
- A. A
- B. B
- C. C
- D. D　✅

### 官方解析
题干图形从左至右分别标上面a、b、c、d。

A项：由面b和面d构成，题干沿面b蓝色点顺时针画边，边2挨着c面，选项边2挨着d面，选项与题干不一致，排除；

B项：由面b和面a构成，题干沿面b蓝色点顺时针画边，边3挨着a面，选项边1挨着a面，选项与题干不一致，排除；

C项：由面b和面d构成，题干沿面b蓝色点顺时针画边，边1挨着d面，选项边3挨着d面，选项与题干不一致，排除；

D项：选项与展开图一致，当选。
故正确答案为D。
