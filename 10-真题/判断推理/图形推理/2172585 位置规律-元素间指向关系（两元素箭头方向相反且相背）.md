# 位置规律-元素间指向关系（两元素箭头方向相反且相背）

考点：[[20-考点/判断推理/图形推理/位置规律-元素间指向关系（两元素箭头方向相反且相背）|图形推理 / 位置规律-元素间指向关系（两元素箭头方向相反且相背）]]


**问法模型**：一条式图形系列填问号 → 元素组成相同时先看位置，位置无规律则转找元素间指向/角度关系，并延续到问号处

## 推理链
1. 第1步：题干5个图形均由'带箭头的方块（菱形）'和'弯曲箭头'两个相同元素组成，元素组成相同→优先考虑位置规律
2. 第2步：逐图核对位置（左上/右下/居中交替分布），发现位置排布无循环或移动规律，排除位置规律
3. 第3步：转而观察元素自身特征：每个图形中两个元素各带一个箭头，核对5个图形均为'方块箭头与弯曲箭头指向相反、且两箭头背向（相背）'
4. 第4步：归纳规律：问号处图形两元素的箭头也应'指向相反且相背'
5. 第5步：逐项对照：A项两箭头相反且相背，符合；B项两箭头指向相同方向，排除；C项两箭头并非相反方向，排除；D项两箭头相反但指向相对（相向），排除
6. 第6步：只有A项同时满足'方向相反+相背'两个条件，故选A

**最快解法**：⚡ 两级排除法：先排除明显不合的B（同向）、C（非反向），再在A、D之间做'相背vs相向'二级辨析，D相向、A相背，秒选A

## 易错点
- ⚠ 只验证'箭头方向相反'这一级就作答，漏掉'相背/相向'的二级辨析而误选D
- ⚠ 因元素组成相同而死磕位置移动规律，在无规律的位置关系上浪费时间
- ⚠ 弯曲箭头的指向判断不准，误把C当成'方向相反'的干扰项

## 母题抽象
> 🧩 当图形元素组成相同但位置无明显规律时，转找元素间的指向/角度关系（同向、相反、相背、相对），问号处延续该关系，并注意做两级辨析

**同类特征**：元素组成相同、位置排布无规律、两元素均带箭头、箭头方向相反、箭头相背（背向）、弯曲箭头+带箭头方块

### 题干
从四个图中选出唯一的一项，填入问号处，使其呈现出一定的规律性。

### 选项
- A. A　✅
- B. B
- C. C
- D. D

### 官方解析
图形元素组成相同，优先考虑位置规律，但位置无明显规律。观察发现，每个图形中由两个元素组成，且这两个元素的箭头均指向相反方向且指向相背，故？号处图形中的两个元素的箭头也应该指向相反方向且指向相背。A项箭头指向相反方向，B项箭头指向相同方向，C项并非相反方向，D项箭头指向相反方向但指向相对，只有A项符合。
故正确答案为A。
