# 空间重构-展开图折叠（相邻面图案指向关系）

考点：[[20-考点/判断推理/图形推理/空间重构-展开图折叠（相邻面图案指向关系）|图形推理 / 空间重构-展开图折叠（相邻面图案指向关系）]]


**问法模型**：问哪个展开表面能折叠成给定几何体 → 空间重构折纸盒模型：先从立体图提炼侧面图案的相对指向规律，再逐项检验展开图相邻面是否满足

## 推理链
1. 第1步：观察左框几何体，由四个正方形侧面和顶部锥面构成，四个正方形侧面上各有一个箭头，规律为'四个箭头首尾对应'（前一箭头的头部衔接相邻面箭头的尾部，围成一圈循环）
2. 第2步：确定检验规则——展开图折叠后相邻的箭头面必须满足'箭头头部对准相邻箭头尾部'，以此为唯一标准逐项排查
3. 第3步：A项中第二行第三个正方形面的箭头指向第三行正方形面箭头的侧面（而非尾部），不满足首尾对应，与题干不一致，排除
4. 第4步：B项中四个含箭头正方形面的箭头均首尾对应，与题干几何体一致，保留
5. 第5步：C项中第二行第二个正方形面的箭头指向该行第三个正方形面箭头的侧面，不满足首尾对应，排除
6. 第6步：D项中第二行第一个正方形面的箭头未指向第三行相邻面箭头的尾部，不满足首尾对应，排除
7. 第7步：四项对照，仅B项完全满足'箭头首尾对应'，故正确答案为B

**最快解法**：⚡ 箭头指向排除法：紧扣立体图'四箭头首尾对应'特征，逐项核查展开图中相邻箭头面的指向——凡箭头指向相邻箭头'侧面'或未对准'尾部'的（A、C、D）直接排除，唯B全首尾对应

## 易错点
- ⚠ 只看箭头有无、不核验指向是'头对尾'还是'头对侧'，易被图案布局相似的干扰项迷惑
- ⚠ 未注意展开图折叠后相邻关系的转化，把展开图中不相邻的面误当作相邻面检验
- ⚠ 忽略题干'正反面图形完全一致'的说明，纠结折叠朝向（正反面）而误判或耗时

## 母题抽象
> 🧩 当立体图形各侧面带方向性图案（如箭头）且给出展开图求折叠时，先从立体图提炼图案间相对指向规律（如首尾循环），再逐项检验展开图中相邻面的图案指向，指向不符者排除

**同类特征**：空间重构折纸盒、方体加锥顶几何体、四个侧面箭头首尾对应、展开表面正反面图形完全一致、逐项排除定答案

### 题干
下图右框内所给几何体的展开表面中，能折叠成左框内所示几何体的是：
（注：右框内所给几何体展开表面正反面图形完全一致）

### 选项
- A. A
- B. B　✅
- C. C
- D. D

### 官方解析
本题考查空间重构。根据题干左框几何体可知，几何体的四个正方形侧面中四个箭头首尾对应，根据题干逐一进行分析。
A项：选项中第二行第三个正方形面的箭头指向第三行正方形面的箭头侧面，而题干几何体的四个正方形侧面中四个箭头首尾对应，选项与题干几何体不一致，排除；
B项：选项四个含有箭头的正方形面中的箭头首尾对应，选项与题干几何体一致，当选；
C项：选项中第二行第二个正方形面的箭头指向该行第三个正方形面的箭头侧面，而题干几何体的四个正方形侧面中四个箭头首尾对应，选项与题干几何体不一致，排除；
D项：选项中第二行第一个正方形面的箭头没有指向第三行中相邻面的箭头的尾部，而题干几何体的四个正方形侧面中四个箭头首尾对应，选项与题干几何体不一致，排除。
故正确答案为B。
