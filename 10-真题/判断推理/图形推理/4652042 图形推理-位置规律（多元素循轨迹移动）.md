# 图形推理-位置规律（多元素循轨迹移动）

考点：[[20-考点/判断推理/图形推理/图形推理-位置规律（多元素循轨迹移动）|图形推理 / 图形推理-位置规律（多元素循轨迹移动）]]


**问法模型**：‘符合所给图形的变化规律的是’→元素组成相同的位置类题目，给各位置编号后逐图追踪每个元素的移动轨迹，并外推到问号处对照选项。

## 推理链
1. 第1步：三幅图及选项均由●、■、□、○、△、×六个相同元素组成，仅位置改变，优先考虑位置规律；每个图形含顶部、中间、左上、右上、左下、右下共6个位置。
2. 第2步：对比图1→图2逐元素追踪：●由顶部→中间，×由中间→左下，□由左上→顶部，○由右上→右下，△由左下→右上，■由右下→左上。
3. 第3步：对比图2→图3验证：□顶部→中间、■左上→顶部、△右上→右下、×左下→右上、●中间→左下、○右下→左上，与上一步完全一致，归纳出六条轨迹：左上元素顺时针1格、右上元素顺时针1格、右下元素顺时针2格（经左下到左上）、左下元素逆时针2格（经右下到右上）、顶部元素→中间、中间元素→左下。
4. 第4步：将规律应用于图3（顶部■、中间□、左上○、右上×、左下●、右下△）：○左上顺1→顶部，■顶部→中间，△右下顺2→左上，●左下逆2→右上，□中间→左下，×右上顺1→右下。
5. 第5步：问号处图形应为：顶部○、中间■、左上△、右上●、左下□、右下×，逐项对照，仅B项完全吻合，排除A、C、D。

**最快解法**：⚡ 双元素排除法：先盯黑块■，其轨迹为图1右下→图2左上（顺2）→图3顶部（顺1），下一步按‘顶部→中间’应落到中间，排除中间非■的A、C；再看图3中间的□，按‘中间→左下’应移到左下角，B项左下为□、D项左下为△，锁定B。

## 易错点
- ⚠ 六个元素位置相近，把‘左上/右上’与‘左下/右下’认错，会导致移动方向和格数全盘算错
- ⚠ 右下角元素是‘顺时针2格’（经左下到左上），易误算成逆时针或只移1格
- ⚠ ‘顶部→中间、中间→左下’这两条非旋转轨迹易被忽略，误把整图当成单纯的整体旋转
- ⚠ 只追踪一个元素就作答：B、D中间都是■，必须再用第二个元素（□或●）交叉验证才能区分

## 母题抽象
> 🧩 当题干出现‘元素组成相同、多个元素绕中心多点分布且逐图换位’的特征时，给各位置编号，追踪2~3个代表元素得出每条轨迹的步数与方向，验证两图规律一致后外推到问号处逐一比对选项。

**同类特征**：元素组成相同、六元素绕中心排布、位置逐图变化、外圈旋转+顶部与中间换位、问号处求下一幅图、位置类移动规律

- B. B　✅
- C. C

### 官方解析
元素组成相同，优先考虑位置规律。每幅图位于左上角的元素沿顺时针移动1格，位于左下角的元素沿逆时针移动2格，位于右上角的元素沿顺时针移动1格，位于右下角的元素沿顺时针移动2格，位于顶部的元素移动到中间，位于中间的元素移动到左下角，只有B项符合。
故正确答案为B。
