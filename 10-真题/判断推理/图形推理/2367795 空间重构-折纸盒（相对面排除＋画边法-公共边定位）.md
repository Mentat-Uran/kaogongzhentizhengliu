# 空间重构-折纸盒（相对面排除＋画边法-公共边定位）

考点：[[20-考点/判断推理/图形推理/空间重构-折纸盒（相对面排除＋画边法-公共边定位）|图形推理 / 空间重构-折纸盒（相对面排除＋画边法/公共边定位）]]


**问法模型**：问'哪一项能由展开图折叠而成'→ 采用空间重构模型：先用相对面排除，再以公共边为唯一起点顺时针画边核对相邻面图案指向

## 推理链
1. 第1步：给展开图各面标号a~f，确定相对面：面f与面b相对、面e与面c相对（由此面a与面d相对）
2. 第2步：规则一：相对面在立体图中不能同时可见；规则二：相邻面上线条指向用'以两面的公共边为唯一边、统一顺时针画边'定位
3. 第3步：A项必然存在面e和面f，因面f与面b相对，右侧面只能是面d；以面d和面e的公共边为唯一边对面d顺时针画边，选项中边4对应面f，而展开图中边4对应面b，指向不符，排除A
4. 第4步：C项由面f、面b、面d组成，而面f与面b是相对面，在立体图中不可能同时出现，排除C
5. 第5步：D项必然存在面e和面f，因面e与面c相对，顶面只能是面a；以面a和面f的公共边为唯一边对面f顺时针画边，选项中边2对应面e，而展开图中边2对应面c，指向不符，排除D
6. 第6步：B项可见三面的相邻关系及对角线/叉线指向均与展开图一致，当选B

**最快解法**：⚡ 相对面排除＋画边法：先抓f—b、e—c两组相对面秒杀C项；A、D项两面组合合法但需画边，以'公共边为唯一起点、顺时针标边'核对特征线指向（A中边4、D中边2对应面不符），排除后锁定B

## 易错点
- ⚠ 展开图为不规则阶梯形，误用'隔一个面即相对'的口诀找错相对面（需按Z字形/行走法确认f—b、e—c）
- ⚠ 画边起点选错：必须以两面的公共边为唯一边作为第1条边，再顺时针依次标边，起点错则边号全错
- ⚠ 只看'哪些面组合出现'而忽略线条指向：A、D的面组合本身合法，但对角线/叉线的指向与展开图不符，仅凭组合判断会误选

## 母题抽象
> 🧩 当展开图各面图案为相似线条（对角线、叉线）且排布不规则时，先用相对面排除明显矛盾项，再对剩余选项用'公共边唯一＋顺时针画边法'核对特征线指向

**同类特征**：左边给定纸盒外表面展开图，问哪项能折叠而成、展开图为不规则阶梯形排布、各面图案为单对角线与双对角线（叉线），图案高度相似、需辨析相对面（f—b、e—c）与相邻面公共边关系、四个选项均展示三个可见面及棱上线条走向

### 题干
左边给定的是纸盒外表面的展开图，右边哪一项能由它折叠而成？请把它找出来。

### 选项
- A. A
- B. B　✅
- C. C
- D. D

### 官方解析
将原展开图标上序号，逐一分析。

A项：该项必然存在面e和面f，由于面f和面b是相对面，故右侧面只能是面d，以面d和面e的公共边为唯一边，对面d进行顺时针画边，如下图所示，选项中边4对应的是面f，而在展开图中边4对应的是面b，故选项与题干不一致，排除；

B项：与题干一致，当选；
C项：该项由面f、面b、面d组成，面f和面b是相对面，在选项中不可能同时存在，排除；
D项：该项必然存在面e和面f，由于面e和面c是相对面，故顶面只能是面a，以面a和面f的公共边为唯一边（如下图所示），对面f进行顺时针画边，选项中边2对应的是面e，而展开图中边2对应的是面c，故选项与展开图不一致，排除。

故正确答案为B。
