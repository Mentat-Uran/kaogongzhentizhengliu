# 空间重构-折纸盒（相对面排除+无中生有面排除）

考点：[[20-考点/判断推理/图形推理/空间重构-折纸盒（相对面排除+无中生有面排除）|图形推理 / 空间重构-折纸盒（相对面排除+无中生有面排除）]]


**问法模型**：'由左边图形折叠而成的是' → 空间重构（折纸盒）题：先给展开图各面标号找相对面做排除，再对剩余选项验证相邻面图案与方向

## 推理链
1. 第1步：题干展开图为'1-4-1'型：中间一行四个面依次为空白面、'Ǝ'面、空白面、'V'形面，上方为'▷'三角图案面（面e），下方为实心黑三角面（面g）
2. 第2步：用相对面判定规则（同行相隔一个面为相对面、上下两端面为相对面）标出三组相对面：面h（'Ǝ'面）与面k（'V'形面）相对，面e与面g相对，两个空白面相对
3. 第3步：A项由面g、面h和面k构成，同时出现相对面h与k，而相对面在立体图中不能同时出现，排除
4. 第4步：C项同样由面g、面h和面k构成，相对面h与k同时出现，排除
5. 第5步：B项中出现两个面k（同图案面重复），展开图中该面仅有一个，属于'无中生有'的面，排除
6. 第6步：D项由面e、面h和面i构成，三个面分属三组相对面中各取其一，且相邻位置与图案方向均与展开图一致，当选

**最快解法**：⚡ 相对面排除法：先在展开图标号，'同行隔一面'定出'Ǝ'面h与'V'形面k相对、两端'▷'面e与黑三角面g相对；A、C均同时含h与k直接排除，B重复出现面k（无中生有）排除，锁定D，无需细致画箭头。

## 易错点
- ⚠ 忽视'相对面不能同时出现'：A、C中'E/Ш形面'与'V/W形面'实为展开图中间一行相隔一面的相对面，被表面图案差异迷惑而误判
- ⚠ 忽略'无中生有'：展开图中同一图案面只有一个，B项重复出现两个面k即为错
- ⚠ 排除后不做最终验证：对D项还应确认相邻面图案方向（'▷'尖角指向、'Ǝ'开口方向）与展开图一致再确定答案

## 母题抽象
> 🧩 当题干出现'六面体展开图+问哪个能折叠而成'时，先给各面标号，用'同行隔一面、两端必相对'找出三组相对面，凡选项同时出现一对相对面或出现展开图中不存在的面即排除，剩余选项再用相邻面图案方向验证。

**同类特征**：六面体展开图折叠、1-4-1型展开图、相对面不能同时出现、无中生有的面、面内含'Ǝ'字母与三角形图案、选项排除法优先于逐面拼合

### 官方解析
本题为空间重构题。对题干展开图标上序号，如下图所示，逐一进行分析。

A项：选项由面g、面h和面k构成，题干展开图中面h和面k为相对面，相对面不能同时出现，选项与题干展开图不一致，排除；
B项：选项出现两个面k，其中一个为无中生有的面，选项与题干展开图不一致，排除；
C项：选项由面g、面h和面k构成，题干展开图中面h和面k为相对面，相对面不能同时出现，选项与题干展开图不一致，排除；
D项：选项由面e、面h和面i构成，选项与题干展开图一致，当选。
故正确答案为D。
