# 数量规律-数线（内部直线数量等差递增）

考点：[[20-考点/判断推理/图形推理/数量规律-数线（内部直线数量等差递增）|图形推理 / 数量规律-数线（内部直线数量等差递增）]]


**问法模型**：'最符合所给图形规律'→ 元素组成不同先查属性，属性无规律转数量规律，本题数内部直线数

## 推理链
1. 第1步：图1~4外圈均为圆，仅内部线条不同：图1内部1条直线，图2内部'X'为2条直线，图3内部三角形3条边，图4内部2横2斜共4条直线
2. 第2步：元素组成不同且无对称、曲直等属性规律，按'属性不成、数数量'思路锁定数线
3. 第3步：内部直线数依次为1、2、3、4，构成公差为1的等差数列，问号处应为5条直线
4. 第4步：对照选项数内部直线：A三角形3条，B菱形4条，C内部三角形3条且外圈非圆，D五边形5条
5. 第5步：只有D内部直线数为5且保持外圈为圆，符合规律

**最快解法**：⚡ 数线法：快速数每幅图内部直线数1、2、3、4→等差顺延选5条，直接锁定D（五边形5条边）

## 易错点
- ⚠ 图2的'X'易被当作1个整体而误数成1条，实际为2条交叉直线
- ⚠ 图4内部2条横线+2条斜线共4条，粗心易数成3条或5条
- ⚠ 忽略'外圈均为圆'这一辅助规律，可能误选外圈形状发生变化的C

## 母题抽象
> 🧩 当题干图形外框一致、内部元素各异且属性（对称/曲直/封闭）无规律时，优先数内部直线数，若呈等差数列则按公差顺延选择对应数量的选项

**同类特征**：外圈均为圆、内部直线数量递增、元素组成不同、无明显属性规律、数量规律-数线、等差数列1/2/3/4/5

### 题干
下列选项中最符合所给图形规律的是（    ）。

### 选项
- A. A
- B. B
- C. C
- D. D　✅

### 官方解析
元素组成不同，且无明显属性规律，考虑数量规律。观察图形发现，题干外圈均为圆，内圈出现多条直线，考虑数线。题干图形内部的直线数量为：1、2、3、4、？，因此？处图形内部应有5条直线。只有D项符合。
故正确答案为D。
