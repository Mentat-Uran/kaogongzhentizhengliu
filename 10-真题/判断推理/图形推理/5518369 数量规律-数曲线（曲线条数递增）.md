# 数量规律-数曲线（曲线条数递增）

考点：[[20-考点/判断推理/图形推理/数量规律-数曲线（曲线条数递增）|图形推理 / 数量规律-数曲线（曲线条数递增）]]


**问法模型**：问号处填入图形使整组呈现规律 → 元素组成不同且属性无规律时，优先数曲线数量找递增/等差规律

## 推理链
1. 第1步：题干五幅图元素组成不同（Q形、双弧线、双圆+椭圆、笑脸、问号），对称性、开闭性等属性无统一规律，转向数量规律
2. 第2步：观察发现题干所有图形均含曲线，且图2是两条单一弧线、图4含大圆和弧线嘴巴，符合'含单一曲线'的数曲线提示特征，优先数曲线
3. 第3步：逐图数曲线条数：图1的Q形大圆轮廓为1条曲线（底部直线尾巴不计）；图2两条弧线为2条；图3上方两圆+底部椭圆为3条（中间竖直线不计）；图4大圆脸+两眼小圆+嘴巴弧线为4条，呈1、2、3、4等差递增
4. 第4步：由递增规律推知问号处图形曲线数应为5
5. 第5步：逐项数曲线：A圆柱的椭圆约2条、B月牙为2条弧、C火柴人仅头部1个圆、D为5个圆圈（圆内三角形由直线构成不计曲线），仅D含5条曲线

**最快解法**：⚡ 数曲线法：锁定'全图含曲线'特征后直接清点各图曲线条数，得1、2、3、4递增，问号处需5条曲线，快速数出D项五个圆圈即5条曲线，秒选D

## 易错点
- ⚠ 误数封闭区域或交点：D项圆内的三角形、A圆柱的直线轮廓会干扰视线，须只数曲线（圆/弧/椭圆）
- ⚠ 图4笑脸的曲线易漏数：大圆+两眼小圆+嘴巴弧线共4条，漏数眼睛或嘴巴会得出错误递增规律
- ⚠ 忽略'直线不计入曲线数'：图1的直线尾巴、图3的竖直茎干是直线，不能计入曲线条数

## 母题抽象
> 🧩 当题干图形元素组成不同、对称/开闭等属性无统一规律，且各图均含曲线（尤其出现单一弧线或圆）时，优先数曲线条数，验证其构成1、2、3、4式等差递增，选曲线数延续的选项

**同类特征**：元素组成不同、无明显属性规律、所有图形均含曲线、图2、图4出现单一曲线、曲线数1、2、3、4递增、问号处延续数量规律
