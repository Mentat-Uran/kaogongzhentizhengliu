# 位置规律（旋转180°）

考点：[[20-考点/判断推理/图形推理/位置规律（旋转180°）|图形推理 / 位置规律（旋转180°）]]


**问法模型**：三组'冒号左：右'成对图形且内部元素组成相同 → 考虑位置规律，找出左侧图形到右侧图形的旋转关系并应用到第三组

## 推理链
1. 第1步：题干为电子数码管字形数字'06:90''18:81''32:?'，三组图形各自内部元素组成相同，优先考虑位置规律而非样式规律
2. 第2步：验证第一组：把'06'整体旋转180°，右侧的'6'转到左侧变'9'，'0'转到右侧形状不变，恰得冒号右边的'90'，规律成立
3. 第3步：用第二组复核：'18'整体旋转180°得'81'（1、8在数码管字形下旋转后形状不变，仅左右位置互换），同一规律得到验证
4. 第4步：将规律应用于第三组'32'：整体旋转180°后左右位置互换——右边的'2'移到左侧，且在七段数码管字形下'2'旋转180°后形状保持不变；左边的'3'移到右侧，旋转180°后开口由朝右变为朝左，成为'E'形
5. 第5步：故'？'处应为'2E'，对照选项A'53'、B'23'、C'5E'、D'2E'，只有D符合

**最快解法**：⚡ 整体倒转法：把'32'整块在脑中旋转180°（上下、左右同时翻转且两位互换），直接读出'2E'，秒选D

## 易错点
- ⚠ 只交换两位位置而不旋转字形，误选B'23'——忽略了'3'旋转180°后变为'E'
- ⚠ 把'2'误认为旋转后变'5'（2与5实为左右镜像关系，是翻转不是180°旋转），误选C'5E'
- ⚠ 忽略'整体旋转'包含左右位置互换，只对单个数字旋转而不换位

## 母题抽象
> 🧩 当成组图形为电子数码管式数字/字母且冒号（或分隔符）两侧元素组成相同时，用'整体旋转180°'验证：每位字形旋转后的形状+整体左右互换，逐位比对选项

**同类特征**：冒号分隔的左右成对图形、电子数码管/计算器数字字形、三组图元素组成相同、左边图形旋转得到右边图形、6-9、3-E等字形旋转变形
