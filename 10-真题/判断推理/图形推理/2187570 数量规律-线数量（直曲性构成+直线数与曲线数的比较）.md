# 数量规律-线数量（直曲性构成+直线数与曲线数的比较）

考点：[[20-考点/判断推理/图形推理/数量规律-线数量（直曲性构成+直线数与曲线数的比较）|图形推理 / 数量规律-线数量（直曲性构成+直线数与曲线数的比较）]]


**问法模型**：问号处填入与题干一组图形呈相同规律的图形 → 归纳题干全部图形在'直曲构成、曲线条数、直曲数量关系'上的共性规律，逐项排除

## 推理链
1. 第1步：元素组成不同，优先属性/数量规律；题干图1（上部曲线+下部两直线交成尖角）、图2（扇形：两条直半径+一条弧）、图3（圆+五角星）均由直线和曲线共同构成 → 排除纯直线的A项（三角形）
2. 第2步：数曲线条数：图1仅上部1条曲线，图2仅1条弧，图3仅圆1条曲线 → 题干规律为'每图只有一条曲线'
3. 第3步：对照B项：弯带由上下两条弧构成，含两条曲线，不满足'仅一条曲线' → 排除B
4. 第4步：对比C、D：C为扇形（2条直线+1条曲线），直线数多于曲线数；D为半圆（1条直线+1条曲线），直线数等于曲线数
5. 第5步：回验题干：图1直线2>曲线1，图2直线2>曲线1，图3五角星直线10>圆曲线1 → 题干均为'直线数多于曲线数'，锁定C
6. 第6步：辅助验证：题干图形均含刻意构造的角（图1下尖角、图2扇形顶角、图3五角星角），C有角、D半圆无角，同样指向C

**最快解法**：⚡ 排除法+线数量比较：第一层'须含直线和曲线'排A → 第二层'只有一条曲线'排B → 第三层'直线数多于曲线数'排D，锁定C

## 易错点
- ⚠ 只看到'直线数多'而忽略'必须同时含曲线'，可能误选纯直线的A项
- ⚠ B项弯带两端看似有直线而误判其曲线条数，实际B含上下两条曲线，不满足'仅一条曲线'
- ⚠ C、D都由一一直一曲构成，若不加数'直线数与曲线数的多少关系'这一层，C/D无法区分

## 母题抽象
> 🧩 当题干各图形均由直线与曲线混合构成时，先排除纯直线/纯曲线项，再数每图曲线条数是否一致，最后比较'直线数vs曲线数'的多少关系，即可锁定答案

**同类特征**：元素组成不同，考虑属性+数量规律、每图均由直线和曲线共同构成、每图仅含一条曲线、直线数多于曲线数、图形含刻意构造的角（尖角）、正确项C与图2同为扇形结构
