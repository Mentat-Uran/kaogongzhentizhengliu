# 样式规律-黑白运算（黑白叠加）

考点：[[20-考点/判断推理/图形推理/样式规律-黑白运算（黑白叠加）|图形推理 / 样式规律-黑白运算（黑白叠加）]]


**问法模型**：两组图求问号处最合适的一项 → 先由第一组'图1+图2=图3'归纳样式规律（黑白运算），再将规则代入第二组逐位求答案

## 推理链
1. 第1步：题干为两组图，每幅图均由一条竖线和左、右分布的黑、白横条构成，各图元素组成相似、仅黑白色块分布不同，优先考虑样式规律而非位置规律。
2. 第2步：图形中出现黑白块，锁定样式规律中的黑白运算：将第一组图1与图2按'同一行、同一侧（竖线左/右）'逐位对齐叠加，与图3对照，归纳出黑+白、白+黑、黑+黑、白+白等组合的叠加结果。
3. 第3步：验证第一组：图1、图2逐位叠加后的黑白横条分布与图3吻合（如三幅图第4行右侧均为黑色横条，同黑叠加处仍为黑色），规律成立。
4. 第4步：将同一套叠加规则代入第二组：图1（左侧多为黑色横条、第2行右侧黑条）与图2（右侧白条、第3、4行左侧黑条）逐行逐侧运算。
5. 第5步：逐位运算结果显示：问号处图形整体呈'白多黑少'的分布——多数位置为白色横条，仅左下角为一处黑色横条。
6. 第6步：对照选项：B、C左侧连续出现成片黑色横条，D的黑白色块位置与运算结果不符，只有A的黑白横条分布与逐位运算结果一致，故选A。

**最快解法**：⚡ 黑白运算法+排除法：先由第一组'图1+图2=图3'确定各位置黑白叠加规则，再将第二组图1、图2逐行逐侧叠加，与选项比对——B、C为成片黑块、D黑白错位，直接排除，仅A吻合。

## 易错点
- ⚠ 误判考点：见横条位置在图间变动就往'平移/翻转'等位置规律上想，而本题实为样式类黑白运算
- ⚠ 叠加错位：未按'同一行+同一侧（竖线左右）'逐位对齐，把左右两侧横条混为一谈，导致黑白色块对应错误
- ⚠ 受B、C成片黑色横条干扰，凭'黑块多'的直觉误选，忽略运算结果应是'白多黑少'的分布

## 母题抽象
> 🧩 当题干出现'两组图+黑白块/黑白格'且元素组成相似时，用黑白运算（同位叠加）：先由第一组图1、图2逐位叠加得图3归纳规则，再把规则逐位代入第二组，与选项黑白色块分布比对。

**同类特征**：两组式图形推理、黑白横条（黑块+白块）、竖线分隔左右两侧、元素组成相似、问号在第二组第三幅、同位叠加规律
