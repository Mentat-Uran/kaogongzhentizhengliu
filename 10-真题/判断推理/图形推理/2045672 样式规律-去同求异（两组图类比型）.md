# 样式规律-去同求异（两组图类比型）

考点：[[20-考点/判断推理/图形推理/样式规律-去同求异（两组图类比型）|图形推理 / 样式规律-去同求异（两组图类比型）]]


**问法模型**：“右边图形的变化规律与左边图形一致”→ 两组图类比：先从第一组归纳样式运算规律，再原样套用到第二组选答案

## 推理链
1. 第1步：第一组图1为一个大正方形，图2为沿对角线相接排列的两个小正方形（位于大正方形内部的两个对角区域），图3为位置互补的另两个对角区域上的两个小正方形
2. 第2步：元素组成相似，考虑样式规律；将图1与图2重叠，公共部分是图2的两个小正方形，从大正方形中去掉该公共部分，剩下的恰是图3的两个小正方形，即规律为“去同求异”
3. 第3步：第二组图1为大圆，图2为沿对角线相切排列的两个小圆（一大一小，对应放入大圆内部的位置）
4. 第4步：套用去同求异：大圆与图2两小圆的重叠部分是这两个小圆，去掉后保留大圆剩余部分，轮廓画法即“大圆内部含两个相切的小圆”
5. 第5步：逐项对照：A、B只是两个等大小圆外切（缺少大圆剩余轮廓，且圆的相对大小、方位与图2不符）；D是一个小圆在大圆外部与之外切，不是“挖去”后的剩余部分；C为大圆内含两个相切小圆，与去同求异结果一致，故选C

**最快解法**：⚡ 两组图类比+去同求异口诀“同去异留”：第一组验证“大正方形挖去图2两个小正方形=图3”后，第二组直接做“大圆挖去两个相切小圆”，轮廓为大圆内含两小圆，秒选C

## 易错点
- ⚠ 把去同求异误当作去异求同或直接叠加，看到小圆相切就误选A/B
- ⚠ 忽略图2中小图形位于大图形内部这一位置关系，误以为剩余部分在圆外而错选D
- ⚠ 只盯着第二组孤立找规律，忘记先用第一组验证样式运算规则

## 母题抽象
> 🧩 当题干出现“两组图”且元素组成相似（同类图形的大小、组合变化）时，先在第一组验证“图1与图2去同求异=图3”，再将该样式运算原样套到第二组，对照选项选剩余轮廓

**同类特征**：两组图类比、元素组成相似、大图形套小图形（正方形/圆）、小图形沿对角线相接/相切排列、去同求异、问号处求第三幅图

### 题干
请选择最适合的一项填入问号处，使右边图形的变化规律与左边图形一致：

### 选项
- A. A
- B. B
- C. C　✅
- D. D

### 官方解析
元素组成相似，考虑样式规律。观察发现，第一组图形中，第一幅图和第二幅图去同求异得到第三幅图。第二组图形应遵循相同的规律，？处应填入第一幅图和第二幅图去同求异后的图形，即为C项。
故正确答案为C。
