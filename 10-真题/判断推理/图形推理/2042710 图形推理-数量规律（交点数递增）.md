# 图形推理-数量规律（交点数递增）

考点：[[20-考点/判断推理/图形推理/图形推理-数量规律（交点数递增）|图形推理 / 图形推理-数量规律（交点数递增）]]


**问法模型**：五图呈规律性、选第六图延续规律 → 元素组成不同且属性无规律时，转数量规律找递增/等差数列（本题数交点）

## 推理链
1. 第1步：五图均为'六边形外框+内部直线'，元素组成不同，对称、曲直、封闭等属性无统一规律，指向数量规律
2. 第2步：图形'窟窿较多且存在多边形'，先数面数量、再数线数量均无递增规律，按解析思路转数交点
3. 第3步：以六边形6个顶点为基数逐图清点：图1横线端点与顶点重合不新增，交点=6；图2两线交于中心新增1，交点=7；图3斜线两端落在边上新增2，交点=8；图4斜线两端点+与横线交叉点新增3，交点=9；图5两条平行斜线4个端点新增4，交点=10
4. 第4步：交点数6、7、8、9、10构成公差为1的等差数列，第六图应有11个交点
5. 第5步：逐项清点选项：A项三线交于中心为7个、C项与图1同构为6个、D项亦不为11，均排除
6. 第6步：仅B项交点数为11，符合'6→11'递增规律，故选B

**最快解法**：⚡ 数交点法+递推：先数出首图6个交点（六边形顶点即交点），再快速发现每图内部线新增交点依次+0、+1、+2、+3、+4，锁定'逐图+1'规律后直接在选项中数出11个交点者即选

## 易错点
- ⚠ 看到'窟窿多'先入为主死磕面数量、看到多边形死磕线数量，无规律时未及时转换为数交点
- ⚠ 数交点时漏数六边形顶点这一基数6，或漏数内部线与外框边的交点、线与线的交叉点，导致数列对不上
- ⚠ 内部线端点与顶点重合时（如图1横线、图2对角线）重复或漏计交点

## 母题抽象
> 🧩 当题干图形'元素组成不同+属性无规律+外框多边形内部穿插直线'时，以外框顶点为基数数交点，若逐图递增构成等差数列，则选交点数等于下一项的选项

**同类特征**：元素组成不同、无明显属性规律、外框六边形+内部直线、面数量、线数量均无规律、交点数6→10等差递增、求第六图延续规律

### 题干
上边的题干中给出一套图形，其中有五个图，这五个图呈现一定的规律性。在下边给出一套图形，从中选出唯一的一项作为保持上边五个图规律性的第六个图。

### 选项
- A. A
- B. B　✅
- C. C
- D. D

### 官方解析
元素组成不同，无明显属性规律，考虑数量规律。观察图形特征，窟窿较多且存在多边形，优先数面数量和线数量，但均无规律，考虑数点。每幅图中交点数量依次为：6、7、8、9、10，呈现数量递增的规律，因此应选择交点数量为11的图形，只有B项符合。
故正确答案为B。
