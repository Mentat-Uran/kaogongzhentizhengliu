# 位置规律（小元素平移）＋阴影线条方向交替

考点：[[20-考点/判断推理/图形推理/位置规律（小元素平移）＋阴影线条方向交替|图形推理 / 位置规律（小元素平移）＋阴影线条方向交替]]


**问法模型**：五幅图元素组成完全相同求规律 → 优先考虑位置规律：分别追踪各小元素的平移方向与步数，再用线条方向交替等复合规律锁定唯一答案

## 推理链
1. 第1步：五幅图及选项均由外层双正方形八角星网格、内部阴影四边形、黑色三角形、小白圆圈构成，元素组成相同，优先考虑位置规律
2. 第2步：沿八角星网格格点追踪黑色三角形，发现其每次逆时针平移3格；追踪小白圆圈，发现其每次顺时针平移2格
3. 第3步：按黑三角逆3、白圈顺2的平移规律推出第6幅图两小元素应在的位置，D项小元素位置不符，排除D
4. 第4步：再观察最外圈阴影部分线条与最中间阴影部分线条的方向关系，依次为平行、垂直、平行、垂直、平行，呈交替规律
5. 第5步：交替规律下问号处应为'垂直'，B、C两组阴影线为平行关系，只有A满足垂直，且小元素位置符合平移规律
6. 第6步：综合两组规律，仅A同时满足，故正确答案为A

**最快解法**：⚡ 双规律排除法：先数小元素平移——黑三角逆时针3格、白圈顺时针2格，排除D；再看最外圈与最中间阴影线方向'平行—垂直'交替，问号处应为垂直，锁定A

## 易错点
- ⚠ 只追踪黑三角和白圈的平移规律，忽略阴影线条方向交替这一第二重规律，导致无法在剩余选项中定案
- ⚠ 平移方向与格数数错（逆时针3格误看成顺时针、或格点计数出错），误排除正确选项
- ⚠ '平行/垂直'比的是最外圈阴影线与最中间阴影线的关系，误拿外圈线与其他层次线条比较而看错规律

## 母题抽象
> 🧩 当一组图形元素组成相同且含多个可追踪小元素时，先逐一定位各小元素的平移方向与步数排除部分选项，再用线条方向、阴影样式等交替规律验证锁定唯一答案

**同类特征**：元素组成相同、八角星嵌套网格背景、黑色三角形逐格平移、小白圆圈逐格平移、外圈与中间阴影线平行/垂直交替、五幅图＋问号求第六幅

### 题干
从四个选项中选最合适的一个填入问号处，使之呈现一定的规律性：

### 选项
- A. A　✅
- B. B
- C. C
- D. D

### 官方解析
图形元素组成相同，优先考虑位置规律。观察发现，黑色三角形每次逆时针平移3格，小白圆圈每次顺时针平移2格，排除D项；最外圈阴影部分的线条与最中间阴影部分线条的方向依次是平行、垂直、平行、垂直、平行、？，因此问号处应当填一个垂直的，只有A符合。
故正确答案为A。
