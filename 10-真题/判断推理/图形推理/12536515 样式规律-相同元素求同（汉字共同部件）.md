# 样式规律-相同元素求同（汉字共同部件）

考点：[[20-考点/判断推理/图形推理/样式规律-相同元素求同（汉字共同部件）|图形推理 / 样式规律-相同元素求同（汉字共同部件）]]


**问法模型**：两套三格汉字图形求延续规律 → 分组寻找每组三个汉字的共同部件（求同），选项须延续第二组的共同部件

## 推理链
1. 第1步：题干为两组汉字，第一组「达、窝、顺」，第二组「离、脑、？」，四个选项均为单个汉字
2. 第2步：元素组成相似，优先考虑样式规律中的求同——找每组三个字共有的部件/笔画形状
3. 第3步：第一组中「达」含大字中的'人'形、「窝」含穴底'八/人'形、「顺」含页部贝内'人'形，三字均有'人'
4. 第4步：第二组「离」「脑」右部均含'凶'，其中均有'乂'（两笔交叉），故'？'处汉字也应含'乂'
5. 第5步：逐项对照：A鸽（合字头含'人'，无'乂'）；B泓（氵+弓+厶，无'乂'）；C癸（底部天含'人'形，无'乂'）；D斑（中间'文'=亠+'乂'，含'乂'）
6. 第6步：只有D项含'乂'，能延续第二组规律，故选D

**最快解法**：⚡ 求同法+部件扫描：第一组三字共有'人'，第二组前两字共有'乂'（凶中交叉两笔），直接在四个选项中找含'乂'的汉字——仅'斑'中的'文'含'乂'，秒选D

## 易错点
- ⚠ 误把汉字题往笔画数、封闭区域等数量规律上想，忽略'元素组成相似→优先样式求同'的解题顺序
- ⚠ '人'与'乂'形近易混：第一组是'人'形（撇捺分开不交叉），第二组'凶'内是交叉的'乂'，部件辨析需精确
- ⚠ 沿用第一组规律而非第二组：A鸽、C癸均含'人'，若错套第一组规律会误选A或C

## 母题抽象
> 🧩 当题干为两套汉字图形且元素组成相似时，用'分组求同'法：先找第一组三字共同部件，再找第二组共同部件，最后验证唯一选项中含该部件者即为答案

**同类特征**：两套三段式汉字图形、元素组成相似、问号处求延续规律、汉字部件求同、形近部件'人'与'乂'、选项为四个单个汉字

### 题干
从四个选项中选择一个替代问号，使两套图形的规律表现出最大的相似性，最适合的是（    ）。

### 选项
- A. A
- B. B
- C. C
- D. D　✅

### 官方解析
元素组成相似，优先考虑样式规律。观察发现，题干两组图中，第一组图均有“人”，第二组前两幅图均有“乂”，故“？”处也应该有“乂”，只有D项符合。
故正确答案为D。
