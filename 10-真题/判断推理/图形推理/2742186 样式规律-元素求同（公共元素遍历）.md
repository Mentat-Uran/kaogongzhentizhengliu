# 样式规律-元素求同（公共元素遍历）

考点：[[20-考点/判断推理/图形推理/样式规律-元素求同（公共元素遍历）|图形推理 / 样式规律-元素求同（公共元素遍历）]]


**问法模型**：『填入问号处使之呈现一定的规律性』且图形元素组成相似、部分元素反复出现 → 用样式求同法找各已知图形的公共元素，问号处延续该元素

## 推理链
1. 第1步：观察题干五图：①菱形外框内含圆、②圆内含正方形、③正方形内含三角形、④正方体、⑤圆内十字四分区中含三角形/圆/正方形/长方形，元素相似且有重复元素，指向样式规律
2. 第2步：采用求同法：逐图筛查在所有已知图形中都出现的公共元素
3. 第3步：图①外框为旋转45°的正方形、图②内含正方形、图③外框是正方形、图④正方体的正面为正方形、图⑤四分区中含正方形——五图均包含『正方形』元素
4. 第4步：由遍历规律推定，问号处图形也必须包含正方形元素
5. 第5步：逐项对照：A为八边形内含圆、C为圆内含三角形、D为箭头加长方形组合，均不含正方形，排除
6. 第6步：B为正方形内嵌正方形，是唯一含正方形元素的选项，故选B

**最快解法**：⚡ 样式求同口诀『相似找相同』：快速扫视五图锁定公共元素——正方形（图①外框是旋转45°的正方形、图④正方体含正方形面），直接选含正方形的选项，秒定B

## 易错点
- ⚠ 图①外框呈菱形，易误判为『不含正方形』而否定求同思路，实际是旋转45°的正方形
- ⚠ 图④是立体图，易忽略其表面（正面）所含的正方形元素
- ⚠ D项尾部的小矩形易被看成正方形而误选，需目测边长比例区分长方形与正方形

## 母题抽象
> 🧩 当题干图形元素组成相似且某元素不止一次出现时，用『样式求同』找出所有已知图形的公共元素，问号处必须延续该公共元素，据此排除定答案

**同类特征**：元素组成相似、同一元素（正方形）反复出现、内外嵌套/组合结构、含立体图（正方体）、菱形外框（旋转45°正方形）、问号延续公共元素

### 题干
从所给的四个选项中，选择最合适的一个填入问号处，使之呈现一定的规律性：

### 选项
- A. A
- B. B　✅
- C. C
- D. D

### 官方解析
元素组成相似，且某些元素不止一次出现在各图形中，优先考虑样式规律中的遍历。比较相邻图形发现，题干已知图形都包含正方形元素，故问号处图形也应满足此规律，只有B项符合。
故正确答案为B。
