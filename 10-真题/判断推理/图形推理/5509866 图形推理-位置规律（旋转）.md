# 图形推理-位置规律（旋转）

考点：[[20-考点/判断推理/图形推理/图形推理-位置规律（旋转）|图形推理 / 图形推理-位置规律（旋转）]]


**问法模型**：两组图、第一组三图呈现规律、第二组同规律求问号 → 两段式类比：先归纳第一组旋转方向与角度，再平移应用到第二组

## 推理链
1. 第1步：两组图形元素组成完全相同（第一组为'双向箭头+三角形'，第二组为'房屋形箭头+内嵌四角星'），仅方向变化，锁定位置规律类题
2. 第2步：观察第一组主箭头指向：图1朝上→图2朝右→图3朝下，三角形随之从右侧转到下方再转到左侧，即整幅图形每次顺时针旋转90°
3. 第3步：验证第二组前两幅：图1箭头朝上，图2箭头朝右，恰好也是顺时针旋转90°，规律成立
4. 第4步：依规律，问号处应为第二组图2（箭头朝右）再顺时针旋转90°，即箭头朝下、四角星仍在图形内部的图形
5. 第5步：对照选项：A箭头朝上、C箭头朝右、D箭头朝左，只有B箭头朝下，故选B

**最快解法**：⚡ 箭头指向法：只盯主箭头指向，第一组'上→右→下'即顺时针每次转90°；第二组已给出'上→右'，问号必为'朝下'，直接锁定B，无需逐项分析内部小元素

## 易错点
- ⚠ 旋转方向误判为逆时针，会错选D（箭头朝左）
- ⚠ 第二组未以图2为基准继续旋转，而是回到图1重新开始，会错选A（箭头朝上）
- ⚠ 被内部元素（三角形/四角星）形态干扰，忽略'箭头指向'这一最直观的方向指针

## 母题抽象
> 🧩 当两组图元素组成相同、仅方向变化时，先找图中最明确的'指针型'元素（箭头）的指向序列确定旋转方向和角度，再将该旋转规则套用到第二组求出第三幅图

**同类特征**：两组式图形推理、元素组成相同、箭头类指针元素、仅方向/位置变化、顺时针旋转90°、求第三幅图

### 选项
- A. A
- B. B　✅
- C. C
- D. D

### 官方解析
图形元素组成相同，优先考虑位置规律。观察发现，题干中第一组图的三幅图依次顺时针旋转；第二组图也按此规律进行旋转，所以问号处图形应为该组第二幅图顺时针旋转后所得，只有B项符合。
故正确答案为B。
