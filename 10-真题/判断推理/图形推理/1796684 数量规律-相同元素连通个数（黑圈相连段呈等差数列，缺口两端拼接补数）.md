# 数量规律-相同元素连通个数（黑圈相连段呈等差数列，缺口两端拼接补数）

考点：[[20-考点/判断推理/图形推理/数量规律-相同元素连通个数（黑圈相连段呈等差数列，缺口两端拼接补数）|图形推理 / 数量规律-相同元素连通个数（黑圈相连段呈等差数列，缺口两端拼接补数）]]


**问法模型**：整串图形被'？'框截断、要求填入一段使之呈现规律 → 采用'缺口拼接法'：把选项两端与问号两侧元素连通合并后，验证整串'相连同色段'个数构成等差数列

## 推理链
1. 第1步：题干是一条由黑圈、白圈串成的链条，中间被'？'框截断，仅两种元素，位置与样式无规律，考虑数数（数'相连'的个数而非总数）
2. 第2步：按连续相邻为单位清点黑圈，题干已知各段相连黑圈个数为1、2、X、X、5，两端1与5提示中间X应为3、4，构成1、2、3、4、5的递增等差数列
3. 第3步：观察缺口两侧：问号前紧贴已有2个相连黑圈，问号后紧贴也有2个相连黑圈，故所选选项须'左端补1个黑圈'（2+1=3）、'右端补2个黑圈'（2+2=4）
4. 第4步：逐项对照：A左端为白圈、无法与问号前的2黑连通成3，排除；C左端为2黑（2+2=4，错位）、排除；D右端仅1黑（2+1=3≠4）、排除；B左端1黑、右端2黑，恰好补足3和4
5. 第5步：二次验证：将B代入后，整串相连白圈个数依次为5、4、3、2、1，同样构成递减等差数列，黑增白减两规律自洽，故选B

**最快解法**：⚡ 缺口拼接法+等差数列：数'相连黑圈'得1、2、？、？、5，锁定应为1~5递增；问号前后各贴2个黑圈，故选项必须'左端1黑、右端2黑'，直接锁定B，再用白圈5、4、3、2、1递减验证

## 易错点
- ⚠ 只数黑圈总个数而不数'相连（连续相邻）段'的个数，把题目当成普通元素总量比较
- ⚠ 忽略问号框两侧紧贴的2个黑圈需与选项端点黑圈合并连通，误选左端2黑的C或右端1黑的D
- ⚠ 只验证黑圈递增规律而不做白圈5、4、3、2、1递减的二次验证，遇到双满足项时无法区分

## 母题抽象
> 🧩 当图形为'一条被问号截断的双色串珠链'时，按'相连同色段'逐段计数找等差数列，用缺口两侧端点已有的元素个数反推选项两端必须补足的数量（左补=目标数−左侧已有数，右补同理）

**同类特征**：黑白两色圆圈串成的链条、中间问号框截断需拼接口、相连黑圈个数为1、2、X、X、5、等差数列递增规律、选项端点元素与缺口两侧元素连通合并、白圈相连个数5、4、3、2、1递减验证

### 题干
从所给四个选项中，选择最合适的一个填入问号处，使之呈现一定的规律性。

### 选项
- A. A
- B. B　✅
- C. C
- D. D

### 官方解析
本题只有两种元素，黑圈和白圈，观察选项中的黑圈白圈个数存在不同，考虑数数。题干中除了问号处，已知相连黑圈的个数分别为1，2，X，X，5，由此可知，与选项结合后的最终图形中，中间两个X应该分别有3个黑圈相连和4个黑圈相连，而题干问号前后已经各有两个黑圈，选择的选项中左端应该有1个黑圈，右端有2个，只能选B项。将B项代入整体观察后，发现相连的白圈个数也满足等差数列依次递减的规律，分别是5，4，3，2，1。
故正确答案为B。
