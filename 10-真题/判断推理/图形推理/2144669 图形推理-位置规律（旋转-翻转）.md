# 图形推理-位置规律（旋转-翻转）

考点：[[20-考点/判断推理/图形推理/图形推理-位置规律（旋转-翻转）|图形推理 / 图形推理-位置规律（旋转/翻转）]]


**问法模型**：两组类比型图形推理（第一组3图找规律、第二组前2图+？）→ 元素组成相同，套用位置规律模型：第一组建立规律，第二组延续规律，当旋转与翻转双解时用选项延续验证排除

## 推理链
1. 第1步：两组图形均由九宫格中3个黑格构成，黑格数量、形状完全一致，仅位置改变→元素组成相同，优先考虑位置规律（旋转/翻转）
2. 第2步：验证第一组：图一（黑格在左上、中心、右下的主对角线）整体旋转90°得图二（右上、中心、左下的副对角线），图二再旋转90°回到图三；左右翻转对第一组同样成立
3. 第3步：第二组中图一（顶中、左中、右下）→图二（顶中、右中、左下），旋转90°与左右翻转两种变换结果相同，规律存在双解，需向后延续并用选项排除
4. 第4步：假设为左右翻转，则图二再翻转应回到图一（顶中、左中、右下），四个选项中均无此图形，排除翻转假设
5. 第5步：故锁定规律为整体顺时针旋转90°：图二黑格（顶中、右中、左下）顺时针转90°，落位为左上、右中、下中
6. 第6步：对照选项，仅B项黑格位于左上、右中、下中，与该规律完全吻合

**最快解法**：⚡ 双解排除法（延续验证）：发现图一→图二用'旋转'和'翻转'都能解释时，不急着选，先假设翻转延续——图三应等于图一，选项无解，排除；再用顺时针旋转90°直接转图二（左下黑格→左上、顶中→右中、右中→下中），秒选B

## 易错点
- ⚠ 第一组对角线图形旋转与翻转结果相同，第二组图一→图二旋转与翻转结果也相同，若不向后延续验证就落笔，会陷入'翻转/旋转'双解陷阱
- ⚠ 小格旋转落位算错方向：误以为左下角黑格顺时针转90°后到右上角（实际到左上角），导致误选A
- ⚠ 忽略'整体旋转'是全图所有黑格同步转动，只单独挪动某个黑格造成落位错乱

## 母题抽象
> 🧩 当两组图形元素组成完全相同、仅位置改变，且某一步变换存在旋转/翻转双解时，用'该变换继续作用于下一幅图'去匹配选项——能在选项中落地的变换才是真规律

**同类特征**：两组各三幅图、问'？'处图形、九宫格黑白格、元素组成相同、位置变化（旋转/翻转）、第一组规律需在第二组延续验证、双解靠选项排他确定

### 官方解析
元素组成相同，优先考虑位置规律。第一组图的图二可由图一整体旋转90度形成，也可左右翻转形成，图二到图三也是同样的规律。但根据第二组图可知，若图一到图二左右翻转而来，则选项无相应答案，因此图一到图二为整体顺时针旋转90度，？处为图二顺时针旋转90度，只有B项符合该规律。
故正确答案为B。
