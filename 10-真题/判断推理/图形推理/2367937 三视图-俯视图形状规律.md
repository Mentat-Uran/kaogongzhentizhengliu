# 三视图-俯视图形状规律

考点：[[20-考点/判断推理/图形推理/三视图-俯视图形状规律|图形推理 / 三视图-俯视图形状规律]]


**问法模型**：一排立体积木图+问号求延续规律 → 数量/位置规律不明时，转向三视图（俯视图）找投影形状共性

## 推理链
1. 第1步：题干为5个由小立方体堆叠而成的立体图形，后接问号，需找出五图共同规律
2. 第2步：五个图形高度层数不一（有单层也有多层），方块总数也无明显递变，排除数量类与位置类常规规律
3. 第3步：改从投影角度观察——把每个立体图'从上往下看'，只看底面方块的占位形状
4. 第4步：发现题干5个图形的俯视图均为'L'形（即底面方块拐角排布，两臂互相垂直）
5. 第5步：逐项验证：A、B、C三项的底面方块占位投影均不构成L形（拐角结构缺失或呈其他分布），D项底面一臂较长、一臂较短且垂直相接，俯视图恰为L形
6. 第6步：符合'俯视图为L形'规律的唯一选项为D

**最快解法**：⚡ 三视图法+排除法：对每个立体图做'俯视压扁'处理（只看底面占位不看高度），题干5图俯视图均为L形；快速扫四个选项的底面投影，A、B、C非L形直接排除，锁定D

## 易错点
- ⚠ 误看主视图或左视图而非俯视图，被立方体堆叠高度和遮挡棱线干扰
- ⚠ 在等轴测图中被斜向棱线误导，把底面占位方块数错，误判俯视图形状
- ⚠ 执着于数方块总数、找层数递变等数量规律，忽略'投影形状共性'这一视角

## 母题抽象
> 🧩 当题干出现'一串立方体堆叠立体图+问号'且数量、位置规律均不明显时，应转向三视图视角（依次检验俯视图/主视图/左视图），验证各图投影形状是否具有同一性

**同类特征**：立方体堆叠立体图、等轴测(斜二测)画法、各图层数高低不一、方块数量无规律、问号处求规律延续、选项同为立体积木图

### 题干
从四个图中选出唯一的一项，填入问号处，使其呈现一定的规律性:

### 选项
- A. A
- B. B
- C. C
- D. D　✅

### 官方解析
本题考查三视图。观察图形发现，题干的每一个立体图形的俯视图均为“L”形，符合此规律的只有D项。
故正确答案为D。
