# 图形推理-平面拼合（平行且等长相消法）

考点：[[20-考点/判断推理/图形推理/图形推理-平面拼合（平行且等长相消法）|图形推理 / 图形推理-平面拼合（平行且等长相消法）]]


**问法模型**：四个小图形只能上、下、左、右平移拼成一个图形 → 用平行且等长相消法：内部相贴边两两消去，剩余线段构成的外轮廓即答案

## 推理链
1. 第1步：提取题干四个小图形的边特征：①细长尖角三角形（右侧竖直短边、长斜边）、②斜置四边形（两条斜边）、③细长竖直条（两条竖直边）、④直角三角形（左侧竖直长边、底部横边、斜边）
2. 第2步：依据拼合规则（只许平移、不重叠不留缝），内部相贴的边必须平行且等长，将这些边两两相消
3. 第3步：将①的长斜边与②的一条斜边配对相消，②的另一条斜边与④的斜边配对相消
4. 第4步：①④的竖直边与③的竖直条在竖直方向拼合相消，底部横边由④的横边提供
5. 第5步：消去全部内部公共边后，剩余边围成的不规则四边形轮廓为：左侧斜边＋上方斜边＋右侧竖边＋底部横边
6. 第6步：逐项对照：A为该不规则四边形轮廓；B为规则平行四边形、C为上斜梯形、D多出内凹缺口，均与消边结果不符

**最快解法**：⚡ 平行且等长相消法（排除法辅助）：给四个小图形的每条边按方向和长度标号，平行且等长的边两两相消，剩余线段连成的轮廓直接与四个选项比对，只有A吻合，秒选A。

## 易错点
- ⚠ 误认为小图形可以旋转或翻转后再拼合（题干明确只能上、下、左、右平移），按旋转拼会配错边
- ⚠ 只数外轮廓边数、不看边的方向与长度，把边数相近的C或B误选
- ⚠ 忽略拼合不允许重叠与缺缝，误选带内凹缺口的D

## 母题抽象
> 🧩 当题干出现'几个小图形只能平移拼合成一个图形'时，用平行且等长相消法：把内部平行等长的公共边两两消去，剩余线段构成的轮廓与选项逐一比对。

**同类特征**：平面拼合、四个小图形拼成一个、只能上、下、左、右移动（不可旋转）、轮廓唯一、平行且等长相消、斜边与直角边混合的碎片图形
