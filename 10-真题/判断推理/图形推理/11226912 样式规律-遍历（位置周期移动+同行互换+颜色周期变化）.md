# 样式规律-遍历（位置周期移动+同行互换+颜色周期变化）

考点：[[20-考点/判断推理/图形推理/样式规律-遍历（位置周期移动+同行互换+颜色周期变化）|图形推理 / 样式规律-遍历（位置周期移动+同行互换+颜色周期变化）]]


**问法模型**：『符合所给图形变化规律』的递推型问法 → 逐幅对比相邻图形，归纳移动、互换、变色的复合规律后递推到？处

## 推理链
1. 第1步：四幅图元素组成相似，圆、三角形、矩形等相同元素重复出现，优先考虑样式规律中的遍历
2. 第2步：对比相邻图形位置，元素所在行按『第三行→第二行→第一行→第三行』的周期循环上移，如图1第三行的『■□』移到图2第二行、图1第一行的白圆移到图2第三行
3. 第3步：同一行存在两个元素时，每次移动后二者左右互换，如图1第三行『■(黑)□(白)』移至图2第二行变为『□(白)■(黑)』
4. 第4步：当元素从第一行循环回到第三行时，颜色按『白→灰→黑→白』周期变化，如图1第一行白圆→图2第三行灰圆，图2第一行黑三角→图3第三行变白三角
5. 第5步：递推？处位置：图4第一行灰圆移到第三行；图4第二行『▽(白)▲(黑)』互换后到第一行为『▲(黑)▽(白)』；图4第三行『灰□、白▭』互换后到第二行为『白▭、灰□』，据此排除C、D
6. 第6步：？处第三行的圆由图4第一行的灰圆经循环跨行（第一行→第三行）按周期『灰→黑』变为黑色，排除B项（白圆），锁定A

**最快解法**：⚡ 『位置+颜色』双规律递推法：先用行周期『3→2→1→3』加同行左右互换锁定？处结构（圆在第3行、▲▽在第1行、白▭灰□在第2行，排除C、D），再单追圆的颜色（图4第一行灰圆回第三行按白灰黑白周期变黑，排除B），秒选A

## 易错点
- ⚠ 只盯位置移动，忽略『从第一行回到第三行时颜色按白灰黑白周期变化』，误选白圆的B项
- ⚠ 同行双元素移动后忘记左右互换位置，误判C、D
- ⚠ 把颜色变化误解为每次移动都变色，实际仅循环跨行（第一行→第三行）时才按周期变色

## 母题抽象
> 🧩 当图形元素组成相似且相同小元素逐图重复出现时，用『遍历/移动』思路：先找位置移动周期与同行互换规则排除结构不符项，再追踪单个元素的颜色（或填充）周期变化定答案

**同类特征**：元素组成相似、相同元素（圆/三角/矩形）重复出现、三行结构逐图递推、同行双元素左右互换、颜色按白灰黑白周期变化、问？处应填图形

### 题干
下列选项中，符合所给图形变化规律的是        。

### 选项
- A. A　✅
- B. B
- C. C
- D. D

### 官方解析
元素组成相似，且相同元素重复出现，优先考虑样式规律中的遍历。观察发现，前一幅图形到后一幅图形，元素的位置按照“第三行第二行第一行第三行”的周期进行移动，且当一行存在两个元素时，每次移动后二者会左右互换位置，据此排除C、D两项；继续观察发现，当元素从“第一行第三行”时，元素的颜色会按照“白灰黑白”的周期进行变化，故？处第三行的圆形应为黑色，只有A项符合。
故正确答案为A。
