# 数量规律-面（黑面数量+相邻图黑面与外框形状的跨图关联）

考点：[[20-考点/判断推理/图形推理/数量规律-面（黑面数量+相邻图黑面与外框形状的跨图关联）|图形推理 / 数量规律-面（黑面数量+相邻图黑面与外框形状的跨图关联）]]


**问法模型**：'选择最合适的一个填入问号处，使之呈现一定的规律性'且元素组成不同 → 先数面，数面无唯一答案时找相邻图之间的形状传递规律（前图黑色面旋转后=后图外框）

## 推理链
1. 第1步：题干五图元素组成不同，对称、曲直等属性规律不明显，转向数量规律；逐一观察发现每幅图均由1个黑色面和3个白色面构成，共4个面
2. 第2步：整体数面，题干各图与选项面数无区分度，无唯一答案，故细化观察黑面与外框的关系
3. 第3步：对比相邻图形：图1的黑色面（不规则四边形）旋转后与图2的梯形外框形状相同；图2的黑色面旋转后与图3外框一致；图3的黑色面旋转后与图4的三角形外框一致；图4的黑色面旋转后与图5外框一致
4. 第4步：归纳出跨图传递规律：第n幅图的黑色面旋转后等于第n+1幅图的外框形状
5. 第5步：将该规律用于问号处：图5的黑色面是带缺口的方框形（L形），其旋转后的形状应与问号处图形的外框一致
6. 第6步：逐项对照：A项外框为L形，与图5黑色面旋转后吻合；B、C、D外框形状均与图5黑色面不匹配，故选A

**最快解法**：⚡ 相邻图关联法（形状传递）：确认每图均为'1黑+3白'且数面无区分度后，直接比对'前图黑面旋转后=后图外框'，只需用图5的黑色面形状去匹配四个选项的外框，L形外框的A项秒杀

## 易错点
- ⚠ 只停留在'每图都是4个面'的整体数面层面，发现无唯一答案后不知如何深入，忽略黑面与相邻图外框的关联
- ⚠ 比对形状时忽略'旋转'变换，按原图方向硬套而误排正确选项
- ⚠ 只关注问号处图形自身的黑白面数量等局部特征，忽视规律是跨图传递关系

## 母题抽象
> 🧩 当题干各图均含'1个黑色面+若干白色面'且单纯数面无唯一答案时，应检验'前一图黑色面（可旋转）与后一图外框形状相同'这类跨图传递规律，用末图黑面去匹配选项外框

**同类特征**：元素组成不同且属性规律不明显、每图恰有1个黑色面、黑色面形状为不规则图形、整体数面无唯一答案、相邻图形外框形状逐图变化、黑色面与相邻图外框存在形状呼应

### 题干
从所给的四个选项中，选择最合适的一个填入问号处，使之呈现一定的规律性：

### 选项
- A. A　✅
- B. B
- C. C
- D. D

### 官方解析
元素组成不同，且无明显属性规律，考虑数量规律。观察发现，题干图形均由一个黑色面和三个白色面组成，优先考虑数面，但整体数面无唯一答案。继续观察发现，前一幅图形中的黑色面形状旋转之后，与后一幅图的外框形状相同，满足这一规律的只有A项。
故正确答案为A。
