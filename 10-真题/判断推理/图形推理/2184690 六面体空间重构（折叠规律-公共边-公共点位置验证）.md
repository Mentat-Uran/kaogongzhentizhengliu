# 六面体空间重构（折叠规律-公共边-公共点位置验证）

考点：[[20-考点/判断推理/图形推理/六面体空间重构（折叠规律-公共边-公共点位置验证）|图形推理 / 六面体空间重构（折叠规律-公共边/公共点位置验证）]]


**问法模型**：题干给出纸盒外表面展开图，问'下面哪一项能由它折叠而成' → 采用空间重构模型：以特征图案（扇形直角边、黑色阴影、白色直角点）的公共边与公共点位置为锚点，逐项验证相邻关系并排除

## 推理链
1. 第1步：题干展开图共6个面，各面分别含白色扇形、黑色扇形、黑色阴影等图案，官方标注为面1~面6，折叠后各面相对位置固定
2. 第2步：所用规则为空间重构的公共边/公共点法——展开图中相邻两面的图案在公共边或公共点处有确定的位置关系，折叠后不得改变
3. 第3步：A项逐面对照——题干中白色扇形面的两条直角边均不在黑色扇形面的白色区域，而A项中白色扇形面有一条直角边落在黑色扇形面的白色区域，公共边位置关系不符，排除
4. 第4步：B项逐面对照——题干面1与面3的黑色阴影部分在展开图中无公共点，而B项中两块黑色阴影出现公共点，相邻关系不符，排除
5. 第5步：D项逐面对照——题干面4与面5白色部分的直角点在展开图中是同一个点，而D项中两个面的白色部分直角点不是同一点，公共点关系不符，排除
6. 第6步：C项三个面为面1、面4、面5，其相邻组合及图案相对位置与展开图一致，当选C

**最快解法**：⚡ 公共边/公共点锚定法：先锁定图案特征最明显的面（白色扇形直角边、黑色阴影块、白色直角点），对每个选项检查特征面与其相邻面的图案落点是否与展开图一致，凡公共边/公共点上图案位置对不上的立即排除，全部吻合的即为答案（本题C项面1、4、5组合吻合）

## 易错点
- ⚠ 只看面上图案'有无'、忽略图案在面上的朝向与旋转，误判扇形直角边落在相邻面的白色还是黑色区域（A项陷阱）
- ⚠ 混淆相对面与相邻面，误以为面1与面3的黑色阴影折叠后可相交出公共点（B项陷阱）
- ⚠ 视角旋转/翻转后直角点重合关系看错，未验证两面白色直角点是否为同一点（D项陷阱）

## 母题抽象
> 🧩 当六面体展开图的各面上出现方向性特征图案（扇形直角边、色块、直角点）时，用公共边/公共点锚定法：逐项验证选项中相邻面图案的落点与展开图是否一致，位置不符即排除

**同类特征**：纸盒外表面展开图折叠、面内含扇形/黑色阴影等特征图案、需验证相邻面公共边位置、白色扇形直角边落点、两直角点是否为同一点、四选项逐项排除选一

<p>本题考查六面体的空间重构。将题干展开图中的面依次标注为123456，如下图：</p><p><img width="563px" height="164px" src="../../../90-图片/题目图/17b0f0717cdad67.png" /></p><p>A项：题干中白色扇形面中的两条直角边不在黑色扇形面的白色区域，而选项中白色扇形面中的一条直角边在黑色扇形面的白色区域，选项与题干展开图不一致，排除；</p><p>B项：题干中面1和面3的黑色阴影部分无公共点，而选项中，黑色阴影部分有公共点，选项与题干展开图不一致，排除；</p><p>C项：选项是面1，面4，面5，和题干一致，当选；</p><p>D项：题干中面4和面5的白色部分的直角点是同一点，而选项中，两个面中白色部分的直角点不是同一点，选项与题干展开图不一致，排除。</p><p>故正确答案为C。</p>
