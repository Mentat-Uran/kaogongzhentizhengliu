# 图形推理-位置规律（左右翻转+顺时针旋转复合）

考点：[[20-考点/判断推理/图形推理/图形推理-位置规律（左右翻转+顺时针旋转复合）|图形推理 / 图形推理-位置规律（左右翻转+顺时针旋转复合）]]


**问法模型**：‘符合所给图形的变化规律’且九宫格、元素组成相同 → 优先横行找位置规律（先翻转后旋转），用第二行验证后套用到第三行求问号

## 推理链
1. 第1步：九宫格每格均由‘外框+内部箭头’两部分组成，元素组成相同，优先考虑位置规律，且九宫格优先看横行
2. 第2步：第一行规律——图1到图2外框位置不变、内部箭头左右翻转；图2到图3外框位置不变、内部箭头顺时针旋转90°
3. 第3步：第二行验证——图1内部白箭头向右，图2翻转后向左，图3顺时针旋转90°后向上（向左逆时针才会向下，故确定为顺时针），规律成立
4. 第4步：第三行套用——图1内部双向斜箭头沿‘↖↘’轴，图2外框不变、左右翻转后沿‘↗↙’轴
5. 第5步：问号处应为第三行图2外框不变、内部双向箭头顺时针旋转90°：‘↗↙’轴旋转后变为‘↖↘’轴
6. 第6步：对照选项——A为‘↖↘’向双向斜箭头，B为竖直双向箭头，C为‘↗↙’向（即未旋转的图2），D为水平双向箭头，只有A符合

**最快解法**：⚡ 位置规律口诀‘横行：翻转→旋转’：只盯内部箭头方向，第三行图2的斜箭头（↗↙轴）顺时针转90°得↖↘轴，直接锁定A；C是没旋转的同轴干扰项，用外框不变+只看内部即可秒杀

## 易错点
- ⚠ 误以为外框也参与旋转/翻转，实际三行中‘外框位置不变’是前提，只有内部箭头动
- ⚠ 跳过第二行验证，导致无法确认是顺时针还是逆时针旋转（第二行‘向左→向上’证明是顺时针）
- ⚠ 把图2未旋转的状态误当答案而错选C，或看错斜箭头的轴向错选B、D

## 母题抽象
> 🧩 当九宫格每格都由‘不变的外框+可动的内部元素’构成且元素组成相同时，按横行归纳‘左右翻转→顺时针旋转’的位置规律，先用第二行验证，再对第三行图2施以旋转即可锁定答案

**同类特征**：九宫格、元素组成相同、外框不变、内部元素变、左右翻转与顺时针旋转复合、双向斜箭头方向轴、需第二行验证旋转方向

### 题干
下列选项中，符合所给图形的变化规律的是        。

### 选项
- A. A　✅
- B. B
- C. C
- D. D

### 官方解析
元素组成相同，优先考虑位置规律。九宫格图形优先看横行，观察发现，第一行中图1外框位置不变、内部箭头通过左右翻转得到图2，图2外框位置不变、内部箭头通过顺时针旋转得到图3。经验证，第二行满足此规律。因此问号处图形应该是第三行中的图2外框位置不变、内部箭头通过顺时针旋转得到，只有A项符合。
故正确答案为A。
