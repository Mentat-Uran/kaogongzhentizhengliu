# 图形推理-数量规律+位置规律复合（小球总数按行守恒、横线上下两行的间隔-对齐排布）

考点：[[20-考点/判断推理/图形推理/图形推理-数量规律+位置规律复合（小球总数按行守恒、横线上下两行的间隔-对齐排布）|图形推理 / 图形推理-数量规律+位置规律复合（小球总数按行守恒、横线上下两行的间隔/对齐排布）]]


**问法模型**：九宫格'填入问号处使之呈现规律性' → 优先横行观察，先用数量规律排除，再用位置细节规律锁定唯一项

## 推理链
1. 第1步：九宫格优先横行观察并数每格小球总数：第一行三图均为3个球，第二行三图均为4个球，即每行球数守恒
2. 第2步：第三行前两图均为4个球，按'每行球数恒定'规律，问号处图形应含4个球
3. 第3步：逐项对照数量：D项只有2个球（横线上下各1个），排除D
4. 第4步：观察排布特征：题干所有图形的小球均被横线整齐分为上下两行，而A项下部两球呈斜向错落、未构成整齐两行，排除A
5. 第5步：比较B、C（球数、分行均相同），差异在于下边两球之间的距离；归纳位置规律：第一行横线上下两行间隔排列（如第一行第一图上○○居两侧、下●居中错开），第二行上下两行对齐排列（●○对○●逐列对齐），第三行前两图均为间隔排列（图1上○○居中、下●●居两侧；图2上○○居两侧、下○○居中）
6. 第6步：问号处应延续第三行'间隔排列'规律，B项下○●分居两侧、与上排○○错开，符合间隔排列；C项下两球间距与上排对齐，不符合，故选B

**最快解法**：⚡ 双重排除法：第一步按横行球数守恒（3、3、3／4、4、4／4、4、？）排除D；第二步按'所有球整齐分为上下两行'排除A；第三步用第三行'间隔排列'的位置规律，在B、C中选下两球与上排错开的B

## 易错点
- ⚠ 只关注球的数量和黑白颜色，忽略横线上下两行'间隔排列vs对齐排列'的位置规律，在B、C之间误选C
- ⚠ 九宫格未优先按横行观察，按列或整体找规律，导致'每行球数恒定'的数量规律难以发现
- ⚠ 忽略A项下部两球斜向错落、并未整齐分为上下两行的细节，仅凭球数为4误选A

## 母题抽象
> 🧩 当九宫格每格由'横线+若干小球'构成、元素种类相同仅排布不同时，先按行统计小球总数找数量规律排除，再比较横线上下两行的相对位置（间隔/对齐）等细节规律锁定答案

**同类特征**：九宫格图形推理、每格含横线分隔的上下两行小球、黑白小球总数逐行守恒、元素相同仅位置排布不同、剩余两项仅细节间距差异需二次辨析

### 题干
从所给的四个选项中，选择最合适的一个填入问号处，使之呈现一定的规律性：

### 选项
- A. A
- B. B　✅
- C. C
- D. D

### 官方解析
九宫格优先横行观察，第一行都有3个球，第二行都有4个球，第三行前两幅图都有4个球，故问号处也应有四个球，排除D项；观察发现，题干所有球均分为上下两行，排除A项；比较B、C两项，发现B、C两项下边两个球之间的距离不一致，观察题干发现，九宫格第一行中，横线上下两行间隔排列，第二行，横线上下两行对齐排列，第三行前两幅图中，横线上下两行间隔排列，因此问号处选择一个横线上下两行间隔排列的，只有B选项符合。
故正确答案为B。
