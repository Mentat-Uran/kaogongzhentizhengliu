# 属性规律-对称性（内外图形对称轴的位置关系：平行-垂直交替）

考点：[[20-考点/判断推理/图形推理/属性规律-对称性（内外图形对称轴的位置关系：平行-垂直交替）|图形推理 / 属性规律-对称性（内外图形对称轴的位置关系：平行/垂直交替）]]


**问法模型**：『填入问号处使之呈现规律性』且各图元素组成不同 → 优先考虑属性规律，本题考查内部对称面与外框对称轴的夹角关系（平行/垂直交替）

## 推理链
1. 第1步：题干五幅图均由'外框+内部线条分割'构成，元素组成不同，排除位置/样式规律，转向属性规律
2. 第2步：观察发现每幅图内部均存在一个轴对称的面（如图1左上的折线形面、图2内的折角形面），且外框本身也是轴对称图形
3. 第3步：分别画出'内部对称面的对称轴'与'外框的对称轴'，比较两轴关系：图1、图3、图5中两轴平行，图2、图4中两轴垂直
4. 第4步：归纳出规律——两条对称轴的关系按'平行、垂直'交替出现，第6幅（问号处）应为垂直
5. 第5步：逐项验证A、B、C、D，只有D项内部对称面的对称轴与外框对称轴呈垂直关系，A、B、C均不满足
6. 第6步：故问号处选D

**最快解法**：⚡ 对称轴方向法：先在每个图形中找出内部那个'轴对称面'并画出其对称轴，再画外框对称轴，判断两轴是平行还是垂直；由'平行、垂直'交替规律知第6幅应为垂直，直接锁定D

## 易错点
- ⚠ 只关注外框对称性、漏看内部那个轴对称的面，导致无从比较两轴关系
- ⚠ 内部对称面找错：并非所有封闭面都轴对称，需逐面筛选出轴对称的那个面再画轴
- ⚠ 交替规律数错位置：图1/3/5为平行、图2/4为垂直，问号处（第6幅）应延续为垂直，误以为循环重新从平行开始
