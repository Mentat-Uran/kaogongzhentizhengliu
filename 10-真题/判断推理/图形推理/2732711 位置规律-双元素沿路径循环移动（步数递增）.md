# 位置规律-双元素沿路径循环移动（步数递增）

考点：[[20-考点/判断推理/图形推理/位置规律-双元素沿路径循环移动（步数递增）|图形推理 / 位置规律-双元素沿路径循环移动（步数递增）]]


**问法模型**：元素组成相同、仅小元素位置变化且首图给出'编号+箭头路线' → 分元素追踪沿路线的移动步数，归纳步数递增规律后外推定位问号处位置

## 推理链
1. 第1步：各图形元素组成相同（同一立方体框架＋一个黑点'·'＋一个白圆'○'，仅位置改变），优先考虑位置规律；第一幅图标出1~8号位置及箭头，是两元素移动的路线图
2. 第2步：分别追踪两个元素——黑点从1号位置出发，沿箭头路线依次移动2、3、4步；白圆从2号位置出发，依次移动1、2、3步
3. 第3步：归纳规律——两种元素的移动步数均逐次加1（2,3,4,…与1,2,3,…），故问号处黑点应在前一幅基础上走5步、白圆应走4步
4. 第4步：沿箭头路线循环计数（超过8个位置则循环取余）：黑点累计走2+3+4+5=14步，14÷8余6，即从1号位走6步，落在7号位置；白圆累计走1+2+3+4=10步，10÷8余2，即从2号位走2步，落在4号位置
5. 第5步：逐项对照——A、B项黑点不在7号位置，排除；C项白圆不在4号位置，排除
6. 第6步：D项黑点在7号位置、白圆在4号位置，同时满足两条移动规律，故正确答案为D

**最快解法**：⚡ 双元素分轨追踪＋步数等差外推：黑点步数为2,3,4→下次走5步到7号位，先排除A、B；白圆步数为1,2,3→下次走4步到4号位，再排除C，锁定D。先验黑点再验白圆，两轮排除即可

## 易错点
- ⚠ 只验证单一元素：黑点位置对但白圆位置不对的干扰项（如C）易误选，必须黑点、白圆两条规律同时满足
- ⚠ 忽略闭合循环计数：累计步数14、10已超过8个位置，需沿路线循环（取余）数步，按直线硬数会定位错误
- ⚠ 步数规律看错：误以为每次移动步数恒定，而实际是2,3,4,5与1,2,3,4的逐次递增数列

### 题干
“·”和“○”按箭头指示路线运动。下列选项中，符合所给图形的变化规律的是：

### 选项
- A. A
- B. B
- C. C
- D. D　✅

### 官方解析
元素组成相同，优先考虑位置规律。观察发现，黑点沿着第一幅图的箭头指示路线运动，从1号位置开始分别移动2、3、4步，因此问号处黑点位置应为前一幅图中黑点沿箭头路线走5步，应在7号位置，排除A、B两项；白圆沿着第一幅图的箭头指示路线，从2号位置开始分别移动1、2、3步，因此问号处白圆位置应为前一幅图中白圆沿箭头路径走4步，应在4号位置，排除C项。
故正确答案为D。
