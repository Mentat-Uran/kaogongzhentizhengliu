# 样式规律-求异（去同存异）与位置规律（顺时针旋转90°）复合

考点：[[20-考点/判断推理/图形推理/样式规律-求异（去同存异）与位置规律（顺时针旋转90°）复合|图形推理 / 样式规律-求异（去同存异）与位置规律（顺时针旋转90°）复合]]


**问法模型**：九宫格'选择最合适的一个填入问号处，使之呈现一定的规律性'且元素组成相似 → 横行验证'图1⊕图2（求异）后顺时针旋转90°＝图3'的复合规律，第三行套用比对选项

## 推理链
1. 第1步：题干为九宫格，每行图形元素组成相似（第一行黑白三角形块、第二行线条图、第三行黑白填充图），优先考虑样式规律；第二行相同线条重复出现，锁定'加减同异'方向
2. 第2步：按'九宫格优先看横行'验证第一行：图1与图2叠加去同存异（求异），再将结果顺时针旋转90°，恰好得到图3
3. 第3步：用第二行验证规律：图1（折线+斜线）与图2（方框+内折线）求异后顺时针旋转90°，与图3吻合，规律成立
4. 第4步：第三行应用规律：将图1（拱形轮廓、顶部白色三角缺口、下端尖角）与图2（右上、左下两个黑色扇形）重叠，公共黑色部分相消（同色相消即求异）
5. 第5步：将求异结果整体顺时针旋转90°，得到'拱顶在上、顶部留白色三角缺口、底部呈双尖'的图形
6. 第6步：对照选项：A（圆+四角星镂空）、D（四角星）形状不符；C与B互为上下颠倒（对应旋转方向看反的错误结果），只有B符合'求异+顺时针旋转90°'，故选B

**最快解法**：⚡ 复合规律口诀'先求异、再旋转'：第三行图1与图2重叠去同存异 → 整体顺时针旋转90° → 直接比对选项锁B；并用C（逆时针/未正确旋转的干扰项）反向排除

## 易错点
- ⚠ 只做求异、忘记再旋转，直接拿求异结果比对选项而误选干扰项
- ⚠ 旋转方向看反：B与C互为颠倒图形，若按逆时针旋转会误选C
- ⚠ 第三行为黑白填充图，求异时忽略'同色相消'规则，误将两图重叠的公共黑色区域保留
- ⚠ 九宫格惯性按列或整体找规律，漏掉'优先看横行'的验证路径

## 母题抽象
> 🧩 当九宫格（或两组图）元素组成相似、同位置线条/色块重复出现时，优先验证'图1与图2去同存异后再顺时针旋转90°＝图3'的复合规律，并在问号所在行套用比对选项

**同类特征**：九宫格、元素组成相似、相同线条/色块重复出现、黑白填充图形、去同存异（求异）、顺时针旋转90°
