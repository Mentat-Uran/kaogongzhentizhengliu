# 数量规律-面数量+二级辨析（面与外框形状对应）

考点：[[20-考点/判断推理/图形推理/数量规律-面数量+二级辨析（面与外框形状对应）|图形推理 / 数量规律-面数量+二级辨析（面与外框形状对应）]]


**问法模型**：填入问号处使之呈现规律性 → 元素不同且属性无规律时先数面，面数相同再用'与外框同形面的个数'做二级辨析锁定答案

## 推理链
1. 第1步：四幅图元素组成不同，对称、曲直等属性无明显统一规律，但每幅图均由多个封闭空间构成，优先考虑数量规律中的'面'
2. 第2步：数面：图1（圆环加内部分割线）、图2（矩形框内分割）、图3（直角三角形内分割）、图4（扇形内加弧线与方框）均恰好由5个面组成 → 问号处图形面数应为5
3. 第3步：面数规律不足以唯一锁定答案，继续找二级规律：每幅图内部都恰有一个面与外框形状（含比例）完全相同——图1有小圆、图2有小矩形、图3有小直角三角形、图4有小扇形
4. 第4步：逐项数面：D项面数不为5，排除
5. 第5步：A项面数符合5，但其内部没有任何一个面与外框L形同形状、同比例，排除
6. 第6步：B项中存在多个面与外框形状相同，不符合题干'每图恰有一个同形面'的规律，排除；C项5个面且恰有一个面与外框L形同形同比例，符合全部规律，当选

**最快解法**：⚡ 排除法+二级辨析口诀：'面数相同找同形'——先数面，题干均5个面，排除面数不符的D；再数'与外框同形面的个数'：A为0个、B为多个、C恰为1个，直接锁定C

## 易错点
- ⚠ 只数面数就停手：A、B、C面数同为5，仅靠一级数量规律无法锁定答案，必须进行'与外框同形面个数'的二级辨析
- ⚠ 忽略'比例'限定：形状相似但被拉伸变形（比例不同）的面不算'与外框形状相同'，易误选A
- ⚠ 面数数错：把内部交错的线条误判成多余封闭区域，可能误排除正确选项或误留D

## 母题抽象
> 🧩 当题干各图元素组成不同、属性无统一规律且都含多个封闭空间时，先统一数面数量；若面数相同仍有多个选项符合，则验证'恰有一个面与外框形状（含比例）相同'的个数规律

**同类特征**：元素组成不同、属性无明显规律、多个封闭空间、面数量均为5、有面与外框同形、二级规律辨析

### 题干
从所给的四个选项中，选择最合适的一个填入问号处，使之呈现一定的规律性：

### 选项
- A. A
- B. B
- C. C　✅
- D. D

### 官方解析
元素组成不同，且无明显属性规律，考虑数量规律。每幅图形均存在多个封闭空间，优先数面。观察发现，题干中四幅图形均由5个面组成，排除D项。继续观察发现，题干中每幅图形均有一个与外框形状相同的面，A选项不存在与外框形状、比例都完全相同的面，B选项存在多个面的形状与外框形状相同，只有C项满足题干要求。

故正确答案为C。
