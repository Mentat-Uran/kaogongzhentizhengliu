# 样式规律-黑白运算（定义叠加）

考点：[[20-考点/判断推理/图形推理/样式规律-黑白运算（定义叠加）|图形推理 / 样式规律-黑白运算（定义叠加）]]


**问法模型**：“符合所给图形规律的一项”＋两组图类比结构 → 先由第一组图1与图2逐位叠加归纳黑白运算规则，再同位套用到第二组排除选答案

## 推理链
1. 第1步：两组图形元素组成相似，每组内部轮廓与分割区域完全相同（第一组为十字五格、第二组为倒凸五格），但黑块个数无恒定数量规律，排除数量类，锁定样式类黑白运算
2. 第2步：第一组图1与图2按相同位置叠加得到图3，逐位比对提炼规则：白+黑=白、黑+白=白、白+白=黑、黑+黑=黑，可记为口诀“同色得黑、异色得白”
3. 第3步：将该规则同位套用到第二组：图1与图2逐格做黑白运算
4. 第4步：逐位运算结果：顶部、中心、底中均按“黑+白=白”变白，底行左右两端按“白+白=黑”变黑，即黑块只出现在底行左右两端，其余全白
5. 第5步：与选项对照：仅C项为“上白、中白、底行黑白黑”；A项多出下中黑块，B项顶部为黑，D项黑块位置为下中黑，均不符，故选C

**最快解法**：⚡ 口诀法＋反色技巧：由第一组归纳出“同色得黑、异色得白”（白+白=黑、黑+黑=黑，异色得白）；第二组图2全白，等价于图1每个位置直接取反色（黑变白、白变黑），黑块仅剩底行左右两端，秒选C

## 易错点
- ⚠ 先入为主套用“黑+白=黑”的常规叠加直觉；本题规则反直觉（白+黑=白、白+白=黑、黑+黑=黑），必须先从第一组逐位验证规则再套用
- ⚠ 只数黑块个数找数量规律，或忽略“轮廓相同、元素组成相似”这一提示样式类叠加的信号
- ⚠ 逐位运算后黑块位置记错（正确结果黑块仅在底行两端），误选A、D等形近项

## 母题抽象
> 🧩 当两组图形轮廓相同、分割区域一致且黑块分布无数量规律时，用黑白运算：先拿第一组图1+图2=图3逐位总结每种颜色组合的运算结果（警惕“同色得黑、异色得白”这类反直觉规则），再同位套用到第二组验证选项

**同类特征**：两组图轮廓与分割区域完全相同、黑白块数量无规律、元素组成相似、两组图类比式问法、需同位逐格叠加验证

### 题干
符合所给图形规律的一项是        。

### 选项
- A. A
- B. B
- C. C　✅
- D. D

### 官方解析
元素组成相似，优先考虑样式规律。题干每组图形轮廓和分割区域相同，且黑块数量没有规律，考虑黑白运算。第一组图形的运算规则为：白+黑=白，黑+白=白，白+白=黑，黑+黑=黑；第二组图形运用此规律，只有C项符合。
故正确答案为C。
