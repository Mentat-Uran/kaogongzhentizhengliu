# 图形推理-对称性（对称轴数量与方向）

考点：[[20-考点/判断推理/图形推理/图形推理-对称性（对称轴数量与方向）|图形推理 / 图形推理-对称性（对称轴数量与方向）]]


**问法模型**：九宫格'选最合适图形填问号'且元素凌乱 → 按行观察属性规律，本题用对称轴数量+方向遍历模型

## 推理链
1. 第1步：九宫格图形元素组成凌乱，先考虑属性规律；第一行第一个图形'0X□'为轴对称图形，提示从对称性切入
2. 第2步：横向逐行数对称轴数量并记录方向：第一行三图对称轴均为1条，方向依次为横向、斜向、竖向
3. 第3步：第二行验证规律：三图对称轴也均为1条，方向依次为横向（交叉缎带'X'）、斜向（圆与括号钩组合）、竖向（带内折线的矩形），'横斜竖'遍历规律成立
4. 第4步：第三行应用规律：图1圆内含'Λ'对称轴为竖向，图2多层'L'嵌套对称轴为斜向，故问号处应填对称轴方向为横向的图形
5. 第5步：逐项检验选项：A项仅是中心对称图形（无横向对称轴），排除
6. 第6步：B项为轴对称且对称轴方向横向，保留；C项为中心对称图形，排除；D项对称轴为竖向，排除，故选B

**最快解法**：⚡ 对称轴方向口诀法：每行'横、斜、竖'各出现一次，第三行已出现竖、斜，缺'横'——快速排除中心对称的A、C与竖轴的D，直接锁定B

## 易错点
- ⚠ A、C两项是中心对称图形，易被误当成'对称图形'而误选，需区分轴对称与中心对称
- ⚠ 第二行第二个图形（圆、括号、钩、圆的组合）易误判为不对称或竖轴，实际沿斜向对称
- ⚠ 九宫格易先按列或整体找规律而走弯路，应先横向按行观察属性遍历

## 母题抽象
> 🧩 当九宫格图形元素凌乱但每个图形都具有对称特征时，按行统计对称轴数量与方向，若前两行呈'横/斜/竖'遍历规律，则在第三行选出缺失方向的对称轴图形即可

**同类特征**：九宫格、元素组成凌乱、轴对称图形、对称轴方向横斜竖遍历、中心对称作干扰项

### 题干
从所给四个选项中，选择最合适的一个填入问号处，使之呈现一定的规律性：

### 选项
- A. A
- B. B　✅
- C. C
- D. D

### 官方解析
元素组成凌乱，考虑属性变化。九宫格题先横向找规律，很显然九宫格中第一个图形为轴对称图形，因此先考虑对称性。第一行图形对称轴数量均为一条，方向分别为横、斜、竖，第二行图形对称轴数量也均为一条，方向分别为横、斜、竖，因此第三行图形也应满足此规律。第三行图形对称轴方向分别为竖、斜、？，因此“？”处应选一个对称轴方向为横向的图形。A项为中心对称图形，排除；B项为对称轴方向为横向的轴对称图形，保留；C项为中心对称图形，排除；D项为对称轴方向为竖向的轴对称图形，排除。
故正确答案为B。
