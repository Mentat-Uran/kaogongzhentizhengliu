# 属性规律-曲直性

考点：[[20-考点/判断推理/图形推理/属性规律-曲直性|图形推理 / 属性规律-曲直性]]


**问法模型**：九宫格'根据图形规律填入问号处最合适的一项'→元素组成不同优先看属性规律，按行归纳曲直性并锁定问号处图形的曲直构成

## 推理链
1. 第1步：九宫格中元素组成不同（第一行：立方体、菱形、箭头；第二行：月亮、笑脸、云朵气泡；第三行：禁止符、太阳、问号），优先考虑属性规律
2. 第2步：题干同时出现全直线图形与全曲线图形，优先考虑曲直性；九宫格优先按横行观察
3. 第3步：第一行立方体、菱形、箭头均由纯直线构成；第二行月亮、笑脸、云朵气泡均由纯曲线构成
4. 第4步：第三行图1禁止符（圆环为曲线+斜杠为直线）、图2太阳（圆为曲线+三角形光芒为直线）均由曲线和直线共同构成，故？处也应为'曲+直'图形
5. 第5步：对照选项：A双圆为全曲线，B方框四向箭头为全直线，C四角星为全直线，D圆柱（顶底椭圆为曲线、侧边为直线）为曲直结合
6. 第6步：只有D满足第三行'曲线+直线'的规律，故选D

**最快解法**：⚡ 属性规律口诀'元素组成不同看属性，见全直全曲查曲直'：横行扫描发现第一行全直、第二行全曲、第三行前两图均'曲+直'，直接在选项中找曲直结合图形——排除全曲的A、全直的B和C，秒选D（圆柱=椭圆曲线+侧边直线）

## 易错点
- ⚠ 竖列看规律导致找不到统一规律，九宫格默认优先横行观察
- ⚠ 误判圆柱的曲直构成：圆柱不只有曲线（顶底椭圆），侧面轮廓为直线段，属'曲+直'图形；同理注意B中四方箭头均为折线直线而非曲线
- ⚠ 被对称性、封闭性等其他属性干扰，未抓住题干'全直与全曲分行呈现'对曲直性的强提示

## 母题抽象
> 🧩 当九宫格元素组成不同且图中混排全直线、全曲线图形时，按行看曲直性：若前两行分别为'全直''全曲'，则第三行通常为'曲直结合'，在选项中找同时含直线与曲线的图形即可

**同类特征**：九宫格、元素组成不同、第一行全直线图形（立方体/菱形/箭头）、第二行全曲线图形（月亮/笑脸/云朵气泡）、第三行前两图曲直混合（禁止符/太阳）、选项设置全曲、全直、曲直结合对比（圆柱）

### 题干
根据图形规律，填入问号处最合适的一项是：

### 选项
- A. A
- B. B
- C. C
- D. D　✅

### 官方解析
图形元素组成不同，优先考虑属性规律。观察发现，题干出现全直线、全曲线图形，优先考虑曲直性。九宫格优先横行看，第一行图形均由直线组成，第二行图形均由曲线组成，第三行图1和图2均由曲线和直线构成，故？处图形应该由曲线和直线构成，只有D项符合规律。
故正确答案为D。
