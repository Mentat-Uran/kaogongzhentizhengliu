# 图形推理-样式规律-去同存异（九宫格按行叠加运算）

考点：[[20-考点/判断推理/图形推理/图形推理-样式规律-去同存异（九宫格按行叠加运算）|图形推理 / 图形推理-样式规律-去同存异（九宫格按行叠加运算）]]


**问法模型**：九宫格问'呈现一定规律性'且各格图形元素组成相似→按行观察，对前两图做'去同存异'运算求第三图

## 推理链
1. 第1步：题干为3×3九宫格，每格均由线段构成的几何图形，元素组成相似、线条有重合，优先考虑样式规律中的图形运算
2. 第2步：按行观察第一行：图1（含对角交叉线等）与图2（尖角折线加横线）重合的线段去掉，各自独有的线段保留拼合，恰好得到图3，即'去同存异'
3. 第3步：用第二行验证：图1的V形折线与图2的斜线加短竖线做去同存异，剩余线段与图3（右下角小三角形）完全吻合，规律成立
4. 第4步：将规律迁移到第三行：图1的对角斜线与图2的尖角折线无重合线段，'去同'后各自独有线段全部保留
5. 第5步：把第三行前两图的独有线段拼合，得到向上的山形（V形）折线图形
6. 第6步：对照选项：A为一段残斜线缺线、C多出右侧竖线、D多出左侧对角三角形，均与运算结果不符，排除，锁定B

**最快解法**：⚡ 图形运算口诀'去同存异'+按行验证：先看第一行图1与图2重合线消去、剩余线拼成图3，确认规律后第三行直接叠画前两图并划掉公共线，剩余线条与B项吻合，秒选B

## 易错点
- ⚠ 把'去同存异'（相同线去掉）误用成'求同存异'（相同线保留），方向搞反得出含公共线的错误选项
- ⚠ 观察路径错误：按列或对角找规律，绕远且易得出伪规律；应先按行验证
- ⚠ 去同存异要求线段位置精确重合才去掉，近似相似不可去，易误删独有线段而错选A或D

## 母题抽象
> 🧩 当九宫格图形'元素组成相似、线条有重合'时，优先按行做去同存异运算，并用其中一行验证规律成立后，再对问号所在行前两图做同样运算

**同类特征**：九宫格、元素组成相似、线段拼合类图形、去同存异、按行规律、样式类叠加运算

### 选项

- B. B　✅

### 官方解析
元素组成相似，优先考虑样式规律。观察发现，第一行前两个图形去同存异得到第三个图形，经验证第二行图形满足此运算规律，第三行前两个图形去同存异得到B项。
故正确答案为B。
