# 三视图-俯视图规律（立体积木九宫格，横行俯视图一致+层数二级验证）

考点：[[20-考点/判断推理/图形推理/三视图-俯视图规律（立体积木九宫格，横行俯视图一致+层数二级验证）|图形推理 / 三视图-俯视图规律（立体积木九宫格，横行俯视图一致+层数二级验证）]]


**问法模型**：九宫格立体积木图形问'？'处呈现规律 → 优先横行找共性：先比对俯视图投影是否相同，再用层数/方块数做二级排除

## 推理链
1. 第1步：题干为九宫格，每格均由若干小正方体堆叠成的立体图形，第一行三个图形均为2层结构，优先横行观察
2. 第2步：采用三视图中的俯视图（从上往下投影）对比：第一行三个立体图形的俯视图（底面占格形状）完全相同
3. 第3步：验证第二行，三个图形的俯视图同样彼此相同，确认'每行俯视图一致'规律成立
4. 第4步：第三行应用规律：'？'处图形的俯视图必须与第三行前两个图形的俯视图相同，据此排除俯视图形状不符的A、C两项
5. 第5步：启用二级规律验证：题干已给八个图形均为2层高，D项立体图形为3层高，排除D
6. 第6步：仅剩B项同时满足'俯视图与第三行相同'且'层数为2层'，故选B

**最快解法**：⚡ 横行找规律法+二级排除：先横向比对每行三图俯视图是否相同（排A、C），再用'层数均为2层'这一特征秒杀D，锁定B

## 易错点
- ⚠ 只凭立体外形'看起来相似'比对，忽略投影角度，未严格按俯视图底面占格形状对比
- ⚠ 找到俯视图规律后停止验证，未做层数等二级辨析，可能误选形态相近的干扰项
- ⚠ 九宫格习惯性先看竖列规律，本题规律需横行观察才成立

## 母题抽象
> 🧩 当九宫格出现小正方体堆叠的立体图形时，优先横行比对'俯视图是否相同'，若仍有剩余选项再用层数/方块个数等细节特征二级排除

**同类特征**：九宫格立体积木图形、小正方体堆叠、俯视图逐行相同、立体图形均为2层、需二级规律收尾、横行找规律
