# 位置规律（翻转+叠加+整体旋转）

考点：[[20-考点/判断推理/图形推理/位置规律（翻转+叠加+整体旋转）|图形推理 / 位置规律（翻转+叠加+整体旋转）]]


**问法模型**：两组图问号处填入最合适图形呈现规律性 → 元素组成相同，先用第一组归纳位置变换规则，再类比迁移到第二组验证选项

## 推理链
1. 第1步：两组图形元素组成相同（相同的方格与黑白三角形/线条），只是位置变化，优先考虑位置规律
2. 第2步：拆解第一组规则——图一的第二格（中间格）向下翻转，与原来的第一格、第三格叠加后得到图二，图二再整体旋转得到图三
3. 第3步：将规则迁移到第二组，注意格子结构不同：第二组为四个格子（2×2），对应关系改为图一的上面两个格子向下翻转，与原来的下面两个格子叠加后得到图二
4. 第4步：第二组图二再整体旋转（图形朝向、条纹线条方向随之改变）即为问号处图形
5. 第5步：逐项对照A、B、C、D，按'上两格翻转叠加+整体旋转'后的阴影三角形朝向与条纹方向检验，只有D项符合
6. 第6步：故问号处选D

**最快解法**：⚡ 规则迁移法+整体轮廓对照：先由第一组锁定'翻转→叠加→整体旋转'三步链，再看第二组图二的外框长宽比例与阴影/条纹朝向，将图二在脑中整体旋转后与选项比对轮廓和朝向，直接锁定D

## 易错点
- ⚠ 只做翻转叠加、漏掉最后'整体旋转'这一步，误选形状相似但朝向未变的选项
- ⚠ 第二组格子数由3格变为4格，机械照搬'第二格向下翻转'而未调整为'上面两格向下翻转'
- ⚠ 忽略条纹线条方向随整体旋转而改变，仅凭阴影三角形位置排除会误判A/C

## 母题抽象
> 🧩 当题干为两组图且元素组成相同、呈方格拼合结构时，先用第一组归纳'局部翻转+叠加+整体旋转'的位置变换链，再按第二组的格子数类比迁移规则，验证选项的轮廓与阴影朝向

**同类特征**：元素组成相同、两组图对比出规律、三格与四格方格拼合结构、黑白三角形与条纹阴影、局部翻转叠加、末位图整体旋转

### 题干
从所给的选项中，选择最合适的一个填入问号处，使之呈现一定的规律性：

### 选项
- A. A
- B. B
- C. C
- D. D　✅

### 官方解析
图形元素组成相同，优先考虑位置规律。观察发现，第一组图中，图一的第二格向下翻转并与原来的第一格、第三格叠加后得到图二，图二再整体旋转得到图三；第二组图应用此规律，但第二组图没有三格，而是四个格子，观察前两幅图发现，图一的上面两个格子向下翻转与原来的下面两个格子叠加后得到图二，图二再整体旋转得到问号处图形，只有D项符合。
故正确答案为D。
