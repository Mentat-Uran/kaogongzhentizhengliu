# 位置规律（上下翻转+分行平移复合变化）

考点：[[20-考点/判断推理/图形推理/位置规律（上下翻转+分行平移复合变化）|图形推理 / 位置规律（上下翻转+分行平移复合变化）]]


**问法模型**：问'符合所给图形变化规律的选项'且元素组成相同 → 优先考虑位置规律，先辨整体翻转再分行追踪平移

## 推理链
1. 第1步：四幅已知图与选项中元素完全相同（花朵、白圆、黑方块、三角、W等），元素组成相同，优先考虑位置规律
2. 第2步：相邻两图对比，发现整幅图先发生上下翻转（各行元素上下颠倒）
3. 第3步：翻转后各行再按不同规则平移——第一行和第三行的元素每次向下平移一格；第二行和第四行的元素每次向上平移一格；第五行的元素（花朵）每次向右平移两格，到头循环走
4. 第4步：将'先上下翻转+分行平移'的复合规律从第四幅图继续推一步，得到？处各元素的目标位置
5. 第5步：逐项对照，A、C、D中均有元素所在行位或列位与推导结果不符，只有B项完全符合翻转加平移后的位置
6. 第6步：故正确答案为B

**最快解法**：⚡ 标记元素追踪法：每行选一个代表元素（如第五行花朵、黑方块、白圆），先对比相邻图确定'整图上下翻转'，再数各元素移动格数得出口诀'1、3行下移1格，2、4行上移1格，5行右移2格循环'，末图直接套口诀锁定B

## 易错点
- ⚠ 忽略'先翻转后平移'的复合顺序，只按单一平移规律看图易误选
- ⚠ 第五行元素是右移两格且到头循环，易错看成移一格或忘记循环回绕
- ⚠ 图中元素多，只盯单个元素验证，某个元素位置碰巧吻合就误选A/C/D

## 母题抽象
> 🧩 当题干出现元素组成相同的网格图且问变化规律时，先判断整体翻转/旋转，再分行追踪各元素的方向与步数（注意循环走位），用末图验证选项。

**同类特征**：元素组成相同、5×5网格多元素分布、整图上下翻转、分行不同方向平移、到头循环走、问？处图形

### 题干
下列选项中，符合所给图形变化规律的是        。

### 选项
- A. A
- B. B　✅
- C. C
- D. D

### 官方解析
元素组成相同，优先考虑位置规律。观察发现，题干图形每次先上下翻转，然后位于第一行和第三行的元素每次向下平移一格，位于第二行和第四行的元素每次向上平移一格，位于第五行的元素每次向右平移两格（到头循环走），故？处图形也应符合此规律，只有B项符合。

故正确答案为B。
