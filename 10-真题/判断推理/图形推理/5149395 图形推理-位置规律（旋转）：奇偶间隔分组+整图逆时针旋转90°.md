# 图形推理-位置规律（旋转）：奇偶间隔分组+整图逆时针旋转90°

考点：[[20-考点/判断推理/图形推理/图形推理-位置规律（旋转）：奇偶间隔分组+整图逆时针旋转90°|图形推理 / 图形推理-位置规律（旋转）：奇偶间隔分组+整图逆时针旋转90°]]


**问法模型**：'填入问号处使之呈现一定的规律性'且各图均为3×3黑白格、元素组成基本相同→优先考虑位置规律；单一相邻规律不通时，按奇偶项间隔拆成两条链找旋转规律

## 推理链
1. 第1步：题干为5+1个3×3黑白格图形，数黑块发现图1、3、5均为5个黑块，图2、4均为4个黑块，'元素组成'奇偶不同，提示按1-3-5与2-4-6间隔分成两条链
2. 第2步：先用位置规律验证奇数链：图1'黑白黑/黑黑白/白黑白'整体逆时针旋转90°（新图第1行=原图第3列自上而下）得'黑白白/白黑黑/黑黑白'，恰为图3
3. 第3步：图3再逆时针旋转90°得'白黑白/白黑黑/黑白黑'，恰为图5，确认奇数链规律为'依次逆时针旋转90°'
4. 第4步：把同一规则套到偶数链验证：图2'黑白黑/白白黑/白黑白'逆时针旋转90°得'黑黑白/白白黑/黑白白'，与图4完全一致，规律成立
5. 第5步：问号为第6项，应等于图4'黑黑白/白白黑/黑白白'再逆时针旋转90°：第1行取原图第3列得'白黑白'，第2行取第2列得'黑白白'，第3行取第1列得'黑白黑'
6. 第6步：逐项比对选项：A'白黑白/黑白白/黑白黑'与推导结果完全吻合；B第2行为'黑黑白'、C和D第1行均为'白黑黑'，均不满足该旋转结果，故选A

**最快解法**：⚡ 奇偶分组+旋转口诀法：先数黑块个数（5/4）发现奇偶组成不同→分两条链；用图3→图5锁定'逆时针转90°'规律；对图4直接套用'新行=旧列自上而下'逐行写出，一秒锁定A

## 易错点
- ⚠ 把6个图当作一条连续规律找，忽略黑块个数（奇数项5个、偶数项4个）这一奇偶间隔分组的强提示
- ⚠ 旋转方向看反：题干为逆时针旋转90°，若误用顺时针旋转或左右/上下翻转，会错选B或D等干扰项
- ⚠ 3×3网格旋转时行列对应关系搞错（逆时针是新图第1行=原图第3列自上而下，而非自下而上），逐格比对时出错

## 母题抽象
> 🧩 当一组黑白格/小元素图形'整体元素组成基本相同'但相邻两项直接看规律不通时，先按元素个数或特征做奇偶间隔分组，再用'顺/逆时针旋转90°'逐项验证子链，最后把规律套用在问号前一项上推出答案

**同类特征**：3×3黑白格矩阵、黑块个数奇偶不同（5个/4个）、奇偶间隔两条链（1-3-5、2-4-6）、整图逆时针旋转90°、问号位于第6项（偶数链延伸）
