# 数量规律-复合考点（面数量+直线数量，按行规律）

考点：[[20-考点/判断推理/图形推理/数量规律-复合考点（面数量+直线数量，按行规律）|图形推理 / 数量规律-复合考点（面数量+直线数量，按行规律）]]


**问法模型**：九宫格'填入问号处使之呈现规律性'→ 元素组成不同先看数量规律，按行找第一规律粗筛，剩两项再换第二数量规律做二级辨析

## 推理链
1. 第1步：九宫格各图元素组成不同，无对称、开闭等明显属性规律，且每个图都含封闭面，转向数量规律
2. 第2步：先数封闭面：第一行三图面数依次为2、3、4，呈等差递增；第二行验证同为2、3、4，规律成立
3. 第3步：第三行前两图面数为2、3，故问号处应有4个封闭面，A、C项面数不符，排除A、C
4. 第4步：剩余B、D进行二级辨析，题干图形均为全直线图形，数直线：第一行直线数均为7
5. 第5步：第二行直线数均为8，第三行前两图直线数均为9，故问号处直线数应为9
6. 第6步：B项直线数为8不符合，排除；D项直线数为9且面数为4，双规律均满足，当选

**最快解法**：⚡ 两步排除法（先面后线）：第一步数面——每行2、3、4递增，问号需4个面，排除A、C；第二步数直线——每行直线数恒定7、8、9，第三行需9条，排除B（8条），锁定D

## 易错点
- ⚠ 只数面数排除A、C后就直接选B、D中靠前的一项，缺二级辨析（直线数）这一步
- ⚠ 数直线时把拐角处的连续折线误数成两条，或漏数独立短线，导致7/8/9的常数规律看不出来
- ⚠ 按列找规律（列上面数为2、3、4不成规律）而误判规律方向

## 母题抽象
> 🧩 当九宫格图形元素组成不同、属性无规律且各图均含封闭面时，先按行数面找等差（或常数）规律粗筛，若剩余两项再换第二条数量规律（线/点/角）做二级辨析验证

**同类特征**：九宫格、元素组成不同、全直线图形、均有封闭面、面数按行2/3/4递增、直线数按行恒定7/8/9

### 题干
从所给的四个选项中，选择最合适的一个填入问号处，使之呈现一定的规律性：

### 选项
- A. A
- B. B
- C. C
- D. D　✅

### 官方解析
元素组成不同，无明显属性规律，优先考虑数量规律。图形均有封闭面，九宫格第一行图及第二行图封闭面数量均分别为2、3、4；第三行前两幅图封闭面数量分别为2、3，故处封闭面数量应为4，排除A、C两项。再次观察题干，图形均为全直线图形，考虑数直线。九宫格第一行图直线数均为7；第二行图直线数均为8；第三行前两幅图直线数均为9，故处图形直线数也应为9，B项直线数为8，排除；D项直线数为9，符合规律，当选。
故正确答案为D。
