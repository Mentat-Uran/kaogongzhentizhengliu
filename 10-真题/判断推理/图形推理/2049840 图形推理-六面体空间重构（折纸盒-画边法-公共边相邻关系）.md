# 图形推理-六面体空间重构（折纸盒-画边法-公共边相邻关系）

考点：[[20-考点/判断推理/图形推理/图形推理-六面体空间重构（折纸盒-画边法-公共边相邻关系）|图形推理 / 图形推理-六面体空间重构（折纸盒-画边法/公共边相邻关系）]]


**问法模型**：题干给不规则展开图、问'哪项能由它折叠而成'→ 对每个选项先锁定构成面，再用画边法比对公共边上的图案特征逐项排除

## 推理链
1. 第1步：展开图为非常规排布，先给各面标号（E、F、G、H、I、K），并给相邻面公共边编号（边1、边4等），选项面内含黑色三角形、白色三角形、直角梯形、黑色菱形等图案特征。
2. 第2步：对每个选项判定其由哪三个面构成：A项由面E、G、H构成，B项由面I、G、F构成，C项由面H、I、K构成，D项由面E、K、F构成。
3. 第3步：验A项——展开图中边4与面H的白色三角形相邻，而A选项中边4与面H的黑色三角形相邻，公共边两侧图案不符，排除。
4. 第4步：验B项——展开图中边1与面I直角梯形的短直角边相邻，而B选项中边1与直角梯形的底边相邻，梯形方位错位，排除。
5. 第5步：验C项——展开图中同一条1号边对应面K，而选项中1号边对应面H，相邻面的相对位置发生改变，排除。
6. 第6步：验D项——面E、K、F两两相邻，各公共边两侧图案的指向与展开图完全一致，当选。

**最快解法**：⚡ 画边法（公共边比对）：给展开图每条公共边编号后逐项比对——A比边4旁是白三角还是黑三角、B比边1旁是梯形短直角边还是底边、C比1号边通向面K还是面H，三处均不符直接排除得D

## 易错点
- ⚠ 展开图不是标准1-4-1型，套用'相对面排除法'失效，必须改用画边/相邻面法
- ⚠ 面H中白色三角形与黑色三角形容易看混，A项正是考'同一边旁黑白三角之别'
- ⚠ 直角梯形的'短直角边'与'底边'易混淆，B项考此细节；还须留意展开图与选项中面的旋转方向

## 母题抽象
> 🧩 当展开图排布不规则、选项三个面两两相邻时，用画边法：给展开图与选项的公共边编号，比对同一条边两侧图案的特征与指向，凡有一处不符即排除，全部吻合者为答案

**同类特征**：纸盒外表面展开图、六面体空间重构、非常规展开图（非十字型）、公共边画边编号、面内图案指向（黑/白三角、直角梯形）、相邻面相对位置

### 题干
左边给定的是纸盒的外表面，下列哪项能由它折叠而成？

### 选项
- A. A
- B. B
- C. C
- D. D　✅

### 官方解析
本题考查六面体的空间重构。
A项：由面E、面G和面H构成，对题干和选项画边如下，题干边4与面H的白色三角形相邻，A选项边4与面H的黑色三角形相邻，与展开图不一致，排除；

B项：由面I、面G和面F构成，对题干和选项画边如下，题干边1与面I的直角梯形的短直角边相邻，B选项边1与直角梯形的底边相邻，与展开图不一致，排除；

C项：由面H、面I、面K构成，对题干和选项画边如下，展开图中1号边对应面K，选项中1号边对应面H，与展开图不一致，排除；

D项：由面E、面K、面F构成，与展开图一致，当选。
故正确答案为D。
