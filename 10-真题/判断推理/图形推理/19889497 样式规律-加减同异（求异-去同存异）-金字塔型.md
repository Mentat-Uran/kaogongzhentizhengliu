# 样式规律-加减同异（求异-去同存异）-金字塔型

考点：[[20-考点/判断推理/图形推理/样式规律-加减同异（求异-去同存异）-金字塔型|图形推理 / 样式规律-加减同异（求异/去同存异）-金字塔型]]


**问法模型**：“符合所给图形规律的一项”且图形呈金字塔分层排布 → 自下而上逐层对相邻两图做求异（去同存异）运算推至塔顶

## 推理链
1. 第1步：题干图形为金字塔结构（底层3图、中层2图、顶层问号），元素组成相似且相同线条重复出现，优先考虑样式规律中的加减同异
2. 第2步：塔型题自下向上找规律：下层相邻两图之间进行运算得到上面一幅图，本题运算方式为求异（去同存异）
3. 第3步：验证规律——第三行图1与图2求异得到第二行图1，第三行图2与图3求异得到第二行图2（公共线条相消，差异线条保留，黑点随线条一起参与运算）
4. 第4步：按同一规律，将第二行左、右两个图形叠加后去掉公共部分，保留不同线条，即为问号处图形
5. 第5步：逐项对照——A、B、C的线条组合与求异结果不符，D项与第二行两图求异所得图形完全一致

**最快解法**：⚡ 去同存异口诀＋自下而上：直接把中层两图叠放，删去重合线条，剩下的差异线条即为问号图形，对照选项秒选D

## 易错点
- ⚠ 忽略金字塔结构方向，误从上往下找规律
- ⚠ 误用求同（去异存同）而非求异，导致公共线条被保留
- ⚠ 黑点等小元素也随线条参与求异运算，容易遗漏点的加减

## 母题抽象
> 🧩 当图形呈金字塔/塔状分层排列且相邻图形线条大量重合时，用'自下而上相邻两图去同存异'逐层运算推至塔顶得答案

**同类特征**：金字塔分层排布、相同线条重复出现、元素组成相似、去同存异运算、黑点小元素参与运算、自下而上推导

### 题干
符合所给图形规律的一项是        。

### 选项
- A. A
- B. B
- C. C
- D. D　✅

### 官方解析
元素组成相似，且相同线条重复出现，优先考虑样式规律中的加减同异。本题为金字塔类题目，要自下向上找规律，即下层相邻的两幅图之间进行运算得到上面的一幅图。观察发现，第三行的图1和图2求异后可得第二行的图1，第三行的图2和图3求异后可得第二行的图2，则问号处也应遵循此规律，即第二行的两个图形求异后得到问号处图形，只有D项符合。
故正确答案为D。
