# 图形共性-特定元素存在（每图均含三角形）

考点：[[20-考点/判断推理/图形推理/图形共性-特定元素存在（每图均含三角形）|图形推理 / 图形共性-特定元素存在（每图均含三角形）]]


**问法模型**：问号处填入图形使之呈现规律 → 元素组成不同且属性数量无规律时，整体寻找各图共同包含的特定形状（三角形）

## 推理链
1. 第1步：题干四图依次为'三角形加穿出底线线条的树形图'、'飞镖形'、'鼻子为三角形的笑脸'、'数字4形'，元素组成不同，对称性、封闭区域数等属性与数量规律均不成立
2. 第2步：换角度找整体共性——逐一扫视每个图形内部的形状，发现图1有三角形轮廓、图2由三角形拼接、图3含三角形鼻子、图4左侧是三角形，即'每个图形中都存在三角形'
3. 第3步：逐项检验选项：A项为圆+两个圆形眼睛+弧线嘴，无三角形；B项为圆被十字分割，形成的是4个扇形（圆弧边）而非三角形；C项为沙漏形，由上下两个三角形拼接而成；D项为百分号（两圆+斜线），无三角形
4. 第4步：只有C项包含三角形，与题干'每图均含三角形'的共性一致，故选C

**最快解法**：⚡ 共性元素扫描法：属性、数量规律全失效时，整体扫题干找共同形状（三角形），直接排除A、D（无三角形）和B（十字分圆是扇形不是三角形），锁定C

## 易错点
- ⚠ B项圆内十字线易误看成4个'三角形'，实际是4个扇形（底边为圆弧）
- ⚠ 只纠结单图的数量/属性规律（如对称、面数），忽略'每图均含同一形状'的整体共性
- ⚠ A项笑脸与题干第3图风格相似，易因'外观像'误选，但相似不等于含三角形

## 母题抽象
> 🧩 当题干图形元素组成不同、属性与数量规律均不成立时，改找'每幅图共同包含的特定形状元素'，在选项中选唯一含该形状的一项

**同类特征**：元素组成不同、属性数量无规律、每图均含三角形、飞镖形/笑脸/数字4、B项扇形陷阱、整体共性观察
