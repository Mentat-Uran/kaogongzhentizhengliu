# 图形推理-位置规律（左右翻转-上下翻转）

考点：[[20-考点/判断推理/图形推理/图形推理-位置规律（左右翻转-上下翻转）|图形推理 / 图形推理-位置规律（左右翻转/上下翻转）]]


**问法模型**：两组图类推填问号 → 元素组成相同时优先找位置规律，用第一组确定变换链条后逐步套用到第二组

## 推理链
1. 第1步：两组图形元素组成完全相同（第一组均为六等分圆+✱+□，第二组均为四宫格+两个○），优先考虑位置规律
2. 第2步：观察第一组图1→图2：图1中□在左上、✱在右上，图2中✱在左上、□在右上，左右元素镜像互换，即左右翻转
3. 第3步：验证图2→图3：图2经上下翻转后✱移至左下、□移至右下，与图3位置一致，确认链条为'图1左右翻转→图2上下翻转→图3'
4. 第4步：第二组套用同一链条：图1两个○都在右列（右上、右下），左右翻转后到左列（左上、左下），与图2吻合
5. 第5步：图2再经上下翻转：左上○与左下○互换位置，仍在左列，故问号处应为'左列上下两格各一个○'的图形
6. 第6步：对照选项：A两○在上排、B两○在下排、C两○在左列、D两○在右列，只有C符合

**最快解法**：⚡ 位置规律口诀+对应套用：先由第一组锁定'左右翻→上下翻'链条，第二组图2（○在左列）上下翻转后○仍在左列（上下互换但都在左侧），直接锁定C；注意C与图2同形是因○上下对称分布，属正常结果

## 易错点
- ⚠ 发现'上下翻转后图形和图2看起来一样'而怀疑规律出错，实际因○均匀分布在左列上下两格，翻转后自然同形
- ⚠ 把左右翻转误当180°旋转处理，若按旋转会误选D（右列）
- ⚠ 只看第一组规律不回验第二组图1→图2，链条套错一步即错选A或B

## 母题抽象
> 🧩 当两组图元素组成完全相同、仅位置改变时，先在第一组确定'图1→图2→图3'的翻转/旋转链条，再将链条逐步套用到第二组求出问号图形

**同类特征**：两组图类推、元素组成相同、位置变化、左右翻转、上下翻转、问号处求规律延续

### 题干
从所给的四个选项中，选择最合适的一个填入问号处，使之呈现一定的规律性：

### 选项
- A. A
- B. B
- C. C　✅
- D. D

### 官方解析
元素组成相同，优先考虑位置规律。观察发现，第一组图形中，图1经左右翻转后得到图2，图2经上下翻转后得到图3；第二组图形也应符合相同的规律，图1经左右翻转后得到图2，图2经上下翻转后得到？处图形，只有C项符合。
故正确答案为C。
