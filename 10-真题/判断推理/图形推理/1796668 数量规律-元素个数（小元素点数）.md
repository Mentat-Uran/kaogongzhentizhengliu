# 数量规律-元素个数（小元素点数）

考点：[[20-考点/判断推理/图形推理/数量规律-元素个数（小元素点数）|图形推理 / 数量规律-元素个数（小元素点数）]]


**问法模型**：问号处填入最合适图形使之呈现规律性 → 元素组成不同且均为多个小元素构成时，优先数每幅图的元素个数找交替/等差规律

## 推理链
1. 第1步：题干四幅图元素组成各不相同，且每幅图都由多个独立小元素构成，提示优先考虑数元素的个数和种类
2. 第2步：采用数元素个数法逐一清点：图1为小正方形+大正方形+圆+小三角形共4个；图2为3个大小不同的圆共3个
3. 第3步：图3为大圆+四边形+相交圆+小三角形共4个（注意有元素相交，勿漏数）；图4为两个小正方形+一个大正方形共3个，得到数列4、3、4、3
4. 第4步：个数呈4、3、4、3交替规律，问号处应含4个元素
5. 第5步：对照选项：A为3个三角形，B为正方形+圆+三角形+直角三角形共4个，C为3个圆，D为2个正方形，仅B含4个元素，故选B

**最快解法**：⚡ 数元素个数法：快速点数题干四图小元素个数得4、3、4、3交替，直接在选项中找含4个元素的图形，一眼锁定B

## 易错点
- ⚠ 误去数元素的种类数或纠结形状属性（如全圆、全三角），忽略本题只考个数的交替规律
- ⚠ 图3中存在元素相交重叠，容易漏数被压住/相交的小元素而数错
- ⚠ 只对个别图形数个数、未形成完整数列就匆忙选答案，需四个图全部数完确认4、3、4、3的交替规律

## 母题抽象
> 🧩 当题干各图元素组成不同且均由多个零散小元素构成时，优先数元素个数；若个数呈交替或等差规律，则按目标数量直接在选项中筛选对应元素个数的图形

**同类特征**：元素组成不同、每图由多个小元素构成、个数呈4、3、4、3交替、存在元素相交/重叠的干扰、选项间元素个数差异明显
