# 图形间关系-相交（公共边数量等差递增）

考点：[[20-考点/判断推理/图形推理/图形间关系-相交（公共边数量等差递增）|图形推理 / 图形间关系-相交（公共边数量等差递增）]]


**问法模型**：『选择最合适的一个填入问号处使之呈现一定的规律性』且每幅图均为两个图形拼合 → 优先考虑图形间关系，清点两图形的公共边数量找规律

## 推理链
1. 第1步：题干5幅已知图均由两个图形拼合而成（图1三角形+菱形、图2四边形+三角形、图3房形+三角形、图4双箭头+正方形、图5凹形+菱形），元素组成不同，考虑图形间关系
2. 第2步：观察两图形的接触方式：图1中三角形与菱形仅相交于一个点（顶点接触），公共边为0；图2起两图形改为相交于线（存在重合公共边）
3. 第3步：逐图清点公共边数量：图1为0条（点接触），图2为1条，图3为2条，图4为3条，图5为4条，构成0、1、2、3、4的等差递增数列
4. 第4步：由等差规律推定，问号处两图形的公共边数量应为5条
5. 第5步：逐项对照选项：A、B、C项两图形的公共边数量均不足5条，予以排除；D项两图形相交且公共边恰为5条，符合规律

**最快解法**：⚡ 数公共边法：先看图1发现是点接触（公共边0），再看图2~5公共边依次为1、2、3、4，确认等差递增，直接在选项中数公共边=5的图形，锁定D

## 易错点
- ⚠ 误以为规律只是'相交于线'，忽略真正考点是公共边数量的等差递增，错选仅满足'相交于线'的A/B/C项
- ⚠ 忽视图1为点接触、公共边为0，把数列起点当作1，导致规律整体错位、推不出答案
- ⚠ 将公共边数量与交点数量、图形自身边数混淆，数错重合线段条数

## 母题抽象
> 🧩 当题干每幅图都由两个图形拼合（相交）且元素组成不同时，优先考虑图形间关系，依次清点两图形的公共边（重合线段）数量，若呈等差数列则按递增到问号处的数值在选项中找对应图形

**同类特征**：每幅图均为两个图形拼合、元素组成不同、图1为点接触其余为线接触、公共边数量依次递增、等差数列规律、问号处填图形

### 题干
从所给的四个选项中，选择最合适的一个填入问号处，使之呈现一定的规律性:

### 选项
- A. A
- B. B
- C. C
- D. D　✅

### 官方解析
元素组成不同，且每幅图均为两个图形拼合而成，优先考虑图形间关系。观察发现，图1中两个图形相交于点，而图2、3、4、5中两个图形均相交于线，且相交于线的数量依次为1、2、3、4。由此可知，题干中两个图形的公共边数量依次为0、1、2、3、4，故问号处两个图形公共边的数量应为5，只有D项符合。
故正确答案为D。
