# 数量规律-部分数（汉字题：部首分组、笔画数作辅助排除）

考点：[[20-考点/判断推理/图形推理/数量规律-部分数（汉字题：部首分组、笔画数作辅助排除）|图形推理 / 数量规律-部分数（汉字题：部首分组、笔画数作辅助排除）]]


**问法模型**：三组汉字、每组两字选一个填问号 → 按汉字三大数量考点'部首归组→笔画数→部分数'逐层找组内一致规律并排除选项

## 推理链
1. 第1步：题干为三组汉字'庚、府''陆、陈''昊、？'，元素组成不同且无明显属性（对称/封闭）规律，优先考虑数量规律
2. 第2步：数部分数（不相连的独立块个数）：第一组庚=2、府=4，第二组陆=2、陈=4，规律为每组'2、4'；第三组昊='日'与'天'互不相连共2部分，故？处部分数应为4
3. 第3步：逐项数部分数：吕两个'口'分离=2、周（冂+土+口）非4、呈='口'+'王'=2，只有员='口'1+贝的'冂'框1+撇1+点1=4部分，锁定C
4. 第4步：辅助验证（出题人思路）：三组部首依次为'广''阝''口'，答案部首应为'口'，周部首为'冂'，排除B
5. 第5步：笔画数：第一组均8画、第二组均7画、第三组首字按官方口径7画，答案应为7画，吕为6画排除A，员与呈同7画，最终靠'部分数=4'排除呈（2部分），确定员，选C

**最快解法**：⚡ 排除法+汉字'部首→笔画→部分数'三步口诀：先按三组部首'广/阝/口'锁定答案含'口'排除B（周部首为冂）；再按笔画8/7/7排除A（吕6画）；最后数部分数——昊为2部分，'?处应为4'，员=4部分、呈=2部分，秒选C。若考场上只抓部分数：2、4/2、4/2、?，唯一4部分的只有员，一步锁定C

## 易错点
- ⚠ 只盯笔画数：员与呈同为7画，笔画数无法区分，必须落到'部分数'这一终极考点
- ⚠ 部分数数错：贝的撇、点与'冂'框不相连，员是4部分而非2部分；吕两个口上下分离是2部分而非4部分
- ⚠ 部首辨析缺位：周外框看似含'口'，但其部首为'冂'，易误留B项

## 母题抽象
> 🧩 当题干出现'三组汉字填问号、元素组成不同'特征时，按'部首归组→笔画数→部分数'三链依次验证排除，其中部分数（不相连独立块个数）常作为同笔画选项的终极区分器

**同类特征**：汉字图形推理、三组两字对照填问号、部首成组（广/阝/口）、组内笔画数相等（8/8、7/7）、部分数呈2、4规律、无属性规律转向数量规律

### 官方解析
解法一：元素组成不同，且无明显属性规律，优先考虑数量规律。观察发现题干第一组图的部分数分别为2、4，第二组图的部分数也分别为2、4，故？处图形的部分数应为4，只有C项符合规律。
解法二：题干图形均为汉字，观察发现第一组部首均为“广”，第二组部首均为“阝”，第三组部首应为“口”，排除B项；继续观察发现题干第一组笔画数均为8，第二组笔画数均为7，第三组第一个图的笔画数为7，故？处图形的笔画数应为7，排除A项；比较C、D两项，发现部分数存在区别，题干第一组图的部分数分别为2、4，第二组图的部分数也分别为2、4，故？处图形的部分数应为4，排除D项，只有C项满足所有规律。
故正确答案为C。
注：本题不够严谨，将汉字当成“图形”时，解法一更加严谨，但本题汉字部首相同的特征较为明显，可先根据此考点进行排除，再考虑汉字的笔画以及部分数，因此解法二可能更符合出题人的思路，故写两种解法供大家参考。
