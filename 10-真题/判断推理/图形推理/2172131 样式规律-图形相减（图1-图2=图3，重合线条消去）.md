# 样式规律-图形相减（图1-图2=图3，重合线条消去）

考点：[[20-考点/判断推理/图形推理/样式规律-图形相减（图1-图2=图3，重合线条消去）|图形推理 / 样式规律-图形相减（图1-图2=图3，重合线条消去）]]


**问法模型**：“使右边图形的变化规律与左边图形一致”且第一组已完整给出运算关系（图1-图2=图3）→ 直接套用相减去同模型：把第二组图2的线条从图1中消去，剩余线条即问号处图形

## 推理链
1. 第1步：第一组图1为“正方形＋十字中线＋两条对角线”的组合图形，官方给出运算关系“图1-图2=图3”，优先锁定样式规律中的相减（去同）：图1中与图2重合的线段被消去，剩余线段构成图3
2. 第2步：用第一组验证规律——图2所含的斜线、横线、竖线均能在图1中逐条找到并擦去，擦完恰好剩下图3的线条，确认“相减去同”成立
3. 第3步：第二组图1为正方形与四个顶点外凸的菱形叠加成的组合图形，图2为顶部带V形缺口的杯状轮廓，将图2轮廓与图1线条重合比对
4. 第4步：执行相减：与杯状轮廓重合的线段（杯口两侧横线、两侧竖边、底部斜边及被其覆盖的菱形下部线条等）全部从图1中消去
5. 第5步：清点剩余线条：菱形上端露出正方形外的“∧”形两斜线（顶点闭合）、其下方一段横线、以及下部带V形缺口的杯底轮廓
6. 第6步：逐项对照——A项左右两侧多出两条短竖线，B项缺少顶部“∧”形及横线，D项顶部“∧”顶点断开且下部线条不符，仅C项与剩余线条完全一致，故选C

**最快解法**：⚡ 相减口诀法：“图1有、图2也有的线→擦掉”。把图2杯形往图1上一扣，重合线全擦，剩下“闭合屋顶＋横线＋缺口杯底”，直接锁定C；再用三查秒排干扰项：A多竖线、B少屋顶、D顶点断开

## 易错点
- ⚠ 把“图1-图2相减”误当成整图“去同存异/求同”处理，消减方向搞反而误选B或D
- ⚠ 忽略A项图形左右两侧多出的短竖线——这些线在图1中已被图2覆盖、相减后不应保留，多线即错
- ⚠ 只看轮廓大形不看线条细节，忽略C与D在“∧”顶点是否闭合上的差别而误选D

## 母题抽象
> 🧩 两组图题中，一旦第一组呈现“图1-图2=图3”的线条消减关系，第二组就把图2轮廓向图1扣合、消去所有重合线段，剩余线条与选项比对时用“多线、少线、断点”三查快速排除

**同类特征**：两组图对照求规律、图1-图2=图3、元素组成相似考样式规律、正方形叠加外凸菱形、杯状轮廓（顶部V形缺口）、线条相减去同
