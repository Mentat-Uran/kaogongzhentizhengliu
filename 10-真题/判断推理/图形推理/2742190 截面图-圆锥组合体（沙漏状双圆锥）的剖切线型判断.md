# 截面图-圆锥组合体（沙漏状双圆锥）的剖切线型判断

考点：[[20-考点/判断推理/图形推理/截面图-圆锥组合体（沙漏状双圆锥）的剖切线型判断|图形推理 / 截面图-圆锥组合体（沙漏状双圆锥）的剖切线型判断]]


**问法模型**：给定立体（上下两圆锥顶点相接）从任意角度剖开问哪项可能是截面 → 用'刀法-线型'对应模型：逐一分析每个截面图形需要哪种剖切角度（平切/斜切/竖切/过顶点），判断能否由同一平面一次切出

## 推理链
1. 第1步：立体为上下两个圆锥在顶点相接的'沙漏'组合体，截面的边线只可能来自：上下底面（直线弦）、圆锥侧面（圆弧/椭圆弧/双曲线弧/抛物线弧）、过顶点剖切（两相交直线即三角形）
2. 第2步：调用圆锥截线规律：平行于底面切→圆；斜切不过顶点→椭圆（若同时穿过底面则得'直线+椭圆弧'的弓形）；平行于轴线竖切且偏离顶点→双曲线；平面过顶点→只能是三角形（相交两直线），绝不可能得椭圆
3. 第3步：A项两个梯形需要侧边为直线，但垂直于上下底面且偏离顶点剖切时，圆锥侧面的交线是双曲线弧而非直线，切不出梯形（应得双曲线弧配两条平行弦），排除
4. 第4步：B项上面'平顶下弧'的弓形、下面'上弧平底'的拱形，只需一个斜平面同时穿过上底面、上圆锥侧面、下圆锥侧面、下底面一次剖出，上下两部分因不经过公共顶点而分离，可截出
5. 第5步：C项上面的弓形需斜切、下面的圆需平行于底面切，两种刀法角度不同，不能存在于同一截面平面内，排除
6. 第6步：D项两个相切的椭圆要求切面经过两圆锥的公共顶点，但过顶点的平面截圆锥只能得三角形（两相交直线），切不出椭圆，排除；故只有B可由一次剖切得到

**最快解法**：⚡ 口诀排除法：记'平切得圆、斜切得椭圆、竖切偏轴得双曲线、过顶点只得三角形'；A的梯形、C的圆+弓形混搭、D的过顶点椭圆均违反口诀，一刀斜穿上下底面即可截出B的两个弓形，秒选B

## 易错点
- ⚠ 把立体图的正视图轮廓（A项两梯形）误当成竖直剖切结果，忽略圆锥侧面竖切出的边线是双曲线弧而非直线
- ⚠ 忽略'过顶点剖切只能得三角形'，误以为D项两个相切椭圆可以通过顶点切出
- ⚠ 忘记截面必须是同一平面一次剖切所得，误把两种不同刀法的结果拼接当成可行截面（如C项圆与弓形）

## 母题抽象
> 🧩 当题干出现'给定立体从任意角度剖开求截面'且立体含圆锥（或圆锥组合体）时，用'刀法-线型'对应表逐项验证：平行底面→圆、斜切不过顶点→椭圆（弧）、竖切偏离轴线→双曲线（弧）、过顶点→三角形，凡选项内不同图形需要两种不同刀法或要求过顶点出椭圆者均排除

**同类特征**：沙漏状双圆锥组合体、从任意角度剖开、截面图、弓形/梯形/椭圆/圆混合选项、同一平面一次剖切

### 题干
左边为给定的立体图，从任意角度剖开，右边哪一项可能是它的截面图？

### 选项
- A. A
- B. B　✅
- C. C
- D. D

### 官方解析
本题考查截面图，逐一分析选项。
A项：垂直于上下底面偏离圆锥顶点不能切出两个梯形，切出的应该是双曲线加两条平行线的图形，选项与题干不一致，排除；
B项：如下图所示，B项可截出，选项与题干一致，当选；
C项：要想切出上面的形状，刀片应该斜切，要想切出下面的形状，应该平行于上下底面切，不同角度切出来的面不能存在于同一平面，选项与题干不一致，排除；
D项：要想切出相切的两个椭圆，必然要经过两个圆锥顶点，但是经过顶点斜切不能切出椭圆，选项与题干不一致，排除。

故正确答案为B。
