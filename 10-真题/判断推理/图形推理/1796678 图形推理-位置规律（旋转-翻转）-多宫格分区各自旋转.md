# 图形推理-位置规律（旋转-翻转）-多宫格分区各自旋转

考点：[[20-考点/判断推理/图形推理/图形推理-位置规律（旋转-翻转）-多宫格分区各自旋转|图形推理 / 图形推理-位置规律（旋转/翻转）-多宫格分区各自旋转]]


**问法模型**：问号处填入使系列图呈现规律性，且各图元素组成完全相同 → 按位置拆分，逐区找各自的旋转/翻转规律

## 推理链
1. 第1步：题干三幅图均由田字格四个元素组成（左上半黑菱形、右上三角套黑三角、左下菱形套圆、右下圆套黑三角），元素组成完全相同，优先考虑位置变化而非样式规律
2. 第2步：分区观察：左下角'菱形套圆'在三幅图中完全一致→该位置保持不动，是定海神针；其余三个位置需分别比较相邻两图的方向变化
3. 第3步：左上角半黑菱形：图1黑半在右→图2黑半在下→图3黑半在左，规律为每次顺时针旋转90°，故问号处应为横置菱形且黑半在上，据此排除C（竖置黑半在右）、D（竖置黑半在上）
4. 第4步：右上角三角形：图1尖朝上→图2尖朝下→图3尖朝上，规律为每次旋转180°（等价于上下翻转），故问号处应尖朝下，排除A（尖朝左）、D（尖朝右）
5. 第5步：右下角圆内黑三角：图1尖朝上→图2尖朝左→图3尖朝下，规律为每次逆时针旋转90°，故问号处应尖朝右
6. 第6步：对照选项，仅B同时满足：左上黑半在上、右上尖朝下、右下尖朝右、左下不变，故选B

**最快解法**：⚡ 分区跟踪法：先锁定不动的左下角，再用'半黑菱形的黑半指向'这一最明显指针找左上规律（顺时针90°）快速排除C、D，最后用右上（180°）或右下（逆时针90°）在A、B中锁定B

## 易错点
- ⚠ 试图用一个统一规律套四个位置，忽略田字格中每个位置各有独立的旋转规则
- ⚠ 混淆旋转方向：左上是顺时针90°而右下是逆时针90°，两者方向相反，看错即误选A
- ⚠ 半黑图形应以黑色部分指向判断旋转，只看外框菱形易误判（外框旋转90°后形态重合难区分）；另外180°旋转与上下翻转在此图等价，不必纠结浪费时间

## 母题抽象
> 🧩 当题干出现'元素组成完全相同+复合/多宫格图形'特征时，用分区跟踪法，先找不变位置，再逐位置验证各自旋转/翻转规律并排除选项

**同类特征**：元素组成完全相同、田字格四分区复合图形、位置规律而非样式规律、各分区独立旋转规则、半黑图形可作指针、顺时针90°/逆时针90°/180°混合

### 题干
从所给四个选项中，选择最合适的一个填入问号处，使之呈现一定的规律性。

### 选项
- A. A
- B. B　✅
- C. C
- D. D

### 官方解析
本题元素组成完全相同，考查位置变化。每幅图都由田字格中的四个图形构成，观察左下角图形始终不动，左上角图形从左到右，依次顺时针旋转90度，可以排除C、D选项；右上角图形依次进行180度旋转（或看成依次上下翻转）；右下角图形应该是从左到右依次逆时针旋转90度，只有B项符合。
故正确答案为B。
