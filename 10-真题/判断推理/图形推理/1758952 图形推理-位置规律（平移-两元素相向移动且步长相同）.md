# 图形推理-位置规律（平移-两元素相向移动且步长相同）

考点：[[20-考点/判断推理/图形推理/图形推理-位置规律（平移-两元素相向移动且步长相同）|图形推理 / 图形推理-位置规律（平移-两元素相向移动且步长相同）]]


**问法模型**：九宫格问'符合图形变化规律的是'→按行先看元素组成是否相同，再看位置移动方向与步长，末格按规律延续作答

## 推理链
1. 第1步：逐行观察元素组成：第一行为两个相同矩形（图1三格并排、图2部分重叠、图3重合为一格），第二行为两个带小圆点的相同圆形，第三行为两个相同三角形，每行均由两个相同元素构成
2. 第2步：归纳位置规律：每行两个元素相向而行，左图向右走、右图向左走，且每次移动距离相同（第一行矩形由分离到重合即验证此规律）
3. 第3步：第二行验证规律一致性：两圆相向移动，由相交→重合（圆内两点）→再相交（两点移至外侧），方向与步长规律不变
4. 第4步：将规律应用到第三行：图1两三角形顶点相接，图2部分重叠，按相同步长继续相向移动，图3（问号处）两三角形重叠程度应比图2更大
5. 第5步：逐项对照：C项图形形状已改变（非原三角形元素），排除；A项两图形呈分离趋势（背离相向移动），排除；D项重叠程度比图2更小（相当于回退），排除
6. 第6步：B项两三角形元素不变且重叠程度大于图2，完全符合'继续以相同步长相向移动'的规律，故选B

**最快解法**：⚡ 相向平移法+排除法：先确认每行元素相同排除C（形状变了），再看第三行从图1到图2重叠加深，'步长相同继续相向'则图3重叠应更深，A是分开、D是重叠变浅，只有B重叠更深且元素不变，锁定B

## 易错点
- ⚠ 只盯图形轮廓相似而忽略移动方向，误选A（两三角形分开不符合相向而行）
- ⚠ 忽略'每次移动距离相同'的步长条件，误选D（重叠程度比图2更小，等于反向移动）
- ⚠ 只看重叠交叠线条的数量，忽略元素本身必须保持不变，误选C（图形已变成两个沙漏状）

## 母题抽象
> 🧩 当九宫格（或三格组）每行由两个相同元素组成且位置逐格变化时，先按行确认'元素相同'排除形变项，再判定相向/背向移动方向与步长是否恒定，末格按延续规律锁定答案

**同类特征**：九宫格按行找规律、每行两元素形状相同、两元素相向移动、每次移动距离相同、重叠程度逐格递变、问号处求延续规律

### 题干
下列选项中，符合所给图形的变化规律的是（  ）。

### 选项
- A. A
- B. B　✅
- C. C

### 官方解析
分析图形的特征。每行组成图形都相同，排除C项；研究图形的位置变化，每行两个元素相向而行，即左边的图向右走，右边的图向左走，而且每次移动的距离相同，排除A、D两项。
故正确答案为B。
