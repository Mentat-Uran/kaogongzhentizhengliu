# 图形推理-位置规律（平移-内外圈分块追踪）

考点：[[20-考点/判断推理/图形推理/图形推理-位置规律（平移-内外圈分块追踪）|图形推理 / 图形推理-位置规律（平移-内外圈分块追踪）]]


**问法模型**：问'？处符合图形变化规律'且各图元素组成相同 → 采用位置规律法：分内外圈、对每个黑块编号，逐一归纳'方向+步数'后代入选项排除

## 推理链
1. 第1步：题干四幅图元素组成完全相同（外圈大菱形+内圈方格+3个黑块），优先考虑位置规律而非样式规律
2. 第2步：将图形拆分为内外圈结构，把3个黑块分别编号，逐图对比每块位置变化，归纳'方向+步数'
3. 第3步：追踪黑块1——每幅图依次顺时针移动1步，则？处应移动到左侧位置，对照选项排除D
4. 第4步：追踪黑块2——每幅图依次顺时针移动1步，则？处应移动到右侧位置，对照选项排除C
5. 第5步：追踪黑块3——每幅图依次逆时针移动2步，则？处应移动到正上方偏右的位置
6. 第6步：将黑块3的位置与剩余选项（A、B）对照，只有B项三块位置全部吻合，故选B

**最快解法**：⚡ 位置规律口诀'元素相同看位置，分圈编号定步数'——先看外圈黑块1、2（均顺时针1步）快速排D、C，再用黑块3（逆时针2步）在A、B中锁定B

## 易错点
- ⚠ 忽略内外圈结构，把三个黑块当整体找统一规律，发现步数、方向不一致而误判'无规律'
- ⚠ 黑块3方向看反：其规律为逆时针移动2步，误按顺时针验证会错选其他项
- ⚠ 只验证黑块1、2排掉C、D后未再用黑块3核对A与B，凭直觉误选A

## 母题抽象
> 🧩 当题干图形元素组成相同且存在内外嵌套/分圈结构、含多个可追踪小块时，用'分圈+编号追踪'法，为每块写出'方向+步数'的移动规律，再逐项代入验证

**同类特征**：元素组成相同、内外圈嵌套结构、多个黑块分块移动、顺时针/逆时针不同步数、问号处求下一状态、逐块排除选项

### 题干
下列选项中，符合所给图形的变化规律的是（    ）。

### 选项
- A. A
- B. B　✅
- C. C
- D. D

### 官方解析
元素组成相同，优先考虑位置规律，题干图形可分内外圈，首先观察外圈图形，黑块1依次顺时针移动一步，则？处应移动到左侧的位置，排除D项。继续观察发现，黑块2依次顺时针移动一步，则？处应移动到右侧的位置，排除C项。进一步观察发现，黑块3依次逆时针移动两步，则？处应移动到正上方右侧的位置，只有B项符合。

故正确答案为B。
