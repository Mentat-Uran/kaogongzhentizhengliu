# 图形推理-位置规律（旋转-翻转）

考点：[[20-考点/判断推理/图形推理/图形推理-位置规律（旋转-翻转）|图形推理 / 图形推理-位置规律（旋转/翻转）]]


**问法模型**：元素组成相同、两行图形顺推填空 → 先在第一行归纳出'旋转+翻转'的连续变换序列，再到第二行复现前几步并对末图执行剩余一步变换

## 推理链
1. 第1步：两行图形均由'中心圆+外周带数字的椭圆'构成，元素组成完全相同，只有位置和朝向变化，优先考虑位置规律
2. 第2步：观察第一行：图1沿顺时针旋转得到图2，图2经上下翻转（沿横轴镜像）得到图3，图3经左右翻转（沿纵轴镜像）得到图4，规律为'顺时针旋转→上下翻转→左右翻转'三步连续变换
3. 第3步：将规律套用到第二行：图1沿顺时针旋转得到图2，图2经上下翻转得到图3，与第一行规律完全吻合，规律成立
4. 第4步：因此问号处图形应由第二行图3经左右翻转（沿纵轴镜像）得到
5. 第5步：逐项对照：B项出现数字'6'，而第二行仅有2/3/4/5，排除；A、C项数字位置虽近但椭圆及数字朝向与'图3左右翻转'后的镜像朝向不符，排除；D项数字位置与朝向均与翻转结果完全一致，当选

**最快解法**：⚡ 规律搬用法：第一行归纳出'顺时针旋转→上下翻转→左右翻转'三步序列，第二行复现前两步后，只需将图3左右翻转；再用细节朝向排除法区分A/C/D（B项数字'6'无中生有直接排除），秒选D

## 易错点
- ⚠ 混淆翻转轴：把'左右翻转'（沿纵轴镜像）误当作'上下翻转'（沿横轴镜像），导致变换顺序错乱
- ⚠ 只对位置不对朝向：A、C、D数字所在方位几乎相同，仅椭圆/数字镜像朝向不同，忽略细节易误选A或C
- ⚠ 未核对元素：B项'6'为无中生有，跳过元素核对直接比对位置可能误判

## 母题抽象
> 🧩 当图形元素组成相同且按行排列顺推时，用第一行归纳'旋转/翻转'的完整变换序列，第二行复现前几步并对末图执行剩余一步翻转，最后以数字/图案的镜像朝向细节排除易混选项

**同类特征**：元素组成相同、两行图形序列顺推、中心圆+外周数字椭圆、旋转与翻转复合变换、选项间仅朝向细节差异

### 官方解析
元素组成相同，优先考虑位置规律。第一行图形中，图1沿顺时针旋转得到图2，图2经过上下翻转得到图3，图3经过左右翻转得到图4；将此规律应用到第二行图形，图1沿顺时针旋转得到图2，图2经过上下翻转得到图3，因此“？”处图形应由图3经过左右翻转得到。
故正确答案为D。
