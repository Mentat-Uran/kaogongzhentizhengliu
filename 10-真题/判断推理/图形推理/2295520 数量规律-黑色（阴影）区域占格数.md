# 数量规律-黑色（阴影）区域占格数

考点：[[20-考点/判断推理/图形推理/数量规律-黑色（阴影）区域占格数|图形推理 / 数量规律-黑色（阴影）区域占格数]]


**问法模型**：『符合所给图形的变化规律』且图形为两组九宫格含黑块 → 分组数黑色区域占据的格子数，找组内恒定数量规律

## 推理链
1. 第1步：题干两组成语，每幅图均为3×3九宫格，内部为形状各异的黑色区域，无明显位置移动或样式叠加特征
2. 第2步：黑块形状杂乱无统一形状规律，转向数量规律——逐一数每幅图黑色区域占据的格子数
3. 第3步：第一组三幅图黑色区域均占3个格子（星形、折角形、对勾形均覆盖3格），组内数量恒定为3
4. 第4步：第二组前两幅图黑色区域均占6个格子（斜带形、凹形均覆盖6格），故？处黑色区域也应占6个格子
5. 第5步：逐项数选项黑色占格数：A、B、D三项黑色区域占格数均不等于6，予以排除
6. 第6步：C项黑色区域占6个格子，与第二组数量规律一致，当选

**最快解法**：⚡ 数格子法+排除法：九宫格黑块形状无位置/样式规律时直接数黑色占格数——第一组恒为3、第二组恒为6，四选项中只有C黑色区域占6格，秒选C

## 易错点
- ⚠ 被黑块的具体轮廓（星形、对角带、箭头、U形）吸引，误去考查对称性、旋转或笔画，漏掉本题真正的考点是占格数量
- ⚠ 数格时把黑块未完全填满的格子多算，或把连通黑块误当一整格，导致计数偏差而排除正确项
- ⚠ 误将第一组的数量3直接套用到第二组（两组数量规律不同：3与6），从而错选黑色仅占3格的干扰项

## 母题抽象
> 🧩 当题干是九宫格/方格网且黑色（阴影）区域形状杂乱、无位置或样式规律时，优先数黑色区域占的格数，验证『组内数量恒定、组间递变』的数量规律，再按格数排除选项

**同类特征**：两组各三幅图（3+3对比型）、每幅图为3×3九宫格、内部为形状不规则的黑色区域、黑块形状各异无平移旋转规律、可按格子计数、组内占格数恒定

### 题干
下列选项中，符合所给图形的变化规律的是      。

### 选项
- A. A
- B. B
- C. C　✅
- D. D

### 官方解析
观察题干图形，每幅图形均为九宫格，且存在黑色区域。观察发现，第一组图中，每幅图形中的黑色区域均占3个格子；第二组图中，前两幅图黑色区域均占6个格子，故？处图形黑色区域应占6个格子，只有C项符合。
故正确答案为C。
