# 样式规律-图形叠加（图1+图2=图3的直接相加）

考点：[[20-考点/判断推理/图形推理/样式规律-图形叠加（图1+图2=图3的直接相加）|图形推理 / 样式规律-图形叠加（图1+图2=图3的直接相加）]]


**问法模型**：九宫格要求同时填入1、2两处且选项为成对图形 → 优先横行找'图1+图2=图3'的叠加规律，用两处空缺逐一代入排除

## 推理链
1. 第1步：看第一行，图1（长斜线+右上端一根短线）与图2（长斜线+顶部另一侧一根短线）相加恰好拼出图3（顶部双刺形），确定本题为'横行图1+图2=图3'的直接叠加规律
2. 第2步：看第二行，图1与图3完全相同，说明填入1处的图形不能带来任何新线条，即必须被图1完全包含（就是'长斜线+右上端一根短线'本身）
3. 第3步：逐项对照1处：A项图1为顶部双刺形，会在第二行图1基础上增加新线条，排除A；B、C、D项图1均为单短线形，暂都符合
4. 第4步：看第三行，图1（双刺）与中图（另一侧单短线）相加，得到的图形应是长斜线两边各有两根短线
5. 第5步：逐项对照2处：A项图2为无刺长斜线，B、C项图2仅单边双刺，均不满足；只有D项图2是长斜线两边各有两根短线
6. 第6步：两处同时吻合的只有D，故正确答案为D

**最快解法**：⚡ 叠加规律+排除法：先用第二行'图1=图3'锁定1处不能加新线，秒排A；再直接看第三行叠加结果'两边各有两根短线'，对比选项第二幅图数短线数量与位置，锁定D

## 易错点
- ⚠ 忽略第二行隐含条件：1处图形必须是图1的子集（不加新线），只套用第一行相加规律会漏掉这个筛选
- ⚠ 第三行叠加结果误数成单边双刺而误选B或C，未注意'两边各有两根'这一位置细节
- ⚠ 九宫格思维定式去竖看或整体看，未优先横行比较导致规律难发现

## 母题抽象
> 🧩 当九宫格中某行出现'图1与图3完全相同'时，该行待填图2必为图1的子集（不得新增元素）；叠加类题目须精确清点每种小元素的根数与朝向位置再逐一排除

**同类特征**：九宫格、两处空缺需同时选择、选项为成对双图、长斜线+短线小元素、图1+图2=图3、第二行首尾图形相同

### 题干
请从所给四个选项中选择一个最合适的填入1和2处，使之呈现一定的规律性。

### 选项
- A. A
- B. B
- C. C
- D. D　✅

### 官方解析
观察图形特征，九宫格优先横着看，第一行图1和图2相加得到图3，第二行图1到图3图形没有改变，说明图2不能在图1的基础上增加新的线条，因此排除A项。第三行图1和图2相加得到的图形应该是长斜线两边各有两根短线，因此选D。
故正确答案为D。
