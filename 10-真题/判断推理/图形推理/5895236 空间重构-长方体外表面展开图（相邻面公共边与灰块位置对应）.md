# 空间重构-长方体外表面展开图（相邻面公共边与灰块位置对应）

考点：[[20-考点/判断推理/图形推理/空间重构-长方体外表面展开图（相邻面公共边与灰块位置对应）|图形推理 / 空间重构-长方体外表面展开图（相邻面公共边与灰块位置对应）]]


**问法模型**：给出带灰块的立体图形，问'哪一个可能是其外表面展开图' → 空间重构模型：先以特征面定位各面对应关系，再用公共边相邻关系（画边法）逐项排除验证

## 推理链
1. 第1步：题干长方体由8个白色正方体和4个灰色正方体粘接而成（12块，2×2×3规格），官方将外表面六面标号：正面e、顶面f、背面g、底面h、左侧面i、右侧面k，各面灰块位置固定
2. 第2步：所用规则——展开图折叠后须同时满足：①每个面的灰块分布与对应面一致；②相邻面公共边两侧图案的'挨着'关系与立体图一致（画边法/描点法）
3. 第3步：对照B、C项——展开图的6个面中不存在能对应面e（正面）和面f（顶面）的面，即灰块分布/面规格无法与题干外表面匹配，排除
4. 第4步：对照A项——6个面虽能与外表面一一对应，但题干中面e与面i的公共边应紧挨着面i中的灰色方块，A项公共边未挨着该灰块，相邻关系不符，排除
5. 第5步：对照D项——6个面与长方体外表面一一对应，面e—面i公共边紧挨面i灰块，各面灰块位置全部吻合，当选D

**最快解法**：⚡ 特征面定位+公共边排除法：先按各面灰块分布找特征面（正面e、顶面f），B、C缺对应特征面直接排除；再盯住'面e—面i'公共边是否挨着面i的灰块排除A，剩余D当选

## 易错点
- ⚠ 只核对每个面灰块的数量与排布，忽略相邻面公共边与灰块的'挨着'关系——A项正是此坑
- ⚠ 长方体面有2×2与2×3两种规格，误按正方体六面等大折叠，导致面的定位错乱
- ⚠ 同一灰色正方体可在相邻外表面同时显露灰块，逐面核对时勿把其拆成多个独立灰块；展开图中灰块随面旋转后方位会变，须折回立体验证

## 母题抽象
> 🧩 当题干出现'由黑白（灰）正方体粘成的立体+问外表面展开图'时，用'特征面定位+公共边画边法'，验证每个面灰块分布一一对应，并重点检查相邻面公共边是否紧挨特征灰块

**同类特征**：8白4灰正方体粘接成的长方体、问哪一个可能是外表面展开图、六面标号e/f/g/h/i/k逐一分析、面e与面i公共边应挨着面i中的灰色方块、各面灰块分布须一一对应、面规格含2×2与2×3两类
