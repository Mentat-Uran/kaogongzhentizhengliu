# 数量规律-面数量（封闭区域数等差递增）

考点：[[20-考点/判断推理/图形推理/数量规律-面数量（封闭区域数等差递增）|图形推理 / 数量规律-面数量（封闭区域数等差递增）]]


**问法模型**：'填入问号处使之呈现一定的规律性'且元素组成不同、封闭面明显 → 采用数面法找面数量递增规律

## 推理链
1. 第1步：题干四幅图元素组成不同（圆、三角形、正方形组合各异），优先考虑属性规律（对称/曲直/开闭），但无唯一答案
2. 第2步：观察发现题干每幅图封闭区域（面）非常明显，转向数量规律优先数面
3. 第3步：依次点数面数量——图1圆被一条横线平分为2个面；图2三角形被下方梯形及两侧竖线分隔共4个面；图3外框正方形内含三角形、小圆及底部横线共6个面
4. 第4步：面数量依次为2、4、6，呈公差为2的等差递增规律，故问号处图形应含8个面
5. 第5步：逐项点数选项——A项三角形加方框加圆共4个面；B项四边形内多线交叉分割共8个面；C项六边形放射线分割为6个面；D项五角星为6个面
6. 第6步：只有B项面数量为8，满足规律，故选B

**最快解法**：⚡ 数面法+排除法——快速点数题干面数得2、4、6，锁定公差2的等差规律，直接在选项中找8个面的图形：先排除明显为6个面的C（六角分割）和D（五角星），再排除4个面的A，仅剩B（8个面）

## 易错点
- ⚠ 图3结构复杂（外方框+内三角+小圆+底部横线），易数漏小圆内部或底部横线分割出的区域，误判面数规律
- ⚠ B项线条交叉密集，点数时易重复或遗漏某一封闭区域，应按区域逐块标记计数
- ⚠ 元素组成不同时易先纠结对称性、曲直性等属性规律而浪费时间，需及时切换到数量规律

## 母题抽象
> 🧩 当题干图形元素组成不同、属性规律无唯一答案且每幅图封闭区域明显时，优先数面数量；若面数呈等差递增，按公差外推问号处数值并选对应选项

**同类特征**：元素组成不同、封闭面明显、面数量依次递增、等差数列公差为2、属性规律无唯一答案需转数量规律
