# 位置规律-平移（内外圈分层移动：外圈顺时针3格、内圈逆时针2格）

考点：[[20-考点/判断推理/图形推理/位置规律-平移（内外圈分层移动：外圈顺时针3格、内圈逆时针2格）|图形推理 / 位置规律-平移（内外圈分层移动：外圈顺时针3格、内圈逆时针2格）]]


**问法模型**：问'最符合所给图形规律'且五幅图元素组成相同 → 优先考虑位置规律（平移/旋转），轨迹不规则时按圈层拆分分别追踪

## 推理链
1. 第1步：五幅图均为同一蜂窝状小六边形结构，仅黑块位置不同，元素组成相同 → 优先考虑位置规律而非样式规律
2. 第2步：黑块轨迹'不是常规的直线走'，且蜂窝呈环状分布 → 将小六边形分为外圈、内圈和中心三部分，内外分开看，中心位置一直保持空白
3. 第3步：追踪外圈黑块：每幅图到下一幅图，外圈黑块绕外圈依次顺时针移动3格
4. 第4步：追踪内圈黑块：每幅图到下一幅图，内圈黑块绕内圈依次逆时针移动2格
5. 第5步：由图4出发，将外圈黑块顺时针移3格、内圈黑块逆时针移2格，中心仍留空白，得到问号处图形
6. 第6步：逐项对照，A、B、C的黑块落位均与'外3顺/内2逆'的推导结果不符，只有D项完全吻合

**最快解法**：⚡ 分层标号法：给蜂窝外圈、内圈分别按顺时针编号，只盯黑块相对位置——外圈黑块每步顺时针+3格、内圈黑块每步逆时针-2格、中心恒空，直接推出问号处黑块落位锁定D

## 易错点
- ⚠ 把蜂窝黑块当整体找直线平移或黑白叠加规律，发现'不常规'后误判为无规律
- ⚠ 忽略内外圈步长与方向不同（外圈顺3、内圈逆2），套用统一移动步长导致错选
- ⚠ 把中心恒定的空白误认为是黑块移走后留下的空位，误以为中心也有块在移动

## 母题抽象
> 🧩 当题干出现蜂窝/环形等非直线点阵且元素组成相同、仅黑块位置变化时，按圈层（外圈/内圈/中心）拆分，分别追踪各圈黑块的顺/逆时针移动步数，验证步长恒定后推出答案

**同类特征**：元素组成相同、蜂窝状小六边形、仅黑块位置变化、轨迹非直线平移、内外圈分层结构、中心恒为空白

### 官方解析
元素组成相同，优先考虑位置规律。观察发现，题干的小六边形不是常规的直线走，故考虑内外分开看。如下图所示，图形的小六边形可以分为内外两圈以及中心位置的一块空白，外圈小六边形绕着外圈依次顺时针移动三格；内圈小六边形绕着内圈依次逆时针移动两格；中心位置一直保持空白，对应D项。

故正确答案为D。
