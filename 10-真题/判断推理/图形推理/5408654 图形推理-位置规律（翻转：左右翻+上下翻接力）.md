# 图形推理-位置规律（翻转：左右翻+上下翻接力）

考点：[[20-考点/判断推理/图形推理/图形推理-位置规律（翻转：左右翻+上下翻接力）|图形推理 / 图形推理-位置规律（翻转：左右翻+上下翻接力）]]


**问法模型**：“填入问号处使之呈现一定的规律性”且九宫格各图元素组成完全相同 → 按横行寻找位置规律（翻转/旋转）并套用到第三行

## 推理链
1. 第1步：九宫格中每个图形均由相同数量的小方格用连线相互连接构成，元素组成完全相同，故排除数量、样式规律，锁定位置规律
2. 第2步：九宫格优先看横行；观察第一行：图1左右（水平）翻转得到图2，图2再上下（垂直）翻转得到图3
3. 第3步：第二行验证：图1左右翻转=图2，图2上下翻转=图3，翻转接力规律成立
4. 第4步：第三行应用规律：问号处图形 = 第三行图2上下翻转（等价于图1左右翻后再上下翻）
5. 第5步：将第三行图2上下翻转后逐项对照A、B、C、D：A、B、C各行小方格与连线的相对排布均与翻转结果不符
6. 第6步：只有D项与第三行图2上下翻转后的图形完全一致，故选D

**最快解法**：⚡ 翻转接力+排除法：元素相同直接想位置规律，抓第三行图2做一次上下翻转，盯住最上、最下两行小方格连线的走向（上下错位关系）作锚点与选项比对，一步锁定D

## 易错点
- ⚠ 看错翻转顺序：规律是“图1左右翻→图2、图2上下翻→图3”，误当成图1连续两次翻转或对图1直接上下翻会选错
- ⚠ 小方块连线网络整体样式相近，肉眼易混各行连线的错位位置，应抓上下边行连线的方向作锚点逐一比对
- ⚠ 忽略“元素组成相同→优先位置规律”的信号，误去数方块个数或连线数量走入死胡同

## 母题抽象
> 🧩 当九宫格各图元素组成完全相同（仅朝向/位置变化）时，先横行验证“左右翻转→上下翻转”的接力规律，再对第三行套用并排除，答案即图2的上下翻转

**同类特征**：九宫格、元素组成相同、位置规律、左右翻转、上下翻转、连线小方块网络

### 题干
从所给的四个选项中，选择最合适的一个填入问号处，使之呈现一定的规律性：

### 选项
- A. A
- B. B
- C. C
- D. D　✅

### 官方解析
元素组成相同，优先考虑位置规律。九宫格优先看横行，观察发现，第一行中，第一个图形左右翻转得到第二个图形，第二个图形上下翻转得到第三个图形；第二行符合此规律，第三行应用此规律，只有D项符合。
故正确答案为D。
