# 属性规律-对称性（轴对称与中心对称的行规律）

考点：[[20-考点/判断推理/图形推理/属性规律-对称性（轴对称与中心对称的行规律）|图形推理 / 属性规律-对称性（轴对称与中心对称的行规律）]]


**问法模型**：九宫格问'填入问号处使之呈现规律性'且元素组成不同 → 按横行归纳属性规律（对称性类型）并找第三行所缺类型

## 推理链
1. 第1步：图形元素组成不同，无相同元素可数，优先考虑属性规律（对称性）
2. 第2步：九宫格优先按横行看，判定每个图形的对称类型：第一行为直角三角形（仅轴对称）、平行四边形（仅中心对称）、箭头形（仅轴对称），呈'仅轴—仅中心—仅轴'规律
3. 第3步：代入第二行验证：五边形（仅轴对称）、两个对顶小三角形组合（仅中心对称）、碗形/半圆（仅轴对称），与第一行规律一致
4. 第4步：第三行已有五角星（仅轴对称）、S形双箭头曲线（仅中心对称），按规律问号处应填'仅轴对称'图形
5. 第5步：逐项对照——A项循环双箭头仅中心对称，B项禁止符号既轴对称又中心对称，D项对话气泡为不对称图形，C项心形有一条竖直对称轴、仅轴对称，故选C

**最快解法**：⚡ 对称类型四分法+排除：对每个图形快速判定'仅轴/仅中心/既轴又中心/不对称'，发现每行规律为'仅轴—仅中心—仅轴'，第三行缺'仅轴对称'，直接锁定C（心形只有一条竖直对称轴）

## 易错点
- ⚠ B项禁止符号既是轴对称又是中心对称，只验证出有对称轴就误选B，忽略'仅轴对称'的限定
- ⚠ A项循环箭头是仅中心对称而非轴对称，需实际旋转180°或找对称轴验证，凭直觉易判错
- ⚠ 只看列不看行：本题若按竖列找规律会偏离命题人设置的横向循环规律

## 母题抽象
> 🧩 当九宫格图形元素组成不同且图形轮廓简洁、对称特征明显时，按横行归纳每图属于'仅轴对称/仅中心对称/双对称/不对称'中的哪一类，找出问号处所缺的对称类型即可秒杀

**同类特征**：九宫格、元素组成不同、三角形/平行四边形/五角星等规则图形、对称性差异明显、每行呈'仅轴—仅中心—仅轴'循环、选项含双对称干扰项

### 题干
从所给的四个选项中，选择最恰当的一个填入问号处，使之呈现一定的规律性。

### 选项
- A. A
- B. B
- C. C　✅
- D. D

### 官方解析
图形元素组成不同，优先考虑属性规律。九宫格优先按横行来看，第一行中，三幅图依次为仅轴对称图形、仅中心对称图形、仅轴对称图形；代入第二行验证，第二行与第一行规律相同。因此，第三行也应该满足此规律，问号处应该填入一个仅轴对称的图形。A项为仅中心对称图形，B项为既轴对称又中心对称图形，D项为不对称图形，只有C项符合题干规律。
故正确答案为C。
