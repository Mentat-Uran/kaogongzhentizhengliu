# 位置规律（平移+移动元素轮换、重叠遮挡）

考点：[[20-考点/判断推理/图形推理/位置规律（平移+移动元素轮换、重叠遮挡）|图形推理 / 位置规律（平移+移动元素轮换、重叠遮挡）]]


**问法模型**：“符合所给图形的变化规律”→元素组成相同优先看位置规律：给元素编号，逐图追踪哪个元素平移、平移几步

## 推理链
1. 第1步：题干四个图形（含问号前一幅）均由同样的4个长方形组成，仅位置和重叠方式不同，元素组成相同，优先考虑位置规律
2. 第2步：在图一中从左到右给长方形编号为1、2、3、4，观察相邻图形发现每次只有一个长方形发生平移，重叠处图形中出现表示遮挡的横线
3. 第3步：图一到图二，1号长方形向右平移两步，与后方长方形重叠，其余长方形位置不变
4. 第4步：图二到图三，2号长方形向右平移两步，移动元素依次为1号→2号，呈现按编号顺序轮换的规律
5. 第5步：依此规律，图三到图四（问号处）应由3号长方形向右平移两步，形成新的重叠形态
6. 第6步：逐项对照：A项正是3号长方形向右平移两步后的重叠图形；B项长方形完全分离无重叠、C项与D项移动的元素或重叠位置均不符合该规律，排除后锁定A

**最快解法**：⚡ 编号追踪法（位置平移口诀）：按图一从左到右编号1-4，发现“每次一个元素、按1→2→3轮换、每次向右平移两步”，问号处轮到3号平移两步，直接锁定A

## 易错点
- ⚠ 重叠遮挡使画面中长方形看似“减少”，误判为数量规律而排除含重叠线的正确选项
- ⚠ 只盯住某一个长方形追踪，未发现移动元素是按1→2→3依次轮换的
- ⚠ 把平移步数看成一步而非两步，误选移动距离不符的C或D

## 母题抽象
> 🧩 当题干图形元素组成相同但出现重叠、错位时，先按初始位置给元素编号，验证“每次一个元素按固定步数平移、移动对象依次轮换”的规律，再推出问号处该轮到的移动结果

**同类特征**：元素组成相同、4个长方形组合图形、图形中出现重叠横线、位置平移、移动元素依次轮换、问号求下一幅图

### 题干
下列选项中，符合所给图形的变化规律的是      。

### 选项
- A. A　✅
- B. B
- C. C
- D. D

### 官方解析
元素组成相同，优先考虑位置规律。每个图形都是由4个长方形组成的，在图一中，从左到右依次给长方形编号为1、2、3、4，图一到图二1号长方形向右平移两步，图二到图三2号长方形向右平移两步，图三到图四应该是3号长方形向右平移两步，只有A项符合。
故正确答案为A。
