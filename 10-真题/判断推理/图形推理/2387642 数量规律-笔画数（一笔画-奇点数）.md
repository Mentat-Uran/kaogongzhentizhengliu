# 数量规律-笔画数（一笔画-奇点数）

考点：[[20-考点/判断推理/图形推理/数量规律-笔画数（一笔画-奇点数）|图形推理 / 数量规律-笔画数（一笔画/奇点数）]]


**问法模型**：选择最合适的一个填入问号处使之呈现规律性 → 元素组成不同且属性规律不通时，转数笔画数（奇点数）找常数规律

## 推理链
1. 第1步：题干五幅图元素组成不同，对称性、封闭性、曲直性等属性规律不明显，转向数量规律
2. 第2步：图①为五角星（一笔画经典特征图），图②出现明显端点（端点即奇点，提示数奇点定笔画）
3. 第3步：逐一验证：图①奇点为0，图②图③图④图⑤奇点数均为0或2且图形连通，题干五图均能一笔画出
4. 第4步：归纳规律：问号处也应填入一笔画图形
5. 第5步：逐项数奇点：A项奇点多、分断明显为三笔画，B项为三笔画，C项为两笔画
6. 第6步：D项（两个相邻正方形共用一条边，类似'日'字变形）奇点数恰为2且连通，为一笔画，符合规律

**最快解法**：⚡ 奇点数法：数每个图形中引出奇数条线的点（端点必是奇点），奇点数为0或2且连通即一笔画；题干五图全为一笔画，快速扫选项——A、B端点多直接排除，C为两笔画排除，D只有2个奇点为一笔画，锁定D

## 易错点
- ⚠ 凭图形简繁直觉判断笔画，忽略'奇点数为0或2且图形连通'的严格判定标准
- ⚠ A、B项线条少看似简单，误当作一笔画，实际端点（奇点）多
- ⚠ 图③、图⑤交点处引出线条数数错，把偶点（如中点连接处引出4条线）误判为奇点
- ⚠ 忽略一笔画前提是图形连通，误把不连通图形也算作一笔画

## 母题抽象
> 🧩 当题干图形元素组成不同、属性规律（对称/封闭/曲直）均不通，且出现五角星、明显端点、'日'字及'中'字变形等特征图时，用奇点数法定笔画数，验证题干笔画数一致（如全为一笔画）后，在选项中找相同笔画数的图形

**同类特征**：五角星、明显端点、元素组成不同、无属性规律、多交点连通图形、问号延续规律
