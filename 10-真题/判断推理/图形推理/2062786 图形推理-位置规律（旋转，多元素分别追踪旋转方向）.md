# 图形推理-位置规律（旋转，多元素分别追踪旋转方向）

考点：[[20-考点/判断推理/图形推理/图形推理-位置规律（旋转，多元素分别追踪旋转方向）|图形推理 / 图形推理-位置规律（旋转，多元素分别追踪旋转方向）]]


**问法模型**：两组图，问第二组的第三个图形 → 元素组成相同优先看位置规律，按长短给每条线/弧标号，逐元素追踪旋转方向与角度并外推

## 推理链
1. 第1步：第一组三个图形均由最长、较长、最短三条折线段构成，元素组成相同，仅朝向和位置变化，锁定位置规律
2. 第2步：分组分别追踪，第一组中'最长图形每次顺时针旋转90度'，'较长图形'与'最短图形'均每次逆时针旋转90度
3. 第3步：第二组图形由三条不同长度的弧线构成，图1到图2：最长弧线逆时针旋转90度、较长弧线逆时针旋转90度、最短弧线逆时针旋转90度，即三条弧线整体呈逆时针90°的同步旋转
4. 第4步：将第二组图2中的三条弧线各自再逆时针旋转90度：外层长弧从上方拱形转到左侧、开口朝右，内层中短弧随之转到偏左内侧
5. 第5步：逐项对照：A项外弧开口朝下、B项为同心多层拱形、C项长弧位置开口朝向与推演不符，均排除
6. 第6步：D项长弧位于左侧开口朝右、内部弧线排布与'图2三条弧线各逆时针旋转90°'完全吻合，故选D

**最快解法**：⚡ 元素标号追踪法（排除法辅助）——把第二组图1的三条弧线按长短标为'长/中/短'，确认图1到图2每条弧线均逆时针转90°，再将图2三条弧线各逆时针转90°，与选项比对：仅D项长弧在左侧开口朝右且内外弧相对位置保持，直接锁定D

## 易错点
- ⚠ 三条线长短相近时看错长短，把旋转主体（长/中/短）分配错，导致方向推错
- ⚠ 第一组与第二组旋转方向不同（第一组长线顺时针、其余逆时针；第二组统一逆时针），直接照搬第一组规律会误选
- ⚠ 把图形的整体变化误看成翻转/镜像，旋转应以每条线的开口或凸起朝向为基准判定顺逆时针

## 母题抽象
> 🧩 当图形'元素组成相同、仅朝向位置变化'且由多条可按长短区分的线段/弧线构成时，给每条线标号并分别追踪其'旋转方向+角度'，两组规律分别归纳后外推到问号处逐项比对

**同类特征**：元素组成相同、多条长短不同的线段/弧线、两组图对照找规律、位置规律-旋转90度、逐元素追踪旋转方向、第一组与第二组规律独立

### 题干
从所给四个选项中，选择最合适的一个填入问号处，使之呈现一定的规律性：

### 选项
- A. A
- B. B
- C. C
- D. D　✅

### 官方解析
元素组成相同，优先考虑位置规律。第一组图中，最长的图形每次顺时针旋转90度，较长的图形每次逆时针旋转90度，最短的图形每次逆时针旋转90度。第二组图中，图1到图2，最长的图形逆时针旋转90度，较长的图形逆时针旋转90度，最短的图形逆时针旋转90度，则？处也应保持此规律，得到D图形。
故正确答案为D。
