# 立体拼合-由两视图及全等小块反推小立体（数小立方体+旋转试装）

考点：[[20-考点/判断推理/图形推理/立体拼合-由两视图及全等小块反推小立体（数小立方体+旋转试装）|图形推理 / 立体拼合-由两视图及全等小块反推小立体（数小立方体+旋转试装）]]


**问法模型**：给出组合体的正面、后面两个视图，说明整体由三个完全相同的小立体组成，求小立体形状 → 采用'立体拼合'模型：先按方块总数÷3锁定单块方块数，再以'正面有缺口、后面完整'两个轮廓为约束，将选项旋转试装验证

## 推理链
1. 第1步：读正面视图——整体为4列×3层的墙面轮廓，第二层中部有一处凹陷缺口，缺口内能看到更靠后的方块表面，说明缺口是'凹进一层'而非贯穿空洞；读后面视图——4列×3层轮廓完整无缺，说明从背面看每个位置均有方块遮挡
2. 第2步：由'三个完全相同的小立体'可知选项图形需满足：单块含5个小立方体（3×5=15，与两视图所示整体规模相符），且'完全相同'指全等，允许旋转（翻转）后重合再拼
3. 第3步：以两个约束核验选项——拼好后正面投影必须恰好在中部第二层出现缺口，背面投影必须完整；同时三块咬合后不得重叠、不得悬空出多余方块
4. 第4步：排除A/B/C——A的台阶形、B的横排叠块形、C的竖直三连柱形，无论怎样旋转，三块相拼要么无法补齐背面完整轮廓，要么正面无法恰好留出中部缺口，凹凸结构对不上
5. 第5步：验证D——D为'2×2方块体加侧面凸出1块'的五连立方体，三块经旋转可层层咬合：两块交叠搭出正面中部缺口，第三块补足背面，拼合结果与题干正面、后面两视图完全一致（与官方解析拼合图吻合）
6. 第6步：得出结论，该小立体图形为D

**最快解法**：⚡ 拼合试装法（凹凸咬合）+数块校验：先确认每块含5个小立方体，再抓住'正面中部缺口、背面完整'这一对约束，将D项图形在脑中旋转三次互相咬合拼装验证；A/B/C用凹凸形状差异快速排除

## 易错点
- ⚠ 把正面缺口当成贯穿的空洞，误以为该位置前后都没有方块，导致整体方块数数错
- ⚠ 只验证正面轮廓是否相似，忽略背面轮廓必须完整这一约束，误选形状接近的选项
- ⚠ 忽略'完全相同'允许旋转（翻转）后再拼，误以为三块必须同向摆放，从而觉得无解或排除正确答案

## 母题抽象
> 🧩 当题干给出立体组合体的两个相对视图并说明由n个全等小立体组成时，先由小立方体总数÷n确定单块方块数，再用两视图的轮廓及缺口位置作约束，对选项逐个旋转试装，唯一能同时满足两视图的即为答案

**同类特征**：立体拼合、正面和后面两个视图、由三个完全相同的小立体组成、视图轮廓存在缺口与完整对比、小立方体个数守恒、需旋转后咬合拼装
