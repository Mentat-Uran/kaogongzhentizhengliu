# 空间重构-六面体折叠（相对面排除+公共点-公共边画边法）

考点：[[20-考点/判断推理/图形推理/空间重构-六面体折叠（相对面排除+公共点-公共边画边法）|图形推理 / 空间重构-六面体折叠（相对面排除+公共点/公共边画边法）]]


**问法模型**：“左边展开图，右边哪一项能由它折叠而成”→ 空间重构模型：先用相对面不能同时出现排除并确定各面身份，再用公共点/公共边细节验证相邻关系

## 推理链
1. 第1步：给展开图各面标号a~f，其中面a与面e“长得一样”（均含黑三角形与白三角形），面b、面d为空白面，面c为带斜线的面，面f为带“X”交叉线的面
2. 第2步：使用相对面规则——相对面在立体图中不能相邻同时出现：面c与面a相对，面b与面e相对
3. 第3步：A项出现面c、面f和带黑三角形的面，因面c与面a相对，带黑三角形的面只能是面e；展开图中面c、面e、面f存在公共点，该公共点挨着面c的斜线，而A项中公共点不挨着面c的斜线，排除
4. 第4步：B项为面b、面c和面d三个相邻面，图案与相邻关系均与展开图一致，当选
5. 第5步：C项出现面b、面d和带黑三角形的面，因面b与面e相对，带黑三角形的面只能是面a；展开图中面a与面b的公共边挨着面a的白色三角形，而C项中该公共边挨着面a的黑三角形，排除
6. 第6步：D项出现面a、面e和面f，面a与面e图案相同无法直接区分，但可确定“唯一点”；在展开图和选项中以唯一点为起点沿顺时针方向画边：展开图中只有边2挨着面f、边3挨着面b，而D项中面f同时挨着一个面的边2和另一个面的边3，相邻关系不一致，排除
7. 第7步：综合排除A、C、D，确定正确答案为B

**最快解法**：⚡ 相对面排除+公共点/画边法：先用“面c与面a相对、面b与面e相对”锁定选项中黑三角面（a或e）的身份排除A、C；再对含两个相同面的D项找“唯一点”，从该点顺时针画边比对边2、边3的相邻面，即可快速锁定B

## 易错点
- ⚠ 面a与面e图案完全相同，凭图案直接对应会出错，必须借助公共点或画边法区分
- ⚠ 公共点/公共边的细节看错：A项公共点应挨着面c的斜线、C项公共边应挨着面a的白色三角形，忽略这些细节会误选
- ⚠ 相对面判断失误（c-a相对、b-e相对），导致带黑三角形面的身份（a还是e）认定错误

## 母题抽象
> 🧩 当折纸盒题的展开图中出现两个图案完全相同的面时，先用相对面规则排除并确定各面身份，再用公共点/公共边的指向细节（或以唯一点顺时针画边）验证相邻关系，逐一排除

**同类特征**：纸盒外表面展开图、四个立体折叠选项、存在两个图案相同的面、相对面不能同时出现、公共点挨着斜线/公共边挨着黑白三角形、以唯一点顺时针画边

### 题干
左边给定的是纸盒外表面的展开图，右边哪一项能由它折叠而成？请把它找出来。

### 选项
- A. A
- B. B　✅
- C. C
- D. D

### 官方解析
将原展开图标上序号如下图，逐一进行分析。

A项：选项中出现了面c，面f和带黑三角形的面，面c与面a是相对面，故选项中带黑三角形的面是面e，在展开图中，面c、面e、面f存在公共点（如下图中蓝点所示），公共点挨着面c的斜线，选项中公共点不挨着面c的斜线，选项与题干不一致，排除；

B项：选项为面b，面c和面d，与题干一致，当选；
C项：选项中出现了面b，面d和带黑三角形的面，面b与面e是相对面，故选项中带黑三角形的面是面a，在展开图中，面a和面b有公共边，公共边挨着面a的白色三角形，选项中，面a和面b的公共边挨着面a的黑三角形，选项与题干不一致，排除；
D项：选项中出现了面a，面e和面f，面a和面e长得一样，无法区分，但是可以确定唯一点的（如下图中绿点所示）。在展开图和选项的面a和面e上，以唯一点为起始点，沿顺时针方向同时进行画边，选项中面f分别挨着一个面的边2和另一个面的边3，展开图中只有一个面的边2挨着面f，另一个面的边3挨着面b，选项与题干不一致，排除。

故正确答案为B。
