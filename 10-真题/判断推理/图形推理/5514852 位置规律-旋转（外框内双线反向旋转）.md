# 位置规律-旋转（外框内双线反向旋转）

考点：[[20-考点/判断推理/图形推理/位置规律-旋转（外框内双线反向旋转）|图形推理 / 位置规律-旋转（外框内双线反向旋转）]]


**问法模型**：“元素组成相同，选择最合适的填入问号处”→ 优先考虑位置规律：把图形拆成多个运动元素（长直线、短直线），分别追踪各自的旋转方向，再外推到问号处与选项比对

## 推理链
1. 第1步：五幅图均为“正六边形外框不变＋内部一长一短两条相交直线”，元素组成相同，锁定位置规律而非数量或样式规律
2. 第2步：将图形拆分为“长直线”与“短直线”两个独立运动元素，分别读出它们在图1至图4中的指向（注意线端伸出六边形外的“出头”段可帮助辨认指向）
3. 第3步：长直线指向依次为“竖直向上→左上→左上偏左→水平向左”，呈逐次逆时针旋转，故问号处应继续逆时针转到“左下方”
4. 第4步：短直线指向依次为“右上→偏右→右下→更陡的右下”，呈逐次顺时针旋转，问号处短线继续顺时针转动
5. 第5步：用长直线规律先排除：A、B、D三选项的长直线仍停留在“水平向左”未继续逆时针转动，均不符
6. 第6步：C项长直线恰已逆时针转至左下方，且短线方向符合顺时针延续，与两条线的规律同时吻合，故选C

**最快解法**：⚡ 排除法＋“只盯一条线先走”：先只看长直线——四幅图指向“上→左上→左→?”逐图逆时针推进，问号处必指向“左下”，一票锁定C（A/B/D的长线都还停在“水平向左”）；再回看C的短线确为顺时针延续即可放心作答

## 易错点
- ⚠ 把长短两条线当作一个整体看旋转，发现“整体忽逆忽顺”后误判无规律，转而去数交点、面数等无效规律
- ⚠ 只追踪其中一条线（如只盯短线顺时针），漏看长线反向旋转，导致在B/D等短线方向貌似吻合的干扰项上误选
- ⚠ 被线条“伸出六边形”的出头段干扰，误以为考查线与外框交点数或出头位置的变化

## 母题抽象
> 🧩 当题干图形为“外框不变＋内部多条线段位置变动”且元素组成相同时，用分轨追踪法：给每条线单独记录指向的顺/逆时针变化；若发现两条线一逆一顺反向旋转，则按各自规律外推到问号处，并优先用规律最独特的那条线排除选项

**同类特征**：元素组成相同、六边形外框固定不变、内部一长一短两条直线、线端伸出图形外（出头段）、两条线旋转方向相反（一逆一顺）、单空问号求规律延续

### 题干
从所给的四个选项中，选择最合适的一个填入问号处，使之呈现一定的规律性：

### 选项
- A. A
- B. B
- C. C　✅
- D. D

### 官方解析
元素组成相同，优先考虑位置规律。观察发现，每幅图的长直线依次逆时针旋转，短直线依次顺时针旋转，只有C项符合。
故正确答案为C。
