# 位置规律-翻转（左右翻转＋上下翻转）

考点：[[20-考点/判断推理/图形推理/位置规律-翻转（左右翻转＋上下翻转）|图形推理 / 位置规律-翻转（左右翻转＋上下翻转）]]


**问法模型**：两组图'选最合适的一个填入问号'→ 先在第一组三图中找位置变化规律（翻转的轴），第二组严格套用同一规律选答案

## 推理链
1. 第1步：两组图元素组成相同（第一组均为'六边形＋黑三角＋小圆点'，第二组均为'双圆＋内接方形对角线＋黑三角'），仅位置不同，优先考虑位置规律而非样式或数量规律。
2. 第2步：对比第一组图1与图2：黑三角由左上变右上、圆点由右上变左上，整幅图左右翻转；对比图2与图3：黑三角由右上变右下、圆点由左上变左下，整幅图上下翻转，即'图1左右翻→图2，图2上下翻→图3'。
3. 第3步：将规律迁移到第二组验证：图1黑三角在左侧，图2黑三角在右侧，正是图1左右翻转的结果，规律吻合。
4. 第4步：问号处应为图2上下翻转所得图形；上下翻转只改变上下方位、不改变左右方位，故黑三角仍应位于右侧。
5. 第5步：逐项对照：A黑三角在上、B在左、C在右、D在下，只有C符合'图2上下翻转'的落点，故选C。

**最快解法**：⚡ 位置规律口诀法：'左右翻不动上下、上下翻不动左右'。第一组验证出'先左翻再上翻'链条后，第二组直接看图2黑三角在右侧，上下翻转后仍在右侧，秒选C（A上、B左、D下均排除）；亦可用等价捷径'图3＝图1旋转180°'快速核对黑三角由左变右。

## 易错点
- ⚠ 把规律误判为'元素各自平移/轮流换位'（左→右→左），从而误选B；实际是整幅图形的翻转，黑三角与圆点（第一组）同步整体变化
- ⚠ 混淆两种翻转：误以为'上下翻转'会把三角形换到另一侧，而错选A或D；上下翻转只颠倒上下、左右方位不变
- ⚠ 只盯单一元素（黑三角）而忽略第一组小圆点的同步翻转验证，规律归纳不完整时容易在第二组套错

## 母题抽象
> 🧩 两组图题型：当两图元素组成相同、仅位置不同时，先在第一组找位置规律（翻转要定轴：先左右翻再上下翻），第二组严格套用；记住口诀'左右翻不动上下、上下翻不动左右、先左翻再上翻等价于旋转180°'，用特征元素（如黑三角）的方位直接锁定选项。

**同类特征**：元素组成相同、两组三图对照式、黑白元素位置变化、左右翻转＋上下翻转、问号处补第三幅图、无数量/样式变化

### 题干
从所给的四个选项中，选择最合适的一个填入问号处，使之呈现一定的规律性：

### 选项
- A. A
- B. B
- C. C　✅
- D. D

### 官方解析
元素组成相同，优先考虑位置规律。第一组图形中，图1左右翻转得到图2，图2上下翻转得到图3。第二组图形运用此规律，图1左右翻转得到图2，图2上下翻转得到图3，故只有C项符合此规律。
故正确答案为C。
