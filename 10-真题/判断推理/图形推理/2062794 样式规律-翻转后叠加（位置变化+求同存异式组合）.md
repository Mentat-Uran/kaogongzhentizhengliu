# 样式规律-翻转后叠加（位置变化+求同存异式组合）

考点：[[20-考点/判断推理/图形推理/样式规律-翻转后叠加（位置变化+求同存异式组合）|图形推理 / 样式规律-翻转后叠加（位置变化+求同存异式组合）]]


**问法模型**：两组图、每组已知前两图求第三图 → 先在第一组内验证'前图翻转后与自身叠加'的演变规律，再将同一规律套用到第二组

## 推理链
1. 第1步：第一组图1为单条斜折线，图2呈'Z'形，图3呈上下对称的沙漏形，三图组成相似，考虑样式规律而非数量规律
2. 第2步：验证图1→图2：将图1上下翻转后与原图1叠加，两条斜折线恰好拼成'Z'形即图2
3. 第3步：验证图2→图3：将图2左右翻转后与原图2叠加，形成上下对称的沙漏形即图3，确认规律为'后图=前图依次按上下翻转、左右翻转后与自身叠加'
4. 第4步：第二组图1为直角折角形，按规律图2应为图1上下翻转后与图1叠加所得的开口']'形，与题面图2吻合
5. 第5步：问号处应为图2左右翻转后与图2叠加：开口']'形左右翻转后两者背靠拼合，形成四周封闭、四角带小折角缺口的回字形轮廓
6. 第6步：逐项比对A/B/C/D四选项回字形轮廓上的缺口与折角细节，只有B与'图2左右翻转叠加'的结果一致，故选B

**最快解法**：⚡ 翻转叠加规律法：第一组确认'先上下翻叠加、再左右翻叠加'的顺序后，直接把第二组图2左右翻转与自身拼合，抓轮廓四角小缺口的方向排除A/C/D，锁B

## 易错点
- ⚠ 只看到图形叠加而忽略'翻转'这一前置位置变化，误找去同存异/线条相加规律
- ⚠ 翻转方向用错：第一组是先上下翻后左右翻，第二组须延续'上下翻→左右翻'的交替顺序，误用左右翻或两次同向翻会错选
- ⚠ 四个选项外形高度相似（均为回字形带缺口），不抠四角折角与缺口细节易误选A/C/D

## 母题抽象
> 🧩 当两组图'组成相似且后图明显由前图变形加倍复杂'时，用'前图翻转后与自身叠加'验证规律，翻转轴按上下、左右交替，最后以轮廓缺口/折角细节比对选项

**同类特征**：两组三图式问号处、图形组成相似、后图由前图变形叠加而来、沙漏形/回字形对称轮廓、上下翻转+左右翻转交替、选项间仅细节缺口不同

### 官方解析
