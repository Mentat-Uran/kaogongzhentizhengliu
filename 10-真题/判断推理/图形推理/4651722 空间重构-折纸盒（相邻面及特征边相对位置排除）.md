# 空间重构-折纸盒（相邻面及特征边相对位置排除）

考点：[[20-考点/判断推理/图形推理/空间重构-折纸盒（相邻面及特征边相对位置排除）|图形推理 / 空间重构-折纸盒（相邻面及特征边相对位置排除）]]


**问法模型**：'右边哪一项能由它折叠而成'→采用特征面锚定的相邻关系排除法，逐项比对特征图案的边/角与哪个面相邻

## 推理链
1. 第1步：给展开图各面标序号，锁定特征面——面a（含黑点矩形）、面f（含白圆矩形）、面b/面d（含阴影三角形）、面e及面c
2. 第2步：解题规则：折叠后每个特征图案的'关键边'（矩形长边、三角形顶点/底边）只能与展开图中原本相邻的面相接，相邻关系不符即排除
3. 第3步：验证A项——选项中面a黑点矩形的长边（线1）与面e相邻，但展开图中该长边与面b相邻，相邻关系不符，排除
4. 第4步：验证B项——选项中面f白圆矩形的长边（线2）与面c相邻，但展开图中该长边与面e相邻，相邻关系不符，排除
5. 第5步：验证D项——选项中面e挨着顶面（面b或面d）的空白三角形（线3），但展开图中面e挨着的是面b或面d内的阴影三角形，排除
6. 第6步：验证C项——选项同时出现面c、面d和面f，三面相邻位置与展开图完全一致，当选

**最快解法**：⚡ 特征边锚定排除法——优先看带黑点/白圆的矩形面，确认其'长边'在选项中贴着哪个面：A项黑点矩形长边错贴面e、B项白圆矩形长边错贴面c，均可一条特征边秒杀；再用三角形阴影/空白朝向排除D项，唯一无矛盾者为C

## 易错点
- ⚠ 只检查图案是否出现，忽略特征图案'长边/顶点'与哪个面相邻这一决定性细节（A、B项正是靠长边指向排除）
- ⚠ D项中把面b/d内的阴影三角形与选项顶面的空白三角形混淆，漏看'挨着的应是阴影三角形'
- ⚠ 不给展开图标注面序号，凭空间硬想相邻关系，容易把相邻面认成相对面

## 母题抽象
> 🧩 当展开图含'带圆点的矩形面＋带三角形的面'等强特征图案时，用'特征边锚定法'：先确认特征图案的长边/顶点在展开图中与哪个面相接，再逐项检查选项中该边是否仍与同一面相邻，不符即排除

**同类特征**：多面体外表面展开图折叠、含黑点/白圆的矩形特征面、阴影三角形与空白三角形朝向、三个面共现的组合判断、相邻面长边/顶点相接关系、选项间用单条特征边即可区分
