# 位置规律-元素位置不重复（位置遍历）

考点：[[20-考点/判断推理/图形推理/位置规律-元素位置不重复（位置遍历）|图形推理 / 位置规律-元素位置不重复（位置遍历）]]


**问法模型**：两组式图形、元素组成完全相同仅排列顺序变化→逐元素追踪其在各图中的位置，套用'位置不重复/遍历'模型排除

## 推理链
1. 第1步：两组图形均由黑三角、白三角、黑圆、白圆4个小元素纵向堆叠而成，元素组成相同、仅上下顺序变化，定位位置规律
2. 第2步：第一组验证'位置不重复'规律：黑三角依次居第1、4、3位，白三角居第2、1、4位，黑圆居第3、2、1位，白圆居第4、3、2位，每个元素在3个图中位置均不重复
3. 第3步：第二组提取已占位置：图1为黑圆1/白圆2/黑三角3/白三角4，图2为白三角1/黑三角2/黑圆3/白圆4，问号处每个元素的位置须不同于其在图1、图2中的位置
4. 第4步：逐项排除——B中黑三角在第2位与图2重复，C中白三角在第1位与图2重复，D中黑圆第1位、白圆第2位均与图1重复
5. 第5步：A中白圆1/黑圆2/白三角3/黑三角4，四个元素位置均未与图1、图2重复（黑圆1→3→2、白圆2→4→1、白三角4→1→3、黑三角3→2→4），符合规律，当选

**最快解法**：⚡ 排除法+盯单一元素：先看白三角，图1、图2中分别在第4、第1位，问号处不能在第4或第1位，C（第1位）排除；再看黑三角，图1、图2中在第3、第2位，B（第2位）、D（第3位）排除；只剩A，故选A

## 易错点
- ⚠ 第一组图形暗似'整体上移一位'的平移规律，误套到第二组发现不吻合而纠结，实际规律是'每个元素位置不重复'的遍历规律
- ⚠ 只核对一两个元素就选答案，需四个元素逐一验证位置不重复
- ⚠ 黑白易混：三角形和圆圈各有黑白两色，读图时把黑/白看反会导致位置记录全错

## 母题抽象
> 🧩 当两组式图形出现'元素组成完全相同、仅纵向排列顺序变化'的特征时，用逐元素追踪位置法，验证每个元素在各图中的位置不重复（位置遍历），排除存在位置重复的选项

**同类特征**：两组式图形、元素组成相同、黑白三角形+黑白圆圈四个小元素、纵向堆叠排列、仅排列顺序变化、位置不重复（位置遍历）
