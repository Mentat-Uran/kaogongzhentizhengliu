# 对称性-对称轴与图形内部线条的位置关系（重合-不重合交替）

考点：[[20-考点/判断推理/图形推理/对称性-对称轴与图形内部线条的位置关系（重合-不重合交替）|图形推理 / 对称性-对称轴与图形内部线条的位置关系（重合/不重合交替）]]


**问法模型**：‘填入问号处使之呈现一定规律性’→ 元素组成不同时先看属性（对称性），属性无法排除时细化为‘对称轴与内部线条是否重合’的交替规律

## 推理链
1. 第1步：题干五图元素组成不同，且图1、图4均出现等腰三角形这一轴对称特征图，优先考虑属性规律中的轴对称
2. 第2步：题干与选项均为轴对称图形，单纯‘是否对称’无法排除，需细化考查对称轴与图形内部线条的位置关系
3. 第3步：观察题干：图1（竖线+等腰三角形）、图3（M形）、图5（长方形内交叉线）的对称轴均不与内部任何一根线条重合；图2（矩形正中竖线）、图4（三角形内 部线条）的对称轴恰好与内部一根线条重合
4. 第4步：归纳出交替规律——不重合、重合、不重合、重合、不重合，故问号处应为‘对称轴与内部线条重合’的图形
5. 第5步：逐项对照：A项对称轴不与内部裁角线重合；B项等腰三角形内部无线条，谈不上重合；C项六边形中间竖线恰与竖直对称轴重合；D项对称轴不与内部线条重合
6. 第6步：只有C满足‘对称轴与内部一根线条重合’，故选C

**最快解法**：⚡ 对称轴描线法+交替规律：先排除法确认全轴对称后，在每图对称轴位置描一条线，标记‘与内部线条重合/不重合’，发现1不重合→2重合→3不重合→4重合→5不重合的交替，问号处应为重合，直接锁定C

## 易错点
- ⚠ 只验证到‘都是轴对称图形’这一层就停步，未细化对称轴与内部线条的位置关系，导致四个选项无法区分
- ⚠ 误用‘对称轴数量=面数量’规律错选B：题干图5外框为长方形，对称轴横竖共2条而面数为4，二者数量并不一致，该规律不成立
- ⚠ 忽略奇偶项交替规律，只对比相邻图形或只看个别图形，把‘重合/不重合’的周期性看成随机分布

## 母题抽象
> 🧩 当题干各图均为轴对称且选项无法用‘是否对称’排除时，升级考查‘对称轴是否与图形内部线条重合’，按重合与不重合的交替（或数量）规律定位答案

**同类特征**：元素组成不同优先属性规律、出现等腰三角形（轴对称特征图）、五个图形均为轴对称、对称轴与内部线条重合与否交替出现、部分图形对称轴穿过内部实线（如图2中间竖线、图4内部线）

### 题干
从所给的四个选项中，选择最合适的一个填入问号处，使之呈现一定的规律性：

### 选项

- B. B
- C. C　✅
- D. D

### 官方解析
元素组成不同，优先考虑属性规律，题干中图1、图4都出现等腰三角形，是轴对称的特征图，优先考虑轴对称；题干和选项都是轴对称图形，无法排除。观察发现，如下图所示：

图1、图3、图5的对称轴与图形内部线条都不重合，而图2、图4的对称轴都与图形内部的一根线条重合，因此问号处要填入一个对称轴与图形内部线条有重合的选项，只有C选项满足。
故正确答案为C。
注：本题有同学的解题思路是对称轴的数量与面数量一致，选择B项。但是粉笔认为选C项的原因有二：第一，本题题干第五幅图形外框为长方形，其对称轴的数量应为横竖2条，而面数量为4，二者数量并不一致；第二，从近年来的命题规律来看，2019年国考和2018年北京市考都考查了对称轴与图形中线条重合这一知识点，C选项更符合最新的命题趋势。
