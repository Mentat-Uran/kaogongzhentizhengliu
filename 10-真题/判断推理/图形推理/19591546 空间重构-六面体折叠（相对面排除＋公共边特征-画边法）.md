# 空间重构-六面体折叠（相对面排除＋公共边特征-画边法）

考点：[[20-考点/判断推理/图形推理/空间重构-六面体折叠（相对面排除＋公共边特征-画边法）|图形推理 / 空间重构-六面体折叠（相对面排除＋公共边特征/画边法）]]


**问法模型**：‘左边展开图，右边哪一项能折叠而成’→ 先用相对面不能同现排除，再用公共边两侧图案特征或画边法验证相邻面方向

## 推理链
1. 第1步：给展开图各面标号（解析记为面e、面g、面h、面i、面k等）：面e为线条面（存在与其内部线条垂直的边），面g内含阴影三角形，面h、面i内含白色三角形，且面e与面k互为相对面
2. 第2步：用规则一‘相对面不能同时出现’检查四选项：B项同时出现面e和面k，直接排除B
3. 第3步：用规则二‘公共边与面内线条的位置关系’检查A项：A项顶面与右侧面的公共边与两个面内三角形的内部线条均垂直，但逐一核对展开图，不存在任何相邻两面公共边均垂直于其内部三角形线条的情况，排除A
4. 第4步：验证C项：C项由面e、面h、面g三个面构成，其相邻关系与公共边上的图案特征均与展开图一致，能折叠而成
5. 第5步：用画边法复核D项：D项出现面e，正面与右侧面的公共边挨着两个白色三角形的直角边，故正面、右侧面分别为面h和面i；在展开图和选项中分别以面e内与其线条垂直的边为起始边顺时针画边，展开图中边2挨着面g的阴影三角形，而选项中边2挨着白色三角形，相邻关系不符，排除D
6. 第6步：A、B、D均与展开图不一致，仅C项能由展开图折叠而成，故选C

**最快解法**：⚡ 相对面排除＋画边法组合：①B项面e与面k（相对面）同现，秒排；②A项公共边垂直于两面内部线条而展开图中无此相邻关系，排除；③D项以垂直于面e内线条的边为起点顺时针画边，边2所邻三角形由‘阴影’变‘白色’，排除；锁定C

## 易错点
- ⚠ 相对面判定失误：展开图非标准排布时看错面e与面k的相对关系，漏排B项
- ⚠ 公共边特征只看‘是否挨着三角形’而忽略细节（挨的是阴影三角形还是白色三角形、是直角边还是斜边），导致D项无法排除而误选
- ⚠ 画边法起始边选错：未以‘垂直于面e内部线条的边’为起点，或展开图与选项中画边方向不一致，造成相邻面定向错误

## 母题抽象
> 🧩 当题干为‘六面体展开图＋四选一折叠’且面内含线条、阴影三角形等方向性图案时，先排相对面同现的选项，再以特征边为起点顺时针画边（或核对公共边两侧图案的方向/颜色）验证相邻面，与展开图完全一致的即为答案

**同类特征**：正方体外表面展开图、面内含竖线条纹、X形、阴影/白色三角形等方向性图案、问法为‘哪一项能由它折叠而成’、存在明确相对面组（面e与面k）、相邻面公共边上有可辨识的图案特征（三角形直角边、线条垂直关系）、需区分阴影三角形与白色三角形的朝向差异

### 题干
左边给定的是正方体的外表面展开图，右边哪一项能由它折叠而成？

### 选项
- A. A
- B. B
- C. C　✅
- D. D

### 官方解析
将题干展开图标上序号，如下图所示，逐一进行分析。

A项：选项顶面和右侧面的公共边与面内三角形的内部线条均垂直，但展开图中不存在两个面的公共边与面内三角形的内部线条均垂直的情况，选项与题干展开图不一致，排除；
B项：选项出现了面e和面k，展开图中面e和面k是相对面，相对面不能同时出现，选项与题干展开图不一致，排除；
C项：选项由面e、面h和面g构成，选项与题干展开图一致，当选；
D项：选项出现了面e，正面和右侧面的公共边挨着两个白色三角形的直角边，因此正面和右侧面分别为面h和面i，在展开图和选项中分别以面e内线条垂直的边为起始边，顺时针在面e内画边，展开图中边2挨着面g中的阴影三角形，而选项中边2挨着白色三角形，选项与题干展开图不一致，排除。
故正确答案为C。
