# 立体图形-六面体整体旋转规律（九宫格空间重构）

考点：[[20-考点/判断推理/图形推理/立体图形-六面体整体旋转规律（九宫格空间重构）|图形推理 / 立体图形-六面体整体旋转规律（九宫格空间重构）]]


**问法模型**：九宫格问号处填入最合适图形 → 优先横向观察找同一六面体'整体旋转'规律，再结合特征面细节排除

## 推理链
1. 第1步：九宫格中每格均为同一个六面体的不同摆放视角，特征面包含灰色三角形面与两个斜线面（面4、面5）
2. 第2步：九宫格优先横向观察，第一行图1整体沿水平方向顺时针旋转得到图2，图2再整体沿水平方向顺时针旋转得到图3
3. 第3步：用第二行验证该整体旋转规律，第二行同样满足横行旋转关系
4. 第4步：第三行应用规律，'？'处图形应由第三行图2整体沿水平方向顺时针旋转所得，旋转后顶面为斜线面、正面为灰色三角形面
5. 第5步：逐项对照，B、D两项顶面/正面与旋转结果不符，排除B、D
6. 第6步：比较A、C，两项右侧面不同但均出现两个斜线面（面4和面5），依据展开图两斜线面上的斜线应相交于一点（第一行图1、第二行图2可验证该相交关系）
7. 第7步：A项中两个斜线面上的斜线不相交，与展开图矛盾，排除A，故选C

**最快解法**：⚡ 横行整体旋转规律+特征面验证法：先按'图2沿水平方向顺时针整体旋转'锁定问号处'顶面斜线面+正面灰色三角形面'排除B、D，再用'两个斜线面上的斜线相交于一点'排除A，秒选C

## 易错点
- ⚠ 只验证旋转规律而不核对特征面细节（两斜线面斜线的交点关系），误选A
- ⚠ 把六面体整体旋转误解为仅正面/局部图案变化，忽略顶面、侧面联动
- ⚠ 未先用第二行验证旋转方向（顺时针），直接套用易把旋转方向搞反

## 母题抽象
> 🧩 当九宫格各图呈现同一六面体的不同视角时，优先横向找'整体旋转'规律并用下一行验证，再用展开图中特征面细节（如线条交点、相对位置）排除形似选项

**同类特征**：九宫格、同一六面体多视角、整体旋转规律、斜线面、灰色三角形面、斜线相交于一点
