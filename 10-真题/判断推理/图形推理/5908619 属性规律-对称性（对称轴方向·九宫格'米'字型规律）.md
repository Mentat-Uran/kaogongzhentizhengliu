# 属性规律-对称性（对称轴方向·九宫格'米'字型规律）

考点：[[20-考点/判断推理/图形推理/属性规律-对称性（对称轴方向·九宫格'米'字型规律）|图形推理 / 属性规律-对称性（对称轴方向·九宫格'米'字型规律）]]


**问法模型**：九宫格'问号处填最合适图形'且元素组成不同→先看属性规律，本题锁定对称性，归纳八个图形对称轴的方向规律并补缺。

## 推理链
1. 第1步：九宫格八个已知图形元素组成各不相同（月牙+三角形、皇冠含星、散点星阵、菱形加短棒、四叶花、圆矩组合、十字内含小元素、笑脸），优先考虑属性规律而非位置或数量规律。
2. 第2步：题干多处出现等腰三角形、菱形、五角星、圆等典型'等腰/轴对称'元素，据此锁定对称性考点。
3. 第3步：逐一验证八个已知格均为轴对称图形，仅凭'是否轴对称'无法区分选项，需进一步比较每格对称轴的方向。
4. 第4步：标注各格对称轴方向：皇冠、圆矩组合、笑脸等为竖轴，菱形加短棒为横轴，月牙+三角形、四叶花、散点星阵、十字格等为斜轴——八个方向合并恰构成'米'字的横、竖、撇、捺四笔。
5. 第5步：'米'字型规律要求问号处图形补上缺失的斜向对称轴，而非再补一条竖轴。
6. 第6步：对照选项：A（丝带+矩形）、B（双菱形）、D（闹钟）的对称轴均为竖直方向，与题干已充足的竖轴重复；C（散布的菱形与正方形）对称轴为斜向。
7. 第7步：只有C能补全'米'字型对称轴方向规律，故选C。

**最快解法**：⚡ 对称轴方向标记法：在每格快速画出对称轴并标注方向，发现题干方向呈'米'字（横竖撇捺）分布且问号处缺斜轴；A、B、D均为竖轴，唯C为斜轴，直接锁定C。

## 易错点
- ⚠ 只验证'是轴对称'就急于选答案，误选同为轴对称的A、B或D，漏掉'对称轴方向'这一二级比较。
- ⚠ 忽略九宫格整体的'米'字型方向分布，误按行/列找对称轴数量或元素数量规律。
- ⚠ 对散点式排布图形（第一行第三格、选项C）的对称轴方向判断失误，看不出其斜轴。

## 母题抽象
> 🧩 九宫格元素组成不同且多处出现等腰三角形/菱形/五角星等腰元素时，先确认轴对称，再画各格对称轴看方向：若八个方向合成'米'字（横、竖、撇、捺），问号处补缺失方向即可秒选。

**同类特征**：九宫格、元素组成不同、等腰三角形/菱形/五角星等典型等腰元素、各格均为轴对称图形、对称轴方向呈'米'字型（横竖撇捺）、问号处补斜向对称轴
