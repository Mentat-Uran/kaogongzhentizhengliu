# 复合规律-属性（曲直性）初筛+数量规律（数面）

考点：[[20-考点/判断推理/图形推理/复合规律-属性（曲直性）初筛+数量规律（数面）|图形推理 / 复合规律-属性（曲直性）初筛+数量规律（数面）]]


**问法模型**：问号处填入图形使整组呈现规律 → 元素组成不同时，先用属性规律（曲直性）排除，再用数量规律（面数量）锁定唯一答案

## 推理链
1. 第1步：题干五幅图形元素组成各不相同（圆加交叉线、方圆三角组合、双弯曲箭头、方框加叶片、圆柱体），无相同元素重复出现，优先考虑属性规律
2. 第2步：观察曲直性——图1圆含曲线与交叉直线、图2圆（曲线）与方形三角（直线）共存、图3弯曲箭头含曲线且箭头轮廓含直线段、图4矩形（直线）与叶片（曲线）共存、图5矩形与椭圆共存，题干图形均由曲线和直线共同构成
3. 第3步：逐项对照曲直性——A项双线方框全部由直线构成、B项同心圆与月牙全部由曲线构成，均不符合'曲直共存'，排除A、B
4. 第4步：对剩余选项继续观察，题干图形封闭区域（面）特征明显，转用数量规律数面，题干每幅图的面数量均为4
5. 第5步：对照剩余选项数面——C项外圈大圆内含两个圆眼、一个三角鼻、一个半圆嘴，面数量为5，不符合；D项层叠纸张图形面数量为4，符合规律

**最快解法**：⚡ 属性排除法+数面：第一步按'曲直共存'秒杀排除A（全直线）、B（全曲线）；第二步数面，题干均为4个面，C为5个面排除，D为4个面当选

## 易错点
- ⚠ 跳过曲直性筛选直接数面，会误把C项（含直线三角与曲线圆，曲直共存）纳入候选，效率低且易错数
- ⚠ 复合嵌套图形数面遗漏：C项大圆内部多个小封闭图形须逐一计数（5个面），漏数会误判C符合
- ⚠ 层叠式图形（D项多张纸张叠放）易因前后遮挡而数错面数量

## 母题抽象
> 🧩 当题干图形元素组成不同、且曲直特征肉眼可辨时，先用'曲直性'快速排除纯直线或纯曲线选项，再用'数面/数线'等数量规律在剩余选项中验证唯一解

**同类特征**：元素组成不同、曲直线条共存、封闭面明显、面数量恒定（均为4）、属性与数量双重筛选

### 题干
请从所给的四个选项中，选出最恰当的一项填入问号处，使之呈现一定的规律性。

### 选项
- A. A
- B. B
- C. C
- D. D　✅

### 官方解析
图形元素组成不同，优先考虑属性规律。观察发现，题干图形都是由曲线和直线共同构成，排除A、B两项；继续观察发现，题干图形封闭面明显，考虑数面。题干图形面数量都为4，故“？”处应该选择面数量为4的图形，只有D项符合。
故正确答案为D。
