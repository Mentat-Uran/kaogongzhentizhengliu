# 数量规律-部分数（生活化图形数部分）

考点：[[20-考点/判断推理/图形推理/数量规律-部分数（生活化图形数部分）|图形推理 / 数量规律-部分数（生活化图形数部分）]]


**问法模型**：问号处填入图形使整组呈现规律 → 元素组成不同且属性无规律时，对生活化图形优先数'部分数'（独立不相连的块数）

## 推理链
1. 第1步：题干五图均为生活化组合图形（圆内米字加梯形底座、交叉桌腿加蝴蝶结、圆内信封、方框内丁字、两个回字纹），元素组成不同，对称/曲直/开闭等属性规律不明显
2. 第2步：改走数量规律，生活化图形的典型考点是'部分数'，即图形中互不相连的独立部分个数
3. 第3步：逐图数部分：图1'圆+底座'为2部分，图2'桌架+蝴蝶结'为2部分，图3'外圆+信封'为2部分，图4'方框+内部丁字'为2部分，图5'两个回字纹'为2部分，题干规律为部分数恒等于2
4. 第4步：问号处图形的部分数也应为2
5. 第5步：数选项：A为回字纹加独立线条共3部分，C为圆角方框加3条竖线共4部分，D为胶囊加4条横线共5部分，均排除
6. 第6步：B项为钩形主体与底部L形线两个互不相连部分，部分数为2，与题干规律一致，当选

**最快解法**：⚡ 口诀'生活图形数部分'：快速数每个图形独立不相连的块数，题干全为2，选项排除法——A为3部分、C为4部分、D为5部分，秒选B

## 易错点
- ⚠ 误把考点当成'面数/封闭区域数'：图3信封、图5回字纹都有封闭空间，但真正规律是部分数而非面数
- ⚠ 漏数独立线条：A项回字纹外围还有互不相连的线条，若漏数会误判A为2部分而错选
- ⚠ 相连与不相连判断失误：需确认内部线条与外框是否真正相交连接，只有真正相触才算同一部分

## 母题抽象
> 🧩 当题干出现生活化、元素组成不同且对称/开闭等属性无规律时，优先数'部分数'，找出题干共同的部分数值（如均为2），再在选项中匹配同部分数的图形

**同类特征**：元素组成不同、生活化图形、无明显属性规律、部分数恒定、独立不相连的部分、数量规律
