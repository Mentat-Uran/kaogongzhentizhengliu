# 样式规律-加减同异（求异）

考点：[[20-考点/判断推理/图形推理/样式规律-加减同异（求异）|图形推理 / 样式规律-加减同异（求异）]]


**问法模型**：两组图元素相似、相同线条大量重复出现 → 用第一组验证'同去异留'的求异规律，第二组套用选出答案

## 推理链
1. 第1步：题干为两组对照图，两组内部线条重合度高（第一组三角形与正方形共享边线，第二组两图均含整圆外框），符合'元素组成相似'特征，优先考虑样式规律
2. 第2步：相同线条重复出现，进入'加减同异'辨析，用第一组验证具体规律：图1与图2逐条比对线条，相同的消去、不同的保留（求异）
3. 第3步：第一组验证成立——图1（直角三角形及内部线条）与图2（正方形及内部斜线）中两图共有的左竖边、下横边及重合内部线全部相消，仅剩只在单个图中出现的顶部横线与右侧竖线，恰为图3的'┐'形
4. 第4步：第二组套用求异规律：图1（圆内五边形及内部连线）与图2（圆内自顶点向下展开的扇形线）叠加，两图共有的整圆外框及重合线段全部消去
5. 第5步：保留仅出现一次的线条：一条竖线、一条与之交叉的斜线以及左下角的一段弧线（曲线同样参与求异）
6. 第6步：逐项对照——仅A项线条组成与求异结果完全一致；B、C、D均多出尖顶斜边或横线、缺少对应线条，与'同去异留'结果不符，故选A

**最快解法**：⚡ 求异口诀'同去异留'：先看外框——第二组两图共有整圆直接消去，排除保留圆形的错误思路；再比对内部线条，只出现一次的竖线、交叉斜线和左下小弧保留，与A项吻合，直接锁定

## 易错点
- ⚠ 把规律误判为'求同'：误以为保留两图相同的线条（如整圆外框），与第一组图3结果矛盾
- ⚠ 忽略曲线参与运算：只数直线会漏掉左下角应保留的弧线段，误选无弧的C或D
- ⚠ 未先用第一组验证规律就直接套用，混淆求同、求异、相加、去同存异等多种加减同异变体

## 母题抽象
> 🧩 当两组图形元素组成相似、相同线条（尤其外框）大量重复出现时，先用第一组确定'求异（同去异留）'规律，再对第二组逐线比对——消去共有线条、保留单出线条（含弧线）即为答案

**同类特征**：两组各三幅图的对照式布局、元素组成相似、相同线条重复出现、两图共享整圆外框、内部线条部分重合、问号在第二组第三幅

### 题干
根据所给图形的现有规律，选出一个最合理的答案：

### 选项
- A. A　✅
- B. B
- C. C
- D. D

### 官方解析
图形元素组成相似，优先考虑样式规律。相同线条重复出现，考虑加减同异。观察发现，第一组图中，图1和图2求异后得到图3，第二组图运用相同规律，图1和图2求异后，对应A项图形。
故正确答案为A。
