# 数量规律-笔画数（一笔画与多笔画，奇点计数）

考点：[[20-考点/判断推理/图形推理/数量规律-笔画数（一笔画与多笔画，奇点计数）|图形推理 / 数量规律-笔画数（一笔画与多笔画，奇点计数）]]


**问法模型**：'把六个图形分为两类，使每一类都有各自共同特征'的分组分类问法 → 元素组成不同且属性规律不通时，转向数量规律，本题落点为笔画数分组

## 推理链
1. 第1步：提取图形特征——元素组成不同，先排查对称、曲直、开闭等属性规律，各组无法形成统一标准，故转数量规律
2. 第2步：题干图①、图⑤存在明显端点，图③为'田'字变形图，图⑥为'日'字变形图，端点与'日/田'类变形是笔画数考点的典型信号，改用奇点法数笔画
3. 第3步：逐图数奇点——图①④⑥的奇点数为0或2（端点亦计为奇点），满足一笔画条件；图②③⑤的奇点数为4，笔画数=4÷2=2，均为两笔画
4. 第4步：按'一笔画/两笔画'分组，①④⑥为一组、②③⑤为一组，对照选项仅D（①④⑥，②③⑤）符合，与官方答案一致

**最快解法**：⚡ 笔画数口诀法：见端点和'日/田/中'字变形立即数奇点——奇点0或2个→一笔画，奇点4个→两笔画；①④⑥一笔画、②③⑤两笔画，直接锁定D

## 易错点
- ⚠ 把有端点的图误判为一笔画与多笔画的分界标准混乱：端点本身就是奇点，须逐点数总奇点数而非只看端点个数
- ⚠ '田''日'变形图线条交叉处漏数奇点：交叉相接的顶点度数为奇数时必须计入，如③的内部交叉点
- ⚠ 在属性规律（对称、封闭、曲直）上纠缠过久，未及时切换到数量规律；或误按线段数/面数等数量维度分组

## 母题抽象
> 🧩 当分组分类题元素组成不同、属性规律无解，且图中出现端点或'日/田/中'类变形图时，优先数奇点定笔画数，按一笔画与多笔画完成两类分组

**同类特征**：六图分组分类、元素组成不同、图①⑤含端点、图③为田字变形、图⑥为日字变形、奇点数0/2与4的两分结构

### 题干
<p>把下面的六个图形分为两类，使每一类图形都有各自的共同特征或规律，分类正确的一项是：</p><p><img width="450px" height="350px" src="../../../90-图片/题目图/18688c6c9723625.png" /></p>

### 选项
- A. ①②③，④⑤⑥
- B. ①②⑤，③④⑥
- C. ①②⑥，③④⑤
- D. ①④⑥，②③⑤　✅

### 官方解析
本题为分组分类题目。元素组成不同，无明显属性规律，考虑数量规律。观察发现，题干图①、图⑤存在端点，图③为“田”字变形图，图⑥为“日”字变形图，考虑笔画数，图①④⑥均为一笔画图形，图②③⑤均为两笔画图形。即图①④⑥为一组，图②③⑤为一组。
故正确答案为D。
