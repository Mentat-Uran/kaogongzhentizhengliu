# 空间重构-六面体折叠（相对面排除法）

考点：[[20-考点/判断推理/图形推理/空间重构-六面体折叠（相对面排除法）|图形推理 / 空间重构-六面体折叠（相对面排除法）]]


**问法模型**：给出立体图与四个展开图，问哪个展开图折叠后能构成该立体图 → 先用相对面排除，再用相邻面线条方向验证的折纸盒模型

## 推理链
1. 第1步：从立体图提取特征——前、上、右三个可见面各有一条过面中心的线段，三个面两两相邻（共用顶点），三条线在前、上、右三个方向上两两垂直
2. 第2步：调用折叠规则——展开图中互为相对面的两面折叠后必然相对、不能相邻共顶点，故立体图中两两相邻的三个带线面，在展开图中必须两两相邻，不能出现任何一对相对面
3. 第3步：四个展开图外轮廓一致，按官方解析对六面编号并标出相对面：1面与4面相对、2面与6面相对、3面与5面相对
4. 第4步：逐项检查带线面位置——A、C、D中带线的三个面里均有两个互为相对面，折叠后这两面必然相对，无法与第三个带线面共顶点相邻，与立体图矛盾，排除A、C、D
5. 第5步：检验B项——三个带线面两两相邻（均为相邻面），且折叠后三条线方向互相垂直，与立体图'前横线、上纵线、右竖线'的两两垂直关系一致
6. 第6步：对照结论——仅B项能折成题干立体图，故选B

**最快解法**：⚡ 相对面排除法：外轮廓一致时先给展开图六面编号、标出相对面（1-4、2-6、3-5）；立体图中三个带线面两两相邻共顶点，故带线面中只要含一对相对面即直接排除——A、C、D均含相对面对被排除，仅剩B，再验证三线两两垂直即锁定

## 易错点
- ⚠ 只盯线条方向先验垂直关系，漏用'相对面不能相邻共顶点'这一更强的排除规则，在A、D之间反复纠结浪费时间
- ⚠ 四个展开图外轮廓一致时未先编号定位各面，凭平移直觉判断相对面，把'隔一个面'误判为相邻面
- ⚠ 忽略立体图中三线共顶点且两两垂直的方向约束，只验证相邻关系不验证线向，可能误选相邻但线条指向不符的干扰项

## 母题抽象
> 🧩 当折纸盒题的立体图中出现三个带特征线/图案的面且它们两两相邻（共顶点）时，先在展开图中标出相对面，凡特征面中含一对相对面的选项直接排除，剩余项再验证线条指向或垂直关系

**同类特征**：六面体折纸盒、四个展开图外轮廓一致、立体图三个相邻面各有一条中线、三条线两两垂直、共顶点、相对面1-4/2-6/3-5、相对面排除

### 题干
上边这个图形是由下边四个图形中的某一个作为外表面折叠而成，请指出它是哪一个？

### 选项
- A. A
- B. B　✅
- C. C
- D. D

### 官方解析
本题考查六面体结构，主要着眼考查相对面的识别。
选项所示图形平面展开图外轮廓一致，首先考虑平面展开图中相对面的识别。

平面展开图中1面与4面为相对面，2面与6面为相对面，3面与5面为相对面。
逐一分析选项：
ACD选项中均存在相对面，立体图中的三个横线面无法在平面展开图中体现，排除ACD。
B选项中三个面中的横线互相垂直，能够折合成题干所示的立体图。
故正确答案为B。
