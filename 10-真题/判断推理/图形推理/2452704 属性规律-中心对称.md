# 属性规律-中心对称

考点：[[20-考点/判断推理/图形推理/属性规律-中心对称|图形推理 / 属性规律-中心对称]]


**问法模型**：问号处填入图形使整组呈现规律 → 元素组成不同时优先考虑属性规律（对称性），验证中心对称

## 推理链
1. 第1步：题干五幅图均由小黑球和小白球在网格位置上排布，元素组成不同，排除位置移动、样式叠加，优先考虑属性规律
2. 第2步：图2（上中黑、右上白、下中黑、左下白）与图5呈'S或Z'变形图，提示本题考查对称性
3. 第3步：逐图验证：图1黑球居左上/中心/右下、白球居左中/右中，图3、图4为'角球+中间三球'的三连结构，图2、图5为S/Z形，全部满足'绕中心旋转180°后与原图重合'，且对称位置黑白颜色保持一致
4. 第4步：归纳规律——题干所有图形均为中心对称图形，问号处也应选中心对称图形
5. 第5步：逐项检验：A项左上黑↔右下黑、右上白↔左下白、中心黑自对称，为中心对称；B项左上黑对应右下无球；C项左上黑对应右下白、左下白对应右上黑，颜色不一致；D项左上黑对应右下无球，B/C/D均排除
6. 第6步：只有A项为中心对称图形，与官方答案A一致

**最快解法**：⚡ 中心对称判定口诀'旋转180°重合'——将选项绕中心倒转过来看颜色：A倒转后黑白位置完全重合；B/D对称位缺球、C对称位黑变白，直接秒选A

## 易错点
- ⚠ 只统计黑白球个数或黑白总量，忽略'对称位置上颜色也必须一致'这一约束
- ⚠ 误用轴对称（左右翻折）验证：题干图形多不是轴对称，规律是中心对称而非轴对称
- ⚠ C项外轮廓与A相同，仅对称位置黑白互换，粗心易把C误判为对称图形

## 母题抽象
> 🧩 当题干出现散落的小黑球小白球等小元素且元素组成不同时，优先验证对称性——逐项检查'绕中心旋转180°后黑白位置是否与原图完全重合'，选出同为中心对称的选项

**同类特征**：图形由小黑球和小白球组成、元素组成不同、图2与图5呈S或Z变形、所有图形均中心对称、对称位置黑白颜色一致
