# 图形推理-样式规律（叠加求异-去同存异）

考点：[[20-考点/判断推理/图形推理/图形推理-样式规律（叠加求异-去同存异）|图形推理 / 图形推理-样式规律（叠加求异/去同存异）]]


**问法模型**：两组图问'符合变化规律的是' → 先从第一组归纳图形运算规律（求异），再将规律平移应用到第二组求问号处图形

## 推理链
1. 第1步：第一组三个图形线条大量重合、元素组成相似，优先考虑样式规律，而非位置或数量规律
2. 第2步：对比第一组图一（六边形及内部竖线、交叉线）与图二：两图叠加后，重合的线条在图三中全部消失，只在其中一个图形中出现的线条被保留，即图三＝图一⊕图二（求异/去同存异）
3. 第3步：用图三（上下双向箭头）验证：由图一、图二求异可直接得到，规律成立
4. 第4步：第二组图一为'圆＋内接三角形'，图二为'圆＋右上方一条弦线'，该弦线恰与三角形右上那条边重合
5. 第5步：对第二组两图求异：两图共有的'圆'被去掉，与三角形重合的右上边也被去掉
6. 第6步：仅剩三角形的左、下两条边，组成一个不封闭的角形
7. 第7步：对照选项：A为圆（求同结果）、C为叠加结果、D为完整三角形（漏去重合边），只有B为两条线段构成的角形，符合求异结果

**最快解法**：⚡ 叠加去同存异法：将第二组图一、图二重合放置，删去共同的圆及重合的那条弦边（即三角形右上边），剩余两条边直接锁定B

## 易错点
- ⚠ 求异时漏掉图二中与三角形重合的那条边，只去掉圆，误选D（完整三角形）
- ⚠ 把规律误解为'求同'或直接叠加，误选A（圆）或C
- ⚠ 未先用第一组验证'重合线条消失'这一关键规则，直接套用导致判断失误

## 母题抽象
> 🧩 当两组图形'元素组成相似、线条大量重合'时，用样式规律中的求异（去同存异）：两图叠加→删去重合线条→保留差异线条即答案，且必须先在第一组完整验证该运算规则

**同类特征**：两组式图形推理、元素组成相似、线条重合/相交明显、第三图由前两图运算得到、问号处求第二组第三图、去同存异（求异）

### 题干
下列选项中，符合所给图形的变化规律的是        。

### 选项
- A. A
- B. B　✅
- C. C
- D. D

### 官方解析
元素组成相似，优先考虑样式规律。观察第一组图形发现，图三由图一和图二求异后得到。第二组图形应用此规律，将图一和图二求异后，得到的图形对应B项。
故正确答案为B。
