# 空间重构-六面体展开图（相对面排除法）

考点：[[20-考点/判断推理/图形推理/空间重构-六面体展开图（相对面排除法）|图形推理 / 空间重构-六面体展开图（相对面排除法）]]


**问法模型**：展开图与立体图的数字字母一一对应求对应顺序 → 先定展开图三组相对面，再定立体图三组相对面，逐项排除对应不一致者

## 推理链
1. 第1步：展开图为十字形，竖列为1、5、3、6，两侧翼为2、4；按'同行/同列隔一个面为相对面'规则，竖列中1与3（隔5）相对、5与6（隔3）相对，两翼2与4相对，得三组相对面：1-3、5-6、2-4
2. 第2步：读立体图：长方体中a与f为两端面（相对），b与c为前后面（相对），d与e为顶面与底面（相对）；即立体图三组相对面为a-f、b-c、d-e
3. 第3步：逐项对照：A项cabdfe中5→f、6→e，但f与e在立体图中相邻不相对，排除；B项caefdb中1→c、3→e，但c与e相邻不相对（c的相对面是b），排除；C项cefdba中1→c、3→f，但c与f相邻不相对，排除
4. 第4步：D项cabfde中1→c、3→b相对吻合，5→d、6→e相对吻合，2→a、4→f相对吻合，三组相对面与展开图完全一致，当选

**最快解法**：⚡ 相对面排除法（隔一相对+两翼相对）：展开图竖列'1、5、3、6'隔一取相对得1-3、5-6，两翼2-4相对；立体图中a-f、b-c、d-e相对；把选项字母串按位对号，验证三组相对面是否都落到立体图的相对面上，仅D全中

## 易错点
- ⚠ 忽略相对面、只逐面模拟相邻位置，费时且易在折叠方向上出错
- ⚠ 立体图中看不见的面（c、e、f）位置想错，导致相对面配对（如误认为f与e相对）出错
- ⚠ 展开图相对面判断规则用错，如误以为2和4不相对或漏掉5-6这组

## 母题抽象
> 🧩 当题干给出六面体展开图与立体图且问数字字母一一对应时，先用'隔一相对、两翼相对'找展开图三组相对面，再找立体图三组相对面，选项中有一组相对面对不上即排除，三组全对者当选

**同类特征**：左展开图右立体图、数字与字母一一对应、六面体（长方体）折叠、选项为六字母排列串、相对面关系可排除

### 题干
左图是右图的平面展开图，数字与字母一一对应，与123456可以对应的是      。

### 选项
- A. A
- B. B
- C. C
- D. D　✅

### 官方解析
本题考查六面体。
A项：题干展开图中的面5和面6是相对面，而面f和面e不是，排除。
B项：题干展开图中的面1和面3是相对面，而面c和面e不是，排除。
C项：题干展开图中的面1和面3是相对面，而面c和面f不是，排除。
D项：题干展开图中六个面的相对位置关系和立体图形中六个面的相对位置一致，当选。
故正确答案为D。
