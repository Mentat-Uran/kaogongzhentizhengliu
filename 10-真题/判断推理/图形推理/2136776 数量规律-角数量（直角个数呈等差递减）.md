# 数量规律-角数量（直角个数呈等差递减）

考点：[[20-考点/判断推理/图形推理/数量规律-角数量（直角个数呈等差递减）|图形推理 / 数量规律-角数量（直角个数呈等差递减）]]


**问法模型**：『填入问号处使之呈现一定的规律性』且元素组成不同→先排除属性规律，改用数量规律逐图计数，找出递变（等差）规律后选满足下一项数量的选项

## 推理链
1. 第1步：题干五幅图元素组成不同，对称、曲直、开闭等属性均无明显统一规律，故转向数量规律
2. 第2步：逐一点数点、线、面、素均无递变规律；但图1、图2出现矩形和正方形边角，图3圆内直线垂直相交，提示应聚焦'直角'这一特殊角
3. 第3步：逐图数直角个数：图1（矩形/正方形结构）8个、图2（直角梯形加竖线）7个、图3（圆内垂直相交线）6个、图4（嵌套V形折线）5个、图5（扇形含折线）4个，构成8、7、6、5、4的递减数列
4. 第4步：按等差递减规律，问号处图形应恰有3个直角
5. 第5步：逐项数直角：A项4个、B项1个、C项3个、D项9个，仅C项为3个直角，符合规律

**最快解法**：⚡ 直角计数法：一旦发现矩形、正方形或垂直相交线元素，立即只数'直角'（不数锐角钝角），验证题干8→7→6→5→4递减后，直接在选项中找3个直角的图形，秒选C

## 易错点
- ⚠ 数角时未锁定'直角'，误数全部内角或锐角钝角总数，导致找不到8、7、6、5、4的规律
- ⚠ 忽略隐性直角：嵌套V形折线的折角、圆内垂直相交弦构成的直角容易被漏数
- ⚠ 选项三角形外框诱使误判：B项等腰三角形无直角却易被当成直角三角形；D项直角密集（9个）数错则可能误选D

## 母题抽象
> 🧩 当图形组成不同、点线面素数量均无规律，但图中出现矩形、正方形或垂直相交线等'直角信号'时，改数直角个数，验证是否呈等差递变并选满足下一项的选项

**同类特征**：元素组成不同、出现矩形/正方形、圆内垂直相交线、嵌套V形折线、直角数8-4递减、选项均为三角形内含线条

### 题干
从所给的四个选项中，选择最合适的一个填入问号处，使之呈现一定的规律性：

### 选项
- A. A
- B. B
- C. C　✅
- D. D

### 官方解析
元素组成不同，属性无明显规律，考虑数量规律。观察题干图形发现，点、线、面、素均无明显规律。再次观察，发现图1、图2出现矩形和正方形，图3圆中的直线都是垂直相交的，考虑数直角数量。题干图形中直角数分别是8、7、6、5、4，依次递减，故？处应选择有3个直角的图形。选项直角数分别为A项4个、B项1个、C项3个、D项9个，只有C项符合题干规律。
故正确答案为C。
