# 数量规律-笔画数（一笔画：奇点法+组合图形求和）

考点：[[20-考点/判断推理/图形推理/数量规律-笔画数（一笔画：奇点法+组合图形求和）|图形推理 / 数量规律-笔画数（一笔画：奇点法+组合图形求和）]]


**问法模型**：元素组成不同、属性无规律且出现多端点图形/日字变形图 → 拆分组合图形按'奇点数÷2'数最少笔画数，找与题干笔画数恒等的选项

## 推理链
1. 第1步：题干各图元素组成不相同也不相似，对称、曲直、开闭等属性无明显统一规律，转向数量规律。
2. 第2步：识别笔画数特征图——图一波浪线、图二火苗、图三回形针均为典型多端点图形，图四靴子、书本含日字变形结构，提示优先数笔画数。
3. 第3步：按'最少笔画数=奇点数÷2'拆分数题干：图一 箭头(1)+双波浪线(2)=3；图二 火苗(1)+铅笔(2)=3；图三 眼睛(2)+回形针(1)=3；图四 靴子(1)+书本(2)=3，题干笔画数恒为3。
4. 第4步：逐项数选项：A（飞机+量杯）、B（灯泡+闪电）、C（矩形+椭圆）各元素笔画数合计均不为3，排除。
5. 第5步：D项五角星(1)+带杆小圆(2)=3笔，与题干'笔画数均为3'的恒等规律一致，故选D。

**最快解法**：⚡ 奇点数笔画法+排除法：题干每幅图由两个独立小元素组成，逐元素数奇点求最少笔画再求和，得题干恒为3笔；速扫选项，仅D（五角星1笔+圆带杆小旗2笔）为3笔，秒选D

## 易错点
- ⚠ 特征图信号漏判：多端点图形（火苗、回形针、波浪）和日字变形图是笔画数题的标志，若先去数面或部分数易误选A或C
- ⚠ 本题设有多规律陷阱：按面数量周期23232会选A、按部分数周期32323会选C，需按'恒等规律优于周期规律'择优
- ⚠ 数笔画时忘记组合图形要拆成独立小元素分别计数再求和，或把奇点个数直接当作笔画数

## 母题抽象
> 🧩 当图形元素组成不同、属性无规律，且出现多端点图形（火苗/回形针/波浪类）或日字变形图时，用'奇点数÷2'逐元素数最少笔画并求和，验证选项笔画数与题干恒等

**同类特征**：元素组成不同不相似、属性无规律转数量、多端点图形、日字变形图、每幅图为两个独立小元素组合、笔画数恒为3
