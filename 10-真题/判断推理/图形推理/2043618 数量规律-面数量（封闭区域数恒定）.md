# 数量规律-面数量（封闭区域数恒定）

考点：[[20-考点/判断推理/图形推理/数量规律-面数量（封闭区域数恒定）|图形推理 / 数量规律-面数量（封闭区域数恒定）]]


**问法模型**：五个图呈现规律性，选第六图延续规律 → 元素组成不同先看属性，属性无规律则统一数面（封闭区域）数量

## 推理链
1. 第1步：题干五图分别为三角形组、T形线+圆+三角、大圆+月牙、半圆+竖线箭头、双圆+斜线，元素组成不同，对称、曲直等属性无统一规律
2. 第2步：按'属性不行数数量'的思路，逐图清点封闭区域（面）数
3. 第3步：图1三角形交叠、图2圆与三角及横线围出的封闭区、图3大圆与月牙、图4弧形上下两区加箭头围成区、图5两圆加斜线分割区，题干每图均含3个面
4. 第4步：逐项数选项：A项三圆两两相交共4个面，B项外框分割加双圆共4个面，C项四边形被线段分成4个三角形面，均为4个面，与题干不符
5. 第5步：D项箭头、矩形、内含椭圆共3个面，与题干'每图3个面'的恒定规律一致，故选D

**最快解法**：⚡ 数面法（数量规律口诀：属性不行数数量）——快速清点题干五图封闭区均为3个面，再扫选项：A/B/C均4个面、D为3个面，直接锁定D

## 易错点
- ⚠ A项三圆两两相交易误数成3个面，漏掉中央重叠出的第4个封闭区
- ⚠ D项箭头+矩形+椭圆的组合易只数椭圆漏数箭头或矩形区域，误判面数
- ⚠ 忽略线条交叠切割出的小封闭区（如图2圆与三角、横线的交叠处），导致题干面数数错

## 母题抽象
> 🧩 当题干图形元素组成不同、对称/曲直等属性无规律时，改为数封闭区域（面）数量；若五图面数恒定（如均为3面），则选面数相同的选项。

**同类特征**：元素组成不同、属性无明显规律、每图3个面、封闭区域数量、线条交叠围成面、数量规律-面

### 题干
上边的题干中给出一套图形，其中有五个图，这五个图呈现一定的规律性。在下边给出一套图形，从中选出唯一的一项作为保持上边五个图规律性的第六个图。

### 选项
- A. A
- B. B
- C. C
- D. D　✅

### 官方解析
元素组成不同，属性无明显规律，考虑数量规律。题干中每个图形都有3个面，选项A、B、C都是4个面，D是3个面。
故正确答案为D。
