# 样式规律-元素遍历（相邻图形求同-公共元素长方形）

考点：[[20-考点/判断推理/图形推理/样式规律-元素遍历（相邻图形求同-公共元素长方形）|图形推理 / 样式规律-元素遍历（相邻图形求同-公共元素长方形）]]


**问法模型**：'选择最合适的一个填入问号处，使之呈现一定的规律性'且各图元素组成相似、某元素反复出现 → 用样式求同（遍历）模型：题干每图均含的元素，问号处图形也必须包含

## 推理链
1. 第1步：观察题干四幅已知图，元素组成相似：图1中部小长方形、图2外框长方形、图3中间水平长方形、图4外部长方形边框——长方形元素在每幅图中至少出现一次
2. 第2步：依据样式规律中的遍历/求同规则，公共元素（长方形）应延续到问号处图形
3. 第3步：逐项对照：A项含倾斜放置的小长方形，满足；B项为六边形内含两个三角形（沙漏形），无长方形
4. 第4步：C项为立方体透视图，各面呈平行四边形而非标准长方形，且正面被椭圆占据，不满足；D项为圆内含五边形，无长方形
5. 第5步：只有A项包含长方形元素，与题干公共元素规律一致，故选A

**最快解法**：⚡ 求同法（找公共元素）：快速扫视题干四图，锁定'每图都有长方形'这一公共元素，再到选项中找含长方形的图形，A项倾斜小长方形直接锁定答案A

## 易错点
- ⚠ 误选C：立方体透视图的'面'看似方形，但立体图中各面实为平行四边形且正面被椭圆覆盖，并非标准长方形
- ⚠ 漏选A：A项长方形倾斜放置，误以为'歪的不算长方形'而排除
- ⚠ 走数量规律歧路：误去数面数、线数、交点数，而忽略'元素组成相似'应优先考虑样式求同的提示

## 母题抽象
> 🧩 当题干各图元素组成相似且同一元素（如长方形、三角形、圆）在每幅图中反复出现时，优先用样式求同（遍历）：问号处图形必须包含该公共元素，据此排除选项

**同类特征**：元素组成相似、长方形元素每图出现、相邻图形求同、样式类遍历、五图序列含问号

### 题干
从下列所给四个选项中选择最合适的一个填入问号处，使之呈现一定的规律性：

### 选项
- A. A　✅
- B. B
- C. C
- D. D

### 官方解析
元素组成相似，且某些元素不止一次出现在各图形中，优先考虑样式规律中的遍历。比较相邻图形发现，题干已知图形都包含长方形元素，故问号处图形也应满足此规律，只有A项符合。
故正确答案为A。
