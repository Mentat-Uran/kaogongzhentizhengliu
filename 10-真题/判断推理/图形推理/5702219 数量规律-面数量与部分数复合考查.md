# 数量规律-面数量与部分数复合考查

考点：[[20-考点/判断推理/图形推理/数量规律-面数量与部分数复合考查|图形推理 / 数量规律-面数量与部分数复合考查]]


**问法模型**：题干问'符合所给图形的变化规律的是'（一组图顺推、末位问号）→ 元素组成不同且属性无统一规律时转数量规律，先用'面数量'排除，再用'部分数'锁定唯一

## 推理链
1. 第1步：题干为'四个已知图+？'的顺推型，元素组成不同，曲直、对称、开闭等属性规律不明显，按'属性不行看数量'转向数量规律。
2. 第2步：题干图形分割特征明显（图1梯形内被折线分割、图2含圆圈封闭区、图3折线交叉围出封闭区、图4云朵被内弧线分割），优先数'面'：图1~图4的面数量均为2。
3. 第3步：故？处图形面数量应为2——B项三角形内部被线条分割出3个面、C项开口框内交叉线形成4个面，均不为2，排除B、C。
4. 第4步：A、D面数量均为2，需启用二级规律'部分数'（图形是否连通为一部分）：题干图1~图4均连为一体，部分数均为1。
5. 第5步：A项为上下两个互不相连的箭头形，部分数为2，排除；D项三角形加一条横线，面数量为2、部分数为1，与题干规律完全吻合，当选。

**最快解法**：⚡ '数面→数部分'两步排除法：先数面，题干均为2个面，B(3面)、C(4面)秒排；再验部分数，题干均为1部分，A为2部分排除，直接锁定D，全程约20秒。

## 易错点
- ⚠ 只验证面数量、漏做部分数二级验证：A项面数量同为2，是最强干扰项，不数部分数极易误选A
- ⚠ 数面不严谨：C项顶部开口处未封闭不能算面，应数框内交叉线围成的4个封闭三角形，漏数或多数都会排错选项
- ⚠ 图2（图钉状）封闭面小而易看漏，误以为题干面数量不统一，从而放弃'数面'思路绕弯路

## 母题抽象
> 🧩 当一组图'元素组成不同、无属性规律'且图形带有明显封闭区域（内部线条分割、交叉线、轮廓内含弧线）时，先数面数量框定范围，再用部分数（是否连通为一部分）二次筛选，两把尺子量出唯一答案。

**同类特征**：元素组成不同、图形分割明显、含封闭区域、面数量恒为2、部分数恒为1（整体连通）、顺推型问号求规律、存在面数量相同的干扰项需部分数辨析

### 题干
下列选项中，符合所给图形的变化规律的是        。

### 选项
- A. A
- B. B
- C. C
- D. D　✅

### 官方解析
元素组成不同，无明显属性规律，考虑数量规律。观察发现，图形分割明显，考虑数面，题干图形的面数量均为2，故？处图形的面数量应为2，排除B、C两项；继续观察发现，题干图形的部分数均为1，故？处图形的部分数应为1，只有D项符合。
故正确答案为D。
