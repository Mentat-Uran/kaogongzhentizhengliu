# 数量规律-笔画数（奇点数-一笔画判定）

考点：[[20-考点/判断推理/图形推理/数量规律-笔画数（奇点数-一笔画判定）|图形推理 / 数量规律-笔画数（奇点数/一笔画判定）]]


**问法模型**：'选择最合适的一个填入问号处使之呈现一定规律性'且元素组成不同 → 先看属性再看数量，本题用'数奇点判一笔画'模型

## 推理链
1. 第1步：题干五幅图（三叉箭头、直角三角形、块状箭头、折线箭头、三角形叠矩形）元素组成不同，无位置与样式规律，转向属性与数量规律
2. 第2步：各图均为连通图形，套用一笔画判定规则：连通图中奇点（引出奇数条线的点）数为0或2时可一笔画出
3. 第3步：数题干图形奇点——前四幅图奇点数均为0，第五幅图奇点数为2，五幅图全部为一级笔画图形，故问号处应填一笔画图形
4. 第4步：逐项数奇点——A项（'田'字变形的圆内十字）4个奇点，两笔画；B项（'田'字变形方格）4个奇点，两笔画；C项（波浪线加横线）曲线两端与直线两端共4个奇点，两笔画
5. 第5步：D项（五边形加一条对角线/'日'字变形）仅对角线与顶点相交的2个奇点，一笔画，为唯一符合规律的选项，故选D

**最快解法**：⚡ 奇点计数法：先确认图形连通，再数奇点——奇点数为0或2即一笔画；快速扫出A、B、C均有4个奇点（两笔画）予以排除，D仅2个奇点（一笔画）直接锁定

## 易错点
- ⚠ 漏数端点：C项波浪线与直线的自由端点各引出1条线，是奇点，漏数会误判其为一笔画
- ⚠ 把偶点误判为奇点：A项圆内十字的中心交点引出4条线是偶点，交叉密集处数线易出错
- ⚠ 忽略'连通'这一一笔画前提，未先确认连通就直接数奇点，或把'田'字变形类图形凭直觉当作一笔画

## 母题抽象
> 🧩 当题干图形元素组成不同且出现'日''田'字变形、封闭箭头轮廓、带端点的线条等特征时，优先数奇点判笔画：连通且奇点数为0或2→一笔画，奇点数为2n(n≥2)→n笔画，据此排除选答案

**同类特征**：元素组成不同、日字变形/田字变形、封闭箭头轮廓、带端点的线条、奇点数、一笔画与两笔画

### 题干
从所给四个选择中，选择最合适的一个填入问号处，使之呈现一定规律性：

### 选项
- A. A
- B. B
- C. C
- D. D　✅

### 官方解析
元素组成不同，考虑属性规律和数量规律。观察发现，A项、B项为“田”字变形图，图5和D项为“日”字变形图，可考虑笔画数。题干前四幅图，奇点数均为0，是一笔画，第五幅图奇点数为2，也是一笔画，故？处图形应为一笔画图形。A项、B项、C项均有4个奇点，是两笔画图形，D项有2个奇点，是一笔画图形。
故正确答案为D。
