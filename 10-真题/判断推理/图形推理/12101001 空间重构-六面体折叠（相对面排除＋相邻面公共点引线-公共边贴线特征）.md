# 空间重构-六面体折叠（相对面排除＋相邻面公共点引线-公共边贴线特征）

考点：[[20-考点/判断推理/图形推理/空间重构-六面体折叠（相对面排除＋相邻面公共点引线-公共边贴线特征）|图形推理 / 空间重构-六面体折叠（相对面排除＋相邻面公共点引线/公共边贴线特征）]]


**问法模型**：'右边哪一项能由左边展开图折叠而成'→空间重构题：先把孤立面平移归位并给各面标号，再用'相对面排除＋相邻三面公共点/公共边细节指纹'逐一验证选项

## 推理链
1. 第1步：将展开图右下角孤立的面平移到相贴位置，对六个面进行标号（面e、面f、面g、面h、面i、面k），建立分析基准
2. 第2步：先找相对面做排除——展开图中面f和面k为相对面，折叠后不能在同一视图中同时出现
3. 第3步：A项一定含面i和面f，故其右面只能是面e；展开图中面e、面f、面i三面的公共点只引出1条线，而A项该公共点引出2条线，与展开图不一致，排除
4. 第4步：B项由面e、面g与面k构成，三面相邻关系及公共边、公共点引线细节均与展开图一致，保留
5. 第5步：C项一定含面h和面i，展开图中面h与面i的公共边挨着面h中的两条线，而C项中该公共边只挨着面h中的一条线，排除
6. 第6步：D项由面f、面h和面i构成，展开图中三个面的公共点引出2条线，而D项中该公共点只引出1条线，排除；故正确答案为B

**最快解法**：⚡ 相对面排除＋公共点引线数指纹法：先判定面f与面k为相对面；再以'三面公共点引出几条线'（e-f-i为1条、f-h-i为2条）和'公共边贴着几条线'（h-i公共边贴面h两条线）为指纹，逐一核对选项，排除A、C、D锁定B

## 易错点
- ⚠ 忽略展开图右下角孤立的面需先平移归位再标号，直接判相对面/相邻面会错位
- ⚠ 数公共点引出的线条数出错：线条恰好穿过公共点时易把1条数成2条或漏数，A、D项均靠此细节排除
- ⚠ 把公共边'挨着几条线'误看成面内线条总数，忽略线与公共边的相对位置（C项排除依据）

## 母题抽象
> 🧩 当六面体展开图各面均为线条图案、单面图案无法直接排除选项时，先平移孤立面并标号→用相对面排除→再用'公共点引线数/公共边贴线数'作为相邻面指纹逐一验证

**同类特征**：六面体外表面展开图折叠、展开图中含孤立待移动的面、面内图案为线条、五边形、圆形等、相对面不可同时出现、公共点引出线条数（1条/2条）、公共边紧挨的线条数

### 题干
左边给定的是六面体的外表面展开图，右边哪一项能由它折叠而成？

### 选项

- B. B　✅
- C. C
- D. D

### 官方解析
本题考查六面体。将展开图中右下角的面移动，并给每个面标号，如下图所示，逐一进行分析。

A项：选项一定有面i和面f，右面为面e或面k，展开图中面f和面k为相对面，无法同时出现，故右面为面e。展开图中面e、面f和面i的公共点引出一条线，而选项中三个面的公共点引出两条线，选项与题干展开图不一致，排除；
B项：选项由面e、面g与面k构成，选项与题干展开图一致，当选；
C项：选项一定有面h和面i，展开图中面h与面i的公共边挨着面h中的两条线，而选项中两个面的公共边只挨着面h中的一条线，选项与题干展开图不一致，排除；
D项：选项由面f、面h和面i构成，展开图中三个面的公共点引出两条线，而选项中三个面的公共点只引出一条线，选项与题干展开图不一致，排除。
故正确答案为B。
