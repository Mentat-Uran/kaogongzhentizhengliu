# 位置规律-旋转移动（同心内外圈分轨追踪）

考点：[[20-考点/判断推理/图形推理/位置规律-旋转移动（同心内外圈分轨追踪）|图形推理 / 位置规律-旋转移动（同心内外圈分轨追踪）]]


**问法模型**：'元素组成相同、小元素在内外圈扇格间换位，选？处图形' → 拆分内圈/外圈两条轨道，各锁定一个特征元素，数步长、定方向，逐项排除

## 推理链
1. 第1步：五幅图元素组成相同（均含黑色五角星、白色五角星、三角形、圆点、五边形等），无增减变化，优先考虑位置规律
2. 第2步：图形为同心双圆结构，元素分别落在内圈扇格与外圈扇格，应拆成内圈、外圈两条轨道分别找移动规律
3. 第3步：内圈锁定'黑色五角星'，观察得它沿内圆每次逆时针移动2格；由第四幅图再逆时针移2格，A项位置不符，排除A
4. 第4步：B、C、D三项内圈其余元素位置完全相同，规律无法区分，转而观察外圈
5. 第5步：外圈锁定'白色五角星'，观察得它每次顺时针移动1格；由第四幅图再顺时针移1格，B、D位置不符，排除B、D
6. 第6步：仅C项同时满足内圈黑五角星逆时针2格、外圈白五角星顺时针1格的移动规律，故选C

**最快解法**：⚡ 拆圈追踪法（特征元素定位）：内外圈分开看，先盯内圈'黑色五角星'按逆时针2格走一步排除A；再用外圈'白色五角星'按顺时针1格走一步排除B、D，直接锁定C

## 易错点
- ⚠ 把内外圈当成一个整体数格子，步长被两圈混在一起，找不出规律
- ⚠ 只盯一个元素一条轨道，忽略'另一条轨道需换特征元素再验证'，在B/C/D中卡住
- ⚠ 方向或步长看错：顺时针/逆时针看反，或把内圈2格、外圈1格的步长记混

## 母题抽象
> 🧩 当题干图形为同心双圈、相同小元素在扇格间换位时，拆内外两条轨道，各锁定一个易识别元素（如黑色五角星），数步长定方向，逐项排除选项

**同类特征**：元素组成相同、同心圆内外圈双层结构、小元素在扇格间规律移动、黑白元素对比鲜明便于追踪、单元素规律不足以区分时需换元素二次验证

### 题干
从所给的四个选项中，选择最合适的一个填在问号处，使之呈现一定的规律性：

### 选项
- A. A
- B. B
- C. C　✅
- D. D

### 官方解析
元素组成相同，考虑位置规律。每个图形分为内圈和外圈两部分。先看内圈，有四个不同的元素，挑一个观察，内圈的黑色五角星沿内圆每次逆时针移动2格，由第四幅图到？处，黑色五角星也应逆时针移动2格，排除A项。B、C、D内部其他元素位置相同，考虑外圈位置变化。外圈的白色五角星每次顺时针移动1格，由第四幅图到？处，白色五角星也应顺时针移动1格，排除B、D两项。
故正确答案为C。
