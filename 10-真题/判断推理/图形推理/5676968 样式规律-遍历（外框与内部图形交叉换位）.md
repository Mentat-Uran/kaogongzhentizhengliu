# 样式规律-遍历（外框与内部图形交叉换位）

考点：[[20-考点/判断推理/图形推理/样式规律-遍历（外框与内部图形交叉换位）|图形推理 / 样式规律-遍历（外框与内部图形交叉换位）]]


**问法模型**：两组图形求问号处图形 → 两段式遍历模型：从第一组归纳'外框与内部图形'的组合规律，机械套用到第二组缺项

## 推理链
1. 第1步：第一组中，图一为'梯形外框+三角形内部'，图二为'正方形外框+圆形内部'，图三为'圆形外框+梯形内部'，每图均由外框和内部两层图形构成
2. 第2步：归纳规律——图一的外框（梯形）成为图三的内部图形，图二的内部图形（圆形）成为图三的外框，即内外元素交叉遍历、三种图形各出现两次
3. 第3步：第二组中，图一为'正方形外框+圆形内部'，图二为'三角形外框+梯形内部'，按同样规律，？处外框应取图二的内部图形（梯形），内部应取图一的外框（正方形）
4. 第4步：对照选项——A为正方形外框+圆形内部，B为梯形外框+圆形内部，C为三角形外框+圆形内部，均不符
5. 第5步：D为梯形外框+正方形内部，与推导完全一致，故选D

**最快解法**：⚡ 排除法+元素遍历口诀：先看外框，第二组已有正方形、三角形，缺梯形→排除A、C；再看内部，第二组已有圆形、梯形，缺正方形→排除B，锁定D

## 易错点
- ⚠ 只盯外框或只盯内部单一维度，未做两层交叉验证，可能误选B
- ⚠ 把规律误解为'外框元素在第三图继续做外框'的简单依次遍历
- ⚠ 梯形与三角形轮廓相近，审图不细易看混第二组图二的外框与内部

## 母题抽象
> 🧩 当两组图形均由'外框+内部'两层元素构成且元素重复出现时，用遍历法：分别统计两组已出现的外框和内部元素，缺什么补什么，交叉对应即得答案

**同类特征**：元素组成相似、外框+内部两层嵌套结构、相同元素重复出现、两组对照（两段式）、问号求第三幅图

### 题干
符合所给图形规律的一项是        。

### 选项
- A. A
- B. B
- C. C
- D. D　✅

### 官方解析
元素组成相似，优先考虑样式规律。题干图形均有外框和内部图形，且相同元素重复出现，考虑遍历。第一组图形中图一的外框成为图三的内部图形，图二的内部图形成为图三的外框；第二组图形运用此规律，故？处图形的内部图形应为图一的外框，？处图形的外框应为图二的内部图形，只有D项符合。
故正确答案为D。
