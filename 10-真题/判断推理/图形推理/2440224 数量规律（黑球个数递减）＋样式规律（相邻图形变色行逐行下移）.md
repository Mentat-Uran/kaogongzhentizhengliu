# 数量规律（黑球个数递减）＋样式规律（相邻图形变色行逐行下移）

考点：[[20-考点/判断推理/图形推理/数量规律（黑球个数递减）＋样式规律（相邻图形变色行逐行下移）|图形推理 / 数量规律（黑球个数递减）＋样式规律（相邻图形变色行逐行下移）]]


**问法模型**：'填入问号处使之呈现规律性'且图形为黑白球点阵 → 先数黑球数量定递变趋势做第一轮排除，再逐行比较相邻图形找变色位置移动规律做第二轮排除

## 推理链
1. 第1步：题干五幅图均为黑白球点阵，元素组成不同，优先考虑数量规律：图一至图五黑球数依次为14、13、12、11、10，呈每次递减1的等差趋势
2. 第2步：由数量规律推出？处应为9个黑球的图形，选项中B、C两项黑球数不是9，排除B、C
3. 第3步：再比较相邻图形找变化位置：图二与图一相比仅第一行黑白颜色变动、其余行不变；图三与图二相比仅第二行变动；图四与图三相比仅第三行变动；图五与图四相比仅第四行变动
4. 第4步：归纳规律：发生变色的行依次为第1、2、3、4行，逐行下移，故？处图形应与图五相比仅第五行颜色变动、其余四行保持不变
5. 第5步：对照剩余选项：A项与图五相比除第五行外其他行也有变动，不满足'仅第五行变色'，排除A
6. 第6步：D项黑球数为9，且与图五相比仅第五行变色、其余行不变，同时满足数量与位置两条规律，故选D

**最快解法**：⚡ 排除法＋'变色行下移'规律：先数黑球（14→13→12→11→10→9）排除B、C；再将剩余选项与图五逐行对比，锁定'只有第五行变色、其余四行不变'的一项，排除A选D

## 易错点
- ⚠ 只验证黑球数量为9，忽略'逐行变色'的样式规律，在同为9球的A、D中误选A
- ⚠ 比较相邻图形时看错变色行顺序，未发现变色行为第1、2、3、4行依次下移，误去寻找循环或对称规律
- ⚠ 黑白球数量多且密集，数个数时漏数或多数，导致第一轮排除出错

## 母题抽象
> 🧩 当题干为黑白球（黑白格）点阵且元素组成不同时，先数黑球个数找递变趋势做第一次排除，再逐行（列）比较相邻图形找'变色位置依次移动'的规律做第二次排除，双重验证锁定答案

**同类特征**：黑白球点阵（多行多列）、元素组成不同、黑球数量依次递减1、相邻图形仅一行颜色变动、变色行自上而下逐行移动、六宫格前五图加问号求第六幅

### 题干
从所给四个选项中，选择最合适的一个填入问号处，使之呈现一定规律性。

### 选项
- A. A
- B. B
- C. C
- D. D　✅

### 官方解析
元素组成不同，每幅图都有小黑球，发现小黑球数量从图一到图五依次递减，分别为14、13、12、11、10，？处应选择一个9个黑球的，排除B、C两项。再次观察题干发现，图二和图一相比只有第一行颜色变动，其他行不变，图三和图二相比只有第二行颜色变动，其他行不变，图四和图三相比只有第三行颜色变动，其他行不变，图五和图四相比只有第四行颜色变动，其他行不变，因此问号处应该是第五行和前一幅图相比颜色变动，其他行不变。排除A项，只有D项符合。
故正确答案为D。
