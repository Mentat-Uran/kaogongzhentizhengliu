# 样式规律-元素遍历（内外结构分开看：形状遍历+颜色遍历）

考点：[[20-考点/判断推理/图形推理/样式规律-元素遍历（内外结构分开看：形状遍历+颜色遍历）|图形推理 / 样式规律-元素遍历（内外结构分开看：形状遍历+颜色遍历）]]


**问法模型**：题干为六宫格'填入问号处使之呈现规律性'，且元素组成相似、同一元素反复出现 → 采用遍历规律，将内外两层拆开分别找形状与颜色的循环缺项

## 推理链
1. 第1步：题干5幅图均由'外部大图形+内部小图形'嵌套而成，且○、◇、□等形状不止一次出现，符合'元素组成相似、同元素重复出现'的遍历特征
2. 第2步：内外结构明显，按'分开看'原则分层处理：先看外部形状，再看内部形状，最后看内部颜色
3. 第3步：外部形状依次为○、◇、□、○、◇，以'○◇□'三个形状为一组循环，问号处应补□，故排除外框为○的A、C两项
4. 第4步：内部形状依次为◇、□、○、◇、□，同样三元素循环，问号处内部应为○，B、D两项内部均为圆形，符合
5. 第5步：内部颜色依次为黑、白、阴影、黑、白，按'黑→白→阴影'三色循环，问号处内部应为阴影，B、D中D项内部为黑色实心圆，排除D
6. 第6步：仅B项同时满足'外部□+内部阴影○'，与官方答案B一致

**最快解法**：⚡ 遍历法+内外分开看：第一眼数外框形状，○◇□循环缺□，直接锁定B、D两项；再对比B、D内部同圆但颜色不同，用内部颜色'黑、白、阴影'循环缺'阴影'排除D，秒选B

## 易错点
- ⚠ 二级辨析缺位：B、D外框和内部形状都相同，只做到形状遍历就卡住，必须继续对内部颜色做第三层遍历
- ⚠ 忽略第2、4幅图中内外图形之间填充的'阴影'，把颜色序列'黑、白、阴影'错看成只有'黑、白'两种，循环规律判断失误
- ⚠ 遍历分组看错：误以为形状/颜色是两两对称或递变规律，实际是三元素'○◇□'与'黑·白·阴影'一组循环，问号处补足第三组的最后一个元素

## 母题抽象
> 🧩 当题干图形元素组成相似、同一形状或颜色不止一次出现且呈内外嵌套结构时，用'分开看+遍历法'：分别列出外层形状、内层形状、内层颜色的出现序列，找出每层的循环周期，问号处补足缺项并逐层排除选项

**同类特征**：元素组成相似、同一元素重复出现、内外嵌套（外框+内芯）结构、○◇□三种外框形状、黑/白/阴影三种填充色、六宫格问号处补遍历缺项

### 官方解析
图形元素组成相似，同一个元素不止一次出现，优先考虑遍历。图形都是由内外两个图形组成，优先考虑分开看。外部图形的形状分别为○、◇、□、○、◇，形状遍历，最后问号处应为□，排除A、C两项；B、D两项内部图形形状相同，区别在于颜色，而题干内部图形的颜色分别是黑、白、阴影、黑、白，颜色遍历，最后一幅应该是阴影，排除D项。
故正确答案为B。
