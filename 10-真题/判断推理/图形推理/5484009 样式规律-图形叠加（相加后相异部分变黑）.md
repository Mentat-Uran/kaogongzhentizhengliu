# 样式规律-图形叠加（相加后相异部分变黑）

考点：[[20-考点/判断推理/图形推理/样式规律-图形叠加（相加后相异部分变黑）|图形推理 / 样式规律-图形叠加（相加后相异部分变黑）]]


**问法模型**：两套图形'前两图→第三图'对照求同 → 先由第一套归纳样式叠加规律，再原样套用到第二套选答案

## 推理链
1. 第1步：第一套中图1为直角三角形（左竖线、下横线、左上至右下斜边），图2为竖直长方形，元素组成相似且相同线条重复出现，优先考虑样式规律中的加减同异。
2. 第2步：观察第一套图3：整体轮廓恰为图1与图2重叠相加后的并集形状，验证出规则——两图重合（相同）的区域保持白色，仅属于其中一图（相异）的区域涂成黑色。
3. 第3步：将规则迁移到第二套：图1为带直角的L形折线多边形，图2为沙漏形（上下两条横线加中间两条交叉斜线），二者叠加后重合区域留白、相异区域变黑。
4. 第4步：据此锁定问号处图形应同时满足两个条件：外轮廓为两图并集形状，内部黑块只出现在两图不重合的部位。
5. 第5步：逐项对照：A项的黑色区域位置与两图相异部位吻合、重合的沙漏中部留白，符合规律；B、C、D的黑块位置/形状与'相异区域涂黑'的结果不符，排除。
6. 第6步：只有A项同时满足两套图形的最大相似性与第二套自身特征，故选A。

**最快解法**：⚡ 样式叠加口诀法：先看第一套确认'相加后不同的地方变成黑色'，再把第二套两图轮廓快速叠加，直接比对各选项黑块出现的位置，A项黑块恰落在相异区域，一票锁定。

## 易错点
- ⚠ 把规律误判为线条'去同存异（求同存异）'，只盯线条增减而忽略本题是'相异区域涂黑'的面叠加
- ⚠ 只看叠加后的外轮廓并集、不核对内部黑白的归属，容易误选轮廓相近的B或C
- ⚠ 沙漏形中心交叉线附近的区域归属易看错，忽略交叉处小区域的黑白判断

## 母题抽象
> 🧩 当两套图形出现'元素相似+相同线条重复出现'特征时，先用第一套归纳叠加规则（如相异变黑、同存异去、黑白叠加），再用黑块/线条位置逐项验证第二套。

**同类特征**：两套图形对照求问号、元素组成相似、相同线条重复出现、第一套图3出现黑色填充区域、叠加类样式运算

### 题干
每道题包含两套图形和可供选择的4个图形。这两套图形具有某种相似性，也存在某种差异。要求你从四个选项中选择最适合取代问号的一个。正确的答案不仅使两套图形表现出最大的相似性，而且使第二套图形也表现出自己的特征。

### 选项
- A. A　✅
- B. B
- C. C
- D. D

### 官方解析
元素组成相似，且相同线条重复出现，优先考虑样式规律中的加减同异。观察发现，第一组图形中图一与图二相加，相加后不同的地方变成黑色，得到图三。第二组图形也应遵循此规律，图一与图二相加，相加后不同的地方变成黑色，只有A项符合。
故正确答案为A。
