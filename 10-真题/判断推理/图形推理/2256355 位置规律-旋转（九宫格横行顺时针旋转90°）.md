# 位置规律-旋转（九宫格横行顺时针旋转90°）

考点：[[20-考点/判断推理/图形推理/位置规律-旋转（九宫格横行顺时针旋转90°）|图形推理 / 位置规律-旋转（九宫格横行顺时针旋转90°）]]


**问法模型**：九宫格问号处选图形使呈现规律性 → 元素组成相同时优先横行观察位置规律（旋转角度）

## 推理链
1. 第1步：观察题干，三行图形均'元素组成相同'（同一样式箭头、同叠层卡片、同锯齿形），只是角度/朝向变化，锁定位置规律
2. 第2步：第一行最直观——图1箭头向右→图2箭头向下→图3箭头向左，每次顺时针旋转90°
3. 第3步：第二行验证——叠层卡片的叠边露出口由'上方+右侧'→'右侧+下方'→'左侧+下方'，同样每次顺时针旋转90°，规律成立
4. 第4步：第三行应用——把图2的锯齿形顺时针旋转90°即为问号处图形
5. 第5步：逐项对照——旋转后长短齿的分布朝向与B项完全吻合，A项朝向不符，C、D项旋转角度/朝向不符，故选B

**最快解法**：⚡ 位置规律口诀'九宫格先横看'+排除法：用第一行箭头快速确认'顺时针旋转90°'（右→下→左），第二行验证后，直接将第三行图2顺时针转90°与四个选项比对，锁定B。

## 易错点
- ⚠ 锯齿形不规则图形旋转后难以目测，易把'顺时针90°'误看成翻转或180°旋转而错选A或D
- ⚠ 忽略'元素组成相同'这一信号，跑去数面、线、角的数量规律
- ⚠ 九宫格习惯竖看或走S形/米字形路径，本题规律只在横行成立

## 母题抽象
> 🧩 当九宫格各图元素组成相同、仅朝向/角度变化时，先横行找旋转规律（用最简单直观的那一行如箭头确定角度与方向），其余行验证后，将问号前一图按该角度旋转再对照选项。

**同类特征**：九宫格、元素组成相同、第一行箭头朝向依次变化、叠层卡片叠边位置变化、第三行为不规则锯齿形、每行顺时针旋转90°

### 题干
从所给的4个选项中，选择最适合的一个填入问号处，使之呈现一定的规律性：

### 选项
- A. A
- B. B　✅
- C. C
- D. D

### 官方解析
本题为九宫格题目。
元素组成相同，考虑位置规律。九宫格优先横着看，第一行，图1到图2，顺时针旋转，图2到图3，顺时针旋转，第二行验证规律，符合规律。第三行应用规律，图2旋转到“？”处，只有B项符合。
故正确答案为B。
