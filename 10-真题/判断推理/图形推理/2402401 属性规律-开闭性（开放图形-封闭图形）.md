# 属性规律-开闭性（开放图形-封闭图形）

考点：[[20-考点/判断推理/图形推理/属性规律-开闭性（开放图形-封闭图形）|图形推理 / 属性规律-开闭性（开放图形/封闭图形）]]


**问法模型**：问号处填入图形使整组呈现规律 → 元素组成不同，优先属性规律，本题考开闭性（题干全为开放图形，选同为开放的一项）

## 推理链
1. 第1步：题干依次为数字'5'、字母'G'、汉字'手'、'坐标系+双曲线一支'和'?'，图形种类杂、元素组成不同，优先考虑属性规律。
2. 第2步：逐一检查封闭性：'5'笔画不闭合、'G'留有缺口、'手'四笔均未围成封闭区域、坐标系与曲线之间也无闭合回路，全组均为开放图形（无封闭区域）。
3. 第3步：归纳规律：'?'处应填入一个开放图形（不含任何封闭区域）。
4. 第4步：对照选项：A'文'中撇、捺上端与横线围出1个封闭三角形，属含封闭区域图形，排除；B两片叶片轮廓闭合，属封闭图形，排除；C'8'含上下两个封闭圈，排除；D坐标系与曲线均无封闭区域，为开放图形，当选。

**最快解法**：⚡ 开闭性速判（找'洞'）：快速扫每个图形是否围出封闭区域，题干全部无'洞'→排除带'洞'的A（文的撇捺与横围成三角洞）、B（叶片闭合）、C（8字双洞），一眼锁定无洞的D。

## 易错点
- ⚠ 误把A'文'当开放图形：撇、捺上端相接并与横线围成一个封闭三角形，'文'实为含封闭区域的图形，是本题最强干扰项。
- ⚠ 忽略'元素组成不同优先看属性'的解题顺序，误入笔画数、对称性等数量/位置规律的死胡同。
- ⚠ 把D中曲线与坐标轴误判为围成封闭区域，实际曲线两端开放、与坐标轴未构成闭合回路。

## 母题抽象
> 🧩 当一组图形由数字、字母、汉字、函数曲线等异质元素混搭且组成不同时，优先验属性规律中的开闭性：若题干全为开放图形（无封闭区域），则逐项排除一切含封闭区域的选项，锁定同为开放的一项。

**同类特征**：数字与字母混排（5、G）、汉字'手'、坐标系+曲线图、元素组成不同、全组无封闭区域、开放图形规律
