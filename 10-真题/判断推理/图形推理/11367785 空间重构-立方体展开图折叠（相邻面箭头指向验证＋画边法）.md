# 空间重构-立方体展开图折叠（相邻面箭头指向验证＋画边法）

考点：[[20-考点/判断推理/图形推理/空间重构-立方体展开图折叠（相邻面箭头指向验证＋画边法）|图形推理 / 空间重构-立方体展开图折叠（相邻面箭头指向验证＋画边法）]]


**问法模型**：'哪一项可能是立方体的外表面展开图' → 以带方向性图案（箭头）的面为锚点，用相邻面箭头指向关系逐项排除，必要时画边法定精确位置

## 推理链
1. 第1步：从立体图提取三个可见箭头面e面、f面、g面的位置特征：三面两两相邻，且g面箭头的'箭尾'对着e面所在的那条边
2. 第2步：确立第二条指向特征：e面中的箭头指向f面中箭头的'箭尖'（而非箭身），这是逐项比对的锚点
3. 第3步：方法选择——相邻面箭头指向验证法为主，画边法（以特征边为起点顺时针数边）为辅精确定位
4. 第4步：验证A项——选项中g1面、g2面箭头的箭尾均对着f2面，与题干'g面箭尾对着e面'不符，排除
5. 第5步：验证B项——选项中e1面、e2面箭头均指向f2面中箭头的'箭身'，与题干'e面箭头指向f面箭尖'不符，排除
6. 第6步：验证C项——以e面单箭头箭尖所指边为起始边顺时针画边，题干中边4对应g面的箭尾，而选项中e1/e2面画边后边4均不对应g面箭尾，排除
7. 第7步：验证D项——由e1面、g1面、f2面构成与题干相同的相邻关系和箭头指向，折叠后与立体图完全一致，当选

**最快解法**：⚡ 锚点排除法：先用最强特征'g面箭尾对着e面'秒杀排除A；再用'e面箭头指向f面箭尖（不是箭身）'排除B；最后对C、D用画边法（以e面箭尖所指边为起点顺时针数边），核对边4是否对应g面箭尾，选出D

## 易错点
- ⚠ 只比对箭头样式（单箭头/双箭头）不看箭头相对相邻面的指向，漏掉'箭尾对e面'与'箭尾对f2面'这类关键差异
- ⚠ '指向箭尖'与'指向箭身'的区分不够细，B项箭头样式完全相同却指向错误，容易误选
- ⚠ 画边法数边时起始边选取不当或顺/逆时针方向不统一，导致边序错位、误判C项

## 母题抽象
> 🧩 当立体图各面带方向性图案（箭头、字母、图形有朝向）时，以'图案指向相邻面的哪条边/哪个部位'为锚点逐项验证展开图，样式相同用画边法（从特征边顺时针数边）定位

**同类特征**：立方体可见三面均为箭头图案、箭头有明确指向（箭尾/箭尖）、三面两两相邻共顶点、选项为六面展开图且箭头样式相近、需验证折叠后指向一致性、画边法/时针法适用

### 题干
左边给定的是一个立方体，右边哪一项可能是它的外表面展开图？

### 选项
- A. A
- B. B
- C. C
- D. D　✅

### 官方解析
将题干立体图和选项展开图的面均标上序号，如下图所示，逐一进行分析。

A项：题干立体图中g面中箭头的箭尾对着e面，而选项中无论是g1面还是g2面，箭头的箭尾均对着f2面，选项展开图与题干立体图不一致，排除；

B项：题干立体图中e面中箭头指向f面中箭头的尖，而选项中无论是e1面还是e2面，箭头均指向f2面中箭头的箭身，选项展开图与题干立体图不一致，排除；

C项：以e面中单箭头尖指向的边为起始边，在题干立体图和选项展开图中进行顺时针画边（如下图所示），题干立体图中边4对应g面中的箭尾，而选项中无论是e1面还是e2面，边4均不对应g面中的箭尾，选项展开图与题干立体图不一致，排除；

D项：题干由e1面、g1面和f2面组成，选项展开图与题干立体图一致，当选。
故正确答案为D。
