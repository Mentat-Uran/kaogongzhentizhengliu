# 图形推理-位置规律（旋转-九宫格米字型两端互为旋转）

考点：[[20-考点/判断推理/图形推理/图形推理-位置规律（旋转-九宫格米字型两端互为旋转）|图形推理 / 图形推理-位置规律（旋转/九宫格米字型两端互为旋转）]]


**问法模型**：‘选择最合适的一个填入问号处使之呈现一定规律性’且九宫格中心格空白 → 采用米字型路线观察，过中心连线两端图形互为旋转，由已知端推出问号端

## 推理链
1. 第1步：九宫格每格均为3×3小方格且都含3个黑块，组成元素相同，中心格为空白面，优先考虑位置变化
2. 第2步：中心格最特殊（空白），提示走‘米字型’路线：竖线(1,2)-(3,2)、横线(2,1)-(2,3)、主对角线(1,1)-(3,3)、副对角线(1,3)-(3,1)两端图形对应比较
3. 第3步：验证已知对：第一行第二图（黑块右上、中心、下中）与第三行第二图（黑块上中、中心、左下）互为180°旋转；第二行第一图（黑块左上、左中、中心）与第二行第三图（黑块中心、右中、右下）互为180°旋转；第一行第三图与第三行第一图亦互为180°旋转
4. 第4步：故问号处(3,3)应与主对角线另一端(1,1)图（黑块位于上中、中心、左下）呈旋转关系
5. 第5步：将(1,1)图旋转180°：(1,2)→(3,2)、(2,2)→(2,2)、(3,1)→(1,3)，得黑块位于右上、中心、下中的图形
6. 第6步：逐项对照：A项黑块在右上、中心、下中，完全吻合；B项仅2个黑块排除；C、D项黑块位置不符，故选A

**最快解法**：⚡ 米字型两端对照法：见中心格空白即过中心连线配对（均为180°旋转），问号与左上角图配对，左上图‘上中+中心+左下’三黑块转180°得‘右上+中心+下中’，直接锁定A

## 易错点
- ⚠ 忽略‘中心格空白’这一米字型提示信号，改按行/列或相邻顺推而找不到规律
- ⚠ 把180°旋转误当作翻转（镜像），竖直翻转左上角图会误选D项
- ⚠ 黑块具体落格看错（如C项黑块在上左、中心、下左），需逐格核对旋转后坐标

## 母题抽象
> 🧩 当九宫格中心格空白（或最特殊）且各格组成元素相同时，用米字型路线观察，过中心的对线两端图形互为旋转（多为180°），由已知一端即可推出问号端

**同类特征**：九宫格、中心格为空白、每格组成元素相同（均3个黑块）、位置变化（旋转）、米字型路线观察、对线两端图形对应

### 题干
从所给的四个选项中，选择最合适的一个填入问号处，使之呈现一定的规律性：

### 选项
- A. A　✅
- B. B
- C. C
- D. D

### 官方解析
分析图形的特征。图形组成元素都相同，考虑图形的位置变化，同时九宫格中间图形最特殊，为空白面，考虑米字型路线观察。观察发现，米字型的上下左右以及对角线两端的图形都是旋转的关系。故问号处应为第一行第一个图形旋转得到，对应A项。
故正确答案为A。
