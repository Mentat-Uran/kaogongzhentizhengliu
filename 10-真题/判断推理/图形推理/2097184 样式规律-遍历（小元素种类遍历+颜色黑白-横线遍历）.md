# 样式规律-遍历（小元素种类遍历+颜色黑白-横线遍历）

考点：[[20-考点/判断推理/图形推理/样式规律-遍历（小元素种类遍历+颜色黑白-横线遍历）|图形推理 / 样式规律-遍历（小元素种类遍历+颜色黑白/横线遍历）]]


**问法模型**：两组图各含相同四类小元素、仅填充颜色不同 → 用'元素+颜色双遍历'推出缺图再排除选项

## 推理链
1. 第1步：观察第一组三个图，每图均含四个位置固定的小元素——平行四边形、十字（拼图块）、月牙、半圆，且'相同位置的小元素都一样，颜色各不相同'（黑/白/横线）
2. 第2步：归纳规律为双遍历：同一元素在每组三图中，黑、白、横线三种颜色各出现一次（元素种类遍历+颜色遍历）
3. 第3步：将规律套入第二组：六边形已出现白色、横线 → 中间图六边形应为黑色，排除C、D；五角星已出现黑色、白色 → 中间图五角星应为横线，排除B
4. 第4步：A项六边形为黑色、五角星为横线，与遍历规律完全吻合，故选A

**最快解法**：⚡ 遍历排除法：抓六边形（白、横线已现→补黑）一步排除C、D，再用五角星（黑、白已现→补横线）排除B，锁定A

## 易错点
- ⚠ 只看小元素种类遍历、忽略颜色也要遍历，易误选元素齐全但颜色不对的选项
- ⚠ 受选项中图形旋转/翻转方向干扰（如B项三角形朝下、D项三角形朝右、箭头方向变化），误以为方向也参与规律
- ⚠ 把'横线填充'当作第四种颜色漏数，导致遍历链条断裂

## 母题抽象
> 🧩 当同组图形元素组成相似、仅填充色（黑/白/横线）不同时，用'元素+颜色双遍历'：同一元素三种颜色各出现一次，据此补全缺图并逐项排除

**同类特征**：元素组成相似、四类小元素位置对应、黑/白/横线三种填充、两组三图式、缺中间图、两组图共享遍历规律、排除法可快速锁定

### 题干
从所给四个选项中，选择最合适的一个填入问号处，使之呈现一定规律：

### 选项
- A. A　✅
- B. B
- C. C
- D. D

### 官方解析
元素组成相似，考虑样式规律。观察第一组图形发现，每个图中都包含有四种不同的小元素，且相同位置的小元素都一样，颜色各不相同。可知本题考查的是小元素的遍历和小元素颜色的遍历规律。依照此规律，第二组图形中六边形分别是白色和横线，则中间图中六边形应该是黑色，排除C项和D项；第二组图形中五角星分别是黑色和白色，则中间图中的五角星应该是横线，排除B项。
故正确答案为A。
