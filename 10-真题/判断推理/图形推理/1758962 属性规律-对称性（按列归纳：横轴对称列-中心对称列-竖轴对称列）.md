# 属性规律-对称性（按列归纳：横轴对称列-中心对称列-竖轴对称列）

考点：[[20-考点/判断推理/图形推理/属性规律-对称性（按列归纳：横轴对称列-中心对称列-竖轴对称列）|图形推理 / 属性规律-对称性（按列归纳：横轴对称列/中心对称列/竖轴对称列）]]


**问法模型**：九宫格'呈现一定规律性'且图形凌乱无数量特征 → 优先按列归纳对称属性（轴对称轴方向、中心对称），再选与所在列规律一致的选项

## 推理链
1. 第1步：九宫格中图形形状各异（梯形嵌圆、菱形加十字、向上箭头、十字分割圆、双重六边形等），元素组成凌乱，无统一点线面数量规律，优先考虑属性规律中的对称性。
2. 第2步：竖向按列观察：第一列三图（梯形嵌圆、椭圆机身组图、弧线交叉图）都只关于横轴对称。
3. 第3步：第三列已知两图（向上箭头、五边形内含三角形）都只关于竖轴对称，且均只有一条竖直对称轴。
4. 第4步：第二列三图（菱形加十字、十字分割圆、双重六边形）均关于中心点成中心对称，与第一、三列的'仅单轴对称'形成列规律。
5. 第5步：由此确定问号处（第三列）应填入'只关于竖轴对称'的图形。
6. 第6步：对照选项：A项（圆—竖线—右三角组合）与D项（梯形组合）均只关于横轴对称，属于第一列规律；C项六角星有六条对称轴且为中心对称，对称轴数量超出'只竖轴对称'的限定。
7. 第7步：B项为等腰三角形内含竖轴对称的向上箭头，只关于竖轴对称，与第三列规律一致，故选B。

**最快解法**：⚡ 对称性列规律法：竖着快速扫每列，识别出'横轴对称列—中心对称列—竖轴对称列'的结构，问号在竖轴对称列，直接在选项中找'只有一条竖直对称轴'的图形，排除A、D（横轴对称）和C（多轴对称），秒选B。

## 易错点
- ⚠ 第二列图形（如菱形加十字、十字分割圆）既是轴对称又是中心对称，若纠结'该列不够纯中心对称'而推翻整个列规律，会错失答案；应把握'第一、三列仅单轴、第二列含中心对称'的整体结构。
- ⚠ C项六角星同样是竖轴对称图形，若忽略第三列'只'有一条竖对称轴的限定（C有六条对称轴且中心对称），易误选C。
- ⚠ A、D项与第一列同为横轴对称图形，若按行寻找规律或看错列序，可能误选A或D。

## 母题抽象
> 🧩 当九宫格图形整体凌乱、无统一数量规律时，按列归纳对称属性：若出现'仅横轴对称列''中心对称列''仅竖轴对称列'的组合，问号处选择与所在列对称类型一致、且满足'仅一条对称轴'限定的图形。

**同类特征**：九宫格图形、图形组成凌乱无数量规律、按列呈现对称规律、仅横轴对称列、中心对称列、仅竖轴对称列

### 题干
从所给的四个选项中，选择最合适的一个填入问号处。使之呈现一定的规律性。

### 选项
- A. A
- B. B　✅
- C. C
- D. D

### 官方解析
分析图形的特征。图形较为凌乱，考虑图形对称属性。第一列只为横轴对称图形，第二列为中心对称图形，第三列只为竖轴对称图形。
故正确答案为B。
