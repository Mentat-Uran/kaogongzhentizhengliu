# 数量规律-笔画数（奇点数与多笔画）

考点：[[20-考点/判断推理/图形推理/数量规律-笔画数（奇点数与多笔画）|图形推理 / 数量规律-笔画数（奇点数与多笔画）]]


**问法模型**：九宫格'选择最合适的一个填入问号处使之呈现一定规律性'→ 元素不同先排属性，再按'面→线→点→笔画'顺序查数量，九宫格优先按行找规律

## 推理链
1. 第1步：题干九宫格中图形形状各异、元素组成不同，对称/曲直/开闭等属性无统一规律，转入数量规律排查
2. 第2步：题干每幅图均被内部分割、含多个封闭区域，先数面数量，但各行面数量不构成常数或递增规律，排除面规律
3. 第3步：观察发现图形外框内有明显一笔构成的连贯线条（如第一行图内的斜贯线、三角形结构），提示考点为笔画数
4. 第4步：数奇点验证按行规律——第一行三图奇点数≤2，最少笔画数均为1（一笔画）
5. 第5步：第二行三图奇点数均为4（如第三图的立方体：中心三线交汇点及3个相连顶点为奇点），最少笔画数=4÷2=2；第三行前两图奇点数均为6，为3笔画，验证'按行笔画数恒定、逐行为1/2/3'规律
6. 第6步：问号处应为3笔画图形，逐项数奇点：B项奇点数为6，最少笔画数=6÷2=3，A、C、D均非3笔画，故选B

**最快解法**：⚡ 笔画数口诀法：最少笔画数=奇点数÷2（无奇点为1笔）；九宫格横向逐行数奇点得'行1一笔、行2两笔、行3三笔'，直接到选项中找6个奇点（3笔）的图形，锁定B

## 易错点
- ⚠ 见图形被分割就死磕面数量，面无规律后未及时切换到笔画数考点，浪费考场时间
- ⚠ 数奇点时漏数线条端点（端点也发射1条线，是奇点），或把所有交叉点误当奇点，导致笔画数算错
- ⚠ 未按'九宫格优先横向看'的顺序，竖着或斜着找规律，把行内恒定规律误看成其他数量规律

## 母题抽象
> 🧩 当九宫格图形元素组成不同、属性无规律，且图形被分割、外框内含明显一笔画线条时，按行数笔画数（奇点数÷2）验证每行恒定，再选同笔画数的选项

**同类特征**：元素组成不同、图形被分割（多个封闭区域）、外框内有明显一笔构成的线条、九宫格横向规律、笔画数按行递增1/2/3、出现立方体（经典两笔画图形）

### 题干
从所给的四个选项中，选择最合适的一个填入问号处，使之呈现一定的规律性。

### 选项
- A. A
- B. B　✅
- C. C
- D. D

### 官方解析
元素组成不同，且无明显属性规律，考虑数量规律。观察发现，题干图形被分割，考虑面数量，但面数量无规律，且第一行图形的外框内有明显一笔构成的线条，可以考虑笔画数。九宫格优先横向看，第一行图形的笔画数均为1，第二行图形的笔画数均为2，第三行前两幅图的笔画数均为3，故？处应选择一个三笔画图形，只有B项符合。
故正确答案为B。
