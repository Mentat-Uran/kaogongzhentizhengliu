# 位置规律-平移（循环右移一格）

考点：[[20-考点/判断推理/图形推理/位置规律-平移（循环右移一格）|图形推理 / 位置规律-平移（循环右移一格）]]


**问法模型**：题干给出多行网格、已知前四行求'变化后第五行'→逐行对比找位置变化规律并外推到下一行

## 推理链
1. 第1步：从图中提取各行元素序列：第1行'♥、☀、♥、♥、☀、☀、☀'，第2行'☀、♥、☀、♥、♥、☀、☀'，第3行'☀、☀、♥、☀、♥、♥、☀'，第4行'☀、☀、☀、♥、☀、♥、♥'，每行7格，元素只有心形和太阳两种，各行元素组成相同→优先考虑位置规律
2. 第2步：对比第1行与第2行，发现第1行整体向右平移一格、最右端的'☀'循环回到行首，恰好得到第2行，归纳出'每行向右循环平移一格'的规律
3. 第3步：用第3、4行验证：第2行右移一格得'☀、☀、♥、☀、♥、♥、☀'即第3行，第3行右移一格得'☀、☀、☀、♥、☀、♥、♥'即第4行，规律成立
4. 第4步：外推第5行=第4行向右循环平移一格，即把第4行末尾的'♥'搬到行首，得到'♥、☀、☀、☀、♥、☀、♥'
5. 第5步：与选项逐格对照，B项为'♥、☀、☀、☀、♥、☀、♥'，与推理结果完全一致，故选B

**最快解法**：⚡ 循环平移口诀法：把上一行末格元素搬到行首、其余逐格右移；由第4行'☀☀☀♥☀♥♥'直接写出第五行'♥☀☀☀♥☀♥'，秒选B

## 易错点
- ⚠ 元素组成相同时误走'数量规律'或'黑白叠加'路线，忽略位置规律优先原则
- ⚠ 循环平移方向搞反（误判为向左平移或非循环截断），推出A、D等错误序列
- ⚠ 只数心形/太阳的个数不核对具体位置，C项心形数量同为3个，仅靠数量无法排除，必须逐格对照

## 母题抽象
> 🧩 当题干出现'多行/多个图形元素组成相同、仅位置不同'的特征时，用逐行对比找平移方向与步长（注意是否循环）的方法，按规律外推下一项并逐格对照选项验证

**同类特征**：七列网格、每行心形与太阳两种元素、各行元素组成相同、相邻行逐格位置变化、整行循环右移一格、求第五行图形、选项为单行七格序列
