# 图形推理-字母序列规律（字母表序号等差）

考点：[[20-考点/判断推理/图形推理/图形推理-字母序列规律（字母表序号等差）|图形推理 / 图形推理-字母序列规律（字母表序号等差）]]


**问法模型**：九宫格填入问号处字母使之呈现规律 → 优先按横行将字母转为字母表序号，找相邻序号差的行间递增规律

## 推理链
1. 第1步：题干为九宫格，每格为单个字母：第一行D、E、F，第二行F、I、L，第三行H、M、？
2. 第2步：九宫格优先看横行；将字母转为字母表序号：D=4、E=5、F=6，第一行相邻间隔0个字母（序号差1）
3. 第3步：第二行F=6、I=9、L=12，相邻间隔2个字母（隔G、H与J、K），序号差为3；间隔数每行递增2
4. 第4步：第三行H=8、M=13，相邻间隔4个字母（I、J、K、L），按规律M到？也应间隔4个字母（N、O、P、Q）
5. 第5步：M为第13个字母，加5位得第18个字母R；逐项对照：O(15)、N(14)、L(12)、R(18)，仅D项R符合

**最快解法**：⚡ 序号差值法：把字母换成字母表序号，按行看相邻差值——第一行差1、第二行差3、第三行差5（即间隔0/2/4个字母递增），13+5=18→R，选D

## 易错点
- ⚠ 把'间隔4个字母'误当序号差4，用13+4算出Q（Q不在选项中才回头检查）；间隔数对应序号差应为间隔数+1
- ⚠ 忽略九宫格优先看横行，跑到竖列找规律（首列D/F/H也易误导）
- ⚠ 字母序号数错（如把M当第12个），导致间隔计算偏差

## 母题抽象
> 🧩 当九宫格每格为单个字母时，把字母转换为字母表序号，按行（或列）找相邻序号差的等差/递增规律，再由末项推算问号处字母

**同类特征**：九宫格、每格单个大写字母、字母表顺序规律、按行观察间隔递增、问号位于第三行行末、选项为四个字母

### 官方解析
