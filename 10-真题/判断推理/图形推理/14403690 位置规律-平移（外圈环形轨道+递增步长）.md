# 位置规律-平移（外圈环形轨道+递增步长）

考点：[[20-考点/判断推理/图形推理/位置规律-平移（外圈环形轨道+递增步长）|图形推理 / 位置规律-平移（外圈环形轨道+递增步长）]]


**问法模型**：'下列选项最符合所给图形规律'且五幅图元素组成相同 → 优先考虑位置规律，给黑球逐个编号、追踪其沿外圈的平移步长规律

## 推理链
1. 第1步：题干五图与选项均为4×4共16个圈，黑球数量恒为3个，元素组成相同、仅位置变化，优先考虑位置规律。
2. 第2步：黑球只在4×4的外圈（12格环形轨道）上移动，给三个黑球分别编号追踪。
3. 第3步：图1→图2→图3→图4→图5中，标1的两个黑球每次沿外圈逆时针平移1格，如右侧两球(2,4)、(3,4)依次变为(1,4)、(2,4)→(1,3)、(1,4)→(1,2)、(1,3)→(1,1)、(1,2)。
4. 第4步：标2的黑球沿外圈依次逆时针平移1、2、3、4格：图1(1,1)→图2(2,1)→图3(4,1)→图4(4,4)→图5(1,3)。
5. 第5步：问号处延续规律：标1两球由(1,1)、(1,2)各再逆时针移1格到(2,1)、(1,1)；标2球由(1,3)逆时针移5格到(4,1)。
6. 第6步：得黑球位于左列第1、2、4行，即(1,1)、(2,1)、(4,1)，对照选项只有C符合。

**最快解法**：⚡ 编号追踪法：先锁定黑球只在外圈12格环形轨道上走，两个球每次逆时针走1格、第三个球按1/2/3/4/5递增走格；由图5直接外推问号处三点落在左列第1、2、4行，秒选C。

## 易错点
- ⚠ 忽略黑球只在外圈12格环形轨道上移动，把内圈2×2也纳入轨道导致数错格数
- ⚠ 标2黑球步长为1、2、3、4、5递增，误当成每次恒走1格，错选A或B
- ⚠ 顺时针与逆时针方向看反，推出错误落点误选D

## 母题抽象
> 🧩 当图形'元素组成相同、小元素（黑白球/块）数量不变仅位置变'时，用位置规律：给每个移动元素单独编号，沿同一环形轨道逐图数格，验证步长为常数或等差数列，再外推求下一图。

**同类特征**：元素组成相同、黑球数量恒定为3个、位置沿外圈环形轨道变化、步长等差递增（1/2/3/4/5）、逆时针平移、问号处求下一幅图

### 题干
下列选项最符合所给图形规律的是：

### 选项
- A. A
- B. B
- C. C　✅
- D. D

### 官方解析
元素组成相同，优先考虑位置规律。如下图所示，标1的两个黑球沿外圈每次逆时针平移1格，标2的黑球沿外圈依次逆时针平移1、2、3、4格，故图5中标1的两个黑球沿外圈逆时针平移1格，标2的黑球沿外圈逆时针平移5格得到？处图形，只有C项符合。

故正确答案为C。
