# 图形推理-六面体折叠（空间重构-相邻面及面内特征比对）

考点：[[20-考点/判断推理/图形推理/图形推理-六面体折叠（空间重构-相邻面及面内特征比对）|图形推理 / 图形推理-六面体折叠（空间重构-相邻面及面内特征比对）]]


**问法模型**：“左边给定纸盒外表面的展开图，右边哪一项能由它折叠而成” → 六面体空间重构，用排除法：先排无中生有的面，再比对相邻面图案的公共点/公共边邻接细节

## 推理链
1. 第1步：将展开图六面标注为面a~f，提取各面特征：面e含格子三角形且两条直角边均挨着白色区域，面b与面c各含黑色正方形且两黑正方形存在一个公共点
2. 第2步：确定解题方法为排除法，先查“是否有展开图中不存在的面”，再查“相邻面图案的公共点、公共边邻接关系”
3. 第3步：A项右侧的面在展开图中根本没有出现，属无中生有的面，排除
4. 第4步：B项中面e的格子三角形有一条直角边挨着黑色正方形，与展开图中“两条直角边均挨白色区域”矛盾，排除
5. 第5步：C项三个面为面b、面c、面f，展开图中面b与面c的黑色正方形有公共点（绿点），而选项中两黑正方形不存在公共点，排除
6. 第6步：D项三个面为面c、面d、面f，面的组合及相邻关系均与展开图一致，当选

**最快解法**：⚡ 排除法+相邻面特征比对：第一步扫四个选项是否有展开图中不存在的面（A项右侧无中生有）；第二步抓两个细节标尺——①格子三角形直角边的邻接对象（B项错在挨黑正方形），②黑正方形之间是否有公共点（C项错在无公共点）；排除A、B、C后锁定D

## 易错点
- ⚠ 只看面的大类图案（黑方块/阴影块）而忽略面内细节（格子三角形直角边邻接什么、黑方块是否共点），易误选B或C
- ⚠ 空间折叠时搞错相邻面之间的公共点/公共边关系，把展开图中的特征点对接位置想象错
- ⚠ 纠结D项右面内线条方向这一非设坑细节，反复怀疑而不敢选D，浪费考场时间（江苏卷对面内线条方向未设坑）

## 母题抽象
> 🧩 当题干给出六面体展开图且各面含黑白块、阴影格、线条等局部特征时，用排除法：先排除出现“无中生有面”的选项，再以“图案顶点公共点、公共边两侧邻接图案”为标尺逐项排除，最后剩下的即正确项；个别面内线条方向若与选项略有出入，只要其余特征全部吻合即可选定，不必纠结

### 题干
左边给定的是纸盒外表面的展开图，右边哪一项能由它折叠而成？请把它找出来。

### 选项

- B. B
- C. C
- D. D　✅

### 官方解析
本题考查六面体的空间重构。将题干展开图中的面依次标注为面a、b、c、d、e、f，如下图：

A项：右侧的面在展开图中没有出现，属于无中生有的面，选项与题干展开图不一致，排除；
B项：在题干展开图中，面e中的格子三角形两条直角边分别挨着白色区域，而选项中，面e中的格子三角形一条直角边挨着黑色正方形，选项与题干展开图不一致，排除；
C项：选项的三个面分别是面b、面c、面f，如下图：

题干展开图中，面b和面c中的黑色正方形存在一个公共点（如绿点），而选项中，面b和面c中的黑色正方形不存在公共点，选项与题干展开图不一致，排除；
D项：选项的三个面分别是面c、面d、面f，选项与题干展开图一致，当选。
故正确答案为D。
注：有同学会纠结D项右面里的线条方向不对，如果这么理解，这道题就没有答案了，所以从这个细节可以看出，江苏出题人对于面内线条的方向没有过多考虑，也没有在此设坑，如果没有更好的选项，可以选它。
