# 数量规律-一笔画（奇点数）+面的形状（三角形面个数）双规律

考点：[[20-考点/判断推理/图形推理/数量规律-一笔画（奇点数）+面的形状（三角形面个数）双规律|图形推理 / 数量规律-一笔画（奇点数）+面的形状（三角形面个数）双规律]]


**问法模型**：'选出最恰当一项填入问号处使图形呈现规律性'→元素组成不同且无属性规律时，先判笔画数（奇点法），若剩余多选项再用面的数量/形状二次筛选

## 推理链
1. 第1步：题干五幅图（三角形内含线、方形内含斜线、双圆夹菱、五边形内含线、圆内含三角加横线）元素组成不同，对称、曲直等属性规律不明显，转向数量规律
2. 第2步：题干出现多个'日'字变形图（线条交汇的连通图），提示优先考查笔画数：数每幅图奇点（引出奇数条线的交点或端点），奇点数为0或2的连通图为一笔画
3. 第3步：逐一验证题干图1~图5，奇点数均为0或2，即全部为一笔画图形，故问号处也应选一笔画图形
4. 第4步：数选项奇点：A项菱形四角加内交叉线，奇点数超过2（多笔画）；B项方形内对角线加竖线，出现4个奇点（两笔画），排除A、B
5. 第5步：再找第二规律：题干每幅图内部封闭面中均恰好包含两个三角形面，对照剩余C、D两项
6. 第6步：C项为一笔画且内部恰有两个三角形面，D项三角形面数量/结构不符，故选C

**最快解法**：⚡ 双重筛选法：第一步用奇点法快速判一笔画，排除多笔画的A、B；第二步数'三角形面'个数，题干每图均含两个三角形面，C项恰好两个，直接锁定C

## 易错点
- ⚠ 只验证一笔画规律就匆忙作答，忽略还需'两个三角形面'的二次规律（本题一笔画筛选后仍需区分C、D）
- ⚠ 数面时只数面的总个数，忽略面的形状特征（三角形面），导致误选
- ⚠ 数奇点时漏掉端点（引出1条线也是奇点）或漏数线条交汇处的交点，误判笔画数

## 母题抽象
> 🧩 当题干出现'日'字及变形图、多线交汇的连通图形且属性规律不明显时，先用奇点数判一笔画（奇点0或2），若剩余多个选项，再用封闭面的数量或形状（如三角形面）作二次筛选

**同类特征**：'日'字变形图、元素组成不同且无属性规律、多线条交汇的连通图形、封闭面中含三角形、问号处延续规律

### 题干
请从四个选项中选出最恰当的一项填入问号处，使题干图形呈现一定的规律性。

### 选项
- A. A
- B. B
- C. C　✅
- D. D

### 官方解析
元素组成不同，且无明显属性规律，考虑数量规律。观察发现，题干出现多个 “日”字变形图，考虑笔画数。题干图形均为一笔画图形，？处应用规律，排除A、B两项；继续观察发现，题干每幅图形均存在两个三角形面，故？处应选一个存在两个三角形面的图形，只有C项符合。
故正确答案为C。
