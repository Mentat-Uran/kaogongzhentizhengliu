# 数量规律-数面（面数量递增）＋折线开口朝向的二级辨析

考点：[[20-考点/判断推理/图形推理/数量规律-数面（面数量递增）＋折线开口朝向的二级辨析|图形推理 / 数量规律-数面（面数量递增）＋折线开口朝向的二级辨析]]


**问法模型**：问号处填入图形使整组呈现规律性 → 先数折线与直线相交形成的面数量找递增规律，面数相同时再以折线开口朝向做二级筛选

## 推理链
1. 第1步：题干四幅图结构统一，均为'一条水平直线＋一条折线'，折线与直线交叉形成明显封闭区域（窟窿）
2. 第2步：元素组成不同且无明显属性规律，优先考虑数量规律；因'窟窿'明显，首选数面，题干面数量依次为1、2、3、4，呈等差递增
3. 第3步：由递增规律推知问号处图形应有5个面；对照选项，C、D项均只有4个面，排除
4. 第4步：A、B项均为5个面，数量规律失效，转入二级辨析——观察折线整体开口朝向，题干四图依次为上、下、上、下，呈交替规律
5. 第5步：按交替规律，问号处折线开口应朝上；A项折线开口朝下，B项折线开口朝上，故B项当选

**最快解法**：⚡ 数面排除法＋二级辨析：先数面（1、2、3、4→？为5），排除C、D（均为4个面）；再比A、B的折线开口朝向（题干上下交替→问号处朝上），锁定B

## 易错点
- ⚠ 只数面不辨形：A、B面数同为5，若止步于数量规律会误选A，遗漏折线开口朝向的交替规律
- ⚠ 开口朝向判断看反：题干为上、下、上、下交替，若把首图开口方向看错，会推出问号处朝下而错选A
- ⚠ 面数量数错：折线与水平线多次交叉，易漏数或多数封闭区域，导致C、D未被排除

## 母题抽象
> 🧩 当题干出现'折线与直线相交形成窟窿'且面数量呈1、2、3、4递增时，先用数面排除数量不符的选项，再用折线开口朝向等局部形态特征做二级验证

**同类特征**：折线与水平直线相交、封闭区域（窟窿/面）明显、面数量等差递增、折线开口朝向上下交替、选项需两级筛选（先数量后形态）
