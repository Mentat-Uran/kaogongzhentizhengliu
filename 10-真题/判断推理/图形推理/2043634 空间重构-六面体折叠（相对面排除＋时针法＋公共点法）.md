# 空间重构-六面体折叠（相对面排除＋时针法＋公共点法）

考点：[[20-考点/判断推理/图形推理/空间重构-六面体折叠（相对面排除＋时针法＋公共点法）|图形推理 / 空间重构-六面体折叠（相对面排除＋时针法＋公共点法）]]


**问法模型**：左边展开图、右边四个立体图，问'哪一项能由它折叠而成'→ 先用相对面排除，再用时针法/公共点法核对相邻面图案指向，逐一排除锁定答案

## 推理链
1. 第1步：给展开图六个面标号①~⑥，各面特征为含双对角线（X形）图案的面及多个带不同阴影（斜线、网格、小三角）的单对角线面
2. 第2步：先用相对面排除法——展开图中面①与面⑥为相对面（相间/Z字形两端关系），立体图中相对面能且只能出现其中一个
3. 第3步：A项同时出现面①、面⑤、面⑥，含相对面①和⑥，违反'相对面必现且只现其一'，排除
4. 第4步：对C项用时针法——展开图中围绕公共顶点按①→②→③为逆时针方向，而C项立体图中①②③呈顺时针，平面与立体不对应，排除
5. 第5步：对D项用公共点法——无论取面①②⑤还是面②⑤⑥组合，展开图中三面公共顶点应落在对角线端点/线段交汇处，而D项立体图中三面公共点与面①或面⑥中的线段不存在公共点，排除
6. 第6步：B项由面②、面⑤、面⑥构成，三面相邻位置及对角线、阴影图案的指向与展开图完全对应，当选

**最快解法**：⚡ 相对面排除＋时针/公共点定向：一票扫杀——A项同时含①⑥（相对面）直接排除；C项用时针方向（展开图逆时针 vs 立体图顺时针）排除；D项验证公共点是否落在对角线端点处排除；剩余B直接当选

## 易错点
- ⚠ 展开图排布不规整时，把相对面①⑥误判为相邻面，漏杀A项
- ⚠ 时针法要以三个面围绕公共顶点的绕向为准，顺/逆时针看反导致C项误留
- ⚠ D项与B项图案相似，忽略'三面公共点必须与对角线端点/线段交汇'这一细节而误选D

## 母题抽象
> 🧩 当展开图含多条对角线/阴影图案时，先用'相间、Z字形两端'定相对面做一票排除，再按时针方向或公共点（线段是否交汇于公共顶点）核对相邻面指向，逐一排他后锁定唯一项

**同类特征**：六面体展开图折叠、多个面带对角线与不同阴影图案、相对面排除、时针法定向、公共点/公共边法、问'哪一项能由它折叠而成'

### 题干
左边给定的是纸盒外表面的展开图，右边哪一项能由它折叠而成？请把它找出来。

### 选项
- A. A
- B. B　✅
- C. C
- D. D

### 官方解析
本题属于六面体空间重构，在平面图中标示面，利用排除法选出正确答案。

A项：由面①、面⑤和面⑥构成，面①和面⑥为相对面，相对面必然出现且只出现其中一面，排除；
B项：由面②、面⑤和面⑥构成，三面相对位置正确，当选；
C项：由面①、面②和面③构成，平面图中①②③面为逆时针，立体图中①②③面为顺时针，平面图与立体图不对应，排除；
D项：D项无论是由面①、面②和面⑤构成或者是由面②、面⑤和面⑥构成，三面的公共点均与面①或者面⑥中的线段不存在公共点，平面图与立体图不对应，排除。
故正确答案为B。
