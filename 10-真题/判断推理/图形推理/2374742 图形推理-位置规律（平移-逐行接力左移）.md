# 图形推理-位置规律（平移-逐行接力左移）

考点：[[20-考点/判断推理/图形推理/图形推理-位置规律（平移-逐行接力左移）|图形推理 / 图形推理-位置规律（平移-逐行接力左移）]]


**问法模型**：'最符合所给图形规律'+图形序列→元素组成相同，优先考虑位置规律，逐行追踪黑块平移的方向与步长并外推到问号处

## 推理链
1. 第1步：四幅已知图元素组成相同，均为4×4方格内4个小黑块，黑块数量无增减、形状无变化→锁定位置规律（平移）
2. 第2步：逐行定位图1黑块：四行小黑块同处第三列，构成一条竖线
3. 第3步：对比相邻图：图1→图2第四行黑块左移一格（第三列→第二列），图2→图3第三行黑块左移一格，图3→图4第二行黑块左移一格
4. 第4步：归纳规律：每一步只有一行黑块左移一格，且移动行的次序自下而上轮换（第四行→第三行→第二行→第一行）
5. 第5步：外推问号处：图4→？应为第一行黑块左移一格（第三列→第二列），此时四行黑块全部并至第二列，连成第二列竖线
6. 第6步：对照选项：仅B项四行黑块同在第二列；A项黑块仍在第三、四列，C项呈对角散布，D项第一、三行黑块未移到第二列，均排除

**最快解法**：⚡ 位置规律口诀'元素相同看平移'+逐行接力法：对相邻图逐行比对黑块列位置，发现自下而上每步一行左移一格，外推第一行也左移一格→四块并成第二列竖线→秒选B

## 易错点
- ⚠ 只把整条竖线看作整体移动，看不出'逐行接力'式移动，导致找不到规律或误认为整体循环
- ⚠ 忽略移动行的轮换次序（第四行→第三行→第二行→第一行自下而上），误判问号处该动哪一行，误选D（第一、三行错位）
- ⚠ 对'左移一格'的边界处理不当，误以为到边后循环跳到右侧，误选A或C

## 母题抽象
> 🧩 当题干出现'元素组成相同的方格黑白块序列图'时，用'逐行/逐元素追踪平移'的方法，验证每步移动的方向、格数及移动对象的轮换顺序，再外推问号处

**同类特征**：元素组成相同、4×4方格内4个小黑块、相邻图形间位置变化、逐行左移一格、移动行自下而上轮换、问号处延续规律

### 官方解析
元素组成相同，优先考虑位置规律。观察图形发现，图1到图2第四行的小黑块向左平移一格，图2到图3第三行的小黑块向左平移一格，图3到图4第二行的小黑块向左平移一格，因此，图4到？，应为第一行的小黑块向左平移一格，只有B项符合。
故正确答案为B。
