# 空间重构-六面体折纸盒（公共边法+画边法定向）

考点：[[20-考点/判断推理/图形推理/空间重构-六面体折纸盒（公共边法+画边法定向）|图形推理 / 空间重构-六面体折纸盒（公共边法+画边法定向）]]


**问法模型**：给出纸盒外表面展开图，问哪一项能折叠而成 → 采用'相邻面公共边验证+画边法定向'的排除模型：对每个选项找出构成的三面，比对公共边图案特征或以特征边为起点画边数边，排除不一致项

## 推理链
1. 第1步：给展开图六个面依次标号a-f，识别各面图案特征：面e含'与小短线有交点的边'，面a含'纯白矩形'，面b含'大直角三角形'，面c含'小直角三角形'，另有面d等
2. 第2步：确定方法——本题选项均为三个相邻面的组合（不含相对面可直接排除的情形），需逐项用公共边法/画边法比对图案在边上的精确位置
3. 第3步：A项由面a、b、e构成——以面e中'与小短线有交点的那条边'为起点在面e内顺时针画边，题干中第2边对面d，选项中第2边对面b，指向不一致，排除
4. 第4步：B项由面b、c、e构成——题干中面b与面c的公共边是'小直角三角形的斜边'，选项中公共边却是'大直角三角形的直角边'，公共边特征不符，排除
5. 第5步：C项由面a、d、e构成——题干中面a与面d的公共边是'面a中纯白矩形的短边'，选项中却是'纯白矩形的长边'，公共边特征不符，排除
6. 第6步：D项三个面的相对位置及公共边图案特征均与展开图一致，当选

**最快解法**：⚡ 公共边法逐项排除：A用画边法（以面e小短线交点边为起点顺时针数边，比对第2边指向面d还是面b），B、C直接比对公共边是'斜边还是直角边''矩形短边还是长边'，特征错位即排除，剩余D当选

## 易错点
- ⚠ 画边法起点选错或方向（顺/逆时针）搞反，导致A项误判为正确
- ⚠ 公共边上图案细节辨析不到位：矩形的长边与短边、三角形的斜边与直角边混淆（B、C两坑）
- ⚠ 只看三个面'是否相邻'而忽略图案在边上的精确方位，误选相邻组合成立但朝向错误的选项

## 母题抽象
> 🧩 当展开图各面图案带有明显边特征（短线交点、斜边/直角边、矩形长短边）且选项均为相邻三面组合时，用'公共边法+画边法'：先锁定每选项构成的三面，再以特征边为起点顺时针画边比对指向面，或直接比对公共边图案细节，错位即排除

**同类特征**：纸盒外表面展开图、六面体折叠、相邻三面组合、公共边图案特征（斜边/直角边、长短边）、画边法定向（起点边+顺时针数边）、逐一排除选一致项

### 题干
左边给定的是纸盒外表面的展开图，右边哪一项能由它折叠而成？请把它找出来。

### 选项
- A. A
- B. B
- C. C
- D. D　✅

### 官方解析
将题干展开图中的面依次标号，如下图：

A项：选项由面a、b、e构成，以面e中与小短线有交点的那条边为起点在面e中顺时针画边，题干中第2边对着面d，选项中第2边对着面b，选项与题干不一致，排除；

B项：选项由面b、c、e构成，题干中面b和面c的公共边是小直角三角形的斜边，选项中的公共边是大直角三角形的直角边，选项与题干不一致，排除；

C项：选项由面a、d、e构成，题干中面a和面d的公共边是面a中纯白矩形的短边，而选项中面a和面d的公共边是纯白矩形的长边，选项与题干不一致，排除；

D项：选项与题干一致，当选。
故正确答案为D。
