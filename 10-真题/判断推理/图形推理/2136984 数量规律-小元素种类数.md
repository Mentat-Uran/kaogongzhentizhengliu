# 数量规律-小元素种类数

考点：[[20-考点/判断推理/图形推理/数量规律-小元素种类数|图形推理 / 数量规律-小元素种类数]]


**问法模型**：一组线性图形+问号填入 → 元素组成不同且无属性规律时，数小元素的'种类数'（而非个数），找恒定常数并匹配选项

## 推理链
1. 第1步：题干5个图形元素组成各不相同，且无对称、封闭、曲直等属性规律，转向数量规律
2. 第2步：每图均由多个独立小元素构成，分别清点每图元素的个数与种类数
3. 第3步：各图元素个数并非恒定，但'种类数'恒定——题干每个图形均恰由4种不同的小元素构成（形状相同只计1种）
4. 第4步：以'4种不同小元素'为标准逐项清点选项
5. 第5步：A项由3种小元素构成、D项由3种小元素构成、B项由2种小元素构成，均不符合；C项由4种不同小元素构成，与题干规律一致，故选C

**最快解法**：⚡ 种类数清点法+排除法：只数'种类'不数'个数'，确认题干每图恒为4种小元素后，直接排除A（3种）、B（2种）、D（3种），锁定C（4种）

## 易错点
- ⚠ 误数'元素个数'而非'种类数'——题干各图元素个数并不相同，按个数找规律会走死路
- ⚠ 把形状相同但方向/大小/写法不同的同一类元素误判为多种（如B项中不同写法的'×'实为同一种，故B只有2种）
- ⚠ 漏数重复出现元素的种类或将小元素与图形整体混淆，导致种类数清点出错

## 母题抽象
> 🧩 当题干图形由多个独立小元素组成且属性规律（对称/封闭/曲直）全无时，优先清点'小元素种类数'，若种类数恒定（如恒为4种），按该常数排除选项即可秒杀

**同类特征**：多个独立小元素、元素组成不同、无属性规律、小元素种类数、种类数恒定为4

### 题干
请从四个选项中选出最恰当的一项填在问号处，使图形呈现一定的规律性：

### 选项
- A. A
- B. B
- C. C　✅
- D. D

### 官方解析
观察图形发现，元素组成不同，且无属性规律，考虑数量规律。题干中每个图形都是由多个独立小元素构成，可考虑小元素的数量或者种类规律。观察发现，题干中每个图形均由4种不同的小元素构成。观察选项发现，A项和D项由3种小元素构成，B项由2种小元素构成，只有C项由4种小元素构成。
故正确答案为C。
