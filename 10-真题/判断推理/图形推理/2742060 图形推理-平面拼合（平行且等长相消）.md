# 图形推理-平面拼合（平行且等长相消）

考点：[[20-考点/判断推理/图形推理/图形推理-平面拼合（平行且等长相消）|图形推理 / 图形推理-平面拼合（平行且等长相消）]]


**问法模型**：“四个图形只能通过上、下、左、右平移拼合成一个”→ 采用平行且等长相消法：拼接边须平行且等长，消去内部公共边后所得外轮廓即为答案。

## 推理链
1. 第1步：题干给出四个小图形（两个三角形、一个四边形、一个细长条状图形），且限定“只能通过上、下、左、右平移”，即各边方向不可改变。
2. 第2步：使用平行且等长相消法——两块图形拼合时，重合的边必须平行且等长，拼合后这些内部公共边消去，只保留外轮廓。
3. 第3步：将四个小图形的各边两两配对，把平行且等长的边作为拼接缝逐对消去（如解析所附配图所示）。
4. 第4步：消去全部内部边后，剩余外轮廓应为一个带多个凹凸锯齿的凹多边形。
5. 第5步：逐项对照：A项的凹凸轮廓与相消后所得轮廓完全吻合；B、C、D项的锯齿方向、凹口数量或边长关系与拼合轮廓不一致。
6. 第6步：故由四个图形平移拼合而成的只能是A项。

**最快解法**：⚡ 平行等长相消法+轮廓比对：将四个碎片按平行且等长的边两两拼接消去内部线段，直接把所得外轮廓与四个选项比对，秒杀锁定A。

## 易错点
- ⚠ 误以为可以旋转或翻转碎片，导致边方向改变而拼错选项
- ⚠ 只凭外轮廓“大致都是锯齿形”粗看排除，忽略平行且等长的严格拼接条件，误选B、C或D
- ⚠ 忽略拼接边必须等长完全重合，把部分重合的边当作拼接缝

## 母题抽象
> 🧩 当题干出现“若干小图形拼合、只能平移（不可旋转）”特征时，用平行且等长相消法，验证消去内部公共边后的外轮廓与哪个选项一致。

**同类特征**：只能通过上、下、左、右平移、四个三角形/四边形碎片、拼合成一个整体图形、选项为锯齿状凹多边形轮廓、平行且等长相消、无旋转翻转
