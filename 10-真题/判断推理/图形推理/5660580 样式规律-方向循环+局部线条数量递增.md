# 样式规律-方向循环+局部线条数量递增

考点：[[20-考点/判断推理/图形推理/样式规律-方向循环+局部线条数量递增|图形推理 / 样式规律-方向循环+局部线条数量递增]]


**问法模型**：问'符合所给图形的变化规律'的图形填空 → 对同构小元素按'先整体方向、后局部数量'两层规律归纳

## 推理链
1. 第1步：题干10个图形均为箭头，元素组成相似，优先考虑样式规律
2. 第2步：观察箭头方向，图1右、图2右、图3左、图4右、图5右、图6左、图7右、图8右、图9左，呈'右、右、左'每三个一循环
3. 第3步：问号处为第10个图形，按循环应为朝右箭头，排除C项（朝左）
4. 第4步：每支箭头的总线条数无规律，转而观察朝右箭头'上半部分'的线条数：依次为1、2、3、4、5、6，构成递增数列
5. 第5步：问号处朝右箭头上半部分线条数应为7
6. 第6步：对照选项，A、D朝右但上半部分线条数不足7，只有B项朝右且上半部分为7条，故选B

**最快解法**：⚡ 两步筛选法：先按'右右左'三循环锁定问号为朝右箭头排除C，再数朝右箭头上半部分线条1→6递增，选7条的B

## 易错点
- ⚠ 只统计每支箭头的总线条数，发现无规律就放弃，忽略了'仅数朝右箭头上半部分'这一隐藏数量规律
- ⚠ 忽略方向'右、右、左'三循环规律，误以为方向杂乱无章
- ⚠ 辨析B与D时只粗看线条多少，未逐条计数上半部分线条数，导致二级辨析缺位

## 母题抽象
> 🧩 当题干出现同构小元素（箭头/折线等）重复排列时，先看元素朝向是否呈循环规律，再看其中某一部分（如上半部分）的数量是否递增，两层规律叠加定位答案

**同类特征**：元素组成相似、同构箭头连续排列、方向'右右左'三循环、朝右箭头上半部分线条1~6递增、整体线条数无规律、问号处求第10项

### 选项
- A. A
- B. B　✅
- C. C

### 官方解析
元素组成相似，优先考虑样式规律。观察发现，题干图形的箭头的方向为“右、右、左”每三个循环，故？处图形的箭头的方向应朝右，排除C项；再次观察发现，题干每个箭头上的总线条数没有规律，但方向朝右箭头的上半部分的线条数依次为1、2、3、4、5、6（如下图所示），故？处朝右箭头的上半部分的线条数应为7，只有B项符合。

故正确答案为B。
