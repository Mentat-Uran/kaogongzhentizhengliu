# 数量规律-面数量+属性规律-曲直性（复合规律）

考点：[[20-考点/判断推理/图形推理/数量规律-面数量+属性规律-曲直性（复合规律）|图形推理 / 数量规律-面数量+属性规律-曲直性（复合规律）]]


**问法模型**：‘选出最合适的一个填入问号处，使之呈现一定的规律性’且元素组成不同、封闭区域明显 → 优先数面找数量规律，剩余选项再叠加曲直性做二次筛选

## 推理链
1. 第1步：题干六图元素组成各不相同（旗、伞、圆+梯形、杯子、叶枝），无位置或样式规律，且每图封闭区域清晰，优先考虑数面。
2. 第2步：依次数题干面数量：图1无封闭区域为0个面，图2雨伞仅伞面1个面，图3圆+梯形共2个面，图4杯口+杯身+把手共3个面，图5四片叶片共4个面，构成0、1、2、3、4的等差递增数列。
3. 第3步：由等差规律推知问号处图形应含有5个面。
4. 第4步：数选项面数量：B项五边形被分成5个三角形区域、D项五边形内被曲线分割为5个区域，均满足5个面；C项圆内接五角星，星内5个尖角+中心五边形+星外圆内区域，面数不是5，首先排除C。
5. 第5步：观察题干图形的构成属性：每幅图都同时由直线和曲线组成（伞面弧线+直伞杆、圆形曲线+梯形直边、椭圆杯口+直线杯身、叶片曲线+直线茎），曲直兼具。
6. 第6步：对照选项曲直性：A项全部由曲线（圆）构成、B项全部由直线（五边形与三角形）构成，均与题干不符，排除A、B；D项五边形（直线）+内部弧线（曲线），曲直兼具且恰有5个面，当选。

**最快解法**：⚡ 两步排除法：①数面——题干面数为0、1、2、3、4，问号应为5个面，排除C；②看曲直——题干每图均为‘直线+曲线’组合，A全曲线、B全直线，排除A、B，锁定D。

## 易错点
- ⚠ 只验证面数这一步规律：B项五边形分割后恰好也是5个面，若数完面就匆匆选B会掉入陷阱，必须继续用曲直性做二次筛选。
- ⚠ 图1的旗面看似三角形封闭区域，易误判面数为1而使数列错位；实际该图未围成封闭区域，面数为0，数列起点是0。
- ⚠ C项五角星易只数5个尖角误判为5个面，忽略中心五边形及星与圆之间的区域，其面数并非5。

## 母题抽象
> 🧩 当图形元素组成不同且封闭区域明显时，先数面数量找等差/常数规律缩小范围；若仍有多个选项符合，再叠加曲直性等属性规律二次排除。

**同类特征**：元素组成不同、封闭区域（面）清晰可数、面数量0、1、2、3、4等差递增、每个图形均曲直兼具、数量规律与属性规律复合考查、问号处求第6项
