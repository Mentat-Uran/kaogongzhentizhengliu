# 位置规律-相邻比较（黑白三角形拼接图中相邻两图相同黑块数恒定）

考点：[[20-考点/判断推理/图形推理/位置规律-相邻比较（黑白三角形拼接图中相邻两图相同黑块数恒定）|图形推理 / 位置规律-相邻比较（黑白三角形拼接图中相邻两图相同黑块数恒定）]]


**问法模型**：一条式序列末尾问号'使之呈现一定的规律性'，且元素组成相同但平移/旋转规律不明显 → 采用相邻比较法，锁定'相邻两图相同黑三角形位置数恒定'这一隐性规律

## 推理链
1. 第1步：题干5个图形及选项均由同样的三角黑白块拼接而成，元素组成基本相同，直接找整体平移、旋转等位置规律不明显
2. 第2步：换用相邻比较法，逐对统计相邻两图黑三角形重合的位置数：图1与图2有5个位置的黑三角形相同
3. 第3步：验证图2与图3同样有5个位置的黑三角形相同，其余相邻图形（图3-图4、图4-图5）均满足'相邻两图恰有5个相同黑三角形位置'
4. 第4步：再提取辅助规律——题干所有图形左下角和右上角的黑三角形位置恒定不变
5. 第5步：依规律递推，？处图形应与图5恰有5个位置的黑三角形相同，且保持左下、右上角黑三角不变
6. 第6步：逐项与图5对照，只有A项恰有5个位置的黑三角形与图5相同（并符合角落恒定条件），B、C、D均不符，故选A

**最快解法**：⚡ 相邻比较法+末图匹配：直接数图4与图5（最后两个已知图）重合的黑三角形位置数，确认为5个后，拿选项逐一与图5比对相同黑三角个数，恰为5个且保留恒定角落的只有A

## 易错点
- ⚠ 惯性思维先找整体平移/旋转/翻转规律，因本题位置规律不明显而浪费时间
- ⚠ 数重合位置时把'相同黑三角形数'误当成'不同位置数'，或漏数、重数导致规律失真
- ⚠ 忽略'左下角与右上角黑三角恒定'的辅助条件，在多个看似接近的选项中误选

## 母题抽象
> 🧩 当一组图形元素组成相同但整体位置移动规律不明显时，改用相邻比较法：统计相邻两图相同元素（如黑块）的数量是否恒定，再以该数量约束选项与末图的匹配关系

**同类特征**：三角黑白块拼接图形、元素组成基本相同、整体位置规律不明显、相邻两图相同黑三角形数恒定为5、左下角与右上角黑三角形恒定、问号位于序列末尾

### 题干
从所给的四个选项中，选择最合适的一个填入问号处，使之呈现一定的规律性：

### 选项
- A. A　✅
- B. B
- C. C
- D. D

### 官方解析
元素组成基本相同，但位置规律不明显，考虑相邻比较。观察发现，如下图所示，图1和图2有5个位置的黑三角形相同，图2和图3有5个位置的黑三角形相同，题干其他图形也均满足此规律，故？处图形应该和图5有5个位置的黑三角形相同（且题干所有图形左下角和右上角的黑三角形均相同），只有A项符合。

故正确答案为A。
