# 数量规律-线数量（直线数按行做减法）

考点：[[20-考点/判断推理/图形推理/数量规律-线数量（直线数按行做减法）|图形推理 / 数量规律-线数量（直线数按行做减法）]]


**问法模型**：九宫格问'符合图形变化规律'→元素组成不同且无属性规律时，按横行数直线并验证数量运算规律

## 推理链
1. 第1步：九宫格各图形元素组成不同，观察对称、封闭等属性无统一规律，转向数量规律；题干多为多边形，优先数直线数
2. 第2步：九宫格图形优先看横行，对每行三个图形的直线数做算式验证
3. 第3步：第一行：箭头状多边形直线数8、三角形直线数3、五边形直线数5，验证8-3=5成立
4. 第4步：第二行：立方体形直线数9（外轮廓6条+内部3条）、菱形直线数4、菱形加一横线直线数5，验证9-4=5成立，规律为'每行图1直线数-图2直线数=图3直线数'
5. 第5步：第三行：燕尾箭头形直线数6、圆形直线数0（曲线不计），故？处图形直线数应为6-0=6
6. 第6步：逐项数直线：A平行四边形4条、B月牙为两条曲线0条直线、C单一直线1条、D六边形6条，仅D为6条直线，符合规律

**最快解法**：⚡ 数直线法+按行减法口诀：先排除属性规律，快速数每行直线数，发现'图1-图2=图3'；第三行6-0=6，直接锁定六边形D

## 易错点
- ⚠ 按列或整体找规律，忽略九宫格'优先看横行'的习惯
- ⚠ 数复杂图形（立方体形9条、燕尾箭头6条）时漏数内部线或外轮廓边，导致规律验不出来
- ⚠ 把圆、月牙的曲线误计入线数，或只看'有无直线'不做数量运算而误选C

## 母题抽象
> 🧩 当九宫格图形元素组成不同、属性（对称/封闭/曲直）无统一规律且多为多边形时，按行数直线数并验证'图1-图2=图3'的数量运算，再据问号处应有直线数选答案

**同类特征**：九宫格、元素组成不同、多边形为主、含圆形/曲线干扰项、问号处补一图、直线数运算规律

### 题干
下列选项中，符合所给图形的变化规律的是        。

### 选项
- A. A
- B. B
- C. C
- D. D　✅

### 官方解析
元素组成不同，无明显属性规律，考虑数量规律。观察发现，题干图形中出现一些多边形，优先考虑直线数。九宫格图形优先看横行，题干第一行图形直线数依次为：8、3、5，题干第二行图形直线数依次为：9、4、5，即8-3=5，9-4=5，故每行第一个图形的直线数-第二个图形的直线数=第三个图形的直线数，第三行前两个图形的直线数分别为：6、0，故？处图形的直线数应为6，只有D项符合。
故正确答案为D。
