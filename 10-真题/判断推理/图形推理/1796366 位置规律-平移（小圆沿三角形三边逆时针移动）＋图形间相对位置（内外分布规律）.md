# 位置规律-平移（小圆沿三角形三边逆时针移动）＋图形间相对位置（内外分布规律）

考点：[[20-考点/判断推理/图形推理/位置规律-平移（小圆沿三角形三边逆时针移动）＋图形间相对位置（内外分布规律）|图形推理 / 位置规律-平移（小圆沿三角形三边逆时针移动）＋图形间相对位置（内外分布规律）]]


**问法模型**：九宫格填问号且各图元素组成相同 → 优先横向逐行找位置移动规律，移动锁定边位置后再用两元素相对位置（内/外）的数量规律排除

## 推理链
1. 第1步：九宫格每格均为'三角形＋小圆○'，元素组成相同，优先考虑位置规律，九宫格优先横向观察
2. 第2步：第一行○位置为左边(内)→底边(内)→右边(外)，规律为○绕三角形边逆时针每次移动一条边
3. 第3步：第二行验证：底边(外)→右边(内)→左边(内)，同为逆时针每次移一条边，规律成立
4. 第4步：第三行右边(内)→左边(外)→?，按逆时针移一条边，问号处○应在三角形底边上，排除C(右边外)、D(左边内)
5. 第5步：剩余A、B仅差○的内外；统计前两行，每行均为两个'○在三角形内部'、一个'○在三角形外部'
6. 第6步：第三行已有内(右)、外(左)各一，问号处应为'○在内部'，排除A(外)，对照选项B(底边内侧)符合

**最快解法**：⚡ 两步排除法：口诀'元素相同看位置，九宫格先横看'——第一步按'逆时针每次移一条边'确定○落在底边，排C、D；第二步按每行'两内一外'的内外数量规律定内，排A，秒选B

## 易错点
- ⚠ 只盯移动路径（逆时针移边）而忽视○在三角形内/外的属性，误选A
- ⚠ 内外数量规律记反，误以为每行两外一内而错排B
- ⚠ 九宫格竖着看或全盘乱找规律，未先横向逐行验证移动路径

## 母题抽象
> 🧩 当九宫格各图元素组成相同、且一元素依附于另一图形的边/角移动时，先横行归纳移动路径（方向＋步长）锁定位置，再用依附关系属性（内外/上下等）的数量分布规律排除剩余选项

**同类特征**：九宫格、元素组成相同、小圆○绕三角形边移动、逆时针每次移动一条边、内外位置每行两内一外、移动规律＋相对位置两步排除

### 题干
从所给四个选项中，选择最合适的一个填入问号处，使之呈现一定的规律性：

### 选项
- A. A
- B. B　✅
- C. C
- D. D

### 官方解析
图形元素组成相同，优先考虑位置规律。九宫格优先横向观察，观察第一行发现“○”绕着三角形的边逆时针每次移动一条边，第二行验证此规律成立，因此问号处的“○”应在三角形下面的那条边上，排除C、D两项。观察A、B两项发现，“○”所处的位置不同，一个在三角形外部，一个在三角形内部，因此应考虑两个元素之间的位置关系。经观察发现前两行中都有两个图形“○”位于三角形内部，一个图形“○”位于三角形外部，因此问号处的“○”应于三角形的内部，排除A项。
故正确答案为B。
