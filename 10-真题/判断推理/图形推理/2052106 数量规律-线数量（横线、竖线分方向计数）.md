# 数量规律-线数量（横线、竖线分方向计数）

考点：[[20-考点/判断推理/图形推理/数量规律-线数量（横线、竖线分方向计数）|图形推理 / 数量规律-线数量（横线、竖线分方向计数）]]


**问法模型**：『元素组成凌乱、无明显属性规律』且图形全由横竖直线构成 → 分方向数线（横线、竖线分开数），找常数/周期数量规律

## 推理链
1. 第1步：题干三图加问号，图形全部由横线与竖线构成，对称、封闭、曲直等属性规律均不明显，元素组成凌乱，进入数量规律'数数'环节
2. 第2步：线条方向特征突出，按横线、竖线两类分开计数，避免混数：图1横2竖3，图2横5竖3，图3横5竖3
3. 第3步：竖线数列为3、3、3，呈常数规律，故？处图形竖线应为3条
4. 第4步：横线数列为2、5、5，按'2、5、5'为周期循环，故？处横线应为2条（线条总数5、8、8、5的周期规律同样吻合）
5. 第5步：逐项对照：A项横5竖4、B项横2竖4，竖线均不为3，排除；D项横5竖3，竖线虽为3但横线为5，不符合横线周期，排除
6. 第6步：C项横2竖3，同时满足竖线常数规律与横线周期规律，故选C

**最快解法**：⚡ 分类数线法：竖线3、3、3恒定，？处必为3条竖线，排除A、B；横线2、5、5、2呈周期，？处应为2条横线，在同为3竖线的C、D中锁定C

## 易错点
- ⚠ 把横竖线加总计数（5、8、8、？）后看不出规律，误判'无数线规律'而放弃
- ⚠ 只盯竖线常数规律就仓促定答案，忽略横线周期验证，在C、D（竖线均为3条）之间误选D
- ⚠ 被图形外形（网格形、L形）和摆放位置干扰，误往样式类/位置类规律上想，漏掉纯数量规律

## 母题抽象
> 🧩 当题干图形元素凌乱、属性规律（对称/封闭/曲直）全不成立且全部由直线构成时，按横、竖两个方向分别数线找常数或周期规律，且必须横竖两条数列同时吻合才能锁定答案

**同类特征**：元素组成凌乱、全部由横线和竖线构成、无明显属性规律（对称/封闭/曲直均不成立）、线条横竖分明便于分类计数、一组线性序列第4幅为问号
