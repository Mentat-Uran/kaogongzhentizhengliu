# 图形推理-内容属性归纳（人物要素：成人与小孩同现）

考点：[[20-考点/判断推理/图形推理/图形推理-内容属性归纳（人物要素：成人与小孩同现）|图形推理 / 图形推理-内容属性归纳（人物要素：成人与小孩同现）]]


**问法模型**：前五图呈现规律、选第六图延续规律 → 归纳五图在图形内容（人物身份构成）上的共同特征，再匹配唯一符合的选项

## 推理链
1. 第1步：观察题干五图，均为黑色人物剪影，且每幅图中均出现多个人物（如'大人陪坐小孩''大人举小孩''大人牵小孩'等场景）
2. 第2步：进一步观察人物身份构成，五图无一例外都同时包含'成人'与'小孩'两类人物，归纳规律为'成人与小孩同现'
3. 第3步：逐项对照：A项仅一人骑马，无小孩；B项为成人与小孩同框；C项一男一女均为成人；D项两人打球亦均为成人
4. 第4步：只有B项满足'成人+小孩'这一规律，确定为第六图

**最快解法**：⚡ 要素观察法：先排除'单人图'（A），再在多人物选项中检验'是否含小孩'，C、D均只有成人，一步锁定B

## 易错点
- ⚠ 把规律停留在'黑色剪影''人物数量为多人'等表层特征，漏掉'成人与小孩同现'这一关键内容属性
- ⚠ D项虽有两个人物，但均为成人，误认为'多人'即符合规律
- ⚠ A项含'人+马'，误把动物当'小孩'或误认其为符合项

## 母题抽象
> 🧩 当题干图形为人物（剪影）场景图且规律不明时，先从人物数量、身份类别（如成人/小孩）等内容属性归纳共同点，再选唯一同特征项

**同类特征**：人物剪影、每图多个人物、成人与小孩同现、内容属性规律、选第六图延续规律

### 题干
在上边的题干中给出一套图形，其中有五个图，这五个图呈现一定的规律性。在下边给出一套图形，其中有四个图，从中选出唯一的一项作为保持上边五个图规律性的第六个图。

### 选项
- A. A
- B. B　✅
- C. C
- D. D

### 官方解析
题干中的图形出现多人，且出现的人物都有成人与小孩。只有B项有成人与小孩，当选；A项为一个人，C、D两项均为成人，排除。
故正确答案为B。
