# 数量规律-面数量（封闭区域个数）

考点：[[20-考点/判断推理/图形推理/数量规律-面数量（封闭区域个数）|图形推理 / 数量规律-面数量（封闭区域个数）]]


**问法模型**：'选择最合适的一个填入问号处，使之呈现一定规律性' → 元素组成不同先看属性，属性无规律时转数数量（本题数面）

## 推理链
1. 第1步：题干六幅图元素组成不同（同心圆嵌套六边形、L形立体盒、多面体、菱形嵌圆、立方体挖槽），无统一对称/曲直属性，按'属性不行数数量'切入
2. 第2步：每幅图都存在明显封闭空间，符合'出现明显封闭区域优先数面'的提示
3. 第3步：依次清点面数量：第1图同心圆嵌六边形共10个面、第2图L形立体盒9个面、第3图多面体8个面
4. 第4步：第5图菱形嵌圆为6个面、第6图立方体挖槽为5个面，已知数列为10、9、8、?、6、5
5. 第5步：数列呈公差为-1的等差递减，故'？'处应为7个面
6. 第6步：逐项清点选项面数：A项5个、B项7个、C项非7、D项非7，只有B项符合，选B

**最快解法**：⚡ 图形规律口诀'有明显封闭区域先数面'+等差数列：快速点出10、9、8、?、6、5，确定缺7，直接锁定有7个面的B项

## 易错点
- ⚠ 立体感图形（立体盒、多面体、立方体）数面时按立体表面积去数，导致漏数或重复
- ⚠ 数面与数点、数线混淆，本题各图交点线段数量规律不明显，走错数量维度
- ⚠ A项外形与第5图菱形嵌圆相似，误以为考样式类或对称规律而绕开数面

## 母题抽象
> 🧩 当题干图形元素组成不同且每幅图都有明显封闭区域时，优先数面；若面数量构成等差数列，直接按缺口数值找对应选项

**同类特征**：元素组成不同、无明显属性规律、明显封闭区域、面数量等差递减、立体图形与平面图形混排、问号居中位置
