# 位置规律-平移（顺时针步长1-2-3+框内外交替）

考点：[[20-考点/判断推理/图形推理/位置规律-平移（顺时针步长1-2-3+框内外交替）|图形推理 / 位置规律-平移（顺时针步长1/2/3+框内外交替）]]


**问法模型**：『符合所给图形的变化规律』且元素组成相同 → 优先位置规律：逐元素追踪平移步数与框内/框外交替，外推问号处图形

## 推理链
1. 第1步：三幅已知图与选项元素组成完全相同（八边形+黑球+叉号+白球），仅位置不同，锁定位置规律
2. 第2步：以八边形8个顶点为格位顺时针编号1~8（1=左上、2=右上、3=右偏上、4=右偏下、5=右下、6=左下、7=左偏下、8=左偏上），同时记录每个元素压线/贴内计为框内、悬空计为框外
3. 第3步：追踪黑球：图1在1号（框内）→图2在2号（框外）→图3在3号（框内），规律为每次顺时针平移1格且框内、框外交替
4. 第4步：追踪叉号：图1在2号（框外）→图2在4号（框内）→图3在6号（框外），规律为每次顺时针平移2格且框外、框内交替
5. 第5步：追踪白球：图1在3号（框内）→图2在6号（框外）→图3在1号（框内），规律为每次顺时针平移3格且框内、框外交替
6. 第6步：外推问号处：黑球3+1→4号（框外），叉号6+2=8号（框内，即左上），白球1+3=4号（框外），黑球与白球同在4号框外重合，呈现白圈套黑球（⊙）
7. 第7步：逐项对照：A、B、C中黑球与白球分离且位置不符，仅D项左上有框内叉号、右下为⊙，与三条规律全部吻合

**最快解法**：⚡ 分元素描点追踪法：给三个小元素各记一句口诀——黑球顺移1格内外换、叉号顺移2格外内换、白球顺移3格内外换，直接写出第四图位置：叉号在左上框内、黑球与白球重合成⊙于右下框外，秒选D

## 易错点
- ⚠ 只数平移步数、漏看『框内/框外交替』这第二重规律，会误选黑球在框内、白球单独框外的B或C
- ⚠ 第四图黑球与白球重合为⊙，易误判为『少了一个元素』或『白球被涂黑』而不敢选D
- ⚠ 三个元素步长不同（1/2/3格），若统一按同一格数平移则全盘皆错

## 母题抽象
> 🧩 当元素组成相同且小元素沿封闭轮廓分布时，用『逐元素追踪：平移步数+位置属性（框内外）交替』双规律外推问号处，并注意步长不同的元素可能重合形成复合图案（⊙）

**同类特征**：元素组成相同、八边形封闭轮廓、黑球/白球/叉号三种小元素、元素分居框内与框外、顺时针平移且步长1/2/3不同、求问号处第四幅图

### 题干
下列选项中，符合所给图形的变化规律的是：        。

### 选项
- A. A
- B. B
- C. C
- D. D　✅

### 官方解析
元素组成相同，优先考虑位置规律。观察发现，黑球每次顺时针平移1格，且依次交替出现在框内和框外；叉号每次顺时针平移2格，且依次交替出现在框外和框内；白球每次顺时针平移3格，且依次交替出现在框内和框外，只有D项符合。
故正确答案为D。
