# 空间重构-六面体折纸盒（特征面指针指向+相邻面排除）

考点：[[20-考点/判断推理/图形推理/空间重构-六面体折纸盒（特征面指针指向+相邻面排除）|图形推理 / 空间重构-六面体折纸盒（特征面指针指向+相邻面排除）]]


**问法模型**：给出三个立体视图求对应的展开图 → 锁定不对称特征面（五角星黑尖）作'指针'，验证黑尖指向的相邻面后逐一排除

## 推理链
1. 第1步：立体图1显示五角星面在正面，其黑色尖端朝上，正指向顶面'○'（椭圆）面，即'黑尖→○面'为该六面体确定的相邻关系
2. 第2步：所用规则——五角星是不对称特征面，黑尖相当于'箭头'；在展开图中沿黑尖方向确定其指向的面，再与立体图比对（指针指向法）
3. 第3步：A项☆黑尖向上，指向其上方的'\'面，与'黑尖→○'矛盾，排除
4. 第4步：B项☆黑尖向上，指向其上方的'□'面，与'黑尖→○'矛盾，排除
5. 第5步：D项☆位于顶行且黑尖向上，该列折叠成环后黑尖指向底部的空白面，与'黑尖→○'矛盾，排除
6. 第6步：C项☆位于左上角、黑尖向上，☆面折叠为侧面后黑尖指向同列环上的'○'面，与立体图1一致，且与立体图3（黑尖朝下时顶面为黑色三角形而非○）互不矛盾，当选

**最快解法**：⚡ 指针指向法（特征面锚定+排除）：以五角星黑尖为'箭头'，在展开图中沿黑尖方向找所指相邻面——A指'\'、B指'□'、D指空白面，均与立体图'黑尖指○'矛盾，排除后锁定C

## 易错点
- ⚠ 只核对选项中六个面的元素种类是否齐全、忽略黑尖的方向性（指针属性），在元素相同的展开图间误选
- ⚠ 对展开图中处于角部/边部的面（如C项左上角的☆）折叠时的旋转关系想错，把黑尖指向的面判错而误排C
- ⚠ 忽略立体图3的反向印证：黑尖朝下时可见顶面是黑色三角形而非'○'，说明黑尖恒指'○'面，单看一张立体图易将规律当成偶然

## 母题抽象
> 🧩 当立体图与展开图对应题中出现带指向的特征面（箭头、黑尖、图案朝向）时，用指针法：把该指向当作箭头，在展开图中沿箭头方向确定其相邻面，与立体图逐一比对排除。

**同类特征**：六面体折纸盒（立体图↔展开图）、三个立体视图+四个展开图选项、五角星黑尖可作指针、相邻面相对位置不变、T形展开图变体、选项间仅指针指向一处不同
