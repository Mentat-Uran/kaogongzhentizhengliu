# 图形推理-位置规律（旋转-逆时针90°）

考点：[[20-考点/判断推理/图形推理/图形推理-位置规律（旋转-逆时针90°）|图形推理 / 图形推理-位置规律（旋转-逆时针90°）]]


**问法模型**：问'符合所给图形的变化规律'且各图元素组成完全相同 → 考虑位置规律，对比相邻图形确定旋转方向与角度

## 推理链
1. 第1步：图1、图3、图4均为同一'米字+箭头+黑点+白圈'图形，图2为问号，元素组成相同，考虑位置规律
2. 第2步：观察图3→图4：箭头由向下变为向右、黑点由左端移至底端、白圈由右上斜移至左上斜，三元素同步变化，判定整体逆时针旋转90°
3. 第3步：将规律套用到图1→图2（问号处）：图1中向上的箭头逆时针转90°后指向左，右端黑点转到顶端，左下斜白圈转到右下斜
4. 第4步：逐项对照：A项白圈在底端竖直处不符；B项黑点在左上斜、箭头在左下斜不符；C项黑点在右上斜不符；D项黑点顶端、箭头向左、白圈右下斜，完全吻合
5. 第5步：末图验证：将D整体再逆时针旋转90°，箭头向下、黑点到左端、白圈到右上斜，与图3完全一致，规律闭环，确认选D

**最快解法**：⚡ 特征元素追踪法+验证：只盯黑点一个元素——图3黑点在左端、图4黑点在底端，立即判定'逆时针旋转90°'；再把图1右端黑点逆时针转90°到顶端，四个选项中只有C、D黑点在顶端区，再用箭头（图1向上→应指向左）一秒锁定D

## 易错点
- ⚠ 把整体旋转误当成单元素局部移动，只挪黑点不转箭头和白圈，导致位置对不齐
- ⚠ 旋转方向判反：若误判为顺时针90°，图1黑点会转到下端而错选A
- ⚠ 黑点与白圈一实一空易混淆，只验证黑点不核对白圈，可能被干扰项蒙混过关

## 母题抽象
> 🧩 当一组图形'元素组成相同、仅位置变化'且含箭头等方向性标记时，对比相邻两图同一特征元素的位置变动，定出旋转方向和角度，再用答案倒转到下一幅图做闭环验证

**同类特征**：元素组成相同、九宫格式顺推含问号、带箭头的方向性元素、黑点白圈双标记、米字/星形对称骨架、可用隔幅图验证规律

### 题干
下列选项中，符合所给图形的变化规律的是      。

### 选项
- A. A
- B. B
- C. C
- D. D　✅

### 官方解析
元素组成相同，考虑位置规律。观察发现图3到图4，整体图形逆时针旋转90°，根据此规律从图1到？处，整体图形也逆时针旋转了90°，对应D项。验证D项，图形整体旋转90°后刚好走到图3的位置。
故正确答案为D。
