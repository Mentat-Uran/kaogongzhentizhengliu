# 空间重构-六面体折叠（画边法-相邻面公共边）

考点：[[20-考点/判断推理/图形推理/空间重构-六面体折叠（画边法-相邻面公共边）|图形推理 / 空间重构-六面体折叠（画边法/相邻面公共边）]]


**问法模型**：给出展开图问哪个立体图能折叠而成 → 用画边法：以特征点为起点顺时针描边，检验选项中三个相邻面的公共边对应关系是否与展开图一致

## 推理链
1. 第1步：从展开图提取特征面——'X'对角线面、'田'字格面、灰色三角形面、黑色三角形面、带黑方块角面，四个选项的正面组合均由面①、面④、面⑤三个面构成
2. 第2步：采用画边法——以面⑤上的特征点（黄点）为起点，顺时针依次描出各边并标号，使每条边与相邻面建立一一对应关系
3. 第3步：确定题干基准：按此描边顺序，c边对应的相邻面是面②
4. 第4步：A项中c边对应的是面④，与题干面②不一致，排除
5. 第5步：B项中c边对应的是面④，与题干面②不一致，排除；C项中c边对应的是面①，与题干面②不一致，排除
6. 第6步：D项各边（含c边）的相邻面关系均与展开图一致，当选

**最快解法**：⚡ 画边法+排除法：锁定四个选项共用面组合（面①④⑤），从面⑤黄点出发顺时针描边，只需比对c边相邻面——题干为面②，A/B项对应面④、C项对应面①，全部排除，仅D一致

## 易错点
- ⚠ 画边起点未选在特征点（黄点）或未统一顺时针方向，导致各边与面的对应关系错乱
- ⚠ 只看三个面图案'能凑在一起'就选定，忽略相邻面公共边的唯一性检验——图案相同但相邻关系错位仍会折错
- ⚠ 三角形等面内图案随折叠发生旋转后，误将直角边/斜边与相邻面接错位置，凭感觉选成A或C

## 母题抽象
> 🧩 当题干出现'展开图+四个立体图'且各选项共用相同三个面时，用画边法：以公共面上特征点为起点顺时针描边，逐项验证公共边对应的相邻面（或公共边两侧图案）是否与展开图一致
