# 位置规律-内外分开看（翻转+旋转+黑块循环移动）

考点：[[20-考点/判断推理/图形推理/位置规律-内外分开看（翻转+旋转+黑块循环移动）|图形推理 / 位置规律-内外分开看（翻转+旋转+黑块循环移动）]]


**问法模型**：两组图'填入问号处呈现规律性'且元素组成相同 → 位置规律，外框与内部元素分开验证（翻转/旋转+循环移动）

## 推理链
1. 第1步：两组图形元素组成相同（均为'外框图形+内部点/块'结构），优先考虑位置规律，且内外分开看
2. 第2步：第一组外框规律——图1上下翻转得到图2，图2旋转得到图3；内部规律——每个黑点每次沿圈逆时针移动一格
3. 第3步：第二组外框套用：五边形图1上下翻转得图2，图2再旋转得图3，A、C的外框方向/角度不符合'翻转+旋转'的结果，排除A、C
4. 第4步：第二组内部套用：图2中的黑块沿外圈整体逆时针移动一格，即为问号处图形的黑块位置
5. 第5步：对照剩余B、D：D的黑块位置未按'逆时针移一格'变化，B的黑块位置与规律完全吻合，故选B

**最快解法**：⚡ 内外分离法+排除法：先按外框'上下翻转→旋转'排除A、C，再用口诀'黑块逆时针走一格'比对B、D，秒定B

## 易错点
- ⚠ 忽视'内外分开看'，把外框和黑块混在一起找规律，误判为'无规律'
- ⚠ 外框把'上下翻转'误看成左右翻转或旋转，导致错误排除正确选项
- ⚠ 黑块移动方向数反（误按顺时针）或漏数一格，在B、D间选错

## 母题抽象
> 🧩 当图形元素组成相同且呈'外框+内部小元素'结构时，用内外分开看：外框验证翻转/旋转，内部元素验证顺/逆时针循环移动，双重验证锁定答案

**同类特征**：元素组成相同、外框+内部元素、两组图对照推规律、外框上下翻转后旋转、黑点/黑块逆时针移动一格、五边形外框+方格黑块

### 题干
从所给的四个选项中，选择最合适的一个填入问号处，使之呈现一定的规律性：

### 选项
- A. A
- B. B　✅
- C. C
- D. D

### 官方解析
元素组成相同，优先考虑位置规律。观察发现题干图形都由外框图形和内部元素组成，考虑内外分开看。第一组外框图形的位置变化规律为：图1上下翻转后得到图2，图2旋转后得到图3；内部元素的位置变化规律为：每个黑点每次逆时针移动一格。第二组图形应用此规律，根据外框图形规律，排除A、C两项，再考虑内部黑块沿外圈每次逆时针移动一格，只有B项符合。
故正确答案为B。
