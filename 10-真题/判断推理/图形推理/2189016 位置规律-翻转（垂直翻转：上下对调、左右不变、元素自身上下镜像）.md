# 位置规律-翻转（垂直翻转：上下对调、左右不变、元素自身上下镜像）

考点：[[20-考点/判断推理/图形推理/位置规律-翻转（垂直翻转：上下对调、左右不变、元素自身上下镜像）|图形推理 / 位置规律-翻转（垂直翻转：上下对调、左右不变、元素自身上下镜像）]]


**问法模型**：问'可由所给图形经过垂直翻转得到哪个'→ 按'沿水平轴翻转：各面上下相对位置对调、左右相对位置不变、字母自身垂直镜像'逐项验证排除

## 推理链
1. 第1步：从题干图形提取位置关系——'D'面在'A'面左上方，'K'面在'A'面右下方，各面内分别印有字母D、A、K
2. 第2步：明确垂直翻转规则——沿水平轴翻转后，面与面的上下相对位置对调、左右相对位置不变，且字母本身也垂直翻转（'A'翻转为'∀'状）
3. 第3步：推出目标图形应满足：'D'面在'A'面左下方、'K'面在'A'面右上方，且'A'（∀）翻转后应位于图形左上角区域
4. 第4步：A项中'K'面位于'A'面上方、'D'面在下方，上下关系与要求不符，排除
5. 第5步：B项虽满足'D'面在'A'面左下方、'K'面在'A'面右上方，但字母'A'处于图形中间位置，而题干'A'经垂直翻转后应在图形左上角，排除
6. 第6步：C项中'D'面仍在'A'面左上方、'K'面仍在'A'面右下方，上下位置未发生对调，排除
7. 第7步：D项'D'面在'A'面左下方、'K'面在'A'面右上方，且'A''K''D'三个字母本身均已垂直翻转，与目标完全一致，当选

**最快解法**：⚡ 口诀法+排除法：'垂直翻转＝上下对调、左右不变、字母自身倒置'。第一步只盯K与A的上下关系——原图K在A右下方，翻转后K必在A右上方，直接排除A、C；第二步核对A（∀）整体应偏上（左上角区域）而非居中，排除B，锁定D

## 易错点
- ⚠ 混淆垂直翻转与180°旋转或水平翻转：180°旋转会连左右位置一起对调，而垂直翻转左右不变，易错排正确项
- ⚠ 只验证字母自身是否翻转（A→∀）而忽略面与面相对位置的上下对调，易误选'字母翻了、位置没翻'的C项
- ⚠ 只看D、K与A的相对方位而忽略'A'面在圆内的整体上下位置（B项即在此处设陷阱：A应在翻转后的左上角而非居中）

## 母题抽象
> 🧩 当题干问'图形经垂直/水平翻转后得到哪个'且图形由多个带字母（图案）的面构成时，用'翻转不变维'口诀：垂直翻转→上下对调、左右不变、元素自身上下镜像；先以一对醒目元素的相对上下方位快速排除，再用元素自身形态与整体位置复核剩余项

**同类特征**：问法：经垂直翻转得到、球面（五边形拼接）上分布字母面D、A、K、字母面之间的上下左右相对位置、字母自身垂直镜像（A→∀）、一次轴反射即可逐项排除

### 题干
下面选项中，可由所给图形经过垂直翻转得到的是：

### 选项
- A. A
- B. B
- C. C
- D. D　✅

### 官方解析
第一步：分析题干。
观察题干图形，“D”面在“A”面左上方，“K”面在“A”面右下方，对其进行垂直翻转，则图形内部字母所在面的上下相对位置发生变化，左右相对位置不变，即垂直翻转后，“D”面在“A”面左下方，“K”面在“A”面右上方；同时，字母本身也进行垂直翻转，得到其经过垂直翻转的图形。
逐一分析选项。
A项：该项中“K”面位于“A”面的上方，不符合题干要求，排除。
B项：该项中“D”面在“A”面左下方，“K”面在“A”面右上方，但该项中字母“A”处于中间位置，而题干图形中的字母“A”经垂直翻转后应该在图形的左上角，不符合题干要求，排除。
C项：该项中“D”面在“A”面左上方，“K”面在“A”面右下方，不符合题干要求，排除。
D项：“D”面在“A”面左下方，“K”面在“A”面右上方；同时，字母“A”“K”“D”本身也进行垂直翻转，得到其经过垂直翻转的图形，当选。
故正确答案为D。
