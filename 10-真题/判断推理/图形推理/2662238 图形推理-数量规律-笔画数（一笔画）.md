# 图形推理-数量规律-笔画数（一笔画）

考点：[[20-考点/判断推理/图形推理/图形推理-数量规律-笔画数（一笔画）|图形推理 / 图形推理-数量规律-笔画数（一笔画）]]


**问法模型**：‘填入问号处使之呈现一定规律性’且元素组成不同→先查属性规律，属性无规律查数量规律，面数量无规律时切换到笔画数（一笔画）验证

## 推理链
1. 第1步：题干五幅图（三角形加内线、矩形加折线、双圆内嵌三角形、平行四边形内线、梯形含半圆）元素组成不同，先试对称、曲直、封闭等属性规律，均无明显统一规律
2. 第2步：各图封闭区域（‘窟窿’）明显，优先数面数量，但题干五图面数量不构成等差或常数规律，排除面数量考点
3. 第3步：观察到图二为明显一笔画图形，且选项B为‘田’字变形图（一笔画考点的典型提示图形），转向笔画数规律
4. 第4步：数题干各图奇点（引出奇数条线的点，线头、T字接头均算）：每幅图奇点数为0或2，题干图形均为一笔画图形
5. 第5步：对选项逐一数奇点：A项奇点数为2，可一笔画；B项为‘田’字变形，奇点数4，需2笔；C项奇点数4，需2笔；D项奇点数4，需2笔
6. 第6步：题干规律为‘均为一笔画’，只有A项符合，故问号处选A

**最快解法**：⚡ 一笔画口诀法（数奇点）：抓住图2‘明显一笔画’和选项B‘田字变形’两大信号→逐图数奇点，奇点数0或2即一笔画；B、C、D奇点数均为4（2笔），直接锁定A

## 易错点
- ⚠ ‘窟窿’明显时易死磕面数量，发现面数量无规律后未能及时切换到笔画数考点
- ⚠ 数奇点时漏数线头（悬挂端点）和T字交叉点，把两笔画图形误判为一笔画
- ⚠ 圆/椭圆与直线相切处切点连接偶数条线不是奇点，误把切点当奇点导致A、D项笔画数误判

## 母题抽象
> 🧩 当题干图形元素组成不同、属性无规律且面数量无规律，且出现明显一笔画图形或选项含‘田/中’字变形时，用一笔画口诀：数奇点，奇点数为0或2为一笔画，奇点数÷2=笔画数，逐一排除选项

**同类特征**：元素组成不同、无明显属性规律、封闭区域多但面数量无规律、图二为明显一笔画图形、选项含‘田’字变形图、线条交叉出现T字接头与线头

### 题干
从所给的四个选项中，选择最合适的一个填入问号处，使之呈现一定的规律性：

### 选项
- A. A　✅
- B. B
- C. C
- D. D

### 官方解析
元素组成不同，且无明显属性规律，考虑数量规律。观察发现图形分为多个封闭区域，窟窿明显，考虑面数量，但无规律；再观察发现，图二为明显一笔画图形，B项为“田”字变形图，考虑笔画数，题干图形均为一笔画图形，故？处也应为一笔画图形。A、B、C、D四项图形的笔画数分别为1、2、2、2，只有A项符合。
故正确答案为A。
