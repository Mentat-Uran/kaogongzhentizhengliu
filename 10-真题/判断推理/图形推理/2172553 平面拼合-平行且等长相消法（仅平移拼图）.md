# 平面拼合-平行且等长相消法（仅平移拼图）

考点：[[20-考点/判断推理/图形推理/平面拼合-平行且等长相消法（仅平移拼图）|图形推理 / 平面拼合-平行且等长相消法（仅平移拼图）]]


**问法模型**：问法特征：'只有一个图形是由上面四个图形仅通过上、下、左、右平移拼合而成' → 应采用平行且等长相消法：将碎片间的公共边（平行且等长）两两抵消，剩余外围边即答案轮廓。

## 推理链
1. 第1步：从题干提取四个碎片图形：①细长竖置凹四边形（右侧内凹的燕尾状）；②斜向右下的三角形；③尖端朝左的细长三角形；④底边水平的三角形；拼合规则为只能平移，不能旋转、翻转。
2. 第2步：所用规则——平行且等长相消法：把碎片平移拼靠，凡方向相同且长度相等的边作为内部公共边相互抵消，不进入外轮廓；只有未被抵消的边构成拼合后的大图形轮廓。
3. 第3步：逐对配对相消：将②的斜边与④的斜边（平行且等长）拼合相消，再用①的凹边和③的细长斜边嵌入补齐剩余空缺，各内部公共边逐一抵消。
4. 第4步：相消后剩余的外围边为：下边水平、左右两边竖直、上边自左向右略微上倾的四条边，围成一个顶部微斜的四边形轮廓。
5. 第5步：与选项对照：A的顶部水平且底边倾斜、B左边倾斜且底边过短、C顶部向右下倾，均与相消后剩余边的方向、长度不符；只有D（左、右竖直，底边水平，顶边向右上微斜）与相消结果完全一致。
6. 第6步：得出结论：拼合轮廓为D，正确答案是D。

**最快解法**：⚡ 平行等长相消法+排除法：快速目测各碎片的斜边与水平边，把'平行且等长'的边两两配对在脑中抵消，剩余外围边数与倾斜方向直接与A/B/C/D比对，秒杀锁定D。

## 易错点
- ⚠ 忽略'只能上、下、左、右平移'的限制，擅自把碎片旋转或翻转后再拼，得到错误轮廓误选其他选项。
- ⚠ 相消条件记不严：必须'平行且等长'才能抵消，只平行不等长（或只等长不平行）的边不能相消。
- ⚠ 只看整体轮廓'差不多是四边形'而忽略边长比例与倾斜方向细节，在A、C、D等近似轮廓间误判。

## 母题抽象
> 🧩 当题干出现'多个小图形仅通过平移拼合成一个大图形'时，用平行且等长相消法：内部公共边两两抵消，剩余外围边构成的轮廓即为答案。

**同类特征**：平面拼合、只能平移（不可旋转翻转）、三角形碎片拼成四边形、平行且等长相消、轮廓边方向与长度匹配
