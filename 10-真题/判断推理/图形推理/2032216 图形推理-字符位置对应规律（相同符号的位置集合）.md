# 图形推理-字符位置对应规律（相同符号的位置集合）

考点：[[20-考点/判断推理/图形推理/图形推理-字符位置对应规律（相同符号的位置集合）|图形推理 / 图形推理-字符位置对应规律（相同符号的位置集合）]]


**问法模型**：给出符号串'$@$&&@$'，问哪个选项字符间位置对应关系与之相同 → 逐位编号后提取'相同符号占据的位置集合'，逐项对照

## 推理链
1. 第1步：将题干7个字符'$@$&&@$'按位置编号1~7：1=$、2=@、3=$、4=&、5=&、6=@、7=$
2. 第2步：归纳相同符号的位置集合：位置1、3、7相同（均为$）；位置2、6相同（均为@）；位置4、5相同（均为&）
3. 第3步：A项位置1、3、6相同，与题干'1、3、7相同'不符，排除；C项位置1、6、7相同，不符，排除；D项位置1、3、4相同，不符，排除
4. 第4步：B项位置1、3、7相同、位置2、6相同、位置4、5相同，三组位置集合与题干完全一致
5. 第5步：故正确答案为B

**最快解法**：⚡ 位置编号对照法+排除法：给题干7字符编号，记住三组位置'1、3、7 / 2、6 / 4、5'，逐项只核对关键位置（首、尾、中）是否落进同一集合，快速排除A、C、D锁定B

## 易错点
- ⚠ 只核对部分位置（如仅看位置1、3相同）就下结论，漏查位置4、5的配对关系
- ⚠ 未固定编号顺序导致位置错位，把'1、3、7'误看成'1、3、6'
- ⚠ 忽略题干三组符号互异的前提，误选存在额外相同位置的选项

## 母题抽象
> 🧩 当题干给出一串符号/字符并要求选'位置对应关系一致'的选项时，先逐位编号、列出相同符号的位置集合，再逐项核对集合是否完全重合

**同类特征**：符号串共7个字符、优先找相同符号、位置1、3、7相同、位置2、6相同、位置4、5相同、选项仅比对位置对应关系
