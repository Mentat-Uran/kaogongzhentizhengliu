# 数量规律-交点数（曲直交点数量+交点形态交替规律）

考点：[[20-考点/判断推理/图形推理/数量规律-交点数（曲直交点数量+交点形态交替规律）|图形推理 / 数量规律-交点数（曲直交点数量+交点形态交替规律）]]


**问法模型**：问号处填入最合适图形使之呈现规律性 → 元素组成不同且线条交叉明显、每图含曲线，先数曲直交点，数量一致再比较交点形态特征

## 推理链
1. 第1步：题干五幅图元素组成不同、无对称封闭等明显属性规律，且每幅图均只含一条曲线、线条交叉明显 → 锁定'曲直交点'这一数量考点
2. 第2步：逐图数曲直交点：图1至图5的曲直交点数均为1个；对照选项，B项曲线与图形交点数不为1，排除B
3. 第3步：数量无法区分剩余选项，升级比较交点形态：图1为曲线端点与直线交叉，图2为曲线中段与直线'十字交叉'，图3为端点交叉，图4为中段十字交叉，图5为端点交叉
4. 第4步：归纳出'端点交叉、中段十字交叉'交替出现的规律，故？处应为曲线中段与直线'十字交叉'的图形
5. 第5步：逐项对照：A项为曲线与斜线相交（另一种交替思路的产物），C项为曲线端点与直线相交，D项曲线中段与直线呈十字交叉 → 只有D符合交替规律的下一项，故选D

**最快解法**：⚡ 数量+形态两步法：先数曲直交点均为1排除B；再用口诀'端点—十字中段'交替验证，图1/3/5为端点交叉、图2/4为中段十字交叉，问号处取中段十字交叉，直接锁定D

## 易错点
- ⚠ 只数曲直交点数量就停止（A、C、D数量均为1），漏看交点形态'端点vs中段十字'的交替规律而随机猜答案
- ⚠ 误入'曲线与横竖线vs斜线交替'的思路（解析二）而错选A；该思路中图1为竖线、图3和图5为横线，直线方向并不完全一致，依据较弱
- ⚠ 未注意到每幅图只有一条曲线的前提，把多条直线间的交点也计入，导致曲直交点数错数

## 母题抽象
> 🧩 当题干图形均含曲线、线条交叉明显且属性无规律时，先数曲直交点数量，若各图数量一致，则继续观察交点形态（端点相交/中段十字交叉/相切）寻找交替或循环规律

**同类特征**：元素组成不同且无属性规律、每幅图仅一条曲线、曲直交点数均为1、端点交叉与中段十字交叉交替、线条交叉明显
