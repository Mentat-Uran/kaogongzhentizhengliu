# 图形推理-平面拼合（平行且等长相消）

考点：[[20-考点/判断推理/图形推理/图形推理-平面拼合（平行且等长相消）|图形推理 / 图形推理-平面拼合（平行且等长相消）]]


**问法模型**：四个小图形'只能上、下、左、右平移'拼合成一个整体 → 用'平行且等长相消法'：碎片间平行且等长的边相贴后消去，剩余线条即外轮廓，与选项比对

## 推理链
1. 第1步：盘点四个碎片——①上宽下窄的倒置等腰梯形、②直角三角形（竖直边在左、水平边在下）、③左侧竖直的直角梯形、④右侧竖直的直角梯形，各边均有明确的平行对应关系
2. 第2步：题干限定'只能平移'，故碎片相贴的边必须平行且等长，拼合后内部重合线段消去，只保留外轮廓
3. 第3步：配对相消——②的竖直直角边与直角梯形的竖直边平行等长，拼合相消；②的斜边与①的斜腰平行等长，相消；③与④的斜腰彼此平行等长，相消；碎片间若干短水平底边在内部相消
4. 第4步：消去内部线段后，外轮廓特征为：上、下各一条水平边，左侧保留'一段斜边+一段竖直边'，右侧两条斜边收成一个尖角
5. 第5步：逐项对照——A项轮廓与之完全吻合；B项左右两侧均为斜边、缺少左侧竖直段；C项顶部出现凹陷缺口；D项右侧有多余缺口，均与相消后的轮廓不符，排除

**最快解法**：⚡ 平行且等长相消法：先看竖直边——只有直角三角形和两个直角梯形各含一条竖直边，两两相消后整体仅剩左侧一段竖直边；再看斜边两两相消后右侧收成尖角，直接锁定A项

## 易错点
- ⚠ 误以为碎片可以旋转拼合，题干限定'只能平移'，摆错方向会导致边对不上而错选
- ⚠ 只消'平行'忽略'等长'（或反之），把不等长的平行边强行拼合，易错选轮廓相近的B项
- ⚠ 不逐边核对轮廓，被C、D项顶部/右侧的凹陷缺口等细节相似性干扰

## 母题抽象
> 🧩 当题干出现'几个小图形只能平移拼合成一个大图形'时，用'平行且等长相消法'：将碎片间平行且等长的边两两消去，剩余线条即为外轮廓，再与选项逐一比对

**同类特征**：拼合类图形推理、只能平移不能旋转、碎片含直角三角形与直角梯形、求唯一拼合后的整体轮廓、选项为不规则多边形、平行且等长相消
