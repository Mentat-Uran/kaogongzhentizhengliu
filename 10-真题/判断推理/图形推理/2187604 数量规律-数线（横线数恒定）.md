# 数量规律-数线（横线数恒定）

考点：[[20-考点/判断推理/图形推理/数量规律-数线（横线数恒定）|图形推理 / 数量规律-数线（横线数恒定）]]


**问法模型**：问号处填入图形使整体呈现规律 → 元素组成不同且属性规律失效时，转向数量规律；出现单一直线先数直线总数，无规律再细分数横线数

## 推理链
1. 第1步：题干四图元素组成完全不同（太阳笑脸图、黑点连线图、花枝气球图、五角星装饰图），且无对称、曲直、封闭等统一属性规律
2. 第2步：各图中出现明显的单一直线（如图1底部的横线、图3花枝间的横线、图4星上的横线），优先考虑数量规律中的数线
3. 第3步：逐图数直线总数，图与图之间直线总数无递增或恒定规律，需要换细分角度
4. 第4步：观察到每幅图中'横着的线条居多'，改数横线数：图1至图4横线数均为6条，规律为横线数恒等于6
5. 第5步：问号处应填入横线数为6的图形，逐项清点：A项5条横线、B项2条横线、C项0条横线、D项6条横线
6. 第6步：仅D项横线数为6，与题干规律一致，故选D

**最快解法**：⚡ 数线法（细分横线计数）：数直线总数无规律后，立刻按'横线居多'这一特征改数横线，题干四图横线数均为6，快速清点四个选项横线数（5/2/0/6），锁定D

## 易错点
- ⚠ 只数直线总数，因总数无规律而误判'无数线规律'，错走属性或一笔画方向
- ⚠ 忽略'横线居多'这一图形细节提示，想不到把线细分为横线、竖线分别计数
- ⚠ 清点选项横线时漏数短小或与其他元素交叉的横线，或误把曲线（如D项椭圆）计入横线

## 母题抽象
> 🧩 当图形元素组成不同、属性规律失效且图中出现单一直线时，先数直线总数；总数无规律则按横线/竖线细分计数，验证各图某类线数量是否恒定，据此锁定答案

**同类特征**：元素组成不同、无明显属性规律、出现单一直线、横线居多、横线数恒定（均为6）、数量规律-数线细化

### 题干
从所给四个选项中，选择最适合的一个填入问号处，使之呈现一定的规律性：

### 选项
- A. A
- B. B
- C. C
- D. D　✅

### 官方解析
元素组成不同，且无明显属性规律，考虑数量规律。观察题干发现，图形出现了单一直线，优先考虑数直线。但直线数没有规律，观察发现横着的线条居多，考虑数横线数，图1至图4横线数均为6条，因此“？”处应选择一个横线数为6的图形。四个选项中，A项有5条横线，B项有2条横线，C项有0条横线，D项有6条横线。
故正确答案为D。
