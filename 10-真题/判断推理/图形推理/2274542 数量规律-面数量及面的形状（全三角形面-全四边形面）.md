# 数量规律-面数量及面的形状（全三角形面-全四边形面）

考点：[[20-考点/判断推理/图形推理/数量规律-面数量及面的形状（全三角形面-全四边形面）|图形推理 / 数量规律-面数量及面的形状（全三角形面/全四边形面）]]


**问法模型**：两套图形对照填问号 → 提取第一组共性规律（面数量+面的形状），第二组延续同构规律并呈现特征升级，对选项做数量与形状双重过滤

## 推理链
1. 第1步：两套图形元素组成不同，无对称、曲直等明显属性规律，且每个图形均被内部线条分割成多个封闭区域，提示考面数量
2. 第2步：先数第一组三幅正方形分割图：面数量均为4，且每一个面都是三角形，即“4个全三角面”是第一组共性
3. 第3步：再数第二组前两幅图（三角形分割图、梯形分割图）：面数量均为5，且每一个面都是四边形，即第二组规律升级为“5个全四边形面”
4. 第4步：故？处图形须同时满足“面数量为5”且“5个面全为四边形”两个条件
5. 第5步：逐项检验——A项3个四边形面+2个三角形面（形状不符）、B项4个四边形面+1个三角形面（形状不符）、C项5个面但全为三角形面（照搬第一组形状，不符）、D项5个面且全为四边形面（均符合）
6. 第6步：仅D项同时满足面数量与面的形状两重要求，故选D

**最快解法**：⚡ 面数量+面的形状双重过滤法：先数两组面数量（第一组4、第二组5）锁定数量档，发现四个选项面数量均为5后，立即升级辨析面的形状，用“第二组全四边形面”一步排除含三角形面的A、B、C，锁定D

## 易错点
- ⚠ 只数面数量不辨面的形状：四个选项面数量恰好都是5，仅停留在“数面”这一层会无法排除任何选项
- ⚠ 受第一组“全三角形面”干扰误选C：C项面数量虽对，但面的形状是三角形，属于照搬第一组特征而非延续第二组特征
- ⚠ 忽略第二组外部轮廓变化（正方形→三角形→梯形），误以为面形状须随轮廓改变而动摇“全四边形”判断

## 母题抽象
> 🧩 当两套图形元素组成不同且均被线条分割出多个封闭区域时，先数面数量找组内常数；若选项面数量相同，则升级辨析“面的形状”，正确答案须同时满足“数量延续”与“形状特征升级”双重条件

**同类特征**：两套图形对照求同存异、元素组成不同无属性规律、图形被内部线条分割成封闭区域、面数量组内恒定（第一组4、第二组5）、面的形状全为三角形或全为四边形、问号处延续第二组升级规律

### 题干
此题包含两套图形和可供选择的4个图形。这两套图形具有某种相似性，也存在某种差异。要求你从四个选项中选择最适合取代问号的一个。正确的答案应不仅使两套图形表现出最大的相似性，而且使第二套图形也表现出自己的特征。

### 选项
- A. A
- B. B
- C. C
- D. D　✅

### 官方解析
元素组成不同，无明显属性规律，考虑数量规律。观察发现，题干图形被分割成多个封闭区域，考虑面数量。第一组图形中的面数量都是4，且都是三角形的面；第二组图形中面数量都是5，且都是四边形的面，因此？处应选5个四边形面的图形。A项3个四边形的面，2个三角形的面，排除；B项4个四边形的面，1个三角形的面，排除；C项5个三角形的面，排除；D项5个四边形的面，当选。
故正确答案为D。
