# 位置规律（旋转-翻转）

考点：[[20-考点/判断推理/图形推理/位置规律（旋转-翻转）|图形推理 / 位置规律（旋转/翻转）]]


**问法模型**：选非题'以下哪项不是由左图得到的'→ 元素相同用位置规律，逐一验证各选项能否经旋转/翻转得到，排除可得的，选不可得的

## 推理链
1. 第1步：观察左图，卡通牛由牛头（两只牛角、两耳、双眼、双鼻孔）、带斑纹的身体、尾巴、四肢组成，各选项元素组成与左图相同，仅姿态可能变化
2. 第2步：元素组成相同，优先考虑位置规律，即旋转、翻转（翻转可与旋转组合），旋转/翻转只改变朝向位置，不能改变元素数量与形状
3. 第3步：A项：将左图左右翻转，尾巴由左侧变到右侧、斑纹位置对应变化，与A项完全一致，可得到，排除
4. 第4步：B项：将左图先顺时针旋转、再上下翻转，牛头朝向与身体姿态和 B 项一致，可得到，排除
5. 第5步：C项：与左图对比，C项牛头上只有一个牛角，缺少一只牛角，元素数量减少，而旋转/翻转无法增减元素，故不能由左图得到
6. 第6步：D项：将左图逆时针旋转后，牛头、尾巴、斑纹朝向与 D 项一致，可得到，排除
7. 第7步：本题为选非题，A、B、D 均可由左图经位置变化得到，只有 C 项不能，故选 C

**最快解法**：⚡ 

## 易错点
- ⚠ 忽略'选非题'设问，把可得项 A、B、D 误选
- ⚠ 只看整体轮廓和姿态相似，忽略牛角、尾巴、斑纹等局部细节的缺失
- ⚠ 翻转方向混淆（左右翻转与上下翻转、顺时针与逆时针旋转），误判 B、D 不能由左图得到

## 母题抽象
> 🧩 当题干问'哪项不能由左图得到'且各图整体轮廓相同、仅姿态变化时，先用'元素数量核验'查局部细节是否缺失（秒杀项），再对剩余选项逐一验证旋转/翻转的组合，选非题排除可得到的项

**同类特征**：元素组成相同、位置规律、旋转与翻转组合、选非题设问、局部细节差异（牛角/尾巴/斑纹）、整体轮廓相似

### 题干
以下哪项不是由左图得到的？

### 选项
- A. A
- B. B
- C. C　✅
- D. D

### 官方解析
元素组成相同，优先考虑位置规律，逐一分析选项。
A项：可由左图左右翻转得到，排除；
B项：可由左图先顺时针旋转，再上下翻转得到，排除；
C项：选项图形与左图不一致，选项缺少一个牛角，不能由左图得到，当选；
D项：可由左图逆时针旋转得到，排除。
本题为选非题，故正确答案为C。
