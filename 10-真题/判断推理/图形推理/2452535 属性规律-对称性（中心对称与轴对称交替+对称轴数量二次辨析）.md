# 属性规律-对称性（中心对称与轴对称交替+对称轴数量二次辨析）

考点：[[20-考点/判断推理/图形推理/属性规律-对称性（中心对称与轴对称交替+对称轴数量二次辨析）|图形推理 / 属性规律-对称性（中心对称与轴对称交替+对称轴数量二次辨析）]]


**问法模型**：'填入问号处使之呈现一定的规律性'且元素组成不同 → 优先属性规律，本题按'对称类型交替+对称轴条数'两步筛选

## 推理链
1. 第1步：题干五幅图均由黑白小圆点散布组成，元素组成不同且无数量规律，将每幅图的圆点连线，图一、图三、图五整体呈平行四边形轮廓，提示考虑属性规律中的对称性
2. 第2步：逐一判定对称类型——图一中心对称、图二轴对称、图三中心对称、图四轴对称、图五中心对称，呈现'中心对称、轴对称'交替出现的规律
3. 第3步：按交替规律，？处应填入轴对称图形，B、D两项均非轴对称图形，排除B、D
4. 第4步：二次验证——题干已出现的轴对称图形（图二、图四）都只有1条对称轴，故问号处还应满足'仅一条对称轴'
5. 第5步：对比A、C：A项有两条对称轴，排除；C项仅有一条竖直对称轴，符合全部规律，当选

**最快解法**：⚡ 对称交替口诀+数轴二次筛选：先按'中心/轴'交替锁定？处为轴对称排除B、D，再数对称轴条数，A两条、C一条，直接选C

## 易错点
- ⚠ 盯着黑白圆点的数量、颜色分布找规律，忽略'把圆点连线看整体轮廓'这一属性规律切入点
- ⚠ 只判断轴对称/中心对称类型就匆忙作答，跳过对称轴数量的二级辨析而误选A
- ⚠ 把黑圆、白圆分开看对称，因颜色'不对称'而误判图二、图四或C项的对称性（官方按整体图形连线判定）

## 母题抽象
> 🧩 当图形由散落小元素（黑白圆点等）组成且元素组成不同时，先将小元素连线看整体轮廓的对称性；若中心对称与轴对称交替出现，问号处选对应类型，并用'对称轴条数'做二次筛选定答案

**同类特征**：黑白圆点散布排列、元素组成不同、连线后整体轮廓呈平行四边形、中心对称与轴对称交替出现、轴对称图形仅一条对称轴、需二级辨析定答案

### 题干
请从所给的四个选项中，选出最恰当的一项填入问号处，使之呈现一定的规律性。

### 选项
- A. A
- B. B
- C. C　✅
- D. D

### 官方解析
元素组成不同，优先考虑属性规律。整体观察，将图形连线，图一、图三、图五为平行四边形，考虑对称性。图一中心对称、图二轴对称、图三中心对称、图四轴对称、图五中心对称，两种对称图形交替出现，？处选择轴对称图形，排除B、D两项。再次观察，发现题干中轴对称图形均只有一条对称轴，A项有两条对称轴，排除，C项有一条对称轴，当选。
故正确答案为C。
