# 空间重构-长方体展开图折叠（公共边法）

考点：[[20-考点/判断推理/图形推理/空间重构-长方体展开图折叠（公共边法）|图形推理 / 空间重构-长方体展开图折叠（公共边法）]]


**问法模型**：平面图形最可能折叠成左图长方体 → 用公共边法：找出成直角且折叠后重合的两条边，检验是否相互垂直且等长

## 推理链
1. 第1步：左图立体为一个长、宽、高互不相等的扁平长方体，展开图由两类矩形面（大矩形面+细长矩形面）和突出的小矩形面构成，折叠时相邻面的边必须一一重合
2. 第2步：空间重构-公共边规则：平面展开图中成直角的两条边折叠后将重合为同一条公共边，故该公共边必须相互垂直且等长，才能围成封闭且与题干一致的长方体
3. 第3步：A项：线1、线2为平面中相互垂直的两条线，是公共边，但两线垂直而不等长，折叠后无法完全重合，排除
4. 第4步：B项：线1、线2为相互垂直的两条线，是公共边，且垂直且等长，折叠后可严丝合缝围成长方体，保留
5. 第5步：C项：线1、线2为相互垂直的公共边，但垂直而不等长，排除；D项：线1、线2为相互垂直的公共边，但垂直而不等长，排除
6. 第6步：逐项对照后仅B项满足'公共边相互垂直且等长'，与官方答案B一致

**最快解法**：⚡ 公共边等长排除法：锁定每个展开图中成直角的线1、线2（折叠后重合的公共边），直接比较两线长度，'垂直+等长'才可选——A、C、D均不等长秒排，唯B等长当选

## 易错点
- ⚠ 套用正方体展开图经验，忽略长方体各棱长度不一，公共边必须等长这一核心检验条件
- ⚠ 只看面的形状、数量相似就选，未检查突出小矩形与长条矩形交界处两条直角边折叠后是否重合等长
- ⚠ 视觉误差：图中线1、线2长度接近时凭感觉判断，应按矩形格数/边长逐一对比

## 母题抽象
> 🧩 当题干为非正方体（长方体）展开图折叠且问'最可能折叠成'时，用公共边法：找到平面中成直角、折叠后重合的两条边，验证其相互垂直且等长，不等长者直接排除

**同类特征**：空间重构-立体折叠、非正方体长方体（长宽高不等）、展开图为矩形组合、成直角的两边是公共边、公共边需垂直且等长、逐项排除定型

### 题干
以下平面图形最可能折叠成左图所示长方体的是：

### 选项
- A. A
- B. B　✅
- C. C
- D. D

### 官方解析
本题为空间重构题，可以通过公共边长短进行判断，由成直角的两条边是公共边可知，要想折叠成与题干一致的封闭立体图形，需要公共边相互垂直且等长。

A项：线1、线2是平面中相互垂直的两条线，为公共边，垂直但不等长，排除；
B项：线1、线2是平面中相互垂直的两条线，为公共边，垂直且等长，当选；
C项：线1、线2是平面中相互垂直的两条线，为公共边，垂直但不等长，排除；
D项：线1、线2是平面中相互垂直的两条线，为公共边，垂直但不等长，排除；
故正确答案为B。
