# 立体拼合-凹凸对应（拼合成长方体）

考点：[[20-考点/判断推理/图形推理/立体拼合-凹凸对应（拼合成长方体）|图形推理 / 立体拼合-凹凸对应（拼合成长方体）]]


**问法模型**：问'哪一个与①②③④中任一个都不能组成长方体'→选非题，用'凹凸一致'原则将①~④的凸起位置与选项凹槽一一配对，排除能拼合的项，无配对项的即为答案。

## 推理链
1. 第1步：明确拼合规则——两多面体要组成长方体须'凹凸一致'，①~④均为带两个凸起小正方体的零件，其配对件必须在对应位置有两个凹槽。
2. 第2步：逐一定位凸起位置：①在底面两端的中间上方各有一个凸起；②在右上角有两个凸起；③在对角线两端有两个凸起；④在左下角以及对边中间有两个凸起。
3. 第3步：C项凹槽位置与①的两个凸起一一对应，按凹凸一致可知①+C可拼成长方体，排除C。
4. 第4步：B项凹槽与③对角线两端的凸起位置对应，③+B可拼成长方体，排除B。
5. 第5步：A项凹槽与④左下角及对边中间的凸起对应，④+A可拼成长方体，排除A。
6. 第6步：D项的凹槽位置与①③④的凸起均不对应；②虽然也找不到拼合件，但②是题干零件而非选项，不影响作答，故与①②③④中任一个都不能拼成长方体的选项只有D，本题为选非题，选D。

**最快解法**：⚡ 凹凸一致配对排除法：把①③④的凸起位置与选项凹槽快速配对——①配C、③配B、④配A，逐项排除后，剩下的D即为不能与任一零件拼合的答案；牢记②是干扰件（无配对项但不是选项）。

## 易错点
- ⚠ 忽略'选非题'问法，误把'能拼合的A/B/C'当作答案
- ⚠ 被②误导：发现②找不到拼合对象后，误去选项中找与②配对的件（如误认为D应与②拼合），偏离问法指向
- ⚠ 凸起与凹槽的空间对应位置看错（含旋转视角），如把④'左下角+对边中间'的凸起误与D项凹槽对应

## 母题抽象
> 🧩 当题干给出若干带凸起的多面体和一组带凹槽的选项，问'哪个不能拼成完整几何体'时，用'凹凸一致'逐一配对排除；若某题干零件本身无配对项，注意它是干扰件而非答案，答案只能落在无配对的选项上。

**同类特征**：立体拼合、组成长方体、凹凸一致、两个凸起小正方体、选非题（任一个都不能）、四对四配对排除

### 题干
<p>①、②、③、④为四个多面体零件，问A、B、C、D四个多面体零件中的哪一个与①、②、③、④中的任一个都不能组成长方体？</p><p><img width="700px" height="488px" src="../../../90-图片/题目图/15257e527824c38.png" /></p>

### 选项
- A. A
- B. B
- C. C
- D. D　✅

### 官方解析
此题为立体图形拼接问题，做题原则为凹凸一致。首先多面体①在底面两端的中间上方有两个凸起的正方体，按照原则可知①与C项可以组合成长方体，排除C项；多面体②在右上角有两个凸起的正方体，按照原则查看选项，发现没有能够与多面体②拼合成长方体的选项；多面体③在对角线两端有两个凸起的正方体，按照原则可知多面体③与B项可以组合成长方体，排除B项；多面体④在左下角以及对边中间有两个凸起的正方体，按照原则可知多面体④与A项可以组合成长方体，排除A项。
本题为选非题，故正确答案为D。
