# 图形推理-空间重构（六面体折叠-相对面排除+相邻面公共点-公共边比对）

考点：[[20-考点/判断推理/图形推理/图形推理-空间重构（六面体折叠-相对面排除+相邻面公共点-公共边比对）|图形推理 / 图形推理-空间重构（六面体折叠-相对面排除+相邻面公共点/公共边比对）]]


**问法模型**：题干给纸盒外表面展开图，问哪个选项能由其折叠而成 → 空间重构模型：先以相对面排除，再以特征图案的公共边/公共点接触关系逐项验证

## 推理链
1. 第1步：将展开图六面标号a~f，提取各面特征图案：a、c面含S形线条，d面含黑点三角形，e面含黑三角，f面含波浪线三角形，b面与d面在展开图中为相对面
2. 第2步：所用规则——①相对面在立体图中不能同时出现；②相邻两面上的特征图案若有公共点/公共边接触关系，立体图中必须一致（应接触则接触、不应接触则不相交）
3. 第3步：对照C项，其上边b面与前边d面同时可见，而展开图中b与d为相对面，立体图中不能同时出现，排除C
4. 第4步：对照B项，上边f面的波浪线三角形与右边d面的黑点三角形在展开图中没有公共点，但B项立体图中二者出现公共点，与展开图不一致，排除B
5. 第5步：对照D项，上边e面的黑三角与右边d面的黑点三角形在展开图中没有交点，但D项立体图中二者相交，与展开图不一致，排除D
6. 第6步：A项三个面的图案及相邻位置、公共点接触关系均与展开图一致，验证通过，当选

**最快解法**：⚡ 公共点排除法：以立体图三个相邻面（上、前、右）为定位，逐项检查相邻面特征三角形与黑点的接触关系——C项上、前面为相对面直接排除；B项f面波浪线三角与d面黑点三角'不应共点却共点'、D项e面黑三角与d面黑点三角'不应相交却相交'，均排除，锁定A

## 易错点
- ⚠ 只依据a、c面内S形线条的方向排除B、D，而江苏出题人对面内线条方向一般不做考查，易误排除正确项A（参见2018年江苏A类第87题）
- ⚠ 相对面判断失误：b面与d面为相对面，误认为C项三面组合合法
- ⚠ 忽略相邻面特征图案之间的公共点/公共边约束，只看图案'是否在同一视图出现过'而漏掉接触关系错误

## 母题抽象
> 🧩 当题干给出带特征图案（三角、黑点、波浪线等）的六面体展开图时，先排除相对面同时出现的选项，再以特征图案为锚点，用相邻面公共边、公共点的'应接触/不应接触'关系逐项验证剩余选项

### 题干
左边给定的是纸盒外表面的展开图，右边哪一项能由它折叠而成？请把它找出来。

### 选项
- A. A　✅
- B. B
- C. C
- D. D

### 官方解析
本题考查六面体的空间重构。将平面图中的各面进行标号，如图1所示：

A项：与题干展开图一致，当选；
B项：该项上边和右边的面分别为f面和d面，在展开图中，f面中的波浪线三角形和d面中的黑点三角形没有公共点，而在该项中有公共点，与题干不一致，排除；
C项：该项上边和前边的面分别为b面和d面，展开图中这两个面为相对面，在立体图中不能同时出现，与题干不一致，排除；
D项：该项上边和右边的面分别为e面和d面，在展开图中，e面中的黑三角和d面中的黑点三角形没有交点，而在该项中有交点，与题干不一致，排除。
故正确答案为A。
注：有同学会根据a、c面中S线条的方向排除B、D两项，但还是建议同时掌握通过公共边/公共点对选项进行排除的解题方法，因为江苏出题人对于面内线条的方向一般不做考查，例如2018年江苏A类第87题。
