# 位置规律-相对位置关系（两黑块相间：间隔一个白块）

考点：[[20-考点/判断推理/图形推理/位置规律-相对位置关系（两黑块相间：间隔一个白块）|图形推理 / 位置规律-相对位置关系（两黑块相间：间隔一个白块）]]


**问法模型**：两组图+问号处选最合适图形 → 第一组归纳两黑块的相对位置规律（间隔一个白块），第二组验证后代入问号处筛选选项

## 推理链
1. 第1步：两组图形框架不同——第一组为十字方格、第二组为蜂窝六角格，但每幅图均恰好含两个黑块，元素组成相同；因框架与整体布局改变，平移/旋转/翻转等整体位置规律不成立（官方：无明显位置规律）
2. 第2步：转而观察两个黑块之间的相对位置关系：第一组三幅图中，两黑块均不共边相邻，中间恰好隔一个白块（如第一组图1黑块位于上臂与右臂，中间隔中心白块，图2、图3两黑块同样隔一个白块）
3. 第3步：用第二组验证规律：图1、图2中两个黑色六角格之间也恰好间隔一个白色六角格，说明“两黑块间隔一个白块”是贯穿两组的共同规律
4. 第4步：将规律应用到问号处：所选图形中两个黑色六角格也应恰好间隔一个白色六角格（点邻接、不共边）
5. 第5步：逐项对照——A项两黑块之间恰好隔一个白块，符合；B、C项两黑块相隔较远，间隔不止一个白块；D项两黑块共边相邻，中间无白块
6. 第6步：只有A满足“间隔一个白块”，故正确答案为A

**最快解法**：⚡ 相对位置数间隔法：直接数每幅图两黑块之间的白块个数——题干两组每图均为1个；选项中只有A的两黑块隔1个白块（D隔0个、共边相邻，B、C隔多于1个），直接选A

## 易错点
- ⚠ 两组框架不同（十字格→蜂窝格），易执着于找平移/旋转/翻转等整体位置规律而卡壳，忽略可跨框架迁移的“两黑块相间（隔一个白块）”规律
- ⚠ 只确认“每图有两个黑块”就匆忙选答案，未数两黑块之间隔的白块数；D项同为两黑块但共边相邻（间隔为0），最易误选
- ⚠ 蜂窝格中黑块“点邻接（隔一个白块）”与“共边相邻”视觉上接近，粗看易混淆

## 母题抽象
> 🧩 当两组图元素组成相同（均含两个黑块）但外部框架或整体布局不同、无整体平移旋转规律时，转而观察两黑块的相对位置关系（相邻还是相间、间隔几个白块），到选项中找间隔数一致的一项

**同类特征**：两段式两组图、每图恰有两个黑块、第一组十字方格、第二组蜂窝六角格（框架不同）、无明显平移/旋转规律、两黑块间隔一个白块（相间排列）、问号处延续第二组规律

### 题干
从所给的四个选项中，选择最合适的一个填入问号处，使之呈现一定的规律性。

### 选项
- A. A　✅
- B. B
- C. C
- D. D

### 官方解析
元素组成相同，但无明显位置规律。观察发现，题干前组图和后组图均出现两个黑块，且两个黑块之间均间隔一个白块，故问号处应遵循此规律，只有A项符合。
故正确答案为A。
