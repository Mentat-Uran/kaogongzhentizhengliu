# 空间重构-四面体折叠（公共边法-标号描点定位）

考点：[[20-考点/判断推理/图形推理/空间重构-四面体折叠（公共边法-标号描点定位）|图形推理 / 空间重构-四面体折叠（公共边法/标号描点定位）]]


**问法模型**：'左边给定多面体外表面，右边哪一项能由它折叠而成' → 给展开图四面标号，用公共边法逐一验证选项中相邻两面的公共边与图案（黑色三角形的边、线条顶点）的交点关系

## 推理链
1. 第1步：从展开图提取特征——四面体共四个面（标为面a、b、c、d），面a与面d上带黑色三角形（面d为黑色直角三角形），面b引出一条线条，选项每幅三维图只呈现相邻两个可见面
2. 第2步：所用规则为四面体公共边法——先判定选项两个可见面在展开图中的身份，再核对公共边是否与黑色三角形的边相交、线条顶点与三角形哪个顶点相交
3. 第3步：A项，展开图中面c与面a、面d的公共边均与黑色三角形的边相交，而选项中右侧面与左侧面的黑色三角形的边不相交，说明右侧面不是面c而是面b；进一步核对，展开图中面b左侧为面a且面b引出线条的顶点与面a黑色三角形的一个顶点相交，选项中该顶点不相交，排除
4. 第4步：B项，选项由面c、面d构成，公共边及线条顶点与黑色直角三角形顶点的相交关系均与展开图一致，保留
5. 第5步：C项，选项中左右两面的公共边为黑色直角三角形的斜边，而展开图中只有面c与面d的公共边是斜边，故该图应为面c与面d的组合；但展开图中面c引出线条的顶点与面d中'短直角边与斜边的交点'相交，选项中却与'长直角边与斜边的交点'相交，细节不符，排除
6. 第6步：D项，选项右侧面在展开图中找不到对应面，属于无中生有面，直接排除
7. 第7步：结论——只有B项两可见面的身份、公共边及图案交点关系与展开图完全一致，正确答案为B

**最快解法**：⚡ 标号+公共边描点法：先给展开图四面标a/b/c/d；每幅选项只看两个可见面，第一步用'公共边是否与黑色三角形的边相交'锁定面的身份（可同时排除A的身份误判和C），第二步核对'线条顶点与短直角边还是长直角边与斜边的交点相交'这一细节定B、C；D右侧面无中生有可秒排

## 易错点
- ⚠ 只看黑色三角形的形状位置，忽略'公共边是否与黑色三角形的边相交'这一判定点（A项陷阱）
- ⚠ C项中线条顶点与'短直角边与斜边交点'还是'长直角边与斜边交点'相交的细微差别未辨析到位
- ⚠ 面b与面c图案相似，未标序号导致可见面身份判断错位；忽略D项右侧面属无中生有面这一快速排除点

## 母题抽象
> 🧩 当题干为四面体展开图且各面含黑色三角形、引出线条等特征图案时，先给四面标号，用公共边法验证选项相邻两面：公共边与图案的边是否相交、线条顶点与哪个交点相交，凡有一处不一致即排除

**同类特征**：四面体展开图、各面含黑色三角形与引出线条、选项为相邻两面组合的三维图、公共边与图案交点关系是判定核心、存在无中生有面干扰项、问法为'哪一项能由它折叠而成'

### 题干
左边给定的是多面体的外表面，右边哪一项能由它折叠而成？请把它找出来。

### 选项
- A. A
- B. B　✅
- C. C
- D. D

### 官方解析
本题考查四面体，将原展开图标上序号，如下图所示：

逐一分析选项。
A项：展开图中面c与面a、面d的公共边均与面a、面d上的黑色三角形的边相交，而选项中右侧面与左侧面的黑色三角形的边不相交，因此选项中右侧面不可能为面c，应为面b，展开图中面b左侧面应为面a，且面b引出线条的顶点与面a的黑色三角形的一个顶点相交，而选项中面b引出线条的顶点与左侧面上的黑色三角形顶点不相交，选项与展开图不一致，排除；
B项：选项由面c、面d构成，与展开图一致，当选；
C项：选项中左侧面与右侧面的公共边为黑色直角三角形的斜边，展开图中只有面c与面d的公共边为黑色直角三角形的斜边，故选项由面c与面d构成，展开图中面c引出线条的顶点与面d中黑色直角三角形短直角边与斜边的顶点相交，而选项中面c引出线条的顶点与面d中黑色直角三角形长直角边与斜边的顶点相交，选项与展开图不一致，排除；
D项：选项右侧面在展开图中不存在，属于无中生有面，排除。
故正确答案为B。
