# 图形推理-数量规律（汉字笔画数）

考点：[[20-考点/判断推理/图形推理/图形推理-数量规律（汉字笔画数）|图形推理 / 图形推理-数量规律（汉字笔画数）]]


**问法模型**：两组汉字图形问'填入问号处使之呈现规律性' → 先排除属性规律，再按组数汉字笔画找组内递增数列

## 推理链
1. 第1步：题干为两组三格图，第一组汉字为'足、事、修'，第二组为'风、旧、？'，图形全部由汉字构成
2. 第2步：元素组成不同，对称、封闭、结构等属性规律不明显，优先转向数量规律；汉字类图形首先考虑笔画数
3. 第3步：数第一组笔画：足7画、事8画、修9画，构成7、8、9的递增等差数列
4. 第4步：将此规律套入第二组：风4画、旧5画，故问号处应为6画汉字
5. 第5步：逐项数选项笔画：甲5画、争6画、改7画、住7画
6. 第6步：只有B项'争'（6画）满足4、5、6的递增规律，故选B

**最快解法**：⚡ 笔画数法：先数第一组'足事修'=7、8、9递增，立即得出第二组应为4、5、6，直接在选项中找6画字——'争'（B），其余甲5画、改7画、住7画快速排除

## 易错点
- ⚠ 笔画数错数：'争'的撇折、横钩类笔画易漏数或多数（规范为6画），'旧'（5画）易误数为4画
- ⚠ 误把两组笔画混为一组寻找整体规律，忽略'两组分别套用同一递增规律'的命题模式
- ⚠ 先入为主看汉字结构（左右/半包围）或部首偏旁规律，绕开数量规律浪费时间

## 母题抽象
> 🧩 当题干图形全部为汉字且组成不同、属性规律缺失时，用'数笔画'方法，验证各组笔画是否构成等差递增数列并套用到问号处

**同类特征**：图形均为汉字、两组各三格的对比型排版、元素组成不同、无明显属性规律、第一组笔画7、8、9递增、第二组笔画4、5、？

### 题干
从所给的四个选项中，选择最合适的一个填入问号处，使之呈现一定的规律性：

### 选项
- A. A
- B. B　✅
- C. C
- D. D

### 官方解析
元素组成不同，且无明显属性规律，优先考虑数量规律。图形均为汉字，优先考虑笔画数。第一组图笔画数依次为7、8、9。第二组图形运用此规律，第二组图笔画数依次为4、5、？，因此问号处应选择6笔画的汉字。四个选项汉字的笔画数分别为5、6、7、7，只有B选项符合规律。
故正确答案为B。
