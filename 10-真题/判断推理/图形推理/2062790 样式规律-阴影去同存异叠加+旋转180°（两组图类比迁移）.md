# 样式规律-阴影去同存异叠加+旋转180°（两组图类比迁移）

考点：[[20-考点/判断推理/图形推理/样式规律-阴影去同存异叠加+旋转180°（两组图类比迁移）|图形推理 / 样式规律-阴影去同存异叠加+旋转180°（两组图类比迁移）]]


**问法模型**：两组图'选最合适的一个填入问号'且图形组成相似 → 先在第一组内归纳阴影分布的叠加与位置变换规律，再将规律整体平移到第二组对照选项

## 推理链
1. 第1步：第一组三图组成相似，图1为斜线阴影L形、图2为竖线阴影L形，图3田字格仅在左上（竖线）和右下（斜线）两角有阴影，图1图2的阴影样式都在图3中出现，提示做阴影运算规律
2. 第2步：把图1、图2按2×2四分位拆分并忽略线条方向差异：图1占左上、右上、左下，图2占右上、左下、右下；去同存异去掉共有的右上和左下，只剩图1独有的左上、图2独有的右下有阴影
3. 第3步：该去同存异结果再旋转180°，左上与右下对角互换后仍是左上、右下有阴影，且线条样式随位置对调（左上竖线、右下斜线），与图3完全吻合，锁定规律为'去同存异+旋转180°'
4. 第4步：第二组图1为缺右下四分之一的圆形（占左上、右上、左下），图2为下半圆（占左下、右下）；去同存异去掉共有的左下，得阴影占左上、右上、右下、空白位于左下
5. 第5步：将去同存异结果旋转180°：原空白左下转到右上，阴影变为左上、左下、右下
6. 第6步：逐项对照空白位置：A、B空白仍在左下（只叠加未旋转），C空白在左上，仅D右上为空白，符合旋转后规律，故选D

**最快解法**：⚡ 空白位置追踪法（排除法）：第二组去同存异后空白在左下，经180°旋转空白必移到右上，直接扫选项找'右上为空白'的图形，秒选D

## 易错点
- ⚠ 只做去同存异忘记后续旋转180°，误选空白仍在左下的A或B
- ⚠ 因两组图内部阴影线条方向（斜线/竖线）不一致而不敢运算，官方明确可按线条一致处理、只看阴影分布位置
- ⚠ 拆分四分位时看错图1、图2覆盖范围（图1缺右下四分之一、图2只占下半圆），导致共有区域判断错误

## 母题抽象
> 🧩 当两组图组成相似且阴影呈'两图拼合互补'特征时，先按规则区域（象限/网格）拆分做去同存异，再叠加旋转、翻转等位置变换去验证第三图，用空白（或阴影）所在区域即可快速锁定答案

**同类特征**：两组图类比、图形组成相似、阴影样式叠加运算、去同存异、旋转180°、象限拆分定位空白

### 题干
从所给四个选项中，选择最合适的一个填入问号处，使之呈现一定的规律性：

### 选项
- A. A
- B. B
- C. C
- D. D　✅

### 官方解析
图形组成相似，图1图2中的阴影样式均在图3中出现，考虑运算规律。第一组图中，根据阴影样式位置可知，图1与图2阴影部分去同存异（此处阴影虽然线条不同，仍可继续按照阴影线条一致的情况运算）后旋转180度可得图3，则第二组图也应符合此规律。图1和图2左下角的阴影部分去同存异后旋转180度得到的空白区域应在右上角，只有D项符合。
故正确答案为D。
