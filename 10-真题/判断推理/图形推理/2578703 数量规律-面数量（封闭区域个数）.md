# 数量规律-面数量（封闭区域个数）

考点：[[20-考点/判断推理/图形推理/数量规律-面数量（封闭区域个数）|图形推理 / 数量规律-面数量（封闭区域个数）]]


**问法模型**：问号处填入使一组图形呈现规律性 → 元素组成不同且属性无规律时，优先数封闭面个数，按数列规律外推

## 推理链
1. 第1步：题干四幅图元素组成不同（回形针U形、山形照片框、X加外框、双三角组合），先查对称/曲直/开闭等属性规律，无明显统一属性
2. 第2步：各图封闭区域特征明显，按'属性不行数数量'的顺序转入数量规律，且封闭面突出，优先数'面'的个数
3. 第3步：逐图数面：第1幅U形线条未封闭为0个面；第2幅照片框仅山形轮廓封闭为1个面；第3幅外框与内部各1个共2个面；第4幅双三角组合共3个面
4. 第4步：题干面数为0、1、2、3，构成公差为1的递增等差数列，故？处图形应含4个面
5. 第5步：逐项数封闭区域：A项电池形共4个面，B项调色盘共5个面，C项相机共3个面，D项摄像机共6个面
6. 第6步：只有A项面数为4，符合递增规律，故选A

**最快解法**：⚡ 数面法+等差外推：题干面数依次0、1、2、3→问号处需4个面；快速数四个选项封闭区域个数（A为4、B为5、C为3、D为6），排除法直选A

## 易错点
- ⚠ 漏数小的封闭区域（如A项电池正极凸起小矩形、D项镜头处小三角形），导致选项面数误判
- ⚠ 把'×'交叉线或开口的U形线条误当作封闭面，使题干面数起点数错
- ⚠ 被图形的生活实物含义（照片、相机、调色盘等图标）带偏，去联想'摄影/文具'等语义属性而忽视数量规律

## 母题抽象
> 🧩 当题干图形元素组成不同、属性（对称/曲直/开闭）无统一规律且封闭区域明显时，优先数面的个数；若题干面数构成等差数列，则按公差外推问号处的面数，再逐项计数排除

**同类特征**：元素组成不同、无明显属性规律、封闭区域（面）明显、面数量依次递增、等差数列0、1、2、3、生活图标式简笔画图形

### 官方解析
元素组成不同，且无明显属性规律，优先考虑数量规律。由于图形封闭面明显，优先考虑数面的数量。观察发现，题干图形面的数量依次为0、1、2、3，构成了递增的等差数列，因此？处图形面的个数应为4。A项面的个数为4，B项面的个数为5，C项面的个数为3，D项面的个数为6，只有A项符合要求。
故正确答案为A。
