# 立体拼合-数量守恒（小方块计数）

考点：[[20-考点/判断推理/图形推理/立体拼合-数量守恒（小方块计数）|图形推理 / 立体拼合-数量守恒（小方块计数）]]


**问法模型**：“最不可能由两个左侧立体图形拼接成”（选非问法）→ 立体拼合验证模型：先用数量守恒核对块数，再对块数吻合项做旋转拼合验证

## 推理链
1. 第1步：提取前提——左侧立体图形由4个小方块构成（底部成排小块，其上叠1块）
2. 第2步：所用规则——数量守恒：两个立体拼接时小方块只面贴合、不重叠不消失，拼成体必然恰含4+4=8个小方块
3. 第3步：逐项对照——A、B、C补数被遮挡方块后均为8个小方块，且可将左侧图形经旋转后两两贴合拼出（官方解析附拼合示意图验证成立）
4. 第4步：D项逐列清点可见块并补齐遮挡块，合计仅7个小方块，8≠7
5. 第5步：结论——D不满足“8个小方块”的必要条件，最不可能由两个左侧图形拼成；因本题为选非题，故选D

**最快解法**：⚡ 数量守恒法（数块法）：左图4块→两个拼成必为8块；快速清点各选项，D只有7块，直接锁定D，无需逐项试拼

## 易错点
- ⚠ 忽略“最不可能”的选非问法，误把能拼成的A/B/C当答案
- ⚠ 数块时漏数被遮挡的小方块，把A/B/C或D的块数数错
- ⚠ 误以为拼接可以重叠、切割或留空，忽视4+4=8这一数量必要条件

## 母题抽象
> 🧩 当立体拼合题干出现“由两个（N个）同一立体拼接成”的特征时，先算“单个块数×N”得总数，用数量守恒秒杀块数不符的选项，再对块数吻合者做旋转拼合验证

**同类特征**：立体拼合、两个相同立体拼接、选非问法（最不可能）、小方块立体、数量守恒8块、旋转后贴合拼合
