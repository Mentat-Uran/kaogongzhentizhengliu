# 图形推理-平面拼合（平行且等长相消法）

考点：[[20-考点/判断推理/图形推理/图形推理-平面拼合（平行且等长相消法）|图形推理 / 图形推理-平面拼合（平行且等长相消法）]]


**问法模型**：左边整体轮廓可分割为右边'某三个'碎片（可平移、旋转，不可翻转），选'不属于'的一项 → 选非型平面拼合题，用'平行且等长相消'逐项试拼，能复原轮廓的排除，剩者为答案

## 推理链
1. 第1步：题干为选非题，左边图形是带内凹拐角的'L形'轮廓，需判断A、B、C、D中哪一项不参与分割。
2. 第2步：平面拼合规则——两块图形拼合时，相互重合的公共边必定平行且等长，把这对边'消去'，剩下的外围线段就构成拼合后的整体轮廓。
3. 第3步：取B项（直角梯形），其竖直直角边与题干轮廓的竖直边平行等长，先对齐定位；再让A项（不规则四边形）与D项（带凹口的旗形）的斜边两两平行且等长，公共边相互抵消。
4. 第4步：A、B、D消去全部平行且等长的公共边后，剩余外围线段恰好围出左边的'L形'轮廓，说明A、B、D都属于分割所得图形。
5. 第5步：C项（斜向四边形）的各边方向与长度无法与其余碎片及题干轮廓的对应边形成'平行且等长'的配对消去，拼合后无法复原左边轮廓，故C不属于分割所得。
6. 第6步：本题为选非题，'不属于'的C项即为正确答案，与官方答案一致。

**最快解法**：⚡ 平行且等长相消法（拼合消边）：先固定B项直角梯形与题干轮廓的直角边贴合定位，再让A、D的斜边平行等长相互抵消，三块恰好复原左图轮廓；C项各边无法与轮廓边平行等长配对，直接锁定答案C。

## 易错点
- ⚠ 把选非题误当选是题，去找'能拼合'的那一项而错选A/B/D
- ⚠ 忽略'可旋转、不可翻转'的限制，把C项翻转（镜像）后误认为可拼入
- ⚠ 拼合时忘记消去重合的平行且等长公共边，逐边硬比导致判断混乱

## 母题抽象
> 🧩 当题干出现'整体图形可分割为若干碎片、可平移旋转但不可翻转'的拼合特征时，用平行且等长相消法：令碎片间公共边抵消，验证外围线段能否复原整体轮廓，选非题中无法复原者为答案。

**同类特征**：选非题（找不属于分割所得）、平面拼合、可平移旋转、不可翻转、带内凹拐角的L形整体轮廓、碎片为四边形/梯形/凹多边形、平行且等长相消
