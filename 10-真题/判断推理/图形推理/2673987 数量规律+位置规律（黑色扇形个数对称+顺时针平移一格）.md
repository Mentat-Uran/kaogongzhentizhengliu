# 数量规律+位置规律（黑色扇形个数对称+顺时针平移一格）

考点：[[20-考点/判断推理/图形推理/数量规律+位置规律（黑色扇形个数对称+顺时针平移一格）|图形推理 / 数量规律+位置规律（黑色扇形个数对称+顺时针平移一格）]]


**问法模型**：一组序列图填问号问规律 → 先数黑色图形个数找数量规律，数量排除不尽再追踪黑块位置移动

## 推理链
1. 第1步：题干五幅图均为八等分圆盘，黑色扇形数量依次为1、2、4、2、？，呈1→2→4→2→1的对称数量规律，故？处应有1个黑色扇形
2. 第2步：据此排除A（2个黑块）、C（3个黑块），只剩B、D（各1个黑块）
3. 第3步：B、D仅黑块位置不同，启用位置规律：图1左上方的黑扇形顺时针平移一格（45°）即图2中其中一个黑块，说明该黑块每幅图顺时针走一格
4. 第4步：顺推四步，该黑块从左上（约10点半方向）依次到上偏右、再往下、再往左下方向推进，至图5应停在右下方（约4点半方向）
5. 第5步：B项黑扇形位于右下，D项位于左下，排除D，答案为B

**最快解法**：⚡ 数量排除法＋黑块追踪法：先数黑块个数1,2,4,2→1排除A、C；再盯住图1那个黑块按顺时针每格45°走四步，落点右下即B

## 易错点
- ⚠ 只看数量规律排除A、C后，在B、D之间不追踪黑块移动轨迹而凭感觉乱选
- ⚠ 顺时针与逆时针方向看反，误选D（左下）
- ⚠ 忽略图2起出现新增黑块，误以为所有黑块都遵循同一移动规律而否定平移规律

## 母题抽象
> 🧩 当一组圆盘图中黑/阴影块数量呈1、2、4、2、1式对称变化时，先用数量排除，再锁定其中一个黑块追踪其每次旋转的方向与格数，验证剩余选项的位置

**同类特征**：八等分圆盘、黑色扇形数量1、2、4、2、数量对称规律、黑块位置逐图变化、问号处补图、剩余选项仅位置不同

### 题干
从选项中选择最合适的一个填入问号处，使之呈现出一定的规律性。

### 选项
- A. A
- B. B　✅
- C. C
- D. D

### 官方解析
元素组成不同，且无明显属性规律，优先考虑数量规律。观察发现，黑色图形数量依次为1、2、4、2、？，故？处黑色图形数量应为1，排除A、C两项；对比B、D两项，黑色图形位置不同，考虑位置规律，观察发现第一个图形的黑色图形顺时针平移一格得到第二个图形的黑色图形（其中1个），以此类推，该黑色图形每次顺时针平移一格，排除D项。
故正确答案为B。
