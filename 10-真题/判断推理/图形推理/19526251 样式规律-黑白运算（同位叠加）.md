# 样式规律-黑白运算（同位叠加）

考点：[[20-考点/判断推理/图形推理/样式规律-黑白运算（同位叠加）|图形推理 / 样式规律-黑白运算（同位叠加）]]


**问法模型**：“选择最合适的一个填入问号处，使之呈现一定的规律性”+九宫格且每行轮廓、分割区域完全相同 → 按行横向找规律，用黑白运算逐区域定色。

## 推理链
1. 第1步：九宫格每行三个图形元素组成相似——外轮廓与内部分割区域完全相同（第一行沙漏形、第二行台灯形、第三行屋形），仅黑白颜色分布不同，优先考虑样式规律。
2. 第2步：轮廓与分割相同、仅黑白不同 → 锁定黑白运算（同位叠加），即同一位置上“图1颜色+图2颜色=图3颜色”。
3. 第3步：由第一行定运算规则：白+黑=白，白+白=白，黑+白=白，黑+黑=黑，即“两图同为黑才得黑，其余一律得白”。
4. 第4步：用第二行验证：灯座三角形等两图均为黑的区域叠加后仍为黑，灯罩中一黑一白的区域叠加后为白，规律成立。
5. 第5步：将规则套用到第三行：对图1与图2逐区域叠加，两图均为黑的区域（如顶部、中部的黑色块）得黑，一黑一白或均白的区域（如图1第二行左侧黑块对应图2为白）得白。
6. 第6步：对照选项：C项各区域黑白分布与运算结果完全一致；A、B、D均有若干区域颜色与运算结果相悖，排除，故选C。

**最快解法**：⚡ 黑白运算口诀“同黑得黑，其余得白”：第一行定规则、第二行做验证，第三行只找图1与图2黑色区域的“交集”，问号处黑色区域应恰为两图黑色区域的交集，直接锁定C。

## 易错点
- ⚠ 叠加方向看错：应是同一行内“图1+图2=图3”横向叠加，误做成竖向运算或去同存异
- ⚠ 把“黑+黑=黑、其余得白”误记成“异色得黑/去同存异”，易错选D类干扰项
- ⚠ 只凭黑色区域形状整体相似就选（如B项与第三行图2形状相近），不逐区域核对颜色

## 母题抽象
> 🧩 当九宫格每行图形轮廓与分割区域相同、仅黑白分布不同时，用黑白运算：先由第一行确定运算规则（本题“同黑得黑、其余得白”），第二行验证，再逐区域套用到第三行，选与运算结果完全一致的选项。

**同类特征**：九宫格、每行轮廓与分割区域相同、仅黑白颜色分布不同、元素组成相似、问号处填图、黑白叠加

### 题干
从所给的四个选项中，选择最合适的一个填入问号处，使之呈现一定的规律性：

### 选项
- A. A
- B. B
- C. C　✅
- D. D

### 官方解析
元素组成相似，优先考虑样式规律。观察发现，九宫格每行图形轮廓和分割区域相同，优先考虑黑白运算。第一行图形的运算规律为：白+黑=白，白+白=白，黑+白=白，黑+黑=黑；经验证，第二行图形符合此规律；第三行图形应用此规律，只有C项符合。
故正确答案为C。
