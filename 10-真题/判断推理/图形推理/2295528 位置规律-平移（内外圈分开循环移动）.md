# 位置规律-平移（内外圈分开循环移动）

考点：[[20-考点/判断推理/图形推理/位置规律-平移（内外圈分开循环移动）|图形推理 / 位置规律-平移（内外圈分开循环移动）]]


**问法模型**：『符合所给图形的变化规律』且元素组成相同→优先位置规律，将黑圆（内圈）与白圆（外圈）拆开分别找移动方向和步数，用排除法锁定答案

## 推理链
1. 第1步：四幅图形元素组成完全相同（均为黑圆加白圆、仅位置不同），按『元素相同看位置』优先考虑位置规律
2. 第2步：观察发现黑圆只出现在内圈（中央2×2的四个格子），白圆只出现在外圈（周边一圈格子），故内外圈分开看、各找各的规律
3. 第3步：先看内圈：黑圆沿内圈每次逆时针移动1格，图1→图2→图3逐帧验证成立；推到？处，黑圆不应停在内圈左下角（该格应为空白）
4. 第4步：对照选项，B、D的内圈左下角均有黑圆，排除B、D
5. 第5步：再看外圈：白圆沿外圈每次顺时针移动3格，图1→图2→图3逐帧验证成立；推到？处，外圈左上角应有一个白圆
6. 第6步：对照剩余选项，A的外圈左上角无白圆，排除A；C同时满足内外圈两条移动规律，故正确答案为C

**最快解法**：⚡ 分圈排除法：先看内圈——黑圆逆时针走1格，？处内圈左下角必为空，秒排B、D；再看外圈——白圆顺时针走3格，？处左上角必有白圆，排A锁定C

## 易错点
- ⚠ 内外圈混在一起整体观察，因黑圆与白圆的方向、步数不同而找不到统一平移规律
- ⚠ 顺/逆时针方向记反（内圈是逆时针1格、外圈是顺时针3格），导致排除选项出错
- ⚠ 只验证黑圆的内圈规律就匆忙作答，漏验白圆『移动3格』这一步数条件，在A、C之间误选

## 母题抽象
> 🧩 当方格图中黑白小元素组成相同、仅位置变化，且分别位于内外两个圈层时，按圈层拆分，分别数清各自的方向与步数（方向步数可不同），再用『？处某角必有/必无某元素』逐圈排除选项

**同类特征**：元素组成相同、黑白圆位置变化、内圈与外圈分离、逆时针移动1格、顺时针移动3格、角格有无定排除

### 题干
下列选项中，符合所给图形的变化规律的是      。

### 选项
- A. A
- B. B
- C. C　✅
- D. D

### 官方解析
元素组成相同，优先考虑位置规律。观察发现黑圆均在内圈移动，白圆均在外圈移动，考虑内外圈分开看，首先观察内圈，发现黑圆每次逆时针移动1格，因此？处图形中内圈左下角应为空白格，排除B、D选项。继续观察外圈，发现白圆每次顺时针移动3格，因此？处外圈左上角应有一个白圆，排除A选项。
故正确答案为C。
