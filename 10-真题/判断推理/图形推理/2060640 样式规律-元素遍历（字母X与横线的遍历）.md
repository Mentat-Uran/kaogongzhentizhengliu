# 样式规律-元素遍历（字母X与横线的遍历）

考点：[[20-考点/判断推理/图形推理/样式规律-元素遍历（字母X与横线的遍历）|图形推理 / 样式规律-元素遍历（字母X与横线的遍历）]]


**问法模型**：两组式图形、每组末幅为问号且元素组成相似 → 优先考虑样式规律中的元素遍历：提炼前两幅图共同含有的元素，要求问号处图形同样具备

## 推理链
1. 第1步：观察第一组：X/y、X上加横线、e^X三幅图均含字母X，且均含横线——分式横线、X上方横线、e中间的横线
2. 第2步：元素组成相似，定为样式规律-遍历：第一组每幅图都是'X＋横线'的组合，即该组是X与横线的遍历
3. 第3步：将规律平移到第二组：√X含X和根号顶部的横线，±X含X和减号横线，故问号处图形必须同时含X和横线
4. 第4步：逐项对照选项：A sinx、B cosx、D cscx虽均含x，但整词无任何横笔画；C tanx中字母t带横笔画（横线），满足'X＋横线'
5. 第5步：辅助验证：第一组封闭空间数为0、0、1（e有1个），第二组√X、±X均为0，问号处应有1个封闭空间；C(tanx)的a提供1个封闭空间且该字母为半封闭形，排除全封闭o所在的B(cosx)，印证选C

**最快解法**：⚡ 元素遍历＋排除法：先锁定两组共同必备元素'X＋横线'，四个选项都含x，直接比对'横线'——只有tanx的t有横笔画，sinx/cosx/cscx均无横线，秒选C；再用封闭空间0、0、1的规律二次确认

## 易错点
- ⚠ 四个选项均含x，若只验证'含X'这一层则无法排除任何选项，必须进行'横线'的二级辨析
- ⚠ 隐蔽横线易漏看：e中间的横线、t的横笔画这类嵌在字母内部的横线，扫图时容易忽略
- ⚠ 用封闭空间辅助判断时，B(cosx)与C(tanx)都有1个封闭空间，若不做'全封闭o／半封闭a'的二级辨析会误选B

## 母题抽象
> 🧩 当两组图'元素组成相似'且某元素（字母、线条）在组内每幅图重复出现时，用元素遍历法：先提炼每组必备元素清单（如'X＋横线'），再逐选项核对，特别注意字母内部横线等隐蔽元素的二级辨析

**同类特征**：两组式图形、每组第三幅为问号、图形由字母与数学符号（√、±、分式线）构成、元素组成相似、每幅图均含字母X、每幅图均含横线、选项为形近英文词（sinx/cosx/tanx/cscx）

### 题干
从所给四个选项中，选择最合适的一个填入问号处，使之呈现一定的规律性：

### 选项
- A. A
- B. B
- C. C　✅
- D. D

### 官方解析
元素组成相似，考虑样式规律。第一组图中每幅图形中都含有X和横线（注意e的中间有横线），即第一组图形是X和横线的遍历。将此规律应用到第二组图形中，每幅图形都应该含有X和横线，而选项中只有C中含有X和横线。
故正确答案为C。
另外的解法：第一组图形中空间数为0、0、1，第二组图形中空间数量也应该是0、0、1，且存在封闭空间的字母为半封闭图形，即C选项。
