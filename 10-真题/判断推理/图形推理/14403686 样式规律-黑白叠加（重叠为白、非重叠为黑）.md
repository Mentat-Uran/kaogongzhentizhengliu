# 样式规律-黑白叠加（重叠为白、非重叠为黑）

考点：[[20-考点/判断推理/图形推理/样式规律-黑白叠加（重叠为白、非重叠为黑）|图形推理 / 样式规律-黑白叠加（重叠为白、非重叠为黑）]]


**问法模型**：两组图各给三幅、求第三幅图形 → 先从第一组归纳叠加时的黑白规则，再原样套用到第二组

## 推理链
1. 第1步：第一组图1（双正方形）与图2（缺口圆）元素组成相似且相同线条重复出现，优先考虑样式规律中的加减同异
2. 第2步：观察第一组归纳规则——图1与图2叠加后，重叠部分变为白色，不重叠部分变为黑色，得到黑白填充的图3
3. 第3步：第二组将十字形与正六边形同位（中心对齐）叠加：十字与六边形相交的中间区域为重叠区→应为白色
4. 第4步：非重叠区逐一判断——十字上下两个外露端头、六边形左右两侧外露角均为非重叠区→应为黑色
5. 第5步：对照选项——A项整体为线框式未按规则填色，B项重叠区与外露区黑白分布不符，C项中间重叠区为实心黑与'重叠为白'矛盾，均排除
6. 第6步：只有D项中间重叠区为白色、上下端头与左右非重叠区均为黑色，完全符合规律，故选D

**最快解法**：⚡ 黑白叠加规则法：第一组验证'重叠→白、非重叠→黑'后，直接检查第二组十字∩六边形的重叠区是否为白、外露端头是否为黑，排除法锁定D

## 易错点
- ⚠ 误按常规线条求同去异处理，忽略本题核心是叠加后的黑白填充变化
- ⚠ 未先从第一组完整归纳'重叠白、非重叠黑'规则就急于套用第二组
- ⚠ 叠加时未将十字与六边形中心对齐，误判重叠区范围导致黑白分布看错

## 母题抽象
> 🧩 当两组图元素相似且出现黑白填充变化时，先在第一组找出'重叠区与非重叠区各自的黑白规则'，再把该规则原样套用到第二组对照选项排除

**同类特征**：两组三图式问法、元素组成相似、相同线条重复出现、图形叠加、黑白填充变化、求第三幅图形
