# 位置规律（顺时针旋转）与数量规律（逐图增加一条线）复合

考点：[[20-考点/判断推理/图形推理/位置规律（顺时针旋转）与数量规律（逐图增加一条线）复合|图形推理 / 位置规律（顺时针旋转）与数量规律（逐图增加一条线）复合]]


**问法模型**：'选最合适的一个填入问号处使之呈现规律性'→相邻两图两两对比，找出'位置变化+数量变化'复合规律并沿用到问号处

## 推理链
1. 第1步：整体观察题干四个图形，均由外框与内部直线构成，单看形状、面数等常规规律不明显
2. 第2步：对比图1与图2，发现图1顺时针旋转且增加一条线变成图2，即'位置旋转+数量加线'同时发生
3. 第3步：用图2→图3、图3→图4逐一验证，每幅图均在前一幅图基础上顺时针旋转且每次增加一条线，规律成立
4. 第4步：归纳规律：？处图形应在前一个图形（图4）基础上顺时针旋转且再增加一条线，线条数逐图递增、开口方位随旋转依次移动
5. 第5步：逐项对照：需同时满足'旋转后的方位'与'多一条线'两个条件
6. 第6步：只有B项满足在前一图基础上顺时针旋转且增加一条线（新增线表现为伸出边框的线段），故选B

**最快解法**：⚡ 相邻对比法+排除法：先比对图1→图2锁定'顺时针旋转+加一条线'的复合规律，快速验证图3、图4后套用到？处，同时核对旋转方位与线条数量两个维度，排除不符项锁定B

## 易错点
- ⚠ 只验证'多一条线'的数量规律，忽略'顺时针旋转'的位置条件，误选线条数相符但朝向/开口方位不符的选项
- ⚠ 旋转方向看反（误判为逆时针），导致在开口方位相近的选项间误选
- ⚠ 误以为'增加一条线'只能是新增封闭边，忽略新增线可能表现为线段延长、伸出原有边框之外

## 母题抽象
> 🧩 当图形序列组成相似但整体规律不明显时，先对比相邻两图找'位置变化（旋转）+数量变化（加线）'的复合规律，验证全序列后沿用到问号处，用'方位+数量'双维度排除选项

**同类特征**：各图由外框与内部直线构成、组成元素相似、整体观察规律不明显，需相邻两图对比、相邻图形存在旋转的位置变化、线条数量逐图递增、问号处要求延续复合规律
