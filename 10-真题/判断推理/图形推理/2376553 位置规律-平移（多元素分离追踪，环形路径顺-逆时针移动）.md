# 位置规律-平移（多元素分离追踪，环形路径顺-逆时针移动）

考点：[[20-考点/判断推理/图形推理/位置规律-平移（多元素分离追踪，环形路径顺-逆时针移动）|图形推理 / 位置规律-平移（多元素分离追踪，环形路径顺/逆时针移动）]]


**问法模型**：题干给出5幅图+问号，元素组成相同 → 分离追踪各小元素在外圈格上的移动规律（方向+步长），推出问号处位置

## 推理链
1. 第1步：五幅图元素组成相同（均为小三角+小圆圈在4×4去中心的12格外圈上），优先考虑位置规律而非样式规律
2. 第2步：给外圈12格按顺时针编号1~12（1=左上角，沿上边→右边→下边→左边循环）；将小三角与小圆圈分开追踪，互不干扰
3. 第3步：小三角位置依次为第2、4、6、8、10格，规律为每次顺时针平移2格，问号处应到第12格（即第2行第1列）
4. 第4步：小圆圈位置依次为第11、8、5、2、11格，规律为每次逆时针平移3格（跨角拐弯连续计数：11→8→5→2→11），问号处应到第8格（即第4行第3列）
5. 第5步：逐项对照：A项三角在第1格、B项三角在第1格、D项三角在第8格，均不满足三角规律；C项三角在第2行第1列、圆圈在第4行第3列，双元素均吻合，故选C

**最快解法**：⚡ 元素分离追踪法+数格口诀：先盯步长规律更简单的小三角（顺时针每次2格：2→4→6→8→10→12），可直接排除A、B、D锁定C；再用小圆圈（逆时针每次3格：11→8→5→2→11→8）验证C无误

## 易错点
- ⚠ 外圈12格跨角拐弯时数格出错（如从第10格顺时针2格应到第12格即第2行第1列，误数到第1格会错选A/B）
- ⚠ 只追踪一个元素就定答案，忽略双元素需分别验证（如只看圆圈位置，A、C、D中圆圈易混淆）
- ⚠ 移动方向看反：三角为顺时针、圆圈为逆时针，两者方向混用会把三角定位到第8格而错选D

## 母题抽象
> 🧩 当题干图形为'固定框架+移动小元素'且元素组成相同时，给外圈格子顺时针连续编号，分开追踪每个小元素的移动方向与步长（注意跨角连续计数），最后逐项验证选项

**同类特征**：元素组成相同、4×4去中心的外圈12格环形路径、小三角与小圆圈两个移动元素、5幅图+问号的连续位置变化、两元素方向相反、步长不同

### 题干
从所给四个选项中，选择最合适的一个填入问号处，使之呈现一定的规律性：

### 选项
- A. A
- B. B
- C. C　✅
- D. D

### 官方解析
元素组成相同，优先考虑位置规律。整体观察发现，小三角、小圆圈均在移动，可以分开看，先看小三角，小三角的移动规律为每次顺时针平移两格，只有C项符合要求。再通过小圆圈位置验证，小圆圈的移动规律为每次逆时针平移三格， C项当选。
故正确答案为C。
