# 数量规律-数直角（角数量）

考点：[[20-考点/判断推理/图形推理/数量规律-数直角（角数量）|图形推理 / 数量规律-数直角（角数量）]]


**问法模型**：‘填入问号处使之呈现一定的规律性’且元素组成不同 → 先试属性、再按面→点→线顺序数数，均无规律时锁定数直角，找直角数的连续规律

## 推理链
1. 第1步：题干五幅图形状各异、元素组成不同，优先考虑属性规律或数量规律
2. 第2步：观察对称/曲直/开闭等属性无规律，转数数量；图形‘窟窿’较多先数面，面数量为1、3、2、2、2，无规律
3. 第3步：第二幅图存在交叉线条，考虑数点，点数量为3、7、5、5、10，无规律；除第三幅图含圆外其余均由直线构成，数直线为3、5、5、6、9，也无规律
4. 第4步：数线时发现已知图形均含多边形，且包括直角三角形、直角梯形、正方形等，每一幅图都存在直角，转而数直角数
5. 第5步：直角数依次为1、2、3、4、5，构成公差为1的递增数列，问号处图形应含6个直角
6. 第6步：逐项数选项直角：A为2个、B为6个、C为2个、D为5个，只有B满足6个直角，故选B

**最快解法**：⚡ 数数口诀法（有交叉数点、有窟窿数面、含明显直角特征数直角）+ 直角计数：由图一‘直角三角形’、图四‘正方形’等特征直接数直角，得1、2、3、4、5的等差递增，问号处需6个直角，数选项只有B（平行分式矩形组合）含6个直角

## 易错点
- ⚠ 面、点、线数量均无规律后放弃数数，未继续尝试数角这一层级
- ⚠ 把锐角、钝角混入统计，没有严格只数90°直角
- ⚠ 漏数隐蔽直角，如图二旗形顶角处、图五轮廓转折处的直角，导致数列判断错误

## 母题抽象
> 🧩 当图形元素组成不同、属性无规律，且面/点/线数量均不成规律，但图形中出现直角三角形、正方形、矩形等明显直角特征时，改数直角数，验证其是否构成等差或常数数列并据此选答案

**同类特征**：元素组成不同、面数量无规律、点数量无规律、线数量无规律、含直角三角形/直角梯形/正方形等直角特征、直角数1至5递增

### 题干
从所给的四个选项中，选择最合适的一个填入问号处，使之呈现一定的规律性：

### 选项
- A. A
- B. B　✅
- C. C
- D. D

### 官方解析
元素组成不同，考虑属性或者数数。观察发现属性无规律。考虑数数，图形中“窟窿”较多，可以先数面，面数量 1，3，2，2，2无规律；观察图形发现，第二幅图存在交叉，考虑数点，点数量3，7，5，5，10无规律；观察图形发现，除第三幅图外其余所有图形均由直线构成，考虑数线，直线数3，5，5，6，9无规律；并且在数线时发现，已知图形中均有多边形，其中包含直角三角形，直角梯形，正方形，每一幅图形中都有直角，考虑数直角数，直角数1，2，3，4，5为常数列。在选项中寻找直角数目为6的选项，选项中直角数目依次为2，6，2，5。
故正确答案为B。
