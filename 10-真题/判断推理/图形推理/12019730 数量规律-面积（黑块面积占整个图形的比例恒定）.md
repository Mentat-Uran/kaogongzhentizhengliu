# 数量规律-面积（黑块面积占整个图形的比例恒定）

考点：[[20-考点/判断推理/图形推理/数量规律-面积（黑块面积占整个图形的比例恒定）|图形推理 / 数量规律-面积（黑块面积占整个图形的比例恒定）]]


**问法模型**：两组式图形（3+3）问'？'处规律 → 元素组成不同且属性无规律时，对每幅图的可量化特征（本题：黑块面积占比）分组找恒定规律

## 推理链
1. 第1步：第一组三幅图形均为正方形被分割成8个等积三角形，每幅图中黑块均占据其中2份（如第1幅左上、右侧各一块黑三角）
2. 第2步：第二组前两幅均为正六边形被过中心的线分割成6个等积三角形，黑块各占其中2份
3. 第3步：题干元素组成不同、对称性等属性规律不明显，且黑白色块分布均匀，故将规律量化为'黑块面积/整个图形面积'
4. 第4步：第一组黑块面积占比=2/8=1/4，三幅图恒定；第二组前两幅黑块面积占比=2/6=1/3，亦恒定
5. 第5步：依两组各自恒定的规律，？处图形黑块面积应占整个图形的1/3（即6份中占2份）
6. 第6步：逐项核算选项黑块面积：A、D黑块占比不等于1/3，C项黑块明显超过一半（约1/2），均排除
7. 第7步：只有B项黑块占2/6=1/3，与第二组规律一致，故选B

**最快解法**：⚡ 面积占比法+排除法：直接数黑块占等分总份数——第一组黑块恒占2/8=1/4，第二组黑块恒占2/6=1/3，问号处找'6等分中黑块占2份'的图形，排除A、C、D，秒选B

## 易错点
- ⚠ 误数'黑块个数'而非'黑块面积'：本题以面积占比为规律，若数个数会因黑块形状大小差异而找不到规律
- ⚠ 试图在两组之间找统一的位置规律（如黑块旋转/移动），实际两组仅'面积占比各自恒定'，黑块位置并不构成规律
- ⚠ 对C项这类黑块面积明显过半的强干扰项警惕不足，需按1/3的占比精确对比排除

## 母题抽象
> 🧩 当题干图形均由黑白色块填充且色块分布均匀、元素组成不同又无明显属性/位置规律时，优先考虑某色块面积占整个图形的比例是否恒定（等分图形可直接'数黑块占的份数/总份数'）

**同类特征**：两组式出题（3+3）、黑块与白块填充、色块分布均匀、元素组成不同、无明显属性规律、图形被等分为三角形可数份数
