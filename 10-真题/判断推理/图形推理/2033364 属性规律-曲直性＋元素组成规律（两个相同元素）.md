# 属性规律-曲直性＋元素组成规律（两个相同元素）

考点：[[20-考点/判断推理/图形推理/属性规律-曲直性＋元素组成规律（两个相同元素）|图形推理 / 属性规律-曲直性＋元素组成规律（两个相同元素）]]


**问法模型**：题干图形元素组成不同且选项存在曲直之分 → 先用曲直性属性排除，再用'两个相同元素'的数量规律验证

## 推理链
1. 第1步：数元素——图1为两个相同的四角星、图2为两个三角形、图3为两个六边形、图4为两个长方形，每幅图均由'两个相同的元素'组成
2. 第2步：查属性——题干四幅图全部只由直线构成（纯直线图形），对称性、封闭性均无明显规律，锁定曲直性规律
3. 第3步：排除法对照选项——A项含圆（曲线）、C项含圆弧、D项含曲线，均与题干'纯直线'特征不符，排除
4. 第4步：验证双重规律——B项完全由直线构成，且由两个相同的三角形（各带一条穿过的线段）组成，同时满足'曲直性'与'两个相同元素'两条规律，故选B

**最快解法**：⚡ 曲直性排除法：一眼看题干四图全为直线图形，直接排除含曲线的A、C、D，锁定B；再用'每幅图=两个相同元素'二次验证B为两个三角形

## 易错点
- ⚠ 只数部分数或笔画数，未先检验曲直性，在含曲线选项中纠结
- ⚠ 把B项中穿过三角形的线段误当'第三个元素'，怀疑其不符合'两个相同元素'规律
- ⚠ 先试对称性、封闭性无果后未及时切换到曲直性，漏掉属性规律这一优先考察方向

## 母题抽象
> 🧩 当题干图形元素组成不同、且选项明显曲直混杂时，先用曲直性排除含曲线选项，再用'每幅图由两个相同元素组成'的元素构成规律验证唯一答案

**同类特征**：元素组成不同、每幅图由两个相同的元素组成、题干全部为直线图形、对称性、封闭性无规律、选项曲直混杂

### 题干
从所给的四个选项中，选择最合适的一个填入问号处，使之呈现出一定的规律性：

### 选项
- A. A
- B. B　✅
- C. C
- D. D

### 官方解析
元素组成不同，考虑属性规律和数量规律。
解法一：属性规律分为对称性、曲直性、封闭性，对称、封闭无明显规律，题干所有的图形都是直线图形，而选项A、C、D项含有曲线，故根据曲直性选择B选项。
解法二：考虑数量规律。观察发现，每幅图形都是由两个相同的元素组成，第一幅图是两个四角形，第二幅图是两个三角形，第三幅图是两个六边形，第四幅图是两个长方形，？是也应是由两个相同的元素组成，即B选项，由两个带有直线的三角形组成。
故正确答案为B。
