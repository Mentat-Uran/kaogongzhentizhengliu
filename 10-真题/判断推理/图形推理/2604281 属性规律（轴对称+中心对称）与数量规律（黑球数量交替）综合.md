# 属性规律（轴对称+中心对称）与数量规律（黑球数量交替）综合

考点：[[20-考点/判断推理/图形推理/属性规律（轴对称+中心对称）与数量规律（黑球数量交替）综合|图形推理 / 属性规律（轴对称+中心对称）与数量规律（黑球数量交替）综合]]


**问法模型**：一组黑白球阵列图形按序排列求'？'处图形 → 元素组成不同，先验对称属性排除，再数特征色球数量找交替规律定位答案

## 推理链
1. 第1步：提取题干图形信息——四图均为3×3圆圈阵列，图1黑球在中列上下共2个，图2黑球沿副对角线共3个，图3黑球沿主对角线共2个，图4黑球在中列共3个
2. 第2步：元素组成不同，优先属性规律——逐图验证对称性：四图黑球均落在中列或对角线上，既是轴对称又是中心对称图形
3. 第3步：用对称属性筛选项——B项黑球同在左列（仅轴对称、非中心对称），排除；A、C、D均为双对称图形，需进一步区分
4. 第4步：转向数量规律——题干黑球数依次为2、3、2、3，呈交替规律，故？处应为2个黑球
5. 第5步：逐项数黑球——A项2个（副对角线）、B项2个（左列，已排除）、C项3个（主对角线）、D项3个，仅A项双对称且黑球数为2，当选

**最快解法**：⚡ 属性+数量双重排除法：先用'既轴对称又中心对称'秒杀排除B项，再数黑球数2、3、2、3交替，？处选2个黑球，直接锁定A

## 易错点
- ⚠ 只数黑球数量不验对称性会误选B（B也是2个黑球，但仅轴对称、不是中心对称）
- ⚠ 只看对称性不数黑球会在C、D（同样双对称）中无法取舍
- ⚠ 把灰色球误当白球统计，或忽略2、3交替规律而错选3个黑球的C/D

## 母题抽象
> 🧩 当题干出现'黑白球网格阵列、元素组成不同'时，先用对称性（轴+中心）过滤选项，再数特征色球个数找交替/递增规律，两道筛子依次过，剩下的即为答案

**同类特征**：3×3黑白球圆圈阵列、元素组成不同、黑白球交替构成、黑球数2、3、2、3交替、黑球位置在中列/对角线轮换、问号处求下一幅图

### 题干
下列选项中最符合所给图形规律的是（    ）。

### 选项
- A. A　✅
- B. B
- C. C
- D. D

### 官方解析
元素组成不同，优先考虑属性规律。观察发现，题干图形均为既轴对称又中心对称图形，排除B项；进一步观察发现，题干图形均由黑球和白球构成，考虑数量规律，题干黑球数量分别为2、3、2、3，故？处应选择黑球数量为2的图形，只有A项符合，当选。
故正确答案为A。
