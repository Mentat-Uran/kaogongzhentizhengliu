# 属性规律-对称性（轴对称）

考点：[[20-考点/判断推理/图形推理/属性规律-对称性（轴对称）|图形推理 / 属性规律-对称性（轴对称）]]


**问法模型**：两套图形类比型问法且元素组成不同不相似 → 优先考虑属性规律（对称性），验证两组属性一致后在选项中找唯一满足者

## 推理链
1. 第1步：第一组为笑脸、绶带（标语框）、太阳三个生活化粗线条图形，元素组成不相同不相似，排除数量/位置规律，优先考虑属性规律
2. 第2步：检验对称属性——第一组三个图形沿中线对折均可重合：笑脸竖直对称，绶带竖直对称，太阳呈多向轴对称，故第一组规律为'轴对称图形'
3. 第3步：验证第二组前两幅是否满足同一规律：心形沿竖直中线对折重合（竖直对称轴），飞机沿机身中线对折重合（水平对称轴），均为轴对称图形，规律成立
4. 第4步：归纳规律：两套图形最大相似性在于'均为轴对称图形'，问号处也应为轴对称图形
5. 第5步：逐项对照——A苹果顶部有叶柄且右侧有缺口，非轴对称；B梅花沿竖直中线对折左右重合，是轴对称图形；C手掌五指长短位置不对称，非轴对称；D窗口旗帜呈透视变形，非轴对称
6. 第6步：仅B满足轴对称规律，得出结论选B

**最快解法**：⚡ 属性规律口诀法：'生活化、粗线条图形→优先查对称'。直接对四个选项做'对折测试'：A有缺口叶柄、C五指参差、D透视变形均不能对折重合，只有B梅花可沿竖直轴对折重合，秒选B

## 易错点
- ⚠ 误选C：手掌看似规整，但五指长短、位置不对称，不能想当然当作对称图形
- ⚠ 误选A：苹果主体近似圆形产生对称错觉，忽略顶部叶柄和右侧缺口破坏了对称性
- ⚠ 先入为主去数面、线、点等数量规律：本题元素为生活化粗线条图形，无从数起，应先按'不同不相似→属性规律'的提示走
- ⚠ 对飞机图形只看机头朝向而误判不对称，应看整体轮廓是否可沿对称轴对折重合

## 母题抽象
> 🧩 当两套图形元素组成不同不相似、且出现生活化/粗线条图形时，优先用属性规律（对称性）求解：先验证第一组属性，再验证第二组是否一致，最后在选项中找唯一满足该属性的图形

**同类特征**：两套图形类比型、元素组成不同不相似、生活化粗线条图形、轴对称（对折重合）、属性规律优先、问号处延续两组共同规律

从四个选项中选择一个替代问号，使两套图形的规律表现出最大的相似性，最适合的是（    ）。

### 选项
- A. A
- B. B　✅
- C. C
- D. D

### 官方解析
元素组成不相同不相似，而且题目中出现了生活化、粗线条图形，优先考虑属性规律。观察发现第一组图中的图形均为轴对称图形，第二组图中前两幅图也为轴对称图形，故“？”处也应为轴对称图形，只有B项符合。
故正确答案为B。
