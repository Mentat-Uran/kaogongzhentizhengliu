# 样式规律-黑白运算（黑白叠加）

考点：[[20-考点/判断推理/图形推理/样式规律-黑白运算（黑白叠加）|图形推理 / 样式规律-黑白运算（黑白叠加）]]


**问法模型**：九宫格'填入问号处使之呈现一定规律性'且每格均由黑球白球构成 → 元素组成相似，走样式类黑白运算模型：横向归纳叠加规则→下一行验证→末行应用

## 推理链
1. 第1步：九宫格中每幅图均由黑球、白球两种元素构成，轮廓与布局相似，符合'元素组成相似'的特征，优先考虑样式规律而非位置移动或数量规律。
2. 第2步：九宫格优先横向看，把第一行图1与图2在同一位置上的球色两两叠加，归纳出运算规则：黑+白=白，白+白=黑，白+黑=白，黑+黑=空（同色黑球叠加消去）。
3. 第3步：将此规则逐位置代入第二行验证：图1行与图2行按规则运算后得到的图形与第二行第3格完全一致，确认黑白运算规则成立。
4. 第4步：第三行应用同一规则，对前两格逐位置运算：黑+白处得白球、白+白处得黑球、黑+黑处消去变为空位，推出问号处黑球与白球的完整分布。
5. 第5步：将运算结果与A、B、C、D逐项对照：A、C、D在'黑+黑=空'应消去的位置或'白+白=黑'应出黑球的位置与运算结果不符，予以排除。
6. 第6步：只有B项的黑白分布与第三行逐位置运算结果完全吻合，故问号处选B。

**最快解法**：⚡ 黑白运算法+特征位置排除：先由第一行归纳规则'黑+白=白、白+白=黑、白+黑=白、黑+黑=空'，第二行验证后，第三行不必全图运算，只抓2~3个特征位（如'黑+黑=空'的消去位、'白+白=黑'的新增黑球位）即可快速锁定B。

## 易错点
- ⚠ 见黑白球便去找平移、旋转的位置规律，忽视'元素组成相似'对样式规律（黑白运算）的提示，浪费时间追小球轨迹。
- ⚠ 运算规则记反或漏记，如把'白+白=黑'错记为'白+白=白'，或忽略'黑+黑=空'的消去规则，导致运算结果与四个选项均对不上。
- ⚠ 对照选项时忽略空位（消去）区域，把仅差一个黑球位置或多出黑球的近似选项误选。

## 母题抽象
> 🧩 当题干出现'九宫格或两组图、每幅图均由黑白球（黑白块）构成且元素组成相似'的特征时，用横向黑白运算：先归纳四种叠加规则（尤其注意同色叠加可能消去/变空），用第二行或第二组验证后再逐位置运算并对照选项。

**同类特征**：九宫格优先横向看、每格均由黑球和白球构成、元素组成相似、黑白球逐位置叠加、黑+黑=空（同色消去）、问号在第三行第三格

### 题干
从所给的四个选项中，选择最合适的一项填入问号处，使之呈现一定的规律性：

### 选项
- A. A
- B. B　✅
- C. C
- D. D

### 官方解析
图形元素组成相似，优先考虑样式规律。观察发现，题干图形均由黑球和白球构成，考虑黑白运算。九宫格优先横向看，第一行图形的黑白运算规律为：黑+白=白，白+白=黑，白+黑=白，黑+黑=空，第二行图形经验证符合此规律，第三行图形应用此规律，只有B项符合。
故正确答案为B。
