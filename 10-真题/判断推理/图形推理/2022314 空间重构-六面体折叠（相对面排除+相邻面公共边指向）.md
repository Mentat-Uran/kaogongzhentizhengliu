# 空间重构-六面体折叠（相对面排除+相邻面公共边指向）

考点：[[20-考点/判断推理/图形推理/空间重构-六面体折叠（相对面排除+相邻面公共边指向）|图形推理 / 空间重构-六面体折叠（相对面排除+相邻面公共边指向）]]


**问法模型**：给出纸盒外表面展开图问'哪一项能由它折叠而成' → 先用'隔一面为相对面'排除含相对面的选项，再用公共边/图案长边指向验证相邻面位置

## 推理链
1. 第1步：展开图共6个面——横行依次为空白面、三角形面、空白面、梯形面，三角形面上方为条纹心形面、下方为菱形面
2. 第2步：应用展开图相对面规律：同行/同列隔一个面的两面对相对，故三角形面与梯形面相对、两个空白面相对、心形面与菱形面相对
3. 第3步：逐项排除——A项同时出现三角形面与梯形面（相对面不能同时出现），排除；D项同时出现心形面与菱形面（相对面），排除
4. 第4步：C项中梯形面与菱形面相邻，但展开图中梯形面的长边公共边贴着空白面，C项长边却对着菱形面，相邻位置错误，排除
5. 第5步：B项为心形面、梯形面与空白面相邻，三面两两为相邻面且公共边指向与展开图一致，三面相对位置正确，当选

**最快解法**：⚡ 相对面排除法+公共边法：先按'隔一相对'秒杀排除A（三角+梯形）和D（心+菱形），再用'梯形面长边贴空白面'这一公共边特征排除C，直接锁定B

## 易错点
- ⚠ 忽略展开图'同行/同列隔一面即为相对面'，未看出心形与菱形、三角形与梯形互为相对面
- ⚠ 只检查图案是否相邻、不核对公共边指向（梯形长边应贴空白面），易误选C
- ⚠ 将梯形（五边形）面的长边与短边朝向看反，导致折叠后相邻位置判断出错

## 母题抽象
> 🧩 当题干为带特征图案的六面体展开图时，先用'隔一面相对'排除含相对面的选项，再用特征图案的公共边（如长边、尖角指向）验证剩余选项的相邻位置

**同类特征**：纸盒外表面展开图、相对面不能同时出现、心形/三角形/菱形/梯形特征图案面、空白面、梯形长边公共边指向、相邻面位置验证

### 题干
左边给定的是纸盒的外表面，下面哪一项能由它折叠而成：

### 选项
- A. A
- B. B　✅
- C. C
- D. D

### 官方解析
A选项：梯形面和三角形面是相对面，相对面不能同时出现，与题干不一致，排除；
B选项：三面相对位置正确，当选；
C选项：梯形面的长边应该对应空白面，而不是菱形面，与题干不一致，排除；
D选项：心形面和菱形面是相对面，相对面不能同时出现，与题干不一致，排除。
故正确答案为B。
