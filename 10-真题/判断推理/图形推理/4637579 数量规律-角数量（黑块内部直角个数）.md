# 数量规律-角数量（黑块内部直角个数）

考点：[[20-考点/判断推理/图形推理/数量规律-角数量（黑块内部直角个数）|图形推理 / 数量规律-角数量（黑块内部直角个数）]]


**问法模型**：两组式（3+3）图形推理问'？'处规律 → 先在第一组归纳数量规律（直角个数递增），再将同一规律迁移到第二组选出对应图形

## 推理链
1. 第1步：题干均为不规则黑块，元素组成不同，对称性、曲直性、开闭性等属性规律不明显，按'属性不成先数数'转向数量规律
2. 第2步：黑块轮廓出现多处明显的90°方角，优先考虑数'黑块内部的直角个数'而非点、线、面
3. 第3步：第一组依次清点：图1黑块内部直角1个，图2为2个，图3为3个，构成1、2、3的等差递增规律
4. 第4步：将规律迁移至第二组：图1黑块内部直角1个，图2为2个，故'？'处应选黑块内部直角为3个的图形
5. 第5步：逐项对照：A项（L形）、C项（M形）、D项（箭头形）黑块内部直角个数均不是3，B项黑块内部恰含3个直角
6. 第6步：只有B项满足'直角个数为3'的延续规律，故选B

**最快解法**：⚡ 直角计数法：题干黑块多处呈方角即为'数直角'的信号，快速逐图数黑块内部90°角：第一组1、2、3，第二组1、2、？，直接锁定问号为3个直角，对照选项秒选B（注意B左上为斜边，但下方折角处仍含3个直角）

## 易错点
- ⚠ 漏数/错数直角：把凹角（270°）误当直角，或忽略被斜边切割后剩余的直角，导致第一组'1、2、3'规律找不出来
- ⚠ 忽略'黑块内部'这一限定，把外框线或黑块外部区域的角计入统计
- ⚠ 先入为主去数交点、面、边数量，忽视题干中'明显直角'这一优先提示信号；另注意B项因左上斜边易被误判为'无直角'而错排除

## 母题抽象
> 🧩 当图形元素组成不同、无对称/曲直等属性规律，且图中出现明显直角（方角）特征时，优先数'直角个数'构造递增/常数规律，再按同规律在选项中验证数量对应

**同类特征**：两组式（3+3）图形推理、不规则黑色块（阴影图形）、元素组成不同且无属性规律、黑块轮廓多处呈明显直角、数量规律考'角'而非点线面、问号处需延续等差数量规律

### 题干
从所给的四个选项中，选择最合适的一个填入问号处，使之呈现一定的规律性：

### 选项
- A. A
- B. B　✅
- C. C
- D. D

### 官方解析
元素组成不同，且无明显属性规律，考虑数量规律。题干所给的黑块图形出现多个明显的直角，优先考虑直角数。第一组图形中，黑块图形内部的直角个数依次为1、2、3。第二组图形运用规律，图1、图2黑块图形内部的直角个数分别为1、2，故“？”处应选择黑块图形内部直角个数为3的图形，只有B项符合。
故正确答案为B。
