# 图形推理-样式规律（叠加求同-保留相同部分）

考点：[[20-考点/判断推理/图形推理/图形推理-样式规律（叠加求同-保留相同部分）|图形推理 / 图形推理-样式规律（叠加求同/保留相同部分）]]


**问法模型**：'符合所给图形变化规律'的两组图类比问法 → 先判断元素组成相似确定样式规律，从第一组归纳图1与图2的叠加运算规则，再套用到第二组求问号处图形

## 推理链
1. 第1步：题干为两组图，第一组依次为菱形、向右的人字形（箭头状）轮廓、右侧带缺口的图形；第二组为四角星、四个三角形拼成的十字形和问号
2. 第2步：两组图元素组成相似，优先考虑样式规律；观察第一组，图1（菱形）与图2（人字形）叠加后仅保留重合部分得到图3，即'图1∩图2=图3'的求同规律
3. 第3步：将该规律应用到第二组：四角星的四个尖角与十字形的四个三角形在上下左右四个方向各重合出一小块菱形区域，问号处应为四个方向各保留一个菱形的图形
4. 第4步：逐项对照：A项是两图全部线条叠加（并集），保留过多；B项图形整体缩小变形，与相交区域不符；D项是去掉相同、保留两图未重合的外围部分（去同存异）；C项四个菱形恰好为两图重合部分，符合求同规律

**最快解法**：⚡ 样式求同法：先用第一组验证'图1与图2叠加保留相同部分=图3'，再观察第二组两图上下左右四个方向的重合区域均为小菱形，直接锁定由四个菱形构成的C项，排除代表叠加（A）和去同存异（D）的干扰项

## 易错点
- ⚠ 把'叠加'误解为两图简单合并（求并），误选A项
- ⚠ 把规律反向理解成去同存异，误选D项
- ⚠ 忽略重合部分应是两图轮廓相交的区域，误以为整体缩放而错选B项

## 母题抽象
> 🧩 当两组图元素组成相似、且第一组第三图明显是前两图的公共部分时，用'叠加求同（保留相同部分）'规律套用到第二组，验证选项是否等于两图的相交区域

**同类特征**：两组图类比型问法、元素组成相似、第一组图3为前两图重合部分、四角星与三角形十字叠加、样式类求同运算、轮廓线相交保留

### 题干
下列选项中，符合所给图形变化规律的是：

### 选项
- A. A
- B. B
- C. C　✅
- D. D

### 官方解析
元素组成相似，优先考虑样式规律。观察第一组图形发现，图1与图2叠加后保留相同部分得到图3，第二组图形应用此规律，故？处图形应为图1与图2叠加后保留相同部分得到，只有C项符合。

故正确答案为C。
