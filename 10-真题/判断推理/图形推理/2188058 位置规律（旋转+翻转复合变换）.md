# 位置规律（旋转+翻转复合变换）

考点：[[20-考点/判断推理/图形推理/位置规律（旋转+翻转复合变换）|图形推理 / 位置规律（旋转+翻转复合变换）]]


**问法模型**：九宫格问号处填图 → 元素组成相同时优先考虑位置规律，横行找规律、验证后再应用到第三行

## 推理链
1. 第1步：九宫格每行均为同一手势图形，仅朝向变化，元素组成相同，优先考虑位置规律，且九宫格优先看横行
2. 第2步：第一行提取规律——图1（拇指向上）经旋转得到图2（拇指向下），图2再经上下翻转得到图3（拇指向上、与图1呈左右镜像）
3. 第3步：第二行验证——图1（V字手势向上）旋转得到图2（手指朝下），图2上下翻转得到图3（V字手势与图1左右镜像），规律成立
4. 第4步：第三行应用——图2由图1旋转得到，故？处图形应由图2（OK手势）上下翻转得到
5. 第5步：对照选项——第三行图2上下翻转后手势朝向与A项一致，B、C、D项方向均不符

**最快解法**：⚡ 位置规律口诀'横行找规律'+两步变换法：第一行确定'旋转→上下翻转'，第三行直接对图2做上下翻转，比对选项秒选A

## 易错点
- ⚠ 把图1到图2误判为'上下翻转'（拇指朝上翻朝下看似也成立），导致图2到图3误用旋转，变换次序弄反
- ⚠ 上下翻转与左右翻转混淆：上下翻转后图形同时呈现左右镜像效果，误选仅做了左右翻转或旋转的B/C/D项
- ⚠ 忽略OK手势细节（圈孔位置、手指朝向），只看大致轮廓导致排除出错

## 母题抽象
> 🧩 当九宫格每行元素组成相同、仅方向/朝向改变时，用'横行定规律（旋转+翻转）、次行验证、末行应用'模型，对待求图形执行已验证的变换后比对选项

**同类特征**：九宫格、元素组成相同（同一手势）、仅朝向/方向变化、横行规律、旋转与上下翻转复合、第三行应用规律求问号处

### 题干
请从所给四个选项中选择一个最合适的选项填入问号处，使之呈现一定规律性：

### 选项
- A. A　✅
- B. B
- C. C
- D. D

### 官方解析
元素组成相同，优先考虑位置规律。九宫格优先看横行，第一行图1旋转得到图2，图2上下翻转得到图3。第二行验证规律，图1旋转得到图2，图2上下翻转得到图3，规律成立。则第三行应用此规律，图2由图1旋转得到，故？处图形由图2上下翻转得到，只有A项符合。
故正确答案为A。
