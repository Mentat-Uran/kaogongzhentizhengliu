# 图形推理-数量规律（总点数计数：顶点+内部交点，行等差递增）

考点：[[20-考点/判断推理/图形推理/图形推理-数量规律（总点数计数：顶点+内部交点，行等差递增）|图形推理 / 图形推理-数量规律（总点数计数：顶点+内部交点，行等差递增）]]


**问法模型**：九宫格问'填入问号处使之呈现规律性'→ 按行/列统计图形数量特征（总点数），找等差规律，再用共性形状特征做二次排除

## 推理链
1. 第1步：九宫格各图外观差异大、线面规律不明显，转向数量类计数——统计每幅图形的总点数（外框顶点+内部交点，如第1图弓蝶形4个外角+1个中心交点=5）
2. 第2步：逐行验证等差规律：第一横行总点数为5、6、7，第二横行为7、8、9，均构成公差为1的等差数列
3. 第3步：按行间规律外推，第三横行应为9、10、11，故问号处图形总点数须为11，据此排除C、D
4. 第4步：观察剩余项的形状共性：题干八幅图内部均含有三角形，选项B（心形内仅一条折线）内部无三角形，排除B
5. 第5步：A项点数为11且内部含三角形（方形+内菱形与横竖线构成多个三角形），完全满足数量与形状双重规律，选A

**最快解法**：⚡ 点数计数法+共性排除：先数每图'顶点+内部交点'总点数，确认行内5-6-7、7-8-9、9-10-11等差，锁定问号处须为11点排除C、D；再看'内部均含三角形'这一共性排除B，快速锁定A

## 易错点
- ⚠ 只数外框顶点、漏数内部交叉点，导致5-6-7/7-8-9的点数等差规律看不出来
- ⚠ 先入为主找对称、面数、线数等常见规律，绕远路后忽略'总点数量化'这一数量类考点
- ⚠ 用点数排除C、D后忘记做形状共性二次验证，误选内部无三角形的B项

## 母题抽象
> 🧩 当九宫格图形外形差异大、对称/面/线规律均不通时，先数'总点数（外框顶点+内部交点）'按行验证等差；数量规律排除后，再用题干图形的共同形状特征（如内部均含某元素）做二次筛选

**同类特征**：九宫格3×3求问号处、各行总点数成公差1的等差（5,6,7 / 7,8,9 / 9,10,11）、每幅图内部均含三角形、图形外观差异大、需数量化计数、需点数+形状特征双重验证

### 题干
从所给四个选项中，选择最合适的一个填入问号处，使之呈现一定的规律性：

### 选项
- A. A　✅
- B. B
- C. C
- D. D

### 官方解析
考查图形的总点数，第一横行总点数为：5、6、7，第二横行总点数为：7、8、9，第三横行总点数为9、10、11，因此排除C、D两项，而且所有图形内部都有三角形，排除B项，选择A项。
故正确答案为A。
