# 图形推理-平面拼合（纸片一面黑一面白，翻面黑白互换）

考点：[[20-考点/判断推理/图形推理/图形推理-平面拼合（纸片一面黑一面白，翻面黑白互换）|图形推理 / 图形推理-平面拼合（纸片一面黑一面白，翻面黑白互换）]]


**问法模型**：题干给出四张'一面黑一面白'的纸片，允许平移、旋转、翻转拼合，问哪一项能拼成 → 平面拼合＋翻面变色模型：先标注各片显示面颜色，牢记只有'翻转'才使黑白互换，再逐项同时核对'形状可拼＋颜色自洽'双重标准

## 推理链
1. 第1步：从题干提取前提：四张纸片中图①显示面为白色，图②③④显示面为黑色；规则'每张纸片一面是黑色，另一面是白色'意味着任一片一经翻转，颜色必黑白互换（白变黑、黑变白）。
2. 第2步：确定方法：拼合仅允许平移、旋转、翻转三种操作且形状不变；平移、旋转不改变颜色，翻面改变颜色，故每个选项须逐块核对'形状与题干纸片吻合＋黑白颜色与是否翻面自洽'。
3. 第3步：A项：按官方拼合方式图，四片经适当的平移、旋转、翻转可拼出A项图形，且各块的黑白分布与翻面变色规则自洽，当选。
4. 第4步：B项：右上角两个三角形由图②和图③'旋转后平移'而去（未翻面），应保持题干显示的黑色，而选项中却是白色，颜色矛盾，排除。
5. 第5步：C项：右上角的三角形是图②，颜色无误，但其下方的白块形状与题干四张纸片均不相同，形状无法匹配，排除。
6. 第6步：D项：右上角的三角形同样是图②、颜色无误，但其下方的白块同样无法由题干图形拼合而成，排除；仅A项形状与颜色双匹配，故正确答案为A。

**最快解法**：⚡ 颜色排除法＋形状核对：先用'翻面才变色'查颜色——B项中由图②③（原黑色面）仅旋转平移而来的三角形竟呈白色，颜色矛盾秒排；再核形状——C、D项中三角下方的白块形状与题干四片均对不上，排除；A项形状、颜色双匹配，选A。

## 易错点
- ⚠ 忽略'一面黑一面白'设定，误以为翻转不改变颜色，把图②③④随意当白色使用（B项正是此坑）
- ⚠ 只核形状不核颜色、或只核颜色不核形状，漏掉B项颜色矛盾与C/D项形状不符这两类不同性质的错误
- ⚠ 误以为平移或旋转也会改变颜色，忘记只有'翻转'才导致黑白互换

## 母题抽象
> 🧩 当题干出现'若干一面黑一面白的纸片，可平移、旋转、翻转拼合'时，用'翻面必变色＋形状颜色双核对'方法，先排颜色矛盾项，再排形状不符项，锁定唯一自洽选项。

**同类特征**：每张纸片一面黑色另一面白色、可平移、旋转、翻转、平面拼合为一个整体图形、翻面后黑白颜色互换、选项需形状与颜色双重匹配、四选一拼合题

### 题干
上边四张纸片，每张纸片一面是黑色，另一面是白色，下边仅有一项能由它们拼合（可以平移、旋转、翻转）而成，请把它找出来。

### 选项
- A. A　✅
- B. B
- C. C
- D. D

### 官方解析
本题考查平面拼合，可以平移、旋转、翻转，且每张纸片一面是黑色，另一面是白色，需要考虑翻转后的颜色变化。将题干图形标上序号，如下图所示，逐一进行分析。

A项：可以由题干图形拼合而成，拼合方式如图所示，当选；
B项：右上角的两个三角形是由图②和图③旋转后平移过去的，颜色都应该是黑色，而选项是白色，排除；
C项：右上角的三角形是图②，颜色无误，但其下方的白块与题干图形的形状均不相同，无法由题干图形拼合而成，排除；
D项：右上角的三角形是图②，颜色无误，但其下方的白块无法由题干图形拼合而成，排除。
故正确答案为A。
