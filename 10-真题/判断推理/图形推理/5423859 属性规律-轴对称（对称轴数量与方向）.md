# 属性规律-轴对称（对称轴数量与方向）

考点：[[20-考点/判断推理/图形推理/属性规律-轴对称（对称轴数量与方向）|图形推理 / 属性规律-轴对称（对称轴数量与方向）]]


**问法模型**：“符合所给图形的规律”→ 元素组成不同时走属性规律，规整方格图优先检验对称轴条数与方向并逐项排除

## 推理链
1. 第1步：题干三幅图均为4×4方格中分布黑点、白圈、灰圈，元素组成不同，且整体排布规整
2. 第2步：依“元素组成不同优先属性规律、图形规整优先看对称性”的口诀，检验每幅图的轴对称特征
3. 第3步：观察题干三图，每幅图关于同一条对角线折叠后黑/白/灰圆点位置完全重合，即均为轴对称图形且只存在1条对称轴
4. 第4步：进一步核对称轴方向，题干三图的对称轴均沿“左下-右上”对角线方向
5. 第5步：对照选项，A、C不满足“仅1条对称轴”的要求，排除
6. 第6步：B虽为轴对称，但对称轴方向与题干“左下-右上”不符，排除；D仅1条对称轴且方向同为“左下-右上”，与题干规律一致，故选D

**最快解法**：⚡ 对称性排除法：先数对称轴条数（仅1条→排除A、C），再核对称轴方向（左下-右上→排除B），一步锁定D

## 易错点
- ⚠ 只验证是否轴对称或对称轴条数，忽略对称轴方向这一二级标准，易误选B
- ⚠ 元素组成不同时误入数量规律（数黑点/白圈/灰圈个数或位置移动），越走越乱
- ⚠ 混淆两条对角线方向：“左下-右上”（/向）与“左上-右下”（\向）看反
