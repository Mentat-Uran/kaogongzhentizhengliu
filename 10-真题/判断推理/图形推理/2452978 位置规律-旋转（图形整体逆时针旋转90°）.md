# 位置规律-旋转（图形整体逆时针旋转90°）

考点：[[20-考点/判断推理/图形推理/位置规律-旋转（图形整体逆时针旋转90°）|图形推理 / 位置规律-旋转（图形整体逆时针旋转90°）]]


**问法模型**：问'符合所给图形的变化规律的是'且各图元素组成相同→套用位置规律（旋转）模型：先对比相邻两图确定旋转方向与角度，再以前图旋转推出问号处图形并用末图验证

## 推理链
1. 第1步：题干为'图1、图2、？、图4'的序列，每幅图都是同一正方形，内部被对角线与横竖中线分割成8个小三角形，其中若干个为阴影，元素组成完全相同
2. 第2步：元素组成相同→优先考虑位置规律（旋转/翻转/平移），对比相邻图形找位置变化
3. 第3步：逐块对比图1与图2：阴影三角形的数量与形状不变、仅整体方位改变，图1整体逆时针旋转90°即得图2
4. 第4步：归纳规律'后一幅图=前一幅图整体逆时针旋转90°'，故问号处图形=图2整体逆时针旋转90°（等价于图1旋转180°）
5. 第5步：用序列末图二次验证：图4应等于问号处图形再逆时针旋转90°（即图2旋转180°），与图4的阴影位置吻合，规律成立
6. 第6步：将'图2逆时针旋转90°'所得图形与选项逐一比对阴影所在扇形位置：A、B、C的阴影位置均与旋转结果不符，仅D项完全一致，故选D

**最快解法**：⚡ 位置规律口诀'元素相同看位置'+旋转法：取图2整体逆时针旋转90°（阴影三角形随图形同步转动），直接与四个选项比对阴影位置秒选D；再用'图4=图2旋转180°'回头复核一次防方向搞反

## 易错点
- ⚠ 旋转方向搞反：把逆时针90°看成顺时针90°，误选与顺时针旋转结果一致的干扰项
- ⚠ 把轴对称翻转误当旋转：翻转后的阴影位置与旋转不同，需区分'转'与'翻'
- ⚠ 只对比图1→图2一步就下结论，不用图4二次验证，易被阴影数量相同但方位镜像的选项迷惑

## 母题抽象
> 🧩 当题干出现'各图元素组成相同、仅阴影或小元素的位置/方位改变'的图形序列时，用位置规律：先比较相邻两图确定旋转方向与角度，再以前一图旋转推出问号处图形，并用序列中其他已知图二次验证

**同类特征**：元素组成相同、阴影三角形位置改变、正方形八等分（米字形分割）、序列中间设'？'、整体旋转90°、位置规律

### 题干
下列选项中，符合所给图形的变化规律的是        。

### 选项
- A. A
- B. B
- C. C
- D. D　✅

### 官方解析
元素组成相同，优先考虑位置规律。从图一到图二，图形整体逆时针旋转90°，因此问号处图形应该是图二逆时针旋转90°所得，只有D项符合。
故正确答案为D。
