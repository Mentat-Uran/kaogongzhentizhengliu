# 立体图形-三视图（左视图一致）

考点：[[20-考点/判断推理/图形推理/立体图形-三视图（左视图一致）|图形推理 / 立体图形-三视图（左视图一致）]]


**问法模型**：问号处填入图形使呈现规律 → 立体小方块堆叠图优先考虑三视图规律，逐个找出题干各图共同且选项可对照的那个视图（本题锁定左视图）

## 推理链
1. 第1步：题干5个图形均由若干小正方体叠加而成，属于立体图形组，排除线条、面、点等平面规律，转入三视图（主视图/左视图/俯视图）角度找共性
2. 第2步：对题干5个图形逐一作左视图（从每图的左侧向右投影），发现5个图形的左视图轮廓完全相同，即'左视图均相同'为题干统一规律
3. 第3步：将A、B、C、D四个选项分别作左视图投影，与题干统一左视图对照
4. 第4步：A项为低层平铺结构，左视图轮廓与题干不同；B项、D项投影后的左视图也与题干左视图不一致
5. 第5步：只有C项的左视图与题干5图完全相同，符合'延续左视图一致'的规律，故选C

**最快解法**：⚡ 三视图定位法：先在题干内部横向比对，锁定'左视图全部相同'这一规律；再只看左视方向逐一排除选项——A、B、D左视图形状对不上，唯C吻合，直接选C

## 易错点
- ⚠ 混淆三视图观察方向：左视图是从立体图形的左侧向右投影，误用主视图（正面）或俯视图（顶部）对比会得出错误选项
- ⚠ 只数小正方体个数不看投影轮廓：部分选项方块数量与题干相近，数量一致不代表视图形状一致
- ⚠ 未先在题干内部归纳统一规律就急于对照选项，被各图正面形状差异干扰而忽略左视图这一共性

## 母题抽象
> 🧩 当题干出现多个小正方体堆叠的立体图形时，用三视图法：先逐图找出题干共同相同的那个视图（主/左/俯之一），再到选项中匹配该视图完全一致的图形

**同类特征**：小正方体叠加构成的立体图形、五图连续呈现+问号求规律、立体图形优先想三视图、各立体图形状相近需辨析视图差异、选项同为方块堆叠立体图
