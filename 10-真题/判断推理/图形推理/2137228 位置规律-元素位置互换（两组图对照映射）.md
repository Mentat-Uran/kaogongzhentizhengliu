# 位置规律-元素位置互换（两组图对照映射）

考点：[[20-考点/判断推理/图形推理/位置规律-元素位置互换（两组图对照映射）|图形推理 / 位置规律-元素位置互换（两组图对照映射）]]


**问法模型**：题干给出图1与图2的对应关系，问图3对应哪个图形 → 先归纳第一组『谁与谁互换、谁不变』的位置规律，再原样映射到第二组筛选选项

## 推理链
1. 第1步：读取图1要素：正方形外框、内部梯形、左上'+'、右上'×'、左下三角形、右下圆
2. 第2步：读取图2要素：正方形外框、内部三角形、左上'×'、右上'+'、左下梯形、右下圆；对比可得规律：上下两符号互换、三角形与梯形（内部↔左下角）互换、圆位置不变、外框正方形不变
3. 第3步：读取图3要素：梯形外框、内部三角形、左上'*'、右上'#'、左下圆、右下小正方形，将其对应第一组中的位置角色
4. 第4步：按规律映射：内部三角形与左下圆互换→圆进内部、三角形到左下；'*'与'#'互换→'#'到左上、'*'到右上；右下小正方形位置不变；外框保持梯形
5. 第5步：逐项对照：A内部为小正方形且右下变为圆，排除；B外框为正方形且内部仍是三角形、符号未互换，排除；C外框为梯形、内部为圆、'#'左上'*'右上、三角形在左下、小正方形在右下，全部符合；D外框为正方形且左下三角形右下梯形，排除
6. 第6步：只有C同时满足互换规律与不变元素，故选C

**最快解法**：⚡ 排除法+位置互换口诀：先锁定不变项（第二组外框应为梯形、右下角小正方形不动），排除B、D；再看互换项（内部图形与左下角互换、'*''#'左右互换），排除A，锁定C

## 易错点
- ⚠ 只盯内部大图形互换，忽略四角小符号'*'与'#'也需左右互换（B项符号未换）
- ⚠ 误以为外框也要跟着变化，忽略了第一组规律中『外框保持不变』（B、D外框画成正方形）
- ⚠ 忽略『位置不变』的元素：图1→图2中圆不动、图3→答案中右下小正方形不动，A项内部画成小正方形即踩此坑

## 母题抽象
> 🧩 当两组图元素组成相同而位置不同时，先从第一组归纳『两两互换+某些元素不变+外框不变』的位置规律，再把该规律逐项映射到第二组并排除不符选项

**同类特征**：两组图对照式问法（图1↔图2，图3↔？）、元素组成基本相同，仅位置不同、外框+内部图形+四角小符号的三层结构、符号'+/×'与'*/#'成对出现、既有位置互换又有个别元素不变

### 题干
下列选项中，根据图1和图2的关系，与图3对应的图形是      。

### 选项
- A. A
- B. B
- C. C　✅

### 官方解析
元素组成基本相同，优先考虑位置规律。第一组图找规律，观察图1和图2，梯形和三角形的位置进行互换，×和+的位置进行互换，圆的位置不变，外框都是正方形；第二组图用规律，图3中三角形和圆的位置进行互换，#和*的位置进行互换，外框是梯形，所以对应选项C。
故正确答案为C。
