# 图形推理-平面拼合（挖空补块-嵌套拼合）

考点：[[20-考点/判断推理/图形推理/图形推理-平面拼合（挖空补块-嵌套拼合）|图形推理 / 图形推理-平面拼合（挖空补块/嵌套拼合）]]


**问法模型**：'最适合填入图形空缺处，使整幅图形呈现一致的规律性' → 采用平面拼合（补块）模型：将选项补块与空缺处的边界缺口及内部线条走向逐一对应，找能严丝合缝拼合的一块。

## 推理链
1. 第1步：题干是一幅正方形编织纹样图，中间挖去一个圆形空缺（内含'？'），四个选项均为圆形补块，需选出一块填入空缺。
2. 第2步：拼合规则——补块不仅要内部斜线条纹与周围平行编织线走向连贯，其边缘还必须与圆形空缺的弧形边界完全吻合。
3. 第3步：锁定关键验证点——原图中圆圈右上角存在一个弧形缺口，补块的对应位置必须能把这个弧形缺口填上。
4. 第4步：逐项对照——A、C、D 的右上角均无与该弧形缺口相对应的边缘结构，内部线条与圆弧的衔接方式也与之不符。
5. 第5步：只有 B 选项右上角有一个弧形缺口能与原图空缺处的弧形缺口相对应，拼合后边界吻合、线条连贯。
6. 第6步：故只有 B 能与原图拼成完整图形，答案为 B。

**最快解法**：⚡ 边缘缺口定位法（排除法）：只盯空缺圆右上角的弧形缺口这一处，扫一眼四个选项，仅 B 的右上角有对应弧形缺口，直接锁定，不必逐条核对全部内部线条。

## 易错点
- ⚠ 只比较选项内部斜线的分割方式、忽略补块边缘与圆形弧边缺口的对应关系，误选 A 或 D。
- ⚠ 四个选项高度相似（均为圆内斜线分割图形），若不做'缺口方位'这一二级辨析，容易凭大概轮廓误判。
- ⚠ 验证点找偏：去比对左下角或中线等非关键位置，而官方判据在右上角的弧形缺口，验证点选错则无从排除。

## 母题抽象
> 🧩 当题干出现'整幅图形挖去一块、选项为候选补块'的特征时，用边缘缺口对应法：先找空缺处最特殊的边界特征（角部缺口、弧线等），再验证哪个选项在该位置能与之严丝合缝。

**同类特征**：正方形编织纹样中间挖空一个圆形、问法为'填入空缺处使整幅图形呈现一致的规律性'、四个选项均为圆形补块且彼此高度相似、空缺圆右上角有弧形缺口、判据依赖补块边缘与空缺边界的吻合、答案唯一由边界缺口对应决定

### 题干
下列选项中最适合填入图形空缺处，使整幅图形呈现一致的规律性的是：

### 选项
- A. A
- B. B　✅
- C. C
- D. D

### 官方解析
本题考查平面拼合。正确选项应该与原图形拼成一个完整的图形。在原图当中，中间圆圈的右上角要想补进去一个图形，必须得把右上角的弧形缺口给填上，观察四个选项，只有B选项的右上角有一个弧形的缺口能与之相对应。

故正确答案为B。
