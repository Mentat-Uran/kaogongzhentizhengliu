# 位置规律（标号映射移动）＋颜色规律（内外分层看）

考点：[[20-考点/判断推理/图形推理/位置规律（标号映射移动）＋颜色规律（内外分层看）|图形推理 / 位置规律（标号映射移动）＋颜色规律（内外分层看）]]


**问法模型**：“符合所给图形变化规律”→元素组成基本相同优先位置规律；嵌套图形先内外分层，外圈找移动映射、内圈找颜色对应，两层规律组合对照选项

## 推理链
1. 第1步：题干各图均由外圈6个六边形和内圈1个六边形组成，外圈元素样式组成相同、仅位置变化，内圈只有颜色黑白不同→决定内外分开看
2. 第2步：外圈用位置规律，将6个外圈六边形依次标号1~6，图一→图二的移动映射为1→2、2→3、3→6、4→1、5→4、6→5（是固定映射换位，非整体旋转）
3. 第3步：用图二→图三、图三→图四验证同一映射成立，规律稳定，故？处外圈须按此映射排布→排除A、D
4. 第4步：内圈看颜色规律：两个“网格花纹”元素之间为斜向相对位置时内圈为白色（如图一），为横向相对位置时内圈为黑色（如图二、图三）
5. 第5步：？处按映射移动后两个网格元素呈斜向相对位置→内圈颜色应为白色
6. 第6步：对照选项，外圈符合映射且内圈为白色的只有C，故选C

**最快解法**：⚡ 标号追踪＋分层排除法：只盯两个“网格花纹”元素的相对位置，其按“斜对→横对→横对→斜对”变化，对应内圈“白→黑→黑→白”，？处网格斜对→内圈白，先排除A、B；再用外圈映射（1→2、2→3、3→6、4→1、5→4、6→5）核对C、D外圈排布，锁定C

## 易错点
- ⚠ 把外圈规律误判为整体旋转/翻转，因3→6、4→1的跳位映射不符合旋转而放弃位置规律
- ⚠ 内外圈混在一起找规律，漏掉“内外分开看”的分层思路
- ⚠ 内圈颜色误认作简单黑白交替，忽略其实由两个网格元素的相对位置（斜对/横对）决定

## 母题抽象
> 🧩 当题干出现“外圈若干相同元素＋内圈单一元素”的嵌套图形且元素组成基本相同时，用内外分层法：外圈给元素标号追踪移动映射，内圈找颜色/样式与外圈特定元素位置的对应关系，两层规律叠加筛选选项

**同类特征**：外圈6个六边形＋内圈1个六边形的嵌套结构、元素组成基本相同、内圈颜色黑白变化、外圈含网格花纹与条纹两类元素、四幅图加？求第五幅、位置规律优先

### 题干
下列选项中，符合所给图形变化规律的是（    ）。

### 选项
- A. A
- B. B
- C. C　✅
- D. D

### 官方解析
元素组成基本相同，优先考虑位置规律。题干图形均由外圈的6个六边形元素和内圈的1个六边形元素组成，且外圈元素组成相同，内圈元素颜色不同，考虑内外分开看。外圈考虑位置规律，给外圈的6个六边形元素的位置依次标为1、2、3、4、5、6，比较图一和图二发现，1号移动至2号位置、2号移动至3号位置、3号移动至6号位置、4号移动至1号位置、5号移动至4号位置、6号移动至5号位置。经验证，图二到图三、图三到图四均符合该规律，故图四到图五也应符合该规律，排除A、D两项；内圈考虑颜色变化，对比题干的内圈颜色后发现，当两个网格状元素（如图一的1和3）之间为斜向相对位置时内圈颜色为白色，当两个网格状元素之间为横向相对位置时内圈颜色为黑色，？处两个网格状元素之间为斜向相对位置，故？处内圈颜色应为白色，只有C项符合。

故正确答案为C。
