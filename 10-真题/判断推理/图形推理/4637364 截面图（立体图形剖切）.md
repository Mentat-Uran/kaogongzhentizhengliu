# 截面图（立体图形剖切）

考点：[[20-考点/判断推理/图形推理/截面图（立体图形剖切）|图形推理 / 截面图（立体图形剖切）]]


**问法模型**：题干问'从任一面剖开，哪项可能是该立体图形的截面'→采用截面图逐一验证模型：先拆分基本体回忆各自截面库，再结合缺口与组合位置逐项排除

## 推理链
1. 第1步：观察左图，立体图形由'带竖直缺口（槽）的圆柱体'（俯视呈C形）和与之相连的'长方体'组合而成
2. 第2步：调用截面规律：平面截圆柱只得圆/椭圆/矩形类图形，截长方体只得多边形；圆柱上的缺口和相连的长方体会破坏水平圆截面
3. 第3步：A项完整圆环需水平平切完整圆柱，但圆柱被槽切开且下连长方体，只能截出带缺口的C形，排除
4. 第4步：B项半圆需要球面或特殊组合才能截出，圆柱面无论怎么切只得圆/椭圆/矩形，且缺口与长方体干扰，排除
5. 第5步：C项L形可由一个竖直平面同时切过圆柱壁（得竖直细长矩形）和长方体（得横向矩形）拼合而成，可截出
6. 第6步：D项直角三角形不可能：平面截长方体得三角形必是切去一角，三条边落在两两垂直的面上，该三角形必为锐角三角形，排除

**最快解法**：⚡ 排除法+截面方向想象：A想'有槽圆柱平切只得C形缺环'，B想'圆柱无球面切不出半圆'，D想'长方体切角必得锐角三角形'，唯C用竖直面同时切圆柱壁与长方体即可拼出L形

## 易错点
- ⚠ 忽略圆柱上的竖直缺口，误以为水平切可得完整圆环而误选A
- ⚠ 误以为长方体切去一角可得直角三角形而误选D（实为锐角三角形）
- ⚠ 混淆'截面'与'轮廓/投影'，半圆不能由圆柱直接截出
- ⚠ 只盯着单个基本体，忽略组合体中另一部分对截面的附加影响

## 母题抽象
> 🧩 当题干给'组合立体图形，问可能的截面'时，先拆成圆柱/长方体/球等基本体并回忆各自截面库，再考虑缺口、组合位置对切面的限制，用排除法验证选项

**同类特征**：从任一面剖开求截面、圆柱体带缺口（C形柱）、圆柱与长方体组合体、选项为圆环/半圆/L形/三角形、截面图、图形推理立体剖切

### 题干
左图是给定的立体图形，将其从任一面剖开，以下哪项可能是该立体图形的截面？

### 选项

- B. B
- C. C　✅
- D. D

### 官方解析
本题考查截面图，逐一分析选项。
A项：无法截出完整的圆环，排除；
B项：无法截出半圆，排除；
C项：如下图所示，可以截出，当选；
 
D项：长方体中无法截出直角三角形，排除。
故正确答案为C。
