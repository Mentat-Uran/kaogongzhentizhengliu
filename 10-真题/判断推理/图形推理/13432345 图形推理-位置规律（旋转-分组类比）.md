# 图形推理-位置规律（旋转-分组类比）

考点：[[20-考点/判断推理/图形推理/图形推理-位置规律（旋转-分组类比）|图形推理 / 图形推理-位置规律（旋转/分组类比）]]


**问法模型**：'从四个选项中选择一个替代问号，使之呈现一定规律性'的两组对照式问法 → 先归纳第一组逐图变化规律，再原样套用到第二组推问号处图形

## 推理链
1. 第1步：两组图元素组成完全相同（均为3条两端带圆点的短线），数量、样式均无增减，优先考虑位置规律。
2. 第2步：拆解第一组变化：图1→图2只有最左边的短线顺时针旋转（竖变横），其余两条短线位置不动；图2→图3只有最中间的短线顺时针旋转，其余不动——即'三条线轮流单独顺时针旋转'。
3. 第3步：用第二组图1→图2验证规律：图1最左边的竖线在图2中变为横线，右侧两条横线保持不动，与'只转最左边线'的规律吻合，规律成立。
4. 第4步：套用规律推问号处：图2→问号应只有最中间的短线顺时针旋转（横线转成竖线），最左与最下的横线保持不动。
5. 第5步：逐项对照：A、B、D均出现多条线同时变动或旋转位置/方向不符，只有C项呈现'仅中间线变为竖线、其余两横线不动'的形态。

**最快解法**：⚡ 分组类比法＋位置规律口诀'元素相同看位置'：先锁定第一组'每次只顺时针旋转一条线（先左、再中）'的轮流规律，第二组照搬，直接盯住'中间线单独顺时针旋转'，秒选C。

## 易错点
- ⚠ 把整幅图当成整体在旋转，忽略'每一步只旋转其中一条短线、其余不动'的轮流规律
- ⚠ 旋转方向判断错误：此题三条线均为顺时针旋转90°，误判为逆时针会导致错选
- ⚠ 第二组线条初始摆放方向与第一组不同，误以为两组规律不同而另找数量或样式规律

## 母题抽象
> 🧩 当两组图形元素组成相同、但每幅图仅局部发生微小变动时，用'分组轮流位置规律法'：逐图对比第一组，找出'哪个元素、什么方向、移动/旋转多少'，再将该规律逐步套用到第二组验证选项。

**同类特征**：元素组成相同、两组各三图的对照式布局、短线两端带圆点、每次仅一条线旋转、顺时针旋转90°、问号位于第二组末位

### 题干
从四个选项中选择一个替代问号，使之呈现一定规律性，最适合的是（    ）。

### 选项
- A. A
- B. B
- C. C　✅
- D. D

### 官方解析
元素组成相同，优先考虑位置规律。观察发现，第一组图中，从图1到图2只有最左边的短线顺时针旋转，其他短线位置不动，从图2到图3只有最中间的短线顺时针旋转，其他短线位置不动。第二组图应用此规律，从图1到图2只有最左边的短线顺时针旋转，其他短线位置不动，那么从图2到问号处图形应该只有最中间的短线顺时针旋转，其他短线位置不动，只有C项符合。
故正确答案为C。
