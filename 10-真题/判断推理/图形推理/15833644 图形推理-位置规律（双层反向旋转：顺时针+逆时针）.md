# 图形推理-位置规律（双层反向旋转：顺时针+逆时针）

考点：[[20-考点/判断推理/图形推理/图形推理-位置规律（双层反向旋转：顺时针+逆时针）|图形推理 / 图形推理-位置规律（双层反向旋转：顺时针+逆时针）]]


**问法模型**：九宫格'选最合适的一个填入问号处'→ 横行观察、把每幅图拆成两个子元素，分别提取旋转规律并应用到第三行

## 推理链
1. 第1步：九宫格中各图元素组成相同，优先考虑位置规律，而非样式或数量规律
2. 第2步：横行观察第一行——每幅图均由'外圈轮廓+内部月牙'两层构成，外圈轮廓依次顺时针旋转（顶部半圆→右侧→底部），内部月牙依次逆时针旋转
3. 第3步：第二行验证同一规律——上层图形（闪电）依次逆时针旋转，下层图形（箭头）依次顺时针旋转，'一顺一逆'的双层旋转规律成立
4. 第4步：第三行按此拆解——图形由'内部半圆'和'其余线条（连接两角的斜线框）'两层组成
5. 第5步：应用规律——内部半圆依次逆时针旋转，其余线条依次顺时针旋转，推得问号处半圆位置与线条方向
6. 第6步：逐项对照，A、C、D的半圆位置或线条方向无法同时满足'半圆逆时针、线条顺时针'的叠加结果，仅B项完全吻合

**最快解法**：⚡ 分层双轨旋转法：横行看九宫格，每图拆成内外（上下）两个子元素，一个顺时针转90°、一个逆时针转90°；第三行'半圆逆时针、其余线条顺时针'直接锁定B

## 易错点
- ⚠ 把每幅图当整体看旋转，忽略图形可拆成内外/上下两层且各自独立旋转
- ⚠ 顺时针与逆时针方向记反，导致误选A或C
- ⚠ 第三行误把连接两角的线条当作静止背景，漏掉'其余线条也在顺时针旋转'这一半规律

## 母题抽象
> 🧩 当九宫格各图元素组成相同且每幅图可拆成两个子元素时，横行对比发现两个子元素分别以相反方向（一顺一逆）旋转，问号处直接套用该双轨旋转规律选图

**同类特征**：元素组成相同、九宫格优先横看、图形由内外/上下两层构成、两层反向旋转（一顺一逆）、半圆与线条分层结构、第三行延续规律求问号

### 题干
从所给的四个选项中，选择最合适的一个填入问号处，使之呈现一定的规律性：

### 选项
- A. A
- B. B　✅
- C. C
- D. D

### 官方解析
元素组成相同，优先考虑位置规律。九宫格优先横向看，第一行中，内部的图形依次逆时针旋转，外圈的图形依次顺时针旋转，第二行中，上层的图形依次逆时针旋转，下层的图形依次顺时针旋转。第三行应用此规律，内部的半圆依次逆时针旋转，其余线条依次顺时针旋转，对应B项。 
故正确答案为B。
