# 属性规律-对称性（黑白分开看，白色区域轴对称且对称轴方向旋转）

考点：[[20-考点/判断推理/图形推理/属性规律-对称性（黑白分开看，白色区域轴对称且对称轴方向旋转）|图形推理 / 属性规律-对称性（黑白分开看，白色区域轴对称且对称轴方向旋转）]]


**问法模型**：黑白球填格图组问'？处呈现规律' → 元素组成不同优先属性规律，整体无规律时黑白分开看，锁定某色区域的轴对称性及对称轴旋转方向

## 推理链
1. 第1步：五幅图均由黑球、白球排成方阵，元素组成不同，优先考虑属性规律，但整体观察无规律
2. 第2步：注意到题干所有图形均由黑球和白球两种元素构成，采用'黑白分开看'，单独描出每幅图中白色区域（白球连成的整体）的形状
3. 第3步：逐图检验白色区域，发现每幅图形的白色区域均为轴对称图形，且对称轴每次顺时针旋转
4. 第4步：延续该旋转规律，？处图形的白色区域应为轴对称图形，且对称轴应旋转至竖直方向
5. 第5步：对照选项排除：B项白色区域虽为轴对称图形，但对称轴为水平方向，排除；C、D两项白色区域为非对称图形，排除
6. 第6步：A项白色区域为轴对称图形且对称轴为竖直方向，完全符合规律，故选A

**最快解法**：⚡ 黑白分开看＋对称轴定向法：只描白球构成的图形，快速画其对称轴；由'对称轴每次顺时针旋转'推出？处须为竖直对称轴，B（横轴）、C/D（不对称）直接排除，秒选A

## 易错点
- ⚠ 忽略'黑白分开看'，在黑白混杂交织的整体中硬找对称或数量规律而毫无头绪
- ⚠ 只判断'白色区域是否轴对称'，漏看对称轴方向的旋转规律，误选同为轴对称但为水平对称轴的B项
- ⚠ 把考察对象错放在黑球区域上，或将对称轴旋转方向（顺时针）看反，误推为竖轴以外的方向

## 母题抽象
> 🧩 当黑白球填格图形整体无规律时，用'黑白分开看'方法：分别考察黑、白区域的属性（对称性、封闭性、直曲性等），若某色区域均为轴对称，则继续追踪其对称轴方向的旋转规律来验证问号处选项

**同类特征**：黑白球方阵填充、元素组成不同、整体无规律需拆分观察、白色区域均为轴对称、对称轴顺时针旋转、选项按对称轴方向辨析（横轴/竖轴/不对称）
