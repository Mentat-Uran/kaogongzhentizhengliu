# 数量规律-角（直角个数计数）

考点：[[20-考点/判断推理/图形推理/数量规律-角（直角个数计数）|图形推理 / 数量规律-角（直角个数计数）]]


**问法模型**：'选择最合适的一个填入问号处，使之呈现一定的规律性'且元素组成不同、无属性规律 → 采用数量规律法，本题细分为'数直角个数'的等差递增模型

## 推理链
1. 第1步：题干五幅图均为正方形外框内含不同直线分割，元素组成不同，排除样式类和位置类规律
2. 第2步：尝试属性规律（对称、曲直、开闭）均无统一特征，转向数量规律
3. 第3步：观察每幅图内部直线与外框边、直线与直线相交处均出现明显的垂直相交（直角），确定计数对象为'直角个数'
4. 第4步：依次数题干各图直角数：图1为1个、图2为2个、图3为3个、图4为4个、图5为5个，构成公差为1的等差数列
5. 第5步：故问号处图形应含有6个直角
6. 第6步：逐项数直角数对照：A、B、C项直角数均不为6，D项直角数为6，符合延续规律

**最快解法**：⚡ 数角法（直角计数口诀'线线垂直找直角'）：一眼锁定每图中的垂直相交处，快速数出1、2、3、4、5的递增序列，直接选直角数为6的D项，无需数其他量

## 易错点
- ⚠ 只数图形内角总个数或交点数，忽略本题考的是'直角'这一细分角类
- ⚠ 漏数内部直线与正方形外框边垂直相交所形成的直角（直角多出现在线与外框垂直处）
- ⚠ 将接近90°的锐角或钝角误判为直角，导致多数或漏数

## 母题抽象
> 🧩 当图形元素组成不同、无属性规律，且图中出现明显的线线垂直（直角）特征时，优先数直角个数；若题干直角数呈等差递增，问号处选直角数延续该规律的选项

**同类特征**：元素组成不同、无明显属性规律、直线相交、明显直角（线线垂直）、正方形外框内直线分割、直角数1~5等差递增

### 官方解析

故正确答案为D。
