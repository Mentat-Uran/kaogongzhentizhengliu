# 位置规律-旋转（顺时针90°，阴影线方向与矩形横竖同步旋转）

考点：[[20-考点/判断推理/图形推理/位置规律-旋转（顺时针90°，阴影线方向与矩形横竖同步旋转）|图形推理 / 位置规律-旋转（顺时针90°，阴影线方向与矩形横竖同步旋转）]]


**问法模型**：田字格四象限元素组成相同、问？处规律 → 元素相同优先考虑位置规律，验证相邻象限间的旋转关系

## 推理链
1. 第1步：题干为田字格四象限，每格均由'阴影三角形+矩形'两个元素构成，元素组成相同，优先考虑位置规律
2. 第2步：观察左上角（竖直矩形在左、竖线阴影三角形在右上）顺时针旋转90°，矩形变横放移至上方、阴影三角形移至右下且阴影线方向同步旋转，与右上角图形完全吻合
3. 第3步：右上角图形再顺时针旋转90°得到右下角（竖直矩形在右、竖线阴影三角形在左下），旋转规律得到验证
4. 第4步：按此规律，？处（左下角）应由右下角图形顺时针旋转90°得到：阴影三角形转至左上且竖线阴影变为横线阴影，竖直矩形转至下方且变为横放矩形
5. 第5步：逐项对照——A项横线阴影在左上+横放矩形在下方，符合；B、D项矩形仍为竖放，旋转后方向错误；C项阴影线仍为竖线，方向错误
6. 第6步：只有A项符合顺时针旋转90°的全部特征，故选A

**最快解法**：⚡ 图形规律口诀'元素相同看旋转'+方向元素联动：直接将右下角图形顺时针转90°——阴影三角形到左上、竖线变横线、竖矩形变横矩形移到下方，一步锁定A

## 易错点
- ⚠ 只关注阴影三角形的位置旋转，忽略阴影线方向（竖线→横线）也需同步旋转而误选C
- ⚠ 只看矩形位置移动，忽略矩形横竖朝向随旋转由竖变横而误选B或D
- ⚠ 误判旋转方向为逆时针，导致规律对不上已知象限
- ⚠ 对旋转轴的把握不清，误以象限分界线为轴做翻转而非整体旋转

## 母题抽象
> 🧩 当题干图形各区域元素组成相同、且内部含方向性元素（矩形的横竖、阴影线/线条的方向）时，优先验证相邻位置间的90°顺/逆时针旋转，且方向性元素必须与图形同步旋转后再逐项排除

**同类特征**：田字格四象限、元素组成相同、阴影三角形+矩形组合、矩形横竖朝向变化、阴影线方向变化、顺时针旋转90°

### 官方解析
元素组成相同，优先考虑位置规律。观察发现，左上角的阴影三角形和矩形顺时针旋转得到右上角图形，右上角图形顺时针旋转得到右下角图形，因此？处图形应由右下角图形顺时针旋转得到，只有A项符合。
故正确答案为A。
