# 逻辑关系-并列关系与种属关系的复合辨析

考点：[[20-考点/判断推理/类比推理/逻辑关系-并列关系与种属关系的复合辨析|类比推理 / 逻辑关系-并列关系与种属关系的复合辨析]]


**问法模型**：四词类比给出'属：并列两种：其中一种的下位品种'结构 → 用造句法逐项复现'X和Y都是Z，W是Y的一种'验证

## 推理链
1. 第1步：题干中柏树与松树都是树的一种，柏树和松树为并列关系
2. 第2步：雪松是松树的一个品种，雪松与松树为种属关系（雪松⊂松树）
3. 第3步：归纳题干结构为：属概念：并列的两种：其中一种的下位品种，即'并列+种属'复合链
4. 第4步：A项汽车和火车都是车的一种且并列，动车是火车中速度较快的一种（种属关系），与题干结构一致
5. 第5步：B项公民是民法的管理对象而非民法的一种；C项香梨是梨的果实品种而非梨花的一种；D项牛黄是黄牛体内之物，属组成关系而非种属关系
6. 第6步：仅A项完整复现'并列+种属'结构，故选A

**最快解法**：⚡ 造句法+排除法：先造句'柏树、松树都是树，雪松是松树的一种'，再逐项套用'X和Y都是Z，W是Y的一种'，仅A项完全复现，B/C/D依次在第四词处断裂（对象/果实/组成部分）

## 易错点
- ⚠ C项'香梨'与'梨花'字面相近，易误判香梨是梨花的一种，实际香梨是梨树果实的品种而非花的一种
- ⚠ D项'牛黄'易误认为与黄牛是种属关系，实际牛黄是黄牛体内的结石，属组成关系
- ⚠ A项若误把'动车'与'火车'当并列关系（如与'高铁'并列的印象干扰），会错误排除正确答案

## 母题抽象
> 🧩 当四词类比出现'首词为属概念、二三级并列、第四词是第三词下位种'结构时，用造句法验证'都是…；…是…的一种'，并警惕第四词字面与第三词相似但实为组成关系或对象关系的干扰项

**同类特征**：四词类比、首词为属概念（树）、第二、三词并列（柏树/松树）、第四词为第三词的下位品种（雪松⊂松树）、并列+种属复合结构、第四词字面相近干扰（香梨/牛黄/公民）

### 题干
树：柏树：松树：雪松

### 选项
- A. 车：汽车：火车：动车　✅
- B. 法：刑法：民法：公民
- C. 花：梅花：梨花：香梨
- D. 牛：水牛：黄牛：牛黄

### 官方解析
第一步：判断题干词语间的逻辑关系。
柏树和松树都是树的一种，柏树和松树是并列关系，雪松是松树的一个品种，雪松和松树之间是种属关系。
第二步：判断选项词语间的逻辑关系。
A项：汽车和火车都是车的一种，汽车和火车是并列关系，动车是火车中速度较快的一种，动车和火车之间是种属关系，与题干逻辑关系一致，当选；
B项：刑法和民法都是法的一种，刑法和民法是并列关系，但公民是民法的管理对象，二者非种属关系，与题干逻辑关系不一致，排除；
C项：梅花和梨花都是花的一种，梅花和梨花是并列关系，但香梨并不是梨花的一种，二者非种属关系，与题干逻辑关系不一致，排除；
D项：水牛和黄牛都是牛的一种，水牛和黄牛是并列关系，但牛黄是黄牛身体中的一部分，二者属于组成关系，与题干逻辑关系不一致，排除。
故正确答案为A。
