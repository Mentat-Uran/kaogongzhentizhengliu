# 填空型类比-组成关系辨析（含动宾-偏正-载体关系及词序方向比对）

考点：[[20-考点/判断推理/类比推理/填空型类比-组成关系辨析（含动宾-偏正-载体关系及词序方向比对）|类比推理 / 填空型类比-组成关系辨析（含动宾/偏正/载体关系及词序方向比对）]]


**问法模型**：题干为'（ ）对于音乐 相当于 真相 对于（ ）'填空型问法 → 采用代入造句法，将选项分别代入两端造句，要求前后两组词的逻辑关系类型与词语先后方向均一致

## 推理链
1. 第1步：题干为填空式类比，需将选项代入空格，分别检验'X对于音乐'与'真相对于Y'两组关系的类型和词序方向
2. 第2步：代入A项，'演奏音乐'为动宾结构（动词在前）；'揭露真相'虽同为动宾，但题干词序是'真相'（宾语）在前，前后方向相反，排除
3. 第3步：代入B项，'令人感动的音乐'为偏正关系（感动修饰音乐，修饰语在前）；'令人激愤的真相'同为偏正，但题干词序是'真相'（中心语）在前，前后方向相反，排除
4. 第4步：代入C项，'浪漫的音乐'为偏正关系；而'报纸'与'真相'是在报纸上揭露真相的载体关系，前后关系类型不一致，排除
5. 第5步：代入D项，'旋律'是'音乐'的一部分，为组成关系且部分在前；'新闻'包含'真相'，'真相'是新闻的组成部分，同为组成关系且部分在前
6. 第6步：只有D项前后逻辑关系类型（组成关系）与词语先后顺序（部分对于整体）均一致，故当选

**最快解法**：⚡ 代入造句法+排除法：逐项代入造句判关系类型，重点盯'真相'的位置——A、B中'真相'前置导致动宾/偏正方向颠倒可直接秒排；C项'报纸'是载体非修饰；唯D前后均为'部分对于整体'的组成关系

## 易错点
- ⚠ 只验证关系类型不验证词序方向：A、B两项关系类型虽然成立，但'真相'在题干中位于前位，代入后方向相反，极易误选A或B
- ⚠ 把'新闻包含真相'误判为载体对应或种属关系，漏判其与'旋律是音乐的一部分'同属组成（包含）关系
- ⚠ 填空型类比较两遍：既要前后关系类型一致，又要代入后语序通顺方向相同，只查一遍即下手易出错

## 母题抽象
> 🧩 当题干出现'（ ）对于A 相当于 B 对于（ ）'的填空特征时，用代入造句法，先比对两侧逻辑关系类型（动宾/偏正/组成/载体等），再验证代入后词语先后方向是否一致，两者均同者当选

**同类特征**：填空型两端代入、真相、音乐、词序方向比对、组成关系（部分-整体）、动宾/偏正/载体干扰项

### 题干
（    ） 对于 音乐 相当于 真相 对于 （    ）

### 选项
- A. 演奏 揭露
- B. 感动 激愤
- C. 浪漫 报纸
- D. 旋律 新闻　✅

### 官方解析
A项：演奏音乐，二者为动宾结构；揭露真相，二者为动宾结构，但词语先后顺序相反，前后逻辑关系不一致，排除；
B项：令人感动的音乐，感动可以用来修饰音乐，二者为偏正关系；令人激愤的真相，激愤可以用来修饰真相，二者为偏正关系，但词语先后顺序相反，前后逻辑关系不一致，排除；
C项：浪漫的音乐，浪漫可以用来修饰音乐，二者为偏正关系；在报纸上揭露真相，报纸是真相的载体，前后逻辑关系不一致，排除；
D项：旋律是音乐的一部分，二者为组成关系；新闻包含了真相，二者为组成关系，前后逻辑关系一致，当选。
故正确答案为D。
