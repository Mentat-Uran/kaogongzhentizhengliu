# 逻辑关系-组成关系辨析（填空型两空代入）

考点：[[20-考点/判断推理/类比推理/逻辑关系-组成关系辨析（填空型两空代入）|类比推理 / 逻辑关系-组成关系辨析（填空型两空代入）]]


**问法模型**：填空式类比'（ ）对于 松树 相当于 CPU 对于（ ）'→ 将选项逐一代入两空，验证前后两组词项的逻辑关系是否同构

## 推理链
1. 第1步：题干为两空填空型类比，需把选项词语分别代入'（ ）对于松树'和'CPU对于（ ）'两端，比较关系是否一致
2. 第2步：先固定完整词项CPU建立参照关系——CPU是电脑的组成部分（组成关系），同时CPU是芯片的一种（种属关系），据此预判可匹配的关系类型
3. 第3步：代入A项：松果是松树的组成部分（组成关系），但CPU与显卡都是电脑的部件（并列关系），前后不一致，排除
4. 第4步：代入B项：松树是植物（种属关系），但CPU不是电器（不构成种属关系），前后不一致，排除
5. 第5步：代入C项：松子是松树的组成部分（组成关系），CPU是电脑的组成部分（组成关系），前后均为组成关系，保留
6. 第6步：代入D项：松茸是真菌、生长在松树根部附近，与松树为共生关系；CPU是芯片的一种（种属关系），前后不一致，排除
7. 第7步：只有C项两端关系同构，确定答案为C

**最快解法**：⚡ 代入法+关系先验：先锁定题干已给完整词项CPU，默念'CPU是电脑的一部分（组成关系）'，扫一眼选项第二空，只有'电脑'能与CPU构成组成关系，直接锁定C，再代入'松子—松树'验证组成关系成立即可

## 易错点
- ⚠ A项只看前半'松果—松树是组成关系'就心动，漏验后半'CPU—显卡'实为并列关系，填空型必须两端都验证
- ⚠ 种属关系与组成关系混淆：'松树是植物'是'是一种'（种属），'CPU是电脑的一部分'是'是其中一部分'（组成），凭'都跟植物/电脑沾边'误选B
- ⚠ D项误以为'松茸长在松树上'就是组成关系，实际题干表述是生长在根部附近的共生关系；且CPU与芯片是'是一种'的种属关系而非组成关系

## 母题抽象

### 题干
（    ） 对于 松树 相当于 CPU 对于 （    ）

### 选项
- A. 松果  显卡
- B. 植物  电器
- C. 松子  电脑　✅
- D. 松茸  芯片

### 官方解析
逐一代入选项。
A项：松果是松树的组成部分，二者为组成关系；CPU和显卡均为电脑的部件，二者为并列关系，前后逻辑关系不一致，排除；
B项：松树是植物，二者为种属关系；CPU不是电器，二者不是种属关系，前后逻辑关系不一致，排除；
C项：松子是松树的组成部分，二者为组成关系；CPU是电脑的组成部分，二者为组成关系，前后逻辑关系一致，当选；
D项：松茸是一种真菌，通常生长在松树根部附近，二者为共生关系；CPU是一种芯片，二者为种属关系，前后逻辑关系不一致，排除。
故正确答案为C。
