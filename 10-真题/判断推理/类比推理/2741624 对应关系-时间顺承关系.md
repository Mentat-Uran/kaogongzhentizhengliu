# 对应关系-时间顺承关系

考点：[[20-考点/判断推理/类比推理/对应关系-时间顺承关系|类比推理 / 对应关系-时间顺承关系]]


**问法模型**：题干三个动词/动宾词组呈流程环节 → 先固定题干词序为时间先后轴，再逐项核验选项是否保持同序

## 推理链
1. 第1步：题干'策划：编排：直播'为同一节目制作流程的三个环节，先策划、再编排、最后直播
2. 第2步：判定考点为时间顺承对应关系，且要求选项三词的时间顺序与题干词序完全一致
3. 第3步：A项'测试：上线：研发'中，研发应在测试和上线之前，顺序错乱，排除
4. 第4步：B项'育苗：移栽：收割'为种植流程三环节，先育苗、再移栽、最后收割，与题干同序，当选
5. 第5步：C项'学车：年检：考证'中年检一般在考证之后，D项'选房：入住：装修'中装修应在入住之前，均顺序不符，排除

**最快解法**：⚡ 排除法（时间轴口诀：题干词序=时间序）——盯住首尾词：首词须最先发生、尾词须最后发生。A项首词'测试'之前还有'研发'、C项中'年检'跳到'考证'前、D项尾词'入住'之前还有'装修'，均否；仅B项'育苗→移栽→收割'完全同序

## 易错点
- ⚠ 只看三词是否属同一流程、不核验顺序：A项研发/测试/上线确属软件开发流程，但词序被打乱，易误选
- ⚠ 生活常识时序掌握不准：误以为年检可先于考证（C项）、或未注意到装修先于入住（D项）
- ⚠ 未检查三词是否属同一主体的同一连续流程

## 母题抽象
> 🧩 当题干三词均为动词/动宾结构且可排成时间轴时，先按题干词序固定先后，逐项检查选项是否同序——环节正确但顺序错乱的选项（首词不最先、尾词不最后）必排除

**同类特征**：三个动词/动宾词组、同一流程的先后环节、时间顺承对应、词序即时间序、流程类名词辨序

### 题干
策划：编排：直播

### 选项
- A. 测试：上线：研发
- B. 育苗：移栽：收割　✅
- C. 学车：年检：考证
- D. 选房：入住：装修

### 官方解析
第一步：判断题干词语间逻辑关系。
先策划，再编排，最后直播，三者为时间先后顺序的对应关系。
第二步：判断选项词语间逻辑关系。
A项：先测试后上线，但是研发应该在测试和上线之前，与题干逻辑关系不一致，排除；
B项：先育苗，再移栽，最后收割，三者为时间先后顺序的对应关系，与题干逻辑关系一致，当选；
C项：先学车后考证，但是年检一般是在考证之后，与题干逻辑关系不一致，排除；
D项：先选房，再装修，最后入住，装修应该在入住之前发生，与题干逻辑关系不一致，排除。
故正确答案为B。
