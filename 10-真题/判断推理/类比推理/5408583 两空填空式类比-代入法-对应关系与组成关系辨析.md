# 两空填空式类比-代入法-对应关系与组成关系辨析

考点：[[20-考点/判断推理/类比推理/两空填空式类比-代入法-对应关系与组成关系辨析|类比推理 / 两空填空式类比-代入法-对应关系与组成关系辨析]]


**问法模型**：'A 对于 （） 相当于 （） 对于 B'双空题干 → 逐项代入，用造句法验证前后两组词的'关系类型+关系方向'是否完全平行

## 推理链
1. 第1步：提取题干结构'军队：( ) 相当于 ( )：人体'，需在两空填入词项使前后逻辑关系一致且方向平行
2. 第2步：采用代入法逐项验证，判定核心是关系类型（对应/组成/并列）与关系方向（谁是整体谁是部分）双重一致
3. 第3步：代入A项，'军队'与'警察'都能维护国家安全，是并列关系；'甲状腺'是'人体'的一部分，是组成关系，前后不一致，排除
4. 第4步：代入B项，'武器'是'军队'配发使用的工具（工具对应），'维生素'是维持人体生命活动必需的有机物质（营养对应），对应类型不同，排除
5. 第5步：代入C项，造句'军队能保护国家安全''白细胞能包围、吞噬病菌，保护人体免受侵害'，前后均为'保护'功能对应，关系类型与方向一致，当选
6. 第6步：代入D项，'士兵'是'军队'的一部分，'血小板'是'人体'的一部分，虽同为组成关系，但题干结构为'整体：部分 相当于 部分：整体'，前后顺序相反，排除

**最快解法**：⚡ 代入法+造句法：先对C项造句'军队保卫国家、白细胞保卫人体'，两句主宾结构完全平行，直接锁定；再用D项反向自查——士兵在军队之内、血小板在人体之内，但空位方向一前一后，顺序相反即可排除

## 易错点
- ⚠ D项前后均为组成关系，容易只看'关系类型相同'而忽略'方向相反'（士兵是军队的部分，但题干前空在军队之后；血小板是人体的部分，恰在前空位置），方向不平行仍是错误选项
- ⚠ B项前后似都能建立'对应关系'，易忽略二级辨析：武器是军队的工具对应，维生素是人体的营养物质对应，具体对应类型不同
- ⚠ 凭词义亲近感选词（如看到'士兵'联想到'军队'）而跳过造句验证关系一致性，类比题以关系一致为第一标准，而非词义相近

### 题干
军队 对于 （    ） 相当于 （    ） 对于 人体

### 选项
- A. 警察；甲状腺
- B. 武器；维生素
- C. 国家；白细胞　✅
- D. 士兵；血小板

### 官方解析
逐一代入选项。
A项：军队和警察都能维护国家安全，二者是并列关系，甲状腺是人体的一部分，二者是组成关系，前后逻辑关系不一致，排除；
B项：武器是军队配发的工具，二者是工具的对应关系，维生素是维持人体生命活动必需的一类有机物质，二者是对应关系，前后逻辑关系不一致，排除；
C项：军队能保护国家安全，二者是对应关系，白细胞能将病菌包围、吞噬，保护人体免受侵害，二者是对应关系，前后逻辑关系一致，当选；
D项：士兵是军队的一部分，二者是组成关系，血小板是人体血液中的一种成分，是人体的一部分，二者是组成关系，但前后顺序相反，前后逻辑关系不一致，排除。
故正确答案为C。

> [!warning] 疑点（官方解析可能有误，待人工复核）
> 官方解析B项表述略有瑕疵：先称'武器与军队是工具的对应关系''维生素与人体是对应关系'，随后结论写'前后逻辑关系不一致'，字面上存在'同称对应却不一致'的表述矛盾；其真实依据应为对应类型不同（工具对应 vs 营养物质对应），不影响正确答案为C的结论
