# 对应关系-方式依据对应（行为+依据+对象，需二级辨析必要性）

考点：[[20-考点/判断推理/类比推理/对应关系-方式依据对应（行为+依据+对象，需二级辨析必要性）|类比推理 / 对应关系-方式依据对应（行为+依据+对象，需二级辨析必要性）]]


**问法模型**：三词类比填空题 → 造句法串联三词，再对结构一致的选项做'是否必须凭借中间词'的必要性二级辨析

## 推理链
1. 第1步：题干三词为'动词+名词+名词'结构，侦查是行为，案件是作用对象，线索是侦查案件所依据的信息，可造句'通过线索侦查案件'
2. 第2步：用'通过X（动词）Y'的造句法检验各选项，要求结构与'行为∶依据∶对象'完全一致
3. 第3步：逐项对照——A项'通过排行榜评价歌手'句子通顺，保留；B项地图是定位地点的工具（工具对应且中间词'地点'是对象而非依据），排除；C项GPS是提供导航服务的功能工具（功能对应），排除；D项'通过关键词搜索网页'结构一致，保留
4. 第4步：对A、D做二级辨析——题干侦查案件必须依托线索，无线索则无从侦查；D项搜索网页必须输入关键词，必要性相同；A项评价歌手不一定要通过排行榜（还可通过现场表现、专辑等），必要性不足，故D更贴合
5. 第5步：得出结论，正确答案为D

**最快解法**：⚡ 造句法+必要性二级辨析：先用'通过中间词+首词动词+尾词'造句排除B（工具在后）、C（工具/功能对应），A、D句子均通顺后，比较'是否必须凭借中间词'——评价不必须靠排行榜，搜索必须靠关键词，锁定D

## 易错点
- ⚠ 只做造句不做二级辨析，发现A也能造句'通过排行榜评价歌手'而误选A
- ⚠ 把'线索'误解为侦查的工具/手段，与B、C的工具对应混淆，忽略线索实为信息依据
- ⚠ 忽略词序结构：题干中间位置是'依据'，B、C中间位置的词语角色（对象/工具）与题干错位

## 母题抽象
> 🧩 当三词类比出现'动词∶名词∶名词'且可造句'通过中间词实施首词行为于尾词'时，先用造句法筛选结构一致的选项，再用'该凭借是否必不可少'做二级辨析定答案

**同类特征**：三词类比动宾结构、造句'通过线索侦查案件'、中间词为依据/信息、存在多个可造句选项、需辨析凭借的必要性

### 题干
侦查∶线索∶案件

### 选项
- A. 评价∶排行榜∶歌手
- B. 定位∶地点∶地图
- C. 导航∶GPS∶汽车
- D. 搜索∶关键词∶网页　✅

### 官方解析
第一步：判断题干词语间逻辑关系。
题干三词可造句子为：通过线索侦查案件。
第二步：判断选项词语间逻辑关系。
A项：通过排行榜评价歌手，保留；
B项：地图是定位地点的工具，二者为对应关系，与题干逻辑关系不一致，排除；
C项：GPS主要功能是提供实时、全天候和全球性的导航服务，导航和GPS，二者为功能对应关系，与题干逻辑关系不一致，排除；
D项：通过关键词搜索网页，保留；
对比A、D两项，题干侦查案件必须要通过线索，A项评价歌手不一定要通过排行榜，D项搜索网页必须要通过关键词。因此，相比于A项，D项更符合题干逻辑关系，当选。
故正确答案为D。
