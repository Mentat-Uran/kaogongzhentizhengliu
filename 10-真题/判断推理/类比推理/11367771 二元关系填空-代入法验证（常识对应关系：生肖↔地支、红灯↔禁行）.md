# 二元关系填空-代入法验证（常识对应关系：生肖↔地支、红灯↔禁行）

考点：[[20-考点/判断推理/类比推理/二元关系填空-代入法验证（常识对应关系：生肖↔地支、红灯↔禁行）|类比推理 / 二元关系填空-代入法验证（常识对应关系：生肖↔地支、红灯↔禁行）]]


**问法模型**：'A之于（）相当于（）之于B'四词填空式类比 → 将选项逐一代入，要求代入后前后两组词的逻辑关系类型完全一致

## 推理链
1. 第1步：题干为填空式类比'生肖之于（）相当于（）之于禁行'，解题须将每项两个词代入空位，比较前后逻辑关系是否同型
2. 第2步：代入D项前空：生肖是代表十二地支的十二种动物，子属鼠、丑属牛、寅属虎……亥属猪，生肖与地支为一一对应的固定搭配
3. 第3步：代入D项后空：红灯亮时表示禁止通行，红灯与禁行为'标志—含义'的紧密对应关系，与前后空同为对应关系，逻辑一致
4. 第4步：代入A项：有的生肖是飞禽（如鸡）、有的飞禽不是生肖，生肖与飞禽为交叉关系；而'在路口可以禁行'为场所对应，前后关系不一致，排除
5. 第5步：代入B项：生肖与走兽为交叉关系（有的生肖是走兽，有的走兽不是生肖）；'禁行是一种信号'为种属关系，前后不一致，排除
6. 第6步：代入C项：天干是甲、乙、丙、丁等十个次序符号的统称，与生肖无明显逻辑关系；通行与禁行为反义关系，前后不一致，排除

**最快解法**：⚡ 代入法+固定搭配优先：优先检验含常识固定对应的D项——生肖与十二地支一一对应、红灯指示禁行，前后同属紧密对应关系，直接锁定；再快速排除A（交叉/场所对应）、B（交叉/种属）、C（无关系/反义）

## 易错点
- ⚠ 混淆'天干'与'地支'：误以为天干也与生肖对应，实际与十二生肖对应的是地支（子丑寅卯……），天干是甲乙丙丁……
- ⚠ B项误将'禁行是信号'当作对应关系，未识别出这是种属关系，与前面的交叉关系不同型
- ⚠ 仅看词面相近就选C（'通行'与'禁行'反义、字面相对），未比较代入后前后关系类型是否一致

## 母题抽象
> 🧩 当题干出现'A之于（）相当于（）之于禁行'式填空类比时，用代入法逐项验证，只有前后两组词的逻辑关系类型（全同/并列/交叉/种属/对应/反义）完全一致才可选；优先代入含固定常识搭配的选项

### 题干
生肖 之于 （    ） 相当于 （    ） 之于 禁行

### 选项
- A. 飞禽 路口
- B. 走兽 信号
- C. 天干 通行
- D. 地支 红灯　✅

### 官方解析
逐一代入选项。
A项：飞禽指会飞的鸟类，也泛指鸟类。有的生肖是飞禽（如，鸡），有的生肖不是飞禽，有的飞禽是生肖，有的飞禽不是生肖，二者为交叉关系；在路口可以禁行，二者为对应关系，前后逻辑关系不一致，排除；
B项：走兽泛指兽类。有的生肖是走兽（如，牛），有的生肖不是走兽，有的走兽是生肖，有的走兽不是生肖，二者为交叉关系；禁行是一种信号，二者为种属关系，前后逻辑关系不一致，排除；
C项：天干是对甲、乙、丙、丁、戊、己、庚、辛、壬、癸的统称，传统用作表示次序的符号，和生肖无明显逻辑关系；通行和禁行为反义关系，前后逻辑关系不一致，排除；
D项：地支是对子、丑、寅、卯、辰、巳、午、未、申、酉、戌、亥的统称，生肖是代表十二地支而用来记人的出生年的十二种动物，子属鼠、丑属牛、寅属虎、卯属兔、辰属龙、巳属蛇、午属马、未属羊、申属猴、酉属鸡、戌属狗、亥属猪，二者有紧密的对应关系；红灯指红色的交通信号灯，红灯亮时表示禁止通行，二者有紧密的对应关系，前后逻辑关系一致，当选。
故正确答案为D。
