# 语义关系-并列关系（原理相同的事物并列）

考点：[[20-考点/判断推理/类比推理/语义关系-并列关系（原理相同的事物并列）|类比推理 / 语义关系-并列关系（原理相同的事物并列）]]


**问法模型**：'A：B'给出两个具体事物，要求选出逻辑关系一致的选项 → 先判定一级关系（并列关系），再用'工作原理是否相同'做二级辨析锁定答案

## 推理链
1. 第1步：提取题干关系：'跷跷板'与'天平'均为具体事物，跷跷板供游戏、天平供称量，二者并列，共同工作原理是杠杆原理
2. 第2步：确立判定标准：正确选项需同时满足'并列关系'与'原理相同'两个层级，缺一不可
3. 第3步：A项'踢毽子'是脚踢毽球的健身运动，'口琴'是金属簧片振动发声的乐器，二者原理不同，排除
4. 第4步：B项'丢手绢'是民间儿童游戏，'魔术'是表演艺术，二者原理不同，排除
5. 第5步：C项'滑滑梯'靠滑梯光滑表面产生快乐，'杠杆'是可绕固定点转动的硬棒，二者原理不同，且'杠杆'是原理名词而非与滑滑梯并列的应用物，排除
6. 第6步：D项'荡秋千'与'钟摆'均利用单摆原理，并列且原理相同，与题干逻辑关系一致，当选

**最快解法**：⚡ 原理检验法（造句法）：给每组词造句'X与Y的原理都是Z'，逐项套用——A/B/C均造不通，只有'荡秋千与钟摆的原理都是单摆'造得通，直接锁定D

## 易错点
- ⚠ C项'杠杆'正是题干跷跷板与天平的共同原理词，因'眼熟'极易误选，实际滑滑梯与杠杆既非原理相同也非并列事物
- ⚠ 只做一级辨析（都是游乐/物理相关事物）就下结论，忽略'原理相同'这一二级辨析层级
- ⚠ 见'天平'是测量工具而非游戏就误判'不并列'，忽略跨领域（玩具vs工具）并列照样成立

## 母题抽象
> 🧩 当题干出现'两个具体事物'且初看为并列时，用'原理相同'做二级辨析：造句'X与Y的原理都是Z'，能造通且选项词项范畴对齐者当选；警惕题干共同原理名词（如'杠杆'）混入选项充当干扰项

**同类特征**：两个具体事物名词、并列关系、工作原理相同、杠杆原理/单摆原理、二级辨析：原理层面、跨领域并列（游戏物vs工具）

### 题干
跷跷板：天平

### 选项
- A. 踢毽子：口琴
- B. 丢手绢：魔术
- C. 滑滑梯：杠杆
- D. 荡秋千：钟摆　✅

### 官方解析
第一步：判断题干词语间逻辑关系。
跷跷板和天平的原理均为杠杆原理，二者是并列关系，是原理相同的事物。
第二步：判断选项词语间逻辑关系。
A项：踢毽子是一项用脚踢毽球的健身运动，口琴是一种用嘴吹或吸气，使金属簧片振动发声的多簧片乐器，二者原理不同，与题干逻辑关系不一致，排除；
B项：丢手绢是我国传统的民间儿童游戏，魔术是以不断变化让人捉摸不透并带给观众惊奇体验为核心的一种表演艺术，二者原理不同，与题干逻辑关系不一致，排除；
C项：滑滑梯是利用滑梯光滑表面来产生快乐的儿童娱乐活动，杠杆是在力的作用下可绕固定点转动的硬棒，二者原理不同，与题干逻辑关系不一致，排除；
D项：荡秋千是利用秋千单摆原理产生愉悦的一项运动，钟摆是摆钟机件的一部分，其利用的是单摆原理，二者是并列关系，是原理相同的事物，与题干逻辑关系一致，当选。
故正确答案为D。
