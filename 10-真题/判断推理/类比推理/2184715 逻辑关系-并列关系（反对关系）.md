# 逻辑关系-并列关系（反对关系）

考点：[[20-考点/判断推理/类比推理/逻辑关系-并列关系（反对关系）|类比推理 / 逻辑关系-并列关系（反对关系）]]


**问法模型**：题干给出'A：B'两词项 → 用造句法验证两者是否'同属一个大类、同级并列、互不包含'，并二级辨析反对关系与组成/转化/矛盾关系

## 推理链
1. 第1步：题干'桂林'与'北海'同属广西壮族自治区的地级市，是同一大类下的两个同级具体对象
2. 第2步：两者互不包含、不重叠，且除二者外还有南宁、柳州等其他地级市 → 并列关系中的反对关系（而非非此即彼的矛盾关系）
3. 第3步：A项墨汁主要用于书法，颜料用于制造涂料、油墨等，两者领域不同、层级不一致，排除；B项自来水加热可以变成开水，是转化关系而非并列，排除
4. 第4步：C项氧气是空气的组成部分，是组成关系而非并列关系，排除
5. 第5步：D项红茶和黑茶都是茶叶中的发酵茶，除二者外还有绿茶、白茶等 → 同级并列的反对关系，与题干一致，当选

**最快解法**：⚡ 造句法+排除法：先造句'桂林和北海都是（广西的）地级市'确定并列反对关系，再逐项造句——'氧气是空气的（一部分）'为组成、'自来水加热变开水'为转化、'墨汁/颜料领域不同'层级不符，只有'红茶和黑茶都是发酵茶'句式一致，锁定D

## 易错点
- ⚠ 把'氧气存在于空气中'误判为并列，混淆'并列（同级成员）'与'组成（部分与整体）'关系
- ⚠ 忽略'反对 vs 矛盾'二级辨析：除桂林、北海外还有其他地级市，故为反对关系而非矛盾关系
- ⚠ A项被'都是着色/书写用材料'的表面相似迷惑，实际两者用途领域不同、不是同一类属下的同级并列

## 母题抽象
> 🧩 当题干两词是'同一大类下的两个同级具体成员'时，用造句法验证'X和Y都是（同一类属）'，再确认除X、Y外还有其他成员（反对关系），排除组成、转化、领域不同的干扰项

**同类特征**：两词为同一层级的具体对象（地级市）、同属一个大类属（广西/茶叶中的发酵茶）、互不包含、互不重叠、除二者外还有其他同级成员（反对关系）、选项设置组成关系与转化关系干扰

### 题干
桂林：北海

### 选项
- A. 墨汁：颜料
- B. 开水：自来水
- C. 氧气：空气
- D. 红茶：黑茶　✅

### 官方解析
第一步：判断题干词语间的逻辑关系。
桂林和北海是广西壮族自治区地级市，两者是并列关系的反对关系。
第二步：判断选项词语间的逻辑关系。
A项：墨汁主要用于书法，颜料主要用于制造涂料、油墨、油画色膏、化妆油彩、彩色纸张等，两者所在的领域不同，与题干逻辑关系不一致，排除；
B项：自来水加热可以变成开水，与题干逻辑关系不一致，排除； 
C项：氧气是空气的组成部分，两者是组成关系，与题干逻辑关系不一致，排除；
D项：红茶和黑茶都是茶叶中的发酵茶，两者是并列关系中的反对关系，与题干逻辑关系一致，当选。
故正确答案为D。
