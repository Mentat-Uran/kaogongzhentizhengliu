# 语义关系-组成关系（同字嵌套'X中X'格式辨析）

考点：[[20-考点/判断推理/类比推理/语义关系-组成关系（同字嵌套'X中X'格式辨析）|类比推理 / 语义关系-组成关系（同字嵌套'X中X'格式辨析）]]


**问法模型**：题干给出'单字：X中X'式同字嵌套词组找同类 → 先比对构词格式（同字出现次数与位置），再辨析重复两字之间的逻辑关系（组成/并列）

## 推理链
1. 第1步：题干'园中园'中两个'园'字均指园子，且'园中园'是园中之园，第二个'园'嵌套于第一个'园'内部
2. 第2步：归纳题干双重规律——①构词格式为'X中X'（同一字出现两次）；②两个'园'之间是组成关系（包含嵌套）而非并列
3. 第3步：逐项对照——A项'楼外楼'同字出现两次但两'楼'是并列关系（楼外另有一楼），非组成关系
4. 第4步：B项'梦中人'、C项'水中月'中'人''月'均只出现一次，格式与'园中园'不对应，直接排除
5. 第5步：D项'画中画'两个'画'均指画，'画中画'是画中之画，两'画'为组成关系且同字出现两次，与题干双重规律完全一致，当选

**最快解法**：⚡ 格式比对法+关系辨析：先用'同字出现次数'排除B、C（'梦中人''水中月'仅出现一次目标字），再对比A与D——'外'表并列延展、'中'表内部包含，题干'园中园'用'中'为组成关系，故选与'中'结构一致的D

## 易错点
- ⚠ 被'楼外楼'与'园中园'表面格式相似迷惑，忽略'外'与'中'方向相反，两'楼'是并列而非组成关系
- ⚠ 忽略格式比对，未发现B、C项中心字只出现一次，与'园中园'同字两次的结构不对应
- ⚠ 混淆组成关系与并列关系：组成关系是嵌套包含（园中之园），并列关系是同层并列（楼外之楼）

## 母题抽象
> 🧩 当题干出现'单字：X中X'式同字嵌套词组时，用格式比对法先核同字出现次数与位置，再用'中（组成/包含）'与'外（并列/延展）'等方位字判断重复两字间关系，选双重规律均一致者

**同类特征**：同字嵌套格式'X中X'、重复字均指同一事物、两同字为组成关系（内部包含）、构词格式与逻辑关系双重对应、类比推理-词组结构辨析

### 题干
园：园中园

### 选项
- A. 楼：楼外楼
- B. 人：梦中人
- C. 月：水中月
- D. 画：画中画　✅

### 官方解析
第一步：分析题干词语间逻辑关系。
“园”同“园中园”的园都指园子，且“园中园”是园中之园,两个“园”之间是组成关系。
第二步：判断选项词语间逻辑关系。
A项：“楼”和“楼外楼”所指楼相同，但“楼外楼”中的两个“楼”是并列关系，不是组成关系，不符合题干的逻辑关系，排除；
B项：“人”和“梦中人”所指相同，但“梦中人”只出现一个“人”，跟“园中园”的格式不对应，不符合题干的逻辑关系，排除；
C项：“月”和“水中月”所指相同，但“水中月”只出现一个“月”跟“园中园”的格式不对应,不符合题干的逻辑关系，排除；
D项：“画”和“画中画”都指画，且“画中画”是画中之画，两个“画”之间是组成关系，符合题干的逻辑关系，当选。
故正确答案为D。
