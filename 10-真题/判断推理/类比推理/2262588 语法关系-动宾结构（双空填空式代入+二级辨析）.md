# 语法关系-动宾结构（双空填空式代入+二级辨析）

考点：[[20-考点/判断推理/类比推理/语法关系-动宾结构（双空填空式代入+二级辨析）|类比推理 / 语法关系-动宾结构（双空填空式代入+二级辨析）]]


**问法模型**：题干为'X 对于 （ ）相当于（ ） 对于 Y'双空填空式 → 逐一代入选项，检验代入后前后两组词项的关系类型是否一致，多项一致时再做二级辨析择优

## 推理链
1. 第1步：题干为两空填空式类比，需将选项两个词分别代入，构成'培养+第一词'与'第二词+成绩'两组搭配
2. 第2步：代入后逐一判定每组词项间的关系：语法关系（动宾）还是语义关系（近义/对应）
3. 第3步：A项'培养能力'为动宾，'提高成绩'为动宾，前后一致；B项'培养—培育'为近义词，'分数—成绩'为评判标准的对应关系，不一致；C项'培养兴趣'为动宾，'获得成绩'为动宾，表面一致；D项'培养—提高'无必然关系，'绩效—成绩'为近义词，不一致，排除B、D
4. 第4步：A、C同为动宾，进入二级辨析：'培养'与'提高'均含'使对象逐步变好'的过程性，'获得'只强调直接取得结果，故'提高成绩'与'培养能力'的过程性对应更一致，当选A

**最快解法**：⚡ 代入法+造句验证：将各选项代入造短语'培养X'与'X成绩'，先用'动宾关系'排除B（近义+对应）、D（无关系+近义），再对A、C做二级辨析——'提高成绩'与'培养能力'同为过程性动宾，'获得成绩'偏结果性，锁定A

## 易错点
- ⚠ A、C均能构成动宾搭配，只验证到'动宾'一层就误选C，缺了'过程性vs结果性'的二级辨析
- ⚠ 把'分数—成绩'误判为近义词，实际是'评判标准'的对应关系，误排除/误选B
- ⚠ 忽略代入后的语序搭配方向：第二空必须与'成绩'构成动宾（X成绩），读错方向会把关系判反

### 题干
培养 对于 （    ） 相当于 （    ） 对于 成绩

### 选项
- A. 能力  提高　✅
- B. 培育  分数
- C. 兴趣  获得
- D. 提高  绩效

### 官方解析
逐一代入选项。
A项：培养能力，二者为语法关系中的动宾关系；提高成绩，二者为语法关系中的动宾关系，前后逻辑关系一致，保留；
B项：培养和培育，二者为近义词关系；分数是评判成绩好坏的标准，二者为对应关系，前后逻辑关系不一致，排除；
C项：培养兴趣，二者为语法关系中的动宾关系；获得成绩，二者为语法关系中的动宾关系，前后逻辑关系一致，保留；
D项：培养和提高，二者没有必然的关系；绩效指成绩、成效，绩效和成绩二者为近义词关系，前后逻辑关系不一致，排除。
对比A、C两项，培养和提高都存在一个过程，而获得成绩只是拥有成绩，更偏重直接获得结果，相比较而言，A项的前后逻辑关系更为一致，当选。
故正确答案为A。
