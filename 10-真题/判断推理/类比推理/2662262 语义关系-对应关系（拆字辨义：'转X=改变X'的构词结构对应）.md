# 语义关系-对应关系（拆字辨义：'转X=改变X'的构词结构对应）

考点：[[20-考点/判断推理/类比推理/语义关系-对应关系（拆字辨义：'转X=改变X'的构词结构对应）|类比推理 / 语义关系-对应关系（拆字辨义：'转X=改变X'的构词结构对应）]]


**问法模型**：题干给出一对名词性词组，判断词项间逻辑关系 → 拆字造句法：验证'首字动作+尾字对象'是否构成相同语义结构

## 推理链
1. 第1步：题干'转念'释义为'改变主意'，'转'取'改变'义，'念'对应'主意'，二者是'动作-被改变对象'的对应关系
2. 第2步：确定验证规则——拆字造句：合格选项须满足'转X = 改变X'的语义结构
3. 第3步：逐项代入：A项'转述'是把别人的话传给别人，不是'改变说话'，结构不符；B项'转交物品'是动宾关系且'转交'不含'改变'义；D项'转录'与'翻译'是基因表达的两个并列过程，为并列关系
4. 第4步：C项'转向'释义为'改变方向'，与'转念=改变主意'结构完全一致，与题干逻辑关系相同，当选

**最快解法**：⚡ 拆字造句法：将各词代入'改变X'模板——转念=改变主意✓，转述=改变说话✗，转向=改变方向✓，仅C与题干同构，直接锁定

## 易错点
- ⚠ A项被字面'转'字迷惑，误以为'转述'含'改变'义，实际'转'在此取'传达/转告'义，属同字异义干扰
- ⚠ B项误将'转交：物品'判为与'转念：主意'相同的对应关系，忽略'转交'是'转送'而非'改变'，且整体为动宾结构
- ⚠ D项'转录：翻译'是生物学术语，看似专业高级易误选，实为并列关系而非对应关系

## 母题抽象
> 🧩 当题干出现'单字动词+单字名词'的复合词对且首字为多义字（如'转'）时，先拆字释义确定语义结构（'转X=改变X'），再用造句法逐项验证，警惕同字不同义的干扰项

**同类特征**：两字词对：转念：主意、首字'转'为多义字，需拆字辨义、对应关系而非动宾/并列、'改变+对象'构词结构、选项含同前缀词组与专业术语干扰

### 题干
转念：主意

### 选项
- A. 转述：说话
- B. 转交：物品
- C. 转向：方向　✅
- D. 转录：翻译

### 官方解析
第一步：判断题干词语间逻辑关系。
转念是指改变主意，二者是对应关系。
第二步：判断选项词语间逻辑关系。
A项：转述是指把别人说的话说给另外的人，并不是改变说话，与题干逻辑关系不一致，排除；
B项：转交物品为动宾关系，与题干逻辑关系不一致，排除；
C项：转向是指改变方向，二者是对应关系，与题干逻辑关系一致，当选；
D项：转录和翻译是蛋白质生物合成中基因表达的两个过程，二者是并列关系，与题干逻辑关系不一致，排除。
故正确答案为C。
