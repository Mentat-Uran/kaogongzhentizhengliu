# 逻辑关系-交叉关系

考点：[[20-考点/判断推理/类比推理/逻辑关系-交叉关系|类比推理 / 逻辑关系-交叉关系]]


**问法模型**：题干给出两个词项问逻辑关系一致的一组 → 先用'有的A是B，有的A不是B'句式判定题干关系类型，再逐项同法验证

## 推理链
1. 第1步：题干'党员'与'学生'是两种身份集合，个体可同时兼具（有的党员是学生，有的党员不是学生；有的学生是党员，有的学生不是党员）
2. 第2步：判定题干为交叉关系，用'有的A是B，有的A不是B'双重句式做验证标尺
3. 第3步：逐项对照——A项排球与篮球是并列关系；B项货轮是轮船按用途分出的一种，为种属关系；D项照相可能用到胶卷，为对应关系
4. 第4步：C项演员与歌手满足'有的演员是歌手，有的演员不是歌手；有的歌手是演员，有的歌手不是演员'，与题干同为交叉关系，当选

**最快解法**：⚡ 造句法：对题干和各选项统一套用'有的A是B，有的A不是B'句式，仅C项双向造句通顺且存在兼具个体的可能，直接锁定C

## 易错点
- ⚠ B项易误判为交叉：货轮是轮船的一个种类（种属），并非部分轮船兼具货轮身份之外另有交集概念
- ⚠ A项并列关系与交叉关系混淆：排球、篮球互斥不兼容，而交叉关系要求个体可兼具两种身份
- ⚠ D项误把'照相会用到胶卷'当成关系相近而忽略其为功能对应关系而非集合关系

## 母题抽象
> 🧩 当题干两词均为身份/职业/属性类名词且个体可同时兼具时，用'有的A是B且有的A不是B'句式验证交叉关系；种属关系只能单向造句'所有B都是A'，并列关系个体互斥，对应关系是用途/工具等外延联系

**同类特征**：两词型类比推理、身份类名词、个体可兼具双重身份、有的A是B句式、交叉关系辨析、与并列/种属/对应关系的区分

### 题干
党员：学生

### 选项
- A. 排球：篮球
- B. 轮船：货轮
- C. 演员：歌手　✅
- D. 照相：胶卷

### 官方解析
第一步：判断题干词语间逻辑关系。
党员与学生二者为交叉关系，有的党员是学生，有的党员不是学生，有的学生是党员，有的学生不是党员。
第二步：判断选项词语间逻辑关系。
A项：排球与篮球二者为并列关系，与题干逻辑关系不一致，排除；
B项：轮船是指所有大的，机动推进的船只，而货轮是按船舶用途分类出来的一种船，二者是种属关系，不是交叉关系，与题干逻辑关系不一致，排除；
C项：演员与歌手二者为交叉关系，有的演员是歌手，有的演员不是歌手，有的歌手是演员，有的歌手不是演员，与题干逻辑关系一致，当选；
D项：照相时候可能会用到胶卷，二者是对应关系，不是交叉关系，与题干逻辑关系不一致，排除。
故正确答案为C。
