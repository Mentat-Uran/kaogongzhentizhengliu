# 对应关系-时间顺承＋主体数量辨析

考点：[[20-考点/判断推理/类比推理/对应关系-时间顺承＋主体数量辨析|类比推理 / 对应关系-时间顺承＋主体数量辨析]]


**问法模型**：题干给出'A：B：C'三个流程类动词判断逻辑关系 → 先验证时间顺承顺序是否严格，再核对动作发出主体的数量（一/二/三个）双重匹配

## 推理链
1. 第1步：题干三词呈先后链条：先'下单'、其次'付款'、然后被'送货'，'下单''付款'由消费者发出，'送货'由商家/快递方发出，共涉及两个主体
2. 第2步：提炼双重判定标准：①三词须严格按先后顺序发生；②动作主体须为两个（前两个动作同一主体、第三个动作换主体执行）
3. 第3步：A项'寄件：收件：派件'涉及寄件人、收件人、快递员三个主体，主体数量不符，排除
4. 第4步：B项'撰稿：改稿：投稿'三个动作均由作者一人完成，仅一个主体，排除
5. 第5步：C项'耕地：施肥：播种'中'施肥'与'播种'无严格先后顺序，且均为农民一个主体，双重不符，排除
6. 第6步：D项'复习：考试：阅卷'中'复习''考试'由考生完成、'阅卷'由老师完成，顺序严格且恰为两个主体，与题干一致，当选

**最快解法**：⚡ 顺承＋主体数双重排除法：先用'施肥与播种无严格先后'排除C，再数主体数量——A为三个、B为一个、D为两个，题干为两个主体，直接锁定D

## 易错点
- ⚠ 只验证时间顺承而忽略主体数量：A项'寄件：收件：派件'顺序读起来也通顺，极易误选A
- ⚠ 误把题干拆成消费者、商家、快递员三个主体，与官方'两个主体'的判定基准不符
- ⚠ 忽略C项'施肥'与'播种'无严格先后顺序这一细节，仅凭'都是农活'误判为顺承

## 母题抽象
> 🧩 当题干三个词是同一条流程中的先后动作时，用'顺承＋主体数'双筛法：先核对动作先后是否严格有序，再数动作发出者的个数（一/二/三个），两项全部一致者才当选

**同类特征**：三个动词呈先后顺承、同一动作链中第三个动作换主体、涉及两个主体、流程类场景（购物/考试）、需数主体数量辨析

### 题干
下单：付款：送货

### 选项
- A. 寄件：收件：派件
- B. 撰稿：改稿：投稿
- C. 耕地：施肥：播种
- D. 复习：考试：阅卷　✅

### 官方解析
第一步：判断题干词语间逻辑关系。
先“下单”，其次“付款”，然后被“送货”，共涉及两个主体。
第二步：判断选项词语间逻辑关系。
A项：先“寄件”，其次“收件”，然后“派件”，先后顺序正确，但是共涉及三个主体，与题干逻辑关系不一致，排除；
B项：先“撰稿”，其次“改稿”，然后“投稿”，先后顺序正确，但共涉及一个主体，与题干逻辑关系不一致，排除；
C项：先“耕地”，“施肥”和“播种”没有严格的先后顺序，并且共涉及一个主体，与题干逻辑关系不一致，排除；
D项：先“复习”，其次“考试”，最后“阅卷”，共涉及两个主体，与题干逻辑关系一致，当选。
故正确答案为D。
