# 填空式类比-代入验证；对应关系-活动（过程）与产物

考点：[[20-考点/判断推理/类比推理/填空式类比-代入验证；对应关系-活动（过程）与产物|类比推理 / 填空式类比-代入验证；对应关系-活动（过程）与产物]]


**问法模型**：'A对于（ ）相当于（ ）对于B'的填空问法 → 采用逐项代入法，将选项词填入空格，检验前后两组逻辑关系是否同类型、同方向

## 推理链
1. 第1步：题干为填空式类比'龙葵碱 对于 （ ）相当于 （ ）对于 面团发酵'，需将选项两词分别代入前后空，比较两组关系是否一致
2. 第2步：先分析已知词项——'龙葵碱'是茄科植物（如发芽土豆）中产生的毒素，'面团发酵'是酵母等微生物的代谢过程，二者都指向'过程—产物'这一候选关系
3. 第3步：代入B项：'土豆发芽'产生'龙葵碱'，'面团发酵'过程中酵母代谢产生'二氧化碳'，前后均为'活动（过程）与其产物'的对应关系，方向一致
4. 第4步：代入A项排除：'芝麻开花'是植株生长阶段，与'龙葵碱'无明显逻辑关系；'无氧呼吸'是'面团发酵'的方式/过程而非产物，前后不一致
5. 第5步：代入C项排除：'冬瓜落霜'与'龙葵碱'无明显关系；'线粒体'是酵母菌的细胞器，与'面团发酵'是组成/场所对应而非产物对应
6. 第6步：代入D项排除：'香蕉成熟'与'龙葵碱'无明显关系；'葡萄糖'是发酵的底物（被消耗的原料）而非产物，与'面团发酵'的关系方向不符
7. 第7步：只有B项前后两组均为'过程→产物'的同向对应，故正确答案为B

**最快解法**：⚡ 代入法+关系方向校验：优先代入B——'土豆发芽产生龙葵碱'与'面团发酵产生二氧化碳'同为'过程→产物'，前后一致直接锁定；其余选项只需发现前空与'龙葵碱'无产物关系或后空为方式/原料即可快速排除

## 易错点
- ⚠ A项'无氧呼吸'与面团发酵确有联系（发酵属于无氧呼吸过程），但它是'方式/过程'对应而非'产物'对应，勿因后半组看似合理而误选
- ⚠ D项'葡萄糖'是发酵的底物（被消耗的原料），不是产物，'原料'与'产物'方向相反是高频陷阱
- ⚠ 填空式类比必须前后两组关系同时同类型同向，只验证一组就下结论易出错

## 母题抽象
> 🧩 当类比题以'A对于（ ）相当于（ ）对于B'的填空形式出现时，用代入法将选项填空，验证前后两组是否构成同类型、同方向的对应关系（如过程—产物、原料—成品），仅一组匹配即可排除该项

**同类特征**：填空式'相当于'问法、代入验证前后关系一致、活动（过程）与产物的对应关系、生物/生活常识词汇、龙葵碱—发芽土豆、面团发酵—二氧化碳

### 题干
龙葵碱 对于 （    ） 相当于 （    ） 对于 面团发酵

### 选项
- A. 芝麻开花；无氧呼吸
- B. 土豆发芽；二氧化碳　✅
- C. 冬瓜落霜；线粒体
- D. 香蕉成熟；葡萄糖

### 官方解析
逐一代入选项。
A项：“芝麻开花”是芝麻植株生长的一个自然阶段，与“龙葵碱”无明显逻辑关系；“无氧呼吸”是“面团发酵”过程中酵母等微生物所采用的一种生理过程，二者为对应关系，前后逻辑关系不一致，排除；
B项：“土豆发芽”会产生“龙葵碱”，二者为活动与其产物的对应关系；“面团发酵”过程中酵母等微生物代谢会产生“二氧化碳”，二者为活动与其产物的对应关系，前后逻辑关系一致，当选；
C项：“冬瓜落霜”是指冬瓜在成熟的时候，表面会生出一层白霜，和“龙葵碱”无明显逻辑关系；“线粒体”是酵母菌的细胞器，酵母菌可以用来“面团发酵”，二者为对应关系，前后逻辑关系不一致，排除；
D项：“香蕉成熟”与“龙葵碱”无明显逻辑关系；“葡萄糖”是“面团发酵”过程中酵母进行发酵作用的重要能量来源和底物，二者为对应关系，前后逻辑关系不一致，排除。
故正确答案为B。
