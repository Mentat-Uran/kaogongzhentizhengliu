# 对应关系-场所与行为（生产活动）

考点：[[20-考点/判断推理/类比推理/对应关系-场所与行为（生产活动）|类比推理 / 对应关系-场所与行为（生产活动）]]


**问法模型**：'A 之于（ ）相当于 C 之于（ ）'两空填词式类比 → 逐项代入选项，用统一句式造句，验证前后两组词的逻辑关系是否同构一致

## 推理链
1. 第1步：从题干提取核心词项——'草原'与'海洋'均为自然场所（空间地点），所填词须分别与二者构成同一种对应关系
2. 第2步：所用规则——代入法+造句法：将每个选项的两个词分别代入两空，用同一句式'在（场所）……'造句，比较前后关系的类型与方向是否一致
3. 第3步：逐项对照：A项'在草原放牧''在海洋捕捞'均为场所与人类生产活动的对应，且放牧、捕捞同为生产活动，前后一致；B项虫草一般生长在高原，'草原—虫草'无明确关系，而'海洋—鱼群'是场所与生物，前后不一致；C项'草原—羊群'是生存场所与生物，'海洋—水手'是工作场所与职业，一为生物一为职业，关系不同构；D项'草原—牧羊犬'是场所与生物的应用关系，'海洋—指南针'是场所与工具的应用关系，生物与工具类别不同，不一致
4. 第4步：对照选项结论：仅A项前后均为'场所与人类生产活动（行为）'的同构对应，故选A

**最快解法**：⚡ 代入造句法：用统一句式'在草原放牧 / 在海洋捕捞'一次验证A项即成立；其余选项按'场所+对象'造句时前后句式无法统一（虫草不生于草原、羊群是生物而水手是职业、牧羊犬是生物而指南针是工具），直接排除

## 易错点
- ⚠ B项被'海洋—鱼群'的场所与生物关系迷惑，忽略前半句'草原—虫草'关系本身不成立（虫草长在高原）
- ⚠ C项粗看都是'场所与某对象'，未做二级辨析：羊群是生物、水手是职业，关系类别不同
- ⚠ D项误把牧羊犬与指南针都当作'在场所中起作用的辅助对象'，忽略生物与工具的类别差异及词项方向不一致

### 题干
草原 之于（  ）相当于 海洋 之于（  ）

### 选项
- A. 放牧——捕捞　✅
- B. 虫草——鱼群
- C. 羊群——水手
- D. 牧羊犬——指南针

### 官方解析
逐一代入选项。
A项：在草原进行放牧，草原和放牧是场所和行为的对应关系；在海洋进行捕捞，海洋和捕捞也是场所和行为的对应关系，且放牧和捕捞都是人类生产活动的一种，前后逻辑关系一致，当选；
B项：虫草一般生长在高原地区，草原和虫草无明显逻辑关系；海洋和鱼群为场所与生物的对应关系，前后逻辑关系不一致，排除；
C项：草原和羊群是生存场所与生物的对应关系；海洋和水手是工作场所与职业的对应关系，前后逻辑关系不一致，排除；
D项：牧羊犬可以在草原上帮助人们放牧，二者是生物与其应用场所的对应关系；在海洋航行也可以用指南针来指引方向，二者是应用场所与工具的对应关系，前后逻辑关系不一致，排除。
故正确答案为A。
