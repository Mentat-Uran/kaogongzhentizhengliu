# 逻辑关系-原材料对应+并列关系（复合关系位置对应）

考点：[[20-考点/判断推理/类比推理/逻辑关系-原材料对应+并列关系（复合关系位置对应）|类比推理 / 逻辑关系-原材料对应+并列关系（复合关系位置对应）]]


**问法模型**：三词类比给出'书：纸：笔'式词串→先拆出两两关系（中间词是首词的原材料、中间词与尾词并列），再要求选项三词关系及位置完全对应

## 推理链
1. 第1步：题干三词'书：纸：笔'，拆解两两关系——纸是制作书的原材料（纸→书为原材料对应），纸和笔均为文具，二者为并列关系。
2. 第2步：锁定双重关系及位置结构：第一词=成品，第二词=原材料，第二词与第三词并列，三词位置必须一一对应。
3. 第3步：逐项对照——A项'河：水：海'：水是河、海的组成部分而非原材料，河与海并列，关系错位；B项'饭：米：青菜'：米是做饭的原材料，米与青菜是并列的食材，与题干一致；C项'林：树：木'：树与木共同组成林，但组成无需加工，不是原材料关系；D项'枪：子弹：炮'：枪与炮并列，子弹与枪是配套使用关系，原材料关系缺失且位置错乱。
4. 第4步：仅B项同时满足'第二词是第一词的原材料＋第二词与第三词并列'，与题干逻辑关系一致，当选B。

**最快解法**：⚡ 造句法＋双重关系位置锁定：先给题干造句'纸做成书，纸和笔是并列文具'，代入验证B'米做成饭，米和青菜是并列食材'直接锁定；A、D用'水/子弹不是原材料'快速排除，C用'树组成林无需加工'排除。

## 易错点
- ⚠ 只验证并列关系、忽略原材料关系：A项河与海并列、D项枪与炮并列看似相似，但水是组成部分、子弹是配套使用，均非原材料。
- ⚠ C项易误判'树是林的原材料'：'组成/聚集'与'原材料需加工'不同，林由树天然聚集而成，无加工环节。
- ⚠ 忽略三词位置对应：类比推理要求关系位置一一对应，即使选项中出现相同关系（如枪炮并列），位置错乱也不可选。

## 母题抽象
> 🧩 当题干三词呈'成品：原材料：并列物'结构时，用造句法先确认'中间词加工成首词、中间词与尾词并列'的双重关系，再逐项验证关系类型与位置双重对应，排除只满足单一关系或位置错位的选项。

**同类特征**：三词类比、原材料对应、并列关系、成品与原料、关系位置一一对应、造句验证

### 题干
书：纸：笔

### 选项
- A. 河：水：海
- B. 饭：米：青菜　✅
- C. 林：树：木
- D. 枪：子弹：炮

### 官方解析
第一步：判断题干词语间的逻辑关系。
纸是书的原材料，纸和笔又是并列关系。
第二步：判断选项词语间的逻辑关系。
A项：河与海二者之间为并列关系，水是河、海的组成部分，与题干逻辑关系不符，排除；
B项：米是饭的原材料，米和青菜又是并列关系，与题干逻辑关系一致，当选；
C项：树和木共同组成了林，但是树和木无需经过加工形成林，与题干逻辑关系不符，排除；
D项：枪和炮为并列关系，子弹和枪为配套使用的关系，与题干逻辑关系不符，排除。
故正确答案为B。
