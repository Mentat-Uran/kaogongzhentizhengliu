# 填空式类比-两次代入验证（种属关系与对应关系辨析）

考点：[[20-考点/判断推理/类比推理/填空式类比-两次代入验证（种属关系与对应关系辨析）|类比推理 / 填空式类比-两次代入验证（种属关系与对应关系辨析）]]


**问法模型**：“按揭对于（ ）相当于（ ）对于促销”为填空式类比问法 → 应采用两次代入法，将每个选项分别代入两个括号，验证前后两组词项关系的类型与顺序是否一致

## 推理链
1. 第1步：题干为填空式，需将选项第一空与'按揭'、第二空与'促销'分别组成两组关系，先代入A项：'银行—按揭'与'商场—促销'，官方解析指出'在银行办理按揭''在商场进行促销'同为地点对应，但前者是'行为—地点'、后者是'地点—行为'，逻辑顺序相反，排除
2. 第2步：代入B项：'抵押—按揭'与'打折—促销'，按揭'以所购房屋或物品为抵押向银行贷款'，按揭需要抵押，二者为必要条件对应；打折是一种促销方式，为种属关系，前后关系类型不同，排除
3. 第3步：代入C项：'贷款—按揭'与'降价—促销'，按揭指'一种购房或购物的贷款方式'，按揭是贷款的一种，为种属关系；降价是一种促销方式，也是种属关系，且均为'前词是后词的下位概念'，顺序一致
4. 第4步：代入D项：'购房—按揭'与'商品—促销'，按揭是购房的一种方式，为方式目的对应；商品是促销的对象，为行为—对象对应，前后关系不一致，排除
5. 第5步：逐项对照后，只有C项前后两组均为同序种属关系，得出正确答案C

**最快解法**：⚡ 代入法+造句验证：把选项代入括号后造句——C项'按揭是一种贷款''降价是一种促销'两句句式一致、均成立；A项两句需调换语序才通顺（顺序相反），B、D两句句式明显不同，直接锁定C

## 易错点
- ⚠ B项干扰最强：'按揭需要抵押'易被误判为种属关系，实为必要条件对应，与'打折—促销'的种属关系类型不同
- ⚠ A项顺序陷阱：两组确实都是地点对应，但一个是'行为—地点'、一个是'地点—行为'，忽略逻辑顺序相反易误选A
- ⚠ 只验证一组关系就下结论：填空题必须两次代入、前后两组关系同类型且同顺序才可选

### 题干
按揭 对于 （    ） 相当于 （    ） 对于 促销

### 选项
- A. 银行 商场
- B. 抵押 打折
- C. 贷款 降价　✅
- D. 购房 商品

### 官方解析
A项：在银行办理按揭手续，二者为地点对应关系；在商场进行促销活动，二者为地点对应关系，但逻辑顺序相反，前后逻辑关系不一致，排除；
B项：按揭指一种购房或购物的贷款方式，以所购房屋或物品为抵押向银行贷款，然后分期偿还，按揭需要抵押，二者为必要条件对应关系；打折是一种促销方式，二者为种属关系，前后逻辑关系不一致，排除；
C项：按揭指一种购房或购物的贷款方式，以所购房屋或物品为抵押向银行贷款，然后分期偿还，按揭是一种贷款方式，二者为种属关系；降价是一种促销方式，二者为种属关系，前后逻辑关系一致，当选；
D项：按揭指一种购房或购物的贷款方式，以所购房屋或物品为抵押向银行贷款，然后分期偿还，按揭是购房的一种方式，二者为方式目的对应关系；对商品进行促销，商品是进行促销的对象，前后逻辑关系不一致，排除。
故正确答案为C。
