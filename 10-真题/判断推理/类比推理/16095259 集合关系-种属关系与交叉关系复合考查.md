# 集合关系-种属关系与交叉关系复合考查

考点：[[20-考点/判断推理/类比推理/集合关系-种属关系与交叉关系复合考查|类比推理 / 集合关系-种属关系与交叉关系复合考查]]


**问法模型**：三词类比，第一词明显是后两词的实例 → 用造句法判定'第一词是后两词（种属）+后两词部分重叠（交叉）'的组合关系，并要求选项关系位置逐一对应

## 推理链
1. 第1步：观察题干'手术机器人：医疗设备：高新装备'，造句'手术机器人是医疗设备''手术机器人是高新装备'，第一词与后两词均为种属关系
2. 第2步：再验后两词：'有的医疗设备是高新装备，有的不是；有的高新装备是医疗设备，有的不是'，'医疗设备'与'高新装备'为交叉关系
3. 第3步：A项：公办中学是事业单位的一种、也是教育机构的一种（第一词与后两词均为种属）；有的事业单位不是教育机构（如科研单位）、有的教育机构不是事业单位（如民办学校），后两词交叉，与题干逻辑完全一致
4. 第4步：B项：重大项目与在建工程是'有的…是…'的交叉关系，交叉位置在前两词而非后两词，与题干不符
5. 第5步：C项：耄耋老人（八九十岁老人）与健康老人同为交叉关系，第一词'耄耋老人'不必然是'健康老人'的种属，交叉位置同样错位，排除
6. 第6步：D项：管理成本与生产成本是并列关系，不存在种属+交叉的组合结构，排除，故选A

**最快解法**：⚡ 造句法+排除法：先造句锁定题干结构为'①第一词是第二词、②第一词是第三词、③第二三词交叉'；再逐项造句，B、C项交叉出现在前两词（位置错位），D项为并列关系，只有A三项关系同位置对应

## 易错点
- ⚠ 只验证第一词与后两词的种属关系，漏验后两词之间是否为交叉关系，导致误选或错排
- ⚠ 对交叉关系的位置不敏感：B、C项交叉关系出现在前两词，与题干'交叉在后两词'位置不符，需逐位对应而非笼统判断
- ⚠ 对'事业单位'外延把握不准，误以为所有事业单位都是教育机构（或反之），从而错排正确项A；另D项易误将'管理成本'当作'生产成本'的下位概念

## 母题抽象
> 🧩 当类比推理三词中第一词明显是后两词的实例（小类）时，用造句法依次验证'第一词是第二词/第三词'的种属方向和'有的第二词是第三词'的交叉方向，且三个关系在选项中的位置必须与题干逐一对应

**同类特征**：三词类比、种属关系与交叉关系复合、第一词是后两词的小类、后两词外延部分重叠、关系位置需逐一对应、逐项造句验证

### 题干
手术机器人：医疗设备：高新装备

### 选项
- A. 公办中学：事业单位：教育机构　✅
- B. 重大项目：在建工程：跨境设施
- C. 耄耋老人：健康老人：高龄老人
- D. 管理成本：人力成本：生产成本

### 官方解析
第一步：判断题干词语间逻辑关系。
手术机器人既是医疗设备，又是高新装备，第一词与后两词均是种属关系；有的医疗设备是高新装备，有的医疗设备不是高新装备，有的高新装备是医疗设备，有的高新装备不是医疗设备，后两词是交叉关系。
第二步：判断选项词语间逻辑关系。
A项：事业单位指接受国家或地方财政拨款，从事教育、科技、文化、卫生等活动，具备法人条件的社会服务组织。公办中学既是事业单位，又是教育机构，第一词与后两词均是种属关系；有的事业单位是教育机构，有的事业单位不是教育机构，有的教育机构是事业单位，有的教育机构不是事业单位，后两词是交叉关系，与题干逻辑关系一致，当选；
B项：有的重大项目是在建工程，有的重大项目不是在建工程，有的在建工程是重大项目，有的在建工程不是重大项目，前两词是交叉关系，与题干逻辑关系不一致，排除；
C项：耄耋老人指八九十岁的老人，有的耄耋老人是健康老人，有的耄耋老人不是健康老人，有的健康老人是耄耋老人，有的健康老人不是耄耋老人，前两词是交叉关系，与题干逻辑关系不一致，排除；
D项：管理成本与生产成本是并列关系，与题干逻辑关系不一致，排除。
故正确答案为A。
