# 三词型-种属关系+组成关系复合辨析（功能体现二级辨析）

考点：[[20-考点/判断推理/类比推理/三词型-种属关系+组成关系复合辨析（功能体现二级辨析）|类比推理 / 三词型-种属关系+组成关系复合辨析（功能体现二级辨析）]]


**问法模型**：三词依次给出，问逻辑关系最一致项 → 依次判定词1-词2、词2-词3两重关系，再对相似选项做第三重（功能体现）二级辨析

## 推理链
1. 第1步：题干'房屋是一种建筑'，词1与词2为种属关系（房屋⊂建筑）
2. 第2步：'房间是房屋的组成部分'，词2与词3为组成关系，且房屋通过房间体现作用，构成'种属+组成+功能体现'三重关系链
3. 第3步：A项'越野车是汽车的一种'（种属成立）、'车窗是越野车的组成部分'（组成成立），但越野车并非通过车窗体现作用，第三重不满足，排除
4. 第4步：B项'电视机是一种电器'（种属成立）、'屏幕是电视机的组成部分'（组成成立），且电视机通过屏幕体现作用，三重关系与题干完全一致
5. 第5步：C项'私立医院是一种医院'（种属成立），但'医生'与'私立医院'是职业与工作地点的对应关系而非组成关系，排除
6. 第6步：D项'盘子是一种餐具'（种属成立），但'筷子'与'盘子'同为餐具，二者是并列关系而非组成关系，排除
7. 第7步：逐项对照后仅B项三重关系全部吻合，故正确答案为B

**最快解法**：⚡ 造句法+排除法：先用模板句'X是Y的一种，Z是X的组成部分'快速排除C、D（医生非医院部件、筷子与盘子并列），再对A、B做二级辨析'是否通过第三词体现作用'，电视机通过屏幕体现作用、越野车不通过车窗体现作用，锁定B

## 易错点
- ⚠ A项前两重关系（种属+组成）与题干完全相同，只验证两重关系不做'功能体现'三级辨析会误选A
- ⚠ C项易把'医生属于医院的一员'误判为组成关系，实为职业与工作地点的对应关系
- ⚠ D项易因'筷子放在盘子上'的空间联想误判为组成关系，实为同属餐具的并列关系

## 母题抽象
> 🧩 当题干三词呈'A∶B∶C'且初步判定B是A的种、C是B的部分时，用'种属+组成+功能体现'三重造句验证；若多个选项前两重关系相同，必须检验C是否是B体现作用的核心部分（如屏幕之于电视机），以此二级辨析定答案

**同类特征**：三词型类比推理、第一重为种属关系、第二重为组成关系、整体通过部分体现作用、需三级功能辨析排除干扰项、两选项前两重关系相同

### 题干
建筑∶房屋∶房间

### 选项
- A. 汽车∶越野车∶车窗
- B. 电器∶电视机∶屏幕　✅
- C. 医院∶私立医院∶医生
- D. 餐具∶盘子∶筷子

### 官方解析
第一步：判断题干词语间逻辑关系。
房屋是一种建筑，二者是种属关系，房间是房屋的组成部分，二者是组成关系，且房屋通过房间体现作用。
第二步：判断选项词语间逻辑关系。
A项：越野车是汽车的一种，二者是种属关系，车窗是越野车的组成部分，二者是组成关系，但越野车并不是通过车窗体现作用，与题干逻辑关系不一致，排除；
B项：电视机是一种电器，二者是种属关系，屏幕是电视机的组成部分，二者是组成关系，且电视通过屏幕体现作用，与题干逻辑关系一致，当选；
C项：私立医院是一种医院，二者是种属关系，但医生与私立医院是职业与工作地点的对应关系，与题干逻辑关系不一致，排除；
D项：盘子是一种餐具，二者是种属关系，但筷子和盘子都是餐具，二者是并列关系，与题干逻辑关系不一致，排除。
故正确答案为B。
