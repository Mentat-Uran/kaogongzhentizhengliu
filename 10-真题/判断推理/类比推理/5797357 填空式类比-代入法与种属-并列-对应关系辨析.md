# 填空式类比-代入法与种属-并列-对应关系辨析

考点：[[20-考点/判断推理/类比推理/填空式类比-代入法与种属-并列-对应关系辨析|类比推理 / 填空式类比-代入法与种属/并列/对应关系辨析]]


**问法模型**：题干为'( )对于保险相当于航天飞机对于( )'的填空式类比 → 采用代入法，逐项将选项词代入空位，验证前后两半逻辑关系类型是否一致

## 推理链
1. 第1步：题干为填空式类比，两个空分别位于'保险'之前和'航天飞机'之后，需把选项两个词分别代入验证
2. 第2步：采用代入法+造句法，对每组选项分别判断'前词与保险'、'航天飞机与后词'的逻辑关系类型（种属/并列/对应）
3. 第3步：A项代入：银行是销售保险产品的渠道，为渠道对应关系；航天飞机与空间站都是航天器，为并列关系，前后不一致，排除
4. 第4步：B项代入：股票与保险无明显逻辑关系；航天飞机需要燃料，为对应关系，前后不一致，排除
5. 第5步：C项代入：医保是一种保险，为种属关系；航天飞机是一种航天器，为种属关系，前后一致，当选
6. 第6步：D项代入：保险与理财是方式目的对应关系；卫星可搭载航天飞机发射，非方式目的对应，前后不一致，排除

**最快解法**：⚡ 代入法：用造句'C（医保）是保险''航天飞机是航天器'快速验证，只有C项两句句式与关系类型完全一致；其余选项造句后关系类型明显不匹配即排除

## 易错点
- ⚠ A项：误将'银行与保险'当作种属或并列关系，实际是销售渠道的对应关系，与'航天飞机与空间站的并列关系'不一致
- ⚠ D项：误将'保险与理财的方式目的关系'与'卫星与航天飞机的关系'强行对应，后者实为搭载发射的对应关系
- ⚠ 未用代入法、仅凭词项熟悉度凭语感选择（如选B'股票'）而忽略前后关系类型是否一致

### 题干
（    ）对于 保险 相当于 航天飞机 对于 (    )

### 选项
- A. 银行  空间站
- B. 股票  燃料
- C. 医保  航天器　✅
- D. 理财  卫星

### 官方解析
逐一代入选项。
A项：银行是保险公司销售保险产品的一种渠道，二者构成对应关系；航天飞机是指能单独进行航天活动，也能往返于地面和空间站之间运送人员或物资、设备的航天器，空间站是一种在近地轨道长时间运行、可供多名航天员巡访、长期工作和生活的载人航天器，二者都是航天器，构成并列关系，前后逻辑关系不一致，排除；
B项：股票和保险无明显逻辑关系；航天飞机需要使用燃料，二者构成对应关系，前后逻辑关系不一致，排除；
C项：医保是一种保险，二者构成种属关系；航天飞机是一种航天器，二者构成种属关系，前后逻辑关系一致，当选；
D项：通过保险可以进行理财，二者构成方式目的的对应关系；卫星是指在围绕一颗行星轨道并按闭合轨道做周期性运行的天然天体，人造卫星一般亦可称为卫星，其可以搭载航天飞机发射到太空，二者不构成方式目的的对应关系，前后逻辑关系不一致，排除。
故正确答案为C。
