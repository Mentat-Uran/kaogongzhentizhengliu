# 全同关系（城市古今异名-古称对应）

考点：[[20-考点/判断推理/类比推理/全同关系（城市古今异名-古称对应）|类比推理 / 全同关系（城市古今异名/古称对应）]]


**问法模型**：'A对于（ ）相当于B对于（ ）'填空型类比 → 将选项逐一代入括号，用代入法验证前后两组词项逻辑关系是否完全一致

## 推理链
1. 第1步：题干为'合肥对于（ ）相当于南京对于（ ）'，合肥、南京均为今地名，括号处最可能填与其构成'城市—古称'全同关系的历史地名
2. 第2步：代入D项：'庐州是合肥的古称，建业是南京的古称'，前后两组均为全同关系，方向一致
3. 第3步：代入A项：邺城遗址在今河北临漳、河南安阳一带，与合肥无全同关系；汝南位于河南驻马店，与南京无全同关系，排除
4. 第4步：代入B项：合州是合肥的古称，前半组为全同关系；但柴桑是江西九江市辖区（原名九江县），并非南京古称，后半组断裂，排除
5. 第5步：代入C项：徽州今分属安徽省与江西省，并非合肥古称；会稽是绍兴的古称，与南京无全同关系，排除
6. 第6步：仅D项前后两组逻辑关系均为'城市—古称'的全同关系且完全一致，当选

**最快解法**：⚡ 代入法+全同关系验证：直接锁定D项'庐州—合肥''建业—南京'两组均为城市与古称的全同关系；最快排除陷阱项B——合州虽是合肥古称，但柴桑是九江古称而非南京古称

## 易错点
- ⚠ 只验证前半组就选B：'合州是合肥古称'确实成立，但代入法要求前后两组关系同时一致，柴桑对应九江而非南京
- ⚠ 被'徽州—安徽'地域联想干扰：合肥是安徽的省会，但徽州并非合肥的古称，地域关联不等于全同关系
- ⚠ 历史地名积累混淆：需辨析南京古称为建业/金陵/建康，九江古称为柴桑，绍兴古称为会稽，记忆错位易误选

### 题干
合肥 对于 （    ） 相当于 南京 对于 （    ）

### 选项
- A. 邺城：汝南
- B. 合州：柴桑
- C. 徽州：会稽
- D. 庐州：建业　✅

### 官方解析
逐一代入选项。
A项：邺城，古代著名都城，遗址范围包括今河北临漳县西（邺北城、邺南城遗址等）、河南安阳市北郊（曹操高陵等）一带，与合肥无明显逻辑关系；汝南，一般指汝南县，位于河南省驻马店市，与南京无明显逻辑关系，前后逻辑关系不一致，排除；
B项：历史上有多个合州，合肥的古称为合州，二者是全同关系；柴桑，原名九江县，为江西省九江市市辖区，与南京无明显逻辑关系，前后逻辑关系不一致，排除；
C项：徽州，为浙江省最早雏形唐末两浙道的组成部分，今徽州分属安徽省与江西省，与合肥无明显逻辑关系；会稽是绍兴的古称，与南京无明显逻辑关系，前后逻辑关系不一致，排除；
D项：庐州是合肥的古称，二者是全同关系；建业是南京的古称，二者是全同关系，前后逻辑关系一致，当选。
故正确答案为D。
