# 对应关系-指导者与被指导者（填空型代入验证）

考点：[[20-考点/判断推理/类比推理/对应关系-指导者与被指导者（填空型代入验证）|类比推理 / 对应关系-指导者与被指导者（填空型代入验证）]]


**问法模型**：填空式'（　）对于A相当于B对于（　）'问法 → 采用逐项代入法，把选项词分别代入前后两空，比较两组词项的逻辑关系类型及语序是否一致

## 推理链
1. 第1步：题干为填空式类比，需将选项词代入括号，形成'X对于演员'与'指挥对于Y'两组词项关系
2. 第2步：对每组代入后的词对造句，判定关系类型（种属关系/对应关系/主谓结构等）
3. 第3步：A项代入：'主演对于演员'为种属关系（主演是演员的一种），'指挥对于主唱'为指导者与被指导者关系，前后不一致
4. 第4步：B项代入：'导演对于演员'为指导者与被指导者关系（导演指导演员），'指挥对于乐手'亦为指导者与被指导者关系（指挥指导乐手），前后关系一致
5. 第5步：C项代入：'演出对于演员'为主谓结构（演员演出），'指挥对于演奏'中指挥并不承担演奏工作，即使造句'指挥演奏'语序也与题干相反，前后不一致
6. 第6步：D项代入：'主角对于演员'为种属关系，'指挥对于观众'为演出者与观众的对应关系，前后不一致；故选B

**最快解法**：⚡ 逐项代入造句法：将选项词代入两空分别造句，B项'导演指导演员/指挥指导乐手'两句句式与关系完全平行，直接锁定；其余三项前后关系类型（种属vs指导、主谓vs无关系、种属vs观众对应）均不平行，排除

## 易错点
- ⚠ A项'主唱'与'指挥'同属乐队角色，易误判为与'指挥-演员'关系平行，实际'主演-演员'是种属关系而'指挥-主唱'是指导关系，前后错位
- ⚠ C项只看'演出/演奏'字面相近而选错，忽略'指挥不承担演奏'及语序相反的问题
- ⚠ 填空式类比必须双向验证（前空关系+后空关系同时成立），只验证一侧易被干扰项迷惑

## 母题抽象

### 题干
（    ） 对于 演员 相当于 指挥 对于 （    ）

### 选项
- A. 主演；主唱
- B. 导演；乐手　✅
- C. 演出；演奏
- D. 主角；观众

### 官方解析
逐一代入选项。
A项：主演是演员的一种，二者为种属关系；指挥是指挥乐队或合唱队的人，指挥指导主唱，二者为指导者与被指导者的对应关系，前后逻辑关系不一致，排除；
B项：导演指导演员，二者为指导者与被指导者的对应关系；指挥是指挥乐队或合唱队的人，指挥指导乐手，二者为指导者与被指导者的对应关系，前后逻辑关系一致，当选；
C项：演员演出，二者为主谓结构；指挥是指挥乐队或合唱队的人，并不承担演奏工作，且即使造句为指挥演奏，词语的前后顺序也相反，前后逻辑关系不一致，排除；
D项：主角是演员的一种，二者为种属关系；指挥在观众面前进行表演，二者为演出者与观众的对应关系，前后逻辑关系不一致，排除。
故正确答案为B。
