# 对应关系-功能对应（修饰词语义角色辨析）

考点：[[20-考点/判断推理/类比推理/对应关系-功能对应（修饰词语义角色辨析）|类比推理 / 对应关系-功能对应（修饰词语义角色辨析）]]


**问法模型**：题干给出'名词：功能词组'的词项对，问哪一组逻辑关系一致 → 先造句判定题干关系类型，再逐项辨析各组对应的语义角色是否同为'功能'

## 推理链
1. 第1步：提取题干词项'消毒水：消毒'，造句'消毒水用来消毒'，'消毒'是'消毒水'的功能
2. 第2步：判定题干为功能对应关系，且从构词看'消毒'作定语修饰'水'，修饰语表示功能
3. 第3步：逐项验证修饰语的语义角色——A项'部队锅'因起源与部队物资相关得名，'部队'表来源；B项'橄榄球'外形类似橄榄，'橄榄'表形状；C项'葡萄酒'以葡萄为原料制成，'葡萄'表原材料
4. 第4步：D项'减脂餐'用来减脂，'减脂'表功能，且构词同为'功能+主体'偏正结构，与题干完全一致，当选

**最快解法**：⚡ 造句法+构词辨析：看'修饰语'表示什么——'X水/X餐/X酒'中前一成分若表示用途功能（消毒水用来消毒、减脂餐用来减脂）即为功能对应；快速排除'部队'（起源）、'橄榄'（形状）、'葡萄'（原材料）三类其他对应

## 易错点
- ⚠ 误将A项'部队锅'与'部队'看成功能或领属关系，实则'部队'表名称起源
- ⚠ 把C项'葡萄酒：葡萄'误判为与题干一致，忽略功能对应与原材料对应的区别
- ⚠ 只看词形相似（都含两字词）不看修饰语的语义角色，忽略'功能/材料/形状/来源'二级辨析

## 母题抽象
> 🧩 当类比题干为'X+主体名词：X'结构（如消毒水：消毒）时，先造句判定X的语义角色，在选项中找同为'功能'修饰的构词（原材料/形状/来源/功能二级辨析），选修饰角色一致者

**同类特征**：消毒水：消毒、功能对应关系、偏正构词'功能+主体'、造句'前者用来后者'、辨析来源/形状/原材料对应、两级关系对比排除

### 题干
消毒水：消毒

### 选项
- A. 部队锅：部队
- B. 橄榄球：橄榄
- C. 葡萄酒：葡萄
- D. 减脂餐：减脂　✅

### 官方解析
第一步：判断题干词语间逻辑关系。
消毒水具有消毒的功能，二者为功能对应关系。
第二步：判断选项词语间逻辑关系。
A项：部队锅是因其起源与部队物资相关而得名，二者不是功能对应关系，与题干逻辑关系不一致，排除；
B项：橄榄球的外形类似橄榄，二者不是功能对应关系，与题干逻辑关系不一致，排除；
C项：葡萄酒是以葡萄为原材料而制成的，二者为原材料对应关系，与题干逻辑关系不一致，排除；
D项：减脂餐具有减脂的功能，二者为功能对应关系，与题干逻辑关系一致，当选。
故正确答案为D。
