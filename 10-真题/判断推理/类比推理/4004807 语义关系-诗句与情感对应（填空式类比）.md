# 语义关系-诗句与情感对应（填空式类比）

考点：[[20-考点/判断推理/类比推理/语义关系-诗句与情感对应（填空式类比）|类比推理 / 语义关系-诗句与情感对应（填空式类比）]]


**问法模型**：诗句 对于 （） 相当于 （） 对于 情感词 的填空式类比 → 逐项代入，验证前后'诗句—所表达情感'关系是否一致

## 推理链
1. 第1步：题干两处空白前后给定要素为诗句'莫愁前路无知己'与情感词'感恩'，需判断诗句所表达的情感与所填词语的对应关系
2. 第2步：采用代入法，将各选项词语分别填入两空，检查'诗句—情感/事物'的前后逻辑关系是否一致
3. 第3步：A项代入：'莫愁前路无知己'表达朋友间离别之情，与'爱情'无对应；'恩疏媒劳志多乖'意为皇帝疏远、举荐徒劳、壮志难酬，虽含'恩'字但与'感恩'无对应，前后均不一致，排除
4. 第4步：B项代入：'莫愁前路无知己'与'场所'无对应；'千古兴亡多少事'表达怀古愁思感慨，与'感恩'无对应，前后均不一致，排除
5. 第5步：C项代入：'莫愁前路无知己'表达与朋友的'离别'之情，'报答平生未展眉'（'报答'二字点明感恩）表达'感恩'之情，前后均为'诗句—情感'对应关系，一致，当选
6. 第6步：D项代入：'莫愁前路无知己'可与'送别'对应，但'西出阳关无故人'表达的是与朋友的离别之情而非'感恩'，后半关系断裂，前后不一致，排除

**最快解法**：⚡ 代入法+关键词定位：先看右空，找能与'感恩'构成对应关系的诗句——'报答平生未展眉'中'报答'直接点明感恩，锁定C；再用首句'离别'之情验证C成立；最后用D排除法核对（'西出阳关无故人'表离别而非感恩）

## 易错点
- ⚠ C、D前空均能描述首句情感（离别/送别），仅凭前空无法排除D，必须验证后半句对应关系
- ⚠ A项'恩疏媒劳志多乖'字面含'恩'字，属字面陷阱，实际表达壮志难酬而非感恩
- ⚠ '报答平生未展眉'为悼亡诗语句，易误判为爱情主题而错选A，忽略其核心情感是'报答（感恩）'

### 题干
莫愁前路无知己 对于 （    ） 相当于 （    ） 对于 感恩

### 选项
- A. 爱情 恩疏媒劳志多乖
- B. 场所 千古兴亡多少事
- C. 离别 报答平生未展眉　✅
- D. 送别 西出阳关无故人

### 官方解析
逐一代入选项。
A项：“莫愁前路无知己”的意思是此去不要担心遇不到知己，表达了作者与朋友的离别之情，与“爱情”无明显逻辑关系；“恩疏媒劳志多乖”的意思是皇帝疏远，举荐徒劳，壮志难酬，与“感恩”无明显逻辑关系，前后逻辑关系不一致，排除；
B项：“莫愁前路无知己”的意思是此去不要担心遇不到知己，表达了作者与朋友的离别之情，与“场所”无明显逻辑关系；“千古兴亡多少事”的意思是从古到今，有多少国家兴亡大事呢，表达了作者怀古的愁思和感慨，与“感恩”无明显逻辑关系，前后逻辑关系不一致，排除；
C项：“莫愁前路无知己”的意思是此去不要担心遇不到知己，表达了作者与朋友的“离别”之情，二者为对应关系；“报答平生未展眉”的意思是报答你一生的愁苦奔忙，表达了“感恩”之情，二者为对应关系，前后逻辑关系一致，当选；
D项：“莫愁前路无知己”的意思是此去不要担心遇不到知己，表达了作者对朋友的“送别”之情，二者为对应关系；“西出阳关无故人”的意思是当你向西出了阳关后，就难以遇到故人了，表达了作者与朋友的离别之情，与“感恩”无明显逻辑关系，前后逻辑关系不一致，排除。
故正确答案为C。
