# 填空式类比-概念间关系辨析（交叉关系-种属关系-并列关系）

考点：[[20-考点/判断推理/类比推理/填空式类比-概念间关系辨析（交叉关系-种属关系-并列关系）|类比推理 / 填空式类比-概念间关系辨析（交叉关系/种属关系/并列关系）]]


**问法模型**：'A对于（）相当于（）对于B'填空式类比 → 逐项代入两空，分别定性前后两组概念间关系，选前后关系类型一致且同构的选项

## 推理链
1. 第1步：题干为填空式类比，两端词为'程序法'与'个人收入'，需将选项两词分别代入两空，验证'程序法：（第一词）'与'（第二词）：个人收入'的关系是否一致
2. 第2步：方法为代入法+概念间关系定性（全同/种属/交叉/并列/全异），关键口诀'有的A是B且有的A不是B，即为交叉关系'
3. 第3步：A项代入：程序法与成文法是交叉关系（有的程序法是成文法，有的成文法不是程序法），而企业收入与个人收入是并列关系，前后不一致，排除
4. 第4步：B项代入：经济法属实体法而非程序法，与程序法为全异（反向包容）关系，而劳动收入是个人收入的一种，为种属关系，全异对种属，前后不一致，排除
5. 第5步：C项代入：诉讼法是程序法的一种，为种属关系；而合法收入与个人收入是交叉关系（有的合法收入不是个人收入，如企业的合法收入），种属对交叉，前后不一致，排除
6. 第6步：D项代入：有的程序法是国内法、有的不是，二者为交叉关系；有的投资收入是个人收入、有的个人收入不是投资收入，二者也为交叉关系，交叉对交叉，前后一致，当选

**最快解法**：⚡ 代入法+关系定性口诀'能是能不是即交叉'：快速判定第一空与'程序法'的关系——诉讼法是种属、经济法是全异、成文法和国内法是交叉；再判定第二空与'个人收入'的关系——企业收入并列、劳动收入种属、合法收入和投资收入是交叉；只有D项前后同为交叉关系，直接锁定

## 易错点
- ⚠ C项陷阱：误以为'合法收入'自然属于'个人收入'而看成种属对应，忽略企业也有合法收入，二者实为交叉关系，与第一空'诉讼法⊂程序法'的种属关系不对应
- ⚠ B项陷阱：只看到'经济法'和'劳动收入'都与分析对象相关（法律/收入领域），未识别'经济法属实体法、与程序法全异'与'劳动收入⊂个人收入种属'的关系错位
- ⚠ 只验证第二空、忽略第一空，或凭'都是法律词、都是收入词'的表面语感选B/C，未做严格的关系类型对照

## 母题抽象
> 🧩 当题干出现'A对于（）相当于（）对于B'的填空式类比时，用逐项代入法，对前后两组概念分别做关系定性（全同/种属/交叉/并列/全异），只有关系类型相同且方向一致的选项当选

**同类特征**：填空式（对当式）类比、左侧为法律概念（程序法/成文法/经济法/诉讼法/国内法）、右侧为经济概念（个人收入/企业收入等）、核心辨析交叉关系与种属关系、前后逻辑关系一致性验证、多概念身份叠加（如'国内法'同时涉及法的渊源与适用范围）

### 题干
程序法 对于 （    ） 相当于 （    ） 对于 个人收入

### 选项
- A. 成文法：企业收入
- B. 经济法：劳动收入
- C. 诉讼法：合法收入
- D. 国内法：投资收入　✅

### 官方解析
逐一代入选项。
A项：“程序法”是以保证权利和义务得以实施或职权和职责得以履行的有关程序为主的法律，如民事诉讼法、刑事诉讼法、行政诉讼法等，“成文法”是由国家特定机关制定和公布，并以成文形式出现的法律，又称制定法。有的程序法是成文法，有的程序法不是成文法，有的成文法是程序法，有的成文法不是程序法，二者为交叉关系；企业收入和个人收入是两种不同的收入，二者为并列关系，前后逻辑关系不一致，排除；
B项：“经济法”是调整国家宏观经济管理过程中所发生的社会关系的法律规范的总称，经济法是实体法，不是程序法，二者为反向包容关系；“劳动收入”是指各类劳动者通过劳动获得的各种报酬，劳动收入是个人收入，二者为种属关系，前后逻辑关系不一致，排除；
C项：“诉讼法”指规定诉讼活动的法律规范的总称，诉讼法是程序法，二者为种属关系；有的合法收入是个人收入，有的合法收入不是个人收入，有的个人收入是合法收入，有的个人收入不是合法收入，二者为交叉关系，前后逻辑关系不一致，排除；
D项：有的程序法是国内法，有的程序法不是国内法，有的国内法是程序法，有的国内法不是程序法，二者为交叉关系；有的投资收入是个人收入，有的投资收入不是个人收入，有的个人收入是投资收入，有的个人收入不是投资收入，二者为交叉关系，前后逻辑关系一致，当选。
故正确答案为D。
