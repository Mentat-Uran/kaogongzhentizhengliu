# 逻辑关系-种属关系（种属+限定构成的偏正结构'A是C的B'）

考点：[[20-考点/判断推理/类比推理/逻辑关系-种属关系（种属+限定构成的偏正结构'A是C的B'）|类比推理 / 逻辑关系-种属关系（种属+限定构成的偏正结构'A是C的B'）]]


**问法模型**：三词型类比：先确定题干两两关系并整体造句验证，再在选项中寻找同构关系（'叔侄是一种血亲关系'的结构需完整复现）

## 推理链
1. 第1步：分析题干——'叔侄'是人与人之间的一种'关系'，'血亲'限定关系的种类（区别于姻亲等），可造句'叔侄是一种血亲关系'，三词构成种属+限定结构
2. 第2步：确定方法——用造句法提取'A是C的B'（首词是尾词所限定的中间词的一种）这一整体结构，逐项比对
3. 第3步：A项造句'银河是一种宇宙'不成立，银河和恒星都是宇宙的组成部分，为组成关系而非种属关系，排除
4. 第4步：B项中姑嫂与家庭为组成关系（姑嫂是家庭的成员），且'家庭'并非对'亲人'种类的限定，结构断裂，排除
5. 第5步：C项中课堂、书本是获取知识的载体，与'知识'为载体对应关系，排除
6. 第6步：D项中'抑郁'是一种'疾病'，'心理'限定疾病种类，造句'抑郁是一种心理疾病'，与题干'A是C的B'结构完全一致，当选

**最快解法**：⚡ 造句法+排除法：先对题干造句'叔侄是一种血亲关系'锁定'种属+限定'结构，再逐项造句验证，仅D项'抑郁是一种心理疾病'结构同构，直接锁定D

## 易错点
- ⚠ B项迷惑性强：误以为'姑嫂是一种亲人'构成种属关系就选B，忽略第三个词'家庭'不是对'亲人'种类的限定（整体结构不成立，且姑嫂与家庭是组成关系）
- ⚠ A项偷换概念：把组成关系（部分与整体）误当种属关系，'银河是宇宙的一部分'不等于'银河是一种宇宙'
- ⚠ 只验证相邻两词关系、忽略三词整体造句：必须验证首尾词构成的限定结构'A是C的B'是否同时成立

## 母题抽象
> 🧩 当三词型类比题干满足'中间词是属概念，且首词+尾词可造句A是C的B（首词是尾词限定下中间词的一种）'时，用造句法在选项中寻找同构的种属+限定（偏正）关系，警惕组成关系和载体对应关系的干扰项

### 题干
叔侄：关系：血亲

### 选项
- A. 银河：恒星：宇宙
- B. 姑嫂：亲人：家庭
- C. 课堂：知识：书本
- D. 抑郁：疾病：心理　✅

### 官方解析
第一步：判断题干词语间逻辑关系。
叔侄是一种关系，血亲是关系种类的限定，三者之间存在种属关系。
第二步：判断选项词语间逻辑关系。
A项：银河和恒星都是宇宙的一部分，银河和恒星分别与宇宙为组成关系，与题干逻辑关系不一致，排除；
B项：姑嫂是家庭的一部分，二者为组成关系，与题干逻辑关系不一致，排除；
C项：课堂和书本都是获取知识的载体，课堂和书本分别与知识为载体对应关系，与题干逻辑关系不一致，排除；
D项：抑郁是一种疾病，心理是疾病种类的限定，三者之间存在种属关系，与题干逻辑关系一致，当选。
故正确答案为D。
