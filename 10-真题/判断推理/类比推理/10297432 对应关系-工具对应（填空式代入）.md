# 对应关系-工具对应（填空式代入）

考点：[[20-考点/判断推理/类比推理/对应关系-工具对应（填空式代入）|类比推理 / 对应关系-工具对应（填空式代入）]]


**问法模型**：'A 对于 （）相当于 （） 对于 B'填空式问法 → 逐项代入，验证前后两组词的逻辑关系类型及词序方向是否一致

## 推理链
1. 第1步：题干为填空式结构，固定词为'健身'与'眼罩'，需代入选项使'健身：（）'与'（）:眼罩'两组关系同构
2. 第2步：采用逐项代入法，对每组词造句判断关系类型（功能/种属/原材料/工具），并额外检查词语先后方向
3. 第3步：A项代入：'运动'有'健身'的作用（功能对应），而'口罩'与'眼罩'是并列的两种用具，前后不一致，排除
4. 第4步：B项代入：'健身'有'增肌'的作用（功能对应），'眼罩'有'遮光'的作用（功能对应），但前组是'主体词→功能'，后组是'功能→主体词'，词序相反，排除
5. 第5步：C项代入：'健步走'是一种'健身'（种属关系），'丝绸'是'眼罩'的原材料（原材料与成品对应），前后不一致，排除
6. 第6步：D项代入：'健身'时可能会用到'跑步机'（工具对应），'睡眠'时可能会用到'眼罩'（工具对应），关系类型与词序方向均一致，当选

**最快解法**：⚡ 逐项代入+造句法：统一用'做X的时候可能会用到Y'句式造句，只有D项两句同构（健身用跑步机、睡眠用眼罩），且B项功能对应因词序相反可先排除

## 易错点
- ⚠ B项前后都是功能对应，只比关系类型不看词序方向（'健身→增肌'与'遮光→眼罩'方向相反）而误选
- ⚠ 忽略'可能用到'的或然对应，纠结'跑步机/眼罩是否为必需工具'而排除D项
- ⚠ A项'运动有健身作用'易误判为与'口罩—眼罩'并列关系同类，未发现关系类型本身不同

## 母题抽象
> 🧩 当题干为'A对于（）相当于（）对于B'的填空式类比时，用逐项代入+造句法，必须同时验证前后关系类型相同且词语先后方向一致，二者缺一即排除

**同类特征**：填空式类比（相当于结构）、逐项代入验证、功能对应、工具对应、词序方向一致、种属与原材料干扰项

### 题干
健身 对于 （    ） 相当于 （    ） 对于 眼罩

### 选项
- A. 运动；口罩
- B. 增肌；遮光
- C. 健步走；丝绸
- D. 跑步机；睡眠　✅

### 官方解析
逐一代入选项。
A项：“运动”有“健身”的作用，二者为功能对应关系；“口罩”和“眼罩”是两种不同的用具，二者为并列关系，前后逻辑关系不一致，排除；
B项：“健身”有“增肌”的作用，二者为功能对应关系；“眼罩”有“遮光”的作用，二者为功能对应关系，但前后词语顺序相反，前后逻辑关系不一致，排除；
C项：“健步走”是一种“健身”方式，二者为种属关系；“丝绸”是制作“眼罩”的原材料，二者为原材料和成品的对应关系，前后逻辑关系不一致，排除；
D项：“健身”的时候可能会用到“跑步机”，二者为工具对应关系；“睡眠”的时候可能会用到“眼罩”，二者为工具对应关系，前后逻辑关系一致，当选。
故正确答案为D。
