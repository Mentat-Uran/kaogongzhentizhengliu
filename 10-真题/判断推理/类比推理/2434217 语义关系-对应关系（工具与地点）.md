# 语义关系-对应关系（工具与地点）

考点：[[20-考点/判断推理/类比推理/语义关系-对应关系（工具与地点）|类比推理 / 语义关系-对应关系（工具与地点）]]


**问法模型**：二元词项关系类比题 → 先用造句法确定题干'工具—地点'对应，再逐项造句排除，注意'常见/典型'二级辨析

## 推理链
1. 第1步：分析题干'镰刀：稻田'——镰刀是在稻田里进行收割作业时常见的工具，稻田是作业地点
2. 第2步：造句验证：'在稻田里用镰刀收割'语义通顺，确定二者为'常见工具与地点'的典型对应关系
3. 第3步：A项试管是化学实验室常用仪器，医院并非其典型使用场所，且'试管'非'医院常见工具'的典型搭配，排除
4. 第4步：B项在办公大楼书写不一定用钢笔，也可能是签字笔等，'钢笔'与'办公大楼'非常见工具与地点的典型对应，排除
5. 第5步：C项导弹是军队可能使用的武器，军队是组织而非具体作业地点，不构成工具与地点的对应，排除
6. 第6步：D项造句'在建筑工地用塔吊起吊'成立，塔吊是建筑工地常用的起重设备，与题干'常见工具和地点'对应关系一致，当选

**最快解法**：⚡ 造句法+排除法：题干造句'在稻田用镰刀收割'锁定'工具—地点'关系；A对应实验室、B不必然用钢笔、C'军队'非地点，逐一排除后仅D'在建筑工地用塔吊'完全对应

## 易错点
- ⚠ A项易被'医院抽血用试管'干扰而误选，但需辨析'试管'最典型的使用场所是化学实验室而非医院
- ⚠ B项'写字'与'钢笔'存在或然性关联，误把'可能使用'当'常见典型使用'
- ⚠ C项忽略地点要素，把'军队'（组织机构）误当作与'稻田'同类的具体作业场所

## 母题抽象
> 🧩 当题干出现'名词：名词'且能用'在某场所用某工具做某事'造句时，先确定工具与地点的典型对应关系，再逐项造句验证，排除非典型场所、或然性搭配或非地点词项的选项

**同类特征**：镰刀、稻田、工具、地点、常见/典型对应、收割作业

### 题干
镰刀：稻田

### 选项
- A. 试管：医院
- B. 钢笔：办公大楼
- C. 导弹：军队
- D. 塔吊：建筑工地　✅

### 官方解析
第一步：判断题干词语间逻辑关系。
镰刀是稻田里常见的一种收割工具，二者是常见工具和地点的对应关系。
第二步：判断选项词语间逻辑关系。
A项：试管是化学实验室常用的仪器，而非医院里常见的工具，与题干逻辑关系不一致，排除；
B项：在办公大楼里书写时不一定使用钢笔，也可能是签字笔等，二者不是常见工具和地点的对应关系，与题干逻辑关系不一致，排除；
C项：导弹是军队可能使用的一种武器，二者不是常见工具和地点的对应关系，与题干逻辑关系不一致，排除；
D项：塔吊是建筑工地上常用的一种起重设备，二者是常见工具和地点的对应关系，与题干逻辑关系一致，当选。
故正确答案为D。
