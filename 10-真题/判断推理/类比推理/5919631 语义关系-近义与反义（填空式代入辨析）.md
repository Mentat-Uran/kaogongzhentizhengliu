# 语义关系-近义与反义（填空式代入辨析）

考点：[[20-考点/判断推理/类比推理/语义关系-近义与反义（填空式代入辨析）|类比推理 / 语义关系-近义与反义（填空式代入辨析）]]


**问法模型**：填空式类比（敬重之于X相当于X之于拘谨）→ 将选项逐一代入，判定前后两组词的语义关系（近义/反义）是否完全一致

## 推理链
1. 第1步：提取题干词义：'敬重'指恭敬尊重（态度肯定类）；'拘谨'指言语行动过分谨慎、拘束（性格拘束类）
2. 第2步：填空式类比必须代入验证，且要求前后两组词的关系类型（同为近义或同为反义）一致，不能只看单侧
3. 第3步：代入A：敬重≈尊重（近义），但'谨慎'与'拘谨'无明确近反关系（拘谨强调'过分'拘束）→ 前后不一致，排除
4. 第4步：代入B：敬重与蔑视为反义，但'拘束'与'拘谨'为近义 → 一反一近，前后不一致，排除
5. 第5步：代入C：敬重与尊崇为近义，但'豪放'与'拘谨'为反义 → 一近一反，前后不一致，排除
6. 第6步：代入D：敬重与'鄙视'（轻视看不起）为反义，'洒脱'（自然不拘束）与拘谨为反义 → 前后同为反义，关系一致，当选

**最快解法**：⚡ 代入法+关系一致性口诀：填空类比先找'前后关系同型'的选项——直接验证D：鄙视↔敬重（反义）、洒脱↔拘谨（反义），前后均为反义即秒选D；再用B做反向验证（一反一近）确认排除

## 易错点
- ⚠ B项最具迷惑性：前后各自都有'明确关系'（前反后近），考生误认为有关系即可选，忽略关系类型必须前后一致
- ⚠ A项'谨慎'与'拘谨'字形相近（同含'谨'字），易误判为近义词，实际拘谨的核心是'过分拘束'，与谨慎无明显语义关系
- ⚠ C项与D项是一组镜像陷阱（一近一反 vs 两反），若只验证前半部分（敬重-尊崇近义）就匆忙排除D，会误选C

## 母题抽象
> 🧩 当题干为'填空式'类比（A之于（ ）相当于（ ）之于B）时，用代入法逐项检验，只有前后两组词的语义关系类型（同近义或同反义）完全一致的选项才当选；凡'一组近义+一组反义'的混搭选项必排除

**同类特征**：填空式两空类比、'之于…相当于…之于'句式、考近义与反义辨析、情感态度类词对（敬重/鄙视）、性格状态类词对（拘谨/洒脱）、需前后关系一致性验证

### 题干
敬重 之于 （    ） 相当于 （    ） 之于 拘谨

### 选项
- A. 尊重；谨慎
- B. 蔑视；拘束
- C. 尊崇；豪放
- D. 鄙视；洒脱　✅

### 官方解析
逐一代入选项。
A项：“敬重”指恭敬尊重，“尊重”指尊敬，敬重，二者为近义关系；“谨慎”指对外界事物或自己的言行密切注意，以免发生不利或不幸的事情，“拘谨”指（言语、行动）过分谨慎，拘束，二者无明显逻辑关系，前后逻辑关系不一致，排除；
B项：“敬重”指恭敬尊重，“蔑视”指轻视、小看，二者为反义关系；“拘束”指过分约束自己，显得不自然，“拘谨”指（言语、行动）过分谨慎，拘束，二者为近义关系，前后逻辑关系不一致，排除；
C项：“敬重”指恭敬尊重，“尊崇”指尊敬推崇，二者为近义关系；“豪放”指气魄大而无所拘束，“拘谨”指（言语、行动）过分谨慎，拘束，二者为反义关系，前后逻辑关系不一致，排除；
D项：“敬重”指恭敬尊重，“鄙视”指轻视、看不起，二者为反义关系；“洒脱”指（言谈、举止、风格）自然、不拘束，“拘谨”指（言语、行动）过分谨慎，拘束，二者为反义关系，前后逻辑关系一致，当选。
故正确答案为D。
