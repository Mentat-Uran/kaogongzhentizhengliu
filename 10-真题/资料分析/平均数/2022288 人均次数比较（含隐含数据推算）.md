# 人均次数比较（含隐含数据推算）

考点：[[20-考点/资料分析/平均数/人均次数比较（含隐含数据推算）|平均数 / 人均次数比较（含隐含数据推算）]]
材料：[[15-材料/资料分析/184894 2015年A市统计局对5000名有网|184894 2015年A市统计局对5000名有网]]

**问法模型**：题干问'下列群体中2015年人均网购次数最少的是' → 对四个群体的人均次数逐一取值比较，其中男性数据需由'女性次数−高出量'推算后再比

## 推理链
1. 第1步：从文字材料直接读取三个群体数据：35岁以下人均25.5次（A项）、大专学历21.8次（D项）、月收入10000元以上31.0次（C项）
2. 第2步：B项男性次数材料未直接给出，须用隐含关系推算：女性人均21.1次、比男性高3.8次
3. 第3步：代入计算男性人均网购次数 = 21.1 − 3.8 = 17.3次
4. 第4步：四者比较：17.3 < 21.8 < 25.5 < 31.0，男性受访者最少
5. 第5步：对照选项，男性受访者对应B项，与官方答案一致

**最快解法**：⚡ 隐含数据推算法+截位比较：四个选项中只有B需计算，先算男性21.1−3.8=17.3次；因17.3已小于直接读出的最小值21.8（大专），立即锁定B，其余选项无需再核

## 易错点
- ⚠ 男性人均次数是隐藏数据：材料只给'女性21.1次、比男性高3.8次'，漏推21.1−3.8=17.3会误判B项数据缺失而错选
- ⚠ 高低方向搞反：把'女性比男性高3.8次'误算成21.1+3.8=24.9次，得出男性并非最少的错误结论
- ⚠ 学历口径陷阱：'大专'（21.8次）与'大学本科及以上'（27.3次）是并列两档，题干问大专须取21.8，取错数值可能误判D为最少

## 母题抽象
> 🧩 当题干出现'最值比较'且某选项数据未直接给出时，先用材料中'A比B高/低X'的差值关系推算隐含值，再与直接读取的数值比较，优先核查隐藏数据项即可锁定答案

**同类特征**：人均网购次数、最少的是、群体比较、男性受访者、比…高出、隐含数据需推算

### 题干
下列群体中，2015年人均网购次数最少的是：

### 选项
- A. 35岁以下的受访者
- B. 男性受访者　✅
- C. 个人月收入为10000元以上的受访者
- D. 大专学历的受访者

### 官方解析
A项：35岁以下的受访者人均网购次数为25.5次；
B项：定位文字材料，“女性受访者人均网购次数为21.1次，比男性受访者高出3.8次”，所以男性网购次数为次；
C项：个人月收入为10000元以上的受访者人均网购次数为31.0次；
D项：大专学历的受访者人均网购次数为21.8次。
所以最少的是男性受访者。
故正确答案为B。
