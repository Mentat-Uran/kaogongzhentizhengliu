# 现期平均数复合计算（比重求部分值+单价换算+单位量级换算）

考点：[[20-考点/资料分析/平均数/现期平均数复合计算（比重求部分值+单价换算+单位量级换算）|平均数 / 现期平均数复合计算（比重求部分值+单价换算+单位量级换算）]]
材料：[[15-材料/资料分析/305737 2018年第一季度全国星级饭店经营情|305737 2018年第一季度全国星级饭店经营情]]

**问法模型**：已知'元/间夜'单价与客房收入比重，求'平均每家订出客房数' → 用'营业收入×比重÷单价÷家数'四步复合平均数模型

## 推理链
1. 第1步：从统计表提取三星级数据：4613家、营业收入105.76亿元、客房收入比重41.58%；题干另给单价260.26元/间夜
2. 第2步：表中只给比重不给绝对额，客房收入=营业收入×比重=105.76×41.58%≈43.97亿元
3. 第3步：单位换算：43.97亿元=4.397×10⁹元（亿元→元差10⁸量级）；全国总间夜数=4.397×10⁹÷260.26≈1.69×10⁷间夜
4. 第4步：平均每家订出=1.69×10⁷÷4613≈3663间夜（题干问'该季度'整季，无需再除3个月或91天）
5. 第5步：3663落在2000-5000区间，与选项B对照成立

**最快解法**：⚡ 量级控制+截位直除：105.76×41.58%≈44亿元=44×10⁸元；44×10⁸÷260≈1.7×10⁷间夜；1.7×10⁷÷4613≈3700间夜——只需判定数量级落点即可锁B，全程无须精算到个位

## 易错点
- ⚠ 量级陷阱：营业收入是'亿元'而单价是'元/间夜'，漏掉10⁸换算会把结果缩小10⁸倍或误判到D（超过10000间）
- ⚠ 表中给的是客房收入'比重'而非金额，必须用105.76×41.58%现算，直接读表无绝对额可用
- ⚠ 时间口径：题干问'该季度'总量，算出的3663间夜即每家整季度订出量，不要再除以3个月或一季度天数；另注意餐饮+客房比重合计不足100%（41.58%之外还有其他收入），不能把105.76亿全部当客房收入

## 母题抽象
> 🧩 当题干出现'已知单价（元/间夜、元/人次）+求平均每家/每单位的量'特征时，用'总额×占比→总量→÷单价→÷家数'四步链，先锁定10⁸量级换算再截位直除，只需数量级匹配选项区间即可作答

**同类特征**：平均每家……订出客房、元/间夜（复合单位单价）、客房收入比重、三星级、该季度、区间型选项（不到/……之间/超过）

### 题干
已知2018年一季度全国三星级酒店平均客房收入为260.26元/间夜，问该季度平均每家三星级酒店订出客房：

### 选项
- A. 不到2000间
- B. 2000-5000间之间　✅
- C. 5000-10000间之间
- D. 超过10000间

### 官方解析
根据题干“已知2018年一季度······平均每家三星级酒店订出客房”，结合材料时间是2018年第一季度，可判定本题为现期平均数问题。定位统计表可得：2018年第一季度全国三星级饭店4613家，营业收入105.76亿元，客房收入比重41.58%；题干给出2018年一季度全国三星级酒店平均客房收入为260.26元/间夜。故2018年一季度平均每家三星级酒店订出客房数量间，介于2000-5000间之间。
故正确答案为B。
