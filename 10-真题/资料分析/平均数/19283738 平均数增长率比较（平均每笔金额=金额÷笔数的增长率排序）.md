# 平均数增长率比较（平均每笔金额=金额÷笔数的增长率排序）

考点：[[20-考点/资料分析/平均数/平均数增长率比较（平均每笔金额=金额÷笔数的增长率排序）|平均数 / 平均数增长率比较（平均每笔金额=金额÷笔数的增长率排序）]]
材料：[[15-材料/资料分析/4504602 2023年三季度中国支付系统运行情况|4504602 2023年三季度中国支付系统运行情况]]

**问法模型**：题干要求将四个系统'平均每笔业务金额同比增速'从高到低排列 → 对每个系统套用平均数增长率公式(金额增速-笔数增速)/(1+笔数增速)，算出四个增速值后比大小排序

## 推理链
1. 第1步：从材料第三段提取四个系统2023年三季度现期同比增速：①银行行内笔数+11.14%、金额-4.10%；②银联跨行+21.37%、+8.70%；③城银清算+34.61%、+36.31%；④农信银-39.98%、-13.55%
2. 第2步：平均每笔业务金额=金额÷笔数，其增长率公式为(金额增速-笔数增速)/(1+笔数增速)
3. 第3步：逐个代入：①(-4.10%-11.14%)/(1+11.14%)=-15.24%/1.1114≈-13.7%；②(8.70%-21.37%)/(1+21.37%)=-12.67%/1.2137≈-10.4%；③(36.31%-34.61%)/(1+34.61%)=1.70%/1.3461≈+1.3%；④(-13.55%+39.98%)/(1-39.98%)=26.43%/0.6002≈+44.0%
4. 第4步：比较四个结果：+44.0%＞+1.3%＞-10.4%＞-13.7%，即④＞③＞②＞①
5. 第5步：④③②①对应选项C，与官方答案一致

**最快解法**：⚡ 公式法+正负分组速判：先只算分子（金额增速-笔数增速）：④=+26.43%、③=+1.70%为正，②=-12.67%、①=-15.24%为负，正者必排前、负者排后；④分子26.43%远大于③的1.70%且④分母0.60<1反而放大比值，故④＞③；②①均为负且分母均略大于1接近，分子②(-12.67%)＞①(-15.24%)，故②＞①，全程无需精确除法即得④③②①选C

## 易错点
- ⚠ 只比金额增速不套公式：若直接按金额增速(-4.10%、8.70%、36.31%、-13.55%)排序会误得③②①④选B，必须用平均数增长率公式
- ⚠ 负增速分母处理错误：④农信银笔数下降39.98%，分母应为1-39.98%≈0.60（小于1），误写成1+39.98%或1+(-39.98%)算错会改变④的排序地位
- ⚠ 增速符号看串：材料正负增速混排（农信银双降、银行行内金额降4.10%），'下降'须代入负号，分子-13.55%-(-39.98%)中负负得正为+26.43%，符号写错会误判④为负

## 母题抽象
> 🧩 当题干出现'平均每笔/平均每个…同比增速(比较/排序)'特征时，对每个主体套平均数增长率公式(a-b)/(1+b)（a=总量增速、b=份数增速），先用分子a-b的正负分组粗排，再在同组内比分子大小（分母接近时分子大者值大）定序

**同类特征**：平均每笔业务金额、同比增速、从高到低排列、四个系统并列比较、其他支付系统、只给增速不给基期量
