# 比值比较（旅客周转量÷客运量=平均运距）

考点：[[20-考点/资料分析/平均数/比值比较（旅客周转量÷客运量=平均运距）|平均数 / 比值比较（旅客周转量÷客运量=平均运距）]]


**问法模型**：题干出现'……与……之比最大的运输方式'→对四个选项分别做 旅客周转量÷客运量，比较商的大小取最大者

## 推理链
1. 第1步：题干要求比较2010年江苏四种运输方式'旅客周转量÷客运量'的大小；从表格提取数据：旅客周转量铁路351.3、公路1196.9、水路1.5、民航60.9亿人公里，客运量铁路9711.4、公路215850、水路690、民航475.9万人
2. 第2步：规则判断——四个选项分子单位均为'亿人公里'、分母单位均为'万人'，单位完全一致，可直接相除比较，无需换算；该比值实际含义为平均每人次运输距离（平均运距）
3. 第3步：截位直除估算各比值：铁路351.3/9711.4≈0.036，公路1196.9/215850≈0.0055，水路1.5/690≈0.0022，民航60.9/475.9≈0.128
4. 第4步：比较商的大小：民航0.128＞铁路0.036＞公路0.0055＞水路0.0022，民航最大，对应选项D

**最快解法**：⚡ 量级判断+截位直除：四项单位一致直接相除，民航60.9/475.9首位商约1（≈0.13），铁路351.3/9711.4首位商约3（≈0.036），公路约0.005，水路约0.002，民航比铁路高一个量级，秒选D

## 易错点
- ⚠ 只看分子大小误选公路（其周转量1196.9亿人公里最大）——比值比较必须做除法，分子大不代表比值大
- ⚠ 表格中旅客与货运数据并存，看错列，把'货运量/货物周转量'当作'客运量/旅客周转量'提取
- ⚠ 纠结'亿人公里÷万人'单位而强行换算浪费时间——四选项分子分母单位相同可直接比较，只有求具体平均运距才需换算（×10⁴公里/人次）

## 母题抽象
> 🧩 当题干出现'A与B之比最大/最小'的比值比较特征时，先核对各选项分子分母单位是否一致，一致则截位直除比商，并验证'分子最大者'是否商也最大，防止被大分子误导

**同类特征**：旅客周转量与客运量之比、之比最大、比值比较型、运输方式逐一对比、表格材料、单位一致的分数比较
