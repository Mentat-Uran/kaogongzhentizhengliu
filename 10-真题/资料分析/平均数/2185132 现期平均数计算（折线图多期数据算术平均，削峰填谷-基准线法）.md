# 现期平均数计算（折线图多期数据算术平均，削峰填谷-基准线法）

考点：[[20-考点/资料分析/平均数/现期平均数计算（折线图多期数据算术平均，削峰填谷-基准线法）|平均数 / 现期平均数计算（折线图多期数据算术平均，削峰填谷/基准线法）]]
材料：[[15-材料/资料分析/194915 2015—2017年（重点2017年|194915 2015—2017年（重点2017年]]

**问法模型**：题干问'2015—2017年各季度比率的平均值'→ 将折线图12个季度数据求和后除以12，用基准线（削峰填谷）法速算

## 推理链
1. 第1步：题干要求2015—2017年全部季度比率的平均值，从折线图提取12个季度数据：2015年为1.12、1.06、1.09、1.10；2016年为1.07、1.05、1.10、1.13；2017年为1.13、1.11、1.16、1.22
2. 第2步：平均数=各季度比率之和÷12，项数为12个季度（非2017年4个季度）
3. 第3步：以1.10为基准线削峰填谷，各期偏差为+0.02、-0.04、-0.01、0.00、-0.03、-0.05、0.00、+0.03、+0.03、+0.01、+0.06、+0.12，正偏差合计+0.27、负偏差合计-0.13，净偏差+0.14
4. 第4步：平均值=1.10+0.14÷12≈1.10+0.012≈1.11（与官方以1.00为基准的算法一致：偏差和1.34÷12≈0.11）
5. 第5步：与选项对照，1.11对应C项，故选C

**最快解法**：⚡ 削峰填谷（基准线法）：取接近数据波动中心的1.10为基准，正偏差0.27与负偏差0.13抵消后净+0.14，0.14÷12≈0.01，平均值≈1.10+0.01=1.11，直接锁定C；避免直接加总12个两位小数

## 易错点
- ⚠ 项数陷阱：'2015—2017各季度'是12个季度数据的平均，误只取2017年4个季度会得到约1.16而错选D
- ⚠ 读数陷阱：折线图数据点密集，1.06与1.05、两个1.13等易看错漏数，须按12个点逐一核对
- ⚠ 口径混淆：本题与同比上升0.09、环比上升0.06的比率差值无关，不要把文字段的同比/环比变化数据代入本题

故2015—2017年，各季度的岗位空缺与求职人数比率的平均值为。
故正确答案为C。
