# 平均数增长率（人均薪酬增速，份数增速为0的特例）

考点：[[20-考点/资料分析/平均数/平均数增长率（人均薪酬增速，份数增速为0的特例）|平均数 / 平均数增长率（人均薪酬增速，份数增速为0的特例）]]
材料：[[15-材料/资料分析/238954 某市调查总队抽样调查：2017年全市|238954 某市调查总队抽样调查：2017年全市]]

**问法模型**：题干问'人均薪酬比上年增长'（选项为百分数）→ 平均数增长率模型：人均增速=(1+总量增速)/(1+份数增速)-1，当份数（人数）增速为0时退化为'人均增速=总量增速'

## 推理链
1. 第1步：题干问'2017年从业人员人均薪酬比上年增长'，人均薪酬=人员薪酬总额÷从业人员数，属平均数增长率题型
2. 第2步：从文字段取数：2017年人员薪酬19.3亿元、比上年增长（该增速即待求值）；从业人员29028人、'与上年持平'→人数同比增速b=0，且隐含2016年人数同为29028人
3. 第3步：代入平均数增长率公式 g人均=(a-b)/(1+b)，其中a为薪酬总额同比增速，b=0
4. 第4步：化简得 g人均=(a-0)/(1+0)=a，即分母（人数）不变时，人均薪酬增速就等于薪酬总额增速
5. 第5步：方法二验证：2017年人均=19.3×10^8÷29028≈6.65万元/人；2016年人均=19.3/(1+a)÷29028，两期分母相同，人均之比=总额之比=1+a，故人均增速=a
6. 第6步：与选项对照：正确答案应等于文字中'人员薪酬比上年增长'的数值，按官方信息锁定B

**最快解法**：⚡ 特例秒杀：材料注明'从业人员29028人，与上年持平'⇒份数增速=0⇒平均数增速=总量增速，直接把文字中'人员薪酬19.3亿元，比上年增长____%'的数值抄为答案，零计算；若套公式则为 g均=(a-0)/(1+0)=a

## 易错点
- ⚠ 单位量级陷阱：19.3亿元÷29028人≈6.65万元/人是'人均水平'而非'增长率'，且须做亿元→元换算，选项常以元/万元混排量级
- ⚠ 结构陷阱：人均增速≠薪酬总额增速并非恒等，本题成立唯一桥梁是文字隐含条件'人数与上年持平（b=0）'，忽略该条件则基期人均无法落地；反之若人数有增长，仍划等号就会错
- ⚠ 阅读陷阱：本题增速数值只存在于文字段（图中仅有资产/收入/费用三条增速线），不能去折线图找薪酬增速；另勿把'与上年持平'误读到薪酬上

## 母题抽象
> 🧩 当题干问'人均××比上年增长'且材料注明'份数（人数）与上年持平'时，用平均数增长率公式在b=0处退化：人均增速=总量增速，验证选项等于总量的同比增速即可秒杀

**同类特征**：人均薪酬比上年增长、平均数增长率、从业人员与上年持平、人员薪酬19.3亿元、现期2017年、同比口径、选项为百分数
