# 统计图直接读数与极值比较

考点：[[20-考点/资料分析/其他/统计图直接读数与极值比较|其他 / 统计图直接读数与极值比较]]
材料：[[15-材料/资料分析/257871 甲、乙、丙、丁四个城市的通勤特征对比|257871 甲、乙、丙、丁四个城市的通勤特征对比]]

**问法模型**：题干问'四个城市中通勤空间半径最短的是'哪一个 → 锁定图一中'通勤空间半径'对应的那组条形数据，做四城数值的极值比较

## 推理链
1. 第1步：题干要求比较'通勤空间半径'，需取图一《四个城市平均通勤距离与通勤空间半径》中深色条（通勤空间半径）的数据，而非浅色条（平均通勤距离）
2. 第2步：从图一条端标注读取四城通勤空间半径：甲40公里、乙39公里、丙31公里、丁40公里
3. 第3步：比较大小：31 < 39 < 40 = 40，最小值为丙市的31公里
4. 第4步：对照选项，丙市对应C选项，与官方答案C一致

**最快解法**：⚡ 直接读数比较（无需计算）：只看图一深色条，肉眼扫一遍四根长条找最短者即丙（31公里），条端标注31<39<40=40即可锁定答案

## 易错点
- ⚠ 图例看反：浅色条（8.1~11.1公里）是平均通勤距离，深色条（31~40公里）才是通勤空间半径，若混淆会误选平均距离最短的丁市（8.1公里）
- ⚠ 甲与丁的通勤空间半径同为40公里，条长几乎相同，仅靠目测难区分；虽然不影响本题极值判断，但提醒读图须依赖条端数值标注而非条形长度
- ⚠ 跨图误读：图一单位是公里、图二单位是百分比，量纲不同不能跨图比较数值大小，本题只需用图一

## 母题抽象
> 🧩 当题干出现'四个/多个对象中某指标最短、最长、最大的是哪一个'特征时，先在对应图表中锁定该指标对应图例的那组数据，直接读取条端（或柱端）标注数值做极值比较，并验证极值是否唯一

**同类特征**：通勤空间半径、最短、四个城市中、图一条形图、直接读数、极值比较

### 题干
在四个城市中，通勤空间半径最短的是：

### 选项
- A. 甲市
- B. 乙市
- C. 丙市　✅
- D. 丁市

### 官方解析
定位图一可得，甲、乙、丙、丁四个城市的通勤空间半径分别为：40公里、39公里、31公里、40公里，则通勤空间半径最短的是丙市（31公里）。
故正确答案为C。
