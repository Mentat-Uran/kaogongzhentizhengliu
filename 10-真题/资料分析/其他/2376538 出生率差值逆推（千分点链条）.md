# 出生率差值逆推（千分点链条）

考点：[[20-考点/资料分析/其他/出生率差值逆推（千分点链条）|其他 / 出生率差值逆推（千分点链条）]]
材料：[[15-材料/资料分析/239308 我国2014—2017年“单独两孩”|239308 我国2014—2017年“单独两孩”]]

**问法模型**：题干直接求'十二五'时期年平均出生率的绝对水平 → 材料未给该值，改走'千分点率差'链条逆推：目标值＝2017年出生率＋0.52‰－0.84‰

## 推理链
1. 第1步：从材料第1段提取两处率差：2016年出生率比'十二五'年平均出生率高0.84个千分点；2017年出生率比上一年（2016年）降低0.52个千分点（本图版2017年出生率数值空缺，代入时用原卷给定值）
2. 第2步：两处差值均为'率'的千分点差而非人口数差，可沿时间线逆推：十二五年均出生率＝2016年出生率－0.84‰，而2016年出生率＝2017年出生率＋0.52‰
3. 第3步：合并链条：十二五年均出生率＝2017年出生率＋0.52‰－0.84‰＝2017年出生率－0.32‰
4. 第4步：代入2017年出生率数值，得到十二五年平均出生率（千分比‰量级），与四个选项对照
5. 第5步：结果与B选项一致，故正确答案为B

**最快解法**：⚡ 率差链条法（千分点加减）：先加后减，十二五年均出生率＝2017年出生率＋0.52‰－0.84‰＝2017年出生率－0.32‰，代入原卷2017年出生率数值一次心算即出，不必分两步先求2016年再求十二五

## 易错点
- ⚠ 加减方向弄反：材料说2017比2016'降低'0.52个千分点，倒推2016要＋0.52‰；2016比十二五'提高'0.84个千分点，倒推十二五要－0.84‰，方向与材料叙述相反
- ⚠ 单位口径：0.84、0.52是'千分点'（‰之差）不是'百分点'，且率差不能乘人口基数折算成人数；与'量'的差（79万人、47万人、131万人）分属两套基准，不可交叉使用
- ⚠ 基准混淆：0.84‰的对照基准是'十二五年平均出生率'，不是'十二五年平均出生人口'（1644万）；且本图版2017年出生率数值空缺，本题是全组唯一硬性依赖该空缺值的题

## 母题抽象
> 🧩 当题干求某基准期'率'的水平、而材料只给'某年率比上一年降x个千分点＋某年率比基准期高y个千分点'时，用'现期率＋x－y'的千分点链条逆推，加减方向与材料表述相反

**同类特征**：十二五时期、年平均出生率、0.84个千分点、0.52个千分点、率差逆推、千分比‰
