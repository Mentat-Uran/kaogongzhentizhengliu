# 逐年差值比较（贫困发生率较上年下降的百分点数比较）

考点：[[20-考点/资料分析/其他/逐年差值比较（贫困发生率较上年下降的百分点数比较）|其他 / 逐年差值比较（贫困发生率较上年下降的百分点数比较）]]
材料：[[15-材料/资料分析/239236 2012—2018年全国脱贫攻坚成效|239236 2012—2018年全国脱贫攻坚成效]]

**问法模型**：题干出现'2013—2018年较上年下降最多的是哪年'→对折线图7个年度点做6个相邻差（当年−上年，按百分点计），取差值最大者

## 推理链
1. 第1步：正文两处发生率数值留白，回图1折线（右轴%）读出2012—2018年依次为10.2、8.5、7.2、5.7、4.5、3.1、1.7
2. 第2步：'较上年下降最多'按百分点差计算，公式为当年发生率−上年发生率，差值越大下降越多
3. 第3步：逐年做差：2013年10.2−8.5=1.7，2014年8.5−7.2=1.3，2015年7.2−5.7=1.5，2016年5.7−4.5=1.2，2017年4.5−3.1=1.4，2018年3.1−1.7=1.4（个百分点）
4. 第4步：比较6个差值，最大为1.7个百分点，对应2013年，与A项吻合

**最快解法**：⚡ 读数做差法：从右轴折线直接取数，结合选项只需算2013（1.7）、2015（1.5）、2017（1.4）、2018（1.4）四个差，最大1.7即2013年；均为一位小数减法，口算即可，无需截位

## 易错点
- ⚠ 双轴图量纲陷阱：柱（万人，左轴0—10000）与折线（%，右轴0—12）刻度不同，不能按图形高度目测哪段折线降得最陡，必须读右轴数值
- ⚠ '下降最多'指百分点差（相邻两年发生率相减），不是降幅比例（差÷上年值），勿改用增长率模型
- ⚠ 正文'累计下降8.5个百分点'是2012对2018的累计差（10.2−1.7），不能当作任何单年的下降量；2018年发生率1.7与正文'高出全国实际增速1.7个百分点'中的1.7数字巧合、含义不同，勿混用

## 母题抽象
> 🧩 当题干出现'某指标较上年下降（上升）最多的是哪年'且材料为逐年点值图/表时，用逐年做差法：当年值−上年值取差，逐年比较取最大，且只需对选项涉及年份做差即可提速

**同类特征**：较上年下降最多、年份区间2013—2018、贫困发生率（折线）、相邻两年做差、按百分点而非比例、读数差值比较型

### 题干
2013—2018年，全国农村贫困发生率较上年下降最多的是（    ）年。

### 选项
- A. 2013　✅
- B. 2015
- C. 2017
- D. 2018

### 官方解析
本题所求“······全国农村贫困发生率较上年下降最多······”，定位折线图，A项2013年：，即下降1.7个百分点；B项2015年： ，即下降1.5个百分点；C项2017年： ，即下降1.4个百分点；D项2018年：，即下降1.4个百分点。则下降最多的为A项2013年。
故正确答案为A。
