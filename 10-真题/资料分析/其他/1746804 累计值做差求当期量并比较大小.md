# 累计值做差求当期量并比较大小

考点：[[20-考点/资料分析/其他/累计值做差求当期量并比较大小|其他 / 累计值做差求当期量并比较大小]]
材料：[[15-材料/资料分析/180726 2014年全国社会物流运行情况：社会|180726 2014年全国社会物流运行情况：社会]]

**问法模型**：题干问'总额最高的季度'而图2给出的是分季度'累计'值 → 相邻两期累计做差还原当季值后再比较大小

## 推理链
1. 第1步：从图2读取2014年各季度累计社会物流总额：一季度47.8、上半年累计101.5、前三季度累计158.1、全年累计213.5万亿元，柱子口径为'累计'而非当季值
2. 第2步：当季值=本期累计值−上期累计值，一季度当季即47.8万亿元
3. 第3步：代入做差：二季度=101.5−47.8=53.7万亿元，三季度=158.1−101.5=56.6万亿元，四季度=213.5−158.1=55.4万亿元
4. 第4步：比较47.8、53.7、56.6、55.4，三季度当季56.6万亿元最高，对照选项选C

**最快解法**：⚡ 累计做差法（口算+尾数法）：只需三道减法 101.5−47.8=53.7、158.1−101.5=56.6、213.5−158.1=55.4，直接比出三季度最大；若嫌小数麻烦，可先比较差值的整数部分与首位，56.6明显最大，无需精确算到位

## 易错点
- ⚠ 直接比柱高误选D（第四季度）：图2柱子是'累计'值，Q4柱213.5最高但Q4当季仅55.4万亿元，必须相邻累计做差
- ⚠ 把101.5、158.1误当Q2、Q3当季值：若不还原当季量，会得出'逐季递增、Q4最高'的错误结论
- ⚠ 单位口径陷阱：本题主图用万亿元，与构成表（亿元）不同，本题虽不跨表但需锁定万亿元口径，勿受213.5万亿元=2135000亿元换算干扰

## 母题抽象
> 🧩 当题干问'最高的季度/月份'而图表数值标注为'累计'时，必须用相邻两期累计做差还原当期量再比较，切勿直接比柱高或比累计值大小

**同类特征**：最高的季度、分季度累计社会物流总额、柱状图+折线混合图、做差还原当季值、社会物流总额、2014年
