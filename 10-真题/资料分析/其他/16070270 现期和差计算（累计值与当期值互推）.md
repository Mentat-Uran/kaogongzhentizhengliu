# 现期和差计算（累计值与当期值互推）

考点：[[20-考点/资料分析/其他/现期和差计算（累计值与当期值互推）|其他 / 现期和差计算（累计值与当期值互推）]]
材料：[[15-材料/资料分析/5455839 2022—2025年Q市12348公|5455839 2022—2025年Q市12348公]]

**问法模型**：题干求图中缺失的2025年第二季度量 → 用文字'上半年累计102428人次'减图中2025年一季度柱52802人次，再换算为万人次

## 推理链
1. 第1步：定位文字材料，2025年上半年Q市法律热线咨询量为102428人次，这是Q1+Q2的半年累计值
2. 第2步：定位统计图，2025年（虚线柱）只有一季度数据，2025Q1=52802人次，二季度柱不存在，必须倒推
3. 第3步：套用公式 2025Q2 = 上半年累计 − 2025Q1 = 102428 − 52802 = 49626人次
4. 第4步：单位换算，49626人次≈4.96万人次，与选项B一致，故选B

**最快解法**：⚡ 截位口算：10.24万 − 5.28万 = 4.96万，直接锁定B，无需精算

## 易错点
- ⚠ 图中2025年只有一季度虚线柱，二、三、四季度无2025年柱，若只看图找柱会误以为无解或错拿其他年份数据
- ⚠ '上半年102428'是累计值，图中各柱是当季值，累计与当期混排，必须做减法拆分而非直接引用
- ⚠ 单位陷阱：材料单位为'人次'，选项单位为'万人次'，49626人次=4.96万人次，量级换算错易误选

## 母题抽象
> 🧩 当题干问某期数据而图形缺少该期柱（文字只给累计值）时，用'文字累计值 − 图中已有的当期值'倒推缺口，再按选项单位换算量级验证

**同类特征**：2025年第二季度、图中无对应柱（虚线柱仅一季度）、上半年累计102428人次、减去一季度52802、人次换算万人次、选项带'万人次'单位

### 题干
2025年第二季度Q市法律热线咨询量约为：

### 选项
- A. 4.83万人次
- B. 4.96万人次　✅
- C. 5.12万人次
- D. 5.23万人次

### 官方解析
定位文字材料可得，2025年上半年Q市法律热线咨询量为102428人次；定位统计图可得，2025年一季度Q市法律热线咨询量为52802人次。根据公式：第二季度数据=上半年数据-第一季度数据，则2025年第二季度Q市法律热线咨询量为102428-52802=49626人次万人次，对应B项。
故正确答案为B。
