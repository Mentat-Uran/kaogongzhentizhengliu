# 隔年（间隔）增长率

考点：[[20-考点/资料分析/增长/隔年（间隔）增长率|增长 / 隔年（间隔）增长率]]
材料：[[15-材料/资料分析/5668700 2022年全国软件和信息技术服务业的|5668700 2022年全国软件和信息技术服务业的]]

**问法模型**：题干出现'2022年……比2020年增长了（百分数）'的隔年比较问法 → 采用间隔增长率公式 r=r1+r2+r1×r2，先由'回落X个百分点'还原中间年增速

## 推理链
1. 第1步：题干要求'2022年比2020年增长'，选项均为百分数，判定为隔年增长率问题；从材料第1段提取：2022年软件业务收入108126亿元，同比增速11.2%，增速较上年同期回落6.5个百分点
2. 第2步：由'回落6.5个百分点'还原2021年增速（回落是增速作差，用加法）：r2021 = 11.2% + 6.5% = 17.7%
3. 第3步：代入间隔增长率公式 r = r1 + r2 + r1×r2 = 11.2% + 17.7% + 11.2%×17.7%
4. 第4步：两项和 11.2% + 17.7% = 28.9%，乘积项 11.2%×17.7% ≈ 2.0%，合计约 30.9%
5. 第5步：与选项对照，30.9%与D项31%最接近，故选D

**最快解法**：⚡ 公式法（间隔增长率）：r=r1+r2+r1×r2。先加回回落数得r2=17.7%，和为28.9%，乘积项11.2%×17.7%≈11×18≈2%，合计约31%，直接秒选D（若漏乘积项得28.9%会误选C，选项C即此陷阱）

## 易错点
- ⚠ 误把'增速较上年同期回落6.5个百分点'当成增长量或作除法，正确做法是现期增速+回落数还原2021年增速17.7%
- ⚠ 漏掉乘积项r1×r2，只算11.2%+17.7%=28.9%恰好落入C项29%的干扰设计
- ⚠ 基期混淆：所求是相对2020年（间隔两年）的增长率，误只算相对2021年的一期增速11.2%即错

## 母题抽象
> 🧩 当题干出现'现期年比隔年（如2022比2020）增长了百分之几'特征时，先用'回落/提高X个百分点'还原中间年增速（基期增速=现期增速±百分点数），再套间隔增长率公式 r=r1+r2+r1×r2，对照最接近选项

**同类特征**：2022年……比2020年增长、约……增长了、选项为百分数、增速较上年同期回落X个百分点、软件业务收入、隔年/间隔两年

### 题干
2022年，全国软件和信息技术服务业规模以上企业累计完成软件业务收入约比2020年增长了：

### 选项
- A. 16%
- B. 23%
- C. 29%
- D. 31%　✅

### 官方解析
<p>根据题干“2022年······约比2020年增长了”，结合选项为百分数，可判定本题为间隔增长率问题。定位文字材料第一段可得：2022年，全国软件和信息技术服务业规模以上企业累计完成软件业务收入同比增长11.2%（<img flag="tex" src="../../../90-图片/公式图/formula-0149dcd72981f0c9.png" />），增速较上年同期回落6.5个百分点。则2021年，全国软件和信息技术服务业规模以上企业累计完成软件业务收入同比增长11.2%+6.5%=17.7%（<img flag="tex" src="../../../90-图片/公式图/formula-269dcb8a6b163dde.png" />）。根据间隔增长率公式：<img flag="tex" src="../../../90-图片/公式图/formula-eeb4bbb4e72c9d84.png" />，则所求<img flag="tex" src="../../../90-图片/公式图/formula-d99cbac066d56c9c.png" /><img flag="tex" src="../../../90-图片/公式图/formula-b8491131cd11eb0f.png" />，与D项最接近。</p><p>故正确答案为D。</p>
