# 增长率比较（增量-基期型）

考点：[[20-考点/资料分析/增长/增长率比较（增量-基期型）|增长 / 增长率比较（增量/基期型）]]
材料：[[15-材料/资料分析/6023796 2023-2024年我国洗涤行业生活|6023796 2023-2024年我国洗涤行业生活]]

**问法模型**：题干问'2017-2024年数量增长率最大的年份' → 对各年份套用 增长率=同比增量÷上年基数=增量÷(当年总量−当年增量)，逐年计算后比较大小

## 推理链
1. 第1步：题干锁定图2《在运行洗衣龙数量趋势变化图》，白柱=当年在运行总量，黑柱=当年增量，选项涉及2018(465,150)、2019(735,270)、2023(1610,295)、2024(1987,377)四组数据
2. 第2步：增长量已知时增长率公式为 增长率=增量÷基期量=增量÷(当年总量−当年增量)
3. 第3步：代入计算：2018年=150÷(465−150)=150/315≈47.6%；2019年=270÷(735−270)=270/465≈58.1%；2023年=295÷(1610−295)=295/1315≈22.4%；2024年=377÷(1987−377)=377/1610≈23.4%
4. 第4步：先用'增量是否超过基期一半'粗判是否超50%：2019年基期465的一半为232.5<270（超50%），2018年315的一半157.5>150（不足50%），2023、2024约22%~23%远低于50%，故2019年唯一超50%
5. 第5步：精确比较确认270/465≈58.1%为四项最大，对照选项2019年对应B项

**最快解法**：⚡ 半数判定法+分数比较：增长率=增量÷(总量−增量)；只需检查增量与基期一半的大小——2019年270>465÷2=232.5（唯一超50%），2018年150<315÷2=157.5，2023年295<1315÷2、2024年377<1610÷2，直接锁定B，无需精算四个百分数

## 易错点
- ⚠ 公式错用：增长率=增量÷(总量−增量)即除以基期量，而非增量÷当年总量；本题若误用增量÷总量（如270/735≈36.7%）虽排序碰巧不变，但数值口径错误，遇排序接近时会出错
- ⚠ 把图2右轴折线'国产化率'（72.0%→86.6%）误当作'增长率'来比较，因2024年86.6%最高而误选D——国产化率是国产设备占比，与数量增长率完全无关
- ⚠ 图2总量柱与增量柱数值标签密集且双轴混排，易看串行（如1610配86.1%、1987配377），抄数须核对白柱/黑柱归属；另注意2017年基期量=315−90=225须由增量柱倒推

## 母题抽象
> 🧩 当题干出现'某总量增长率最大的年份'且图形同时给出'总量柱+增量柱'时，用 增长率=增量÷(总量−增量)，先用'增量是否大于基期一半'判断是否超50%做排除，再对接近项做分数比较验证

### 题干
2017-2024年，我国在运行“洗衣龙”数量增长率最大的年份是        。

### 选项
- A. 2018
- B. 2019　✅
- C. 2023
- D. 2024

### 官方解析
根据题干“2017-2024年······增长率最大的年份是”，可判定本题为一般增长率问题。定位统计图可得2017-2024年我国在运行“洗衣龙”数量及其同比增量。根据公式：增长率，可得选项各年份我国在运行“洗衣龙”数量同比增长率分别为：
A项，2018年；
B项，2019年；
C项，2023年；
D项，2024年。
比较可知，2019年同比增长率最大。
故正确答案为B。
