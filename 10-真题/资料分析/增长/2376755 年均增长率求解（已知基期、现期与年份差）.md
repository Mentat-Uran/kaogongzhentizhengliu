# 年均增长率求解（已知基期、现期与年份差）

考点：[[20-考点/资料分析/增长/年均增长率求解（已知基期、现期与年份差）|增长 / 年均增长率求解（已知基期、现期与年份差）]]
材料：[[15-材料/资料分析/239310 2011—2017年全国马拉松赛事发|239310 2011—2017年全国马拉松赛事发]]

**问法模型**：题干出现'从2018年开始，每年需要平均增长多少才能实现2020年目标'→ 采用年均增长率模型：(1+r)^n = 现期目标÷基期值，n=目标年−基期年=3。

## 推理链
1. 第1步：从文字段②提取数据——2017年年度产业总规模700亿元（基期），2020年发展目标产业规模1200亿元（现期，规划值）。
2. 第2步：确定增长间隔——以2017年为基期，2018、2019、2020三年实现增长，故 n=2020−2017=3。
3. 第3步：代入年均增长率公式 (1+r)^n=现期÷基期，得 (1+r)^3=1200÷700=12/7≈1.71。
4. 第4步：代入选项验证——优先代入居中且好算的C选项，(1+20%)^3=1.728，与1.71最接近，故r≈20%，锁定C。

**最快解法**：⚡ 代入排除法（居中代入）：先算1200÷700≈1.71，再验证(1.2)^3=1.728≈1.71成立，直接选C，无需开立方精确求根。

## 易错点
- ⚠ 年份差误算为4：误以为2017—2020跨越4个年份就取n=4，实际以2017年为基期、从2018年起增长，n=3
- ⚠ 基期与现期写反：误用700÷1200导致(1+r)^3<1，或以2016年/其他年份为基期
- ⚠ 把1200亿元当成已实现的实际统计值——它是2020年规划目标值，仅作现期代入，不代表实际数据

## 母题抽象
