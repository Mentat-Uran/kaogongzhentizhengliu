# 间隔增长率（隔年增长率）

考点：[[20-考点/资料分析/增长/间隔增长率（隔年增长率）|增长 / 间隔增长率（隔年增长率）]]
材料：[[15-材料/资料分析/4146677 2022年全国银行理财市场运行情况：|4146677 2022年全国银行理财市场运行情况：]]

**问法模型**：题干问'2022年与2020年相比约（下降多少）'且选项均为'下降+百分数' → 间隔增长率模型 r = r1 + r2 + r1×r2，其中r1为2022年同比增速、r2为由'降幅扩大7.22个百分点'还原的2021年同比增速

## 推理链
1. 第1步：从材料第1段提取条件：2022年累计新发理财产品2.94万只，同比下降38.23%，降幅比上年同期扩大7.22个百分点
2. 第2步：还原2021年（中间年）同比增速：'降幅扩大'说明2021年降幅比2022年小7.22个百分点，故 r2 = -38.23% + 7.22% = -31.01%
3. 第3步：套用间隔增长率公式 r = r1 + r2 + r1×r2，代入 r1 = -38.23%、r2 = -31.01%
4. 第4步：计算线性项 -38.23% + (-31.01%) = -69.24%；乘积项 r1×r2 = (-0.3823)×(-0.3101) ≈ +11.85%（负负得正）
5. 第5步：合并得 r ≈ -69.24% + 11.85% ≈ -57.39%，即2022年比2020年约下降57%
6. 第6步：与选项对照：下降57%对应B，排除A（45%）、C（66%）、D（69%，即漏加乘积正项的错误结果）

**最快解法**：⚡ 间隔增长率公式法+截位估算：先由'降幅扩大7.22个百分点'得2021年增速 -38.23%+7.22% = -31.01%；再算 r1+r2 = -69.24%，r1×r2 ≈ 0.38×0.31 ≈ 0.118 取正号；-69.24% + 11.8% ≈ -57%，直接锁定B。考场可只验算到'介于-57%与-58%之间'即可排除C、D（D=-69%对应漏加乘积项）

## 易错点
- ⚠ '降幅比上年同期扩大7.22个百分点'方向弄反：扩大意味着2021年降幅更小（-31.01%），误写成-45.45%会得出下降约65%错选C
- ⚠ 乘积项 r1×r2 负负得正、应加回：漏加11.85%会算成-69%左右而错选D；误取负号会算成-81%
- ⚠ '降幅扩大7.22个百分点'是百分点不是百分率；另注意本题用'新发只数'的增速口径（第1段流量），与第2段'存续只数-4.41%'、'存续规模-4.66%'是不同口径，不能混用

## 母题抽象
> 🧩 当题干出现'现期与隔一年（N年与N-2年）相比增长/下降多少'且材料给出现期同比增速和'降幅扩大/收窄X个百分点'时，先用加减还原中间年增速，再套间隔增长率 r=r1+r2+r1×r2，注意乘积项两负相乘为正需加回

**同类特征**：2022年与2020年相比（隔两年）、选项均为'下降+百分数'（间隔增长率题型标志）、材料含'降幅比上年同期扩大7.22个百分点'、只数/金额同比增速、累计新发（流量口径）、负负得正的乘积项处理

### 题干
2022年全国银行机构和理财公司累计新发理财产品只数与2020年相比约：

### 选项
- A. 下降45%
- B. 下降57%　✅
- C. 下降66%
- D. 下降69%

### 官方解析
<p>根据题干“2022年······与2020年相比约”，结合选项均为“下降+百分数”，可判定本题为间隔增长率问题。定位文字材料第一段可得：2022年，全国银行机构和理财公司累计新发理财产品2.94万只，同比下降38.23%（<img flag="tex" src="../../../90-图片/公式图/formula-0149dcd72981f0c9.png" />），降幅比上年同期扩大7.22个百分点。则2021年全国银行机构和理财公司累计新发理财产品只数的同比增速<img flag="tex" src="../../../90-图片/公式图/formula-b630109bb7532d8e.png" /><img flag="tex" src="../../../90-图片/公式图/formula-2cf969623fb07739.png" />。根据间隔增长率公式：<img flag="tex" src="../../../90-图片/公式图/formula-dd771ba47dee4ba0.png" />，则题干所求<img flag="tex" src="../../../90-图片/公式图/formula-f5c415c6e7ddfd18.png" /><img flag="tex" src="../../../90-图片/公式图/formula-89d2f6451f99f0e8.png" /><img flag="tex" src="../../../90-图片/公式图/formula-5120264ebefe1565.png" />，即约下降57%。</p><p>故正确答案为B。</p>
