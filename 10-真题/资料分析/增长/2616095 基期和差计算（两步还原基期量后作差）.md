# 基期和差计算（两步还原基期量后作差）

考点：[[20-考点/资料分析/增长/基期和差计算（两步还原基期量后作差）|增长 / 基期和差计算（两步还原基期量后作差）]]
材料：[[15-材料/资料分析/260067 2019年6月及2019年上半年全国|260067 2019年6月及2019年上半年全国]]

**问法模型**：题干求'2018年1至5月'发行量，而材料只给'2019年6月当月8996亿元'与'2019年1至6月累计28372亿元'及各自同比增速 → 基期和差模型：2018年1-5月=现期累计÷(1+g累计)−现期当月÷(1+g当月)。

## 推理链
1. 第1步：题干时间'2018年1至5月'在材料中无直接数据，可提取两个现期值：2019年6月发行8996亿元（同比增长约68.4%，具体数值以原卷为准）、2019年1至6月发行28372亿元（同比增长约101.0%）。
2. 第2步：规则：基期量=现期量÷(1+同比增速)；区间和差：2018年1-5月=2018年1-6月−2018年6月，且两段同比增速不同、须分别还原。
3. 第3步：还原2018年1-6月：28372÷(1+101.03%)≈28372÷2.01≈14113亿元。
4. 第4步：还原2018年6月：8996÷(1+68.37%)≈8996÷1.68≈5343亿元（该中间量与同组题'2018年6月基期'连环复用）。
5. 第5步：作差：2018年1-5月≈14113−5343≈8770亿元。
6. 第6步：选项对照：C(14109)恰为2018年1-6月基期（漏减6月）、B(19376)=28372−8996（未还原基期）、A(23029)=28372−5343（现期累计与基期当月混减），仅D(8766)与8770最接近，故选D。

**最快解法**：⚡ 基期和差＋截位直除：28372÷2.01≈14113，8996÷1.68≈5350，相减约8760~8770，锁定D；并用选项特征秒排——B=28372−8996（未还原基期）、C≈14113（只算1-6月基期漏减6月）、A=28372−5343（口径错位），三项均无需精算即可排除。

## 易错点
- ⚠ 时间口径陷阱：2018年1-5月无直接数据，必须'累计基期−当月基期'两步相减；直接用28372−8996=19376（B项）是未还原基期的典型错解。
- ⚠ 两段同比增速不同（6月约+68.4%、1-6月约+101.0%，文本中空白需以原卷数值代入），不能共用一个增速；只算出2018年1-6月≈14113就误选C(14109)，漏减了2018年6月。
- ⚠ 口径混搭陷阱：A项23029=28372−5343，把2019年现期累计与2018年基期当月直接混减；另注意本材料中'置换债券和再融资债券'为同比减少（负增长），其基期公式是÷(1−|g|)，与本题正向增速的÷(1+g)不可混用。

## 母题抽象
> 🧩 当题干求上年同期'1至N月'而材料只给'当月'与'1至(N+1)月累计'及各自同比增速时，用基期和差两步还原：上年1至N月=现期累计÷(1+g累计)−现期当月÷(1+g当月)，并警惕'未还原基期直接相减'与'漏减当月'两类干扰选项。

**同类特征**：跨年求'上年某1至N月'区间值（如2018年1至5月）、材料仅有'当月值+累计值'双口径、两段同比增速不同需分别还原、两步还原（同比还原+区间相减）、设问带'约'字属估算型、选项含未还原基期/漏减当月/口径错位的干扰项

### 题干
2018年1至5月，全国发行地方政府债券约：

### 选项
- A. 23029亿元
- B. 19376亿元
- C. 14109亿元
- D. 8766亿元　✅

### 官方解析
根据题干“2018年1至5月······约”，定位材料第一段“2019年6月，全国发行地方政府债券8996亿元，同比增长”，第三段“2019年1至6月，全国发行地方政府债券28372亿元，同比增长”，可判定本题为基期和差问题。根据公式：基期量，可知2018年1至5月，全国发行地方政府债券亿元，与D项最接近。
故正确答案为D。
