# 年均增速比较（年均增长率大小比较）

考点：[[20-考点/资料分析/增长/年均增速比较（年均增长率大小比较）|增长 / 年均增速比较（年均增长率大小比较）]]
材料：[[15-材料/资料分析/3624575 2015-2022年我国酱油进出口贸|3624575 2015-2022年我国酱油进出口贸]]

**问法模型**：题干问'2016-2022年四个指标中年均增速最快的是'→ 用年均增速模型(现期/基期)^(1/n)−1，各指标年份差n相同时，退化为直接比较现期÷基期比值大小

## 推理链
1. 第1步：由题干判定为年均增速比较问题，定位表格取基期2015年与现期2022年数据：进口量1.16→1.17万吨、出口量11.74→18.61万吨、进口额1758→1905万美元、出口额11320→18385万美元
2. 第2步：年均增速=(现期/基期)^(1/n)−1，四个指标年份差相同（以2015为基期，n=7），只需比较现期/基期比值，比值最大者增速最快
3. 第3步：截位直除算比值：进口量1.17/1.16≈1.01；出口量18.61/11.74≈1.59；进口额1905/1758≈1.08；出口额18385/11320≈1.62
4. 第4步：比值排序：出口额1.62＞出口量1.59＞进口额1.08＞进口量1.01，故出口额年均增速最快，对照选项选D

**最快解法**：⚡ 排除法+1.6临界比较：进口量比值≈1.0、进口额≈1.1远小于其余两项先排除；出口量18.61/11.74与出口额18385/11320用1.6作临界——11.74×1.6=18.78＞18.61（出口量＜1.6），11320×1.6=18112＜18385（出口额＞1.6），出口额胜出，选D

## 易错点
- ⚠ 基期口径歧义：'2016-2022年年均增速'可按2015为基期（n=7）或2016为基期（n=6），四个指标必须统一基期口径；若用2016基期，进口量1.17/1.38≈0.85、进口额1905/2109≈0.90均为负增长，出口额18385/11940≈1.54仍＞出口量18.61/12.74≈1.46，结论不变
- ⚠ 看错列/量级混淆：进口额（千级万美元）与出口额（万级万美元）量级差约10倍，进口量与出口量同样相差约10倍，勿将2022年1905与18385、1.17与18.61串列误读
- ⚠ 现期下滑的干扰：2022年进口量、进口额较2021年双双下降（1.35→1.17、2342→1905），但比较的是基期到2022年的总倍数，勿因末期下滑而误判进口类增速，也勿因出口额基数大而误以为不宜比较
