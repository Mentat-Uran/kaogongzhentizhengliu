# 年均增长率（基期需自算，n=5次方）

考点：[[20-考点/资料分析/增长/年均增长率（基期需自算，n=5次方）|增长 / 年均增长率（基期需自算，n=5次方）]]
材料：[[15-材料/资料分析/186836 2010—2015年（“十二五”期间|186836 2010—2015年（“十二五”期间]]

**问法模型**：题干出现“‘十二五’期间……年均增长率约为”→ 用 期初×(1+r)^n=期末 模型，先减法自求基期面积，再开5次方（或代入选项验证）求 r

## 推理链
1. 第1步：定位文字段1，现期2015年末全国水果种植总面积1536.71万公顷，较“十二五”期初增加143.38万公顷
2. 第2步：基期（2010年末）面积材料未直接给出，需自算：1536.71-143.38=1393.33万公顷（用水果总面积口径，非园林水果1281.67万公顷）
3. 第3步：年均增长率模型：期初×(1+r)^n=期末，“十二五”期初2010年末→期末2015年末增长跨度n=5年，应开5次方
4. 第4步：代入得(1+r)^5=1536.71/1393.33≈1.1029≈1.103
5. 第5步：各选项数值过于接近无法粗估，需精确代入验证，逐项计算(1+r)^5与1.103比对
6. 第6步：代入选项A，(1+r)^5≈1.103，对应r≈1.98%（约2%），与精确值1.103^(1/5)-1≈1.98%一致，故选A

**最快解法**：⚡ 先减法求基期：1536.71-143.38=1393.33万公顷；再截位直除求比值：1536.71/1393.33≈1.103（即五年整体增幅约10.3%）；因选项过近无法用二分估算，改用精确代入验证：试(1.02)^5=1.0404×1.0404×1.02≈1.104，最接近1.103，锁定A（r精确约1.98%，约2%）

## 易错点
- ⚠ 基期面积是隐藏数据：须先做减法1536.71-143.38=1393.33万公顷；误把现期1536.71当基期、或误用园林水果口径1281.67（基期1154.39）均错
- ⚠ 年数n易错：“十二五”期初为2010年末、期末为2015年末，跨度为5年应开5次方；若按2010—2015共6个年份误开6次方得r≈1.6%即错
- ⚠ 年均增长率与五年整体增幅是两个概念：整体增幅=143.38/1393.33≈10.3%，年均r≈2%（约10.3%÷5的近似），且本组选项数值过近，粗估无效，必须精确验证(1.02)^5≈1.104

## 母题抽象
> 🧩 当题干出现“某五年规划期间……年均增长率约为”且期初值需减法自求时，先算基期=期末-增加量，再用(1+r)^n=期末/基期（规划期n=5）代入选项验证；(1.02)^5≈1.104可作为常用锚点

**同类特征**：十二五期间、年均增长率约为、种植面积、基期未直接给出需减法自算、跨度5年开5次方、选项接近需精确代入验证
