# 年均增长率比较（以2014年为基准，n相同比现期-基期倍数）

考点：[[20-考点/资料分析/增长/年均增长率比较（以2014年为基准，n相同比现期-基期倍数）|增长 / 年均增长率比较（以2014年为基准，n相同比现期/基期倍数）]]
材料：[[15-材料/资料分析/7364672 2014-2023年全球及主要国家和|7364672 2014-2023年全球及主要国家和]]

**问法模型**：题干问'2014-2023年平均增速（以2014年为基准）最快的是'→ 年均增长率模型，各选项年份差n相同（n=9），只需比较现期2023年与基期2014年的倍数大小，倍数最大者年均增速最快

## 推理链
1. 第1步：从统计表首列（2014年）提取四选项基期值：欧洲7.2 GW、美国6.7 GW、拉美0.5 GW、中东及北非0.3 GW
2. 第2步：从统计表末列（2023年）提取四选项现期值：欧洲61.2 GW、美国31.1 GW、拉美25.4 GW、中东及北非18.2 GW
3. 第3步：由年均增长率公式 (1+r)^n=现期/基期，年份差n相同，比较r只需比较现期/基期倍数，无需开9次方
4. 第4步：口算倍数——欧洲61.2/7.2=8.5倍；美国31.1/6.7≈4.6倍；拉美25.4/0.5=50.8倍；中东及北非18.2/0.3≈60.7倍
5. 第5步：比较得60.7＞50.8＞8.5＞4.6，中东及北非的现期/基期倍数最大，年均增速最快
6. 第6步：对照选项，D为中东及北非，与官方答案一致

**最快解法**：⚡ 倍数比较法（公式法+口算倍数）：年均增速比较题，n相同直接比'2023年/2014年'——中东及北非18.2/0.3≈60倍、拉美25.4/0.5≈51倍，两者远大于欧洲8.5倍和美国4.6倍；再粗比60.7＞50.8即锁定D，全程无需开方

## 易错点
- ⚠ 看倍数不看增量：欧洲绝对增量最大（61.2-7.2=54 GW），中东及北非增量仅17.9 GW，若按增量比较必误选A；年均增速比较只看现期/基期倍数
- ⚠ 基期量级陷阱：0.3、0.5这类小数基期对应数十倍的大倍数，勿因表中数值小而忽视其增速；同时勿看错量级把0.3当3
- ⚠ 年份差纠结：以2014年为基准对应n=9个增长年份，但四选项n相同可整体约去，不必按10年计算或开9次方浪费时间
- ⚠ 层级混淆：拉美、中东及北非是非欧美海外的子项（子项加和≠父级99.5），本题只需按行取数，勿试图用加和法校验

- C. 拉美
