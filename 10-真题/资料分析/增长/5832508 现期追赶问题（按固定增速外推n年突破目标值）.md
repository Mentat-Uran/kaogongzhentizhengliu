# 现期追赶问题（按固定增速外推n年突破目标值）

考点：[[20-考点/资料分析/增长/现期追赶问题（按固定增速外推n年突破目标值）|增长 / 现期追赶问题（按固定增速外推n年突破目标值）]]
材料：[[15-材料/资料分析/357041 2017年末杭州市常住人口总量、增长|357041 2017年末杭州市常住人口总量、增长]]

**问法模型**：题干出现'按照2017年的人口增长速度，哪一年突破1000万人'的追及外推问法 → 采用现期追赶模型：基期量×(1+增长率)^n≥目标值，解出n并向上取整，基期年份+n即答案年份

## 推理链
1. 第1步：从文字材料提取条件：2017年末杭州常住人口946.8万人（基期量），增幅3.05%（对应比2016年末增加28.0万人）
2. 第2步：所用公式：现期追赶模型 946.8×(1+3.05%)^n ≥ 1000万人，n为从2017年末起算的年数
3. 第3步：代入变形：需(1.0305)^n ≥ 1000/946.8 ≈ 1.0562；n=1时1.0305<1.0562不够（2018年末约946.8×1.0305≈975.7万<1000），n=2时1.0305²≈1.062>1.0562成立（2019年末约1005.4万>1000）
4. 第4步：解得n约为1.8，即需1年多，年份差向上取整为2年
5. 第5步：2017+2=2019年，与选项对照，2019年对应B项，故选B

**最快解法**：⚡ 缺口+逐年增量估算法：缺口=1000-946.8=53.2万；按3.05%增速，第一年增量≈946.8×3.05%≈28.9万<53.2万（一年不够，排除A/2018）；第二年增量≈975.7×3.05%≈29.8万，两年累计≈58.7万>53.2万（两年够），故2017+2=2019年突破；或用截位直除验证：1000/946.8≈1.056，比较(1.0305)²≈1.062>1.056即n=2

## 易错点
- ⚠ 取整方向错误：解得n≈1.8（需1年多），必须向上取整为2，若四舍五入取1或向下取整会误选2018（A项）
- ⚠ 起点数错：n是从2017年末起算的年数，2017+2=2019，即2019年末突破；误以为'2017年后第一年'是答案会选2018
- ⚠ 模型误用：若误用2017年增量28.0万作为每年固定增量（算术增长）验证，53.2/28≈1.9虽同得2年，但规范模型是复合增长(1+3.05%)^n，未来每年增量应递增（28.9、29.8…），勿死套28.0万
- ⚠ 口径提醒：3.05%是2017年相对2016年的增幅，题干假定该速度不变外推，不要用千分点、百分点等其他材料中的变动量混算

## 母题抽象
> 🧩 当题干出现'按照某年增长速度/增速保持不变，哪一年达到或突破某值'的特征时，用现期追赶模型：基期量×(1+r)^n≥目标值，解出n向上取整，答案=基期年份+n，并用(1+r)、(1+r)²与目标比值1000/946.8≈1.056的大小关系快速验证

### 题干
按照2017年的人口增长速度，哪一年杭州市常住人口突破1000万人？

### 选项
- A. 2018
- B. 2019　✅
- C. 2020
- D. 2021

### 官方解析
根据题干“按照2017年······增长速度，哪一年······突破1000万人”，可判定本题为现期追赶问题。定位文字材料可得：2017年末，杭州市常住人口为946.8万人，比2016年末增加28.0万人，增幅3.05%。根据公式：现期量，则，即，解得，即需要1年多，年份差n向上取整为2，则至少需要2年，即2017+2=2019年杭州市常住人口突破1000万人。
故正确答案为B。
