# 隔多年（多年复合）增长率计算

考点：[[20-考点/资料分析/增长/隔多年（多年复合）增长率计算|增长 / 隔多年（多年复合）增长率计算]]
材料：[[15-材料/资料分析/238954 某市调查总队抽样调查：2017年全市|238954 某市调查总队抽样调查：2017年全市]]

**问法模型**：题干为'2017年比2013年增长'的跨多年增长率问法 → 用图中2013-2017各年同比增速复合连乘(1+r1)(1+r2)…(1+rn)-1求解，绝不能将各年增速简单相加

## 推理链
1. 第1步：题干要求销售总收入2017年对2013年的增长率；从图中点状虚线（销售总收入）读出各年同比增速：2013年11.4%、2014年14.0%、2015年9.3%、2016年18.8%、2017年3.1%（4.2%属总资产实线，勿混）
2. 第2步：2017对2013共跨5个逐年增长环节，故增长率=(1+11.4%)×(1+14.0%)×(1+9.3%)×(1+18.8%)×(1+3.1%)-1
3. 第3步：两两迭代计算：(1+11.4%)(1+14.0%)-1≈27.0%；×(1+9.3%)-1≈38.8%；×(1+18.8%)-1≈64.9%；×(1+3.1%)-1≈70.0%
4. 第4步：若误将五数相加仅得11.4+14.0+9.3+18.8+3.1=56.6%，明显偏小（漏掉约13个百分点的复合交叉项）；计算结果≈70%与B选项对应，故选B

**最快解法**：⚡ 复合增长连乘+隔年增长公式迭代（r=r1+r2+r1×r2）：11.4%+14.0%+11.4%×14.0%≈27.0%→再+9.3%+27.0%×9.3%≈38.8%→再+18.8%+38.8%×18.8%≈64.9%→再+3.1%+64.9%×3.1%≈70.0%，锁定B；考场亦可先加总56.6%，再补交叉项约13%心算出约70%

## 易错点
- ⚠ 把5年增速直接相加得56.6%当作答案，忽略复合增长的交叉乘积项
- ⚠ 读图张冠李戴：2017年4.2%是总资产（实线方块）、3.1%才是销售总收入（点状虚线），2016年三点密集（18.8/10.5/5.1）易读错线型
- ⚠ 时间口径错误：'2017比2013增长'不能用图中任一单年同比增速（如取3.1%），也不能套用单年'现期×r/(1+r)'类模型，须复合连乘

## 母题抽象
> 🧩 当题干出现'现期比间隔多年的基期增长'且材料只给各年同比增速时，用(1+r1)(1+r2)…(1+rn)-1复合连乘（两两迭代估算）求解，验证结果应明显大于各年增速之和

**同类特征**：2017年比2013年增长、销售总收入、隔多年增长率、各年同比增速连乘、点状虚线读数、增速不能简单加总
