# 增长率计算（两期相比的下降幅度）

考点：[[20-考点/资料分析/增长/增长率计算（两期相比的下降幅度）|增长 / 增长率计算（两期相比的下降幅度）]]
材料：[[15-材料/资料分析/239250 A省2014-2017年绿色无公害农|239250 A省2014-2017年绿色无公害农]]

**问法模型**：题干为'2017年比2015年约增加/下降[百分数]'特征 → 先用两期数值大小判断方向排除选项，再套增长率公式（现期−基期）/基期计算幅度

## 推理链
1. 第1步：从统计表'单位耕地面积农药使用量（千克/亩）'行提取数据：2017年为1.47千克/亩，2015年为1.59千克/亩
2. 第2步：比较两期大小：1.47＜1.59，亩均农药使用量减少，方向锁定'下降'，排除增加方向的A、C
3. 第3步：套用变化率公式（现期−基期）/基期=(1.47−1.59)/1.59=−0.12/1.59
4. 第4步：截位直除计算幅度：0.12÷1.59≈12÷16=0.075，即约下降7.5%
5. 第5步：与选项对照：'下降'且幅度约7.5%，对应B项，故正确答案为B

**最快解法**：⚡ 先定方向后算幅度：1.47＜1.59直接锁'下降'排除A、C；再用截位直除0.12÷1.59≈7.5%，选B

## 易错点
- ⚠ 拿错行：本题比较的是'单位耕地面积农药使用量'（1.47对1.59千克/亩），若误用'农药使用总量'行（5.80对6.28万吨）则完全算错
- ⚠ 基期现期混淆：分母必须用2015年（基期）的1.59，若误用2017年的1.47作分母会得约8.2%的错误幅度
- ⚠ 时间口径：题干为2017年对2015年的隔年比较（跨过2016年），不要按同比习惯错取2016年的1.56
