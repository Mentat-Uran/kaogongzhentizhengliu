# 增长量比较（现期量×r-(1+r)）

考点：[[20-考点/资料分析/增长/增长量比较（现期量×r-(1+r)）|增长 / 增长量比较（现期量×r/(1+r)）]]


**问法模型**：题干问'2009年比2008年增产量最多'→ 对各作物用增长量公式 现期×r/(1+r) 比较大小，先用'大大则大'定性排除再定量验证

## 推理链
1. 第1步：从表格提取四类作物2009年产量与增长率：糖蔗1116.11万吨/3.4%，粮食1314.5万吨/5.7%，蔬菜2567.17万吨/5.6%，水果1061.89万吨/8.0%
2. 第2步：增长量=现期×r/(1+r)，比较遵循'大大则大'：现期量与增长率均更大者，增长量必更大
3. 第3步：粮食产量1314.5万吨与增长率5.7%均大于糖蔗（1116.11万吨、3.4%），故粮食增长量>糖蔗，排除A
4. 第4步：蔬菜与粮食增长率近似相等（5.6%≈5.7%），但现期量2567.17万吨远大于1314.5万吨，故蔬菜增长量>粮食，排除B
5. 第5步：定量验证剩余：蔬菜增长量≈2567.17×5.6%/1.056≈136万吨，水果增长量≈1061.89×8%/1.08≈78.7万吨
6. 第6步：136万吨>78.7万吨，蔬菜增长量最大，对照选项选C

**最快解法**：⚡ '大大则大'+百化分速算：先用现期、增长率双大排除A（粮食碾压糖蔗）、B（蔬菜与粮食率同量异）；剩余两组百化分：5.6%≈1/18，蔬菜增长量≈2567/(18+1)≈135万吨；8%≈1/12.5，水果增长量≈1062/13.5≈79万吨，蔬菜明显最大，秒选C

## 易错点
- ⚠ 混淆材料文字中的'种植面积'与表格中的'产量'口径——本题问增产量，须用产量数据而非面积数据（糖蔗面积是下降的，但产量是增长的）
- ⚠ 直接用现期×增长率比较而漏除以(1+r)，增长率接近时侥幸可行，但增长率差异大（如8.0%对3.4%）时可能出错
- ⚠ 只与直接相邻选项比较就下结论，须保证最大者与其他所有选项比较完备（本题需蔬菜同时压过水果）

## 母题抽象
> 🧩 当题干出现'增产量最多/增长量最大'且各选项现期量与增长率均已给出时，先用'大大则大'规则定性排除，再对剩余选项用百化分（增长率≈1/n，增长量≈现期/(n+1)）快速定量比较

**同类特征**：增产量最多、增长量比较、现期量与增长率均已知、同一指标跨选项比较、数据定位在表格而非文字材料

### 题干
下列作物2009年比2008年增产量最多的是：

### 选项
- A. 糖蔗
- B. 粮食
- C. 蔬菜　✅
- D. 水果

### 官方解析
