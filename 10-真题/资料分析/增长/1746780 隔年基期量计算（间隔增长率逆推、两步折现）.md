# 隔年基期量计算（间隔增长率逆推、两步折现）

考点：[[20-考点/资料分析/增长/隔年基期量计算（间隔增长率逆推、两步折现）|增长 / 隔年基期量计算（间隔增长率逆推、两步折现）]]
材料：[[15-材料/资料分析/180730 2014年全国市场主体情况：既有期末|180730 2014年全国市场主体情况：既有期末]]

**问法模型**：题干以'截至2012年12月底……最接近以下哪个数字'求隔年基期量 → 先由'增速较上年同期增加4.02个百分点'还原两年增速，套间隔增长率公式，再用现期量6932.22万户折现两次

## 推理链
1. 第1步：从段1提取条件：截至2014年12月底全国实有各类市场主体6932.22万户，比上年末增长14.97%（提供文本该百分数缺失，按原题完整数据回填），增速较上年同期增加4.02个百分点，求隔年基期即2012年12月底的户数
2. 第2步：还原2013年增速：r2013=14.97%-4.02%=10.95%，注意4.02个百分点是两年增速之差，不是2013年增速本身
3. 第3步：套间隔增长率公式：r2014对2012=14.97%+10.95%+14.97%×10.95%≈25.92%+1.64%≈27.56%
4. 第4步：隔年基期量=现期量÷(1+间隔增长率)=6932.22÷1.2756，等价于两步折现6932.22÷1.1497÷1.1095
5. 第5步：截位直除估算：6932.22÷1.2756≈5434万（取1.28粗估得6932÷1.28≈5400余万，量级锁定在5000~5500一带）
6. 第6步：与选项对照：5434万与B项5500万仅差约66万，与C项5100万差300余万，选项间距约400万、粗算即可锁定，故最接近B（5500万），与官方答案一致

**最快解法**：⚡ 间隔增长率公式+截位直除：先还原r2013=14.97%-4.02%=10.95%，间隔增长率≈14.97%+10.95%+15%×11%≈27.6%，再算6932.22÷1.276≈5434万；四个选项间距400万，直接选最接近的5500万（B）

## 易错点
- ⚠ 只折现一次：不还原2013年增速、直接用2014年增速一步折现6932.22÷1.1497≈6030万，会误选A（6100万）
- ⚠ 把'增速较上年同期增加4.02个百分点'当成2013年增速本身或当成独立的第三年增速，间隔增长率公式套错
- ⚠ 时间与指标口径：问的是'截至2012年12月底'的存量户数，基期为隔年的2012年末而非2013年末，且应取户数6932.22万户，不能误用注册资本129.23万亿元

## 母题抽象
> 🧩 当题干问'两年前（隔年）的基期量'且材料给出'现期增速+增速较上年增加/回落n个百分点'时，先用r上年=r现期∓n个百分点还原两个增速，再用间隔增长率r间=r1+r2+r1×r2，最后用现期量÷(1+r间)与'最接近'型选项对照锁定答案

**同类特征**：截至2012年12月底（隔年基期、时点存量）、最接近以下哪个数字（估算式选项）、增速较上年同期增加4.02个百分点（需百分点差还原）、全国实有各类市场主体户数、间隔增长率+两步折现、选项间距大可粗算
