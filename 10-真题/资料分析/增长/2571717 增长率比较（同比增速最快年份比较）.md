# 增长率比较（同比增速最快年份比较）

考点：[[20-考点/资料分析/增长/增长率比较（同比增速最快年份比较）|增长 / 增长率比较（同比增速最快年份比较）]]
材料：[[15-材料/资料分析/257533 2010～2017年我国生物质发电的|257533 2010～2017年我国生物质发电的]]

**问法模型**：题干问'同比增速最快的年份是'→ 对各年份分别套用增长率=（现期值−基期值）/基期值（基期为上一年年末装机），算后比较大小

## 推理链
1. 第1步：从统计图左轴柱形读取各年年末装机容量：2010年550、2011年700、2012年770、2013年900、2014年1070、2015年1120、2016年1225、2017年1476（文字精确值1476.2）万千瓦
2. 第2步：增长率为一般增长率比较，公式为增长率=（现期值−基期值）/基期值，各年基期取上一年年末装机
3. 第3步：代入四个选项年份：2011年(700−550)/550=150/550≈27.3%；2013年(900−770)/770=130/770≈16.9%；2014年(1070−900)/900=170/900≈18.9%；2017年(1476.2−1225)/1225=251.2/1225≈20.5%
4. 第4步：比较得27.3%＞20.5%＞18.9%＞16.9%，2011年同比增速最快，对应A选项

**最快解法**：⚡ 截位直除＋首位商比较：四个年份均算'增长量/基期'，2011年150/550首位商2（约27%），而130/770、170/900、251/1225首位均商1，仅2011年首位商2，无需精算直接锁定A；辅以性质：2017年增长量251.2虽最大，但基期1225也大，增速反不及2011年

## 易错点
- ⚠ 双轴图陷阱：装机看左轴柱形（万千瓦），勿误读折线发电量数据计算装机增速
- ⚠ 基期混淆：2011年的基期是2010年550万千瓦，各年基期均为上一年年末值，勿错用当年发电量或当年装机作分母
- ⚠ 直观误判：2017年柱子增量最大（约251），易误认为增速最快，实际因基期大增速仅约20.5%；另图中2017年1476为约数，精确计算应用文字值1476.2，但不影响结论

## 母题抽象
> 🧩 当题干出现'某年间……同比增速最快（最大）的年份是'且材料给逐年数据时，逐年套（现期−上年）/上年，用'增长量/基期'截位直除比首位商，验证最大增量年份未必是最大增速年份

**同类特征**：2011～2017年间、年末装机容量、同比增速最快、年份比较、柱形数据（左轴）
