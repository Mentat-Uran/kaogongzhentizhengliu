# 增长量计算（已知现期值与同比增长率）

考点：[[20-考点/资料分析/增长/增长量计算（已知现期值与同比增长率）|增长 / 增长量计算（已知现期值与同比增长率）]]
材料：[[15-材料/资料分析/195178 2017年上半年全国居民收入与消费支|195178 2017年上半年全国居民收入与消费支]]

**问法模型**：题干问'2017年上半年人均财产净收入比上年约增加多少元'→增长量计算模型：增长量=现期值×r/(1+r)，r百化分为1/n后等价于现期/(n+1)估算

## 推理链
1. 第1步：从文字材料第二段提取：2017年上半年人均财产净收入现期值1056元，同比名义增长率在所给文本中空缺（原文为图片），须回原图读取；按官方答案A=92元反推该增长率约为9.5%~9.6%，取9.6%口径代入。
2. 第2步：所用公式：基期=现期/(1+r)，增长量=现期−基期=现期×r/(1+r)。
3. 第3步：代入计算：1056×9.6%/109.6% = 101.376/1.096 ≈ 92.5元（若按9.5%代入，1056×9.5%/109.5% ≈ 91.6元，同样落在92附近）。
4. 第4步：与选项对照：92.5元与A项92最接近（B为102、C为112、D为122均明显偏离），故正确答案为A。

**最快解法**：⚡ 百化分+截位直除：将9.6%≈1/10.4，增长量=现期/(n+1)=1056/11.4≈92.6元；更粗快捷径取9.6%≈10%=1/10，增长量≈1056/11≈96元，虽不精确但距A项92（差约4）比距B项102（差约6）更近，秒选A。

## 易错点
- ⚠ 公式误用陷阱：直接算1056×9.6%≈101元，会误选B（102）；增长量必须乘r/(1+r)，多除一个(1+r)。
- ⚠ 数据空缺陷阱：文字段各'增长'后的百分数在所给文本中呈空缺（原文系图片），且所附图片仅为消费支出表，财产净收入增长率须回原图确认，不得凭印象臆造代入。
- ⚠ 口径与单位：1056元是2017年上半年'人均'半年累计的现期值，非基期、非全国总量；求的是增长量（元），不是增长率也不是基期值。
