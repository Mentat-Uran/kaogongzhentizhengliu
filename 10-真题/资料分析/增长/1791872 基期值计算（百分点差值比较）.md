# 基期值计算（百分点差值比较）

考点：[[20-考点/资料分析/增长/基期值计算（百分点差值比较）|增长 / 基期值计算（百分点差值比较）]]
材料：[[15-材料/资料分析/182298 2014年全国农民工参加'五险一金'|182298 2014年全国农民工参加'五险一金']]

**问法模型**：题干问'2013年（基期）A比B高多少个百分点'，材料只给2014年参保率和'比上年提高'→先用'现期−提高'分别反推两地基期参保率，再作差

## 推理链
1. 第1步：定位表格工伤保险列，2014年东部参保率29.8%、比上年提高1.0个百分点；中部参保率17.8%、比上年提高1.6个百分点
2. 第2步：规则——'比上年提高'是百分点差值，2013年参保率=2014年参保率−提高值（做减法，不能当增长率做除法）
3. 第3步：东部2013年=29.8−1.0=28.8%；中部2013年=17.8−1.6=16.2%
4. 第4步：作差：28.8%−16.2%=12.6个百分点
5. 第5步：与选项对照，12.6个百分点对应A，故正确答案为A

**最快解法**：⚡ 口算减法+尾数验证：29.8−1.0=28.8，17.8−1.6=16.2，差为12.6；用尾数快速锁定（0.8−0.6=0.2→16.2，28.8−16.2尾数0.6→12.6），秒选A

## 易错点
- ⚠ 基期/现期混淆：直接用2014年参保率作差29.8−17.8=12.0，误选B（B正是现期差陷阱）
- ⚠ 把'比上年提高'当增长率做除法求基期（如29.8÷1.01），口径错误——提高列是百分点，必须做减法
- ⚠ 忘记对东、中两行分别减去各自的提高值（1.0与1.6不同），或忽略符号运算导致差值算错

## 母题抽象
> 🧩 当题干出现'基期年份A比B高（低）多少个百分点'且表格给现期值与'比上年提高'两列并排时，用'现期−提高'分别反推基期再作差，带符号运算，答案单位是百分点

**同类特征**：2013年（基期年份）、参保率比较、高多少个百分点、东/中部地区分组、现期值−提高值反推基期、两行数据分别处理后再作差
