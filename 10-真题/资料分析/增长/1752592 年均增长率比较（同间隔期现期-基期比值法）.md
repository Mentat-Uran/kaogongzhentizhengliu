# 年均增长率比较（同间隔期现期-基期比值法）

考点：[[20-考点/资料分析/增长/年均增长率比较（同间隔期现期-基期比值法）|增长 / 年均增长率比较（同间隔期现期/基期比值法）]]
材料：[[15-材料/资料分析/181128 2005—2013年中国科技人力资源|181128 2005—2013年中国科技人力资源]]

**问法模型**：题干问'哪个时间段内每万人口中的科技人力资源数年均增速最慢'→四个时间段间隔均为5年，年均增长率(1+r)^n=现期/基期，n相同则直接比较现期/基期比值，比值最小者增速最慢

## 推理链
1. 第1步：锁定折线指标'每万人口中科技人力资源数'（右轴，单位人）：2005年268、2006年292、2007年321、2008年354、2010年425、2011年468、2012年498、2013年522（2009年389本题不用）
2. 第2步：核对四个选项的间隔年数：2010-2005=2011-2006=2012-2007=2013-2008=5年，间隔相同，故比较年均增速只需比较各段现期/基期比值
3. 第3步：代入计算比值：A项425/268≈1.59；B项468/292≈1.60；C项498/321≈1.55；D项522/354≈1.47
4. 第4步：D项比值1.47在四个比值中最小，即2008—2013年每万人口中科技人力资源数年均增速最慢，与选项对照锁定D

**最快解法**：⚡ 比值比较法（截位直除）：先确认各段间隔同为5年，再逐项估现期÷基期的首位商——D项522/354首位仅1.4（354×1.5=531>522），明显小于A的1.5+、B的1.6+、C的1.5+，直接锁定D，其余三项无需精算

## 易错点
- ⚠ 双轴陷阱：必须读方块折线（右轴，单位'人'），误读白色柱或黑色柱（左轴，单位'万人'）则全盘皆错
- ⚠ 分段起点错位：四个选项基期年份各不相同（2005/2006/2007/2008），须按选项逐段取对应起点值，不能统一直接用2005年数据与2010年及以后比较
- ⚠ 误开5次方：见'年均增速'就习惯性开n次方，本题各段间隔年数相同，开方比较与直接比值比较结论一致，直接比值即可省时；若各段间隔不同则不可省略

## 母题抽象
> 🧩 当题干出现'哪个时间段年均增速最快/最慢'且各选项间隔年数相同时，直接比较各段现期÷基期比值（比值最大→增速最快，最小→最慢），无需开n次方；若间隔不同，需先化成同口径再比

**同类特征**：年均增速最慢、四个时间段选项、起点年份逐段错开、同一折线指标分段比较、各段间隔年数相同（均为5年）、双轴图中折线数据定位

### 题干
下列时间段中，哪个时间段内每万人口中的科技人力资源数年均增速最慢？

### 选项

- B. 2006—2011年
- C. 2007—2012年
- D. 2008—2013年　✅

根据题干“···年均增速最慢”，可判定本题为年均增长率比较问题。定位图形材料可知：每万人口中科技人力资源数，2005年268人、2006年292人、2007年321人、2008年354人、2009年389人、2010年425人、2011年468人、2012年498人、2013年522人。根据公式：，因为各时段间隔年份相同则比较年均增长率大小直接比较现期与基期比值大小即可。
A，2005—2010年：；
B，2006—2011年：；
C，2007—2012年：；
D，2008—2013年：。根据上述计算可知2008—2013年的年均增速最小。故2008—2013年这个时间段内每万人口中的科技人力资源数年均增速最慢。
