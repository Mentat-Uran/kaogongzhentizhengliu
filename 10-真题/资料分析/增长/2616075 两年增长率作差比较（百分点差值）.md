# 两年增长率作差比较（百分点差值）

考点：[[20-考点/资料分析/增长/两年增长率作差比较（百分点差值）|增长 / 两年增长率作差比较（百分点差值）]]
材料：[[15-材料/资料分析/260066 中国人工智能产业：2014—2018|260066 中国人工智能产业：2014—2018]]

**问法模型**：题干问'A年同比增长率与B年相比约增加/减少多少个百分点' → 对两年分别用（本期−上期）/上期求增速，先定增减方向，再作差得百分点数值

## 推理链
1. 第1步：题干比较2017年与2015年的同比增长率；从图1提取所需四笔数据：2014年51.7亿元、2015年70.2亿元、2016年100.6亿元、2017年152.1亿元（文字段中2018年增速为空格，本题用不到）
2. 第2步：增长率公式 r=(本期−上期)/上期；百分点变化 = r₂₀₁₇ − r₂₀₁₅
3. 第3步：2017年增速 = (152.1−100.6)/100.6 = 51.5/100.6 ≈ 51.2%
4. 第4步：2015年增速 = (70.2−51.7)/51.7 = 18.5/51.7 ≈ 35.8%
5. 第5步：作差 51.2% − 35.8% ≈ +15.4个百分点，差值为正即2017年增速更高，方向为'增加'
6. 第6步：对照选项：数值≈15.4、方向为增加，锁定D'增加了15.4个百分点'

**最快解法**：⚡ 截位直除+口算作差：51.5/100.6截位直除首位商5，得约51%；18.5/51.7截位直除得约35.8%（≈36%）；51.2%−35.8%≈15.4个百分点且2017年增速更高，方向'增加'、数值'15.4'双验证直接选D，无需精算到小数

## 易错点
- ⚠ 增速必须现算：文字中2018年增速是空格，图1只给各年规模（当期值），2017年和2015年的增速都须用相邻两年差值自行求出，切勿把柱高数值或柱高增量直接当增长率
- ⚠ 方向与单位双重坑：2017年增速(≈51.2%)高于2015年(≈35.8%)，方向是'增加'，勿误选A/C；两增速作差的单位是'个百分点'，D项不能读成'增长了15.4%'
- ⚠ 基期对应错位：2017年增速的基期是2016年100.6，2015年增速的基期是2014年51.7，若取错相邻年份（如把152.1的基期错配到其他年份）会算出错误差值而误选13.3等干扰项

## 母题抽象
> 🧩 当题干出现'某年同比增长率与另一年相比增加/减少多少个百分点'特征时，分别用（本期−上期）/上期求两年增速，先比大小定'增加/减少'方向，再作差（单位：百分点）验证选项数值

**同类特征**：同比增长率与某年相比、增加/减少了……个百分点、两个年份增速作差比较、增速未直接给出需现算、柱状图逐年数据、基期量须取相邻上年数值

### 题干
2017年中国人工智能市场规模同比增长率与2015年相比约：

### 选项
- A. 减少了13.3个百分点
- B. 增加了13.3个百分点
- C. 减少了15.4个百分点
- D. 增加了15.4个百分点　✅

### 官方解析
根据题干“2017年······同比增长率与2015年相比”，可判定本题为一般增长率问题。定位柱形图1，2017年和2016年中国人工智能市场规模分别为152.1亿元和100.6亿元，则2017年中国人工智能市场规模同比增长率约为，2015年和2014年中国人工智能市场规模分别为70.2亿元和51.7亿元，则2015年中国人工智能市场规模同比增长率约为，故2017年中国人工智能市场规模同比增长率与2015年相比约增加了，即增加了15.9个百分点，与D项最接近。
故正确答案为D。
