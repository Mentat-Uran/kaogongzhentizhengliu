# 增速回落幅度（百分点）比较

考点：[[20-考点/资料分析/增长/增速回落幅度（百分点）比较|增长 / 增速回落幅度（百分点）比较]]
材料：[[15-材料/资料分析/187418 国家统计局抽样调查口径下，2011-|187418 国家统计局抽样调查口径下，2011-]]

**问法模型**：题干问'同比增速下降最多的年份'→ 直接比较文字材料中各年'比上年回落X个百分点'的差值大小，取最大者对应的年份。

## 推理链
1. 第1步：从文字材料提取条件：2012年、2013年、2014年和2015年农民工总量增速分别比上年回落0.5、1.5、0.5、0.6个百分点，比较区间限定2012-2015年。
2. 第2步：明确规则：'增速下降量'即增速的同比变化幅度，单位是百分点（差值），等于'上年增速-当年增速'，文字已直接给出，无需再用公式计算。
3. 第3步：比较四个回落量：2012年0.5 < 2014年0.5 < 2015年0.6 < 2013年1.5，最大值为1.5个百分点。
4. 第4步：可用图2折线交叉验证：2012年3.9%→2013年2.4%，差1.5个百分点，与文字一致，其余各年差值分别为0.5、0.5、0.6个百分点。
5. 第5步：回落1.5个百分点对应2013年，与选项B对照，故正确答案为B。

**最快解法**：⚡ 直接读数比较法：文字中并列给出'回落0.5、1.5、0.5、0.6个百分点'，四个数一眼扫出最大值1.5，对应第2个年份2013年，全程零计算；图2折线仅作验证，不必读图。

## 易错点
- ⚠ 把'回落X个百分点'误当成增速本身：回落量是百分点差值，若误用增速数值（4.4、3.9、2.4、1.9、1.3）排序会得出错误结论；注意增速最低的2015年（1.3%）并不是回落最多的年份。
- ⚠ 混淆本题与兄弟题第1题：'增速下降最多'比的是百分点差（2013年最大），'总量增长最多'比的是相邻柱相减的增量（2012年+983万人最大），两个问法答案不同。
- ⚠ 时间范围陷阱：题干限定2012-2015年，2011年增速4.4%虽最高但不在比较范围（也无上年数据可算回落量）；另注意正文'增长 。'处增速数值缺失，本题恰好不需要该缺失值。

## 母题抽象
> 🧩 当题干出现'增速下降/回落最多的年份'这类特征时，回文字材料找'回落X个百分点'的并列数据，直接比较百分点差值取最大即可，无需计算各年增速；若文字未给出回落量，再用'上年增速-当年增速'逐年相减（图2折线读数）。

**同类特征**：同比增速下降最多、回落……个百分点、2012-2015年、年份比较、百分点与百分数之辨、文字材料直接读数

### 题干
2012-2015年，我国农民工同比增速下降最多的年份是：

### 选项
- A. 2012
- B. 2013　✅
- C. 2014
- D. 2015

### 官方解析
定位文字材料“2012年、2013年、2014年和2015年农民工增速分别比上年回落0.5、1.5、0.5和0.6个百分点”，因此农民工同比增速下降最多的是2013年。
故正确答案为B。
