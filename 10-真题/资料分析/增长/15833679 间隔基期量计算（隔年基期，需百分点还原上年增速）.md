# 间隔基期量计算（隔年基期，需百分点还原上年增速）

考点：[[20-考点/资料分析/增长/间隔基期量计算（隔年基期，需百分点还原上年增速）|增长 / 间隔基期量计算（隔年基期，需百分点还原上年增速）]]
材料：[[15-材料/资料分析/7875246 2025年3-11月全国手机及智能手|7875246 2025年3-11月全国手机及智能手]]

**问法模型**：题干问'2023年7月（较现期2025年7月隔一年）产量在哪个范围内' → 采用间隔基期模型：基期量=现期量÷(1+间隔增长率)，其中间隔增长率=r2025+r2024+r2025×r2024，r2024须由'增速较上年同期减少的百分点'加回还原

## 推理链
1. 第1步：定位统计表7月行，2025年7月全国手机当期产量12074万部，同比增速-5.9%，增速较上一年度同期减少11.9个百分点
2. 第2步：还原2024年7月同比增速：-5.9%+11.9%=+6.0%（'减少'的百分点需加回，符号反转）
3. 第3步：求间隔增长率 r = -5.9%+6.0%+(-5.9%)×6.0% = 0.1%-0.354% ≈ -0.25%
4. 第4步：隔年基期量 = 12074÷(1-0.25%) ≈ 12105万部（分步验证：12074÷1.06≈11390万部，再÷0.941≈12104万部，两种口径一致）
5. 第5步：换算单位，12105万部≈1.21亿部，介于1.2亿-1.25亿部之间，对照选项锁定B

**最快解法**：⚡ 隔年基期近似法：间隔增长率 r=-5.9%+6.0%-0.35%≈-0.25%≈0，说明2023年基期量≈现期量12074万部=1.2074亿部，直接落在1.2亿-1.25亿区间（12000万部<12074万部<12500万部），无需精算即可秒选B；若求稳则两步截位直除：12074÷1.06≈11390，11390÷0.941≈12105万部

## 易错点
- ⚠ 百分点还原符号陷阱：'增速较上年同期减少11.9个百分点'指2024年增速比2025年高11.9个百分点，应做-5.9%+11.9%=+6.0%；若误减成-17.8%，会算出约1.28亿部而误选C
- ⚠ 间隔增长率漏乘积项：不能只算-5.9%+6.0%=+0.1%就直接代入，严谨须加r1×r2=-0.354%，得r≈-0.25%（本题数值极小不影响区间，但方法必须完整）
- ⚠ 单位口径换算：选项以'亿部'设区间，材料单位为'万部'，12074万部=1.2074亿部，未换算或错位换算会导致区间比对出错；且题干是'当期（当月）产量'，不可按累计口径理解
