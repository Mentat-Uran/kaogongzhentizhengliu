# 基期量计算（时点值差法：基期时点值=现期时点值-期间新增量）

考点：[[20-考点/资料分析/增长/基期量计算（时点值差法：基期时点值=现期时点值-期间新增量）|增长 / 基期量计算（时点值差法：基期时点值=现期时点值-期间新增量）]]
材料：[[15-材料/资料分析/194343 2016年江苏规模以上光伏产业的年度|194343 2016年江苏规模以上光伏产业的年度]]

**问法模型**：题干问'2015年末…累计装机容量'即求基期时点值 → 用材料'2016年末累计546万千瓦（时点量）-2016年当年新增123万千瓦（期间量）'的存量差模型直接作减法

## 推理链
1. 第1步：题干求2015年末（基期）累计装机容量，材料末句给2016年数据：光伏发电新增装机容量123万千瓦、年末累计装机容量546万千瓦
2. 第2步：口径判断——'年末累计'是时点存量，'当年新增'是期间发生量，二者满足：2016年末累计 = 2015年末累计 + 2016年新增
3. 第3步：移项得公式：基期时点值 = 现期时点值 - 期间新增量 = 546 - 123
4. 第4步：代入计算：546 - 123 = 423（万千瓦）
5. 第5步：与选项对照——423万千瓦即选项B；干扰项核对：A=123（新增量）、C=546（现期值）、D=546+123=669（方向反了）均被排除

**最快解法**：⚡ 时点值差法（口算减法）：2015年末 = 546 - 123 = 423万千瓦，秒选B；考场用尾数验证：6-3尾数为3，仅B（423）符合

## 易错点
- ⚠ 时点量与期间量混淆：123万千瓦是2016年全年新增（期间发生量），546万千瓦是2016年末累计（时点存量），误把123当基期值选A、误把546当基期值选C
- ⚠ 方向搞反：误将新增量加回现期值得546+123=669万千瓦误选D（相当于把2016年末当成基期往前加）
- ⚠ '累计装机容量'是存量指标，与文字段总产值/利润的'增长率+回落个百分点'信息无关，不要被并列混排的三组'值+增速'数据带偏去套增长率公式

## 母题抽象
> 🧩 当题干出现'上年（基期）年末累计/存量'且材料给出'现期年末累计+当年新增量'时，用'基期时点值=现期时点值-期间新增量'作减法，并用尾数法验证选项

**同类特征**：2015年末、累计装机容量、新增装机123万千瓦、年末累计546万千瓦、万千瓦时点存量、基期计算

### 题干
2015年末江苏光伏发电累计装机容量是：

### 选项
- A. 123万千瓦
- B. 423万千瓦　✅
- C. 546万千瓦
- D. 669万千瓦

### 官方解析
根据题干“2015年末江苏光伏发电累计装机容量”，结合材料数据为2016年，可判定本题为基期计算问题。定位文字材料最后一句可得：2016年光伏发电新增装机容量123万千瓦，年末累计装机容量546万千瓦。根据公式：，2015年末江苏光伏发电累计装机容量万千瓦。
故正确答案为B。
