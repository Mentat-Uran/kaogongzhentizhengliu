# 同比增长率计算（分量增速，一般增长率）

考点：[[20-考点/资料分析/增长/同比增长率计算（分量增速，一般增长率）|增长 / 同比增长率计算（分量增速，一般增长率）]]
材料：[[15-材料/资料分析/309616 2012—2016年全国就业人员数量|309616 2012—2016年全国就业人员数量]]

**问法模型**：题干为'某年……同比增长率最接近哪个百分数'→ 用(现期−基期)/基期 = 增长量/基期，估算后与选项对照

## 推理链
1. 第1步：由题干定位基期为2013年、现期为2014年，均指乡村就业人员；从堆积柱状图深灰上段标签读取：2013年乡村38240万人，2014年乡村39310万人
2. 第2步：一般增长率公式：同比增长率 =（现期值−基期值）/基期值
3. 第3步：代入计算：(39310−38240)/38240 = 1070/38240 ≈ 0.028，即约2.8%
4. 第4步：与选项对照：A 2.5%、B 2.8%、C 3.4%、D 4.4%，2.8%精确匹配，故选B

**最快解法**：⚡ 截位直除＋百化分：增量1070，除以基期38240，取 1070/38240 ≈ 1070/38000 ≈ 1/35.5 ≈ 2.8%，或首两位商2.8直接锁定B，无需精算

## 易错点
- ⚠ 柱内标签对应颠倒：上段（深灰）才是乡村、下段（浅灰）是城镇；若误取城镇数据(38737→37943)会得到负增长，方向性错误
- ⚠ 基期现期混淆：分母应为基期2013年的38240，若误用现期39310作分母（1070/39310≈2.7%）数值虽仍近2.8%但模型错误，选项更接近时会被带偏
- ⚠ 本图乡村增速为百分之几量级（约2.8%），勿与全国总量0.2%—0.4%量级的极小增速混淆；且材料导读提示2012年无基期数据，凡增长率题基期只能在2013—2015年
