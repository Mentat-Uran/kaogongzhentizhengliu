# 一般增长率计算（结合比重反推总量）

考点：[[20-考点/资料分析/增长/一般增长率计算（结合比重反推总量）|增长 / 一般增长率计算（结合比重反推总量）]]
材料：[[15-材料/资料分析/6366920 2013—2022年中国与共建国家进|6366920 2013—2022年中国与共建国家进]]

**问法模型**：题干问'柱值最低年份的隐含总量（外贸总值）比上年同期变化幅度' → 先定位柱值最低年份及其上年数据，用分量÷比重反推两年总量，套增长率=(现期−基期)/基期，与10%门槛对照

## 推理链
1. 第1步：观察柱状图，2013-2022年进出口总额最低的年份为2016年（1.42万亿美元），对应占比38.6%；其上年2015年为1.54万亿美元、占比38.9%
2. 第2步：材料未直接给外贸总值，须用'分量÷比重=总量'反推：中国外贸总值=进出口总额÷占比；增长率=(2016年−2015年)÷2015年
3. 第3步：反推两年总量：2016年=1.42÷38.6%≈3.68万亿美元，2015年=1.54÷38.9%≈3.96万亿美元
4. 第4步：代入增长率公式：(3.68−3.96)÷3.96≈−0.28÷3.96≈−7.1%
5. 第5步：下降约7.1%，未超过10%，对照选项为'下降了不到10%'，选B

**最快解法**：⚡ 比值法（作商消元）避免两次除法：2016/2015年外贸总值=(1.42÷1.54)×(38.9÷38.6)≈0.922×1.008≈0.929，即同比下降约7.1%（<10%），直接选B；保守做法用截位直除分别反推3.68与3.96后再作商

## 易错点
- ⚠ 串轴与口径陷阱：柱（万亿美元）与线（%）分属两轴，必须'柱值÷占比'反推外贸总值；直接用柱值1.42、1.54算增长率（≈−7.8%）口径错误，本题碰巧同落'不到10%'区间，换题即失分
- ⚠ 基期定位：'比上年同期'指与2015年比较，勿误与2013年基期或与前后其他年份比较
- ⚠ 幅度判断：−7.1%是'下降不到10%'，勿见负号就选'下降10%以上'；另注意2016年占比38.6%略低于2015年38.9%，占比变化会轻微抵消降幅，须按公式精确计算而非目测

### 选项
- A. 下降了10%以上
- B. 下降了不到10%　✅

- D. 上升了不到10%
