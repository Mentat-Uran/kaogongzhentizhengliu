# 年均增长率推总增长率（间隔总增幅计算，n=3）

考点：[[20-考点/资料分析/增长/年均增长率推总增长率（间隔总增幅计算，n=3）|增长 / 年均增长率推总增长率（间隔总增幅计算，n=3）]]
材料：[[15-材料/资料分析/187290 2012-2015年我国国民经济发展|187290 2012-2015年我国国民经济发展]]

**问法模型**：题干问'2015年服务业投资额相当于2012年的增长率'→材料给2012-2015年均增速r，按复利推总：总增长率=(1+r)³−1，间隔年数n=2015−2012=3

## 推理链
1. 第1步：定位材料第2段——2015年我国服务业投资额为31.19万亿元，'2012-2015年均增长'后接年均增速r（本呈现中该百分比数值留空，解题前必须回原图读取，严禁凭经验补数）
2. 第2步：2012→2015跨3个增长期（2012→2013→2014→2015），套年均增长率复利公式：现期=基期×(1+r)³，故n=3而非4
3. 第3步：所求为总增长率而非年均增速本身：总增长率=(1+r)³−1，将原图读出的r代入展开；31.19万亿元绝对额是干扰量，求比率无需参与计算
4. 第4步：用常见档位锚点估算量级（(1+10%)³≈1.33、(1+15%)³≈1.52、(1+20%)³≈1.73，即总增幅约33%/52%/73%档），把计算结果与四个选项比对，锁定区间匹配项
5. 第5步：与选项对照，官方正确答案为B

**最快解法**：⚡ 公式法（复利推总）+锚点估算：总增长率=(1+r)³−1，n=3；记住(1.1)³≈1.33、(1.15)³≈1.52、(1.2)³≈1.73三个锚点，把原图读出的年均增速r就近归档，直接匹配选项，无需动用31.19万亿元

## 易错点
- ⚠ 年份数n取值错误：'2012-2015年均增长'间隔为3年，n=3，易错把2012/2013/2014/2015四个年份当4期而乘(1+r)⁴
- ⚠ 问的是'2015相当于2012的总增长率'，是累计增长率；若把年均增速r本身当答案直接选，必错
- ⚠ 口径混用：本段年均增速为2012-2015跨度，与同段服务业增加值的2013-2015年均增速跨度、数值均不同，两段百分比不可互串；且材料原文该百分比留空，必须回原图核对真实数值

## 母题抽象
> 🧩 当题干出现'现期(2015)某量相当于基期(2012)的增长率'且材料给'2012-2015年均增长r'时，用复利公式总增长率=(1+r)^n−1，先核对n=年份间隔（本类题n=3），再用(1.1)³/ (1.15)³/ (1.2)³锚点估算锁选项

**同类特征**：相当于2012年的增长率、2012-2015年均增长、服务业投资额、总增长率/累计增幅、年均增长率与总增长率互算、n=3
