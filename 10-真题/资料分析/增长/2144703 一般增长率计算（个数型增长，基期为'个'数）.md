# 一般增长率计算（个数型增长，基期为'个'数）

考点：[[20-考点/资料分析/增长/一般增长率计算（个数型增长，基期为'个'数）|增长 / 一般增长率计算（个数型增长，基期为'个'数）]]
材料：[[15-材料/资料分析/192279 2012-2016年S省城镇化水平：|192279 2012-2016年S省城镇化水平：]]

**问法模型**：题干'与2012年相比，2016年…数量增长了（%）'→ 一般增长率模型：增长率=（现期个数−基期个数）÷基期个数

## 推理链
1. 第1步：从材料第2段提取条件：全省11个市中'城镇人口超过___'的市由2012年的5个增加为2016年的8个（阈值数值虽被挖空，但个数5→8完整可用）
2. 第2步：题干问'增长了'且选项均为百分数，判定为一般增长率问题，而非增长量问题
3. 第3步：代入增长率公式：（8−5）÷5=3÷5
4. 第4步：计算得3/5=60%，与选项对照，C为60%，故选C

**最快解法**：⚡ 心算直除：增长量=8−5=3个，基期=5个，3/5=60%，一步口算即出；关键是锁死分母为基期'5个'

## 易错点
- ⚠ 分母用错：若误用现期8个作分母得（8−5）/8=37.5%，落入选项干扰项；增长率基期分母必须是2012年的5个
- ⚠ 问'增长了'对应百分数选项，是增长率而非增长量'3个'，不要因题干阈值数值被挖空而误判无解或犹豫
- ⚠ 单位口径：此题运算对象是'个'数，勿与材料中人口'万人'、率的'个百分点'（如1.56、1.62、1.53）混淆

## 母题抽象
> 🧩 当题干出现'某类个数由a年的X个增加为b年的Y个，…增长了（%）'时，用（Y−X）/X求增长率，并验证分母取基期个数X而非现期Y

**同类特征**：与2012年相比…2016年…增长了、城市（市）数量、由5个增加为8个、选项为百分数形式、一般增长率问题、现期−基期除以基期
