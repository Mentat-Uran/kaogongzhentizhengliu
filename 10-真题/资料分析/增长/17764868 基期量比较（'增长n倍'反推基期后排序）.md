# 基期量比较（'增长n倍'反推基期后排序）

考点：[[20-考点/资料分析/增长/基期量比较（'增长n倍'反推基期后排序）|增长 / 基期量比较（'增长n倍'反推基期后排序）]]
材料：[[15-材料/资料分析/6025928 2024年春节假期（2月10~17日|6025928 2024年春节假期（2月10~17日]]

**问法模型**：题干问2023年（基期）三大机场日均客流量由高到低排名 → 用基期量=现期量÷(1+增长倍数)逐个反推，再比较大小排序

## 推理链
1. 第1步：定位材料第二段：2024年春节假期上海浦东、广州白云、北京首都机场日均客流量分别为8.8万、3.7万、3.4万人次，较2023年春节假期分别增长4.9倍、6.2倍、7.5倍
2. 第2步：题干时间(2023年)早于材料时间(2024年)，为基期问题；'增长n倍'即现期=基期×(1+n)，故基期=现期÷(1+n)，三个除数分别为1+4.9=5.9、1+6.2=7.2、1+7.5=8.5
3. 第3步：上海浦东2023年日均≈8.8÷5.9≈1.49万人次，广州白云≈3.7÷7.2≈0.51万人次，北京首都=3.4÷8.5=0.4万人次
4. 第4步：比较得1.49＞0.51＞0.4，即上海浦东＞广州白云＞北京首都，与选项B完全一致
5. 第5步：反向验证：若误把基期算成现期×(1+n)，则首都3.4×8.5=28.9万反而超过白云3.7×7.2=26.6万，名次变为浦东、首都、白云（错选A），说明除法方向才是正确的

**最快解法**：⚡ 分数性质比较（几乎不用算）：三个基期量写成分数8.8/5.9、3.7/7.2、3.4/8.5；浦东分子最大且分母最小，必为最大；白云与首都相比，白云分子3.7＞3.4且分母7.2＜8.5，'分子大且分母小者必大'，故白云＞首都；直接锁定'上海浦东、广州白云、北京首都'选B

## 易错点
- ⚠ '增长4.9/6.2/7.5倍'是增长倍数，基期=现期÷(1+n)，须除以5.9/7.2/8.5；若把增长方向搞反误乘以(1+n)，首都3.4×8.5=28.9反超白云3.7×7.2=26.6，名次变为浦东、首都、白云而错选A
- ⚠ 误把'增长n倍'读成'是基期的n倍'而直接除以4.9/6.2/7.5——本题名次碰巧不变，但数值偏差巨大，是'增长n倍'最典型误读，换个数据即致命
- ⚠ 忽视题干时间'2023年'与材料现期'2024年'不同，直接对现期值8.8/3.7/3.4排序——本题碰巧名次一致，但方法错误，遇到增速差异更大的同类题必错

## 母题抽象
> 🧩 当题干出现'多个主体给出现期量+较基期增长n倍（或增长r%），求基期量排序'的特征时，一律写成分数'现期÷(1+n)'，先用'分子大且分母小者必大'的分数性质两两比较锁定名次，仅在量级接近时才精算

**同类特征**：2023年春节假期（基期年份）、日均客流量、由高到低排名、较2023年增长4.9倍/6.2倍/7.5倍、机场口岸（上海浦东/广州白云/北京首都）、基期比较问题

### 题干
2023年春节假期，上海浦东、广州白云、北京首都机场日均客流量由高到低排名正确的是：

### 选项
- A. 上海浦东、北京首都、广州白云
- B. 上海浦东、广州白云、北京首都　✅
- C. 广州白云、上海浦东、北京首都
- D. 广州白云、北京首都、上海浦东
