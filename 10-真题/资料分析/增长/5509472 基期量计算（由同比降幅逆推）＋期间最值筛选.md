# 基期量计算（由同比降幅逆推）＋期间最值筛选

考点：[[20-考点/资料分析/增长/基期量计算（由同比降幅逆推）＋期间最值筛选|增长 / 基期量计算（由同比降幅逆推）＋期间最值筛选]]
材料：[[15-材料/资料分析/340943 2021年8月至2022年8月中国制|340943 2021年8月至2022年8月中国制]]

**问法模型**：题干给出'某月指标与去年同期相比下降23.4%'且要求'去年大约是多少' → 基期量=现期量÷(1−降幅) 的逆推模型，先在限定月份内筛最值定位现期值

## 推理链
1. 第1步：从表1'供应商配送时间'列提取2022年1~8月数据：47.6、48.2、46.5、37.2、44.1、51.3、50.1、49.5，逐项比较得最小值为2022年4月的37.2%（全期异常低点，图1该月PMI 47.4亦为最低，可交叉印证定位4月行）
2. 第2步：题干告知该月（2022年4月）比去年同期（2021年4月）下降23.4%；表1只覆盖2021年8月起，无2021年4月数据，只能由降幅逆推基期
3. 第3步：套用公式 基期量=现期量÷(1−降幅)=37.2%÷(1−23.4%)=37.2÷0.766≈48.6%
4. 第4步：与选项对照：48.6%即B选项（A.37%为现期值的干扰，C.49.6%、D.51%为偏离值），故选B

**最快解法**：⚡ 公式法＋百化分：先在表1供应商配送时间列圈出2022年1~8月最小值37.2%（4月）；降幅23.4%≈1/4.3，则基期=37.2÷(1−1/4.3)=37.2×4.3/3.3≈37.2×1.30≈48.4~48.6，锁定B；或截位直除37.2÷0.766首两位≈48.5

## 易错点
- ⚠ 逆指数反向运算的干扰：本题问的是表1公布的供应商配送时间指数本身，直接取37.2%即可；若受材料'逆指数需100%−x'规则误导，先算100%−37.2%=62.8%再逆推，就会落入命题人借第2、4题设的坑
- ⚠ 降幅逆推方向混淆：'下降23.4%'是相对降幅，应为现期÷(1−23.4%)；若误用现期×(1+23.4%)≈45.9%或现期÷(1+23.4%)≈30.1%，结果均不对
- ⚠ 时间范围与取数：必须在2022年1~8月这8个月中找最小（勿把范围扩到2021年下半年或误选3月46.5、5月44.1）；且'去年同期'=2021年4月在表中不存在，不能直接查表，表1行多列密，取37.2时防止与同列相邻值（3月46.5、5月44.1）或同行相邻列（从业人员47.2）串位

## 母题抽象
> 🧩 当题干出现'某期间内某指标最小的（月份）与去年同期相比下降x%，求去年同期'的特征时，先在限定月份范围内筛最值定位现期值，再用基期=现期÷(1−降幅)逆推（若为'上升x%'则用÷(1+x%)）；若该指标是逆指数，先判断题目问的是公布值还是合成贡献，问公布值则不做反向运算

**同类特征**：2022年1~8月、供应商配送时间指数最小的那个月、与去年同期相比下降了23.4%、去年同期……大约是、先筛最值再求基期、基期值表中缺失需逆推
