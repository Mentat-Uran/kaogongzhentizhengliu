# 增长率比较（基期需由现期−增量还原）

考点：[[20-考点/资料分析/增长/增长率比较（基期需由现期−增量还原）|增长 / 增长率比较（基期需由现期−增量还原）]]
材料：[[15-材料/资料分析/355887 J省2020年就业与创业工作（新增就|355887 J省2020年就业与创业工作（新增就]]

**问法模型**：题干问'参保人数同比增速最快'且材料只给现期值与'比上年增加'量 → 用 增长率=增量/(现期−增量) 还原基期后逐一计算比较

## 推理链
1. 第1步：定位材料第三段，取四险数据：城镇职工养老参保1167.42万人（比上年+70.52万人）、城乡居民养老2077.99万人（+189.1万人）、失业保险292.1万人（+2.42万人）、工伤保险557.98万人（+18.55万人）
2. 第2步：材料未给基期（2019年底）人数，须用公式 增长率=增量/基期=增量/(现期−增量)，不能用'完成全年计划的104.3%~115.4%'代替增速
3. 第3步：代入计算——城镇职工：70.52/(1167.42−70.52)=70.52/1096.9≈6.4%；城乡居民：189.1/(2077.99−189.1)=189.1/1888.9≈10.0%；失业：2.42/289.68≈0.8%；工伤：18.55/539.43≈3.4%
4. 第4步：四个增速中10.0%最大，对应城乡居民基本养老保险，故选D

**最快解法**：⚡ 截位直除+先排除后精选：失业2.42/290≈0.8%、工伤18.55/540≈3.4%一眼偏小先排除，重点比城镇职工70.5/1097≈6.4%与城乡居民189/1889≈10%，城乡居民增速最大直接锁定D

## 易错点
- ⚠ 把'完成全年计划的108.6%/115.4%/100.7%/104.3%'误当作同比增速来排序（本材料真正的同比增速只在第二段贷款部分）
- ⚠ 跳过基期还原、直接用'比上年增加量'排序或直接用增量/现期：正确口径是增量/(现期−增量)，基期方向不能弄反（误用现期+增量同样错）
- ⚠ 误将'比上年末增加280.56万人'当作某单一险种的增量参与计算，或将第三段的工伤保险'4.67万人（待遇人数）'与第一段'就业困难人员就业4.67万人'混淆串行

## 母题抽象
> 🧩 当题干问'同比增速最快/最慢'而材料只给'现期值+比上年增加量'两列时，先还原基期=现期−增量，再逐一算增量/基期比较，切忌用计划完成率或增量大小替代增速

**同类特征**：同比增速最快、到2020年底（时点数）、四种保险参保人数、比上年增加（给增量非给增速）、增长率比较、基期需自行还原

### 题干
到2020年底，J省四种保险的参保人数同比增速最快的是：

### 选项
- A. 失业保险
- B. 工伤保险
- C. 城镇职工基本养老保险
- D. 城乡居民基本养老保险　✅

### 官方解析
根据题干“到2020年底······同比增速最快的是”，可以判定本题为一般增长率比较问题。定位文字材料第三段可得：到2020年底，参加城镇职工基本养老保险1167.42万人，比上年增加70.52万人；参加城乡居民基本养老保险2077.99万人，比上年增加189.1万人；参加失业保险292.1万人，比上年增加2.42万人；参加工伤保险557.98万人，比上年增加18.55万人。根据公式：增长率，可得各项增长率分别为：
A项；
B项；
C项；
D项。
比较可得，城乡居民基本养老保险的同比增速最快。
故正确答案为D。
