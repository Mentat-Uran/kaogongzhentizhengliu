# 增长率计算与区间计数（增幅落在给定区间的指标个数筛选）

考点：[[20-考点/资料分析/增长/增长率计算与区间计数（增幅落在给定区间的指标个数筛选）|增长 / 增长率计算与区间计数（增幅落在给定区间的指标个数筛选）]]
材料：[[15-材料/资料分析/280092 中国创新指数情况：以2005年为基期|280092 中国创新指数情况：以2005年为基期]]

**问法模型**：'相比于2015年，2018年创新投入指数4个评价指标中增幅在[20%,30%]之间的有几个' → 对4个指标逐一套用 增长率=(现期指数−基期指数)/基期指数，再按区间筛选计数

## 推理链
1. 第1步：锁定'二、创新投入'板块下4个评价指标，取2015年与2018年两列：每万人R&D人员全时当量262.0→300.8；R&D经费占GDP比重157.5→163.6；基础研究人员人均经费248.0→313.4；企业R&D经费占主营业务收入比重125.5→136.7
2. 第2步：定基指数可直接相除求增长率，公式为 增幅=(2018年指数−2015年指数)/2015年指数
3. 第3步：代入计算：38.8/262.0≈14.8%；6.1/157.5≈3.9%；65.4/248.0≈26.4%；11.2/125.5≈8.9%
4. 第4步：与区间(20%~30%)对照：14.8%、3.9%、8.9%均低于20%被排除，仅基础研究人员人均经费指数的26.4%落入区间
5. 第5步：落入区间的指标共1个，对应A项

**最快解法**：⚡ 截位直除+区间排除：先粗估三个易排除项——38.8/262≈15%、6.1/158≈4%、11.2/126≈9%，均<20%直接排除；只需精算65.4/248（248×26%≈64.5，约26.4%），确认落入20%~30%，故仅1个，选A

## 易错点
- ⚠ 层级陷阱：题干问的是'创新投入指数'下4个评价指标，若误用分类总行（164.2→193.4，增幅约17.8%）即错
- ⚠ 列定位陷阱：必须取2015列与2018列，勿拿2019列（基础研究人员人均经费2018年313.4→2019年298.6是回落，若错取2019列会算错方向）
- ⚠ 基期现期混淆：分母必须是2015年（基期）指数，如65.4/248.0，勿用313.4做分母；且指数差≠增长率，65.4不是增幅
