# 增长率计算（增长倍数=增长量-基期量）

考点：[[20-考点/资料分析/增长/增长率计算（增长倍数=增长量-基期量）|增长 / 增长率计算（增长倍数=增长量/基期量）]]
材料：[[15-材料/资料分析/280165 我国城镇就业人员平均工资：图1给出2|280165 我国城镇就业人员平均工资：图1给出2]]

**问法模型**：题干'与2009年相比，2019年……增长的倍数约为'→用增长倍数模型(现期-基期)/基期=现期/基期-1计算

## 推理链
1. 第1步：题干限定'城镇非私营单位'，从图1菱形线（非私营序列）读取两端点：2009年为32244元，2019年为90501元（勿误取方块线私营的18199/53604）
2. 第2步：'增长的倍数'即增长率，公式为(现期-基期)/基期=90501/32244-1
3. 第3步：分子=90501-32244=58257元，58257/32244≈1.8（或先算90501/32244≈2.8，再减1得1.8）
4. 第4步：对照选项，1.8倍对应B项；2.8倍只是'增长到'的倍数（现期/基期），是C项陷阱，'增长了'须减1，故选B

**最快解法**：⚡ 截位直除+公式法：90501/32244≈905/322≈2.8（即增长到约2.8倍），增长的倍数=2.8-1=1.8倍，直接锁定B

## 易错点
- ⚠ '增长了'与'增长到'混淆：90501/32244≈2.8是增长到的倍数，增长(了)的倍数须为(90501-32244)/32244≈1.8，误不减1会错选C
- ⚠ 图1双序列数据标签密集，非私营（菱形）与私营（方块）易串行读错，本题必须取非私营线两端点32244元与90501元
- ⚠ 基期现期方向：'与2009年相比'基期为2009年32244元，分子应为增量58257元而非90501元

## 母题抽象
> 🧩 当题干出现'与A年相比，B年某指标增长的倍数/增长率约为'时，用(现期-基期)/基期模型，并用'现期/基期'的商减1快速验证，警惕把'增长到几倍'直接当答案

### 题干
与2009年相比，2019年城镇非私营单位就业人员平均工资增长的倍数约为：

### 选项
- A. 1.5倍
- B. 1.8倍　✅
- C. 2.8倍
- D. 3.2倍

### 官方解析
根据题干“与2009相比，2019年······增长的倍数约为”，可判定本题为一般增长率计算问题。定位图1可知，2009年、2019年城镇非私营单位就业人员平均工资分别为32244元、90501元。根据增长率，所求增长率倍，即增长的倍数约为1.8倍。
故正确答案为B。
