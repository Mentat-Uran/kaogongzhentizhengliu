# 增长量计算与逐年增量趋势比较（净增量匹配图形）

考点：[[20-考点/资料分析/增长/增长量计算与逐年增量趋势比较（净增量匹配图形）|增长 / 增长量计算与逐年增量趋势比较（净增量匹配图形）]]
材料：[[15-材料/资料分析/239354 2011-2015年我国人口统计数据|239354 2011-2015年我国人口统计数据]]

**问法模型**：题干出现'净增人口变化情况'并配趋势图选项 → 逐年做差（当年量−上年量）得增长量序列，再按升降/峰谷形态匹配曲线

## 推理链
1. 第1步：题干要求2012-2015年65岁及以上人口逐年'净增人口'，定位表末行绝对量：2011-2015年为12261/12728/13199/13815/14386万人（注意2012年增量的基期是2011年）
2. 第2步：规则：净增人口=当年年末人口−上年年末人口（同比增长量）
3. 第3步：代入计算：2012年12728−12261=467万人；2013年13199−12728=471万人；2014年13815−13199=616万人；2015年14386−13815=571万人
4. 第4步：校验：用表中增长率行验证，467/12261≈3.81%、471/12728≈3.70%、616/13199≈4.67%、571/13815≈4.13%，与表中2012-2015年增长率3.81/3.70/4.67/4.13完全吻合
5. 第5步：增量序列形态：467→471（微升）→616（大幅跳升）→571（回落），峰值在2014年，整体'先升后降'
6. 第6步：与选项对照：仅A图呈现'先升后降且2014年最高'的形态，故选A

**最快解法**：⚡ 逐年做差+图形形态排除：四个减法得467/471/616/571万人，抓住关键特征'2014年最高（616万）、2015年回落（571万）'，直接排除单调递增、单调递减及峰值在2013或2015年的图形；可辅以'上年量×当年增长率'估算（如12261×3.81%≈467）快速验证做差结果

## 易错点
- ⚠ 把绝对量或增长率当净增量：表中13815、14386等是年末时点存量，增长率(%)是同比增速，均不是净增人口，必须逐年做差
- ⚠ 与同材料第2题口径混淆：第2题年均增长量=(14386−12261)÷4≈531万人（基期2011年、除以4），本题是四个逐年增量467/471/616/571匹配图形，切勿只算首尾差2125万人
- ⚠ 图形细节误判：467→471仅增4万，易误判为'持平或下降'；应抓住2014年+145万显著跳升、2015年−45万回落的'峰在2014、末年回落'特征

## 母题抽象
> 🧩 当题干出现'某指标净增（增长量）的变化情况'并配折线图选项时，用'当年量−上年量'逐年做差得增量序列（首项基期取统计期首年的前一年），再以升降方向与峰谷位置匹配图形；可用表中同比增速×上年量做量级校验
