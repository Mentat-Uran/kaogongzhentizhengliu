# 增长量计算（多个现期值+增速配对、含负增长项的带符号加总）

考点：[[20-考点/资料分析/增长/增长量计算（多个现期值+增速配对、含负增长项的带符号加总）|增长 / 增长量计算（多个现期值+增速配对、含负增长项的带符号加总）]]
材料：[[15-材料/资料分析/5219532 2023年我国互联网企业互联网业务收|5219532 2023年我国互联网企业互联网业务收]]

**问法模型**：题干问'前5名省级行政区收入比上年'且选项为'增长/减少+不到/以上+量级' → 逐项用增长量公式 现期×r/(1+r)（下降项取负）计算后加总，与500亿元分界比较

## 推理链
1. 第1步：定位材料第4段，提取前5名配对数据：北京5721.4亿元（+4.2%）、上海4167.8亿元（+17.5%）、浙江1955.9亿元（+4.8%）、广东1754.5亿元（下降4.6%）、天津981.7亿元（+20.3%），五项现期合计14581.3亿元
2. 第2步：增长量公式=现期×r/(1+r)；增速为负（广东下降4.6%）时增长量取负值
3. 第3步：北京=5721.4×0.042/1.042≈231亿元；上海=4167.8×0.175/1.175≈621亿元；浙江=1955.9×0.048/1.048≈90亿元
4. 第4步：广东=−1754.5×0.046/0.954≈−85亿元（下降，为负贡献）；天津=981.7×0.203/1.203≈166亿元
5. 第5步：带符号加总：231+621+90−85+166≈1022亿元，为正且大于500亿元
6. 第6步：对照选项，'增长了500亿元以上'即D，故选D

**最快解法**：⚡ 百化分：4.2%≈1/24→5721.4/25≈229；17.5%≈1/5.7→4167.8/6.7≈622；4.8%≈1/21→1955.9/22≈89；下降4.6%≈1/21.7→减少量=1754.5/20.7≈85（取负）；20.3%≈1/4.9→981.7/5.9≈166；合计≈229+622+89−85+166≈1022亿元>500，锁定D。更快的定性判据：仅北京+上海两项增长量≈231+621=852已超500，扣除广东−85后仍约767，浙江与天津为正贡献，总量必超500

## 易错点
- ⚠ 广东是'下降4.6%'（负增速），其增长量约为−85亿元；若误按+4.6%计算会多算约170亿元（虽不影响超500的结论，但精确值出错）
- ⚠ 公式错用：误用'现期×增速'代替'现期×r/(1+r)'，如上海4167.8×17.5%≈729亿元 vs 正确约621亿元，单项偏差即超百亿
- ⚠ 若改用'先求基期再作差'：广东需除以(1−4.6%)=0.954（除以小于1的数，基期1839反而大于现期1754），此处基期方向与符号最易搞反；另注意'下降'对应增长量为负，勿与'减少量'（正值）混淆

## 母题抽象
> 🧩 当题干出现'若干项合计的指标比上年增长/减少多少'且各项均为'现期值+增速'配对、增速有正有负时，用增长量公式现期×r/(1+r)逐项计算（下降项取负），带符号加总后与选项量级分界比较；配百化分r≈1/n可全口算，且可先用最大的正贡献项做定性锁定
