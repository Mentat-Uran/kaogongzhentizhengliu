# 基期量计算（现期÷(1+同比增速)）＋单位换算（亿元→万亿元）

考点：[[20-考点/资料分析/增长/基期量计算（现期÷(1+同比增速)）＋单位换算（亿元→万亿元）|增长 / 基期量计算（现期÷(1+同比增速)）＋单位换算（亿元→万亿元）]]
材料：[[15-材料/资料分析/195083 2017年5月我国境内银行业金融机构|195083 2017年5月我国境内银行业金融机构]]

**问法模型**：题干时间（2016年5月）早于材料时间（2017年5月）且材料无基期列 → 用基期量=现期量÷(1+同比增速)，再÷10000换算成万亿元

## 推理链
1. 第1步：题干时间2016年5月早于材料现期2017年5月，且表无2016年数值列，判定为基期计算题
2. 第2步：定位统计表第一行总计行'银行业金融机构'（勿误读成分项），提取总资产2328934亿元、同比增速12.5%
3. 第3步：套公式基期量=现期量÷(1+增速)=2328934÷(1+12.5%)
4. 第4步：利用12.5%=1/8，1.125=9/8，化除为乘：2328934×8/9≈2070163亿元（即约207万亿元）
5. 第5步：单位换算：2070163亿元÷10000≈207万亿元
6. 第6步：与选项对照：A167、B207、C247、D287，B项最接近，故选B

**最快解法**：⚡ 特殊分数（百化分）化除为乘：12.5%=1/8，则基期=2328934×8/9≈233万亿×8/9≈207万亿元，直接锁定B；或截位直除2328934÷1.125≈207万（亿元）÷10000=207万亿元

## 易错点
- ⚠ 单位量级陷阱：表中金额为亿元，选项问'多少万亿元'，必须÷10000，直接算出约2070000会与选项量级对不上而慌乱或错选
- ⚠ 基期现期方向混淆：误乘(1+12.5%)得约262万亿元，在C(247)与D(287)间徘徊；正确方向是除以(1+增速)
- ⚠ 读行错误：应取总计行'银行业金融机构'的2328934亿元，勿误取分项（如大型商业银行839329亿元或股份制431150亿元）

## 母题抽象
> 🧩 当题干出现'上年同期/基期某量为多少'而材料只给现期值与同比增速时，用'基期=现期÷(1+增速)'，优先把1+r百化分（如12.5%=1/8、16.7%≈1/6）化除为乘，并先核对单位口径（亿→万亿÷10000）再对照选项

**同类特征**：问上年（2016年5月）数值、材料只有现期值和同比增速、问'多少万亿元'、总计行'银行业金融机构'、基期量计算、选项间隔大可估算

### 题干
2016年5月，银行业金融机构总资产金额为多少万亿元？

### 选项
- A. 167
- B. 207　✅
- C. 247
- D. 287

### 官方解析
根据题干“2016年5月，银行业金融机构总资产金额为……”，材料给的是2017年5月，判定为基期计算问题。定位统计表，可得：2017年5月银行业金融机构总资产为亿元万亿元，同比增速为。根据公式，万亿元，B项最为接近。
故正确答案为B。
