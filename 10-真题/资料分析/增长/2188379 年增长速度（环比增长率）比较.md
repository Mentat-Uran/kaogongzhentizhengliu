# 年增长速度（环比增长率）比较

考点：[[20-考点/资料分析/增长/年增长速度（环比增长率）比较|增长 / 年增长速度（环比增长率）比较]]
材料：[[15-材料/资料分析/195136 2013—2017年年末我国固定互联|195136 2013—2017年年末我国固定互联]]

**问法模型**：题干为『2013-2017年……年增长速度最快的年份是』→ 对各年份逐年计算环比增长率（本年−上年）/上年并比较大小

## 推理链
1. 第1步：从白柱读出固定互联网宽带接入用户年末数：2013年18891、2014年20048、2015年25947、2016年29721、2017年34854万户
2. 第2步：『增长速度』=环比增长率=（本年−上年）÷上年，柱状图为年末存量，须相邻两年相减求增量
3. 第3步：2014年增速=(20048−18891)/18891=1157/18891≈6.1%
4. 第4步：2015年增速=(25947−20048)/20048=5899/20048≈29.4%
5. 第5步：2016年增速=(29721−25947)/25947=3774/25947≈14.5%；2017年增速=(34854−29721)/29721=5133/29721≈17.3%
6. 第6步：比较四年增速29.4%＞17.3%＞14.5%＞6.1%，2015年最快，对应选项B

**最快解法**：⚡ 截位直除+增量/基期快速排序：先看增量，2015年增量5899万户为四年最大而基期20048仅2万级（2014年增量仅1157不值一提），可直接锁定2015；再用截位直除验证5899/20048≈29.4%＞5133/29721≈17.3%即可确认选B

## 易错点
- ⚠ 『增长速度最快』比的是增长率而非增长量，本题2015年增量5899万户与最快增速恰巧重合，但必须落到增速上验证；同图兄弟题中移动宽带2017年增量最大（19077万户）而增速并非最快，用增量代替增速会选错
- ⚠ 柱状图各年是『年末』存量值，不能直接比较柱高或当年数值大小，必须相邻两年相减求增量再除以上年
- ⚠ 2013年为基期年份，缺上一年数据无法算增速，比较范围只能从2014年起；基数大≠增速快，2017年总量34854最大但增速仅约17.3%

2013一2017年固定互联网宽带接入用户数的年增长速度最快的年份是：

### 选项
- A. 2014
- B. 2015　✅
- C. 2016
- D. 2017

根据题干“2013-2017年······增长速度最快的年份是”，可判定本题为一般增长率比较问题。由116题计算结果可知，2013-2017年固定互联网宽带接入用户数的年增长速度最快的年份是2015年。
故正确答案为B。
