# 环比增长量计算及增长量倍数比较

考点：[[20-考点/资料分析/增长/环比增长量计算及增长量倍数比较|增长 / 环比增长量计算及增长量倍数比较]]
材料：[[15-材料/资料分析/4603380 2025年8月全国政府采购电梯市场规|4603380 2025年8月全国政府采购电梯市场规]]

**问法模型**：题干问'A的环比增量约是B的环比增量的多少倍'→ 分别用公式 增长量=现期×r/(1+r) 求两子项环比增量后作比。

## 推理链
1. 第1步：从第3段取更新改造现期56108.32万元、环比增速51.92%；从第5段取加装电梯现期9538.15万元、环比增速30.72%（题干问环比增量，不能用同比的347.55%和-18.63%）
2. 第2步：增长量公式 = 现期量 × r/(1+r)
3. 第3步：更新改造环比增量 = 56108.32×0.5192/1.5192 ≈ 56108.32×0.3418 ≈ 19175万元
4. 第4步：加装电梯环比增量 = 9538.15×0.3072/1.3072 ≈ 9538.15×0.2350 ≈ 2241万元
5. 第5步：作比 = 19175/2241 ≈ 8.56，与D项8.6最接近，故选D

**最快解法**：⚡ 百化分+截位估算：51.92%≈1/1.93，增量≈56108/(1.93+1)≈56108/2.93≈19100+；30.72%≈1/3.26，增量≈9538/(3.26+1)≈9538/4.26≈2240；19100/2240≈8.5+，最接近8.6选D。更快的拆分法：比值=(56108/9538)×(0.5192/0.3072)×(1.3072/1.5192)≈5.9×1.69×0.86≈8.6。

## 易错点
- ⚠ 忘记除以(1+r)：直接用56108×51.92%≈29133与9538×30.72%≈2930作比得约9.9，偏差过大导致误判选项
- ⚠ 基期混淆：误用同比增速347.55%和-18.63%计算，题干明确问'环比增量'，必须取环比数据
- ⚠ 跨段取数干扰：材料中河北、北京等省份在总规模、维保、加装段落数值各不相同，本题只需第3、5段的全国规模与环比增速，勿被第2段省份排名数据干扰

## 母题抽象
> 🧩 当题干出现'A环比增长r₁、B环比增长r₂，求A增量是B增量几倍'特征时，用 比值=(A现期/B现期)×(r₁/r₂)×((1+r₂)/(1+r₁))，先估现期倍数再乘增速修正系数，验证最接近选项。

**同类特征**：环比增量、约是……的多少倍、两子项增长量之比、跨段落取数（第3段与第5段）、增长率需换算为 r/(1+r)、选项为非整数倍数需估算
