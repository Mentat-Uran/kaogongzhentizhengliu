# 隔年（间隔）增长率

考点：[[20-考点/资料分析/增长/隔年（间隔）增长率|增长 / 隔年（间隔）增长率]]
材料：[[15-材料/资料分析/310902 2018年第一季度（含3月份当月）全|310902 2018年第一季度（含3月份当月）全]]

**问法模型**：题干出现'相对于2016年3月，2018年3月……增长'且选项为百分数 → 采用隔年增长率模型 r=(1+r1)(1+r2)−1，r1、r2 分别取中间年（2017年3月）与现期（2018年3月）的同比增速

## 推理链
1. 第1步：题干要求2018年3月相对2016年3月（间隔一年）的增长率；从折线图读取2017年3月社零同比增速10.9%、2018年3月同比增速10.1%（不能用文字中一季度增速9.8%）
2. 第2步：套用隔年增长率公式 r = (1+r1)(1+r2) − 1 = r1 + r2 + r1×r2
3. 第3步：代入数据 r = 10.9% + 10.1% + 10.9%×10.1% = 21% + 约1.1% ≈ 22.1%（精确值 1.109×1.101−1 = 22.1009%）
4. 第4步：对照选项：A(10.1%)、B(10.9%)仅是单期同比增速，D(20.7%)对应误用9.8%+10.9%简单相加的陷阱，C(22.1%)与计算结果一致，故选C

**最快解法**：⚡ 公式法（隔年增长率速算）：r = r1 + r2 + r1×r2，先加得 10.9%+10.1%=21%，乘积项用百化分估算 10.9%×10.1% ≈ 11%×10% ≈ 1.1%，合计约22.1%，直接锁定C

## 易错点
- ⚠ 增速取数错位：2018年3月增速10.1%必须从折线图读取，误用文字中一季度增速9.8%再与10.9%相加恰得20.7%（正是D项陷阱）
- ⚠ 漏算乘积项：只算 10.9%+10.1%=21.0% 当作隔年增速，忽略 r1×r2≈1.1% 的修正项
- ⚠ 单期增速误选：A(10.1%)与B(10.9%)分别只是2018年3月、2017年3月的同比增速，均非隔年累计增幅

## 母题抽象
> 🧩 当题干出现'相对于隔年同期……增长'且两期同比增速分散在折线图的不同年份点时，用 r=(1+r1)(1+r2)−1 ≈ r1+r2+r1×r2 计算，结果应略大于两增速之和，再对照选项排除'单期增速'与'两增速简单相加'的干扰项

**同类特征**：相对于2016年3月、2018年3月……增长、隔年（间隔）增长率、增速藏于折线图需跨图取数、选项为百分数、干扰项含单期增速与误加结果

### 题干
相对于2016年3月，2018年3月的全国社会消费品零售总额增长：

### 选项
- A. 10.1%
- B. 10.9%
- C. 22.1%　✅
- D. 20.7%

### 官方解析
根据题干“相对于2016年3月，2018年3月的······增长”，结合选项为百分数，可判定本题为间隔增长率问题。定位图形材料可得：2017年3月全国社会消费品零售总额同比增长10.9%，2018年3月同比增长10.1%。根据间隔增长率公式：，则相对于2016年3月，2018年3月的全国社会消费品零售总额增长率为，与C项最接近。
故正确答案为C。
