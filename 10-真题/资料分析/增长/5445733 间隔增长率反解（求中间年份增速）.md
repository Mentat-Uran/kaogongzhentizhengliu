# 间隔增长率反解（求中间年份增速）

考点：[[20-考点/资料分析/增长/间隔增长率反解（求中间年份增速）|增长 / 间隔增长率反解（求中间年份增速）]]
材料：[[15-材料/资料分析/338024 2021年中国纺织品服装出口情况：总|338024 2021年中国纺织品服装出口情况：总]]

**问法模型**：题干问'2020年比2019年'的增长情况，而材料只给2021年同比增速24.0%和2021年较2019年增速16.0% → 用间隔增长率公式 R=r₁+r₂+r₁·r₂ 反解2020对2019的增速r₂

## 推理链
1. 第1步：题干要求2020年全国服装出口额比2019年的变化率；定位第一段：2021年服装出口1702.8亿美元，同比增长24.0%，较2019年增长16.0%
2. 第2步：2021对2020的增速r₁=24.0%，2021对2019的间隔增速R=16.0%，设2020对2019增速为r₂，套用间隔增长率公式 R = r₁ + r₂ + r₁×r₂
3. 第3步：代入得 16.0% = 24.0% + r₂ + 24.0%×r₂，整理得 -8.0% = 1.24×r₂，解得 r₂ = -8.0%÷1.24 ≈ -6.45%
4. 第4步：r₂≈-6.45%，为负且绝对值小于10%，即2020年比2019年'下降了不到10%'，对照选项只有D符合，故选D

**最快解法**：⚡ 公式法+截位直除：间隔增长率反解 r₂=(R-r₁)/(1+r₁)=（16%-24%）÷(1+24%)=-8%÷1.24≈-6.5%，一眼判断为'负增长且不到10%'，无需精算即可锁定D；速判技巧：R=16%小于r₁=24%，说明中间年份增速必为负，且R-r₁=-8%的量级直接锁定'不到10%'

## 易错点
- ⚠ 两套增速口径混排陷阱：材料同时给出'同比增长24.0%'（2021对2020）和'较2019年增长16.0%'（2021对2019），求2020对2019必须用间隔增长率反解，勿把16.0%直接当作2020对2019的增速
- ⚠ 方向误判：R=16%<r₁=24%，说明r₂必为负（下降），勿误选'增长'类选项A或C
- ⚠ 公式漏项或分母错：若漏掉乘积项r₁·r₂会误算为-8%（本题恰巧同落D区间，但方法错误）；分母应为1+24%=1.24，勿误作0.76或其他口径

## 母题抽象
> 🧩 当题干出现'中间年份比更早年份'（如2020比2019）而材料只给现期同比增速r₁和现期对早期基期的间隔增速R时，用间隔增长率公式反解 r₂=(R-r₁)/(1+r₁)，再按正负与幅度匹配选项

**同类特征**：问法为'2020年比2019年'（隔年比较）、材料同时出现同比增速与'较2019年增长'两套口径、选项为'增长/下降+10%界限'的形式、主体为全国服装出口额、只需判断正负与幅度区间、间隔增长率反解模型

### 题干
2020年，全国服装出口额比2019年：

### 选项
- A. 增长了10%以上
- B. 下降了10%以上
- C. 增长了不到10%
- D. 下降了不到10%　✅

### 官方解析
根据题干“2020年······比2019年”，结合选项为增长/下降+百分数，且材料给出2021年全国服装出口额的同比增速以及相对于2019年的增速，可判定本题为间隔增长率问题。定位文字材料第一段可得：2021年，全国服装出口1702.8亿美元，同比增长24.0%（），较2019年增长16.0%（）。根据公式：，代入数据则有，解得，即下降了不到10%。
故正确答案为D。
