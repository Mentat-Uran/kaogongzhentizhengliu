# 基期增速换算（由'增速同比回落N个百分点'求上年同期增速）

考点：[[20-考点/资料分析/增长/基期增速换算（由'增速同比回落N个百分点'求上年同期增速）|增长 / 基期增速换算（由'增速同比回落N个百分点'求上年同期增速）]]
材料：[[15-材料/资料分析/241028 2018年1-5月我国软件和信息技术|241028 2018年1-5月我国软件和信息技术]]

**问法模型**：题干问'2017年1-5月……利润总额的增速为'（时间倒推一年的增速）→ 增长率类问题中的百分点换算模型：基期增速=现期增速+回落的百分点（回落加回、提高减去），全程不需要基期量

## 推理链
1. 第1步：定位文字第一段：2018年1-5月全行业实现利润总额2822亿元，'同比增长10.2%（本题材料将该值挖空，须回原题原文补读），增速同比回落0.9个百分点'
2. 第2步：规则：'增速同比回落0.9个百分点'=2018年增速比2017年增速低0.9个百分点（百分点是增速之差，不是相对变化），故2017年增速=2018年增速+0.9个百分点
3. 第3步：代入：2017年1-5月利润总额增速=10.2%+0.9%=11.1%，2822亿元这一利润现期量在本题中并不参与计算
4. 第4步：与选项对照：仅B项等于'2018年利润增速+0.9个百分点=11.1%'，与计算一致；按'10.2%−0.9%=9.3%'方向做减法、或误用全国软件业务收入增速14.2%的选项均为干扰，故选B

**最快解法**：⚡ 百分点换算口诀法：见'回落N个百分点'问上年增速，直接加回——现期增速10.2%+0.9%=11.1%，秒选B；纯方向换算题，不列基期公式、不动任何基期量

## 易错点
- ⚠ 方向陷阱：'回落0.9个百分点'意为2018年比2017年低0.9个pp，求2017年须加回；若理解成2017=2018−0.9（10.2%−0.9%=9.3%）即掉入反向干扰项
- ⚠ 百分点≠百分数：0.9个百分点是增速的算术差，不能写成10.2%×(1−0.9%)之类的相对变化，也不能用利润2822亿元去反推基期利润再算增速（材料未给基期利润，且本题无需）
- ⚠ 读数/口径陷阱：本题材料正文将2018年利润增速挖空、两张图表中也无利润增速，必须回原题原文补读10.2%，切勿凭空填数；也不可把全国软件业务收入增速（加权约14.2%）或图1任一地区增速错当利润增速代入

## 母题抽象
> 🧩 当题干出现'上年（基期）同期……增速为'且材料给出'增速同比提高/回落N个百分点'时，用'基期增速=现期增速∓N个pp'（回落则加、提高则减）直接换算，无需计算基期量，关键是先核对方向词再定加减号

**同类特征**：问基期（2017年1-5月）增速、全行业利润总额、增速同比回落0.9个百分点、百分点换算（非增长量/基期量计算）、选项为具体百分数、只需方向加减、无需复杂计算
