# 增长率计算与比较（环比增速取最大后选上限值）

考点：[[20-考点/资料分析/增长/增长率计算与比较（环比增速取最大后选上限值）|增长 / 增长率计算与比较（环比增速取最大后选上限值）]]
材料：[[15-材料/资料分析/264841 以'改革开放之初五年（1978-19|264841 以'改革开放之初五年（1978-19]]

**问法模型**：题干问'某区间内XX增长率最高不超过多少' → 逐年计算环比增长率（当年−上年）÷上年，取四者最大值，再选略大于该精确值的上限选项

## 推理链
1. 第1步：从表2左栏（1978-1982年）提取年末总人口：1978年96259、1979年97542、1980年98705、1981年100072、1982年101654万人
2. 第2步：环比增长率=（当年值−上年值）÷上年值，逐年计算1979-1982四个年份
3. 第3步：1979年：1283/96259≈1.33%；1980年：1163/97542≈1.19%；1981年：1367/98705≈1.39%；1982年：1582/100072≈1.58%
4. 第4步：四年中最高为1982年的约1.58%
5. 第5步：'最高不超过'要求选比1.58%略大的上限值，即1.6%，对应选项D

**最快解法**：⚡ 截位直除+首位观察：分子取各年增量（1283、1163、1367、1582），分母取上年人口，先粗估均为1%出头；重点比较最大分子1582÷100072，首位商1（即1.5%+），得最高约1.58%，故上限为1.6%，直接锁定D，无需精算其余年份

## 易错点
- ⚠ 把'最高不超过'误当作求精确增长率，纠结选项无1.58%这一精确值；正确理解是选上限值（1.6%而非2%）
- ⚠ 基期混淆：分母须用上年（基期）人口，误用当年人口或用1982相对1978的总增幅（约5.6%）代入比较
- ⚠ 表2为左右双栏（左1978-1982、右2012-2016），易串栏读成2013-2016年数据（1.9%-1.5%量级完全不同）；且总人口为'年末'时点数，环比仍按相邻年末值计算，勿与人均GDP混看
