# 同比增速计算（由增长量与现期值求增长率）

考点：[[20-考点/资料分析/增长/同比增速计算（由增长量与现期值求增长率）|增长 / 同比增速计算（由增长量与现期值求增长率）]]
材料：[[15-材料/资料分析/280095 2019年第一季度131家证券公司经|280095 2019年第一季度131家证券公司经]]

**问法模型**：题干问'总资产的同比增速约为'，而材料以'较上年一季度增加0.64万亿元'的增减量形式给同比 → 采用 增长率=增长量/(现期−增长量) 模型，先还原基期再相除

## 推理链
1. 第1步：定位材料第2段，提取条件：2019Q1总资产现期值7.05万亿元，'比上年一季度同期增加0.64万亿元'，即增长量Δ=0.64万亿元（题干给的是量不是速）
2. 第2步：增长率公式 r=增长量/基期量=增长量/(现期−增长量)，基期=7.05−0.64=6.41万亿元
3. 第3步：代入计算 r=0.64/6.41，因641×0.1≈64.1，故r略小于10%，约9.98%≈10%
4. 第4步：与选项对照，计算值约10%对应B项，与官方答案B一致，故选B

**最快解法**：⚡ 速算技巧：截位直除（口算特征分数）。0.64/6.41≈64/641，而6.41的10%恰为0.641，故0.64/6.41≈9.98%≈10%，一步锁定约10%的选项（B）；无需精算，先排除接近9%左右（0.64/7.05≈9.1%，错用现期作分母所得）的干扰项

## 易错点
- ⚠ 增减量与增速混淆：第2、3段给的是'较上年同期增加0.64万亿元'的增长量而非增速，不能把0.64直接当作增速或当作百分比使用
- ⚠ 分母用错：正确分母是基期6.41万亿元（=7.05−0.64），若误用现期7.05作分母得0.64/7.05≈9.1%，与正确值9.98%接近，正是选项设计的干扰点
- ⚠ 单位口径：总资产单位为'万亿元'，与收入类'亿元'差4个数量级，本题分子分母单位一致可直接相除，但若从其他段借数据比较必须换算

## 母题抽象
> 🧩 当题干问'同比增速'且材料以'现期值+较上年同期增/减X（量）'形式给出时，用 增长率=增长量/(现期−增长量)：先减出基期，再以增量÷基期，切勿以现期作分母

### 官方解析
根据题干“2019年第一季度······同比增速约为”，可判定本题为一般增长率问题。定位文字材料第三段可得“2019年第一季度，131家证券公司总资产为7.05万亿元，比上年一季度同期增加0.64万亿元”。根据增长率，则2019年第一季度，131家证券公司总资产的同比增速。
故正确答案为B。
