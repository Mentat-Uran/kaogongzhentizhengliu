# 增速读数比较（逐年与阈值比较计数）

考点：[[20-考点/资料分析/增长/增速读数比较（逐年与阈值比较计数）|增长 / 增速读数比较（逐年与阈值比较计数）]]
材料：[[15-材料/资料分析/195226 2010～2015年中国国际出口带宽|195226 2010～2015年中国国际出口带宽]]

**问法模型**：题干问'增速高于某一阈值的年份有多少个' → 从折线逐年读增速，与阈值逐一比较后计数，无需任何计算。

## 推理链
1. 第1步：从图1折线（右轴，%）读取2010～2015年各年同比增速：2010年26.9%、2011年26.4%、2012年36.7%、2013年79.3%、2014年20.9%、2015年30.9%。
2. 第2步：确定比较基准为30%（题干印制时被截断，由官方解析还原：高于基准的年份为2012、2013、2015）。
3. 第3步：逐一与30%比较：26.9%＜30%、26.4%＜30%、36.7%＞30%、79.3%＞30%、20.9%＜30%、30.9%＞30%。
4. 第4步：高于30%的年份为2012年、2013年、2015年，共3个。
5. 第5步：与选项对照，3个对应C项，故正确答案为C。

**最快解法**：⚡ 直接读数比较法（零计算）：将折线上6个增速点与30%一线比对，立即锁定36.7%、79.3%、30.9%三个点高于阈值，其余三个（26.9%、26.4%、20.9%）均低于30%，计数得3，选C；只需重点核验临界点2015年30.9%（略高于30%）。

## 易错点
- ⚠ 题干'高于'后的比较基准30%被截断缺失，切勿凭空改成20%等其他阈值（若按20%会把6个年份全数进去而出错），应以官方解析还原的30%为准。
- ⚠ 双轴图混读陷阱：增速须看折线（右轴%），勿把柱值（左轴万Mbps）当增速比较。
- ⚠ 临界年份易错：2015年30.9%仅略高于30%（易漏数），2010年26.9%接近30%（易多数），是本题计数的关键卡点。

## 母题抽象
> 🧩 当题干出现'某指标增速高于X%的年份有几个'特征时，直接从折线图逐年读增速与X逐一比较计数，重点核查略高于或略低于X的临界年份，即可秒答。
