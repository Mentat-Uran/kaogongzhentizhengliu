# 综合判断题：多几倍表述+基期差值倒推+负增长判定

考点：[[20-考点/资料分析/综合/综合判断题：多几倍表述+基期差值倒推+负增长判定|综合 / 综合判断题：多几倍表述+基期差值倒推+负增长判定]]
材料：[[15-材料/资料分析/7899892 2023年年末我国港口生产用码头泊位|7899892 2023年年末我国港口生产用码头泊位]]

**问法模型**：题干为'下列选项中，可由资料推出的是'的①②③组合判断 → 逐条验证：①用'多几倍=倍数−1'核对增量倍数表述，②用'基期量=现期量−增长量'倒推2022年后比差值，③用同比增量正负判断增长方向

## 推理链
1. 第1步：定位表2，多用途泊位同比增量8个、其他泊位同比增量4个
2. 第2步：①'多2倍'需满足(8−4)/4=2，实际(8−4)/4=1倍，即只多1倍，①错误
3. 第3步：定位表1沿海港口列，2023年年末3万吨级以下泊位744个（同比+38），5~10（不含）万吨级泊位824个（同比+26）
4. 第4步：②倒推2022年年末：824−26=798个、744−38=706个，差值=798−706=92个，在100以内，②正确
5. 第5步：定位表2，客货泊位2023年年末3个、同比增量为−1个，增量为负即同比负增长，③正确
6. 第6步：综上可推出的是②③，对照选项选C

**最快解法**：⚡ 排除法+口算：①先做——8与4是2倍关系即'多1倍'（多几倍=倍数−1），①错误，排除A、D只剩B、C；③再看——客货增量−1<0即负增长，③正确，排除D锁定答案；②最后验证——(824−26)−(744−38)=92<100成立，确认选C

## 易错点
- ⚠ '多2倍'与'是2倍'混淆：8是4的2倍，但8比4只多1倍，误把①当正确会错选A/D
- ⚠ 取数看错列：②要求沿海港口列（744/38、824/26），误用全国列（932/41、966/36）得(966−36)−(932−41)=39，虽也<100但口径错误；若再看错成内河列会得出不同结论
- ⚠ 基期倒推方向搞反：2022年年末数=2023年年末数−同比增量，误做加法会得798→850、706→782，差值变成68仍<100，易掩盖错误；另③只需看增量正负，勿因年末量3为正而误判为正增长

## 母题抽象
> 🧩 当题干出现'①②③组合判断可由资料推出'时，先用数字最直白的条目（简单倍数表述、负增量、负增长）口算排除选项缩小范围，再对剩余条目用'基期量=现期量−同比增量'倒推验证，注意'多几倍=倍数−1'和取数列口径

**同类特征**：可由资料推出的是、①②③组合判断、多2倍（多几倍=倍数−1）、数量差值在100以内、同比负增长、沿海港口/万吨级及以上泊位

### 题干
下列选项中，可由资料推出的是：
①2023年年末，我国港口生产用万吨级及以上码头泊位中，“多用途泊位”增量比“其他泊位”增量多2倍
②2022年年末，我国沿海港口生产用万吨级及以上码头泊位中，3万吨级以下泊位与5~10（不含）万吨级泊位数量差值在100以内
③2023年年末，我国港口生产用万吨级及以上码头泊位中，客货泊位同比负增长

### 选项
- A. ①②③
- B. ①③
- C. ②③　✅
- D. ①②

### 官方解析
①定位统计表2可得：2023年年末我国港口生产用万吨级及以上码头泊位中，多用途泊位同比增长8个，其他泊位同比增长4个。根据公式：多几倍=倍数-1，则“多用途泊位”增量比“其他泊位”增量多倍，并非多2倍，错误；
②定位统计表1可得：2023年年末我国沿海港口生产用万吨级及以上码头泊位中，3万吨级以下泊位744个，同比增长38个；5~10（不含）万吨级泊位824个，同比增长26个。根据公式：基期量=现期量-增长量，则2022年年末二者相差（824-26）-（744-38）=92个，差值在100以内，正确；
③定位统计表2可得：2023年年末我国港口生产用万吨级及以上码头泊位中，客货泊位3个，同比增长-1个，即同比负增长，正确。
综上，可由资料推出的是②③。
故正确答案为C。
