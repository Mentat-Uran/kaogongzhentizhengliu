# 综合分析判断题（①②③逐条判定可推出性：基期率还原+无中生有识别）

考点：[[20-考点/资料分析/综合/综合分析判断题（①②③逐条判定可推出性：基期率还原+无中生有识别）|综合 / 综合分析判断题（①②③逐条判定可推出性：基期率还原+无中生有识别）]]
材料：[[15-材料/资料分析/198930 2015年我国城市环境质量与环境基础|198930 2015年我国城市环境质量与环境基础]]

**问法模型**：题干出现'根据上述资料，可以推出'+①②③组合判断 → 逐条定位数据链模型：凡材料给出'现期值+提高X个百分点'的可用减法还原基期判真，凡只给现期值而无增幅/变化量的判'无中生有'不能推出

## 推理链
1. 修订版补充国家统计局2015年统计公报的同年数据。①建成区绿地率36.3%，较上年提高0.05个百分点，2014年为36.25%，不等于题项32.6%，错误。
2. ②公报给出2015年城市污水处理率91.0%，比上年提高0.8个百分点，题项正确。
3. ③公报给出2015年生活垃圾无害化处理率92.5%，提高0.7个百分点；2014年为92.5%−0.7%=91.8%，高于90%，正确。
4. ②③正确，修订版答案C。原摘录未补充污水处理率变化时，原官方答案D只适用于原题版本。

**最快解法**：⚡ 用公报核对三项：36.3%−0.05%=36.25%≠32.6%；污水处理率变化正是+0.8个百分点；垃圾处理率92.5%−0.7%=91.8%>90%，仅②③成立，选C。

## 易错点
- ⚠ 原摘录对污水处理率只列现期值；修订版已用国家统计局同年度公报补入“91.0%，提高0.8个百分点”，不能把原题答案D与补充后的答案C混为一题。
- ⚠ 绿地率的基期需用百分点变化直接相减；不能把绿地面积增长率直接套到绿地率。
- ⚠ “提高0.7个百分点”是率之差，2014年率=92.5%−0.7%=91.8%。

## 母题抽象
> 🧩 组合判断题中，凡陈述含'现期值+提高X个百分点'的用'基期值=现期值−X个百分点'减法验证判真；凡只给现期值而无增幅/变化量的判'无中生有'为假，先排除含假项的选项快速锁定答案

**同类特征**：根据上述资料，可以推出、①②③组合判断选项、基期率还原：现期率−提高的百分点、无中生有（信息不足不能推出）、个百分点与增长率口径辨析、纯文字材料综合分析
