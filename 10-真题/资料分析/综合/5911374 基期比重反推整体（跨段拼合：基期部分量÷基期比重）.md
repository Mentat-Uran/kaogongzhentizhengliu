# 基期比重反推整体（跨段拼合：基期部分量÷基期比重）

考点：[[20-考点/资料分析/综合/基期比重反推整体（跨段拼合：基期部分量÷基期比重）|综合 / 基期比重反推整体（跨段拼合：基期部分量÷基期比重）]]
材料：[[15-材料/资料分析/6088004 H市2023年第14周流感哨点医院流|6088004 H市2023年第14周流感哨点医院流]]

**问法模型**：问基期（2022年第14周）的整体量，但材料只有现期部分量+同比增速、现期比重+百分点差 → 采用'基期比重模型'：整体基期量=[A/(1+a)]÷(b±Δ个百分点)

## 推理链
1. 第1步：定位导语与第（一）段：2023年第14周流感样病例5187例，比去年同期（2022年第14周）减少56.16%，全市ILI%=5.98%
2. 第2步：定位第（二）段：2023年第14周全市ILI%比2022年同期低7.56个百分点，因'低'需加回，2022年同期ILI%=5.98%+7.56%=13.54%
3. 第3步：用基期量公式还原2022年第14周流感样病例数=5187/(1-56.16%)=5187/0.4384≈11827例
4. 第4步：用'整体=部分÷比重'求2022年第14周就诊病人总数=11827/13.54%≈87300余例
5. 第5步：与选项对照，87300余最接近87000，选A；注意导语中86749例与环比+5.76%属于上周环比口径，是本题干扰数据，不可用

**最快解法**：⚡ 合并算式+截位直除（百化分）：所求=5187/[(1-56.16%)×(5.98%+7.56%)]，截位得5187/(0.44×13.5%)=5187/0.0595≈8.7万，一步直除直接锁定A；56.16%按'1-56%≈44%'处理，13.54%按13.5%处理

## 易错点
- ⚠ 最大陷阱：误用导语86749例及其'比上周增加5.76%'（环比）去求2022年第14周就诊总数——求去年同期就诊总数必须跨段拼合，单一数据源无法作答
- ⚠ 百分点方向词写反：'比2022年同期低7.56个百分点'求基期率应加回（5.98%+7.56%=13.54%），若减去会得到负值/错误比重，结果完全偏离
- ⚠ 运算方式混淆：基期率用加减百分点，基期量用除法（除以1-56.16%）；同一题内两者混排，易把56.16%当百分点去加减或把除法当乘法
- ⚠ 分类口径重叠：国家级455例、城区1899例、郊区县市3288例与全市总数5187例存在从属关系，本题只需全市口径5187例，误拆三口径会重复计算

## 母题抽象
> 🧩 当题干求基期整体量、材料只给'现期部分量+同比增速'与'现期比重+百分点差'时，先A/(1+a)还原基期部分，再按方向词加减百分点还原基期比重，两者相除即答案；导语中的环比数据（总数、环比增速）是典型干扰项

**同类特征**：求基期（去年/上期）的整体量、材料只给部分量与比重，未直接给整体量、同比增速与'低/高X个百分点'并存、需跨段拼合两处以上数据、现期与基期时间口径不同（2023年第14周vs2022年第14周）、选项差距较小、需精度控制
