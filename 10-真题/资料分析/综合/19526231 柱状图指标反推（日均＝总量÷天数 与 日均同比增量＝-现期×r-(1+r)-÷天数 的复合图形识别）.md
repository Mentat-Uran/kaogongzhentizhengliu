# 柱状图指标反推（日均＝总量÷天数 与 日均同比增量＝-现期×r-(1+r)-÷天数 的复合图形识别）

考点：[[20-考点/资料分析/综合/柱状图指标反推（日均＝总量÷天数 与 日均同比增量＝-现期×r-(1+r)-÷天数 的复合图形识别）|综合 / 柱状图指标反推（日均＝总量÷天数 与 日均同比增量＝[现期×r/(1+r)]÷天数 的复合图形识别）]]
材料：[[15-材料/资料分析/6672424 2025年清明、'五一'、端午三个假|6672424 2025年清明、'五一'、端午三个假]]

**问法模型**：柱状图反推指标（横轴0基准）→ 对四个选项分别按'现期总量÷天数'或'增量[现期×r/(1+r)]÷天数'算出清明/'五一'/端午三期数值，与柱子相对高度逐一匹配排除

## 推理链
1. 第1步：从材料提取条件——三个假期天数分别为3天、5天、3天；红色景区接待54.7、119.5、54.4万人次（增速5.1%、12.0%、17.5%），4A级及以上景区接待657.5、1629.9、726.1万人次（增速7.4%、14.3%、18.9%）
2. 第2步：确定两把计算尺——'日均数量'类＝现期总量÷天数；'日均同比增量'类＝现期总量×r/(1+r)÷天数（先增长量公式再摊到每天）
3. 第3步：验证A项（红色景区日均同比增量）——清明54.7×5.1%/1.051÷3≈0.88、'五一'119.5×12%/1.12÷5≈2.56、端午54.4×17.5%/1.175÷3≈2.70万人次，呈'低—高—略高'递增趋势，与柱状图吻合
4. 第4步：排除B项（红色景区日均数量）——54.7/3≈18.2、119.5/5≈23.9、54.4/3≈18.1万人次，清明与端午首尾几乎相等，与柱状图趋势不符
5. 第5步：排除C项（4A景区日均同比增量）——清明657.5×7.4%/1.074÷3≈15.1、'五一'1629.9×14.3%/1.143÷5≈40.8、端午726.1×18.9%/1.189÷3≈38.5万人次，'五一'增量＞端午，与柱状图不符
6. 第6步：排除D项（4A景区日均数量）——657.5/3≈219、1629.9/5≈326、726.1/3≈242万人次，'五一'＞端午＞清明，与柱状图不符；仅A项趋势吻合，选A

**最快解法**：⚡ 量级排除＋截位直除：图中柱子若为小数量级（零点几到几万人次），可直接排除'日均数量'类（B项18~24万人次、D项219~326万人次量级悬殊）；再对A、C算'增量÷天数'，C项'五一'(约40.8)＞端午(约38.5)与图矛盾，A项0.88→2.56→2.70递增吻合，锁定A；考场可先只算首尾两期（清明最小、端午略大于'五一'）快速定性

## 易错点
- ⚠ '日均'口径陷阱：三个假期天数3/5/3不同，比较趋势必须先除以天数；若直接拿总量比，红色景区'54.7与54.4首尾几乎相等'的假象会把答案误判为B
- ⚠ 增量≠现期×r：同比增量须用r/(1+r)折算；端午增速17.5%最高但基数小，总量增量约8.1万人次仍小于'五一'的约12.8万人次，凭'增速高'直觉易错
- ⚠ 除以天数后趋势反转：'五一'总量增量最大（约12.8万人次）但要摊5天，日均增量约2.56反低于端午约2.70，'总量大≠日均大'是排除C/D的关键；同时注意4A景区数据（657.5/1629.9/726.1）与红色景区数据（54.7/119.5/54.4）不可取数混淆

### 题干
以下柱状图反映了2025年清明假期、“五一”假期和端午假期，Y省接待游客哪一指标的变化情况（横轴位置表示数值为0）？

### 选项
- A. 纳入监测的13家红色旅游经典景区日均接待游客数同比增量　✅
- B. 纳入监测的13家红色旅游经典景区日均接待游客数量
- C. 4A级及以上景区日均接待游客数同比增量
- D. 4A级及以上景区日均接待游客数量

### 官方解析
根据题干“以下柱状图反映了2025年······Y省接待游客哪一指标的变化情况······”，结合选项中涉及日均接待游客数，可判定本题为平均数问题。定位材料第一、二、三段可得2025年清明假期、“五一”假期和端午假期的天数、Y省接待游客各指标数据和同比增长率。根据公式：平均数，增长量，可得Y省接待游客各指标的数据情况如下：
A项，纳入监测的13家红色旅游经典景区日均接待游客数同比增量：清明假期，万人次；“五一”假期，万人次；端午假期，万人次，符合柱状图变化趋势，当选；
B项，纳入监测的13家红色旅游经典景区日均接待游客数量：清明假期，万人次；端午假期，万人次。清明假期日均接待游客数量与端午假期几乎相等，不符合柱状图变化趋势，排除；
C项，4A级及以上景区日均接待游客数同比增量：清明假期，万人次；“五一”假期，人次；端午假期，万人次。“五一”假期同比增量&gt;端午假期同比增量，不符合柱状图变化趋势，排除；
D项，4A级及以上景区日均接待游客数量：清明假期，万人次；“五一”假期，万人次；端午假期，万人次。“五一”假期日均接待游客数量&gt;端午假期日均接待游客数量，不符合柱状图变化趋势，排除。
故正确答案为A。
