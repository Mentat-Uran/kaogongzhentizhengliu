# 综合分析选非题（当月占全年比重、月均值比较、比重比求倍数、基期量与年均值两步拼接）

考点：[[20-考点/资料分析/综合/综合分析选非题（当月占全年比重、月均值比较、比重比求倍数、基期量与年均值两步拼接）|综合 / 综合分析选非题（当月占全年比重、月均值比较、比重比求倍数、基期量与年均值两步拼接）]]
材料：[[15-材料/资料分析/3333931 2023年我国邮政行业业务收入与快递|3333931 2023年我国邮政行业业务收入与快递]]

**问法模型**：题干为'下列表述错误的是'的选非综合题 → 逐项定位数据源并代入对应公式验证，锁定唯一错误项

## 推理链
1. 第1步：A项从统计表取异地快递全年累计1153.6亿件、12月当月115.3亿件，比重=115.3÷1153.6≈10%，表述正确排除
2. 第2步：B项取邮政集团其他寄递业务全年累计304.1亿件、12月当月29.2亿件，1-11月合计=304.1-29.2=274.9亿件，月均=274.9÷11≈25亿件<29.2亿件，12月大于月均值，表述正确排除
3. 第3步：C项从文字第二段取中部、西部快递业务量比重16.7%和8.1%，同一整体下倍数=16.7%÷8.1%≈2.06，为2倍以上，表述正确排除
4. 第4步：D项从统计表取国际/港澳台快递2023年全年累计30.7亿件、同比增速52.0%，基期2022年=30.7÷(1+52.0%)≈20.2亿件
5. 第5步：2022~2023年均值=(20.2+30.7)÷2≈25.4亿件<27亿件，'超过27亿件'表述错误
6. 第6步：本题为选非题，错误项D即为正确答案

**最快解法**：⚡ 百化分+两步拼接直除：优先验算含'基期+年均'两步计算的D项；52%≈1/2，基期=30.7÷(1+52%)≈30.7×2/3≈20.5亿件（精确约20.2），年均=(30.7+20.2)÷2≈25.4亿件<27亿件，立即锁定D错误，A、B、C可粗验（115.3/1153.6≈10%；274.9/11≈25<29.2；16.7/8.1≈2.1>2）无需精算

## 易错点
- ⚠ 表头'12月份'下混排'全年累计'与'当月'两列：A项需用当月115.3对照全年累计1153.6，B项需用当月29.2对照全年累计304.1，勿拿当月值当全年值或混列相除
- ⚠ 求D项基期必须用'全年累计'增速52.0%，误用当月增速35.7%会得到30.7÷1.357≈22.6、年均≈26.7仍小于27虽结论不变但过程口径错误；更需防直接拿30.7与27比较而漏掉2022年基期
- ⚠ '年均快递业务量'指(2022年+2023年)÷2两个年度的平均，勿误算为三年或直接用现期30.7亿件
- ⚠ C项只能用业务量比重16.7%/8.1%相除，误用业务收入比重14.1%/9.7%≈1.45会误判为不到2倍；前提是两者同属'快递业务量'这一同一整体，比重之比才等于部分之比

## 母题抽象
> 🧩 当题干出现'下列表述错误的是'且选项跨表格当月/累计列与文字比重时，逐项套用'当月占比=当月÷全年累计、月均=(全年-当月)÷11、同整体倍数=比重之比、基期=现期÷(1+全年累计增速)、年均=(基期+现期)÷2'，优先验算步骤最多（含基期+年均拼接）的选项

**同类特征**：选非题/表述错误、12月当月占全年比重约10%、1-11月月均值与当月比较、比重之比求倍数、基期量+年均量两步拼接、全年累计与当月口径切换

### 题干
根据所给材料，下列表述错误的是：

### 选项
- A. 我国2023年12月的异地快递业务量约占全年异地快递业务量的10%
- B. 我国2023年12月的邮政集团其他寄递业务量大于同年1-11月的月均值
- C. 2023年，我国中部地区实现的快递业务量是西部地区的2倍以上
- D. 2022~2023年，我国国际/港澳台年均快递业务量超过27亿件　✅

### 官方解析
A项：定位统计表可得：2023年全年累计和12月我国异地快递业务量分别为1153.6亿件和115.3亿件。根据公式：比重，则我国2023年12月的异地快递业务量占全年异地快递业务量的比重，正确；
B项：定位统计表可得：2023年全年累计和12月邮政集团其他寄递业务量分别为304.1亿件和29.2亿件。则1~11月邮政集团其他寄递业务量=全年邮政集团其他寄递业务量-12月邮政集团其他寄递业务量=304.1-29.2=274.9亿件。根据公式：月均值，则2023年1-11月邮政集团其他寄递业务量月均值亿件&lt;29.2亿件，即我国2023年12月的邮政集团其他寄递业务量大于同年1-11月的月均值，正确；
C项：定位文字材料第二段可得：2023年我国中、西部地区快递业务量的比重分别为16.7%和8.1%。根据公式：部分=整体×比重，则倍，即2倍以上，正确；
D项：定位统计表可得：2023年国际/港澳台快递业务量30.7亿件，同比增速52.0%。根据公式：基期量，则2022年国际/港澳台快递业务量亿件。根据公式：年均快递业务量，则2022~2023年我国国际/港澳台年均快递业务量亿件&lt;27亿件，错误。
本题为选非题，故正确答案为D。
