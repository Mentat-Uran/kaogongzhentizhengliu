# 分季度同比增速走势还原与图形选项匹配

考点：[[20-考点/资料分析/综合/分季度同比增速走势还原与图形选项匹配|综合 / 分季度同比增速走势还原与图形选项匹配]]
材料：[[15-材料/资料分析/277850 疫情背景下2020年全国及G省社会消|277850 疫情背景下2020年全国及G省社会消]]

**问法模型**：题干用定性描述给出各季度同比情况（大幅下降/降幅收窄/基本持平/同比增长），要求选出最可能符合的季度走势图 → 先把定性描述翻译成增速大小关系链，再逐图排除

## 推理链
1. 第1步：定位文字第二段，提取四个季度的定性描述：一季度'市场销售大幅下降'→同比增速为较大负值；二季度'降幅较一季度收窄10个百分点'→二季度增速=一季度增速+10个百分点，仍为负值；三季度'与去年同期基本持平'→同比增速≈0；四季度'同比增长'→同比增速>0
2. 第2步：建立四季度同比增速的大小关系与走势模型：一季度 < 二季度 < 三季度≈0 < 四季度，其中一、二季度同为负值且相差10个百分点，三、四季度由0附近转正
3. 第3步：逐项对照选项图形：A、B两项一季度的增速位置与'大幅下降'（深负值）不符，排除A、B；C、D两项一、二季度均满足'深负值→降幅收窄10个百分点'的特征
4. 第4步：三季度增速应'基本持平'即≈0，D项三季度形态与增速≈0不符，排除D；C项四个季度依次呈现深负→负值收窄→≈0→正值的走势，与文字描述完全吻合，当选

**最快解法**：⚡ 定性排序排除法：抓三个0轴锚点——①一季度为最深负值（大幅下降）、②三季度≈0（基本持平）、③四季度在0轴上方（同比增长），先看三、四季度相对0轴位置排除明显不符项，再用'二季度降幅较一季度收窄10个百分点'核对一、二季度同为负值且间距合理的选项

## 易错点
- ⚠ 本题匹配的是各季度同比增速的走势，不是各季度零售额绝对值：全年总量同比下降6.4%（由图中折线读出）不代表每季均为负，四季度同比增长即为正值，误按绝对额下滑选图必错
- ⚠ '降幅收窄10个百分点'是降幅之差：二季度增速=一季度增速+10个百分点，切勿误读为二季度下降10%或降幅恰为10个百分点
- ⚠ '三季度与去年同期基本持平'指同比增速≈0（约等于零，是同比口径而非与二季度环比持平），不是恰好为0；四季度'同比增长'必为正值，落在0轴下方即可排除

## 母题抽象
> 🧩 当题干出现'某季大幅下降/降幅较上季收窄N个百分点/与去年同期基本持平/同比增长'这类季度定性描述并配折线图选项时，先转化为增速大小关系链（深负→负收窄→≈0→正），再以0轴为锚点、按相邻差值逐图排除

**同类特征**：各季度社会消费品零售情况、图形选项匹配、降幅较一季度收窄10个百分点、三季度与去年同期基本持平、四季度同比增长、同比增速走势还原
