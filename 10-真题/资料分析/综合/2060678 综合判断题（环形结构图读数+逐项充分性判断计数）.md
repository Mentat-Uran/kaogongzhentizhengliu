# 综合判断题（环形结构图读数+逐项充分性判断计数）

考点：[[20-考点/资料分析/综合/综合判断题（环形结构图读数+逐项充分性判断计数）|综合 / 综合判断题（环形结构图读数+逐项充分性判断计数）]]
材料：[[15-材料/资料分析/187636 某总公司下属甲、乙、丙3个分公司职工|187636 某总公司下属甲、乙、丙3个分公司职工]]

**问法模型**：'下列说法一定正确的有几个'→对每条陈述做充分性检验（在已知条件下是否必然成立），统计必然成立的条数

## 推理链
1. 第1步：按注释'从内到外分别为甲、乙、丙'读环：甲（内）培训20%、提升职务30%、改善环境20%、提高薪酬30%；乙（中）15%、35%、25%、25%；丙（外）10%、35%、15%、40%，各环合计均为100%
2. 第2步：验证(1)：只给总公司共1500人，乙分公司人数未知，'乙内改善环境占25%'缺少分母，无法乘出125人，(1)不必然成立
3. 第3步：验证(2)：丙环内提高薪酬40%为该环最大占比（高于提升职务35%、改善环境15%、培训10%），丙总人数一定，故该项人数必最多，(2)成立
4. 第4步：验证(3)：甲乙丙三公司各自总人数未知，无法将各环占比加权合并成全公司占比（若甲占比大，甲内提高薪酬30%仅与提升职务30%持平），(3)不必然成立
5. 第5步：必然正确的仅(2)共1个，对照选项C（1个），与官方答案一致

**最快解法**：⚡ 缺口排除法：(1)(3)共同卡点是'各分公司人数未知'——凡需分公司/全公司绝对人数或跨公司加权占比而分母未给的表述直接判'不一定正确'，排除A、B；再验证(2)只需比较丙环四个扇区占比大小（40%最大）即可锁定C

## 易错点
- ⚠ (1)陷阱：误用'总公司1500人×乙占比25%'凑出125人，实际25%的分母是乙分公司人数而非总公司人数
- ⚠ (3)陷阱：把三个分公司占比相加或简单平均当作全公司占比（40%+25%+30%之类），忽略三公司样本量未必相等、不能跨分母直接比较
- ⚠ 读图陷阱：三环数据相近，必须按注释'从内到外为甲、乙、丙'认准归属，防止把丙的40%误读到乙环

## 母题抽象
> 🧩 当综合判断题出现'如果总公司共N人则某分公司某项有X人'或'全公司中某项占比最大'类表述时，先查该项占比的分母（分公司人数/全公司人数）是否已知：分母未知即'不一定正确'；人数多少的比较只在同一分母内（同一分公司内部占比大小）才可判定

**同类特征**：一定正确的有几个、环形结构图、分公司内部占比、总人数/分母未知、逐项充分性判断、计数型综合分析

### 题干
根据该总公司所属3个分公司职工意愿调查结构的情况，下列说法一定正确的有（  ）个。
（1）如果该总公司人数共1500人，则乙分公司有意愿改善工作环境的职工有125人。
（2）丙分公司中，有意愿提高薪酬的职工人数最多。
（3）在该总公司职工中，有意愿提高薪酬的职工在职工总人数中占比最大。

### 选项
- A. 3
- B. 2
- C. 1　✅
- D. 0

### 官方解析
本题属于综合分析，需结合每一个选项的描述与表格、材料中给出的具体数据判断其是否正确。
（1）只给出总公司人数，乙分公司人数未知，无法求出乙分公司中有意愿改善工作环境的职工人数，错误。
（2）由图形材料可得，丙公司中有意愿提高薪酬的职工比重最高，且丙分公司总数一定，故该项人数最多，正确。
（3）由于甲乙丙三个分公司总人数未知，故无法推算有意愿提高薪酬的职工在职工总人数中的占比情况，错误。
故正确答案为C。
