# 综合判断（顺差额比较+基期顺差计算+比重比较）

考点：[[20-考点/资料分析/综合/综合判断（顺差额比较+基期顺差计算+比重比较）|综合 / 综合判断（顺差额比较+基期顺差计算+比重比较）]]
材料：[[15-材料/资料分析/239309 2011-2017年我国服务进出口（|239309 2011-2017年我国服务进出口（]]

**问法模型**：『能够从上述资料中推出的是』→ 综合判断题逐项排除：先查主体/口径偷换，再用顺差=出口-进口、基期=现期÷(1+同比)、占比=部分÷整体逐项核对，锁定唯一可推出项

## 推理链
1. 第1步：A项从表1提取数据——材料只给2011-2017年我国服务进出口额（2017年46991亿元），并非我国（全部货物与服务）进出口额，主体范围被偷换扩大，无法推出
2. 第2步：B项从表2取建筑服务2017年出口1618.0（+92.0%）、进口579.0（+5.4%），按基期=现期÷(1+同比)倒推2016年出口=1618÷1.92≈842.7亿元、进口=579÷1.054≈549.3亿元
3. 第3步：2016年建筑服务顺差=842.7-549.3≈293.4亿元（1039亿元实为2017年顺差1618-579，属基期混淆），B错误
4. 第4步：C项2017年顺差=出口-进口逐项口算：加工服务1223-12=1211、维护和维修401-153=248、建筑1618-579=1039、金融服务250-109=141、电信计算机和信息1876-1295=581、其他商业服务4157-2895=1262，最大为其他商业服务1262亿元，C正确
5. 第5步：D项占比=部分÷整体（整体为表1的2017年服务进出口46991亿元）：别处未提及的政府服务348÷46991≈0.74%，而个人文化和娱乐服务237÷46991≈0.50%更小，故政府服务占比并非最小，D错误
6. 第6步：对照选项，唯一能推出的为C项

**最快解法**：⚡ 综合题先打最易判项：A项『服务进出口』≠『我国进出口』主体偷换直接排除；C项只比顺差两强——其他商业服务4157-2895=1262 与 加工服务1223-12=1211，1262更大即锁定C，B、D无需再验，考场节省时间

## 易错点
- ⚠ A项主体偷换：材料口径为『服务进出口』，选项偷换为『我国进出口』，全口径贸易差额无从判断
- ⚠ B项基期/现期混淆：1039=1618-579是2017年顺差，题干问2016年须先各自÷(1+同比)再作差，仅约293.4亿元，直接用现期作差必错
- ⚠ D项须同分母比占比而非单看金额：348÷46991≈0.74%＞237÷46991≈0.50%，金额第二小的个人文化和娱乐服务占比才最小，勿只盯绝对额
- ⚠ 顺差方向：顺差=出口-进口（收入-支出），反向相减即整题崩盘

- A. 2011年至2017年，我国进出口总是出现逆差
