# 比重传递-比值构造（部分比率=整体比率×比重之比）

考点：[[20-考点/资料分析/比重/比重传递-比值构造（部分比率=整体比率×比重之比）|比重 / 比重传递/比值构造（部分比率=整体比率×比重之比）]]
材料：[[15-材料/资料分析/186512 J省S市2015年（对比2010年-|186512 J省S市2015年（对比2010年-]]

**问法模型**：题干设全省授权率为a（授权量/申请量），求S市授权率 → 用'S市授权量=全省授权量×16.8%、S市申请量=全省申请量×43.8%'还原分子分母，得S市授权率=a×(16.8%/43.8%)的比重传递模型

## 推理链
1. 第1步：从表格提取2015年数据——S市发明专利申请量占全省比重43.8%，授权量占全省比重16.8%
2. 第2步：设2015年全省申请量为A、授权量为B，则全省授权率a=B/A；S市申请量=43.8%×A，S市授权量=16.8%×B
3. 第3步：S市授权率=S市授权量÷S市申请量=(16.8%×B)÷(43.8%×A)=(16.8/43.8)×(B/A)=(16.8/43.8)×a
4. 第4步：代入计算16.8/43.8≈0.384，即S市授权率≈0.38a
5. 第5步：与选项对照，0.38a为A项，0.63a、0.78a、1.05a均与0.38a明显不符，故选A

**最快解法**：⚡ 比重传递+截位直除：S市授权率=a×16.8%/43.8%，截位算168/438，因43.8×0.38≈16.64≈16.8，商首位接近0.38，直接锁定A项（全程只需一次除法估算）

## 易错点
- ⚠ 分子分母口径错位：分子必须用'授权量占全省比重'16.8%，分母用'申请量占全省比重'43.8%；若颠倒得43.8/16.8≈2.6a（无对应选项），若误用授权率a直接乘43.8%÷16.8%亦错
- ⚠ 误用其他列/其他年份数据：'万人发明专利拥有量27.4件'是强度指标不能参与计算，2010年授权量占比为3也不属于本题时间口径（2015年）
- ⚠ 把两列比重关系误作相减：授权率是比值构造（相除），不是百分点差（相减），相减得16.8−43.8=−27%毫无意义

## 母题抽象
> 🧩 当题干出现'设整体（全省）某比率为a，求部分（某市）同口径比率'的特征时，用'部分量=占比×整体量'分别还原部分分子与分母，得部分比率=a×(分子占比÷分母占比)，验证结果系数小于1（因分子占比16.8%<分母占比43.8%）且与选项量级吻合

**同类特征**：设全省授权率为a、S市发明专利授权率、授权量占申请量之比、同用申请量、授权量两列占全省比重、比重相除构造比值、现期比重传递
