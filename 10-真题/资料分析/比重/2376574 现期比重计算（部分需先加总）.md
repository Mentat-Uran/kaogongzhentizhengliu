# 现期比重计算（部分需先加总）

考点：[[20-考点/资料分析/比重/现期比重计算（部分需先加总）|比重 / 现期比重计算（部分需先加总）]]
材料：[[15-材料/资料分析/239310 2011—2017年全国马拉松赛事发|239310 2011—2017年全国马拉松赛事发]]

**问法模型**：题干为'2017年A类与B类赛事占全国马拉松赛事的比例约为'→现期比重=部分÷整体=(A类场次+B类场次)÷全国马拉松赛事总场次

## 推理链
1. 第1步：定位文字材料第一段，提取数据：2017年全国举办马拉松赛事达1102场，其中中国田径协会举办的A类赛事223场、B类赛事33场
2. 第2步：确定部分与整体——整体=全国马拉松赛事1102场，部分=田协举办赛事=A类+B类=223+33=256场（两者口径不同层级，须先加总）
3. 第3步：代入现期比重公式：256÷1102≈23.2%
4. 第4步：与选项对照，约23.2%与B项最接近，故正确答案为B

**最快解法**：⚡ 截位直除：先口算加总223+33=256，再将1102截位为1100，256/1100≈23.3%，直除首两位'23'即可锁定B项；亦可先粗估256/1102略高于五分之一（20%），排除偏差较大的选项

## 易错点
- ⚠ 口径层级陷阱：1102场是'全国举办（规模）赛事'总数，223场、33场是田协认证A/B类赛事（注意与2020年认证目标350场区分），部分须先加总为256场再作比，不能只用223场或拿350场混算
- ⚠ 漏加B类33场：若只算223÷1102≈20.2%，会偏小约3个百分点而误选干扰项
- ⚠ 指标混淆：材料中'参与人次498万''完赛26.89万/45.29万人次'均为人次口径，本题问的是'场数'占比，切勿用人次数据除以场次

## 母题抽象
> 🧩 当题干出现'现期某部分占整体的比例约为'特征时，用现期比重=部分÷整体；若部分由多类构成（如A类+B类），先加总再作比，用截位直除对照选项即得答案

**同类特征**：现期年份2017年、'A类与B类赛事'两部分并列、'占全国马拉松赛事的比例'、问法带'约为'（估算对照选项）、部分需先加总再作比、场次口径而非人次口径
