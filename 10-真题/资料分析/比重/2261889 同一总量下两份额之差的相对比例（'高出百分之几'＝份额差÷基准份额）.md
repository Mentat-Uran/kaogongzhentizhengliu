# 同一总量下两份额之差的相对比例（'高出百分之几'＝份额差÷基准份额）

考点：[[20-考点/资料分析/比重/同一总量下两份额之差的相对比例（'高出百分之几'＝份额差÷基准份额）|比重 / 同一总量下两份额之差的相对比例（'高出百分之几'＝份额差÷基准份额）]]
材料：[[15-材料/资料分析/199272 中国移动支付市场：2015年银行与非|199272 中国移动支付市场：2015年银行与非]]

**问法模型**：'同一总量下，支付宝比财付通交易额高出约（选项为百分数）'→ 高出比例＝（支付宝份额−财付通份额）÷财付通份额＝份额比−1，总量7.5万亿元在比值中自动约去，只需读表1份额。

## 推理链
1. 第1步：题干锁定2016年第2季度，从表1提取支付宝份额55.40%、财付通份额32.10%；从图1末柱知该季第三方移动支付总交易规模7.5万亿元。
2. 第2步：'高出百分数'＝（支付宝交易额−财付通交易额）÷财付通交易额；两者等于7.5万亿×各自份额，总量7.5万亿在分子分母中约去，列式化为（55.40%−32.10%）÷32.10%。
3. 第3步：分子为份额差55.40−32.10＝23.30（个百分点），得23.30÷32.10。
4. 第4步：截位直除：32.1×0.7≈22.5，余约0.8，23.3/32.1≈72.6%，即约73%。
5. 第5步：与选项对照，72.6%（约73%）与B项最接近，选B；而23.30个百分点只是份额差，不等于'高出'的百分数。

**最快解法**：⚡ 份额比−1＋截位直除：同一总量下直接算55.40/32.10−1，把32.1截位为32，55.4/32≈1.73，减1得≈72.6%（约73%），一步出数；全程不需要用7.5万亿元算绝对额，也不用读柱线图。

## 易错点
- ⚠ 把'高出约'误当成份额差：55.40%−32.10%＝23.30个百分点是'高出的百分点'，选项为百分数时必须再除以基准份额32.10%，否则会错选≈23%的干扰项。
- ⚠ 先算绝对额再作比多走弯路：7.5×55.40%＝4.155万亿元、7.5×32.10%＝2.4075万亿元再相除，乘法位数和万亿/亿元量级换算易错；应先约去总量7.5万亿元。
- ⚠ 双轴图与表口径陷阱：柱线图中7.5是左轴交易规模（万亿元），不是右轴环比增速25.8%；表内10项份额合计约99.18%非严格100%，本题直接取用图面值55.40%与32.10%即可。

## 母题抽象
> 🧩 当题干出现'同一时期、同一总量下，甲（份额）比乙（份额）高出约百分数'时，用'份额差÷基准份额（＝两份额之比−1）'模型，总量自动约去，只读份额表，截位直除一步出数；若问'高出多少万亿元'则改为总量×份额差。

**同类特征**：'比……（交易额）高出约'且选项为百分数、同一季度同一市场总量下的两个市场份额、数据取自市场份额（比重）统计表、高出百分数＝差÷基准，而非百分点差、同一总量可约去，无需计算绝对交易额
