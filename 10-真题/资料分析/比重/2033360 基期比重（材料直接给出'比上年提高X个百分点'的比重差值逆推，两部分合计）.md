# 基期比重（材料直接给出'比上年提高X个百分点'的比重差值逆推，两部分合计）

考点：[[20-考点/资料分析/比重/基期比重（材料直接给出'比上年提高X个百分点'的比重差值逆推，两部分合计）|比重 / 基期比重（材料直接给出'比上年提高X个百分点'的比重差值逆推，两部分合计）]]
材料：[[15-材料/资料分析/185418 2015年全国文化及相关产业增加值（|185418 2015年全国文化及相关产业增加值（]]

**问法模型**：题干问基期年份（2014年）两个行业合计占整体的比重 → 先算两行业现期合计比重（增加值之和÷27235亿元），再减去两行业各提高0.5个百分点的比重变化量（共1.0个百分点）

## 推理链
1. 第1步：定位材料第三段：2015年文化休闲娱乐服务业增加值2044亿元、以'互联网+'为主的文化信息传输服务业增加值2858亿元，整体为文化及相关产业增加值27235亿元，且两行业占比均比上年（2014年）提高0.5个百分点
2. 第2步：所用规则——基期比重=现期比重−比重变化量；两行业合计的比重变化量=0.5+0.5=1.0个百分点
3. 第3步：现期合计比重=(2044+2858)÷27235=4902÷27235≈18.0%（27235×18%≈4902，几乎整除）
4. 第4步：2014年合计比重≈18.0%−1.0%=17.0%
5. 第5步：与选项对照，最接近17.0%的为B选项，故选B

**最快解法**：⚡ 特殊分数直除+百分点修正：先加部分值2044+2858=4902亿元，4902÷27235≈18%（按18%整除判定），再减去2×0.5=1.0个百分点，直得17.0%锁定B，无需分别求两行业各自基期比重

## 易错点
- ⚠ 把'提高0.5个百分点'误当增速代入基期量/增长率公式，或只减一个行业的0.5个百分点而漏加另一行业（两行业合计应共减1.0个百分点）
- ⚠ 时间方向搞反：问2014年基期应从现期比重往前减，若误加0.5×2个百分点会得约19%的错误方向选项
- ⚠ 口径与加总陷阱：分母应是文化及相关产业增加值27235亿元（不可误用GDP分母），且须两行业增加值合并后再算比重，只算2044÷27235或2858÷27235均会漏项

## 母题抽象
> 🧩 当题干问'基期年份某部分占整体比重'且材料出现'占X比重比上年提高a个百分点'时，用'基期比重=现期比重（部分÷整体）−a个百分点'直接逆推；两部分并列求合计时，先加现期部分值求总比重，再减a×2个百分点

**同类特征**：基期年份'2014年'设问、'占文化及相关产业增加值的比重'（占27235亿元口径，非占GDP）、两行业并列求合计比重、材料含'均比上年提高0.5个百分点'、现期比重数值被挖空、仅亿元绝对数完整、比重差值逆推而非增速公式法
