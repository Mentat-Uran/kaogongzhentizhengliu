# 现期比重（比重求值+成数判断）

考点：[[20-考点/资料分析/比重/现期比重（比重求值+成数判断）|比重 / 现期比重（比重求值+成数判断）]]
材料：[[15-材料/资料分析/3333931 2023年我国邮政行业业务收入与快递|3333931 2023年我国邮政行业业务收入与快递]]

**问法模型**：题干求'2023年A中B占比最接近几成'且时间与材料现期一致 → 现期比重=部分/总体，再按1成=10%换算选最接近档位

## 推理链
1. 第1步：题干时间为2023年，与材料现期一致，判定为现期比重问题，无需基期还原
2. 第2步：从文字材料第1段提取同口径数据：邮政行业业务收入（不含邮储银行直接营业收入）15293亿元（总体），其中快递业务收入12074亿元（部分）
3. 第3步：代入现期比重公式：比重=部分/总体=12074÷15293
4. 第4步：截位直除：12074/15293≈12074/15300≈0.79，即约79%
5. 第5步：换算成数：1成=10%，79%≈8成（与7成70%相比距80%更近），对照选项得B

**最快解法**：⚡ 截位直除+成数档位判断：12074/15293，分子分母各截三位≈121/153≈0.79，即约八成，直接锁定B；选项为'几成'档位（间隔10%），无需精确计算

## 易错点
- ⚠ 口径陷阱：分子分母必须同口径，均须限定'不含邮储银行直接营业收入'的15293亿元，不能引入其他收入口径
- ⚠ 几成换算错误：0.79≈八成而非七成，1成=10%，且选项是'最接近'的档位判断，不是精确匹配
- ⚠ 分子分母倒置：若误算15293÷12074≈1.27会完全偏离选项，比重=部分（快递收入）÷整体（行业收入）

## 母题抽象
> 🧩 当题干出现'现期A中B占比/比重为几成'且时间与材料一致时，直接用部分÷整体算比重，再按1成=10%换算到最接近的档位选项

**同类特征**：现期时间与材料一致（2023年）、占比/占……比重、最接近几成、部分与总体同在第1段、口径限定'不含邮储银行直接营业收入'
