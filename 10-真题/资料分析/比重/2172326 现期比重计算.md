# 现期比重计算

考点：[[20-考点/资料分析/比重/现期比重计算|比重 / 现期比重计算]]
材料：[[15-材料/资料分析/194345 2017年末全国汽车与机动车保有量及|194345 2017年末全国汽车与机动车保有量及]]

**问法模型**：题干以'A占B的比重是'设问且部分(65.0万辆)与整体(153.0万辆)均为2017年现期值 → 直接套现期比重公式 比重=部分/整体，一步直除。

## 推理链
1. 第1步：由题干'2017年……占……的比重'判定为现期比重问题，无需倒推基期
2. 第2步：定位材料第1段'全国新能源汽车保有量153.0万辆，其中新能源汽车新注册登记65.0万辆'，整体=年末保有量153.0万辆，部分=当期新注册登记65.0万辆
3. 第3步：代入现期比重公式：比重=65.0/153.0
4. 第4步：截位直除：65÷153，因153×0.42=64.26、153×0.43=65.79，商介于42%与43%之间，约42.5%
5. 第5步：与选项对照，约42.5%对应选项B，故正确答案为B

**最快解法**：⚡ 截位直除：65.0/153.0，先看首位商4（650÷153首位为4），153×0.42=64.26略小于65，故商≈42.5%，直选B；若选项量级差异大可直接估'65约为153的四成多'。

## 易错点
- ⚠ 流量/存量口径混排：分子65.0万辆是2017年全年新注册登记（流量），分母153.0万辆是年末时点保有量（存量），按题干设定直接相除，勿自作主张调整口径或另找分母
- ⚠ 干扰数据'比上年增加15.6万辆'：这是新注册登记量的同比增量（可倒推2016年新注册约49.4万辆），本题不需要；误用会错算成65/(153-15.6)等形式
- ⚠ 口径范围陷阱：分母必须是新能源汽车保有量153.0万辆，不能错用同段的民用汽车21743万辆或私人汽车18695万辆；'其中'二字已限定部分与整体的对应关系

## 母题抽象
> 🧩 当题干出现'某年A占B的比重'且A、B均为同一现期时点/期间的值时，直接用现期比重=部分/整体一步直除，不必倒推基期；只需警惕分子为流量、分母为存量的混搭口径。

**同类特征**：占……的比重、现期比重、新注册登记（当期流量）、年末保有量（时点存量）、一步直除/送分题、定位材料第1段
