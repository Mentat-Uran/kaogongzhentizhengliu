# 比重（城镇化率）差值比较及'每万人'人数换算

考点：[[20-考点/资料分析/比重/比重（城镇化率）差值比较及'每万人'人数换算|比重 / 比重（城镇化率）差值比较及'每万人'人数换算]]
材料：[[15-材料/资料分析/181642 中国2005-2014年城镇与乡村人|181642 中国2005-2014年城镇与乡村人]]

**问法模型**：题干问'每万人中城镇人口数量增长最多'→ 将每万人城镇人口=城镇化率×100人，问题等价于比较各国1990-2010年城镇化率百分点差的大小。

## 推理链
1. 第1步：题干要求比较美国、巴西、印度、韩国四国1990-2010年每万人中城镇人口的增长量，数据全部在图2'部分国家和地区城镇化率'表中。
2. 第2步：公式：每万人中城镇人口=城镇化率×10000÷100=城镇化率×100人，故其增长量=城镇化率差（百分点）×100人，四国换算系数相同，只需比较率差。
3. 第3步：代入图中数据求1990→2010年率差：美国82.14−75.30=6.84个百分点；巴西84.34−73.92=10.42个百分点；印度30.93−25.55=5.38个百分点；韩国82.93−73.84=9.09个百分点（对应每万人分别增长约684、1042、538、909人）。
4. 第4步：比较率差：10.42＞9.09＞6.84＞5.38，巴西的城镇化率增长最多。
5. 第5步：故每万人中城镇人口数量增长最多的国家是巴西，对照选项选B。

**最快解法**：⚡ 率差口算比较法：因'每万人'基数固定，人数增量=率差×100人，无需真算人数，直接口算四国2010年与1990年城镇化率之差（美国6.84、巴西10.42、印度5.38、韩国9.09个百分点），差值最大者即答案，秒选巴西（B）。

## 易错点
- ⚠ 单位换算陷阱：图1为万人、图2为%，率差每1个百分点对应每万人100人；本题虽只需比值差大小，但若真算人数漏乘100会量级出错。
- ⚠ 时间口径陷阱：图2年份不连续（仅1970/1980/1990/2000/2010/2011），必须取表中1990年与2010年两列数据，不能自行插值或取'就近年份'。
- ⚠ 范围与数据源陷阱：本题只涉及图2四国，不要误用图1中国人口数据；也不能默认所有国家率都增长（如表中俄罗斯1990→2000年曾回落），须逐年列实际取值作差。

## 母题抽象
> 🧩 当题干出现'每万人中××人口增长最多/最少'且材料只给比重（率）时，用'人数增量=率差（百分点）×固定基数'转化，直接比较各主体率差大小即可，无需计算真实人口。
