# 两期比重差（占比与上年相比下降的百分点）＋增速变化幅度比较

考点：[[20-考点/资料分析/比重/两期比重差（占比与上年相比下降的百分点）＋增速变化幅度比较|比重 / 两期比重差（占比与上年相比下降的百分点）＋增速变化幅度比较]]
材料：[[15-材料/资料分析/347129 2011—2015年我国国内生产总值|347129 2011—2015年我国国内生产总值]]

**问法模型**：先对逐年增速作差取绝对值找出'增速同比变化幅度最小'的年份，再用该年占比减上年占比求下降的百分点数

## 推理链
1. 第1步：从图1提取2011—2015年GDP增速：9.5%、7.7%、7.7%、7.2%、6.9%，题干限定在2012—2015年中比较
2. 第2步：逐年求增速同比变化幅度：2012年|7.7-9.5|=1.8、2013年|7.7-7.7|=0、2014年|7.2-7.7|=0.5、2015年|6.9-7.2|=0.3个百分点
3. 第3步：变化幅度最小为2013年（增速7.7%与2012年持平，变化为0），锁定目标年份为2013年
4. 第4步：从图2读取第二产业占GDP比重：2012年45.0%、2013年43.7%
5. 第5步：43.7%-45.0%=-1.3个百分点，即2013年第二产业占GDP比重比上年下降1.3个百分点
6. 第6步：对照选项，1.3对应C，故选C

**最快解法**：⚡ 心算作差法：扫图1折线找相邻两年增速相同的年份（2012、2013均为7.7%），变化幅度为0即最小，直接锁定2013年；再从图2取45.0%与43.7%作差得1.3，秒选C

## 易错点
- ⚠ 把'增速同比变化幅度最小'误读为'增速最慢'：增速最慢是2015年（6.9%），但变化幅度最小是2013年（0），题干问的是变化幅度而非增速高低
- ⚠ 时间范围陷阱：题干限定2012—2015年，2011年增速9.5%只作2012年的比较基准，不能把2011年纳入'最小年份'候选
- ⚠ 干扰项对应：若误判2014年为目标年会得43.7%-42.7%…即42.7%-43.7%=1.0对应A，误取2012年得46.1%-45.0%=1.1对应B，误把2012年增速变化幅度1.8当答案对应D，四个选项均为年份/指标错位设计

### 题干
2012-2015年，国内生产总值增速同比变化幅度最小的年份，第二产业占GDP的比重与上年相比下降了        个百分点。

### 选项
- A. 1.0
- B. 1.1
- C. 1.3　✅
- D. 1.8

### 官方解析
根据题干“2012-2015年······的比重与上年相比下降了······个百分点”，可判定本题为两期比重问题。定位统计图1可得：2011-2015年国内生产总值的同比增速分别为9.5%、7.7%、7.7%、7.2%、6.9%，由于2012年和2013年国内生产总值的同比增速相同，则2013年国内生产总值增速同比变化幅度最小。定位统计图2可得：2012年、2013年第二产业占GDP的比重分别为45.0%、43.7%，43.7%-45.0%=-1.3%，故2013年第二产业占GDP的比重与上年相比下降了1.3个百分点。
故正确答案为C。
