# 现期比重反推整体量（整体=部分÷比重）

考点：[[20-考点/资料分析/比重/现期比重反推整体量（整体=部分÷比重）|比重 / 现期比重反推整体量（整体=部分÷比重）]]
材料：[[15-材料/资料分析/6462966 2023年M市旅游接待规模（全市及核|6462966 2023年M市旅游接待规模（全市及核]]

**问法模型**：题干直接求'2023年M市地区生产总值'这一整体量，而材料只给部分值（旅游及相关产业增加值1207亿元）及其占比4.0% → 用整体=部分÷现期比重一步反推

## 推理链
1. 第1步：定位统计表得2023年M市旅游及相关产业增加值为1207亿元；定位文字段得该增加值占全市地区生产总值的比重为4.0%（两处数据缺一不可）
2. 第2步：现期比重公式：比重=部分÷整体，变形得整体=部分÷比重
3. 第3步：代入计算：GDP=1207亿元÷4.0%=1207×25=30175亿元
4. 第4步：与选项对照：30175亿元对应D选项，且量级约3万亿元与材料'占GDP比重4.0%'的口径自洽，故选D

**最快解法**：⚡ 百化分速算：4.0%=1/25，故GDP=1207÷(1/25)=1207×25，口算120700÷4=30175亿元，直接锁定D，全程无需动笔除法

## 易错点
- ⚠ 跨段跨表取数：1207亿元在统计表末行、4.0%在文字段末句，只看单一材料无法求解
- ⚠ 勿画蛇添足：表中另有增速13.5%，本题是现期比重求整体，不需要÷(1+13.5%)做基期换算；也不能用'提高0.3个百分点'参与运算（那是比重差不是增速）
- ⚠ 量级恐慌：结果约3万亿元，考生易因GDP'太大'而自我怀疑改选B/C，应相信1207÷4%的硬算结果

## 母题抽象
> 🧩 当题干出现'某年××地区生产总值（整体量）为'且材料同时给出'某部分增加值+其占整体的比重'时，用整体=部分÷比重一步反推，速算技巧是把比重百化分（如4.0%→1/25）转为乘法

**同类特征**：求地区生产总值（整体量未知）、材料给出部分值1207亿元、材料给出占比4.0%、现期比重反推整体、需跨文字段与统计表拼合数据、选项数值量级差异明显
