# 比重差值（百分点简单计算）

考点：[[20-考点/资料分析/比重/比重差值（百分点简单计算）|比重 / 比重差值（百分点简单计算）]]
材料：[[15-材料/资料分析/309014 2016年《中国妇女发展纲要（201|309014 2016年《中国妇女发展纲要（201]]

**问法模型**：题干问'现期占比超过目标值多少个百分点' → 直接用材料给出的现期比重减去目标比重，结果单位为'个百分点'，无需任何基期换算

## 推理链
1. 第1步：定位材料第1段，提取两个数据：2016年全国女性就业人员占全社会就业人员比重43.1%，《纲要（2011-2020年）》规定目标为40%
2. 第2步：所求为两个同口径比重之差，公式：超出量（个百分点）=现期比重−目标比重
3. 第3步：代入计算：43.1%−40%=3.1%，即超出3.1个百分点
4. 第4步：与选项对照：B为3.1，正确；A的4.1、C的18分别是材料后文'提高4.1个百分点''提高18个百分点'的干扰数据，D的2.1为无源干扰项

**最快解法**：⚡ 口算减法（无需速算技巧）：43.1−40=3.1，直接锁定B；关键是看清单位问的是'个百分点'且两个数据在第1段成对出现

## 易错点
- ⚠ 干扰项陷阱：A的4.1来自第3段'比重提高4.1个百分点'，C的18来自第2段'提高18个百分点'，均为材料中其他段落的百分点数据，不可串段取数
- ⚠ 单位口径：差值表述为'个百分点'，不能与增长率'%'混用；本题虽两者数值相同，但表述必须按百分点理解
- ⚠ 跨段误配：勿把第1段43.1%与其他段的73%、38%、46.6%等比重数据混配运算

## 母题抽象
> 🧩 当题干出现'某比重/占比超过目标（规定值）多少个百分点'时，用材料中成对给出的现期比重减目标比重即可，警惕其他段落相同形式的'提高X个百分点'被设为干扰选项

**同类特征**：占比超……多少个百分点、《纲要》规定的目标、现期比重43.1%对40%、两个比重直接相减、单段定位即可求解、干扰项为其他段的百分点数据

### 题干
2016年全国女性就业人员占比超《中国妇女发展纲要（2011-2020年）》多少个百分点？

### 选项
- A. 4.1
- B. 3.1　✅
- C. 18
- D. 2.1

### 官方解析
定位材料第一段：2016年全国女性就业人员占全社会就业人员的比重为43.1%，超过《中国妇女发展纲要（2011-2020年）》规定的40%的目标。则2016年全国女性就业人员占比-《中国妇女发展纲要（2011-2020年）》规定占比=43.1%-40%=3.1%，即3.1个百分点。
故正确答案为B。
