# 自定义比值（老少比）大小比较——同分母抚养比相除

考点：[[20-考点/资料分析/比重/自定义比值（老少比）大小比较——同分母抚养比相除|比重 / 自定义比值（老少比）大小比较——同分母抚养比相除]]
材料：[[15-材料/资料分析/199267 2010年部分省（区、市）人口年龄构|199267 2010年部分省（区、市）人口年龄构]]

**问法模型**：题干临时定义新指标'老少比=60岁及以上人口÷0~14岁人口'并比较四地区大小 → 利用老年抚养比与少儿抚养比分母相同（均为15-59岁人口），转化为'老年抚养比÷少儿抚养比'直接做比值比较

## 推理链
1. 第1步：从统计表提取四地区抚养比数据：北京少儿10.91、老年15.91；上海少儿11.29、老年19.75；重庆少儿25.92、老年26.56；广东少儿22.99、老年13.26（单位%）
2. 第2步：老少比=60岁及以上人口÷0~14岁人口；老年抚养比=60岁及以上÷15-59岁，少儿抚养比=0~14岁÷15-59岁，两式相除分母（15-59岁人口）约去，故老少比=老年抚养比÷少儿抚养比
3. 第3步：代入截位直除：北京15.91/10.91≈1.46；上海19.75/11.29≈1.75；重庆26.56/25.92≈1.02；广东13.26/22.99≈0.58
4. 第4步：比较四个比值，上海≈1.75最接近2且为四地最高，对照选项B（上海），故正确答案为B

**最快解法**：⚡ 同分母消元（公式法）+截位直除：不必先做100%减法补'60岁及以上占比'再算绝对数，直接用老年抚养比÷少儿抚养比：北京1.4+、上海1.7+、重庆1.0+、广东0.5−，一眼锁定上海最大

## 易错点
- ⚠ 绕远路：先由100%−0-14岁占比−15-59岁占比补算'60岁及以上'隐藏列（如上海=100−8.61−76.31=15.08），再算15.08/8.61，步骤多且易算错；直接抚养比相除即可
- ⚠ 口径混淆：抚养比以15-59岁人口为分母，占总人口比重以总人口为分母，两套%不可混用；老少比只能由同分母的抚养比相除（或同口径的占比相除）求得
- ⚠ 查表串行：上海与北京的少儿抚养比（11.29与10.91）、0-14岁占比（8.61与8.60）数值高度接近，13行逐行查找易取错行导致比值算反

## 母题抽象
> 🧩 当题干临时定义'A组人口/B组人口'之比且材料给出两组各自对同一分母的比值（抚养比）时，直接用'分子组比值÷分母组比值'消去公共分母做大小比较，无需回推绝对数或补算隐藏列

**同类特征**：临时定义新指标'老少比'、60岁及以上与0~14岁人口数之比、四地区比值最大/最高、抚养比同分母可约去、60岁及以上占比列留空需100%减法

如果将60岁及以上人口数与0～14岁人口数的比值定义为老少比，那么下列地区中老少比最高的地区是：

### 选项
- A. 北京
- B. 上海　✅
- C. 重庆
- D. 广东

### 官方解析
选项中四个地区的老少比如下：A项，北京：；B项，上海：；C项，重庆：；D项，广东：，比较数字大小，明显上海的老少比接近2，是四个地区中最高的。
故正确答案为B。
