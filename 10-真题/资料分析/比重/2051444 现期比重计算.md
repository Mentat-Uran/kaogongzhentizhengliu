# 现期比重计算

考点：[[20-考点/资料分析/比重/现期比重计算|比重 / 现期比重计算]]
材料：[[15-材料/资料分析/186844 2015年国家自然科学基金委各类项目|186844 2015年国家自然科学基金委各类项目]]

**问法模型**：题干问'2015年A占B（总额）的比重约为'且材料时间即2015年 → 现期比重模型：比重=部分值÷整体值，直接一步除法。

## 推理链
1. 第1步：题干求2015年地区科学基金直接费用占各类资助项目总额的比重，时间与材料现期一致，判定为现期比重问题，无需基期回推。
2. 第2步：定位材料第三段，提取部分值——地区科学基金直接费用10.96亿元。
3. 第3步：定位材料第一段，提取整体值——各类资助项目直接费用218.8亿元（注意必须用总量作分母，分项费用之和仅约166.38亿元，不能充当整体）。
4. 第4步：代入公式比重=10.96÷218.8，分子分母均为'亿元'口径一致，无需换算。
5. 第5步：截位直除：10.96/218.8≈11/219，首位商5，即约5.0%。
6. 第6步：与选项对照，仅C选项约5%吻合，故正确答案为C。

**最快解法**：⚡ 现期比重公式法+截位直除：直接列10.96÷218.8，把分子看成219的约5%（219×5%≈11），一步锁定C，无需精算。

## 易错点
- ⚠ 分母陷阱：已列各类费用之和约166.38亿元小于总量218.8亿元，比重计算必须以材料给的总直接费用218.8亿元为分母，误用分项和会把约5%错算成约6.6%。
- ⚠ 时间口径：材料数据全为2015年现期值，题干也问2015年，不要被'比上年增加78项'诱导去算2014年基期比重。
- ⚠ 单位口径：本题分子分母同为'亿元'可直接相除；勿与'平均资助强度53.8万元/项'的万元口径混淆，本题不需要×10000换算。
