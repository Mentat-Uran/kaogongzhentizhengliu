# 基期部分量计算（基期整体反推＋占比百分点变化还原）

考点：[[20-考点/资料分析/比重/基期部分量计算（基期整体反推＋占比百分点变化还原）|比重 / 基期部分量计算（基期整体反推＋占比百分点变化还原）]]
材料：[[15-材料/资料分析/307982 2017年与2019年全球医疗器械销|307982 2017年与2019年全球医疗器械销]]

**问法模型**：题干以'若…同比提高4.6%…占比同比提高3个百分点，则2016年…销售额约为'给出假设增速与占比变化，求表中不存在的基期(2016)部分量 → 采用'基期整体=现期整体÷(1+增速)，基期占比=现期占比−提高的百分点，基期部分量=基期整体×基期占比'的链式还原模型

## 推理链
1. 第1步：表格中只有2017、2019两列，定位2017年全球医疗器械销售总额4050亿美元、IVD销售额526亿美元；2016年数据表内没有，必须用题干补充的同比条件反推
2. 第2步：基期量公式：基期量=现期量÷(1+同比增速)，2016年销售总额=4050÷1.046≈3872亿美元；现期占比=526÷4050≈12.98%≈13%
3. 第3步：'占比同比提高3个百分点'是百分点减法：2016年IVD占比=13%−3%=10%
4. 第4步：部分量=整体量×比重：2016年IVD销售额≈3872×10%≈387.2亿美元
5. 第5步：与选项对照：387.2与B项387几乎重合（与A 354差约33、C 407差约20、D 421差约34），故选B

**最快解法**：⚡ 截位直除＋百化分：4050÷1.046直除商三位≈3872；526/4050按526≈405×1.3速判为13%，减3个百分点得10%；3872×10%≈387，直接锁定B，全程无需精算

## 易错点
- ⚠ 表中只有2017/2019两列且无2016年，切勿去表中找2016或把2017年4050直接当基期读数，必须用题干'同比提高4.6%'反推
- ⚠ 百分点≠百分数：'占比提高3个百分点'应做13%−3%=10%的减法，误做成13%×(1−3%)≈12.6%会算出约488而怀疑无解
- ⚠ 基期除法方向易反：应为4050÷(1+4.6%)≈3872，误算成4050×(1+4.6%)≈4236、再乘10%≈424会误选D(421)；另IVD在表中第4行(526/588)，勿与影像395、其他631看串行

## 母题抽象
> 🧩 当题干出现'现期部分量＋整体同比增速＋占比同比提高/回落N个百分点，求基期部分量'特征时，用'基期整体=现期整体÷(1+增速)→基期占比=现期占比∓N个百分点→部分量=基期整体×基期占比'三步链式还原，验证结果与最近选项对照

**同类特征**：若…同比提高4.6%（题干假设性补充增速）、占比同比提高3个百分点（百分点口径）、则2016年…销售额约为（基期年份不在表中）、部分量（IVD）占整体（销售总额）比重、选项为百位级近似值
