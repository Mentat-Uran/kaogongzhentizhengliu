# 现期比重计算

考点：[[20-考点/资料分析/比重/现期比重计算|比重 / 现期比重计算]]
材料：[[15-材料/资料分析/186990 2015年我国粮食生产情况：粮食总产|186990 2015年我国粮食生产情况：粮食总产]]

**问法模型**：题干出现'2015年（现期）A占B的比重为'且分子分母现期值均在文字材料直接给出 → 直接用 现期比重=稻谷产量/谷物产量 一步除法

## 推理链
1. 第1步：从题干提取条件——求2015年稻谷产量占谷物产量的比重，时间为2015年即材料现期，无需基期换算
2. 第2步：从文字材料定位数据——'2015年稻谷产量20825万吨，谷物产量57225万吨'，注意分母是谷物57225而非粮食总产62144，分子是稻谷20825而非旱稻3369
3. 第3步：核对口径与单位——稻谷⊂谷物，两者单位均为万吨可直接相除；验证稻谷+小麦+玉米=20825+13019+22458=56302＜57225，确认20825是谷物的子项
4. 第4步：代入公式——比重=20825/57225
5. 第5步：截位直除——57225×36%≈20601，20825-20601=224，224/57225≈0.4%，故比重≈36.4%
6. 第6步：与选项对照，计算结果约36.4%与A选项一致，故选A

**最快解法**：⚡ 截位直除：20825/57225，分子分母各截前三位得208/572≈0.364，即约36.4%，一步出结果直选A

## 易错点
- ⚠ 分母口径陷阱：误用粮食总产量62144作分母（稻谷占粮食≠稻谷占谷物），或误把稻谷+小麦+玉米之和56302当作谷物总量57225
- ⚠ 指标混淆：'旱稻3369万吨'与'稻谷20825万吨'不是同一指标（稻谷包含早稻、中稻、双季晚稻等），分子不能取3369
- ⚠ 时间口径：题干为2015年现期比重，直接用当年值相除即可，切勿画蛇添足去基期化；另外柱状图纵轴从40000起，本题虽不涉及，但同组题比较时不可目测柱高

## 母题抽象
> 🧩 当题干出现'现期年份+某子项占某总体的比重'且材料直接给出两者现期值时，用 现期比重=子项/总体 一步直除，先核对子项确实包含于总体、单位一致再计算

**同类特征**：现期年份（2015年）直接设问、'占……的比重'句式、分子分母在文字材料中直接给出、单位统一为万吨、一步除法、无需增速、谷物类两级包含结构
