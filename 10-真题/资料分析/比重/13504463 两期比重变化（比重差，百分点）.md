# 两期比重变化（比重差，百分点）

考点：[[20-考点/资料分析/比重/两期比重变化（比重差，百分点）|比重 / 两期比重变化（比重差，百分点）]]
材料：[[15-材料/资料分析/4478128 我国A股市场新上市公司情况：图1给出|4478128 我国A股市场新上市公司情况：图1给出]]

**问法模型**：题干'2023年上半年主板首次募资金额占比与去年同期相比下降了（个百分点）'→ 两期比重作差模型：分别求现期与基期的部分占整体比重，基期比重−现期比重即为下降的百分点数

## 推理链
1. 第1步：从表1提取主板数据：2023年上半年首次募资490亿元，2022年上半年1064亿元；分母需自行求整体合计：2023H1=490+877+678+81=2126亿元，2022H1=1064+1156+871+29=3120亿元
2. 第2步：所用公式：比重=部分首次募资金额÷整体首次募资金额；所求=2022H1占比−2023H1占比（个百分点）
3. 第3步：代入计算：2023H1主板占比=490/2126≈23.0%（2126×0.23≈489），2022H1主板占比=1064/3120≈34.1%（3120×0.34≈1061）
4. 第4步：作差：34.1%−23.0%≈11.1个百分点，即占比下降约11个百分点
5. 第5步：与选项对照：11.1与C项'11个百分点'最接近，故选C

**最快解法**：⚡ 截位直除+比重作差：先加总两个分母2126与3120，再分别直除490/2126≈23%、1064/3120≈34%，差约11个百分点直接锁定C；粗判可先看趋势——分子腰斩（1064→490，降约54%）而分母仅降约1/3（3120→2126），占比必大幅下降，先排除A、B，再精算区分C（11）与D（18）

## 易错点
- ⚠ 分子口径陷阱：占比必须用首次募资金额（亿元）计算，若误用新上市公司家数（38/173≈22.0%、30/171≈17.5%）会得出占比'上升'的错误结论
- ⚠ '个百分点'陷阱：所求为两期比重直接作差（34.1%−23.0%≈11.1个百分点），不是百分比变化率（(34.1−23.0)/34.1≈32.5%），误算相对变化率将无对应选项
- ⚠ 基期口径陷阱：基期是表1中2022年上半年（3120亿元），不能误用图1中2022年全年募资5870亿元，全年值与上半年值口径不同、不能跨图表拼接

## 母题抽象
> 🧩 当题干出现'某部分占比与上年同期相比上升/下降了多少个百分点'时，用两期比重作差法：分别计算现期、基期比重后相减，分子分母须用同一指标口径（本题为募资额而非家数），结果读作百分点

**同类特征**：占比与去年同期相比、下降了、个百分点、主板、首次募资金额、两期比重
