# 资助率（批准项数÷受理申请数）比值比较

考点：[[20-考点/资料分析/比重/资助率（批准项数÷受理申请数）比值比较|比重 / 资助率（批准项数÷受理申请数）比值比较]]
材料：[[15-材料/资料分析/186506 2016年国家自然科学基金面上项目在|186506 2016年国家自然科学基金面上项目在]]

**问法模型**：题干问'资助率最高的科学部'→ 对选项各学部逐一计算批准项数÷受理申请数，截位直除后比较大小

## 推理链
1. 第1步：题干求2016年资助率最高的科学部，资助率=批准项数÷受理申请数，只用统计表'申请项目数'与'批准资助'两列，与图1、图2'教育部隶属单位'子口径无关
2. 第2步：公式：资助率=批准项数（个）÷受理申请数（个），分子取'批准项数'列，分母取'受理申请数'列
3. 第3步：代入四个选项：地球1573÷5867≈26.8%；数理1551÷5380≈28.8%；管理720÷3676≈19.6%；化学1576÷6065≈26.0%
4. 第4步：28.8%＞26.8%＞26.0%＞19.6%，数理科学部资助率最高，对照选项锁定B

**最快解法**：⚡ 截位直除：四组比值各取首两位——地球≈15.7/58.7≈26.8%、数理≈15.5/53.8≈28.8%、管理≈7.2/36.8≈19.6%、化学≈15.8/60.7≈26.0%；先排除明显最小的管理，再比数理28.8%最大，直接选B，只需算4个选项学部，不必算全部8个

## 易错点
- ⚠ 口径陷阱：资助率只能用表格全口径'批准项数÷受理申请数'，若误用图1教育部隶属单位获批项数、或拿批准项数去除金额列（如医学4102÷230090）则全错
- ⚠ 列名混淆：表中'受理申请数'与'批准项数'是两列，做比时分子分母别颠倒或看错列（资助率=批准÷受理，不是受理÷批准）
- ⚠ 行序陷阱：表格首行为医学科学部，与图1图2自上而下（数理到医学）顺序相反，取数易串行；同时本题仅涉及表格，不必跨图拼数

## 母题抽象
> 🧩 当题干出现'资助率/通过率/获批率最高（最低）'这类分子分母均直接给定的比值比较时，用截位直除算各比值首两位，先排除量级明显小的选项，再比较剩余项即可锁定答案

**同类特征**：资助率最高、科学部、批准项数与受理申请数作比、比值（比率）比较、选项仅列4个学部、单一现期年份2016

A项：；
B项：；
C项：；
D项：；
项目资助率最高的为数理科学部。
故正确答案为B。
