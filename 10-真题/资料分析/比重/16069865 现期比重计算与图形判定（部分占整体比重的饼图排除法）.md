# 现期比重计算与图形判定（部分占整体比重的饼图排除法）

考点：[[20-考点/资料分析/比重/现期比重计算与图形判定（部分占整体比重的饼图排除法）|比重 / 现期比重计算与图形判定（部分占整体比重的饼图排除法）]]
材料：[[15-材料/资料分析/4211648 2009—2025年我国民营企业外贸|4211648 2009—2025年我国民营企业外贸]]

**问法模型**：题干要求判断'传统市场、东盟、其他地区'占2025年前两个月民企进出口总额的饼图比例关系 → 单位统一后用'部分÷整体'求比重，再以'合计与50%的关系'和'两部倍数关系'两个定性判据排除选项

## 推理链
1. 第1步：从第五段提取2025年前两个月数据：对传统市场1.26万亿元=12600亿元（同比+4%）、对东盟6310.2亿元（+4.8%）、对拉美3247.9亿元（−1.3%）；从第一段提取民企进出口总额3.69万亿元=36900亿元；同比增速本题不用
2. 第2步：用比重公式'比重=部分量÷整体量'，先把'传统市场+东盟'加总：12600+6310.2=18910.2亿元（单位须统一为亿元）
3. 第3步：判据一（与50%的关系）：18910.2÷36900≈51.3%，即白色+灰色合计稍大于50%，黑色'其他地区'=(36900−18910.2)÷36900≈48.7%稍小于一半，排除C、D
4. 第4步：判据二（倍数关系）：12600÷6310.2≈2.0倍，传统市场（白色）扇形约为东盟（灰色）的2倍，排除白色不足灰色2倍的B项
5. 第5步：精算验证：传统市场12600÷36900≈34.1%、东盟6310.2÷36900≈17.1%、其他地区≈48.7%（其中拉美3247.9÷36900≈8.8%属'其他'），三部分比例关系与A图一致，故选A

**最快解法**：⚡ 定性排除法（免精算扇形）：①统一单位后12600+6310.2=18910.2，除以36900得约51.3%稍大于50%，排除C、D；②12600÷6310.2≈2倍，白色约为灰色2倍，排除B，锁定A

## 易错点
- ⚠ 单位混排陷阱：'1.26万亿元'与'6310.2亿元、3247.9亿元'并列，加总或求比重前必须统一为亿元（1.26万亿=12600亿），否则结果差一个量级
- ⚠ 分母口径陷阱：饼图占比的分母是民营企业进出口总额3.69万亿元，不是传统市场+东盟+拉美三者之和（若误用三者之和22158.1亿元作分母会得出56.9%:28.5%:14.7%的错误口径）
- ⚠ 勿陷精算：本题不必计算各扇形精确角度，抓住'白色+灰色稍大于50%'与'白色≈2×灰色'两个定性关系即可快速排除；同比增速（4%、4.8%）是干扰数据，现期比重题不用

## 母题抽象
> 🧩 当题干出现'饼图能准确反映……占比关系'的图形选项特征时，先统一单位再用'部分÷整体'，抓住'部分合计与50%的大小关系'和'两大部分间倍数关系'两个定性判据排除选项，无需逐个精算扇形占比

**同类特征**：饼图能准确反映……占比关系、白色/灰色/黑色对应三个市场、现期比重（2025年前两个月）、万亿元与亿元单位混排、定性排除而非精算、部分÷整体
