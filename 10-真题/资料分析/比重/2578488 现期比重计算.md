# 现期比重计算

考点：[[20-考点/资料分析/比重/现期比重计算|比重 / 现期比重计算]]
材料：[[15-材料/资料分析/257856 2019年全国及东部、中部、西部、东|257856 2019年全国及东部、中部、西部、东]]

**问法模型**：题干问'2019年…在…中的比重约为'且材料时间为2019年 → 直接用现期比重模型：部分值÷整体值作截位直除

## 推理链
1. 第1步：从文字材料提取条件：2019年全国房地产开发投资132194亿元，其中住宅投资97071亿元（整体与部分均为现期值，口径同为亿元）
2. 第2步：所用公式：现期比重=部分值÷整体值=住宅投资÷房地产开发投资
3. 第3步：代入计算：97071÷132194，截位为97÷132≈0.734，即约73.4%，首位商7
4. 第4步：与选项对照：结果首位商7、约73%，与A项最接近，故选A

**最快解法**：⚡ 截位直除：97071/132194≈97/132，首位商7、次位商3，约73%+，直接锁定A，无需精算

## 易错点
- ⚠ 分子分母看串行：表一'住宅'表头横跨两列（住宅投资额、住宅增速），本题取数须用住宅投资97071作分子、投资总额132194作分母，切勿把住宅增速13.9%或投资增速9.9%代入作比
- ⚠ 时间口径：题干问2019年（现期），直接现期作比即可，不要画蛇添足做基期换算（误除以1.139或1.099）
- ⚠ 选项为百分数，结果应写成百分比形式（≈73%）再对照，勿与0.73的小数形式错位比较

## 母题抽象
> 🧩 当题干出现'A年……在……中的比重约为'且A年恰为材料现期时，用'部分现期值÷整体现期值'截位直除，先看首位商即可锁定选项

**同类特征**：'2019年……在……中的比重约为'、现期比重、部分占整体、住宅投资与房地产开发投资同段取数、全国总计口径、结果为百分数选项
