# 现期比重计算（做差求隐含部分）

考点：[[20-考点/资料分析/比重/现期比重计算（做差求隐含部分）|比重 / 现期比重计算（做差求隐含部分）]]
材料：[[15-材料/资料分析/257880 全国移动互联网接入流量：2017年6|257880 全国移动互联网接入流量：2017年6]]

**问法模型**：题干问'未直接给出的部分（非手机设备流量）占整体（累计流量）的比重落在哪个区间' → 先用整体−已知部分做差求该部分，再部分÷整体算现期比重，对照区间选项

## 推理链
1. 第1步：从文字段提取两个口径：2018年上半年全国移动互联网累计流量266亿GB，其中通过手机上网的流量262亿GB
2. 第2步：题干要求'非手机设备上网流量'的比重，材料无该部分现成数据，规则为部分＝整体−其中另一部分：266−262＝4亿GB
3. 第3步：现期比重公式：比重＝部分÷整体＝4÷266
4. 第4步：截位直除：4÷266，首位商1，得约1.5%
5. 第5步：1.5%落在1%~2%区间内，对照选项锁定B

**最快解法**：⚡ 做差+截位直除：266−262＝4亿GB，4÷266首位商1即约1.5%，无需精算即可锁定1%~2%区间选B；亦可口算验证266×1.5%≈4

## 易错点
- ⚠ 方向搞反：误算手机流量比重262÷266≈98.5%后选'超过'型高区间，忽略题干问的是'非手机设备'，必须先做差266−262=4亿GB
- ⚠ 取数口径错位：266亿GB是2018年上半年累计值（文字段），勿误用图中某单月柱值（如2018年6月56.7亿GB）当整体
- ⚠ '非手机设备流量'材料中无现成数据，若按'直接找数'思路会落空，须通过'整体−其中部分'转化；同时注意两个同比增速缺失不影响本题（本题纯现期，不用增速）

## 母题抽象
> 🧩 当题干出现'A占B的比重'且A未直接给出、材料只给整体B与其中另一部分C时，先做差A＝B−C，再A÷B求现期比重，与区间选项对照即可

**同类特征**：占同期…的比重、非手机设备（隐含部分，需做差）、其中…流量（整体与部分并列给出）、现期时间口径（2018年上半年）、比重落区间型选项、仅需文字段、不依赖统计图
