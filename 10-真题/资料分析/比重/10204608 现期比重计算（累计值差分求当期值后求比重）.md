# 现期比重计算（累计值差分求当期值后求比重）

考点：[[20-考点/资料分析/比重/现期比重计算（累计值差分求当期值后求比重）|比重 / 现期比重计算（累计值差分求当期值后求比重）]]
材料：[[15-材料/资料分析/6403877 2023年1-11月J省深圳证券交易|6403877 2023年1-11月J省深圳证券交易]]

**问法模型**：题干问'某月当期成交金额占上半年（累计）的比重' → 先用'本月累计-上月累计'差分求当期值，再除以截至该月的累计值

## 推理链
1. 第1步：定位统计表，2023年5月、6月证券累计成交金额分别为240.6百亿元、289.3百亿元；表格为累计口径，故上半年总额即6月累计值289.3百亿元
2. 第2步：6月当期成交金额 = 6月累计 - 5月累计 = 289.3 - 240.6 = 48.7百亿元
3. 第3步：现期比重 = 部分除以整体 = 48.7 ÷ 289.3
4. 第4步：截位直除：48.7/289.3 ≈ 16.8%（或用区间验证：289.3×15%=43.4，289.3×20%=57.9，48.7介于两者之间）
5. 第5步：16.8%落入15%-20%区间，与B项吻合，选B

**最快解法**：⚡ 累计差分+区间排除法：289.3-240.6=48.7百亿元，分母直接取6月累计289.3；只需验证两个界值：289.3×15%≈43.4＜48.7＜289.3×20%≈57.9，故必为15%-20%，无需算出精确比重即可秒选B

## 易错点
- ⚠ 口径陷阱：表格是'累计成交金额'，若直接把6月累计值289.3当'当期值'（比重将约100%）或用当期值289.3除以上半年错误口径，必错；必须先差分得48.7
- ⚠ 分母陷阱：'上半年'总额就是6月累计值289.3百亿元（截至6月的累计），勿误用其他月份累计或把分母换成11月累计507.9
- ⚠ 单位陷阱：全材料单位为'百亿元'而非'亿元'，本题比重中单位约掉影响不大，但中间差分计算若与'亿元'口径混用易慌乱出错

## 母题抽象
> 🧩 当题干出现'某月当期值占截至该月累计值的比重'特征时，先对累计表做'本月累计-上月累计'差分求当期值，再除以本月累计值，用选项区间端点（整体×各档百分比）与分子比较即可快速锁定区间。

**同类特征**：当期成交金额、占上半年的比重、累计值需差分求当月、现期比重、区间型选项（不到/超过/百分比区间）

### 官方解析
