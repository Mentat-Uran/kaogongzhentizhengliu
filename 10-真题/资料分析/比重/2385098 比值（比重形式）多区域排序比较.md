# 比值（比重形式）多区域排序比较

考点：[[20-考点/资料分析/比重/比值（比重形式）多区域排序比较|比重 / 比值（比重形式）多区域排序比较]]
材料：[[15-材料/资料分析/239832 广东省分区域（珠三角-东翼-西翼-粤|239832 广东省分区域（珠三角-东翼-西翼-粤]]

**问法模型**：题干要求'2016年各区域A指标与B指标的比值由大到小排列' → 对四个区域分别计算 零售总额÷生产总值 的商，再按降序匹配选项

## 推理链
1. 第1步：从表1（2016年横截面）提取各区域社会消费品零售总额与地区生产总值：珠三角25048.68/67841.85，东翼3522.33/5893.19，西翼3407.67/6491.93，粤北山区2767.44/5328.69（单位均为亿元，口径一致可直接相除）
2. 第2步：比较模型：比值=零售总额÷生产总值，四个分数分子分母一一对应，先看数量级再看接近项
3. 第3步：定性筛选：珠三角25048.68÷67841.85≈0.37<0.5；东翼3522.33÷5893.19≈0.598（3522超过5893一半2946.5）；西翼3407.67÷6491.93≈0.525（超过3246）；粤北2767.44÷5328.69≈0.519（超过2664.35）
4. 第4步：西翼与粤北接近，用差分法：(3407.67-2767.44)÷(6491.93-5328.69)=640.23÷1163.24≈0.55，大于粤北的0.519，故西翼>粤北山区
5. 第5步：降序排列为东翼(0.598)>西翼(0.525)>粤北山区(0.519)>珠三角(0.369)，对照选项，与D项顺序一致

**最快解法**：⚡ 分数性质+差分法：先粗判四个比值与0.5的关系锁定珠三角最小、东翼最大；西翼与粤北接近时用差分640.23/1163.24≈0.55>0.519判定西翼>粤北，全程免精算

## 易错点
- ⚠ 排序方向陷阱：题干是'由大到小'，若按从小到大排会误选C/D之外的干扰项；且四个区域名称相似（东翼/西翼/粤北），抄错行即全错
- ⚠ 西翼(0.525)与粤北(0.519)仅差约0.006，凭感觉估'0.5多一点'可能排反，必须用差分法或截位直除到百分位确认
- ⚠ 表1中'进出口总额'单位为亿美元与亿元指标混排，本题虽不涉及，但易误取行或误以为需单位换算；同时勿错用表2时间序列数据

## 母题抽象
> 🧩 当题干出现'某年A指标与B指标的比值由大到小（或由小到大）排列'时，从对应截面表取两列现期数据逐项做商，先用'与1/2比较'定性分层，再用差分法比较接近的两项，最后匹配选项排序

**同类特征**：比值由大到小排列、两指标相除、分区域排序比较、2016年现期截面、选项为区域顺序组合
