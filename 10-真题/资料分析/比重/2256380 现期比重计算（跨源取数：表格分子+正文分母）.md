# 现期比重计算（跨源取数：表格分子+正文分母）

考点：[[20-考点/资料分析/比重/现期比重计算（跨源取数：表格分子+正文分母）|比重 / 现期比重计算（跨源取数：表格分子+正文分母）]]
材料：[[15-材料/资料分析/198982 全国一般公共预算收支执行情况：按'9|198982 全国一般公共预算收支执行情况：按'9]]

**问法模型**：题干'1-9月累计，教育支出占全国一般公共预算支出约为'且选项为百分数 → 现期比重=教育支出现期累计值÷全国一般公共预算支出现期累计值，无需推基期

## 推理链
1. 第1步：题干时间口径为'1-9月累计'，问'教育支出占全国一般公共预算支出约为'，选项为百分数，判定为现期比重问题，分子=教育支出，分母=全国一般公共预算支出总盘
2. 第2步：分子从表2取：教育支出23760亿元；分母从正文第四段取：1-9月累计全国一般公共预算支出163289亿元；表2只列'主要'项目，各项目之和小于正文总盘，分母绝不能用表2项目加总
3. 第3步：代入公式比重=23760/163289，截位直除：≈23760/163300≈23.76/163.3，首位商1、次位商4，得约14.5%
4. 第4步：与选项对照，计算值约14.5%与A项最接近，故正确答案为A

**最快解法**：⚡ 截位直除：23760/163289→分子分母各截三位'238/1633'，首位商1、次位商4（1633×0.145≈236.8），约14.5%，直接锁定最接近的A项；也可将163289百化分近似为1/6.1，23760×6.1/10≈14.5%验证

## 易错点
- ⚠ 分母掉坑：表1、表2均为'主要'项目明细，加总（教育+社保+医疗等）不等于总盘，分母必须用正文第四段的163289亿元，用表2项目加总作分母会显著偏高
- ⚠ 口径掉坑：题干是'1-9月累计'，分子分母都必须用累计值；若误用9月当月支出22616亿元或与收入累计145831亿元混搭，则完全错向
- ⚠ 正文增速均为空白：总盘累计同比增速未显示，本题是现期比重无需基期，切勿因想推基期而臆造增速；另外教育同比+6.5%是干扰信息，现期比重计算用不到

## 母题抽象
> 🧩 当题干出现'某时期，A占B约为（选项为百分数）'时，用现期比重模型：分子取表格中A的现期量，分母取正文中B的总量，警惕'主要项目之和≠总盘'，截位直除对照选项即可
