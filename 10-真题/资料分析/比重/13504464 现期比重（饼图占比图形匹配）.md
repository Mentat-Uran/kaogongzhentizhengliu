# 现期比重（饼图占比图形匹配）

考点：[[20-考点/资料分析/比重/现期比重（饼图占比图形匹配）|比重 / 现期比重（饼图占比图形匹配）]]
材料：[[15-材料/资料分析/4478128 我国A股市场新上市公司情况：图1给出|4478128 我国A股市场新上市公司情况：图1给出]]

**问法模型**：题干问'饼状图描述各板块数量占比'→先求现期比重（各板块家数÷合计家数），再用部分间比例关系（接近或倍数）排除选项匹配图形

## 推理链
1. 第1步：定位表1'新上市公司数量（家）'的2023年上半年列：主板38家、科创板41家、创业板52家、北交所42家（须用家数列，不可误取募资金额列）
2. 第2步：现期比重公式：占比=各板块家数÷合计家数；合计=38+41+52+42=173家
3. 第3步：代入计算：主板38/173≈22.0%、科创板41/173≈23.7%、创业板52/173≈30.1%、北交所42/173≈24.3%；关键关系为科创板41与北交所42几乎相等（41/42≈0.98），创业板52为最大
4. 第4步：与选项对照——A、B、C中科创板扇形均明显大于北交所2倍（即>40%对<20%），与41/42≈0.98的真实占比矛盾，排除；D项两扇形接近、创业板最大，符合，选D

**最快解法**：⚡ 比例排除法（免精算比重）：心算合计173后直接抓最敏感关系——科创板41家≈北交所42家，扫四个饼图，A/B/C中科创板扇形超北交所2倍即全排除，仅D两扇形接近，秒选D；再用创业板52家占约30%应为最大扇形做双重验证

## 易错点
- ⚠ 用错指标列：题问'公司数量占比'必须用家数列（38/41/52/42），若误用首次募资金额列（490/877/678/81亿元），北交所占比会变得极小，图形完全不同
- ⚠ 板块数值扎堆：主板38、科创板41、北交所42三者占比均在22%~24%之间，扇形大小难分辨，易把接近关系看错；唯一显著偏大的是创业板52（约30%）
- ⚠ 跳过合计直接目测：不先算合计173并折算占比，凭扇形视觉大小硬猜易落入选项干扰；另外北交所募资仅81亿元量级小，易误推其家数占比也小（实际约24%，并不小）

## 母题抽象
> 🧩 当题干出现'饼状图描述各部分占比'特征时，用'部分间倍数/接近关系排除法'：先算合计，找出数值最接近或倍数关系最极端的两个部分，验证选项图形中对应扇形大小关系是否一致，一致者当选
