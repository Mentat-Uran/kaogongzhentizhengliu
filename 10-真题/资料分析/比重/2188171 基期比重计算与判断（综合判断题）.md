# 基期比重计算与判断（综合判断题）

考点：[[20-考点/资料分析/比重/基期比重计算与判断（综合判断题）|比重 / 基期比重计算与判断（综合判断题）]]
材料：[[15-材料/资料分析/195126 2017年全国规模以上工业企业经营与|195126 2017年全国规模以上工业企业经营与]]

**问法模型**：『2016年××占该年合计数的（分数）以上』且为『说法正确』综合判断 → 先用主体覆盖范围排除以偏概全项，再对占比项用基期比重=现期比重×(1+分母增速)/(1+分子增速)与分数线比较。

## 推理链
1. 第1步：A、B项断言主体为『所有经济类型』企业，但柱状图与表格仅给出国有控股、集体、股份制、外商及港澳台商投资、私营5类『主要经济类型』，以部分数据无法验证全称命题，A、B排除。
2. 第2步：C、D中『所有经济类型合计数』取全国口径：2017年全国利润总额75187.1亿元、主营业务收入116.5万亿元=1165000亿元；表格给出2017年国有控股利润总额16651.2亿元、主营业务收入258367.4亿元；柱状图给出国有控股增速：利润45.1%、收入15.0%（全国增速由材料原式给出）。
3. 第3步：确定公式：2016年占比（基期比重）=现期比重×(1+全国增速b)/(1+国有控股增速a)。
4. 第4步：C项验证：现期利润比重16651.2/75187.1≈22.2%，因国有控股利润增速45.1%高于全国利润增速b，(1+b)/1.451<1，2016年比重较22.2%下降，按解析计算未达到选项所设分数线，C错误。
5. 第5步：D项验证：现期收入比重258367.4/1165000≈22.2%，代入全国收入增速b'与15.0%，基期比重=22.2%×(1+b')/1.15，按解析结果仍高于选项所设分数线（如五分之一），D正确。
6. 第6步：综合主体排除与基期比重计算，仅D同时通过两项验证，对照选项锁定答案D。

**最快解法**：⚡ 排除法+基期比重公式：A、B见『所有经济类型』而材料只给『主要经济类型』直接秒排；D用基期比重=A/(1+a)÷[B/(1+b)]，先截位直除258367.4/1165000≈22.2%，再乘(1+全国收入增速)/1.15，与分数线比较锁定D。

## 易错点
- ⚠ 主体偷换陷阱：A、B把『主要经济类型』（5类且口径有交叉）当成『所有经济类型』，数据覆盖不全不能对全称命题下结论。
- ⚠ 单位量级混排：收入/成本用『万亿元』、利润用『亿元』，116.5万亿元须先换算为1165000亿元再算比重，否则差5个数量级。
- ⚠ 基期/现期混淆与增速错配：问2016年占比须用基期比重公式并分别代入两组增速（分子用国有控股15.0%/45.1%，分母用全国增速），直接用2017年现期比重22.2%或增速串用均会误判；另『提高0.54个百分点』是利润率的变化量，不能当增速代入。

## 母题抽象
> 🧩 当综合判断题出现『所有××均…』或『占合计数的（分数）以上』时，先用主体覆盖范围排除『以主要/部分冒充全部』的选项，再对占比项用基期比重=现期比重×(1+分母增速)/(1+分子增速)代入验证是否越线。

**同类特征**：下列说法中正确的一项（综合判断）、2016年占该年合计数的（分数）以上（基期比重）、所有经济类型（主体范围陷阱）、均低于/均高于（全称判断）、万亿元与亿元混排、增速取自柱状图
