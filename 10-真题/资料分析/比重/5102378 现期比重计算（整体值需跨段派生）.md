# 现期比重计算（整体值需跨段派生）

考点：[[20-考点/资料分析/比重/现期比重计算（整体值需跨段派生）|比重 / 现期比重计算（整体值需跨段派生）]]
材料：[[15-材料/资料分析/323387 2020年我国软件和信息技术服务业四|323387 2020年我国软件和信息技术服务业四]]

**问法模型**：题干出现'2020年……占……的比重约为'且时间即现期 → 现期比重=部分值÷整体值，本题整体值（全行业收入）材料未直接给出，须先派生锚量再作除法。

## 推理链
1. 第1步：从材料第三段提取部分值：2020年电子商务平台技术服务收入9095亿元。
2. 第2步：全行业收入未直接给出，先派生锚量：四形态加总22758+49868+1498+7492≈81616亿元（亦可用22758÷27.9%≈81584或49868÷61.1%≈81613反推，量级一致）。
3. 第3步：代入现期比重公式：比重=部分值÷整体值=9095÷81616。
4. 第4步：截位直除：9095/81616≈9/81≈1/9≈11.1%。
5. 第5步：与选项对照：11.1%对应B项；若误用信息技术服务49868亿元作分母得9095÷49868≈18.2%，恰为D项陷阱，须排除。

**最快解法**：⚡ 锚量速加+百化分：先算全行业总量≈22758+49868+1500+7492≈81600亿元，再9095÷81600≈9÷81=1/9≈11.1%，直选B（可再用49868÷61.1%≈81600交叉验证锚量）。

## 易错点
- ⚠ 分母口径陷阱：误用电子商务平台的直接上级'信息技术服务收入49868亿元'作分母，得18.2%恰为D项；分母必须是全行业收入（约8.16万亿元）。
- ⚠ 整体值需派生：全行业总量材料未直接给出，忘记四形态加总、或只用单一形态占比反推会引入细微舍入误差，但选项量级下不影响判断。
- ⚠ 层次混淆：电子商务平台技术服务是信息技术服务的子项而非独立形态，其9095亿元仍是合法的'部分值'，可直接除以全行业总量，勿因层次关系错配分母。

## 母题抽象
> 🧩 当题干问'现期某部分占整体比重'且整体值材料未直接给出时，先用各部分加总（或已知部分÷已知占比）派生整体锚量，再以部分值÷锚量截位直除对照选项。

**同类特征**：'占全行业收入的比重约为'、现期时间（2020年）直接对应材料当期、部分值为子项收入9095亿元、整体值（全行业）未直接给出需跨段派生、四个选项差距较大，可估算截位

### 题干
2020年电子商务平台技术服务收入占全行业收入的比重约为：

### 选项
- A. 7.6%
- B. 11.1%　✅
- C. 15.3%
- D. 18.2%

### 官方解析
根据题干“2020年······占······的比重约为”，结合材料时间是2020年，可判定本题为现期比重问题。定位文字材料第二段、第三段可知：2020年，软件产品实现收入22758亿元，同比增长10.1%，占全行业比重为27.9%；电子商务平台技术服务收入9095亿元。根据公式：比重，则2020年全行业收入亿元，故题干所求，与B项最接近。
故正确答案为B。
