# 现期比重计算（部分量需跨段拼接：区域总量−已知省份）

考点：[[20-考点/资料分析/比重/现期比重计算（部分量需跨段拼接：区域总量−已知省份）|比重 / 现期比重计算（部分量需跨段拼接：区域总量−已知省份）]]
材料：[[15-材料/资料分析/5219532 2023年我国互联网企业互联网业务收|5219532 2023年我国互联网企业互联网业务收]]

**问法模型**：题干'2023年河北约占全国的'+选项为百分数 → 现期比重模型：河北收入（京津冀6777亿元−北京5721.4亿元−天津981.7亿元）÷ 全国17483亿元

## 推理链
1. 第1步：题干求2023年河北收入占全国的比重，判定为现期比重；整体量从第1段取全国互联网业务收入17483亿元
2. 第2步：河北数值材料未直接给出，需跨段拼接：第3段京津冀总量6777亿元，第4段前5名中北京5721.4亿元、天津981.7亿元，河北=京津冀−北京−天津
3. 第3步：计算部分量：河北=6777−5721.4−981.7=6777−6703.1=73.9亿元
4. 第4步：代入比重公式：73.9÷17483≈74÷17500≈0.42%
5. 第5步：与选项对照：0.42%最接近A项0.4%，B（0.7%）、C（1.2%）、D（1.9%）均偏大约1.7~4.5倍，故选A

**最快解法**：⚡ 跨段拼接+截位直除：先口算 6777−5721.4−981.7≈74（亿元），再 74/17500≈0.42%，锁定A；无需精算，量级判断即可排除B/C/D

## 易错点
- ⚠ 河北数据必须跨段拼接（京津冀−北京−天津），漏做减法或误以为材料直接给出河北就无法解题；同时注意长三角内江苏、安徽不可拆，勿仿照硬拆
- ⚠ 北京、天津同时出现在'京津冀'与'前5名'两处，拼接时勿重复计入（如只用前5名加总）或漏减某一项；且第4段广东为'下降4.6%'，虽本题不涉增速，做加总类计算时切勿当正增长处理
- ⚠ 量级陷阱：若误用京津冀6777亿元直接除全国17483亿元得约38.8%，或误用利润总额1295亿元、研发经费943.2亿元等口径当分母/分子，均远离选项；正确量级是0.4%量级

## 母题抽象
> 🧩 当题干出现'某未直接给出的地区约占整体（全国/总计）的百分之几'且该地区可由'某区域总量−区域内已知省份'拼出时，先跨段减法求部分量，再除以整体现期值，用截位直除结合量级排除选项

**同类特征**：现期（材料期=题干期，均为2023年）、'约占……的'且选项为百分数、部分主体（河北）材料未直接给出、需区域总量减已知省份跨段拼接、分母为全国总量（17483亿元）、结果为小百分比（<2%）
