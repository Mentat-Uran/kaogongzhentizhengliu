# 现期比重计算

考点：[[20-考点/资料分析/比重/现期比重计算|比重 / 现期比重计算]]
材料：[[15-材料/资料分析/238953 2013—2018年全国互联网业务收|238953 2013—2018年全国互联网业务收]]

**问法模型**：题干出现'2018年A收入占B收入的比重为'的现期特征 → 直接用现期部分值÷现期整体值一步相除

## 推理链
1. 第1步：题干问'2018年互联网企业信息服务收入占互联网业务收入的比重'，时间与材料现期一致，判定为现期比重问题；从文字定位部分值=2018年互联网企业信息服务收入8594亿元，整体值=2018年全国互联网业务收入9562亿元（与图中2018年柱值9562互为印证）
2. 第2步：现期比重公式：比重=部分÷整体=8594/9562，注意8594是9562的'其中'项，口径同层可直接相除
3. 第3步：代入计算：8594/9562，截位直除取859/956，首位商8、次位商9，结果≈0.899，即约89.9%（约90%）
4. 第4步：与选项对照，结果小于100%且接近九成，与C选项吻合，故选C

**最快解法**：⚡ 截位直除：8594/9562→分子分母各截前三位859/956，首位商8、次位商9得约89.9%，一步锁定C，无需精算

## 易错点
- ⚠ 部分—整体口径串层：信息服务收入8594是互联网业务收入9562的'其中'项，而电子商务平台3667、网络游戏1948是信息服务的下层分项，误用3667/9562或8594/3667就错了层
- ⚠ 部分与整体颠倒：误写成9562/8594，结果大于100%可直接排除，发现比值超1应立刻回查分子分母位置
- ⚠ 数据取值来源：题面文字中增速均为空格，但本题只需两个现期收入值8594与9562，均在文字中直接给出，不必也不应去图中读增速或编造分项数据

## 母题抽象
> 🧩 当题干出现'现期A占B的比重'特征时，从材料中取同层的现期部分值与整体值直接相除（部分/整体），用截位直除速算，并验证结果小于100%且与部分<整体的大小关系一致

**同类特征**：2018年（现期时间点）、占……的比重为、信息服务收入（部分值8594亿元）、互联网业务收入（整体值9562亿元）、两个现期值直接相除、比重<100%
