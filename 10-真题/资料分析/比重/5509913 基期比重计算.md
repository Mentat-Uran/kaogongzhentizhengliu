# 基期比重计算

考点：[[20-考点/资料分析/比重/基期比重计算|比重 / 基期比重计算]]
材料：[[15-材料/资料分析/340957 2021年前三季度全国6.4万家规模|340957 2021年前三季度全国6.4万家规模]]

**问法模型**：题干出现基期时间'2020年前三季度……约占……'的占比问法 → 用基期比重公式：现期比重×(1+整体增速)÷(1+部分增速)

## 推理链
1. 第1步：题干时间限定'2020年前三季度'而材料数据为2021年前三季度，判定为基期比重题；部分＝16个行业小类营业收入A=28322亿元，同比增速a=26.1%
2. 第2步：整体＝6.4万家规上文化及相关产业企业营业收入B=84205亿元，同比增速b=21.8%（注意：不能用两年平均增速10.0%/24.0%，其基期为2019年前三季度）
3. 第3步：代入基期比重公式 [A÷(1+a)]÷[B÷(1+b)] = (A/B)×(1+b)/(1+a) = (28322/84205)×(1.218/1.261)
4. 第4步：现期比重28322/84205≈33.6%；修正因子1.218/1.261≈0.966；33.6%×0.966≈32.5%
5. 第5步：与选项对照：因部分增速26.1%＞整体增速21.8%，基期比重必低于现期比重33.6%，四个选项中仅A项32%低于33.6%，且32.5%与32%吻合，故选A

**最快解法**：⚡ 现期比重＋增速关系排除法：截位直除28322/84205≈33.6%（约三分之一）；因a=26.1%＞b=21.8%，部分增长快于整体，基期比重必然小于33.6%，选项中只有32%满足，直接锁定A；精确验证：33.6%×1.218/1.261≈32.5%

## 易错点
- ⚠ 增速口径混淆：材料中24.0%与10.0%是两年平均增速（基期2019年前三季度），求2020年前三季度只能用同比增速26.1%和21.8%，误用两年平均增速是最大陷阱
- ⚠ 不做基期换算：直接用2021年前三季度数值算比重得33.6%，虽然碰巧最接近A，但方法错误；正确逻辑是a＞b时基期比重低于现期比重，32.5%恰验证了这一方向
- ⚠ 干扰信息取数：'两年平均增长高于全部企业14.0个百分点'是百分点差且属于两年平均口径，与本题无关，勿被带入计算

## 母题抽象
> 🧩 当题干出现'上年同期（基期）部分占整体比重'且材料只给现期值与同比增速时，用基期比重公式＝现期比重×(1+整体增速)÷(1+部分增速)，并用'部分增速与整体增速的大小关系'判断结果高于还是低于现期比重，快速排除选项
