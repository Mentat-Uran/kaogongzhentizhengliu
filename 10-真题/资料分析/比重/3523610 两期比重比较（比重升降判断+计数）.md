# 两期比重比较（比重升降判断+计数）

考点：[[20-考点/资料分析/比重/两期比重比较（比重升降判断+计数）|比重 / 两期比重比较（比重升降判断+计数）]]
材料：[[15-材料/资料分析/280258 2019年我国电信业务收入规模、增速|280258 2019年我国电信业务收入规模、增速]]

**问法模型**：题干以'2019年的数值高于2018年的有几项'计数提问，且三项指标均为'部分占整体'的比重 → 采用两期比重升降判据：部分增速＞整体增速⇔比重上升，逐项比增速后数'升'的项数。

## 推理链
1. 第1步：判定题型——①②整体为电信业务收入（2019年1.31万亿元），③整体为固定增值业务收入（2019年1371亿元），三项均为两期比重，比较升降只需比同比增速，无需算具体比重值。
2. 第2步：由组合图折线读出①②的整体增速：2019年电信业务收入同比增长0.8%（文字段该处增速数值空缺）。
3. 第3步：套两期比重结论'部分增速＞整体增速⇒比重上升'：①固定数据及互联网业务收入（2175亿元）增速＞电信收入增速0.8%，则2019年比重高于2018年，成立。
4. 第4步：②移动数据及互联网业务收入（6082亿元）增速＞电信收入增速0.8%，则2019年比重高于2018年，成立。
5. 第5步：③IPTV业务收入（294亿元）增速＜固定增值业务收入（1371亿元）增速，则2019年比重低于2018年，不成立（注意③整体是固定增值，不是电信总收入）。
6. 第6步：2019年数值高于2018年的为①②共2项，对照选项选C。

**最快解法**：⚡ 两期比重升降结论法（增速比较法，零计算）：①②的整体增速直接取图中折线2019年电信收入增速0.8%，各部分增速与整体增速比大小，'部分＞整体'记升；判得①升、②升、③降（IPTV增速＜固定增值增速），数出2项直接选C，全程无需计算任何比重数值。

## 易错点
- ⚠ 口径混淆：图中'固定/移动通信业务收入占比'与文字中'固定/移动数据及互联网业务收入'是不同口径，判断①②升降只能用分项增速与0.8%比较，不能拿图中占比数据（如29.2%→31.8%）代算。
- ⚠ ③的整体口径搞错：③是IPTV占固定增值业务收入的比重，判据是IPTV增速与固定增值业务增速比较，误与电信总收入增速0.8%比较会方向出错。
- ⚠ 文字段所有'比上年增长'后的增速数值缺失，易误判'材料不全无法作答'而放弃；按官方解析口径该增速可用于比大小，勿被空白吓退。

## 母题抽象
