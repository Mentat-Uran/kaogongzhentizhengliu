# 现期比重计算

考点：[[20-考点/资料分析/比重/现期比重计算|比重 / 现期比重计算]]
材料：[[15-材料/资料分析/270495 2013-2019年全球卫星产业收入|270495 2013-2019年全球卫星产业收入]]

**问法模型**：题干为'2019年A占B的比重为'且材料时间与提问时间一致 → 直接用现期比重模型：比重=现期部分值÷现期整体值

## 推理链
1. 第1步：题干问'2019年全球卫星制造业收入占卫星产业收入的比重'，材料时间即2019年，判定为现期比重问题，无需基期换算
2. 第2步：定位文字材料，部分值为2019年卫星制造业收入125亿美元，整体值为2019年全球卫星产业收入2707亿美元
3. 第3步：代入现期比重公式：比重=125÷2707
4. 第4步：截位直除：125÷2707≈125÷2700≈4.6%（精确约4.62%），且四大细分之和125+49+1230+1303=2707验证分子分母口径一致
5. 第5步：对照选项，仅D对应约4.6%，故选D

**最快解法**：⚡ 截位直除（百化分亦可）：125/2707，分母截前三位2707→2700，125÷2700≈4.6%，一步锁定D；勿用3660作分母（那是太空经济，非卫星产业）

## 易错点
- ⚠ 分母错位陷阱：易误用文字中'全球太空经济规模3660亿美元'作分母得约3.4%，但题干问'占卫星产业收入'，3660与2707是包含关系，分母只能是2707
- ⚠ 分子取错细分：文字中并列四个细分（制造业125亿、发射49亿、通信1230亿、地面设备1303亿），勿与'卫星通信服务业1230亿'或'地面设备1303亿'混淆；'较上年减少70亿美元'是绝对减少量，既非增速也不参与本题计算
- ⚠ 现期基期混淆：材料时间为2019年且问法同为2019年，直接用现期值相除即可，勿像同组第3题那样用增速倒推基期

## 母题抽象
> 🧩 当题干出现'现期年A占B的比重'且材料给出现期两个数值时，直接套'比重=部分÷整体'截位直除；关键是按题干措辞锁定分母层级（包含关系中的哪一层整体）

**同类特征**：现期年份提问（2019年）、占……的比重、部分与整体均来自文字段现期值、单一除法、分母为产业总收入口径

### 官方解析
根据题干“2019年······占······的比重为”，结合材料时间为2019年，可判定本题为现期比重问题。定位文字材料可知，2019年，全球卫星产业收入为2707亿美元。在全球卫星产业收入中，卫星制造业的收入为125亿美元。根据公式：比重，则2019年全球卫星制造业收入占卫星产业收入的比重。
