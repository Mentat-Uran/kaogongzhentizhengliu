# 现期比重计算+饼图扇区匹配

考点：[[20-考点/资料分析/比重/现期比重计算+饼图扇区匹配|比重 / 现期比重计算+饼图扇区匹配]]
材料：[[15-材料/资料分析/185156 中国新能源汽车产业五类技术（整车制造|185156 中国新能源汽车产业五类技术（整车制造]]

**问法模型**：'能够正确描述2015年五种专利申请数占比的统计图' → 现期比重模型：各类申请数÷五类总和得占比，再按饼图扇区起始位置与大小顺序逐一匹配排除

## 推理链
1. 第1步：从表中2015年行提取五类数据：整车制造769、电动机制造303、储能装置制造848、零部件配件制造377、供能装置制造315（单位：件）
2. 第2步：现期比重模型：某类占比=该类申请数÷五类总和，先求总和=769+303+848+377+315=2612件
3. 第3步：代入计算：储能装置制造848÷2612≈32.5%（最大，略超1/3），整车制造769÷2612≈29.4%（次大，略小于30%），两项合计约62%；电动机制造303÷2612≈11.6%、供能装置制造315÷2612≈12.1%、零部件配件制造377÷2612≈14.4%，三个小项占比近似相等
4. 第4步：与选项对照：A、D项最大扇区占比明显达不到约32.5%（且小项不相等），排除A、D；按饼图从12点顺时针首项为整车制造，其扇区应约为29.4%，C项该扇区比例不匹配，排除C；B项最大扇区约32.5%、次大约29.4%、三个小扇区大小接近，完全吻合，故选B

**最快解法**：⚡ 饼图特征排除法（比重估算）：求总和2612后只抓两个特征——①最大项848/2612≈32.5%略超三分之一，②最小三项303/377/315占比近似相等（各约12%）；B项同时满足，A、D最大占比不符直接排除，再用首扇区整车制造769≈29.4%（顺时针起点）验证排除C，无需精算全部五个占比

## 易错点
- ⚠ 五类名称相近（储能装置制造vs供能装置制造、整车制造vs零部件配件制造），抄2015年行数据易串列，尤其储能848与供能315差距大，错位即全盘皆错
- ⚠ 忽视饼图从12点位置顺时针依次排列的读图规则，只看'最大扇区'不核对首项整车制造≈29.4%的顺序对应关系，可能在B与图形相近选项间误判
- ⚠ 求总和须五项全部相加（2612件），漏加一项会使所有占比整体偏移；且表中为当期申请量，不需要也不能用其他年份数据参与计算

## 母题抽象
> 🧩 当题干出现'正确描述某年各部分占比的统计图/饼图'时，先求各部分总和，再算最大项占比与小项相对大小，用'最大项占比+首扇区顺序+小项是否相等'三个特征与图形比对快速排除

**同类特征**：正确描述…占比的统计图、饼图扇区匹配、现期比重计算、五类合计求总和、12点位置顺时针排列、最大项/最小项占比特征

### 官方解析
方法一：题干所求为“2015年新能源汽车产业五种专利申请数的占比”，故可判定本题为现期比重计算问题。2015年新能源汽车专利总数件。五种专利中申请数最多的为848，，A、D两项最大占比均不满足，排除A、D。同时最小三种专利申请数303、377、315，所占比重近似相等，只有B项满足。
         方法二：题干所求为“2015年新能源汽车产业五种专利申请数的占比”，故可判定本题为现期比重计算问题。2015年新能源汽车专利总数件。饼形图从12点位置开始顺时针依次排列，第一项整车制造为769，，比稍大一些。A项接近，C项约为，D项不到，均不满足，排除A、C、D。
故正确答案为B。
