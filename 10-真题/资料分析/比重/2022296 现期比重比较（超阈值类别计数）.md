# 现期比重比较（超阈值类别计数）

考点：[[20-考点/资料分析/比重/现期比重比较（超阈值类别计数）|比重 / 现期比重比较（超阈值类别计数）]]
材料：[[15-材料/资料分析/184896 2015年城镇居民人均消费支出（当年|184896 2015年城镇居民人均消费支出（当年]]

**问法模型**：题干问'八类消费中占人均消费支出比重超过（10%）的有几个' → 用总量×10%定出阈值金额，将各类支出与阈值比大小后计数，把比重比较转化为分量比较

## 推理链
1. 第1步：定位表格第一行，2015年第一季度城镇居民人均消费支出为5534元（Q1行累计值即当季值，无需差分）；八类支出依次为：食品烟酒1827、衣着568、居住1159、生活用品及服务319、交通通信717、教育文化娱乐452、医疗保健338、其他用品和服务154
2. 第2步：比重超过10% ⇔ 该类支出 > 总支出×10% = 5534×10% = 553.4元，先算阈值再比较，避免逐类做8次除法
3. 第3步：逐一与553.4元比较：1827、568、1159、717四项大于553.4；319、452、338、154四项小于553.4
4. 第4步：满足条件的是食品烟酒、居住、交通通信、衣着共4类，与选项D（4个）对应，故正确答案为D

**最快解法**：⚡ 基准量法（总量×10%定阈值）：5534×10%=553.4元，八类数值扫一遍，大于553.4的有1827、568、1159、717共4个，直接选D，全程不需计算任何一个比重

## 易错点
- ⚠ 临界值陷阱：衣着568元仅比阈值553.4元高约15元（实际比重约10.3%），极易误判为'未超过'而错选C（3个）
- ⚠ 时间口径干扰：全表为'当年累计'，但Q1行累计值即当季值无需差分；若误用上半年累计10401元作分母或对Q1行强行差分则全错
- ⚠ 题干阈值缺失：题干'超过'后的数字显示不完整，须按官方解析锁定10%口径；若自行假设12.5%等其他阈值，只有食品烟酒、居住、交通通信3类入围，会错选C

### 题干
2015年第一季度，八类消费中占城镇居民人均消费支出比重超过的有：

### 选项
- A. 1个
- B. 2个
- C. 3个
- D. 4个　✅

### 官方解析
定位表格，2015年第一季度城镇居民人均支出为5534元，其为553.4元，则仅需在表格八类消费中找出支出超过553.4元的即可。观察可得，食品烟酒、衣着、居住及交通通信四项满足。
故正确答案为D。
