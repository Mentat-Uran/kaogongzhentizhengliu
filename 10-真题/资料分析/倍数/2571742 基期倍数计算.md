# 基期倍数计算

考点：[[20-考点/资料分析/倍数/基期倍数计算|倍数 / 基期倍数计算]]
材料：[[15-材料/资料分析/257532 2017年全国及J省海洋经济发展情况|257532 2017年全国及J省海洋经济发展情况]]

**问法模型**：题干'2016年……约为……的'+选项全为倍数，设问时间前移一年→基期倍数模型：[A÷(1+分子增速)]÷[B÷(1+分母增速)]=(A/B)×(1+分母增速)/(1+分子增速)

## 推理链
1. 第1步：定位材料第五段，提取2017年现期值与方向——海水养殖产量93.1万吨、同比增长（记增速a>0），海洋捕捞产量53万吨、同比下降（记下降率d>0），两者单位同为万吨可直接相除
2. 第2步：判定模型为基期倍数，列式：2016年养殖÷2016年捕捞=[93.1÷(1+a)]÷[53÷(1−d)]=(93.1÷53)×(1−d)/(1+a)
3. 第3步：先算现期倍数锚点：93.1÷53≈1.76（截位直除）
4. 第4步：定性判断偏移方向：养殖正增长→基期分子93.1÷(1+a)<93.1；捕捞下降→基期分母53÷(1−d)>53，故基期倍数必然<1.76，排除D(1.8倍)
5. 第5步：再定下界：两项增速均为个位数量级，(1−d)/(1+a)接近1，基期倍数仍明显大于1（约1.5~1.7区间），排除A(0.6倍)、B(0.8倍)
6. 第6步：与选项对照，唯一落在区间内的是C(1.6倍)，与官方答案一致

**最快解法**：⚡ 现期倍数定界+增速方向排除法：先截位直除93.1÷53≈1.76得2017年倍数上界；利用'分子正增长、分母负增长'两符号相反推出基期倍数必小于1.76排除D，又因增速为个位数常规幅度基期倍数远大于1排除A、B，直接锁定C，全程无需知道具体百分数

## 易错点
- ⚠ 增速符号方向代错：养殖是'增长'须用93.1÷(1+a)回推，捕捞是'下降'必须用53÷(1−d)回推；若把下降也当增长处理（53÷(1+d)），基期倍数会被抬高至≈1.8附近误选D，这是本组材料标注的最典型基期陷阱
- ⚠ 现期倍数当基期倍数：93.1÷53≈1.76只是2017年值，看到接近1.8就顺手选D，正落入命题用1.6/1.8双近邻设的坑
- ⚠ 材料文本中所有同比百分数留空（需回读原图核对，不得凭空补数）；且本材料单位混杂（万吨/万载重吨/亿吨），本题两项同为'万吨'可直接相除，勿被其他段单位干扰

## 母题抽象
> 🧩 当题干出现'上年/基期 A约为B的多少倍'且材料只给两个现期值与'一增长一下降'的方向性增速时，用基期倍数公式(A/B)×(1+分母增速)/(1+分子增速)：先算现期倍数定上界，再按分子分母增速方向判断基期倍数偏移方向并结合增速量级排除选项

**同类特征**：设问时间2016年早于材料主时间2017年（基期设问）、问法'……约为……的'+选项全为倍数、两个现期量93.1万吨、53万吨同单位可直接相除、分子增速为增长、分母增速为下降，两符号方向相反、具体百分数在文字材料中空缺，需回读原图、对应模型为基期倍数=(A/B)×(1+分母增速)/(1+分子增速)

### 题干
2016年J省海水养殖产量约为海洋捕捞产量的：

### 选项
- A. 0.6倍
- B. 0.8倍
- C. 1.6倍　✅
- D. 1.8倍

### 官方解析
根据题干“2016年······约为······的”，且选项为倍数，结合材料时间2017年，可判定本题为基期倍数问题。定位文字材料第五段，“2017年，J省实现海水养殖产量93.1万吨，同比增长；海洋捕捞产量53万吨，同比下降”，则2016年J省海水养殖产量约为海洋捕捞产量的倍。
故正确答案为C。
