# 现期倍数计算（结合中位数定位）

考点：[[20-考点/资料分析/倍数/现期倍数计算（结合中位数定位）|倍数 / 现期倍数计算（结合中位数定位）]]
材料：[[15-材料/资料分析/340960 2021年全国城市供水情况：供水总量|340960 2021年全国城市供水情况：供水总量]]

**问法模型**：题干问'图2中最高的省份是用水量中位数省份的约多少倍' → 现期倍数模型：最高值÷中位数值（15个数据为奇数个，中位数取升序第8位），结果与选项对照取最接近

## 推理链
1. 第1步：定位图2，提取15个省（区、市）人均日生活用水量：北京163、山西138、辽宁155、吉林125、天津123、浙江212、安徽190、福建231、河南141、广东251、海南315、贵州172、西藏256、陕西161、宁夏168（单位：升）
2. 第2步：确认最高值为海南315升；15个数据的中位数需先升序排序：123、125、138、141、155、161、163、168、172、190、212、231、251、256、315，奇数个取第8个，即宁夏168升
3. 第3步：代入现期倍数公式：倍数=315÷168=1.875
4. 第4步：与选项对照，1.875与B项1.88最接近（A.1.78、C.1.95、D.2.03均偏离更远），故选B

**最快解法**：⚡ 截位直除+中位数快速定位：最高值海南315升；15个数据升序后第8位为宁夏168升；315÷168，商1.8余12.6，即1.875≈1.88，直选B（亦可用168×1.88≈315.8验证吻合）

## 易错点
- ⚠ 中位数错位：15个数据必须先排序再取第8个（宁夏168升），若误取排序后第9个贵州172升（315/172≈1.83）或直接把横轴图上排在中间位置的省份当'中位数'，就会算偏甚至误选A
- ⚠ 图2横轴排列顺序≠数值大小顺序：海南虽大致处于图的中间位置但它是最高值315升，'图中间'与'中位数'完全是两回事
- ⚠ 口径混淆：中位数必须在图2的15个省份截面数据内定位，不能拿图1全国均值185.03升或文字段'供水总量/普及率'等指标掺入计算

## 母题抽象
> 🧩 当题干出现'最高（最大）的…是（中位数/第k位）…的约多少倍'特征时，先对给出的奇数个数据升序排序、定位第(n+1)/2个值作分母，再用最高值作分子直接相除求现期倍数，最后与选项对照取最接近项

### 选项

- B. 1.88倍　✅

### 官方解析
<p>根据题干“图2中······是······”，结合选项求倍数，可判定本题为现期倍数问题。定位图2可知，城市人均日生活用水量最高的省份是海南，用水量为315升；城市人均日生活用水量中位数省份，即排名第8的省份为宁夏，用水量为168升。故城市人均日生活用水量最高的省份是用水量中位数省份的倍数为<img flag="tex" src="../../../90-图片/公式图/formula-d7695fcebfe7263b.png" />倍，与B项最接近。</p><p>故正确答案为B。</p>
