# 基期倍数

考点：[[20-考点/资料分析/倍数/基期倍数|倍数 / 基期倍数]]
材料：[[15-材料/资料分析/6251905 2023年1-7月中国光伏产品（整体|6251905 2023年1-7月中国光伏产品（整体]]

**问法模型**：题干问上一年的'2022年1-7月组件出口量是电池片的几倍'而材料只给2023年1-7月现期值与同比增速 → 用基期倍数模型：各自除以(1+增速)反推基期，再相除求倍数

## 推理链
1. 第1步：题干时间为2022年1-7月（基期），材料时间为2023年1-7月（现期），且材料不给任何基期值，判定为基期倍数问题
2. 第2步：锁定'出口量(GW)'口径提取数据：组件出口量A=123GW、同比+30.4%；电池片出口量B=22.65GW、同比+80.86%（不能用261.2亿、27.26亿美元）
3. 第3步：套用基期倍数公式 [A/(1+a)]÷[B/(1+b)]=(A/B)×(1+b)/(1+a)=（123/1.304）÷（22.65/1.8086）
4. 第4步：代入计算：分子123×1.8086≈222.46，分母22.65×1.304≈29.54，倍数≈222.46/29.54≈7.53
5. 第5步：与选项对照，7.53与D项7.52最接近，且电池片增速(80.86%)大于组件增速(30.4%)，基期倍数应明显大于现期倍数5.43，方向验证一致，故选D

**最快解法**：⚡ 基期倍数公式法+截位直除：先口算现期倍数123÷22.65≈5.43，再乘增速修正因子(1+80.86%)/(1+30.4%)≈1.808/1.304≈1.39，得5.43×1.39≈7.5，锁定D；或直接交叉相乘123×1.8086÷(22.65×1.304)≈222/29.5≈7.5，一步截位直除

## 易错点
- ⚠ 口径陷阱：题干问'出口量(GW)'，若误用出口额（组件261.2亿、电池片27.26亿美元）相除得约9.58，误选C
- ⚠ 基期陷阱：忘记除以(1+增速)，直接用现期值相除123/22.65≈5.43，误选A
- ⚠ 公式方向陷阱：增速修正因子(1+b)/(1+a)写反成(1+a)/(1+b)，得5.43×(1.304/1.809)≈3.91，误选B

## 母题抽象
> 🧩 当题干出现'基期时间A是B的几倍'且材料只给现期值+同比增速时，用基期倍数公式(A/B)×(1+b)/(1+a)（B的增速放分子），并先核对A、B口径一致（量对量、额对额）再代入

**同类特征**：问基期（上年同期2022年1-7月）、材料时间同为1-7月但年份不同、只给现期值和同比增速、明确问'出口量'而非'出口额'、两个主体相除求几倍
