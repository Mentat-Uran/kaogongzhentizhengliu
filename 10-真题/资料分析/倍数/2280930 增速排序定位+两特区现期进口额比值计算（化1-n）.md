# 增速排序定位+两特区现期进口额比值计算（化1-n）

考点：[[20-考点/资料分析/倍数/增速排序定位+两特区现期进口额比值计算（化1-n）|倍数 / 增速排序定位+两特区现期进口额比值计算（化1:n）]]
材料：[[15-材料/资料分析/210315 2018年1～2月我国厦门、深圳、珠|210315 2018年1～2月我国厦门、深圳、珠]]

**问法模型**：题干问'出口同比增速最快的两个特区，同期进口额之比' → 先按1～2月出口同比排序列取前二，再取两特区1～2月累计进口额做A:B比值并化为1:n与选项对照

## 推理链
1. 第1步：从表格'出口同比（1～2月）'列提取五特区增速：厦门20.3%、深圳20.6%、珠海34.9%、汕头11.6%、海南-53.4%（含负增长）
2. 第2步：排序比较：34.9%＞20.6%＞20.3%＞11.6%＞-53.4%，增速最快的两个特区为珠海（34.9%）和深圳（20.6%），深圳20.6%仅比厦门20.3%高0.3个百分点，需精细比较
3. 第3步：从'进口（亿元）1～2月'累计列取对应值：珠海186.3亿元、深圳2064.7亿元，比值=186.3:2064.7
4. 第4步：截位估算186.3÷2064.7≈186÷2065≈9.0%，约等于1/11（因11×186.3=2049.3≈2064.7），对照选项得1:11，选C

**最快解法**：⚡ 排序锁前二后用截位直除/反向倍数验证：186.3÷2064.7≈186÷2065≈9%≈1/11，直接锁定C；亦可用'11×186.3≈2049与2064.7接近'快速验证，无需精算

## 易错点
- ⚠ 增速排序取错第二名：深圳20.6%与厦门20.3%仅差0.3个百分点，误取厦门则算186.3:424.0≈1:2.3，直接掉坑
- ⚠ 取错列口径：'同期进口额'须用1～2月累计进口（186.3、2064.7），误用2月当月值（67.5、931.1）得约1:13.8，会错选D（1:17方向）
- ⚠ 比值分子分母顺序：应按'珠海:深圳'≈1:11，若倒写为深圳:珠海≈11:1则与1:n形式选项不符；另注意海南出口同比-53.4%为负，排序勿漏号

## 母题抽象
> 🧩 当题干出现'增速最快（最高）的两个主体……之比'特征时，先对增长率列精确排序锁定前二（警惕近似增速），再取对应现期累计值做截位直除化成1:n，与选项对照即可

**同类特征**：增速最快的两个经济特区、同期进口额之比、1～2月累计口径取数、排序+比值两步计算、选项为1:n形式

### 题干
2018年1～2月出口额同比增速最快的两个经济特区，同期进口额之比约为：

### 选项
- A. 1:4
- B. 1:7
- C. 1:11　✅
- D. 1:17

### 官方解析
根据题干“2018年1～2月······之比”，结合材料给出2018年1～2月的数值，可判定本题为比值计算问题。定位表格材料可知，2018年1～2月出口额同比增速最快的两个经济特区为珠海经济特区和深圳经济特区，它们同期进口额分别为186.3亿元和2064.7亿元，两者之比约为。
故正确答案为C。
