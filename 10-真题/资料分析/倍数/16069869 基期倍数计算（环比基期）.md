# 基期倍数计算（环比基期）

考点：[[20-考点/资料分析/倍数/基期倍数计算（环比基期）|倍数 / 基期倍数计算（环比基期）]]
材料：[[15-材料/资料分析/4454713 2025年全年及12月我国新能源汽车|4454713 2025年全年及12月我国新能源汽车]]

**问法模型**：题干问'2025年11月（上月）A约是B的多少倍'而材料只给12月现期值和环比增速 → 基期倍数模型：现期倍数×(1+b)/(1+a)

## 推理链
1. 第1步：定位第二段，12月动力电池出口量A=19GWh（环比减少10.4%，即a=-10.4%），储能电池出口量B=13.6GWh（环比增长23.9%，即b=+23.9%）；题干求11月即环比基期
2. 第2步：基期倍数公式=(A/B)×(1+b)/(1+a)
3. 第3步：代入计算：(19/13.6)×(1.239/0.896)≈1.40×1.38≈1.93
4. 第4步：与选项对照，1.93与C项1.9最接近，故选C

**最快解法**：⚡ 截位直除+分式近似：先算现期倍数19/13.6≈1.4；再算修正因子(1+23.9%)/(1-10.4%)≈1.24/0.896≈1.24/0.9≈1.38；相乘1.4×1.38≈1.93，直接锁定1.9（C）

## 易错点
- ⚠ 环比与同比混淆：求11月须用环比增速（-10.4%、+23.9%），误用同比增速（+47.1%、+52.2%）则完全算错
- ⚠ 负增长处理：'环比减少10.4%'即a=-10.4%，公式中1+a=0.896；若误当作+10.4%代入1.104，会得约1.57误选B
- ⚠ 增速交叉方向搞反：基期倍数是分子乘(1+b)、分母乘(1+a)，若交叉写反成(1+a)/(1+b)≈1/1.38，结果约1.0，无对应选项

## 母题抽象
> 🧩 当题干出现'上月/基期A约是B的多少倍'而材料只给现期值和增速时，用基期倍数公式=(A/B)×(1+b)/(1+a)：现期倍数直除，再用'分子加其增速、分母减其降幅'的修正因子放大，注意'减少'记负、环比同比勿混

**同类特征**：时间指向'2025年11月'（上月=环比基期，材料现期为12月）、'约是……的多少倍'倍数问法、材料只给现期值+环比增速，未给上月绝对值、涉及两个主体：动力电池出口量与储能电池出口量、选项为1.3~2.2的小数倍数、材料中'环比减少'的负增长表述是代入符号的关键提示

### 题干
2025年11月，我国动力电池出口量约是储能电池出口量的多少倍？

### 选项
- A. 1.3
- B. 1.6
- C. 1.9　✅
- D. 2.2

### 官方解析
根据题干“2025年11月······约是······的多少倍”，结合材料时间为2025年12月，可判定本题为基期倍数问题。定位文字材料第二段可得：2025年12月，我国动力电池出口量19GWh（A），环比减少10.4%（a）；储能电池出口量13.6GWh（B），环比增长23.9%（b）。根据公式：基期倍数，则所求为，与C项最接近。
故正确答案为C。
