# 现期倍数比较（超过n倍的有几年）

考点：[[20-考点/资料分析/倍数/现期倍数比较（超过n倍的有几年）|倍数 / 现期倍数比较（超过n倍的有几年）]]
材料：[[15-材料/资料分析/195136 2013—2017年年末我国固定互联|195136 2013—2017年年末我国固定互联]]

**问法模型**：题干问'…超过…三倍的有几年'→现期倍数判定模型，逐年判断 移动÷固定>3，等价变形为 移动>3×固定 后比大小

## 推理链
1. 第1步：从柱状图提取两系列年末数据：移动宽带2013—2017年为40161、58254、70611、94075、113152万户；固定宽带为18891、20048、25947、29721、34854万户
2. 第2步：'超过三倍'即 移动/固定>3，为避开除法将不等式变形为 移动>3×固定，逐年代入
3. 第3步：2013年3×18891=56673>40161不满足；2014年3×20048=60144>58254不满足；2015年3×25947=77841>70611不满足；2016年3×29721=89163<94075满足；2017年3×34854=104562<113152满足
4. 第4步：满足'移动>3×固定'的仅有2016、2017两年，对照选项B（2），故正确答案为B

**最快解法**：⚡ 乘法变形避除法：把'移动是固定的三倍以上'改写为 固定×3 与 移动 直接比大小，心算各年固定宽带×3（56673、60144、77841、89163、104562）与移动宽带逐年对位比较，只有2016、2017年移动反超；其中2014年（60144 vs 58254）差距仅约1900为临界年需精算，其余年份倍数离3较远可目测

## 易错点
- ⚠ '超过三倍'的口径：本题官方判定为 移动/固定>3（即移动超过固定的三倍），切勿误解为'比固定多三倍'（即>4倍），后者会导致0年而无对应选项
- ⚠ 2014年是临界年：58254与3×20048=60144很接近，易凭黑柱明显高出白柱的直观感觉误判为超过三倍，实际不到三倍，必须精算
- ⚠ 不能只用移动宽带自身逐年数据判断（如只看移动是否翻倍或增量），必须两系列交叉比较，逐年代入全部5年，不能漏年
