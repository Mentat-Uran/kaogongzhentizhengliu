# 现期与基期倍数计算（增长量还原基期：现期÷(现期−增长量)）

考点：[[20-考点/资料分析/倍数/现期与基期倍数计算（增长量还原基期：现期÷(现期−增长量)）|倍数 / 现期与基期倍数计算（增长量还原基期：现期÷(现期−增长量)）]]
材料：[[15-材料/资料分析/340966 我国2018-2022年电信业务收入|340966 我国2018-2022年电信业务收入]]

**问法模型**：题干'2022年…约为2018年的多少倍'→ 用现期量除以基期量，基期量=现期量−增长量（增长量由'较2018年增长超2800亿元'直接给出），一条除法即可锁定选项。

## 推理链
1. 第1步：由文字材料提取：2022年电信业务收入1.58万亿元=15800亿元（'累计'为2022年当年全年口径），较2018年增长超2800亿元。
2. 第2步：倍数模型：2022÷2018 = 现期量/(现期量−增长量)；由'超2800亿'结合图1中2019-2022年增速（0.5%、3.9%、8.1%、8.0%）量级，可判定增长量在2800~2900亿元之间。
3. 第3步：基期量=15800−2800≈13000亿元（上限）至15800−2900=12900亿元（下限）。
4. 第4步：代入计算：15800/13000≈1.215，15800/12900≈1.224，两界均约为1.2倍。
5. 第5步：交叉验证：用图1增速链乘（2019-2022年）1.005×1.039×1.081×1.08≈1.219，同样得约1.22倍，与增量法一致。
6. 第6步：与选项对照：A=1.1、B=1.2、C=1.3、D=1.4，唯一落在1.2附近的为B。

**最快解法**：⚡ 考场思维（官方提示）：分母13000与12900非常接近，直接近似用1.58÷1.3≈1.215，首位商1.2，秒选B；即'截位直除+增长量还原基期'一步到位，无需逐图找数。

## 易错点
- ⚠ '较2018年增长超2800亿元'是增长量而非2018年收入本身，若误把2018年当2800亿元会得出约5.6倍的荒谬结果。
- ⚠ 单位量级陷阱：文字混用万亿与亿，1.58万亿元=15800亿元，直接拿1.58与2800运算会错10000倍。
- ⚠ '累计完成1.58万亿元'是2022年当年全年口径，不是2018-2022五年累计，切勿与图2五年数据求和比较。
- ⚠ 用图1倒推时注意：2018年的2.9%是2018年相对2017年的增速，2018→2022链乘只能用2019-2022年四个增速（1.005×1.039×1.081×1.08≈1.219），多乘2.9%会错算成约1.25倍而误选C。

## 母题抽象
> 🧩 当题干出现'A年约为B年的几倍'且材料给出'较B年增长超X亿元'时，直接用 倍数=现期/(现期−增长量) 一步估算；若材料未给增长量，可用各年同比增速链乘（注意首年增速属于更早基期）还原倍数。

**同类特征**：现期与基期倍数、约为……的（ ）倍、较2018年增长超2800亿元、万亿/亿单位混用需换算、选项间距0.1、首两位估算即可、增速图可作链乘交叉验证

### 题干
2022年我国电信业务收入约为2018年的（    ）倍。

### 选项
- A. 1.1
- B. 1.2　✅
- C. 1.3
- D. 1.4

### 官方解析
根据题干“2022年······为2018年的（    ）倍”，可判定本题为现期倍数问题。定位文字材料第一段可得：2022年，我国电信业务收入累计完成1.58万亿元，较2018年增长超2800亿元。可知，2022年电信业务收入较2018年的增长量在2800~2900亿元之间。根据公式：基期量=现期量-增长量，则题干所求在倍与倍之间，保留小数点后一位，约为1.2倍。
故正确答案为B。
考场思维：由于分母1.3和1.29很接近，1.58除以这两个数的商应差别很小，考场上可直接近似用1.58÷1.3得出答案。
