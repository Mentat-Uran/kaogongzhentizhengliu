# 考公脑库 · Obsidian 端

把 2016–2026 年国考 / 省考 / 联考行测真题，按「考点」重新组织成的一张知识网络：
**每题一篇深度标注**（推理链 → 最快解法 → 易错点 → 母题抽象），真题 ↔ 考点 ↔ 材料三层双向链接，可直接用 Obsidian 打开浏览。

当前收录 **资料分析** 与 **判断推理** 两个模块。

## 快速开始

1. 本页右上角绿色 **`Code`** → **`Download ZIP`**（压缩包 200MB 出头，解压后约 290MB，含 21,831 张配图）
2. 解压到任意文件夹（建议路径不含 emoji 等特殊符号）
3. 打开 Obsidian → **「打开文件夹作为仓库」** → 选中解压出来的文件夹

> 首次打开需建立索引，2 万余篇笔记约 1–2 分钟。若用 `git clone`，直接克隆进 Obsidian 的仓库目录即可（配图随仓库一起下来，**全程离线可看**）。

## 怎么用

**入口**：`20-考点/00-总览.md` → 模块 → 大类 → 考点。日常复习从考点出发，横向对比不同省份对同一考点的不同考法；做题错了，回到对应考点看「核心立场」。

**关系图谱**：全库 2 万+ 节点，直接开全局图谱会卡。仓库已预置默认筛选「增长」大类（打开即秒开），切换范围只需改图谱左上筛选框，例如：

```
path:"10-真题/资料分析/比重" OR path:"20-考点/资料分析/比重"
```

更顺手的是**局部图谱**：打开任意笔记 → 右上角更多菜单 →「局部图谱」，只加载邻接节点，永远秒开。

**检索**：标签是嵌套的（如 `资料分析/增长`、`判断推理/图形推理`），左侧标签面板可按树展开，或搜 `tag:#判断推理/图形推理`；按地区年份找题用 frontmatter 字段，如 `"浙江" AND tag:#真题 AND "2023"`。

完整说明见仓库内的 `00-使用说明.md`。

## 已知限制

- **配图已随仓库本地化**（`90-图片/`，21,831 张，约 207MB），无需联网即可看图。图片版权归原题库平台所有，详见 [LICENSE](LICENSE)。
- **不含刷题 App**：本仓库只是笔记 vault。配套刷题 App 与数据管线在另一个私有项目中，未包含在内。
- 原始解析由程序批量生成 + 人工抽检，可能存在错漏。针对原疑点清单、关联质量冲突及全量选项扫描共 1,597 道题，已逐题补充独立复核结论、解析、相关考点与证据：1,584 道单答案、12 道按完整集合判分；146 道同时明确区分原题与修订版，原题答案状态单独保留。仍有 1 道在当前证据下无法可靠核定，已列为人工复核并留空、不计分。查看 `30-疑点复核/疑点清单.md`、`31-复核记录/复核记录.jsonl`。
