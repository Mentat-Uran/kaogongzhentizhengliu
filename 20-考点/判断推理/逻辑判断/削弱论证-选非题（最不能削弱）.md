# 逻辑判断 / 削弱论证-选非题（最不能削弱）

> 3 题 · 3 个地区 · 2024–2025年

## 核心立场（母题抽象）
- 🧩 当题干出现'最不能质疑/最不能削弱'特征时，先提炼论点方向，再逐项判断各选项结论方向：与论点反向者为削弱项须排除，与论点同向（加强）或无关者即为答案
- 🧩 当题干出现'最不能削弱/最不能支持'的选非问法且论据与论点话题不一致（实验条件≠目标环境）时，用拆桥、削弱论据、削弱论点三条路径逐项排除削弱项，剩下的加强项或无关项即为正确答案
- 🧩 当题干出现『统计数据+专家据此认为……紧密联系/相关』且问『最不能削弱』时，先给论点定性为相关性判断，再逐项标注削弱/加强方向——凡『控制其他变量后证明相关性存在』的选项为加强项，即选非题答案
