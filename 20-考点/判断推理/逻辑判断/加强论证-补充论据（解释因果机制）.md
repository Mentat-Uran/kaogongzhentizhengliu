# 逻辑判断 / 加强论证-补充论据（解释因果机制）

> 18 题 · 11 个地区 · 2018–2026年

## 核心立场（母题抽象）
- 🧩 当加强题中论点与论据话题一致（同讲'某习性→某结果'）时，优先选能解释因果机制、回答'为什么会这样'的选项；只重复题干事实、变换主体（寄主vs寄生者）或引入无关概念（适应力）的选项一律排除
- 🧩 当加强题论点为“A导致B”且题干已给出A、B同时出现的事实时，优先选能补充“A→B”中间因果环节、解释机制的选项；凡只描述伴随现象、后果成本或话题偏移的选项排除，凡“有效率变化/影响散热”但未落到B上的选项视为不明确项。
- 🧩 当题干只有论点、无论据，且论点内含因果机制（'A越多→B越强'）时，用'补充论据/解释机制'法加强：优先选能补全因果链条中间环节（A→中间变量→B）的选项；与论点前提矛盾的是削弱项，话题偏移到其他变量的是无关项
- 🧩 当题干只有论点'A是B的原因'而无论据时，最强加强是补一条解释'A如何导致B'的完整因果链选项；警惕只给个例数据、只证相关未证变化的'半截子'选项
- 🧩 当加强型题干中论据是论点的具体表现（话题一致）时，正确答案通常是'补充论据/解释原因'——补充论据中现象转化为论点结果的中介机制；凡更换加强主体、只谈问题不谈因果、只讲原理不搭桥的选项一律排除
- 🧩 当题干论点为‘某行为具有某具体益处（如抗菌）’且配机制链时，最能支持的选项必须是解释该益处如何实现的机制补充（顺着题干已有环节搭桥）；凡只陈述该行为的其他好处或否认副作用的选项均因话题不一致而排除
- 🧩 当题干出现'只有论点无论据+最能支持'特征时，用补充论据法，验证选项是否解释论点因果机制并严格对应论点关键词限定（如本题'心理'而非'身体'）
- 🧩 当加强题论点呈‘正是某现象的出现导致某结果（数量增加）’的因果推测时，优先选补充因果机制、解释‘现象如何促成结果’的选项；仅描述现象自身属性（厚度/位置/背景条件）而不涉及结果的选项均为无关项
- 🧩 当题干出现“因此，有专家指出/担忧”结构且论点论据话题一致时，用“补充论据/解释因果机制”法找加强项，与论点核心关键词不一致的选项（举例、追责、其他应用）一律排除
- 🧩 当题干只有论点且含“X是导致Y的重要原因”式因果断言时，最强支持项应在X与Y之间补充完整因果机制链；凡把因果方向颠倒（Y→X）或另立其他原因（Z→Y）者一律排除。
- 🧩 当题干由『调查发现某因素与某结果相关』得出『该因素影响结果』的因果结论时，最能支持的选项是揭示因果机制（通过什么途径如何影响）的补充论据，且必须与论点核心关键词（本题『饮食状况』）话题一致。
- 🧩 当题干问『最能支持/加强』且论点论据话题一致时，优先选补充论据、具体解释因果机制（如何造成伤害/如何起作用）的选项；凡伤害对象偏移、只谈措施效果、只谈污染物存在但未涉及受害对象的选项一律排除
- 🧩 当论点为“X可以治疗/导致Y”，而论据仅为相关性统计或动物实验时，最能支持的选项通常是“解释X起作用的具体机制（补充论据）”；凡出现“实验时间短/安全性未知”“动物实验不等于人体有效”“数据与题干方向相反”的选项均为削弱，直接排除。
- 🧩 当题干只有论点、没有论据（常见于『最新研究指出…』句式）且问『最能加强』时，用『机制搭桥法』，选能解释因果如何发生的选项，排除看似沾边但缺关键桥梁的不明确项和无关项
- 🧩 当题干出现“实验组+对照组得出因果性结论，且问‘最能加强’”时，先用论点关键词排除削弱项（副作用、切断联系）与无关项（群体类比），再锁定解释因果机制或补充正面证据的选项。
- 🧩 当题干给出一组'变量A与结果B'的相关性数据且论据论点话题一致时，加强题优先选补充因果机制（解释A为何导致B）的选项，同时用话题一致性排除无关项、用概念是否对应排除不明确项
- 🧩 当论点为『A是B的重要原因』且论据给出A与B共变的数据时，最能支持的选项是能解释A如何导致B的机制性补充论据；凡时间、对象、话题与论点不一致的选项一律排除。
- 🧩 当题干出现'对比实验/跟踪研究得出X导致Y'且问'最能支持'时，优先选能补充因果机制、说明X如何作用于Y成因的选项；对比对象错位、话题不一致（好处对错领域）、机制不明的选项均排除
