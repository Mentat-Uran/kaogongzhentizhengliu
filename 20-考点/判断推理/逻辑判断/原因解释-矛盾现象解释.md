# 逻辑判断 / 原因解释-矛盾现象解释

> 3 题 · 3 个地区 · 2019–2022年

## 核心立场（母题抽象）
- 🧩 当题干出现'某事物受宣传/有关注/有优势，但实际市场表现或效果不理想'的矛盾时，用矛盾解释法，验证选项能否同时覆盖两端，优先从供给端变化（竞争者涌入、产量激增）或需求端分流找他因
- 🧩 当题干出现'主体一贯坚持某理念/做法，今年却出现反常变化（如来源骤减、标准骤降）'的特征时，用'找矛盾点→选能同时消解全部反常点的选项'方法，验证选项是否覆盖矛盾各方且不与前提理念冲突；只能解释一半矛盾的选项是典型干扰项
- 🧩 当题干出现『原理/专家认为应该X』与『调查显示绝大部分人没做X』的矛盾时，用『找矛盾+验主体范围』模型：优先选择说明『X的前提已改变/已无需X』且覆盖全部现象主体的普遍性新信息，排除只涉及部分主体（有些、很多、个别）或程度界限不明的选项
