# 定义判断 / 单定义-要件对照（选非题）

> 32 题 · 17 个地区 · 2016–2025年

## 核心立场（母题抽象）
- 🧩 当定义描述'结构关系'（把A夹在B/C中间）类特征时，先拆出结构要件，再给选项每句话贴成分标签验证结构与主旨，结构不符或主旨错位者即为选非题答案
- 🧩 当单定义题干包含『主体/对象身份+行为状态+结果损害』多重要件且问『不属于』时，先抓身份关系类硬性要件（如『亲人』『雇员』）快速排除，再用状态与结果要件逐项核验
- 🧩 当定义含'因习惯→产生惰性/不愿改变'的因果结构且为选非题时，逐项核查行为动机：由'习惯'驱动的不选，由其他动机（满意、利益、好奇）驱动且行为方向相反的即为答案
- 🧩 当定义由'已有某物+目的+方式（添置其他物品）'构成且问'不属于'时，用要件对照法逐项验证，重点辨析'添置其他物品'与'重复购买同类物品'的区别
- 🧩 当单定义包含'主体特征+匹配关系'双要件且问'不涉及/不符合'时，先拆要件为关键词，再用关键词逐项扫描，缺任一要件（如学历成就≠性格气质）的选项即答案
- 🧩 当定义题干包含'主体＋活动性质＋范围'多重要件且问'错误的是'时，先圈出定义中的限定性关键词（如'经济'），再逐项提取选项核心行为与要件比对，凡超出限定词范围的选项即为答案
- 🧩 当定义判断出现'不属于/不符合该定义的是'的选非问法时，先从题干定义提取核心要件（主体+行为+对象），再用要件标尺逐项排除，剩余唯一缺要件项即答案
- 🧩 当定义包含'手段（方式）+目的'双重要件且问'不属于'时，优先验证选项是否缺失目的要件——仅有行为但不产生题干所述效果的选项即为答案
- 🧩 当题干给出含'对象要件（污染载体）+方向要件（由X至Y）'的单一定义并要求选'不属于'时，逐项核对两个核心要件，缺'污染载体'或'转移方向'任一项即为答案
- 🧩 当定义中出现'不需要/无需+某种方式'的否定式要件且题目为选非题时，直接在选项中寻找出现该方式（如读取物理卡片）的描述，即可秒锁答案
- 🧩 当题干为'下列没有运用/不符合某定义的是'时，先把定义拆成'手段要件+效果要件'，再逐项检查哪个选项缺失手段要件（如本题缺'与具体形象载体联系'），缺失者即答案
- 🧩 当定义中出现'履行利益以外的损害''给付标的以外的财产损害'等限定语时，解题核心是判断损害对象是否超出给付标的本身：仅标的物自身受损=瑕疵给付，波及人身或标的以外财产=加害给付
- 🧩 当定义中出现'一系列过程'式的环节列举（如招聘/培训/使用/考核/激励/调整）且问'不属于'时，用环节枚举对照法：能归入列举环节或服务于定义目的的选项全部排除，无法归入的即为答案
- 🧩 当定义以'……是指以……为消费单位，为满足……共同需要……'句式给出且问'不属于'时，提取'消费单位+受益对象+是否共同'三要件，重点辨析受益对象是'按共同需要划定的群体'还是'被选出的个体'，后者即为答案
- 🧩 当题干给出含'授权来源+行为名义+权限范围+后果归属'四要件的定义并要求选'不属于'时，逐项核对四要件，凡'冒用他人名义行事+后果由自己承担'的选项即为答案
- 🧩 当题干给出'微小初始变化→长期巨大连锁反应'型定义且问'不宜/不属于'时，用要件对照法逐项验证'微小起点'与'放大结果'两个要件是否齐备，警惕破窗效应、多米诺效应等近义效应的干扰项
- 🧩 当定义含'既不A也不B'的双重排除要件且问'不属于'时，直接扫描选项中命中A或B（此处为就业/深造）的信号词即可秒杀，不必逐项验证列举行为
- 🧩 当定义强调'实际支出/支付货币额'时，选非题优先找只有'价值、估值'而无'支付、花费动作'的选项；有真实货币流转的项均可排除
- 🧩 当定义题干以'手段+结果+过程'要件式给出概念、问法为'不属于'时，用要件对照法，优先排除只出现相关对象或现象、而缺少核心动作要件的选项
- 🧩 当定义包含'由于长期大量使用药物→病原体产生抗性→原药效降低'的因果链且为选非题时，优先排查'无药物使用环节'或'抗性来源主体错位（天然/自身性状）'的选项
- 🧩 当定义含'主体（关联方）+手段（交易）+结果（利益转移/灌输）+性质（违背某原则）'多重要件且问'没有反映/不符合'时，用要件对照排除法，锁定具备合理对价、公平交易特征的选项即为答案
- 🧩 当单定义题干出现‘由某类主体以某种方式处理某事’且问‘不属于’时，先锁定定义中‘主体+渠道/方式’两大最易对立的要件，优先排查选项中主体被替换（如法院替乡贤）或渠道被替换（司法替民间）的选项
- 🧩 当题干给出『一种感官刺激引起另一种完全不同感觉』类定义且问『不属于』时，逐项核对是否存在真实的『感觉A→感觉B』转换过程；含『好像/仿佛/像』等比喻修辞的选项因无真实感觉过程而不符合定义，往往即为目标答案
- 🧩 当定义判断出现'不属于/不符合'的选非问法时，先把定义压缩为一个核心要件（如'对立概念被巧妙联系'），再逐项验证'是否具备该要件'，注意含反义词不等于满足要件
- 🧩 当定义给出'A状态→结果甲、B状态→结果乙'的双向映射时，选非题优先找映射方向相反或状态错配的选项（如'未完成却被忘记'）
- 🧩 当定义判断出现'不属于/不符合'问法时，先把定义拆成目的、方式、结果等核心要件，再用硬性要件（尤其是形式要件）逐项排除，缺任一关键要件者即为答案
- 🧩 当定义题为效应类比喻定义且为选非问法时，先提炼‘机制要件’（如不同环境→结果不同），再将选项中的古语/典故逐句还原含义，凡缺少任一核心要件（单一环境、变化方向相反、主体错位）的即为答案
- 🧩 当定义题干给出'手段（A影响B）+结果（B获得改变）'双要件，且问'没有构成该定义的是'时，逐项核对两要件是否同时具备，缺失任一要件或仅存在单向行为无知识传递的选项即为答案
- 🧩 当定义题干呈现『对象+危害+健康影响』多重要件且问『不属于』时，先圈出定义的评估对象（评估谁），再核对各选项行为指向的对象是否落入该范围，对象越界者即为答案。
- 🧩 当定义题干出现'自我……使行为与……相一致'的双重要件且问'未体现'时，优先排查主体错位（他人认知代替自我）与行为和要件相悖的选项
- 🧩 当单定义题干出现'采用…手段/改变…条件/创造…环境'等多要件结构且设问为'不属于'时，用要件对照排除法，优先锁定完全缺失核心要件（如无人工干预）的选项
- 🧩 当选非型定义判断的定义中出现'扩展到其他行业/与现有业务毫无关系'这类行业边界要件时，先给每个选项的新旧业务标注行业归属，新旧业务同行业的选项即为不符合定义的答案
