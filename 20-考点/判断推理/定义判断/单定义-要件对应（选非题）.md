# 定义判断 / 单定义-要件对应（选非题）

> 25 题 · 16 个地区 · 2016–2025年

## 核心立场（母题抽象）
- 🧩 当定义强调'对某实体对象进行改造/添建'且为选非题时，优先锁定未作用于实体、仅停留在数据收集/信息管理/调研规划层面的选项，通常即答案
- 🧩 当定义以“通过……（手段），达到……（目的）”结构呈现、且问“没有运用/不属于该定义”时，先提取核心手段动词与目的要件，再逐项比对行为实质，唯一缺失手段（或目的）的选项即答案
- 🧩 当定义判断出现'未体现/不属于该定义'的选非问法时，先把定义提炼成一条'动作链'，逐项核对是否完整具备该链条，缺失核心动作（如本题缺'水蒸发'）的选项即为答案
- 🧩 当定义描述‘条件（温差悬殊）+机制（形成隔热层/悬浮保护）’且问‘不属于应用’时，逐项检查是否利用了该机制；与机制目的相反（如利用冷却降温）的选项即为答案
- 🧩 当定义判断出现'没有体现/不符合该定义'的选非问法时，先拆出定义的触发条件与心理行为结果两大要件，逐项找关键词核对，凡要件缺失或动机被偷换（如把'因稀缺而想要'换成'因缺钱而购买'）的选项即答案
- 🧩 当定义由'限定条件（时机/态势/前提）+主体+行为方式'三要件构成且问'不属于'时，优先核对限定条件，条件明显不满足或主体身份不明的选项即为答案
- 🧩 当定义以'手段（供给侧）+针对对象（结构性问题）'双要件列举式给出且设问为'不属于'时，将选项逐一归入要件清单，凡行为目的是营销宣传、需求刺激等供给端之外者即为答案
- 🧩 当定义判断为选非题且定义含『主体+行为方式』结构时，优先审查『行为发出者是否为定义规定的主体』（谁释放/谁施加），主体错位者即非该定义
- 🧩 当题干给出物理现象类定义且问'不属于'时，先提取定义中带方向性/条件性的核心要件（如'从高到低'），再逐项比对流动方向等要件，方向相反者即为答案
- 🧩 当定义判断为选非题且选项含'必将/一定/只有…才'等绝对化表述时，将选项与定义要件逐句比对，凡程度超出定义原文（如把'不利后果'升级为'必败'）的选项即为答案
- 🧩 当定义包含“主体＋方式＋对象＋结果”多要件且问“不属于”时，抓定义中最独特的要件（如本题“申请—批复”关系）作手术刀，逐项切分，凡对象或结果错位者即为答案
- 🧩 当定义判断问'没有使用/不属于某定义'时，先拆出定义核心要件，优先用最能区分项间差异的要件（如本题'逐层递进'）排除符合项，并列、平行、循环结构而无程度递进的选项即为答案
- 🧩 当定义描述『利用某类活动中的空余时间提供付费服务』时，锁定『场景+空余时间+付费服务』三要素；选非题中，凡是当事人专程前往消费、不存在等待/空余状态的选项即为不属于。
- 🧩 当定义呈现'手段+目的'结构（通过吸引注意力→培养潜在群体→获取未来利益）且为选非题时，用'手段定性法'逐项归类：借名人/热点/媒体引流者符合定义，改善产品或服务本身者不符合
- 🧩 当定义限定'某种物质使另一物质特性减弱'时，先核查双方主体是否都属于定义限定的物质类别，再看效果是'减弱'还是'产生'；选非题中无味载体或产生新感觉的选项通常是答案
- 🧩 当定义题干出现'外界条件改变时，知觉/认知结果仍保持不变'的结构，且问'未体现'时，用双要件核对法逐项验证'条件变+结果不变'，两要件缺一即为答案
- 🧩 当题干给出'XX效应=条件A+结果B'的双要件定义且问'不属于'时，用要件双检法：缺A（刺激强度/频次/时长不够）或缺B（无负面心理结果）的选项即为答案，尤其警惕'有重复但无反应'的干扰项
- 🧩 当定义中出现『委托给+特定主体』类要件时，先用受托主体身份（组织/机构/个人）做排除速筛，再验证其余要件；遇选非题先圈出『不属于』再逐项比对
- 🧩 当单定义选非题出现'以下不属于'问法时，先提取定义中最直观的排他性要件（如'只能在网络空间使用'），用该要件逐一扫描选项的使用场景，锁定在现实空间/有实物形态的选项
- 🧩 当定义含明确核心对象词（如'固体废物'）且问'无关/不属于'时，用核心关键词横向扫四项：命中关键词且行为对应要件的排除，仅描述相邻领域（如生态、绿化、旅游）而无关键词落点的即为答案。
- 🧩 当题干出现'根据定义，下列不属于/不符合的是'且定义含明确行为要件（如签订协议、采取某种方式）时，用要件对照排除法：先锁定核心行为要件，逐项勾选命中者，唯一缺要件者即答案
- 🧩 当定义给出『条件X（如光照/暗期时长）→结果（如开花）』的因果要件且为选非题时，直接比对各选项的自变量：与要件变量无关（如温度、水分）的选项即为答案
- 🧩 当定义呈现'依赖对象+行为优先级+中断反应'要件且问'最不可能/不属于'时，用要件比对法，验证各选项与核心要件是否有对应、依赖对象是否与定义一致
- 🧩 当定义描述的是'两主体间关系'（互补、竞争、依存等）时，先核验选项是否真的存在两个独立主体，再验证关系性质；选非题中'主体数量不符'往往是命题人设置答案的高频位置
- 🧩 当定义描述'观察某对象→获取信息→内化→行为反映'的完整链条且问'不涉及/不符合'时，逐项核对要件，完全缺失核心要件（如无观察对象、无信息获取）的选项即为答案
