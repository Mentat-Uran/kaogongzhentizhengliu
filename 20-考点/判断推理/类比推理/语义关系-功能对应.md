# 类比推理 / 语义关系-功能对应

> 3 题 · 3 个地区 · 2018–2019年

## 核心立场（母题抽象）
- 🧩 当题干两词构成'载体/工具：功能'特征（名词+动词、可造句'X用来Y'）时，用造句法锁定功能对应关系，再逐项排除并列、内容、场所等其他对应类型
- 🧩 当题干两词可造句'A可以用来B'（A为事物、B为其功能）时，判定功能对应，验证选项是否同为'事物＋功能'结构，并用'使人/导致'（因果）、'为了'（目的）句式排除干扰项
- 🧩 当题干出现'名词：动词'且动词是名词核心功能的特征时，用功能对应法逐项验证'第二词是否第一词的功能'，警惕使用条件（如租金）、属性优点（如便利）、使用效果（如传播）三类近似干扰项
