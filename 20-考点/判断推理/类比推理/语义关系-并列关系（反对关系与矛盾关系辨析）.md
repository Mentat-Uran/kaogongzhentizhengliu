# 类比推理 / 语义关系-并列关系（反对关系与矛盾关系辨析）

> 3 题 · 3 个地区 · 2016–2017年

## 核心立场（母题抽象）
- 🧩 当题干出现'两个并列名词'时，先用造句确认是否同属一类，再用'找第三者'法细分：同属且存在第三种可能→反对关系（如货币、文体）；非此即彼无第三种→矛盾关系（如阴/阳、生/死）；度量维度或类别不同→全异但非并列，直接排除
- 🧩 当题干两词同属一个大类但大类中还存在其他成员（如两门学科、两种蔬菜）时，先锁定'并列-反对关系'，再用'同一事物=全同、部分重叠=交叉、非此即彼=矛盾、此外还有=反对'四级标签逐一排除选项。
- 🧩 当题干两词同属一类且看似对立时，先检验'除这二者外是否还有第三种同类事物'：有→反对关系，无→矛盾关系，再用同一标准逐项验证选项
