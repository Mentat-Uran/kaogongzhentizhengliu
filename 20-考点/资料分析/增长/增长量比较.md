# 增长 / 增长量比较

> 25 题 · 16 个地区 · 2014–2026年

## 核心立场（母题抽象）
- 🧩 当题干出现'按…同比增量从多到少排序'且数据为逐年存量柱状图时，用相邻年份两两作差法（现期−基期）求各年增量，重点精确比较差值最接近的两项，再对照选项验证排序
- 🧩 当题干出现'增长量最多/最大'且各选项增长率接近、现期量差距明显（约2倍以上）时，直接选现期量最大者，必要时用'增长量=现期×r/(1+r)<现期×r'做上界验证
- 🧩 当题干出现'增加最多/增长最多/增量最大的年份'特征时，用'现期-基期'逐年做差法，仅对选项涉及的年份计算差值并直接比较（整数数据可心算，或用增长率×基期量定性辅助判断）
- 🧩 当题干出现'按同比增量从高到低排序/增量最大(小)的是'特征时，用增量=现期×r/(1+r)模型：先看'现期大且增速也大'的双重占优直接定序，率与基数反向者用百化分r≈1/n代入现期/(n+1)速算比较
- 🧩 当题干出现'现期+同比增量最多/最大'特征时，先用'大大则大'排除现期与增速双小的选项，再对剩余选项用百化分r≈1/n代入增量≈现期/(n+1)精算比大小
- 🧩 当题干出现'与上年相比……变化最大/增长最多'且材料只给现期量与同比增速时，用增长量=现期×r/(1+r)比较，先用'现期×r'粗排，仅当各项接近时再补1/(1+r)修正。
- 🧩 当题干出现'同比增量最多/最大'特征时，用增量=现期×r/(1+r)（'增长N倍'按r=N、分母1+N处理），先精算唯一可算项作锚定基准，再用'现期大且增速大则增量必大'定性锁定答案，避免逐项硬算
- 🧩 当题干出现'某时段内同比增量最大（小）的年份'特征时，直接用柱状图/文字相邻年份现期量−基期量逐个相减（末期增量常可由文字'比上年增长X'直接取得），比较大小对照选项，全程无需除法
- 🧩 当题干出现'同比增量最大/最小'且选项现期量与增速交叉错位时，先用'大大则大'排除现期与增速同小的项，再对'一大一小'项用现期×r/(1+r)（或百化分r≈1/n则增量≈现期/(n+1)）精算比大小
- 🧩 当题干出现'某指标逐年与前一年相比增长最多/增量最大'时，定位逐年当期值用'现期−基期'作差比较，并警惕与'增长最快（增长率）'混淆
- 🧩 当题干出现'同比增量最高/最多的××是'且给出多主体'现期值+同比增速'时，用增长量比较法：先按现期规模排除明显小者，再按'现期相近比增速、现期偏大需增速不太低'定性锁定，必要时用增量=现期×r/(1+r)粗算验证，无需精确计算。
- 🧩 当题干出现'同比增长（增）量最多/最高'且材料只给现期值与增速时，用'现期×r/(1+r)'比较：先比乘积'现期×r'，乘积明显最大者直接锁定；仅当乘积接近时再除以(1+r)精修，避免逐项做完整除法
- 🧩 当题干出现'××量同比增长最大/增长最多'且选项现期量与增速同给时，先剔除负增长项，再用'增长量=现期×r/(1+r)'（百化分速算或量级上限速判）比较，重点排除'高增速小基数'干扰项
- 🧩 当题干出现'以下……中，××同比增长最多的是'这类多主体并列的增长量比较特征时，先统一量级取现期量，用'大大则大'口诀快速淘汰（现期量大且增速大者增长量必大），仅当现期量与增速大小交叉时再套增长量=现期×r/(1+r)精算验证。
- 🧩 当题干出现'同比增量最多/最大'且选项给出现期值与增速时，用 增量=现期×r/(1+r)（百化分：r≈1/n则增量≈现期/(n+1)）逐一估算比较，重点排查'现期很大但增速很小'的干扰项。
- 🧩 当题干出现'某期与某期相比，增加值/增长量最大（小）的主体是'时，用'现期-基期'逐项作差比较；速判技巧：若某主体现期值最大且基期值最小，其增长量必最大，可免逐项计算直接锁定，再用一组作差验证
- 🧩 当题干出现'与上年相比，增加最多的是'且材料按'现期值+同比增速'给出多个指标时，用增长量比较口诀：现期量与增长率同大者增量必大，一大一小则比较现期量×增长率，无需逐项精算现期-基期
- 🧩 当题干出现'某指标同比增加最多的年份是'且材料为逐年期末存量表时，用相邻两年相减求各年增量后直接横向比大小，警惕'现期值最大≠增量最大'且增量可能为负
- 🧩 当题干出现'增长量最大（最小）的年份'时，直接对相邻两期数据做差比较（只需算差额最接近的2-3段），并牢记'增长量看柱差、增速看比值'，勿以柱高或折线走势代替做差
- 🧩 当题干出现'同比增加最多/最多的是'且表格同时给出两年数值时，逐项'现期−基期'心算增量比大小即可，警惕'现期值最大的选项≠增量最大'的干扰项
- 🧩 当题干出现'现期年增量最大/最小的是'并给出各主体现期值与增速时，先用'现期大且r大则增量大'定性排除，再对增速与现期大小交叉的剩余项用增长量=现期×r/(1+r)（百化分r≈1/n，增量≈现期/(n+1)）定量比较
- 🧩 当题干出现'同比增量最多/最大'且选项给出现期量与增速的组合时，先剔除负增长项，再用'大大则大'口诀锁定现期与增速均最大者直接得答案；若无一项两指标同时占优，再百化分套现期×r/(1+r)估算比较
- 🧩 当题干出现'某区间内…增加最多/减少最多的年份'且表格逐年数据齐全时，用逐项作差法（现期−上年）口算各年增量，直接比较大小，无需套复杂公式
- 🧩 当题干出现'某几个年份……同比增量最大（多）的年份'特征时，锁定对应指标逐年作差（首年需多取前一年作基期），若差值接近则精确计算，切勿用增速或目测图形替代
- 🧩 当题干出现'某期间……增长量最多/最大'且材料为分组时间序列柱状图时，对选项区间逐一用'本组值−相邻前一组值'作差，直接比较差值大小（不除基期、不算率），注意大数减法的截位精度
