# 比重 / 现期比重计算

> 26 题 · 14 个地区 · 2015–2026年

## 核心立场（母题抽象）
- 🧩 当题干出现'某时点，A约占B的（百分数）'且A、B为同一现期时点的部分与整体时，直接用现期比重=A/B截位直除；若给出另一部分及其占比，可用1-另一部分占比交叉验证
- 🧩 当题干出现'A占B（总）的比重'且材料直接给出部分与总体的现期数值时，用 部分÷总体 截位直除，首位不够则补第二位，与选项比对即得答案
- 🧩 当题干出现'A占B的比重约为'且A、B为同期现期数据时，用比重=部分÷整体，以'整体×整数百分比与部分比大小+截位直除'快速估算并对照选项
- 🧩 当题干出现'现期年份+某子项占某总体的比重'且材料直接给出两者现期值时，用 现期比重=子项/总体 一步直除，先核对子项确实包含于总体、单位一致再计算
- 🧩 当题干出现'现期年份+某部分占某总体的比重'且材料同段直接给出部分量与总量时，直接用部分÷总量做截位直除即可，无视增速、拉动、贡献率等干扰数据，并核对分母是否为题干所指的总体
- 🧩 当题干出现'现期时间+某部分占整体的比例（比重）约为'，且文字/图表直接给出部分值与整体值时，用现期比重=部分÷整体，截位直除后对照选项即可，全程不涉及增速与基期换算
- 🧩 当题干出现'现期某部分占现期总体的比重'且题干时间=材料主时间时，直接用部分值÷整体值并截位直除对照选项，不引入增速、不换基期、不重算总体口径
- 🧩 当题干出现'A年……在……中的比重约为'且A年恰为材料现期时，用'部分现期值÷整体现期值'截位直除，先看首位商即可锁定选项
- 🧩 当题干出现『A（部分）占B（整体）的比重/约占』且时间与材料一致时，用 现期比重=部分÷整体，以『其中』字锁定分子，再截位直除，验证结果落在0%—100%区间
- 🧩 当题干出现'现期年A占B的比重'且材料给出现期两个数值时，直接套'比重=部分÷整体'截位直除；关键是按题干措辞锁定分母层级（包含关系中的哪一层整体）
- 🧩 当题干出现'某年+某部分占某整体的比重约为'且年份与材料一致时，用同一段落同口径的现期部分÷现期整体，截位直除估算；若材料对同一名称存在存量/流量两套数据，先依据题干限定词（如'新登记''实有'）确认口径再取数
- 🧩 当题干出现'某年A占B（总额）的比重约为'且年份与材料现期一致时，直接用比重=部分值÷整体值，同单位截位直除看首位，验证选项量级与首位数字即可秒杀。
- 🧩 当题干出现'某现期年份A占B的比重'特征时，先确认A⊂B的层级关系找准部分与整体，再用部分÷整体截位直除首两位，与选项量级一致者即为答案
- 🧩 当题干出现'某期A占B的比重/占比'且时间为材料现期时，用'现期比重=部分÷整体'，先用成数档位与整体相乘（整体×40%、×50%）夹逼部分量快速锁定区间选项，再视需要精算
- 🧩 当题干出现'某年A占B的比重/约占'且表格直接给出同口径的部分与整体现期值时，用现期比重=部分÷整体，截位直除对照选项即可，无需复杂变形
- 🧩 当题干出现'A占/约占B的比重'且材料时间与题干时间一致时，直接从文字段取'部分A÷整体B'截位直除，再警惕选项中混入其他口径占比(如图表占比)作为干扰项
- 🧩 当题干出现'某部分约占整体多少（约占了）'特征时，用'比重=部分量÷整体量'一步除法，验证分子分母取自同一段落、同一统计指标（同为竣工项目个数）后再直除
- 🧩 当题干出现'某期A占B的比重'且时间为材料现期时，直接用部分现期量÷总量现期量；先核对当月/累计口径与层级归属，再用截位直除对照选项
- 🧩 当题干出现'某年A占B的比重'且A、B均为同一现期时点/期间的值时，直接用现期比重=部分/整体一步直除，不必倒推基期；只需警惕分子为流量、分母为存量的混搭口径。
- 🧩 当题干出现'现期A占B的比重'特征时，从材料中取同层的现期部分值与整体值直接相除（部分/整体），用截位直除速算，并验证结果小于100%且与部分<整体的大小关系一致
- 🧩 当题干出现'现期…中，A的某指标所占份额/比重约为多少'时，在统计表中定位A所在行的该指标绝对额作分子、总计行同一指标绝对额作分母，现期比重=部分÷总体，截位直除对照选项
- 🧩 当题干出现'某期A中B所占比重约为多少'且时间与材料现期一致时，直接定位B（部分量）与A（整体量），用B÷A截位直除得比重，再对照选项量级与百分数形式；若时间问过去期间才需基期修正
- 🧩 当题干出现'材料当年某部分占某总体的比重约为'特征时，直接在同一统计表同口径分块内取部分量与总量作商，用截位直除估首位商即可锁定选项，无需动用增速
- 🧩 当题干出现'现期年份+A中B的比重约为'且与材料时间一致时，用现期比重=部分÷整体，截位直除后对照选项验证
- 🧩 当题干出现'现期年份+A占B的百分比'且材料以'整体…其中部分…'句式给出两个绝对量时，直接用部分÷整体做截位直除，无需增速参与，同时警惕材料中数值相近的另一组金额做分母干扰
- 🧩 当题干出现'现期年份+A占B的比例约为'且材料同段直接给出部分量与总量时，用比重=部分/总量，截位直除首两位商即可锁定选项
