# 比重 / 基期比重计算

> 28 题 · 18 个地区 · 2016–2025年

## 核心立场（母题抽象）
- 🧩 当题干出现'过去时期+某部分占总体比重'特征时，用基期比重公式：现期部分/(1+部分增速)÷[现期总体/(1+总体增速)]，先用'部分增速vs总体增速'的相对大小定方向排除，再截位直除验证数值。
- 🧩 当题干出现'某年（早于材料现期）……占……的比重'且材料给出现期部分量、总量及增速时，用基期比重公式：现期部分/(1+部分增速)÷[现期总量/(1+总量增速)]=现期比重×(1+总量增速)/(1+部分增速)，并可用图中基期柱值反向验证
- 🧩 当题干出现'基期年份+A占B的比重'且材料只给现期值与增减量时，先分别倒推基期（A₀=A现期+减少量、B₀=B现期+减少量），再做除法对照选项，并可勾稽各部分基期之和=整体基期以验算
- 🧩 当题干出现'上年同期/基期年份+A占B的比重约为'特征时，用基期比重公式=A/B×(1+gB)/(1+gA)：先截位直除现期比重A/B，再按部分增速gA与总体增速gB的大小定偏移方向（部分增速<总体增速→基期比重略大于现期；反之略小），在选项中找'略大/略小'邻域值验证即可。
- 🧩 当题干出现‘上一年（基期）某部分占整体的比重约为’时，用‘基期比重=现期比重×(1+r整体)/(1+r部分)’：先直除得现期比重，再比较部分与整体增速的相对大小定‘略大/略小’方向，直接锁定相应选项
- 🧩 当题干出现'上年同期（基期）A占B的比重'且表格给出A、B的现期值与各自同比增速时，先算现期比重A/B，再用(1+b)/(1+a)修正，且可按'a＞b→基期比重小于现期比重'的方向定性验证选项
- 🧩 当题干出现'上年（基期）A占B的比重/百分比'且给出两量现期值与各自同比增速时，用基期比重公式 A/B×(1+b)/(1+a)：先算现期比重排除明显干扰项，再乘修正因子(1+分母增速)/(1+分子增速)验证选项
- 🧩 当题干出现'基期年份+A占B的比重'且材料只给现期值与各自增速时，用基期比重公式(A/B)×(1+b)/(1+a)，注意负增长增速代入(1-|g|)；先算现期比重A/B再乘(1+b)/(1+a)比分别求两基期量更快
- 🧩 当题干问“上年/基期某部分占总体比重”且材料只给现期量与同比增速时，用基期比重=现期比重×(1+总体增速)/(1+部分增速)，负增长代入1-降幅；判断方向：部分降幅大于总体降幅，则基期比重应高于现期比重
- 🧩 当题干出现'上年同期（基期时间）+某分量占总量的比重'特征时，用基期比重公式'现期比重×(1+总量增速)/(1+分量增速)'，先估现期比重再乘修正因子，对照选项区间验证
- 🧩 当题干出现'基期时间（早于材料现期）+A占B的比重'特征时，用基期比重公式=现期比重(A/B)×(1+B的增速)/(1+A的增速)，先截位直除现期比重，再按两增速相对大小判断修正方向验证选项
- 🧩 当题干出现'基期年份+占+比重区间选项'特征时，用基期比重公式'现期比重×(1+整体增速)/(1+部分增速)'，先截位估现期比重，再按增速比缩放定性判断升降，代入验证选项区间
- 🧩 当题干出现'基期年份+占……比重'且表格给出分子、分母的现期值与各自同比增速时，用基期比重公式(A/B)×(1+b)/(1+a)，先按a与b的大小判断比重相对现期的升降方向排除选项，再精算验证；分母必须按题干字面指标取数，不得换成嵌套项
- 🧩 当题干出现'基期年份+部分占整体的占比'且材料只给现期值与'增长N倍'增速时，用基期比重公式A/B×(1+b)/(1+a)，其中'增长N倍'须按(1+N)还原，先分别反推基期再求比值并对照选项
- 🧩 当题干出现'基期时间＋A占B的比重'特征时，用基期比重公式＝现期比重(A/B)×(1+B增速)/(1+A增速)；先用选项与现期比重的大小关系（比较a与b）排除，再估算修正系数锁定答案
- 🧩 当题干出现'上年同期（基期）某部分占整体的比重'且材料给出现期部分值A、整体值B及各自同比增速a、b时，用基期比重公式=(A/B)×(1+b)/(1+a)，先用截位直除口算现期比重，再按a与b大小判断修正方向（a>b则基期比重小于现期），结合选项排除即可
- 🧩 当题干出现'上年（基期年份）+某部分占总体比重'且部分与总体的现期值及各自同比增速均给出时，用基期比重公式=现期比重×(1+总体增速)/(1+部分增速)，先截位直除现期比重锁定量级，再按增速差方向微调对照选项
- 🧩 当题干问'去年（基期年）A占B的比重'而材料只给今年A、B两量及A、B各自增速时，用基期比重=现期比重×(1+r总体)/(1+r部分)；先截位直除求现期比重，再乘一个接近1的修正因子（分子总体、分母部分），按'略高于/略低于现期比重'对照选项即可秒杀
- 🧩 当题干出现'基期年份+部分占整体比重'特征时，用基期比重公式 A/B×(1+g整体)/(1+g部分)：先截位直除现期比重锁定约数，再用部分/整体增速大小关系判断修正方向，验证选项升降方向即可秒杀
- 🧩 当题干出现'基期时间＋部分占总体比重约是'特征时，用基期比重公式A/B×(1+b)/(1+a)（a为部分增速、b为总体增速），先截位直除估现期比重，再按a与b的大小判断修正方向，结合选项差距决定估算或精算
- 🧩 当题干出现'基期时间+A占B的比重'特征时，用基期比重公式=(A/B)×(1+总体增速)/(1+部分增速)，先速算现期比重再用修正系数微调；部分'下降'时增速带负号，修正系数与1的比较可先定答案方向。
- 🧩 当题干出现'上一年（基期）某部分占某总体的比例'，且材料给出现期部分A、总体B及各自同比增速a、b时，用 A/B × (1+b)/(1+a)：先算现期比重，再按部分与总体增速的相对大小乘增速修正因子，对照选项。
- 🧩 当题干出现'基期年份+A占B的比重约多少'特征时，用基期比重公式(A/B)×(1+整体增速)/(1+部分增速)：先算现期比重，再用'部分降、整体增→基期比重>现期比重'的方向性快速排除选项，最后截位直除或代入增速验证
- 🧩 当题干出现'基期时间+A占B的比重约为'特征时，用基期比重公式A/B×(1+b)/(1+a)，并用方向校验：分子增速a大于分母增速b时，结果应小于现期比重
- 🧩 当题干出现'上年（基期）部分占整体的比重约为'特征时，用基期比重公式A/B×(1+b)/(1+a)：先截位直除算现期比重，再按增速差定方向——部分增速a小于整体增速b则基期比重大于现期比重，选项中现期比重的数值必是干扰项
- 🧩 当题干出现'基期（上一年）某部分占总体比重'而材料给现期值及部分、总体各自增速时，用基期比重公式=现期比重×(1+总体增速)/(1+部分增速)，先由'部分与总体增速的相对大小'判定结果高于还是低于现期比重，再对照选项验证。
- 🧩 当题干出现'基期年份+某部分占整体的比重约为'且材料只给现期值与部分、整体各自同比增速时，用 基期比重=现期比重×(1+整体增速)/(1+部分增速)，先用增速比大小定方向排除，再截位直除选最近项
- 🧩 当题干出现'上年同期（基期）部分占整体比重'且材料只给现期值与同比增速时，用基期比重公式＝现期比重×(1+整体增速)÷(1+部分增速)，并用'部分增速与整体增速的大小关系'判断结果高于还是低于现期比重，快速排除选项
